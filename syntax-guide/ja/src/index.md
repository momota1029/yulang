# Yulang 構文ガイド

このガイドは、Yulang の構文を**書く人**の目で説明する。「この書き方は、こう読まれる」を、例で示す。

## どう読むか

- 各ページは、一つの話題について、書き方、読まれ方、よくある間違い、近い形との違いを並べる。
- 意味(何を計算するか)は `spec/` を見る。構文木の形は `syntax-reference/` を見る。
- 各例の下に、状態を書く。

| 印 | 意味 |
| --- | --- |
| 確定 | 仕様で確定している |
| 仮採用 | 旧版から起こした。細部が変わりうる |
| パース検査済み | 構文エラーなしで読めることをパーサで確かめた。結合の形の確認範囲は「例の検査」を見る |

## Yulang の構文の三つの特徴

1. **空白が意味を持つ。** `f(x)`、`f (x)`、`f: x` は別の構文として読まれる。→ [空白で意味が変わる形](whitespace.md)
2. **演算子は言語に固定されていない。** 宣言で作り、宣言を import したファイルだけが読める。→ [演算子は宣言で決まる](operators.md)
3. **`:` が「ここから本体」を表す。** 字下げのブロックを `:` で開く。式の中でも使える。→ [ブロックと字下げ](layout.md)

この三つを知っていれば、残りの構文の多くは、その応用として読める。
