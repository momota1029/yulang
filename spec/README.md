# Yulang 言語仕様（日本語）

この `spec/` は Yulang の言語仕様の正本。型推論の核の計算体系（Lean）は、この仕様を形式化したものとして別に置く。
実装は仕様に従う。実装の挙動と食い違ったら、仕様か実装のどちらが誤りかを決めるのはユーザー。

## 書き方の規則

- 日本語で書く。ユーザーが読んで把握できることを最優先にする。
- 各節に**状態**を付ける。
  - `確定` — ユーザーが確認した。
  - `要確認` — 素材（main の文書・実装）から起こしたが、ユーザーは未確認。
  - `未定` — 決まっていない。選択肢だけ書く。
- 素材から起こした文は、出典（`main:path`）を節の末尾に書く。出典を書けない文は書かない。
- 実装がそうなっているだけの挙動と、言語として約束する挙動を混ぜない。迷ったら `要確認` にして罠台帳へ書く。
- 例は `.yu` で書き、期待される型・出力を添える。例は後で実行して確かめられる形にする。
- 意味論を勝手に決めない。決める必要が出たら、選択肢と推奨を示してユーザーに聞く。
