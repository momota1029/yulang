# 罠台帳

直感と違う挙動、仕様と表示・実装の乖離を書き留める。ユーザーが随時足す。
各項目は「何が起きるか → どちらが正か → 状態」を書く。正しさの判断はユーザーが行う。

## 書式

```
### <短い名前>
- 状態: 確定 / 要確認 / 未定
- 現象: <最小の .yu 例と、実際に起きること>
- 期待: <言語として約束したいこと>
- 乖離の原因: <分かっていれば>
- 関連: <章 / 出典>
```
