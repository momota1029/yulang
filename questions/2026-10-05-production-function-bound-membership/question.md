## Requested scoped decision

For the production callback/function proof, what is the intended complete
membership rule for a source-owned Function endpoint such as the one generated
by `my id x = x`? The existing source and solver owners preserve its lambda
recipe, four polarized ports, and provenance, but do not define whether these
facts admit only source-witnessed observations or additional whole-root
observations compatible with the ports.

Please select one policy for the successor's production interpretation:

1. **Source-indexed complete relation.** Every root observation must have a
   finite source-constructor witness, including the actual introduction role,
   entry, body, result consumer, and future interactions. Conservative
   widening is allowed only at independently licensed local source/primitive
   relations, with that witness retained. This makes Theorem C's reference
   membership rule the production conformance target; it does not require a
   new carrier.
2. **Additional endpoint-compatible behavior.** Production roots may admit
   observations not generated by source constructors, provided their ports
   are compatible. This requires a separate exhaustive rule identifying
   exactly which alternatives are admitted and how each factors through
   retained evidence; Theorem C alone would not close the production bridge.

## Options and consequences

Option 1 treats the retained source recipe and existing `Rel_C`, occurrence /
incidence, paths, `K,D`, and subtraction evidence as the complete root
interpretation. The next proof can derive exhaustive inversion constructor by
constructor and then connect production roots to those witnesses. A source
counterexample showing that the source semantics itself needs an additional
root alternative would reopen this policy.

Option 2 preserves latitude for a coarser production interpretation, but needs
an independently specified membership grammar for root extras. Each extra must
be accounted for in the full correlated tuple and admit a scope-preserving
decoder or a separate direct proof that it embeds in the checked bound. No
current source or solver owner names such alternatives.
