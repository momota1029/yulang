# What is, and is not, represented in the test

| Claim | Actual positive test | Boundary or counter-test |
|---|---|---|
| Real installed parent and emitted child | `RowParentStep287.actual_step/generated`: checked registry, three-slot raw initial journal, parent class output and real where edge | `RowOuterBoundary287.no_outer_reach`: preserved raw source cannot pass the stronger fixed `GroundRoots` entry |
| Row in the shared type | `RowChildRaw287.exact_source` and `RowParentFrame287.after_exact`: row0 determines the R argument inside output `F(F(R(row0)))` | Changing only row0 in a fixed-type assignment can break the **source** condition; among assignments both already admitted there is no new independent ambient-row test (`RowPublic287.no_new_ambient_row_test`) |
| Direct row-position inspection | A point descriptor for R exists and the demanded argument is Known | `RowGeneratedChild287.pending_actual`: the real generated child is neither Failed nor Prepared; the selected parent has a pending child, not a rejected child |
| Dictionary with whole-type capture | `RowPayloadExact287.exact`: same complete assignment and exact leaf payload | The same complete Models predicate in the other registry cannot yield any root dictionary (`comparison`) |
| Semantic output descriptor | `RowSemanticMark287.all_models_support`: point F(slot1) denotes output2 | A mixed trusted cache cannot certify the descriptor, because the actual child is not ledger Discharged |
| Raw path closure | `RowActualPaths287.only_before/maximal_endpoint`, `RowClosure287.no_step`: one raw Step in either registry | Raw stability and conditional EvidenceAt do not imply complete dictionary production (`RowEvidenceAt287.stable_pending_without_dictionary`) |
| Executable fixture driver | `RowFixtureDriver287.exact_run`; independent `#eval` and `#guard` on both tree shapes | Output-only projection cannot distinguish them. The extra flag is computed from actual bounded inspection in this fixture, not a generally complete classifier. |

These tests use existing Lean operational and semantic boundaries. They
do not classify new Yulang2 parser inputs, prove a general B4 result, or
change any language or kernel rule.
