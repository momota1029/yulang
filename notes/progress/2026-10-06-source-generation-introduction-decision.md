## 1. Result: the missing rule now has concrete, different outputs

The main source-generation gate is **not proved closed from existing
Authority**. The new result is stronger than the preceding inventory of
missing premises: two actual source-owned local producers have been written,
their common ordinary source/address witness has been constructed, and their
different original certificates have been independently reviewed. Neither
producer takes the desired original profile as an input.

The first unresolved output is the **exhaustive original introduction
inventory** at the shared inferred contract of `f`. At the exact source,
one producer emits only the required immediate invocation schema; another
also emits a separately source-owned default over the result endpoint's
effect positions. Both obey the inspected partial formation, policy and
transport requirements. They disagree before a pending comparison, typed
capture attachment, actual receiving event, or handler execution.

This is relative non-entailment at that partial local interface. It is not
two complete Yulang languages, a differing accepted-program theorem, or a
claim that only these two language completions are possible. A further
source theorem could select one, exclude both, or justify another inventory.
What cannot be done is identify the earlier least **generated** footprint
with the complete **original** profile using the retained preservation laws
alone. Adopting either displayed exhaustive producer as intended meaning
requires an explicit semantic completion, unless additional Authority
derives that exact rule.

The proposed decision in §5 covers **all** new original `beta` introductions
of the exact finite tree. It does not merely answer a result-position
question while leaving implicit argument/binder defaults unspecified. It is
a concrete way to resolve the first source-definition cut, not another
conditional theorem claimed to close the main gate.

## 4. Why the new separation reaches a semantic output

Let `o0` be the existing Call origin, `A_c` the result endpoint of the same
`F_c`, and `Eff(A_c)` its independently interpreted decorated effect-position
domain. The local producers have exact definitions:

```text
S0: { Immediate(o0,beta,call.effect) }

S1: S0 plus ResultDefault(o_r,beta,A_c)
    o_r=FormalResultDefault(C,d_f,c,R_f,sigma,NoAnnotation(d_f))
    each s in Eff(A_c) realizes (o_r,beta,result.s,FullProtection,NoGrant)
```

Both are emitted from the source binder and resolved Call before `A_c` is
solved. A descriptor interprets an existing dependent schema; it does not
allocate its source origin. No typed Flow, capture attachment, receipt,
owner, activated receiver, extra Force or grant is created by inspecting
shape. Neither producer consumes a supplied desired `Gamma`.

The common source/address witness is the finite ordinary provider

```text
G=lambda(u,result(reify(result(literal 0))))
```

in a derivation-core Bind/Call context that supplies `G` to the exact `C`
and then supplies a returning integer carrier to the returned `step`.
Literal, Result, Reify, ordinary Pure introduction, Value entry, Name and
complete Call derive the inert returned `Thunk(empty,Integer)`. This is a
bounded ordinary operational/descriptor realization. It does not assert
that every admitted carrier of `G` is pure, prove a general complete-call
bound for `G`, or prove complete Function admission under Option A/2.

At that common raw joint valuation, S1 produces the original certificate

```text
Intro(o_r,beta,(result.latent.effect),OriginalResultPosition(c,A_c,latent.effect))
```

and S0 does not. The empty latent effect row does not remove its signature
position. The two executions can return the same inert value; their
original source certificates are different. If profile outputs are stored
inside a full valuation, the extended valuations differ in those canonical
outputs and project to the same original raw `nu,K,D`. This is not
port-wise witness selection.

The proof establishes compatibility of two expansions of the inspected
partial local contract and a concrete output discriminator. It does not
certify either expansion as the intended whole source relation. That is
precisely why declaring one exhaustive would add semantic content.

Two proposed ways to avoid that content do not establish closure:

- Uniform graft obeys `Interpret_nu(G[theta]) = Interpret_(nu composed with theta)(G)`.
  An already emitted dependent schema can obey this law while its concrete
  position extension varies with the descriptor. Preservation of origins
  does not prove completeness of the input schema inventory.
- For a common realization prefix, adding no-grant protection changes
  candidate visibility exactly under `B and not P and not G and J`, where
  `J` is a live matching added incidence. Expiry, an existing protection,
  or a local grant can remove this particular difference; they do not prove
  equality of all original admitted fibers, predicates and principal
  evidence. A later Pure call/Thunk elimination creates no automatic
  dominating callback boundary.

## 5. Proposed exhaustive original-introduction clause

**This section is a proposal for user adoption, not a theorem or approval.**
Its scope is only the exact resolved, unannotated captured-step component
and original `beta` associated with outer `f`. It specifies all **new
original beta-owned** introductions of that tree. Existing inherited
packets remain separate tagged inputs, including coincident static beta
identities. Broader annotation, computed-callee, multi-use and recursive
component rules are outside this proposal.

| Source node/action | New original `beta` introductions under the proposal |
| --- | --- |
| Outer `f` formal and binding | Own/group the permitted Call schemas; no separate binder or argument-position schema. |
| Inner `x` formal and binding | None. |
| Resolved `f x` Call | Exactly the immediate `CallOrigin` at `(beta,call.effect)`, FullProtection/NoGrant. |
| Formal-result default | **E:** none. **R:** exactly one source-owned `FormalResultDefault` schema over `Eff(A_c)`, as defined below. |
| Names `f`, `x`, `step` | Resolve/reference the original roots; no new introduction. |
| Inner `step` and outer `apply` Lambdas | No introductions beyond those generated in their bodies by this table; no public profile from private capture fields. |
| Inert Result and sequential Bind | No new introduction; preserve tagged inputs and apply independently justified typed correspondences. |
| Capture, typed value transport, actual receipt | No new introduction; use the existing packet/receipt rules with their actual premises. |
| Certified generalization/use | One joint renaming/graft of existing schemas, addresses, witnesses and constraints; no further implicit original schema. |

The two fully written local proposals are:

**E — immediate elimination only.** The exact table emits only `o0`.
For every well-formed realization of the shared signature,

```text
Applicable_original(C,beta,p;xi)
iff p=(beta,call.effect) with its original CallOrigin witness.
```

**R — immediate plus formal-result default.** The exact table also emits
one `o_r=FormalResultDefault(C,d_f,c,R_f,sigma,NoAnnotation(d_f))` before
solving. It realizes every decorated directed effect-observation address
`s` inside this same `A_c` as `(beta,result.s)` with full protection and no
annotation removal grant. `Eff` refers to the existing signature address
domain, not observed effect support, bare family equality, a current printed
type, or a Q-dependent set. Original applicability is exactly the union of
the `o0` instance and these `o_r` instances, with both witnesses retained.
There are no other implicit defaults in this tree.

Both proposals close the table with the same **exhaustiveness clause**:

> An original `beta` position is applicable if and only if it is realized
> from a schema permitted by this table, with that schema's original source
> witness. Realization creates no new source schema or typed operational
> edge. Coincident inherited positions do not create, erase or replace an
> original witness. All original policies, identities and scopes survive
> the existing typed transport; current activity is tested separately.

R has two finite schema nodes, not a proved finite enumeration of arbitrary
recursive signature paths. No new finite-presentation theorem is claimed.
E's singleton is an exact local completion, not an inferred ban on independent
latent profiles elsewhere. Neither proposal changes actual callable roles,
the selected ordinary-value formal outcome, callback B, or annotation rules.

The primary recommends E as the smallest explicit additional introduction
policy beyond the constructed mandatory seed. This is a design recommendation,
not a principality or behavioral theorem and not an approval. R is a concrete
alternative, not an exhaustive catalogue of every possible completion. A
different fully specified introduction table can replace both proposals.

Under `rules/design-authority.md`, the current request to finish the proof
does not choose E or R. The call-view design and a2 expressly leave this
producer open. Under `rules/question-board.md`, a proposed question and any
unapproved answer remain uncommitted; no approved-answer artifact is created
by the questioning primary. Research evidence and its review are committed
and pushed independently.

## 6. The exact remaining gate after that decision

Selecting the table supplies an intended **original applicability target**.
It is insufficient to mark full P, source generation or `FVIEW -> SRC` closed.
The following obligations are not silently delegated to the question:

| Obligation | Exact requirement / current status |
| --- | --- |
| Original profile derivation and contribution completeness | Derive/invert every original introduction under the selected table; retain every tagged contribution and its original position, including all independent inherited sources. |
| Full seed/refined relation | Define the represented whole rows at each internal stage and prove coverage/soundness against the direct original source relation. A static `Role0` cylinder is not this proof. The current evidence establishes no second semantic choice for this obligation. |
| Actual receiving and captured packet | Instantiate the source receipt schema at an independent actual entry, attach/retrieve the complete packet through the corresponding typed environment maps, and preserve `nu,K,D`, scopes and activity. Lexical capture alone cannot prove it. |
| Independent A | Collect every independently typed punctured context and every jointly admissible original world, including divergent carriers, responses, raw resumptions and future typed uses. The finite ordinary context constructor is established at fixed independent meanings; full-world inversion/adequacy remains. |
| Soundness and principality | Prove the generated relation matches the intended original source relation, preserves every original solution under stage changes, respects generalization/use scopes, and factors all independently valid views without losing correlations. |
| Production conformance | Preserve Option A and Option 2, including production-only members, with `D_C(xi) subseteq D_A(xi)` and `forall h in D_C(xi). P_A(h;xi) subseteq P_C(h;xi)`. No source-only trace definition substitutes for production membership. |

Actual provider role/entry and independent ambient interpretation can remain
declared later premises; they are not permissions to backsolve source-owned
facts from Q. No production code or shadow semantic-discharge code is
authorized by this report. The existing shadow source/evidence plumbing is
left unchanged.
