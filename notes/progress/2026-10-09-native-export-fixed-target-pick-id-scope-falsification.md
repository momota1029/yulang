## Derivation of the first missing premise

Fix J_0's actual decorated value `(0,p_0)`, one compatible enclosing world,
the two actual root records, and their original scopes. Specialize the two
payload types to Int only for this audit; preserve the whole original inlet I.
Pick's Fixed clause changes completed body/result equality. It does not
require its argument to return J_0 and does not skip Force of its argument.

For any completed independently admitted argument challenge h, write its
actual entry result as `(a,p_a)` at the formal-rebind event. The canonical id
source proof carries that same pair to its body and outward result. The
authentic pick proof reads `(0,p_0)` from the installed capture instead.

Suppose a proposed root-relative producer map transports the canonical id
proof to Fixed while preserving the same complete tuple and all providers.
At completed BodyValue/Done, the target equality then requires

```text
EqEntry(h): (a,p_a) = (0,p_0).
```

This is a **necessary condition**, derived by substituting the canonical id
result into the Fixed equality. It is not a sufficient map: original read,
world-restriction, invocation and hereditary proof fields still need typed
producers at their actual scopes. PE §6.1 explicitly preserves those fields.

For a Function proof, the obligation is over every target-admitted h and every
relevant complete source record. Thus the required premise is a domain-wide
producer of EqEntry, rather than an equality for one chosen argument. If the
ordinary source record being compared is broader than the canonical id/Echo
record, this necessary-condition argument still applies to the included
canonical id records; it does not prove sufficiency for additional alternatives.

The first unsupplied certificate is the root-relative scope/operand map. Its
first completed-value obligation is EqEntry at the original id formal event.
Neither common lexical scope nor the authentic pick membership proof supplies
this obligation for id. Own-head target validation establishes that Fixed is
a valid descriptor at pick's own recorded operands, not that the same actual
id callable/provider satisfies it. Replacing id's callable by pick's callable
also fails the same-runtime-value/provider premise of ordinary Value checking.

## Five attempted routes and their precise limits

| Route | Evidence actually supplied | First unsupplied obligation |
| --- | --- | --- |
| Shared lexical scope | Both installed bindings/contracts are accessible in a compatible world. | Equality between the independently forced formal result and J_0; access does not identify bindings. |
| Capture/read transplantation | Pick has authentic `ReadCert(z)` and J_0 restriction evidence. | A typed map to id's original `ReadCert(x)` and formal-rebind occurrence. The owning source operand remains x. |
| Whole renaming | Existing telescope, equations and incidences move together; rigid J_0 stays fixed. | Renaming cannot turn a formal-origin read into an external-capture-origin read or insert a capture into id's empty registry. |
| Fix a carrier t | A candidate can stipulate that t returns J_0. | An authentic complete Car certificate plus all same-event/evidence producers, and a reason every challenge of the unchanged target uses that t or has EqEntry. |
| Actual argument/use evidence | A resolved read of the installed z can give that same decorated value at an actual completed source use. | Transport from this one use to the unrestricted original target domain, plus all original intermediate/future proof fields. |

The `id z` route is useful evidence for a single source use **conditional on**
its authentic Name-to-carrier construction and complete current-world law.
It does not require a new capture in id. Even granting that construction,
specializing one challenge to t is not a proof for all independently admitted
target challenges. Adding a new t-only admission predicate would compare a
different restricted target; no such scope change is authorized here.

Under Draft §6.3, transplanting pick's derivation fails to supply the same-id
component derivation and original source occurrence alignment. Calling the
whole lexical block one component does not remove the designated original id
root and its corresponding formal Name occurrence. This classifies the given
transplant, not all semantically sound Function views or all possible proofs.

## Conditional discriminator, not a source counterexample

The smallest semantic discriminator is one completed admitted carrier whose
return pair differs from J_0. Explicit additional hypothesis H_sep is:

```text
At the original comparison scopes and compatible world there exists an
authentically source-licensed Car(I,t,...) challenge returning (1,p_1),
with its complete admission, world and hereditary certificates.
```

**Conditional obstruction.** Under H_sep and the unchanged target admission,
the canonical id Done result is `(1,p_1)` and Fixed requires `(0,p_0)`.
Since `1 != 0`, no same-tuple, provider-preserving map sends that record to
Fixed. This uses one input completion and one body/result observation; pending
phases and future elaboration cannot repair the failed completed equality.

The schematic source discriminator is `id 1` versus `pick 1` in the common
block. H_sep's actual literal-to-whole-carrier/source challenge construction
was **not audited within this lease budget**. Therefore this note does not
present that schematic program as an established source-licensed
counterexample. It gives an explicit conditional derivation and identifies
exactly what a source producer would have to establish. The established
own-head J_0 literal construction alone does not establish H_sep.

an adversarial audit of five proposed scope routes. No model/checker assumes
and then purports to prove these source transition rules. The separate
