## 2. Smallest distinguishing case and exact hypotheses

Keep one source artifact S, one formal `d_f`, one shared variable v/root R_f,
one Call c, its literal a=1, lexical Name `u_f`, and distinct checking upper
use `u_c`, under one original scope sigma and assignment `xi=(nu,K,D)`.
Keep the literal, carrier, complete result, admission and whole operation
fields unchanged. The discriminator needs only these additional premises:

1. The unannotated formal has its independently justified protection seed k
   at this original upper exposure. This is the selected source premise, not
   protection inferred from a solved Function or from comparison success.
2. That source use has the upper constraint `v <: U`, with complete demand U
   and designated covariant output-effect occurrence
   `i_up=(S,c,u_c,U,outEff,sigma)`.
3. An independently present provider/recursive lower constraint `L <: v`
   has original occurrence
   `i_low=(S,provider-declaration,l,L,outEff,sigma)`.
   It is not another upper use and is not rewritten into one.
4. In the one shared assignment the effect readouts coincide:
   `effect(i_up;xi)=effect(i_low;xi)=e`. Original occurrence identities remain
   distinct. No independently supplied lower protection is being deleted.

Premise 4 is an explicit conditional hypothesis, not a proved solver result
for this source. The directional addendum requires distinct provenance when
endpoints coincide; Application_N §8 also distinguishes noninjective endpoint
substitution from nominal occurrence identification. Neither statement proves
an inhabited full provider/Call solution at this particular tuple. No such
inhabitation is claimed here.

Let `New_k(i)` mean protection newly introduced by this seed/exposure step,
excluding inherited marks. The selected positive and negative directions give

```text
New_k(i_up) = true
New_k(i_low) = false.
```

The second equation says that this step contributes no lower mark. It is not
a claim that an actual provider event is unprotected, that its effect row is
empty, or that other rules cannot supply independent marks.

**Conditional no-factorization theorem.** Under premises 1–4, no global bit
`b(e)` keyed only by the solved effect endpoint represents this new protection
at both original occurrences.

**Derivation.** If `New_k(i)=b(effect(i;xi))` for both occurrences, premise 4
forces both to equal b(e). The selected direction forces their values to
differ. Contradiction. This uses the direct selected positive/no-backflow
contract, rather than a checker which assumes that contract.

**Mutation and failure.** Replace the complete collector's occurrence-indexed
mark `(k,u_c,i_up)` with one bit at e. If the bit is true, it newly marks the
provider lower occurrence; if false, it loses the upper mark. Both violate
the selected direction. Swapping upper/lower occurrence readouts while keeping
e fixed likewise fails; such a swap is an adversarial implementation mutation,
not a legal role-preserving whole action. An implementation that retains the
two indexed readouts passes this discriminator.

There are two occurrences and one shared effect endpoint. Removing either
occurrence removes the no-backflow comparison; separating endpoints allows
two endpoint bits; removing the seed removes the positive conclusion. This
is minimal for this particular information-loss claim. It is not claimed to
be the smallest accepted source program in the whole language.
