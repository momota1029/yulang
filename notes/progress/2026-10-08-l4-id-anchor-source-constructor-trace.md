## 5. Earliest unsupplied premise and discriminator

The exact first gap is an authentic `JointWF(C_init,w_init)`/W record containing
its valid registry/scope/authority/incidence tuple and original event fields,
before either Lambda formation or literal ResultBind. SG §2 L4 names this
premise; NC §2.1 describes its retained contents. The current source judgment
fixes the actual event/anchor at entry (SG §3), then constructs descriptions
and publication from it. It is not a theorem that these source strings
inhabit an original world without those inputs.

The tempting bootstrap does not work: IR §4.1 Lemma W says environment
constructors are valid whenever their independent semantic inputs are supplied.
Its Empty case uses **the joint world's empty environment**. Its concluding
paragraph says the induction creates neither a future world nor a newly valid
provider. Import/capture project old evidence; rebind consumes old W and new V;
Return consumes both. Neither empty telescope nor raw closure allocation
discharges the jointly valid registry/authority tuple. Positive recursive-pair
introduction is not an initial-context theorem for these nonrecursive programs.

Concrete documentary discriminator for any claimed unconditional bootstrap:
keep the resolved `my id x=x`, source slots and empty captures fixed, and remove
the independent initial registry/authority/incidence evidence. The same syntax
still matches Parameter/Lambda shape, but the W input is absent, so valid Return
or BindIntro cannot be derived by the displayed rules. Restore that evidence
and the conditional chain can proceed. This is a premise-removal witness, not
an independently legal source counterexample or an executed rejection result.

The bounded absence conclusion is falsified by exhibiting a selected constructor
that, from only already supplied pre-initial inputs, concludes this complete
initial W/JointWF record with every registry/authority/incidence/lifetime field
and registers the formed callable. A rule requiring W as an input, an empty
binding list, or a bare validity flag would not be that falsifier. No attempt
to fabricate such a rule or search a wider source catalogue was made here.
