## 2. Smallest native cases and the fixed-J typing distinction

Fix one frame, a prechosen ordinary Unit description r, the independently
valid pure Unit carrier/context inputs of the uniform inlet's ground instance,
and one actual completed decorated result x=(v,p,e). Let J.payload=r and
let theta be the actual returned VCert(r,x). Retain the original port map,
intrinsic/current guards, whole J certificate and bare-id delta_check. This
is an admitted constructor instance relative to those independently supplied
inputs, not a claim that every proposed root has such inputs.

At this occurrence, Identity(r) relates theta to that exact same theta.
Compose(Identity(r),Identity(r)) retains theta as its intermediate and both
Identity children. Compose and Identity tags remain distinct. These are the
smallest two proof forms relevant to the packet.

Suppose the target description alone becomes a different actual registered
root s, while J stays fixed. The required signature is now r -> s.
Identity(s) has signature s -> s; Identity(r) has r -> r. Neither is a proof
of the required signature. Compose of either pair of identities remains
diagonal at its own root and cannot repair this. This follows from dependent
typing even if r and s have equal printed shapes or identical raw denotations.

For a whole root action H with H(r)=s, every occurrence of r must move
coherently, including J.payload when it is that root. Such an action reaches
the J/Car/formation domains as well as the VCert domain. It is not the fixed-J
case. If the coordinate A is instead specialized independently while a rigid
J.payload remains r, this is a different checked description and needs a new
independently licensed finite r -> s proof.

Legitimate fixed-J checked instances can exist when the selected L catalogue
actually supplies that inclusion. For example, an authentic Top/Any checking
law may check the same r result at Any while keeping J unchanged. This uses
that genuine law and original result incidence, not Identity retagging.
It is one-way checking, not an inverse root action or preservation of the
original Identity proof choice. A registered equivalence rule could justify
another case only with its actual typed premises and both directions. None
is inferred from endpoint shape, soundness, or the existence of a bijection
outside the selected finite checking grammar.

## 3. Restricted conditional theorem

Let E_a(x) denote the actual VCert(a,x) evidence fiber. Supply a coherent
action H on the full endpoint/incidence telescope, and for each endpoint used
by the chosen Identity/Compose tree supply

```text
B_a,x : E_a(x) <-> E_H(a)(H(x))
```

where these are actual typed inverse functions on the already independently
formed domains. Here H fixes the selected raw value/provider/source anchors;
if an event coordinate moves, its independently valid domain moves too.
For every required independently compatible restriction chi, also supply

```text
B_a,x' (restrict_a,chi(theta))
  = restrict_H(a),H(chi) (B_a,x(theta)).
```

Require the coherent forward/inverse maps on the original scope and incidence
fields read by this tree. This theorem is about local checking records; it
does not assume or conclude a complete transported gamma, J admission domain,
or delta_check.

Identity transport sends (theta,theta,Identity(a)) to
(B(theta),B(theta),Identity(H(a))). Equality is preserved by a function and
reflected by its inverse. Compose transport maps the two child records and
the *same retained* intermediate through the one B for its endpoint. Hence
the children still meet at that intermediate. The inverse reconstructs every
proof field, and the Compose tag is retained. Induction on finite trees made
only of these two forms proves a bijection on their complete local checking
records. The displayed hereditary equation gives the same statement at later
compatible result events. No proof irrelevance or canonical witness selection
is used.

Claim class: conditional theorem. The structural Identity/Compose consequence
is derived; domain formation, endpoint bijections, hereditary naturality and
incidence actions are hypotheses. Additional structural, primitive, equation,
continuation or guarantee rules need their own premises when actually used;
this proof does not cover them by naming L. For a fixed-J r -> s specialization,
the Identity case above is unavailable, even if a target E_r <-> E_s bijection
has separately been proved: the original finite proof still lacks an admitted
cross-endpoint checking constructor.

## 4. Minimized hypothetical open-kernel witness

To separate the endpoint hypothesis from the local diagonal rules, consider
two independently registered ground roots r and s with the same raw Unit
membership at one decorated unit value/provider. At every event in any
supplied compatible history domain, provision the independent ground-evidence
slot by

```text
E_r(x) = {u}
E_s(x) = {u0,u1}.
```

Each token independently witnesses the same genuine Unit membership.
Keep it across every supplied hereditary restriction. The histories, raw
value/provider, actual worlds and incidence guards are shared; this example
does not truncate their domain to a finite trace. Tokens are the original
ground witnesses, not extra fields added to a selected native constructor.
Identity uses exact token equality at each root; Compose retains its exact
middle token. Selected Bind/Project/Restrict/Return records can carry whichever
actual typed token their input already has without changing these local laws.
Restriction never changes the root or identifies tokens. CE keeps them exactly
and substitutes only raw aliases. Thus all these inspected local operations
place no equality-of-cardinality condition on the two independent ground slots.

There is no inverse pair E_r(x) <-> E_s(x): a function from the singleton has
one image, so it cannot cover both distinct s witnesses. A right inverse is
impossible. Even adding a sound one-way rule choosing u0 cannot supply the
missing inverse. Equal scalar membership therefore does not imply an exact
evidence action preserving every retained witness choice.

This is minimal among nonempty finite-fiber cardinality witnesses: a changed
root needs two roots, and unequal nonempty fibers need at least one versus
two witnesses. Identity alone suffices; Compose confirms that retaining its
intermediate does not impose a cross-root equation. The witness is a logical
non-entailment example for the *unspecified independent ground-evidence slot*,
not a full source/descriptor/world model. Its authentic declaration, embedding
into the selected ground interpretation, target registration licence and any
permitted actual H are not supplied. Consequently it is not asserted to
satisfy an exhaustive selected VCert grammar or to occur in an admitted
Yulang program. In particular, it is not a counterexample to §3 or CI-use:
the required bijection premise fails, and an identity-sensitive ground
registration may instead be rigid.

The candidate assumption exposed is: each proposed movable actual root's
independently selected evidence domain already has a typed invertible action.
The selected local laws do not manufacture this from soundness or tag shape.
The cardinality witness changes the independent ground-kernel slot only as a
hypothetical assignment; it does not propose changing Yulang's selected law.
