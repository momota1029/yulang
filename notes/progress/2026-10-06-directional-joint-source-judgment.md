## 1. Result

For the directly selected unannotated-formal example, source registration can
produce the seed witness used by the directional Apply bridge. It need not
remain an unrelated supplied `ProtectedVarAt` fact: the ordinary parameter
constructor allocates the inferred endpoint, actual annotation absence supplies
the selected protected-variable treatment, and the resolved callee Name reuses
that endpoint. Applying the reviewed original Call constructor then produces
the upper occurrence and its designated output effect. These logical
dependencies establish the certificate at this exposure without inspecting a
solution. They do not define a general provisional-role introduction judgment
for arbitrary source components.

An existing lower Function constraint does not defeat this derivation. It
remains a separately oriented constraint on the same original endpoint. Its
effect receives no new mark from this rule, even when its denotation equals
the upper effect. Independent provider protection remains active.

Ordinary-value role refinement is not protection release. An admissible
same-root refinement preserves this seed's protection and the incidences
already derived from it. This retention result does not require choosing
whether one or every use triggers role refinement. It also does not prove
that a full semantic refined relation covers every seed-stage solution.

The extension to several original upper uses is a conditional composition of
these source constructors, with one binder seed and shared root. The extension
through generalized use additionally needs the already available **whole**
source-origin/freshening certificate. Such transport conserves applicability;
Name lookup creates no new unannotated-formal seed for a known external value.
Actual recursive source formation and generalized-use production do not yet
construct that certificate in the governing rule inventory.

For a fixed finite set of certified source facts, complete saturation is
schedule-independent. That result cannot manufacture a missing seed-at-exposure
certificate for an earlier exposure. The missing late-seed clause is localized
in §7 without selecting it.

## 3. One joint source judgment

Use the following **proof notation**, not a new solver/runtime carrier:

```text
Gamma; Sigma |- C => (Phi_C, W_C)

Sigma : original binder tree and registered source roots
Phi_C : all original, independently interpreted source constraints
W_C   : dependent source constructor certificates, in that same tree
xi    : one original (nu,K,D), shared by Phi_C and every interpreted certificate
```

`Phi_C` includes actual role/entry, provider and result packets, complete
argument/call/annotation obligations, admission/descriptor/observation clauses
where independently supplied, and every original upper/lower constraint.
It is not a product of per-port projections. `W_C` contains original source
identities and their typed correspondence, not a definition of those semantic
predicates as unconstrained flags. Existentials stay below each rigid binder
on which they depend. Captured roots remain imports at inner generalization.

For a directional incidence its index is

```text
(k, d_f, v, R_f, beta, sigma, u, U_u, p_u)
beta = (d_f,R_f)
p_u  = designated output-effect OCCURRENCE of original upper U_u
```

`k` identifies the original binder's protected-variable seed, `u` the source
upper checking occurrence, and `sigma` their original scope/correspondence.
The lower occurrence has its own index. Type-port equality does not equate
these indices. Several `u` can share a profile slot; counting uses does not
compute the complete `Slots(beta)` inventory.

### 3.1 Registration in the directly selected case

For the exact selected `apply` formal, combine two existing premises:

```text
ordinary unannotated parameter d_f
  -- typed-core parameter constructor --> Gamma(d_f)=Value(v), fresh inferred v

actual annotation absence at this selected higher-order formal
  -- selected protected-variable treatment --> Seed(k,d_f,v,R_f,sigma)
```

The second arrow records the selected **instance** of source policy, not a
general `NoAnnotation -> Protected` axiom for arbitrary Name occurrences.
Its causal datum is on the original binder. It introduces no actual Handler
role for a supplied callable and no empty-row equation. The exact symbolic
ordinary formal is registered in the Lambda environment before deriving its
body. This logical premise order is enough for the selected seed-stage body
exposure; it is not a global scheduling algorithm or an SCC replay policy.

The same registration establishes a common contract identity. `R_f` can be
represented by the existing source-call constructor's dependent root label;
registering its original identity does not solve the complete interface.

### 3.2 Resolved use and upper Call

Name synthesis copies `Gamma(d_f)` at the actual resolved/captured use. The
selected nested-block correspondence fixes that read to the outer formal.
Result adds the ordinary return wrapper while retaining the provider packet.
The reviewed Call constructor at `c=f x` then emits, before solving:

All conjuncts and the original scoped existential for `F_c,e` remain. `J_x`
is the actual returning Name computation, not an arbitrary computation with

decorated receipt/profile premises; this derivation does not rename them into

### Theorem S1: exact selected source seed-to-incidence derivation

Under the selected nested source correspondence and the reviewed ordinary
Name/Call constructor premises, registration of the actual unannotated `f`
derives the directional protection at `p_0`. The independent arbitrary
`ProtectedVarAt` hypothesis in the Apply bridge can be replaced by this
registration/correspondence derivation for this selected seed-stage occurrence.
Neither call satisfiability nor complete original-profile formation is needed.

**Proof.** The parameter constructor introduces the symbolic endpoint `v`.
The selected binder policy produces `k` on that endpoint before its body
exposure. Resolved Name and the exact capture correspondence preserve the
original binder/root/scope and inherited packet. The Call constructor emits
the original upper occurrence and complete-invocation output address using
that same endpoint. These are exactly the two premises of `Dir-Protect`.
All semantic checking clauses remain obligations in `Phi_C`. QED.

This is a bounded actual source-constructor composition. It is stronger than
assuming an unexplained local stage certificate, but it does not construct
the general provisional-role/recursive supplier required by call-view §5.

## 4. Lower-first and multiple original uses

### 4.1 Lower-first is harmless in this precise sense

Let `l:L <: v` be existing original recursive/provider information at this
same registered formal. Retain its whole independently interpreted predicate
and packet in `Phi_C`. Recording `l` before the upper Call does not change
the registration, Name or Call premises of S1. A lower bound also does not
convert the original variable occurrence into a source annotation or known
external Name. The conclusion is still at `p_u`, never at `outEff(L)`.

This statement is about lower information coexisting with a justified
formal seed. It does not assert that an arbitrary recursive SCC creates such
a seed, or that insertion of a lower constraint preserves all typing solutions.
Its admissible solutions remain `Phi_C and Interp(l)`, possibly empty.
If upper and lower effect endpoints coincide under `nu`, the two occurrence
indices and their inherited protection predicates remain distinct.

### 4.2 Conditional original multi-use composition

Suppose a resolved ordinary source derivation has already registered this
selected seeded formal and contains finitely many original direct Call uses
`c_i`, each with a same-root Name/capture certificate and a seed-stage exposure
on that inferred endpoint. Applying §3.2 to each gives

```text
Phi_calls = original scoped conjunction of every G_call_i and every lower
W_calls   = one original k plus all (k,beta,u_i,sigma_i,p_i)
```

There is no independent choice of `xi_i`. Every call witness is bound in the
original tree over the same shared free root and original `xi`. The proof is
induction on the source derivation's constructor occurrences, reusing the
Name rule and Call rule for each leaf and conjunction for composition.
Lower-first ordering changes neither derivation nor incidence output.

This establishes the directional conclusions **given this source envelope**.
It does not classify every multi-use binder as eligible for the singleton
policy, choose mixed-use role aggregation, or extend the exact nested-block
authority to arbitrary recursive local syntax. Each Call's argument tag and
complete obligation remains present even if another use supplies ordinary
Value evidence. Source-level protection and role aggregation are separate.

## 5. Role refinement retains protection; full coverage is still unproved

The authoritative distinction between source annotation, public scheme and
internal inferred view prevents treating the provisional Handler seed as an
irrevocable equation on the actual supplied callable. Conversely, the ordinary
Value argument's `NonHandlerFormal` result grants no effect-removal permission.
The formal-seed-elimination derivation's failure list explicitly excludes both
deleting provisional consequences without proof and using role determination
as protection release.

### Theorem S2: source applicability conservation under compliant role refinement

Let a source-specific role refinement on the same original root retain the
original protection seed, constraints, packets, scope and use correspondence,
as the governing sources require. Then every S1 incidence and its original
`ProtectedVarAt` certificate survives that refinement. For another original
upper exposure on the still-inferred same root with the retained seed and
same-root source correspondence, §3.2 derives the same directional rule.

**Proof.** Its seed, binder/root/scope and source upper occurrence are retained
premises, independent of the role tag being refined. The only conclusion
producer is `Dir-Protect`, which contains no actual-callable role or
`NonHandlerFormal` premise. Reapply that rule to the retained premises.
No annotation grant is introduced, so the refinement has no source premise
for releasing protection. Packet conservation retains independent lower
marks. QED.

S2 is a retention/constructor lemma for a compliant refinement, not its
existence or solution coverage theorem. In particular the qualifier
“still-inferred” is an original source-stage fact, never a test of the
currently solved endpoint shape. No claim is made that an arbitrary later
comparison becomes an original source upper exposure.

### The exact full seed/refined relation obligation

Let `Sol_seed(C)` and `Sol_ref(C)` denote complete independently interpreted
source relations at the original scopes, not raw role-coordinate domains.
Let `Bridge_C(s,r)` retain their common original assignment, all original
constraints, provider/result packets, protection incidences and inherited
evidence. A full source coverage theorem must prove

```text
for every s in Sol_seed(C), there exists original-scope r in Sol_ref(C)
  such that Bridge_C(s,r),

and every refined source derivation in the claimed envelope reconstructs
  its original seed-stage source derivation with that same shared assignment.
```

The corresponding existential display is shorthand for the original binder
tree, not `exists r` moved outside dependent rigid scopes. Inverting ordinary
Name, Result and Call supplies the endpoint, upper orientation and complete
checking witnesses in §3. It does **not** supply the last role-refinement rule
connecting `s` and `r`. The approved singleton result requires that rule's
outcome but expressly leaves its eligibility and transition open. For several
uses, the rule must also specify how their evidence combines on one contract.

Therefore S1 and S2 prove no totality or equality of these full relations.
Conjoining `NonHandlerFormal` to the seed relation, or appending a canonical
role record, would not prove the displayed existential extension. It could
discard old solutions; interpreting seed and refined roles as contradictory
actual-role equations would already violate the chosen example. The missing
source bridge is precisely the eligibility/lifting plus semantic
solution-preservation clause, with multi-use aggregation where needed.

## 6. Recursive formation, generalization and coherent freshening

Monomorphic preallocated recursive **references** in the decorated source
contract reuse registered roots. Conditional on independently justified
seeds/call correspondences at those roots, S1/S2 compose on every finite source
derivation. No unfolding chooses a different assignment or provider per
recursive visit. This is the contract's finite-derivation convention, not a
new source recursive-binding inference judgment.

For certified generalized use, let `r` be one capture-avoiding injective action
on eligible owned coordinates, fixing original imports/captured roots. Copy
the whole `Phi_C`, original binder tree, `K,D`, incident source certificates,
profile/packet fields and designated export. Retain any direct client query
as a new query, not as a source proof of protection. Then

```text
r(ProtectedVarAt(k,v,sigma,u)) = ProtectedVarAt(rk,rv,r sigma,ru)
r(SourceUpperUse(u,v,U,sigma)) = SourceUpperUse(ru,rv,rU,r sigma)
r(NewProtection(k,beta,u,sigma,p)) = NewProtection(rk,r beta,ru,r sigma,rp).
```

Here `rk` denotes the transported original seed identity/correspondence, not
generation of a new seed at the Name. A fixed captured `f` remains fixed;
distinct incoming uses freshen owned identities separately; repeated
occurrences inside one use use one map. The original evidence behind any
permitted joint hiding remains bound once at its original position, including
all latent providers and challenge dependencies. No source occurrence,
receipt or owner identity is quotient-merged merely because type ports agree.

The proof is transport of the **source derivation**: Name maps its environment,
Call maps its complete ordered operands and one checking occurrence,
Dir-Protect maps both premises and the designated occurrence. Applying the
inverse on its image proves reflection. This is more specific than a graph
isomorphism, but conditional on the certificate's source correspondence.

The missing constructor is the source supplier of this full origin-bearing
recursive generalized interface/use certificate. The Name conservation lemma
shows why looking up that interface cannot construct its origin retroactively.
Legacy Q/R restoration and a fresh allocator label are insufficient. The
authoritative body-to-root integer slice and F4 SCC infrastructure do not
cover Function/effect formation. Thus actual arbitrary recursive/member-use
coverage remains open, with no F5 or Oracle scheme shape imposed as target.

## 7. Certified-fact saturation and the actual late-seed gap

Fix finite, already certified source facts `F`: binder seed facts, original
source upper/lower occurrences, same-root/scope correspondences, and explicit
seed-at-exposure derivations. Let `T_F(X)` add precisely all `Dir-Protect`
conclusions whose certified premises are present, retaining `X` and inherited
marks. If certified alpha transports are included, add only their licensed
images in a fixed finite use inventory. Lower records have no protection head.

### Theorem S3: saturation is independent of enumeration schedule

Every exhaustive fair rule schedule from the same `F` produces the same least
closed set. For this one-step Dir-Protect producer, the closed set is exactly
the conclusions of all certified matching seed/exposure pairs, together with
inherited marks and licensed fixed-use transports.

**Proof.** Each rule only adds a fact; all heads lie in a fixed finite universe.
Every derivable fact is produced after its finite premise derivation by fairness.
Every produced fact has such a derivation by induction on additions. Therefore
the result is exactly the finite derivability closure. A monotone worklist
order, including enumeration of a lower first, cannot change it. QED.

S3 accommodates a seed fact arriving late in enumeration **if its original
applicability at the earlier exposure is already certified**. It does not
replace that certificate with the conjunction `Seed(k,v)` and an old upper.
The addendum §3 expressly leaves arbitrary late-seed replay unselected.

The missing late-seed interface can be localized as

```text
original source SeedIntro(k,d_f,v,sigma,t_seed)
original source UpperIntro(u,v,U,sigma,t_upper)
their source-stage relation / scope / common-root derivation
---------------------------------------------------------- [not supplied]
ProtectedVarAt(k,v,sigma,u)
```

For the selected registration-first source derivation, §3 supplies this
stage relation without a global timestamp. For an SCC-generated or generalized
seed not grounded by that registration, neither source-root equality nor
the saturation proof chooses what relation between introductions licenses the
conclusion. A complete source formation rule must decide/derive that premise
and prove its coverage. This note selects no retroactive rule, aggregation
policy or removal policy. The absence is in source applicability production,
not in joining already certified records.
