## 1. Result and scope

The complete Call contribution's **relational interpretation is available**
in the existing source-contract and source-indexed constructor rules. An
additional arbitrary contribution ID is unnecessary. A contribution can be
represented by an index of that complete dependent relation, rather than by
one execution, an effect endpoint, a syntax position, or an outward support
set. Likewise, bijective changes of slot-table representation are harmless

Neither observation supplies the correspondence to the **exact original**
signature/owner/view kernel's slot and contribution coordinates. Total graph

new coordinate for an old active coordinate. This audit therefore does not

source obligation is the inhabited, source-typed fiber of that original
kernel over the independently interpreted complete invocation family, followed
by exhaustive original licensing inversion. The conditional construction below

## 3. Construct the dependent relation before choosing a representation

Fix the approved resolved source C and one original candidate whole row X.
Write `F_C(X)` for the relational family constructed by source-contracts
§§2.1,3.2 and source-indexed callback realization §§3.1–3.2:

```text
F_C(X) = J_f >>= (actual_f =>
    ExecuteCallable_X(actual_f,Delay(J_x); original U, original view operands))

J_f = ReturnImage(Name(d_f), original environment)
J_x = ReturnImage(Name(d_x), original environment).
```

This is a family over the same original parameters, with all complete
observation, provider, current-state, continuation and scope coordinates.
Its generic clauses have independently specified meanings; they are not an
uninterpreted `Callable` atom. At an actual Value-entry provider it contains
receipt, the one designated argument Force, typed rebind, body, designated
consumer and invocation return. Retained entry binds the same inert carrier
without that Force. An operation's native return is followed by its original
declaration-derived result consumer. Request composition retains

```text
Request(q,C,k) >>= S
  = Request(q,C, (response,C') => k(response,C') >>= S).
```

Thus the complete family keeps the original suffix and current resumed state,
including finite prefixes that suspend or diverge before any result. A
representation index of F_C is not an event, a realized computation outcome,
or the raw source expression. Giving the index its explicit denotation removes
the invalid cast `c=j_call`. It supplies a possible representation of the
semantic contribution family; it does **not** identify an original c already
used by an active kernel.

The independent local constructor typing obligation remains explicit:
source-contracts §2.2 requires descriptor typing for every emitted observation,
and §3.5 invokes local descriptor typing lemmas. Coverage allocation §6.1
covers callee evaluation and complete receiver output but retains the whole
non-coverage kernel. Accordingly the family is constructible before solving;
its independent complete typing, original profile predicates and original
owner/view constraints are not proved merely by constructing it.

### Complete root versus the target upper view

For the exact source, J_f and J_x are returning rebound Name computations.
The inner argument is not the carrier that previously entered `step`.
Its actual source return does not recursively force a latent returned value.
For this case the callee-evaluation prefix is event-free, conditional on the
original Name/result interpretation.

A generic Call can instead have an effectful computed callee. Its pre-invocation

## 4. Original fiber, rather than a fresh-ID substitution

Let `I_orig(X)` be the independently interpreted original signature/owner/view
incidence relation. The research sort `t=(beta,s,p,c)` projects fields of an
original incidence witness; it must not be supplied by constructing numerical
labels. Define only the following **query on that existing relation**:

```text
Fiber_C(X,e0) = {
  (t,w) in I_orig(X) |
  t.beta = original beta,
  t.p is the original typed p0,
  w owns t through original (d_f,R,u,sigma_x),
  w types t.c at the same complete receiver-invocation family F_C(X),
  w retains the original provider/result arms, scope, xi and all dependencies
}.
```

The equations are structural source/typed correspondence premises, not endpoint
equality tests. The displayed fiber keeps **all** existing witnesses. It selects
neither one c per use nor the number or sharing of original slots. Any actual
kernel may present its ownership and typing evidence with different fields;
the query's semantic conditions must then be translated to those fields.

The complete original contribution contract need not equal the exact trace
support of F_C. A conservatively licensed contract may contain additional
complete observations. Its original typing/authority/dependency conditions and
its coverage of this source invocation must hold on the same X. One must not
require a source execution for every such observation, or create a fresh
original signature incidence for each production-only member.

The first source existence clause, if independently proved, is now concrete:

```text

```

This clause is a proof target, not a newly accepted rule. Its premises must
not contain the fiber witness itself through a renamed complete-profile

## 5. What a slot-table isomorphism can and cannot prove

For any already supplied typed table T, a bijection h of its representation
labels is an isomorphism only when it preserves beta ownership, upper origin,
typed path, complete contribution, original scope/binder dependencies and
source-arm identity, and coherently acts on **every** membership/admission/
provider/kernel predicate that reads those labels. Under those hypotheses,
inverse substitution gives equal complete relations and admission domains.
This is one whole coherent renaming, not independent port or witness choice.

For a passive derived index F(X), the total graph extension
`{(X,z) | X in R, z=F(X)}` projects back to R. That is the already reviewed
total-definition principle. It establishes representation existence even
without an inhabited R. It cannot prove that z equals an active original c,
or manufacture an original slot s. If R already uses s,c, their exact
correspondence must be proved before substituting a different representation.
Redefining those old kernels to read z would change the theorem target.

A many-to-one collapse is not a bijection. Equal endpoints or equal printed
Function shape do not justify collapsing contribution provenance, original
slots, provider arms or receiver activations. Conversely, rejecting such a
collapse does not choose a slot-sharing law for the language. The precise
law is about an original typed table, not about how many integers a generator
allocates.

## 6. Downstream audit and generalized limits

Selected SV already constructs prospective `argument.result.(u,p0)` at receipt
and actual rebound/capture/read only at their actual original transitions.
It keeps a Pending packet and original suffix during suspended/divergent
entry. This is not a missing opaque capture rule on its reviewed independently
typed/profiled envelope. It also does not supply original complete row/profile
existence or unrestricted general source coverage.

For an actual event, original complete contribution typing does not replace
`Observe(q,V,p_exec)`, matching same-view `Receive`, typed correspondence to
p0, or the actual original receiver/handler liveness. Repeated raw resumptions
preserve the original receipt and receiver; a fresh execution owner does not
revive an expired boundary. Two dynamic invocations can share static beta and
have different receivers. Own-upper and inherited-provider packets stay
separately indexed even when both carry the same static beta or endpoint.

Independent initial admission additionally needs a typed punctured context,
whole carrier contract, original import/provider/world predicates and the
designated port/suffix. Subsequent history induction uses typed response,
original raw handle/current state and actually returned future provider ports.
The four constructor inventory supports an induction once those independent
leaves are proved; it is not itself their inhabitance proof. All-world union
ranges over independently valid contexts, including ones unreached by this
source. No bounded reachability search defines that domain.

Beyond the exact case, computed/grouped callees, annotations, recursive
generalized views, mixed uses, nested result exposures, generalized/imported
contracts and late seeds need their own source ownership/typing clauses.
Our table query makes these extensions visible instead of forcing every
licensed incidence through the exact graph's sole direct exposure. Option 2
does not remove original ownership requirements and does not impose a source
constructor on every production observation.
