## 1. Result and the premise which changes the preceding cut


[inferred-call-view decision](../design/2026-10-05-inferred-function-call-views.md)
§2 supplies a source-formed shared callback contract and stable slot `beta`;
an annotation is not prerequisite. The reviewed selected source registration
and Call construction identifies that slot with this original formal and
upper use. The current directional decision supplies the profile fragment.

Thus the slot's source status is not obtained from `VIncl` success. The
receiving view is constructed from the original formal contract **before**
checking, and subsequent checking remains an obligation. At an independently
typed original invocation, typed-boundary §6's introduction applies to this
source slot. Its receiver is the activation receiving the formal, `r_A`.
The upper position is lifted under the **source-known carrier result prefix**
before entry as prospective result-path evidence. Actual entry rebind removes
that prefix only if the original carrier returns. Before Return there is no
actual rebound `f` value, binding view, local `step` capture or captured read.
Requests retain the same prospective packet and the original pending entry
suffix. Every finite divergent prefix remains covered without fabricating a
result. On actual Return, the binding is constructed; capture/read use it only
when their original source transitions execute.

This proves a narrower result than total inference or all-source adequacy:
the constructor is total as an unsolved schema producer, and its realized

typed original source rows, including complete finite prefixes and raw
resumption developments, and their original compatible profile completions.
It proves neither such rows/completions exist nor that every raw argument
has independent admission. Those inputs do not assume the generated
boundary/view identity, capture association or `SourceViewInst` conclusion.

The preceding DFRAG theorem remains a reviewed conditional dependency. This
note supplies its prospective receipt association unconditionally at actual
receipt, its selected rebound source-view on actual result transitions, and
its ordinary environment association at the original capture/read transitions,
using the slot semantics which that theorem did not compose. It does not

The prior reviewed capture inversion also remains correct for interface-only

## 6. Paired erase/reflect on complete original prefixes and resumptions

Two different erasures must be distinguished. Forgetting dependent source
labels reconstructs the same source graph; that is a useful but insufficient
record theorem. The substantive theorem concerns original typed source
semantics whose slot already supplies the selected invocation view. It does
**not** compare that source semantics to an unprotected provider-only machine.

Let `S_C` be the independently interpreted original source-kernel relation
for this selected ordinary graph, retaining **all** original constraints,
carrier/provider data, results when they actually occur, scopes, roles/entries,
source profile and admissions. It contains the original prefix relation and
all independently admitted typed-response/raw-resumption developments,
including divergent or indefinitely suspended carriers. Their admission is
not narrowed to executions with a returned formal value.
The source-slot introduction/typed transport/receipt laws in §§2,4–5 are its
independently specified primitives, not Boolean flags defined as this
generator's success. It uses the common typed-boundary kernel within that
package's reviewed conditional scope. `S_C` is not a claimed complete
production Function membership grammar or complete Yulang raw-source judgment.

Let `G_C` retain those same whole original predicates and add the constructor
certificates for the actual receiving occurrence, prospective carrier result
lift and pending suffix, and the conditional-on-transition rebound binding,
environment capture and read. Actual result/capture/read identities occur
only at their corresponding original source transitions. Every fresh identity
is a witness at that introduction, with references retained through transport.
No endpoint variable, family predicate or provider witness is independently
duplicated. Existentials remain in the original binder tree.

### Theorem SV: exact constructor extension on this interpreted source envelope

For every independently typed original source row and complete admitted
finite prefix/resumption history `s` of `S_C`, the constructor supplies a
whole original-scope row/history `A(s)` of `G_C`, unique up to coherent
fresh-label renaming. Before a result transition its certificate is Pending;
after an actual result/rebind it contains that Rebound certificate, and
capture/read certificates occur only for the original transitions reached.
This quantifies over histories of admitted carriers which may diverge or
remain suspended, not only histories of eventually returning carriers.
Conversely, erasing the constructor certificates from a `G_C` history
reconstructs an `S_C` history with the same whole original tuple, prefixes,
raw-resumption handle developments and source-semantic behavior:

```text
E(A(s))=s
A(E(g))=g up to coherent fresh labels, for canonical generated g
E(Sol(G_C))=Sol(S_C).
```

Here `Sol` retains original constraints together with the complete prefix
and response/resumption relations, including the Pending summand; it is not
a set of Return-only observations. The equalities are pointwise on those
original relations. A family of compatible prefixes stays compatible under
the causal constructor; the theorem does not assign a result at an infinite
limit or invent an infinite-history semantic clause.

**Forward receipt.** Invert the original parameter/call constructor to obtain
the actual receiver, whole carrier and original entry suffix. No result
witness is extracted unless the original derivation has a Return. Invert its
source-slot invocation law to obtain the boundary/profile introduction
governed by `beta`, independently of provider `VIncl` success. The original
directional policy and known carrier-result prefix construct exactly `P`.
This supplies the Pending case and retains every original carrier/provider
predicate and packet component in the same row.

**Pointwise entry lifting.** Relate each original residual `Force(t) >>= S`
to that same residual with `P` and its exact pending suffix witnesses. For
an original running prefix, execute the same original transitions and retain
`P`; its prospective result position adds no executing observation, demand,
dispatch change or liveness. For an original Request, use the request-bind
equation of §4: expose the same `q` and retain the appended `S` in that
very raw handle. For each independently admitted typed response and current
resumed state, apply the relation to the original `k(response,C_resume)`,
with the same `P`, original receiver reference and suffix. The original owner
protocol determines activity; the decoration supplies no new live owner.
This also applies on each repeated resumption, retaining the original history
sharing rather than selecting separate continuation witnesses per port.

For an original Return at occurrence `h`, retain its **actual** value/provider
packet at every original administrative cut and advance the original `S`.
At its actual rebinding transition, apply the existing result-removal map
to `P` and that returned/provider packet. This is the only Rebound transition.
Continue execution of the original `S`,
with the original body and consumer/return delimiter in order. At an actually
reached Lambda introduction, construct the resolved captured binding image;
at an actually reached Name, construct its read image. Later suspended,
divergent, or returning body/future executions use the same ordinary
prefix/request-bind argument and their original evidence. Do not preexecute
the pending capture/read templates.

These cases establish the lifting by induction on each original finite
execution/interaction history, reusing the original recursive reference when
its derivation advances it. Every admitted finite prefix of an original
divergence therefore lifts. A prefix which stops before any Return remains
Pending; there is no need to prove a Return exists in order to complete the
finite-history induction. Internal original transitions, when exposed by the
source prefix relation, are matched unchanged; the construction introduces
no additional computation step that could make that residual converge.

**Reverse reconstruction.** Invert the generated Receipt-Upper and recover
the same original source slot, profile, actual receiving invocation and
carrier. Pending erases to its actual original prefix and suffix, with no
invented `v_f` or binding. Request erases to the same actual `q`, raw handle
and original appended suffix; each response/resumption erases to the same
admitted source extension and original owner mapping. Rebound inversion
requires and recovers its actual original Return/result witness; then reapply
the original result transport. Env-Capture/Read require and recover actual
Lambda/Name transition witnesses and erase to those constructors with the
common typed environment image. Thus no generated history can acquire a
result/capture/read without the corresponding original source transition.
Each generated Call retains the whole original Function, argument and
complete invocation obligations, not merely two successful port comparisons.
Bind and Result reconstruct the same source constructors and actual providers.
All original upper/lower/role/admission/descriptor predicates remain conjuncts
at the same scopes. Induction on the finite prefix/interaction history gives
the reverse lifting, including histories with only Pending evidence. Original
occurrence identity, imports, provider roots, receiver references and `K,D`
identities are fixed; fresh labels use one coherent renaming. QED.

This is semantic extension on the explicitly independently interpreted
