## 4. Conditional construction and derivation

Under P, K and T define the actual checking map by

```text
kappa_arg,j(e_a) = wrap_O,j(extract_N,j(e_a)).
```

The common-index certificate in K is used between extraction and wrapping;
the same primitive witness is reused. It is not a chosen canonical proof.
This constructs target membership from an actual source member, so it does
not manufacture membership when the N fiber is empty.

Losslessness follows directly. If `kappa_arg(e)=kappa_arg(e')`, apply
`extract_O` and its first inverse equation to get
`extract_N(e)=extract_N(e')`; apply `wrap_N` to get `e=e'`. An inverse on
the image is `wrap_N(extract_O(-))`. No reflection or surjectivity for
arbitrary original alternatives follows from the weaker image-only version.

For any licensed coherent action theta, including admitted restriction to
a later live event, calculate at the transported dependent indices:

```text
kappa_arg,theta(j)(theta_N e)
 = wrap_O,theta(j)(extract_N,theta(j)(theta_N e))
 = wrap_O,theta(j)(theta_K(extract_N,j(e)))
 = theta_O(wrap_O,j(extract_N,j(e)))
 = theta_O(kappa_arg,j(e)).
```

Identity and composition use the single declaration action and the coherent
index certificate. Neither N's component laws alone nor a syntactic port map
justifies the middle equations for an actual original use.

Consequently K excludes the predecessor's asymmetric action *within these
faithfully paired fibers*: both actions come from the same retained primitive
witness action. This does not show that K holds for the actual source uses,
or that the predecessor's hypothetical action is source-licensed.

Transport the entire tuple in dependency order, rather than independently
choosing projection witnesses:

```text
(prefix_N, e_a, e_out, operation_evidence, suffix/future_evidence)
  -> (P(prefix_N), kappa_arg(e_a),
      T_result(prefix_N,e_a,e_out),
      T_operation(prefix_N,e_a,e_out,operation_evidence),
      T_suffix(prefix_N,e_a,e_out,operation_evidence,suffix/future_evidence)).
```

Here P includes the supplied complete Result action. T's constructors consume
the already transported prefix/check fields, so each target dependent fiber
is the correct one. Repeated extraction gives a left inverse for the entire
transported tuple. Substituting the individual action squares in telescope
order proves the whole tuple square. The proof requires their common action
and common dependent indices; separately existential component witnesses
are insufficient.

The suffix map retains callee Bind and pending Delay construction, then the
same actual U's receipt, own entry, body, designated consumer, native delimiter
and complete return. Value entry keeps designated Force and typed rebind;
retained entry binds the same carrier. Operation entry keeps its declaration's
MakeRequestThunk/native-return delimiter before designated consumption.
Resumed/late tails are the actual remaining ordered tails; receipt is not
replayed. A future slot uses its arm's actual output provider and current
world. These follow from the supplied authentic suffix interpretation and
selected schedule, not from F_c's printed shape or Receive-N alone.

This is a conditional theorem about faithfully realized reference uses. No
new semantic rule, runtime certificate, solver API or source acceptance law
is proposed. It neither constructs arbitrary external carrier validity nor
attaches a decorated `g,m` to the source owner.
