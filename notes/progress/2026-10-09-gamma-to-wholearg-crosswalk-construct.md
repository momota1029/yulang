## Claim classification and failure conditions

**Established input results:** authentic native gamma introduction,
`DataArg` assembly in the stated envelope, and same-witness `PackGeneric`
admission, under their selected independent local laws. This note reuses those
results and does not claim new independent certification of them.

**Bounded characterization derived here:** the attempted selected IF primitive
reference requires an actual checking declaration before any mapping into its
ordered fields can be typed. In the inspected assigned clauses that declaration
is a generic independent input, so the constructive crosswalk has no target
instance. The exact premise is the primary's selected source/dependency route.
It is not a theorem of repository-wide nonexistence, source rejection or
incompatibility of the native and independent definitions.

**Candidate assumption, unused:** declaring the complete `WholeArgCompatible`
fiber definitionally identical to gamma (or gamma plus PackGeneric) would fill
the stop only by selecting an independent-kernel meaning. No assigned authority
states this identity, and this note does not adopt it. Equality of witness or
predicate names has no evidential force.

No new conditional transport theorem is claimed. A future crosswalk fails if
its declaration is only a schema; if the callee cannot be inverted at the same
native inlet; if target admission narrows/deletes a J alternative; if a binder,
incidence, provider/current world or proof choice is changed; or if target action
compatibility is only assumed from slot formation. A target using a genuinely
foreign fixed inlet needs its own independent contract bridge.
