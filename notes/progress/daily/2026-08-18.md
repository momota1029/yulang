## Phase 0

`docs/yulang3-architecture.md` §14 冒頭が要求する 5 つの成果物を順に実装した。

### Y2 reference tag

- main HEAD `a58eefc3` を指す annotated tag `yulang2-oracle` を作成し、push した。

### Versioned compatibility corpus

- yulang2 の `tests/yulang/cases.toml` にある stable-core 73 件を、
  `tests/contracts/stable-core/v0/` へ機械的に変換した。内訳は run 38 件、check 19 件、
  public-signature 16 件。
- ディレクトリは kind / backend / result を優先して
  `run/vm/pass/<case>/` などの形にした。期待値は plain file へ分散し、source は case-local に
  コピーした。`corpus.toml` には oracle tag、commit、blob SHA を記録した。
- 全件について元データとのバイト単位の一致を exhaustive に検証した。コミットは
  `dca10f60`。

### Benchmark workload set

- §8.4 の 9 カテゴリに対応する runtime workload を `tests/perf/runtime/v0/` に作成した。
  対象は cold startup、warm startup、direct recursion、ordinary function call、
  effect operation、single-shot capture/resume、multi-shot nondeterministic branch、
  mutable-state effect、text/list allocation、representative showcase。text/list allocation を
  2 件に分け、合計 10 workload とした。
- 一時 git worktree `/tmp/yulang2-oracle-worktree` で `yulang2-oracle` tag を実際にビルドし、
  全 workload の実行と出力を確認した。コミットは `5a56a5c3`。

### Benchmark runner

- 新規 Rust binary crate `tools/bench-runner` を 1,589 行で実装した。corpus 走査、SHA-256
  検証、machine identity 収集、correctness preflight、warmup と sampling による計測、
  median / MAD / p95 / geometric mean の集計、JSON 出力を持つ。
- yulang2 は canonical instruction count などの work counter を公開していないため、
  該当フィールドは `"status": "unsupported"` として記録する設計にした。
- unit test 4 件の成功、release build、dry-run の成功を確認した。コミットは `41338c62`。

### Machine baseline

- bench-runner を全 10 workload、3 warmup + 20 samples の本番設定で実行し、
  `benchmarks/baselines/runtime-v0/yulang2-oracle.json` に保存した。
- 全 10 件で `correctness.status = "passed"` を確認した。コミットは `c971a2e5`。

以上により、Phase 0 の Gate 条件である compatibility corpus、runtime benchmark の
JSON / runner / workload set、固定 machine の baseline が repository に存在する状態を満たした。
Phase 0 は完了とした。
