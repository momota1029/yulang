# 2026-09-04

## G4b ordinary projection controls

The isolated source-free rewrite now routes an adjacent projection opener
before the ordinary field branch. `a.(x,y)` emits `ProjectionTupleTail`, and
`a.{left,right}` emits `ProjectionRecordTail`; both reuse the existing direct
delimited item/close loop and finish their own Rowan node before the enclosing
tail scans again. The focused `a.(x,y).{left,right}` control fixes their flat
outer-chain placement and the direct `)`/`}` owner relationship.

Record spread, record colon items, malformed item/separator/close recovery,
mismatched close, layout, production promotion, AST parity, Yumark, and the
remaining G4b/Gate 4 controls remain deferred. Focused rewrite tests passed
17 cases; package check, format check, and diff check passed.

## G4b decimal integer core

The source-free rewrite now accepts the old parser's decimal lexical core:
one or more ASCII digits. The transactional scanner owns that maximal text as
an `Integer` Item, and the direct NUD emits `IntegerLiteral(Integer)` before
reusing the ordinary tail loop. The `123(a).field::name` control establishes
that integer cores keep the same flat Call/Field/Path continuation as an
identifier core.

ML argument vocabulary beyond identifiers, other literal forms, recovery,
layout, production promotion, AST parity, Yumark, and the remaining G4b/Gate
4 controls remain deferred. Focused rewrite tests passed 18 cases; package
check, format check, and diff check passed.
