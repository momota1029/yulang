now Authoritative. It supersedes raw-fence behavior only for a fence whose
first info atom is exact case-sensitive `yulang`; all other languages retain

the untouched line to outer quote handling and yields one fence Missing. A
multiline lexical item stores only a current-item split-offset sidecar, built
linearly and moved after completion; it is neither a row/body buffer nor parser
state.
