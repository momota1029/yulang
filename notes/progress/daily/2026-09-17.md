## Syntax completion-policy reset

The user explicitly approved ending the exhaustive pre-implementation CST-slot evidence loop after it consumed the available model/review budget with diminishing architectural information.

Recorded decision:

- retain the one-lossless-Rowan-CST architecture, structural `Missing`/raw `Error`/`Invalid` recovery facts, accepted-input/recovery contracts and eventual parser-ledger retirement;
- freeze the current accepted grammar/direct-CST topology as `syntax-v0` for the next implementation phase;
- replace the old requirement to audit every recovery-bearing slot before implementation with representative structural proof;
- permit a deterministic generic CST-derived structural diagnostic for uncataloged occurrences, with no parser-ledger/relex/replay fallback;
- treat only a concrete structural collision, accepted-input bug, active vertical-slice requirement, explicit new feature or release certification as a reason to reopen syntax/schema design;
- stop using unmapped catalog rows as an automatic queue;
- move next to a shadow CST diagnostic interpreter, then effective-table unification and a smallest-existing-fixture CST -> HIR/type vertical slice.
