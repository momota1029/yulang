## Recursive-descent rewrite Gate 1: `with_str`

Gate 1 is complete. `In<&str, R, S>::with_str` consumes an owned `In`, runs its
operation through a short reborrow, and returns the operation result with the
exact borrowed source prefix consumed from the current cursor. A nested caller
that retains its outer handle writes `i.rb().with_str(...)`. This is source
capture only: it adds no transaction, cursor correction, allocation, lookahead,
next-item cache, or source rewind.

`ParserOnceStrExt::with_str()` is an input-independent blanket extension whose
`WithStr` wrapper implements only `ParserOnce<&str, R, S>`. That keeps wrapper
construction inferable while preserving generic recoverable and committed
state. It maps only successful parser output to `(output, consumed_str)`;
non-match remains the wrapped parser's existing transaction.

Focused witnesses cover nested capture, UTF-8, CRLF, zero consumption and
borrowed pointer identity, successful parser capture, tuple non-match with
input/`R` restoration, and non-unit `S` success. `cargo fmt --check -p
chasa-recover` and `cargo test -p chasa-recover --no-fail-fast` passed with 15
unit tests and zero failures. Compiler/referee and regression M2 reviews
approved. No broad workspace check or timing ran; Gate 2 remains next and no
production `yu-syntax` dispatch changed.
