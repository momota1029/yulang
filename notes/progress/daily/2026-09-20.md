The user rejected the active canonical-endpoint candidate's retained interval
model. The controlling valid binding witness is now `42 : int`,
`int <: definition.value`, then positive expansion/simplification
`definition.value -> definition.value | int -> int`. No literal value variable,

Read-only compiler, architecture, specification, and performance audits traced
the frozen oracle's propagation/positive compaction mechanism and confirmed
that the current Yulang3 component-to-component relation is admitted but
ignored by its boolean interval solver. The new Draft
`2026-09-20-simple-sub-direct-int-expansion-supersession-draft.md` replaces the
unapproved candidate. It makes integer occurrence values direct canonical

fact for an integer binding, and bounds R1 to one-pass inline root expansion and
simplification. Revised direct/binding N contracts are respectively
`N/2N/4N` and `2N/3N/6N` for components/facts/endpoint incidences; no timing
experiment is warranted before counter evidence exposes a material risk.

The proposal is Reviewed, not implementation authority. M3 compiler,
specification, and performance reviews are clean after one bounded repair/delta
round; user approval remains required. Names, schemes, generalization,
definition effects, generic closure, and unrelated effect changes remain
