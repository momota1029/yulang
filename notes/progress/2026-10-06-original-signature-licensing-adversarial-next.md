## Objective and result

Attack recovery of complete original slot/contribution licensing from the
single observed upper introduction, source-use multiplicity, equal endpoints,
or retained profiles. The bounded attack produces **no admitted source pair
and no competing complete slot profiles**. It identifies which multiplicity
mutations can preserve the exact approved source identities and why those
mutations cannot presently discriminate complete licensing.

Repeating the derivation of the same tagged original occurrence cannot add a
distinct relational fact. Later invocation can add dynamic occurrences while
retaining that original occurrence. A second distinct source Call changes the
approved source graph. Merging distinct original identities is forbidden;
sharing a slot while retaining those identities is not forbidden by the
directional decision. Neither observation selects a slot-sharing law.

This is a bounded unsuccessful attack with a small conditional representation
lemma. It is not a proof that the language admits multiple meanings or that
no counterexample can exist. The earlier callee-prefix discriminator,
`Attach_C` factorization and current-source supplier map are retained inputs,
not repeated attacks. No Oracle shape-folding witness is reproduced.

## First attempt: duplicate or collapse uses without changing source identity

Separate five counts: proof occurrences, dynamic activations, original source
upper occurrences, static slots, and transported incidence occurrences.
Only the original source-upper count is fixed as one by H1. The others are
neither interchangeable nor inferred from that count.

For a set `I` of fully tagged incidence records and a fixed correspondence
`M`, H3 gives:

```text
I union I = I
M_*(I union I) = M_*I
```

Proof: membership in either union is the same disjunction twice. In the
image, the existential source path and complete original tag are unchanged.
Duplicate derivations of an identical tuple add no relational member. The
same holds for repeated proofs of the same conjunction on `X`. No bound on
the number of licensed incidences follows: their formation is not defined
by this set equation.

This **conditional representation lemma** handles exact duplicate evidence,
not two different actual calls. It does not permit collapsing ordered Bind
operands, fresh events, receiver activations or their current configurations.
Those are distinct whole-tuple operands. Nor does it license a fresh slot
identity just because the proof was copied twice.

| Mutation | Identity-preserving outcome | Licensing discriminator obtained? |
| --- | --- | --- |
| Copy the proof of `e0` with the same complete tags | Same original relational fact | No; no new source premise |
| Invoke returned step again, if independently admitted | Same original `u`, potentially fresh event/receiver occurrences and current world | No static-slot conclusion; admission remains supplied |
| Clone the Call in the core and give it the same original `u` | Two presentation references to one original occurrence, or an unjustified source-to-core duplication | No authorized second original source use |
| Clone the Call and give it distinct original `u1,u2` | Different original source graph | Outside the exact nested-block interpretation; broader derivation not supplied |
| Merge distinct `u1,u2` into one original identity | Loses required original position identity | Violates FVIEW; cannot form an authority-consistent witness |
| Retain `u1,u2` but associate them with one static slot | Preserves use witnesses if a source slot relation justifies the association | Directional §4 explicitly allows this possibility; no association law proved |

The last row is not an instantiated source pair: H1 supplies no `u2`.
The generic decorated grammar contains Bind/Call, but does not itself derive
the source meaning of a changed braced candidate or a complete slot profile.
Consequently `twice` in source-contracts §8 is not authorization to rewrite
this exact block and treat the new source as an admitted licensing witness.

Any proposed cardinality implication needs an additional source premise.
Even a total function from exposures to slots would be an assumption:
existing work permits a relational attachment, with multiple contributions
per exposure and shared slots across exposures. Neither singleton exposure
nor duplicate proof count supplies exhaustive origin inversion.

## Second attempt: merge inherited and newly introduced contribution records

Typed transport can combine actual-provider and projected result evidence at
the same target path. H3 retains each input's source tags and original
predicate identity on the same `X`. Directional §4 additionally preserves
the original upper/lower occurrence distinction even at equal endpoints.

There are two different mutations:

1. Erase source-arm/original-occurrence tags and identify records by target
   path, endpoint value or printed protection. This mutation discards the
   named retention premises. Its lossy representation cannot certify a
   source-origin inverse. It is not an alternative licensed profile.
2. Keep all original tags and let inherited and newly introduced records
   arrive at the same typed target. The resulting record still distinguishes
   their origins. No new beta-owned introduction follows from arrival.
   An inherited record of the same static beta also retains its original
   introduction; the beta label alone does not make it a fresh introduction
   at the current boundary.

Identical fully tagged facts can be idempotently repeated by the lemma;
distinct retained origins cannot be converted into identical facts without
losing a tag. This does not prove that two distinct origins require distinct
slots. The original licensing relation must determine their slot association.

Recovering a **complete** original inventory from a local transported packet
also needs an independently proved coverage/reflection property. The image
formula transfers only paths in `dom(M)`. Provenance retention for transferred
witnesses does not state that every original licensed position lies there.
The persistent original evidence graph preserves supplied input evidence,
but its persistence does not certify that the input inventory was complete.
No additional latent position was inserted to manufacture a countermodel.

This attempt leaves the same original licensing premise as the first.
It therefore stops here. A larger duplicate-shape model or an arbitrary
licensing truth-table would leave that premise untouched again.

## Precise blocker, failure conditions and claim boundary

The missing discriminating input is a source-derived original incidence
`t=(beta,slot,signature-position,contribution,original-origin)` and a source
licensing judgment deciding its association on this same `X`. To compare
two complete profiles, both must additionally satisfy the independently
interpreted complete-row and admission obligations on the claimed scope.
Neither the present inputs nor the preceding reviewed producers supply that
complete witness.

The attack can resume if an independently grounded formation rule yields two
distinct original incidences in the exact component, or if a separately
authorized broader source derivation supplies two uses and their complete
slot associations. It could then test whether a proposed quotient loses a
required association while retaining every original identity. A full-row
pair must keep descriptor, carrier/provider, world, response/history and
Option A/2 obligations active; no successful `Q` or hand-picked identity
execution can replace them.

No conclusion of logical semantic underdetermination follows from the open
proof. Assigning different values to an uninterpreted licensing atom would
only exhibit the weakness of an abstract axiom list. It would not establish
two source-derived authority-consistent alternatives, an admitted history,
or a reason to reopen the selected language decision.

Established inputs: one original upper introduction, preservation of source
identity, selected no-backflow, and previously reviewed limited transports.
New result: the conditional proof-duplication lemma and bounded mutation
classification. Open: original licensing construction/decidability,
exhaustive slot coverage, same-row profile nonemptiness and admission,
generalization/principality, source adequacy and production conformance.
