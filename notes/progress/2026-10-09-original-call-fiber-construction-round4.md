The existing same-context delay/force administrative law permits the displayed
core Call; retaining reify/eliminate is also legitimate. The outer construction
is the approved `lambda(f,bind(step,result(lambda(x,call(n_f,n_x))),
result(name step)))`. It retains the same captured `f`, returns the local
closure and does not execute the latent body. Symbolic endpoints and a
Function demand remain constraints, rather than solved invocation bounds.

Write `T` for the core translation, avoiding confusion with original `X`:

```text
J_f = T[n_f] = Return(lookup d_f)
J_x = T[n_x] = Return(lookup d_x)
J_src = J_f >>= ((actual_f,C) =>
    ExecuteCallable_X(actual_f,Delay(J_x),C))
```

This is the complete actual invocation at the source diagonal. The carrier
that entered `step` is not substituted for `J_x`: its entry already obtained
the rebound value read by `x`. Nor does `Value(A_f)` select the actual
provider's Handler/Pure role or entry.

```text

Request(q,C,k) >>= S = Request(q,C,(r,C') => k(r,C') >>= S)
```

The resumed state is current; receipt is not replayed. Callee-prefix effects
remain distinct from the designated receiver upper view. These equations
describe the image; their semantic descriptor typing is still `H_typed`.

Let `R_U_all` retain the predecessor's full invocation construction evaluated
