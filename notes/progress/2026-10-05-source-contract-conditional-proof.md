## Routes rejected or repaired

### Source probes do not cover all desired instances

A proposed effect probe would emit each contributor's allowed request to
derive its inclusion in the public output. This fails when an earlier stage
cannot return, an intermediate type is uninhabited, a branch is fixed by a
retained predicate, or an opaque provider prohibits the probe. Requiring a
quiet returning prefix for every type assignment cannot cover `never`.

The selected conditional route does not use that hypothesis. Its independent
conservative allowance clauses retain both branches and a bind suffix even
when not executed. Exact execution remains the soundness reference. Exact
trace-valid views omitting unreachable contributors can be outside this
abstraction; no source rejection follows.

### Saturating every old endpoint is invalid

Replacing original `E_j` or `E_out` by a common `W` can violate a retained
literal, declaration, annotation or arbitrary original predicate. The final
construction preserves those endpoints. A public view's source derivation
maps each original source occurrence to its own endpoint; the public allowance
is separate. Only the fresh common coordinate receives `W`.

### Exact execution and a may-bound are different

An exact-image predicate conjoined with a coverage condition that is already
entailed by that image cannot explain a genuine bound observation or altered
provider admission. The proof instead quantifies over a whole provider's
admitted may-bound observations and all finite future interactions. Its
non-coverage challenge domain stays fixed. Retained original contracts actively
constrain the actual common root, rather than merely appearing in provenance.

### Source syntax cannot force missing resolver alternatives

The source conformance checker can prove how an emitted relation is assembled.
It cannot force a sound but incomplete direct resolver to accept a coverage
widening. The local whole-query proof rules are therefore stated separately.
The theorem's proof constructs a finite derivation from them, rather than
assuming that semantic inclusion is recognized by an unspecified resolver.

## Finite evidence

Command:

```text
python3 tools/research_source_allowance_contract.py
```

The isolated Python model uses two fixed dependent type assignments, two
declared families and 40 providers per assignment, with distinct provider and
returned-provider identities, finite ordered request histories, return versus
nonreturn and conservative declared may-bounds. It checks:

- 3,200 typed provider pairs;
- 40 conservative provider bounds whose may set is larger than their trace;
- 648 complete joint absorption cases;
- 648 independent finite allocation-view cases, including a public allowance
  strictly wider than a fixed original output bound;
- 128 empty correlated domains among the original-bound combinations.

Explicit negative cases detect dropping old provider bounds, independently
projecting correlated providers, checking only an exact trace, forgetting
dependent request arguments, overwriting the old outer endpoint, and widening
an input domain while only checking equal output guarantees. A nonreturning
prefix also separates exact empty-output validity from the conservative
allocation rule; the source remains valid with the larger allocation.

The additional three-point whole-tuple model enumerates all 512 binary rewrite
relations and all 8 constant-extra sets. It checks 110,592 guarded
extensivity/envelope cases and 884,736 ordered source/guard comparisons. Its
explicit negative cases show why dropping the complete guard, using unmatched
extra relations, or testing absence from the source relation defeats the
proof. A nonempty constant extra is admitted even for an empty source base.
This verifies the finite algebra shape, not a concrete Yulang abstraction
primitive or the production membership grammar.

This finite experiment does not execute current HIR, generate source endpoints,
implement the certificate calculus, test actual lexical/rigid scope handling,
or enumerate all histories. The unbounded claims rest on the proofs, not the
finite counts. No production Rust files, compiler tests or broad suites were
changed or run for this gate. `git diff --check` passed after the mathematical
repair. A focused relative-link check of the theorem, this record, task file
and design index found no broken reference. No broad suite was required for
this documentation/research-only change.

## Applicability and next concrete gate

The source/core already supplies actual entry ordering, whole argument
retention, stateful bind, roles and the one-assignment discipline. Current
HIR/F5 tests provide bounded source-root/endpoint linkage evidence. They do
not supply the exhaustive source-plus-abstraction membership grammar or its
generalization/use conformance. The policy permitting extra observations is
now approved; the exact grammar and its primitive contracts are not.

The local contract is ready for review as a proof-before-code candidate. A
durable successor choice would still have to adopt the active presentation
meaning, the coverage/component interpretation and finite whole-query rules,
then establish the intended source/view coverage. The proposed abstraction
does not already prove arbitrary value conversions, callback/capture
annotations, local handler images, mutable state or all seven accepted full
principal schemes. Effective solving of all retained symbolic residuals and
the remaining lifecycle obligations also remain separate.

This checkpoint preserves those boundaries without turning them into new
compiler rejections or asking the implementation to supply a global adequacy
oracle.
