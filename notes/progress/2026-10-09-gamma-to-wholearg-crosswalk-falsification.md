## Objective, method and result

Adversarially test the proposed identification of native checked-inlet
`gamma`, `DataArg` and `PackGeneric` evidence with the original independent
`WholeArgCompatible` witness at N and the original Call. The method is a
dependent-index/type audit and one minimized analytical witness, using selected
constructor clauses rather than invented kernel actions.

The selected inputs do not specify an actual original checking declaration
whose fiber can be falsified. A direct identity cast is unsupported: gamma is
fixed-frame checked-inlet evidence, PackGeneric is actual raw-inlet acceptance
evidence, and N's e_a is an independent descriptor-kernel witness. These have
different declared indices and owners.

A distinct conditional discriminator catches a particular domain shortcut:
arbitrary generic acceptance cannot be eliminated as the original gamma of a
prechosen frame. One Int carrier and two legal schema presentations, Int and
Any, suffice. This does not refute a correctly indexed gamma-to-kernel
crosswalk; it identifies a condition that such a crosswalk must retain.

## Exact type separation

At a prechosen native schema `kappa_A=I_q[A;Delta]`, let G(A,t,e) abbreviate
the *existing* gamma record type of uniform §4.2. This is explanatory notation,
not a new language judgment. With the original scope and guards suppressed
only in this display:

```text
gamma_A : G(A,t,e)
PackGeneric(kappa_A,gamma_A)
  : Acc(GenericValueInlet(q,IF0);t,e)
e_a : WholeArgCompatible(R_a,CarrierContract(F_c);xi)
```

DataArg(S,o) is gamma's independently owned complete J operand, with its
source registration o, complete Comp fields and formation record. It is not
itself a checking proof. Gamma adds Car, same-value payload checking, whole port
map, static/whole-image Delta proofs and current guards. PackGeneric adds the
formed schema as a dependent sum tag and preserves all that gamma unchanged.

N §5 does not define WholeArgCompatible by G or by Acc. Its §3 requires the
original checking declaration's complete ordered parameter/evidence telescope,
admission/future domain, licenses and lawful witness action as an independent
input. F_c's complete-demand sort in §4 does not identify it with an actual
native U_g or a Parameter schema merely because the source callee is a Value
formal. No fieldwise identification of that original P_arg/T_arg is specified
in the selected inputs.

Therefore neither gamma nor PackGeneric is definitionally e_a under these
clauses. A typed reference application could establish a correspondence.
The type audit establishes no impossibility of such an application.

## Minimized conditional discriminator: preserve the sum tag

Hypotheses, all explicit:

1. Use the selected bare native id with its fixed actual U_g, q and IF0,
   independently valid Int ground/carrier/context contracts, and a compatible
   live event e. No effect bound or foreign inlet equation is added.
2. Take one source-created pure Int carrier t (for example the native argument
   1) with source-built J=DataArg(Int,o), its authentic complete Car and original
   registration/port fields. Retain every declared J alternative.
3. Form two independently legal prechosen schema presentations at their
   allowed original type scopes, kappa_Int and kappa_Any, with compatible
   original Delta/IF0 incidence and current guards. Use hereditary Identity
   for Int -> Int and Top for Int -> Any. Uniform §4.3 supplies the bare-id
   whole-image Delta derivation at each presentation.

These native premises construct two exact records and two sum witnesses:

```text
gamma_Int : G(Int,t,e)       gamma_Any : G(Any,t,e)
h_Int = PackGeneric(kappa_Int,gamma_Int)
h_Any = PackGeneric(kappa_Any,gamma_Any)
both h_* : Acc(GenericValueInlet(q,IF0);t,e).
```

Their gamma records need not be otherwise identical: the payload inclusion
proof and any dependent result-image evidence have their own exact indices.
No proof irrelevance, merging of frame scopes or normalization of proof
choices is assumed. J's payload remains Int in both records; this is **not**
widening J to DataArg(Any) or narrowing a broad carrier by its actual Return.

Now hold the checked target frame fixed at kappa_Int. The actual sum eliminator
on h_Any returns precisely (kappa_Any,gamma_Any). It returns no witness indexed
by kappa_Int. The schema records differ on their declared payload endpoint;
Top proves inclusion, not equality of those whole schema records. Uniform
§5.2 expressly requires the result to eliminate the frame's original gamma
and forbids using a different sum index to repair that frame.

The rejected shortcut is thus:

```text
arbitrary h : Acc(GenericValueInlet(q,IF0);t,e)
  |-> the stored gamma of h : G(Int,t,e)
```

Taking h=h_Any makes that proposed direct extraction ill typed. Its actual
output is G(Any,t,e). This is a dependent-index discriminator, not a claim
that G(Int,t,e) is empty: gamma_Int already inhabits it. A separately justified
map may exist; it must account for the original frame and proof fields rather
than call this extraction an identity.

For an original WholeArgCompatible declaration that exposes the prechosen
checked schema/result inclusion in P_arg/T_arg, this discriminator conditionally
rejects a crosswalk that first accepts an arbitrary PackGeneric witness and
then treats its projection as that fixed-frame original e_a unchanged.
The premise that the actual original declaration exposes this coordinate is
**not supplied**. If that declaration instead consumes another explicitly
defined complete domain, its genuine typing rule must be checked; this witness
does not falsify it by analogy.

Minimality is relative to this sum-index shortcut: one carrier/provider/event,
one fixed raw U_g, two different legal schema tags, and no Request, recursion,
capture, provider change, nonexecuting result or action mutation is needed.
One tag cannot exhibit projecting the wrong tag. This is not a claim of global
smallest source counterexample.

## What remains unfalsifiable here, and the stopping point

A real crosswalk needs one actual original checking declaration/root t_arg,
ordered P_arg/T_arg, its full independent domain/license/action laws, and
authentic typed applications at both N and original Call. Its operand
interpretations must pair R_a with the complete actual argument J at the
registered Return/Delay/inert incidences, and F_c with the actual whole inlet
at the original checked frame, provider, event, world and scope. It must state
whether it retains G(A,t,e), an injected PackGeneric witness at *that* A, or
another genuine original checking object, and give the full evidence maps.

No such declaration application is defined by N's abstract Kernel input,
DataArg's assembly, generic admission injection or IF's contextual retention.
Consequently the selected inputs give no actual checking-fiber cardinality,
member whose original domain fails, or lawful action mismatch to falsify.
This is a bounded premise characterization, not a global absence theorem.

The existing audits already leave that same premise open. This lane stops at
the concrete registration/index owner instead of inventing another abstract
action model. The sum-index result is a distinct test for a candidate packet,
not progress on the missing source rule itself. Complete Call/result extension,
dependent e_out and all original arm laws remain separate.
