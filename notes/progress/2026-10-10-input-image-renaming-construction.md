## 3. Derived action on presentation variables

Let h bijectively rename only variable/reference spellings denoting the same
bound coordinates in T. Preserve sorts, original binder nodes/order/dependencies
and all fixed constants. Source binder identities are constants/owner fields,
not variable spellings. The alpha hypothesis excludes an operation reading
such a spelling as an actual semantic ID; any such read puts that ID in the
rigid inventory or requires its separate action law.

Construct hT and he by capture-avoiding simultaneous reference substitution.
For every scoped assignment rho construct rho_h by

```text
rho_h(hx) = rho(x),             rho_h(c) = rho(c) for fixed constants c.
[[he]]_(hT,rho_h) = [[e]]_(T,rho).
```

The second equation follows by term/operand induction. A variable uses the
first equation; a constant stays fixed; an operation receives the identical
ordered argument values and the identical fixed interpretation. This uses
neither ID insensitivity nor a redefinition of a primitive relation R.
Even an identity-sensitive primitive has the same truth value because its
actual ID operands have not changed.

Under each original binder, the denoted dependent domain is identical after
the preceding assignment pullback. Carry a strategy to the same domain at
the renamed references, retaining its original witness values/functions and
dependencies. This handles universal challenges as well as existential proof
choices without exchanging binder order or choosing a witness per branch.
Independent primitive witnesses are retained. Finite proof/reference schemas
are re-encoded once; every original finite development uses the same scoped
valuation construction.

Consequently the exact dependent checked-inlet judgment C satisfies

```text
C(q,A,Delta;h0,t,e,gamma) at (T,rho)
  iff
C(q,hA,hDelta;hh0,ht,he,hgamma) at (hT,rho_h).
```

Here `hgamma` is its presentation re-encoding; all denoted field values remain
the original gamma fields. h on a reference to t/e does not move the actual
carrier/event. Every independent predicate and image-law premise therefore
has the same complete tuple. Record formation/elimination, conjunction,
whole-tuple case analysis and original binder congruence justify both directions.
The inverse is the identical construction for h inverse, with
`(rho_h)_(h inverse)=rho` and all proof choices retained.

For the complete input-side port/result image, not just actual executions,

```text
[[hm]]_(hT,rho_h)([[hh0]], [[ho]]) = [[m]]_(T,rho)([[h0]], [[o]]).
```

At a prefix/Request retain the same J observation fields. At Return apply
the same mu_result proof at the same decorated result. At a future port
retain its same hereditary A certificate. delta_check covers every original
J alternative and response/raw/future telescope; its proof is unchanged in
meaning. Licensed non-source members remain in the image. No branch is filtered
by later source success. Inverting the re-encoding gives the reverse equality.
Lemma S and PackGeneric can thus reuse the identical existing component
witness; they do not require a new dynamic index or actual-U admission oracle.

This action has nontrivial variable spellings but is identity on denoted
semantic objects. CE's F/G equality and source/public fiber equality are not
used as nominal covariance premises.

## 4. First missing premise for changing a semantic identity

Suppose instead H maps an actual descriptor/root A to a different actual root
A', while preserving source/provider/world anchors. The assignment equation
above now fails at A. Before transporting mu_result, its owner must supply a
typed bijection on dependent result evidence, for example

```text
B_A : VCert(A,v,p,e,full operands) <->
      VCert(A',v,p,e,transported full operands),
```

at every original compatible result/future telescope, with actual formation,
membership and restriction laws commuting in both directions. This must use
the already independently selected interpretation of A'; declaring that
interpretation to be H's desired image would assume the conclusion.
Formation of the target dependent domain precedes transporting its proof.
Same-value inclusion soundness supplies no B_A, and Top or other one-way
checking proofs do not supply its inverse.

Keeping J fixed still requires, next, a typed transport of the actual finite
mu_result derivation and whole original_port_map incidence at A'. If H moves
J's actual roots instead, it first needs formation/provenance-domain and full
Car/J observation/evidence transport at that independently formed argument
contract. Independently typed J and a complete carrier certificate do not
prove that earlier law either. All delta predicates and genuine L leaves
whose actual operands change then require their own two-way laws, including
future-domain, permission, query and root-lookup identity observers.

Conditional theorem: if those full dependent-domain actions, independent
primitive/image/evidence laws and exhaustive rigid-ID inventory are supplied,
the inlet record/image proof transports by its existing finite constructors.
The missing hypotheses are the substantive source-owner laws, not a proof
obligation discharged by this conditional composition.

Source Generalize's new allocates eligible declarations and proof regions;
it neither renames two different actual incoming-event identities nor proves
this semantic action. Endpoint specialization A:=B is likewise not alpha
renaming or generally invertible. Comparing two encodings of the *same* new
event fits §3; comparing actual newly allocated root identities reaches §4.
For PE-PICK the installed J_z, provider, monomorphic contract and full free
closure remain fixed, even when another import has the same printed type.
