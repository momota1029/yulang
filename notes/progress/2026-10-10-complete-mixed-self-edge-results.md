## 2. Exact algebra, including the raw phase

For one fixed authentic attachment ID and fixed family, W=(p,n,r) retains
leading left POPs, active left PUSHes, and right POPs. Counts are natural.
Left composition is

```
(p,n) o (q,m) = (p+max(q-n,0), m+max(n-q,0)).
```

Replay R(U,V) composes left pairs, sums right debt, then executes directed
mix M. A participating mix preserves `(p,n-r,0)` when n>r, and otherwise
returns `(0,0,p+r-n)`. An absent left or right side is retained unchanged.
Swap gives `(r,0,p)`; both-from-right gives raw `(r,0,r)`. Prefix and suffix
remain raw until the actual mix point. These equations match the pinned
one-ID source owners in the nonoverflowing arithmetic envelope. Oracle stores
u32 counts, with saturating POP additions and ordinary active-PUSH addition;
its machine width is not a termination argument for the natural-count model.

The full operation is nonassociative. This phase retains each displayed
bracketing and the raw node where a check runs. It does not move filters past
normalization, erase consumed registrations, or reinterpret an Empty residual
family as an absent attachment entry.

The primitive source grammar retains all four Function ports. Value argument

## 3. Contextual self-edge results

### 3.1 Exact universal constant criterion

On mix-normal inputs, M(x)=x. The reviewed theorem proves, separately for
both replay orientations,

```
forall normal x. R(x,w)=x    iff w=I
forall normal x. R(w,x)=x    iff w=I.
```

The proof includes raw candidate labels. If M(w) is nonidentity, incoming I
separates it. If M(w)=I but w is nonidentity, w must be `(0,k,k)` with k>0.
Against D=(1,0,0), either replay produces `(0,0,1)` instead of D. Thus merely
normalizing the self label in isolation is incorrect. Conversely actual I
gives exactly M(x), which equals every normal x.

For arbitrary raw inputs there is no universal constant replay unit. Any
candidate would be I by the normal-input theorem, but

```
R(I,(0,1,1)) = M(0,1,1) = I != (0,1,1).
```

These are exact small counterexamples, not limits inferred from tests.
Oracle ordinary bound insertion is not globally proved mix-normal: filters
are erased at insertion without universally normalizing the remaining raw
weight. The criterion therefore cannot silently assume such an invariant.

### 3.2 Direction and persistent obligations

An upper self supplies the lower transfer x -> R(x,w). A lower self supplies
the opposite replay transfer and is also a positive-lower/filter event. These
are distinct operational responsibilities. For a completed normal-fact grammar,
an upper self preserves the exact least solution iff its drop-state lower
set L is closed under R(-,w). The proof uses least-fixed-point inclusion in
both directions. For a lower self, the dual upper-set closure is insufficient
without retaining its own positive-lower and check obligations.

That is an exact state-dependent mathematical condition, not a claimed
algorithm for arbitrary recursive language inclusion. Open-world omission
must remain correct for all actual future lowers, registrations, equality
replays and restores. The universal unit result is the checkable local rule;
nonidentity alternate-path redundancy still needs separate evidence.

The existing source-root bridge remains conditional in exactly its earlier
places. Negative extrusion directly inserts an identity lower and does not
replay it. A retained original local root can later expose a fresh row plus
its older anchored copy; restore then turns a kept upper PUSH into a positive
lower. A separate symbolic-only formal can supply the Empty observation.
The current scoped symbolic-tail constructor supplies the named shared row,
but no concrete formal attachment/filter producer yet supplies the P payload.
No source acceptance or global SCC schedule is inferred from that route.

### 3.3 Raw identity self normalization

The [constructive theorem](2026-10-10-contextual-self-edge-normalizer.md)
removes the need to assume that incoming facts are normal. Its reference
semantics is the exact set L_G(X) of values of all finite derivations at X in
a finite pure unguarded grammar. The grammar permits every bracketed mixed
operation, arbitrary natural constants and recursive PUSH, independent refs,
and lexical let/bound selections of one complete recursive value. Infinite
trees contribute no value. No filter events are hidden in these pure rules.

For each original owner X, mark whether it has a whole bare production

```
X -> replay(ref(X), I)
X -> replay(I, ref(X))
X -> mix(ref(X)).
```

Remove those productions, and independently remove the ordinary vacuous alias
`X -> ref(X)`. At every marked owner retain each other original producer
`X -> E` and add `X -> mix(E)`. Unmarked producers are retained unchanged.
Call the resulting grammar N(G). Constants and the complete expression E,
including its bracketing and shared bindings, are unchanged. There is no
recursive-language enumeration or value cutoff in this transformation.

**Theorem:** for every such finite G and original X, L_N(G)(X)=L_G(X).
For the forward inclusion, a finite derivation's initial chain of M-self and
plain-self rules must end at a nonunit producer E. Translate its proper
reference/supplier derivations inductively, preserving each selected bound
value. With no M in the removed chain, choose E; with at least one M, choose
the generated mix(E). The exact identity M(M(x))=M(x) makes every positive
chain length equivalent to that one wrapper, on raw as well as normal x.
For the reverse inclusion, translate the chosen E's proper derivations and
replace each generated mix(E) by one original M-self followed by E. Both
constructions are finite, preserve lexical sharing/shadowing, and apply at
every original vertex. They never require the remaining recursion to terminate.

The output has at most twice the number of nonunit original productions.
The factoring pass on already validated syntax is linear; the reference's
separate validator can be quadratic because it copies name sets and lexical
scopes. This last qualification is the independent review's sole minor repair.
Neither output finiteness nor exact preservation relies on its complexity.

The mutable-use discipline is concrete:

- For a future original producer, extend the retained original G and refactor
  it. Appending an unwrapped raw seed only to N(G) can lose its mixed value.
- For a supplied SCC/alias quotient, map references and let suppliers and union
  the **original** producers first, then refactor. A former nonself can become
  M-self, and a newly merged raw producer needs the same wrapper. Removing
  ordinary plain aliases prevents recreating mix(ref(X)) during this step.
- Injective vertex renaming commutes with the construction. The implicit
  one-ID name can also be lawfully renamed; no row quotient merges attachment
  identities or grants another occurrence's authority.
- Rollback restores the immutable original/derived pair atomically, or restores
  G and recomputes N(G). Retaining a stale derived graph is not restoration.

The theorem preserves values and retained idempotent fact/check obligations;
it does not preserve the number of duplicate propagation events or literal
syntax-node traces. Original filter checks, registrations and lower-self
positive-fact duties must remain with their actual owners. These obligations
are not silently erased as part of a pure I transfer. The tool receives a
chosen quotient and immutable snapshots; it is not a compiler SCC/journal or
contextual attachment implementation.

### 3.4 Support-only identification fails even for boolean observations

The same note proves that arbitrary distinct raw triples can be separated by
a finite continuation observing only whether the final active count is zero.
For x=(p,n,r), the exact extractors are

```
mix(both(swap(x))) = (0,0,2p)
mix(both(x))       = (0,0,2r).
```

A fixed P_k replay is active precisely when k exceeds the extracted right
debt, separating unequal p or r. If only n differs, choose K=p+r+1; then
replay(P_K,x)=P_(n+1). A fixed trailing left POP separates the two active
counts by their zero/nonzero result. This proves separation at all natural
counts, without assuming an exact-count observer. With a nonempty fixed family,
an Empty allowance can distinguish these final active bits locally.

Consequently no finite, permanent identification of all raw contexts can
preserve every such future observation. This does not exclude a finite
query-specific abstraction backed by the original exact grammar. The simplest
support-only counterexample already has D_1=(1,0,0), D_2=(2,0,0): both have
the same support, but replay(P_2,D_1)=P_1 and replay(P_2,D_2)=I. No assertion
that every separating continuation is an admitted source program is made.

## 4. A positive finite algorithm for genuine mixed recursion

The [new congruence theorem](2026-10-10-complete-mixed-effect-obstruction.md)
allows all mixed operations recursively, including raw both, suffixes, swap,
independent replay and explicitly shared children. Its supplying constants
satisfy p>=n and its fixed prefix pairs (a,b) satisfy a>=b. These are the
theorem's structural scope; ordinary positive-displacement P_1 is outside it.
No compiler input is rejected to impose this mathematical condition.

Let N be the maximum leaf active count or prefix PUSH count. Put d=p-n.
Induction over every finite derivation proves d>=0 and n<=N. The key exact
equations are

```
left replay: d0=d1+d2, n0=max(n2,n1-d2), r0=r1+r2
prefix(a,b): (d+a-b, max(n,b-d), r)
swap:       (r,0,d+n)
both:       (r,0,r).
```

Mixed replay can then remove active PUSHes or move the residual debt right;
it never invalidates the bounds. Arbitrarily many recursive PUSH-bearing
leaves are permitted, for example T -> (1,1,0) | replay(T,T). Bounded active
value is derived, not imposed as a bound on derivation length or PUSH events.

For every K>N define

```
pi_K(d,n,r) = (min(d,K), n, min(r,K)).
```

This is a true congruence of every admitted operation. Any clipped coordinate
is larger than every n or prefix PUSH count, so all cancellation comparisons
have the same branch. Remaining debt additions commute with saturation. The
proof handles raw prefix/suffix and the same selected tuple in every shared
occurrence. Clipping raw p instead of d is not the theorem and has an explicit
active-observation counterexample in the executable checks.

Finite set saturation has at most

```
number_of_nonterminals * (K+1)^2 * (N+1)
```

successful tuple insertions. The number bounds distinct abstract facts, not
iterations of the concrete semantics. Each inserted tuple has a finite
concrete derivation witness by induction on its insertion; each concrete
derivation maps into the closure by congruence. This gives soundness and
completeness, including same-child correlation. Concrete debt values are
never equated in the retained original grammar.

### Future positive PUSH observers

An arbitrary fixed finite continuation may contain positive displacement and
all raw mixed operations. Let h count internal operations, m count supplier
hole occurrences with multiplicity, B count its fixed PUSH mass, and T be the
largest requested constant debt threshold. With

```
M = B+m*N
K = max(N+1, T+(2*h+1)*M+2),
```

the quotient is precise for that continuation. Evaluate its representatives
with exact arithmetic, without clipping its intermediate nodes. Active n is
exact at every node; debt comparisons against every constant through T,
presence, left-entry and identity are exact. Each operation can consume at
most 2M of uncertainty in a large debt coordinate, and the chosen K leaves
strictly more than T precision along every finite path. Full proof, including
all mix guards and the M=0 case, is in the theorem note.

New future continuations resaturate the original syntax with their own K.
Nothing truncates exact POP multiplicity permanently. Joint traces preserve
named-hole correlation; distinct hole names select independently. This does
not decide equality between two unrelated unbounded debts or allow a second
unbounded positive-PUSH supplier under a fixed observer budget.

## 5. A genuine limit for the unrestricted shared grammar

The [PCP reduction](2026-10-10-complete-mixed-effect-construction.md) uses
two fixed, distinct attachment IDs a,b and E(x,y)=(L_x at a, R_y at b).
Actual global operations give

```
A(t)=swap(replay(I,both(swap(t))))  -> E(2x,0)
B(t)=replay(I,both(t))             -> E(0,2y).
```

One shared selected t plus finitely many A(t),B(t) copies implements
E(x,y) -> E(mx+c,ny+d) for arbitrary positive odd fixed m,n. Ternary
sentinel word codes satisfy code(zw)=3^|w| code(z)+digits(w), so finite
unguarded tile productions generate exactly synchronized PCP word-code
pairs. A separate start rule forces a nonempty tile sequence. No zero-test
or enabling predicate is added to recursion.

A separate ordinary recursive supplier J generates a common P_k at both
IDs. At the final, correctly bracketed replay,

```
replay(V(k),E(x,y)) has empty left/right support iff k=x=y.
```

Each cancellation uses the same ID; a is never renamed to b. Hence existential
empty support would decide binary PCP, and no total exact procedure for that
entire grammar/query class exists. The external dependency is only PCP
undecidability, checked against [Halava's primary proof](https://arxiv.org/pdf/1411.5197).
The exact algebra and all boundary cases are proved in the note and independently
reviewed against the global Oracle mix loop.

This is stronger than the earlier conditional guarded-machine warning, but
it is **not** an impossibility proof for the selected compiler. Primitive
bound replay chooses independent records. The reduction repeatedly uses the
same selected recursive child across projected subexpressions, which has no
established source constructor here. Also active absence alone does not test
identity: k=1,x=2,y=3 has no active PUSH but retains pending POPs. Joint empty
support cannot be silently replaced by ordinary union collection of effects.
