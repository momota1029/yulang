## 3. Exact missing typed extension and action premise

Let `i:P -> P_plus` be the old-entry inclusion. Let `z` be an actual old
entry's full dependent source/world tuple; its inclusion moves registry/root
incidences only and preserves the unchanged original tuple. For each exposed
old consumer `C`, use its actual owner-declared fibers, without redefining C:

```text
G_C(P,z)                    original immediate guard interpretation
D_C(P,z)                    original admitted event/history/future domain
L_C(P,z,h), h:D_C(P,z)      original license/guard/domain evidence and alternatives.
```

The missing supplier must identify which actual original owner constructed
each of these families, then give applicable typed maps at this very staged
pair:

```text
guard_i: G_C(P,z) <-> G_C(P_plus,i z)
dom_i:   D_C(P,z) -> D_C(P_plus,i z)
lic_i:   L_C(P,z,h) -> L_C(P_plus,i z,dom_i h).
```

The guard equivalence records preservation of the old interpretation; the
maps retain all old witnesses, proof choices and output-dependent fields.
They require inverses on their old image, with the same original interfaces
and dependent evidence recovered. This demands no inverse for a genuinely new
domain element. Whole dependent domain maps must preserve current worlds,
provider identities, authority and future dependencies; a snapshot or narrowed
old domain is not a substitute.

For every legal whole theta, the supplier must also prove applicability at
`(theta P,theta P_plus)` and typed squares, including

```text
theta(dom_i(h)) = dom_(theta i)(theta h)
theta(lic_i(w)) = lic_(theta i)(theta w).
```

All dependent interface fields and alternatives participate. Identity and
composition hold both for extension/reuse maps where composable and for whole
actions. The candidate §7 already specifies this requirement.

An old positive-lookup equality gives only the entry record. It does not
provide guard_i/dom_i/lic_i for a family with a live registry dependency.
SIG's lawful primitive action cannot be applied until this extension is
actually in that primitive's certified action/domain. Lemma W cannot be
applied until an independently compatible history event with this full change
has been supplied; the candidate has deliberately generated no such event.
This is the precise missing applicability premise.

Exact reuse leaves P unchanged. Original identity laws can supply the identity
instance of these maps, assuming the retained complete old interfaces already
have their original action. This does not discharge the fresh branch.

## 4. Conditional reduction: native static-license replay

This derivation isolates the constructor work that existing native laws can
perform. It does not grant all of H_oldext as one premise.

**Hypotheses.** Restrict to actual old finite native L derivations at their
original complete indices. Require:

1. The old graph inclusion preserves every used registration, clause insertion,
   source reference, scoped substitution, field injection and sharing fact,
   including exact upper source/O0/O1/SpecCall/C0/J-Owned interfaces.
2. Every primitive/local semantic leaf and original annotation witness has an
   applicable dependent extension map at the unchanged original tuple, with
   inverse on image, preserving all proof alternatives.
3. Every retained Whole certificate has an applicable transported certificate
   at the new full indices, including its original domain/legality/admission
   prerequisites. Its action remains coherent with the old inclusion.
4. These maps commute with a single legal whole action on all indices,
   interfaces, origin partitions, witnesses and dependent future fields.

These are **candidate applicability assumptions**, not facts from fresh labels.
They concern old native static licenses only; they do not include arbitrary
old consumer guard/domain equivalence as a conclusion of L.

**Derivation.** Induct on the original finite license development and, for
L-DeclaredPort, on its retained PortProv/DeclContribution development.

- Primitive/local cases use hypothesis 2; Operand/Ref/Scope/Rename retain the
  same old origin and dependent injection by hypothesis 1.
- Union keeps its branch and both schemas; Pair keeps the two old components
  at the same whole tuple. Operator cases retain the same actual semantic
  leaf/field maps. No alternative is chosen or merged.
- L-DeclaredPort reuses the original insertion after translating its retained
  complete contribution evidence. L-UpperCall reuses the exact complete old
  upper package from hypothesis 1.
- L-Reference translates the antecedent and retains its actual original
  reference/substitution. L-Annotation uses its original mapped evidence.
- L-Whole uses hypothesis 3; graph references remain registered edges and
  finite developments, rather than recursive body unfolding.

Thus each old native license witness has a same-rule target witness with the
same retained constructor tree and alternatives. Inverting the mapped leaves
and unchanged tree gives inverse on image. The whole-action square follows
by the same induction from hypothesis 4 and the existing field-injection
equations. This is a **conditional theorem for old native static license
developments**, not an established H_oldext theorem.

The reduction exposes the exact obstacle: the selected grammar performs the
composite replay, but does not supply hypotheses 2–3 for this P_plus or
enumerate every active old consumer and prove its complete domain/guard laws.
For an opaque registry-sensitive primitive, the first unsupplied premise is
its own extension applicability. For a Whole node it can instead be the
transported certificate's actual legality/domain/admission premise. Replacing
either with “the registry is finite” leaves the same premise untouched.

No third toy model is useful here. The remaining method must acquire these
owner-derived laws for the actual exposed dependency closure.
