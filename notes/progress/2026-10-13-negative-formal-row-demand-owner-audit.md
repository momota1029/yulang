`lower_catch` (`lowering/control.rs:770–789`) lowers the actual scrutinee and
calls `lower_catch_with_scrutinee`; the unlabeled Catch-lambda path also calls
it (`810–835`). Effect arms resolve their operation/family, obtain the row

after lowering guard/body (`1083–1124,1175`). `CatchHandledEffects::record`
retains one item per family; `row_items` projects those exact IDs
(`1702–1758`). This is not annotation support masquerading as a contribution.

For nonempty handled heads I, the actual Catch body (`922–970`) allocates
result effect r, determines actual arm completeness, then constructs:

```text
t = Var(r)                    if handled.is_complete(...)
t = Var(fresh rest_effect)    otherwise, with scrutinee.effect <: r also emitted
upper = Neg::Row(handled.row_items(), t)
subtype_scrutinee_effect_to_row(scrutinee.effect, scrutinee.effect_view, upper)
```

`subtype_scrutinee_effect_to_row` (`995–1020`) uses the supplied actual view:
for `LocalEffect::Stack { inner, weight, ... }` it emits both the public
effect-variable-to-upper constraint and `Pos::Stack(Var(inner),weight) <: upper`;
for a Var/no-view case it emits the actual variable-to-upper constraint.
Both use `OriginId::unknown_internal()`, so this is **not** a complete
source-incidence certificate for the adopted Y3 native signature grammar.

Conditional direct dispatch follows: ordinary subtype draining reaches
`step_subtype`; Stack normalization prepends the actual weight with a derived

(`constraints/row_effect.rs:88–234`) derives filter/row parents from the
