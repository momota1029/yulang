# Conditional finite source-instance bridge for SCC constraints

Date: 2026-10-05
Status: reviewed bounded derivation; conditional; no source-rule or implementation authority
Baseline: `757c90564`
Method: topological finiteness argument for finite source SCCs and per-occurrence external scheme instantiation
Review: compiler_referee bounded review; three findings repaired and delta review closed all findings

## Question and result

The source-context audit leaves finite instance/context generation open, including
use-site freshening and unbounded polymorphic recursion. Two narrower premises
are available. The Authoritative SCC foundation says that, in its declared
F0–F2 scope, internal, self, and mutually recursive uses point to live roots
and are never instantiated from a scheme that does not yet exist. Separately,
the reviewed source-generated theorem package gives a finite generator for a
monomorphic pure structural shadow: recursive references reuse preallocated
binder endpoints, while unbounded polymorphic recursion is outside that result.
The SCC-intrusion charter itself remains a reviewed research direction and
does not define the replacement's structural generator.

Under the explicit finite-DAG premises below, this rules out one possible source
of unbounded static graph growth: repeatedly expanding a recursive component
through newly instantiated internal schemes. It does not prove that Yulang3's
complete replacement semantics supplies the other premises, and it does not
close the source-wide comparison-context, effects, handlers, or principal
projection gates.

## Premises

Let `C` be the finite condensation DAG of definition SCCs for one finite,
already-elaborated compilation unit. Assume:

1. Each component `c` has finitely many source nodes and finitely represented
   annotation schemas. The local structural generator allocates finitely many
   endpoint, descriptor, and source-obligation nodes per source node/schema.
   Publishing a component scheme is a finite graph-preserving projection of
   its closed component graph; it does not unfold recursive back-edges.
2. Every internal/self/mutually recursive use in `c` links to an endpoint
   allocated for a member of `c`; it does not freshen or expand a newly inferred
   scheme.
3. Every external use occurrence `u` in `c` targets a component already closed
   in dependency-first order. Its target scheme is a finite graph, and the
   instantiation rule creates one finite fresh copy per static source use site,
   preserving internal sharing and recursive back-references. Re-evaluation of
   that use reuses or replaces its canonical instance; it does not accumulate a
   fresh copy on every solver iteration.
4. Constraint decomposition, normalization, aliasing, and provenance rules
   preserve the finite endpoints and original source roots or close over a
   finite canonical state space. The closure from each finite component input
   allocates finitely many additional nodes and edges. Replays either reuse a
   state or pass through a finite set of canonical dependency versions. They do
   not mint identities from derivation depth, solver iteration count, or dynamic
   execution count.

Premises 1–4 describe a finite structural inference fragment; in particular they
do not silently assert that requests, latent closures, handlers, `K,D`, adapters,
or dynamic `Receive` evidence satisfy them.

## Derivation

For each component `c`, let `l(c)` bound the local nodes generated by its finite
source graph and schemas. Let `U(c,d)` be the finite set of static external use
occurrences from `c` to an already closed dependency `d`. Let `k(c)` be the
number of additional canonical nodes/edges produced by the finite closure from
that component's finite initial input. Define a size bound in dependency-first
order:

```text
g(c) = l(c) + sum over d and u in U(c,d) of inst_size(S_d, u) + k(c)
```

Each `inst_size(S_d,u)` is finite because `S_d` is finite and the use-site
freshening copies each node at most finitely while preserving graph back-edges.
Premise 3 bounds repeated evaluation of the same source use to that canonical
instance rather than a new identity per worklist visit.
The sum is finite because the source SCC graph is finite and every component
has finitely many syntax/use occurrences. No term in the sum recursively refers
to `g(c)`: SCC-internal references use the component's preallocated live roots,
and external dependencies precede `c` in the finite condensation DAG.

Induct on the dependency-first topological order, with the invariant that each
component has a finite closed graph and a finite published scheme. A sink has no
open external dependency. Its finite local graph, finite closure, and finite
graph-preserving scheme projection establish the invariant. For the induction
step, every external target scheme is finite by the induction hypothesis; each
static occurrence adds a finite instance. The finite local graph plus these
finitely many instances has finite closure by premise 4, and its scheme
projection is finite by premise 1. The finite SCC DAG therefore yields a finite
union of statically generated endpoint/schema/use nodes. Recursive source paths
can add graph edges, but by premise 2 they cannot create an unbounded chain of
fresh internal schemes.

This argument proves finiteness only of the supplied structural source/instance
graph under premises 1–4. To obtain the finite guard/evidence context `J_T` of
the residual theorem, premise 4 must be established for each actual rule family:
structural children must retain the root context; replay, alias changes, and
multi-parent rules must use finite labels and finite dependency updates; typed
transport must preserve finite source/evidence ports; and request/store/lifecycle
rules must not create unbounded context identities. The rule-by-rule source
bridge in the finite-context draft remains open.

## Scope boundary

The Authoritative SCC foundation cited below governs its stated F0–F2 constraint
collection and definition-SCC lifecycle. It is positive evidence for internal
live-root reuse there, not authority for the replacement's Function/effect
semantics. The source-generated structural package is a reviewed conditional
theorem for a monomorphic pure structural shadow; it does not certify raw source
acceptance or extend to effects. The SCC-intrusion charter is a reviewed
research direction, not an approved replacement semantics. In particular,
this note does not settle polymorphic recursion policy for the complete source
language, prove callback view registration, or establish that the nested-block
candidate in the pending question realizes this fragment.

The next proof obligation for this finite fragment is a source-to-generator
coverage relation: show that each permitted finite binding/use/annotation node
has a finite local translation, each SCC-internal occurrence reuses the member
root, and every external use creates exactly the finite fresh instance assumed
above. Effects, handlers, State, adapters and joint `nu,K,D` need distinct
coverage arguments before this conditional result can be used for the full
replacement objective.
