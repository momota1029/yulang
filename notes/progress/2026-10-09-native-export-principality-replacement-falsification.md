## 1. Replay excludes a finite local-proof falsifier

Fix the selected id, its actual source-selected final synthesis root, and
its actual ProjectionExport. Assume a finite independently lawful joint source
grammar `d_U` whose checking terms use adopted local grammar L, with its
original scopes, original `(nu,K,D)`, one joint strategy, and well-scoped W.
These are the exact hypotheses of PE-ID, rather than an assumption that an
arbitrary semantic inclusion has an L derivation.

PE §4.2 decodes one actual ordinary `u_i` per real new and preserves aliases.
PE §4.3 substitutes only forced raw aliases; independent logical witnesses
and production alternatives remain separate retained coordinates. PE §6.1
checks the same translated L term at `u_i`, dispatching to Value, Computation,
or Function according to the checking constructor. PE §7 translates the
whole finite client grammar with the same shared strategy. Therefore:

```text
independent finite lawful d_U in the selected native grammar
  => translated finite public client at the actual u_i
     with the same retained solution/complete-observation fiber.
```

This is a consequence of the selected PE-ID result, including nonidentity
terms and independent Option 2 alternatives. A proposed counterexample with
all these hypotheses and a failing translated check would contradict that
result. No such licensed derivation was found here.

The quantifier differs from the ALL_VIEW/PRINCIPAL route. It begins with an
independent finite derivation and produces its public grammar. It does not
start from every independently valid finite public scheme in the declared
conservative abstraction and construct a factorization for that scheme. A
replacement theorem needs an exact bridge identifying which required valid
views admit the replay input, or a separate ordinary checking operation for
the remaining required views. Lack of an L term alone is not a counterexample.

## 3. What this does and does not discriminate

This conditionally separates actual-callable membership from the complete
production-containment premise of the native Function checking constructor.
It does not show that `Direct(u_A,V_0)` fails in every consumer case. PE §6.1's
Value case accepts finite independently justified same-value membership
implications. A legitimate local proof could use the independent exact t
operation law, contextual Function elimination, Echo on actual observations,
and contextual introduction for V_0. If such a full finite law is already
adopted and applies at these exact operands, the source and public consumer
can replay it; the candidate would support the replacement bridge.

The exact unmatched operation to inspect is therefore:

```text
independent exact operation certificate of the retained t
+ contextual membership of the actual callable at u_A
+ original initial equality H and installed Fixed(J_0) evidence
  -> finite same-decorated-value inclusion at (u_A,V_0),
     preserving the complete original telescope and witness strategy.
```

This is neither a successful-query leaf nor permission to filter production
members by actual execution. It names the evidence that a Value inclusion
proof would have to consume. No adoption of that operation is proposed here.

Failure conditions and mutations are explicit:

- If C1 cannot be licensed, the candidate is not a valid view discriminator.
- If `Valid_V` requires complete containment from an allocated native frame,
  rather than the actual-callable membership considered above, this candidate
  need not belong to that valid-view class.
- If C2 is absent, H and a broad Car certificate do not establish a constant
  actual result, so the actual-membership argument fails.
- If C3's extra is absent or equals 0, the displayed observation failure
  disappears. This is a premise mutation, not an executed mutation test.
- Constraining gamma_J to a separate exact-0 complete contract changes C3/C4
  and the retained tuple. A lawful original constraint can do so; the existing
  carrier identity predicate alone cannot.
- A supplied finite Value proof can establish Direct even though the
  complete Function premise fails. Grammar inexpressibility by itself proves
  no semantic or compiler failure.

No fully licensed witness satisfying C1–C4 and the governing `Valid_V`
contract was constructed. No universal impossibility, source rejection,
production defect, common-allowance equality or aggregate gate closure follows.
