## 1. Objective, independent meanings and result

Attempt to construct an independently admitted typed initial context and a
complete original row, first for the approved nested source, then for a
separate returning ordinary caller. The method is direct composition of the
original source constructors, retaining one whole tuple and the original
profile/scopes. It does not define admission by the generated predicate, use
pending Q, execute the frozen Oracle, or search for a convenient comparison.

No complete original row is constructed. The positive route does construct
actual ordinary argument code, a single source-controlled current prefix,
sharing/capture references, and ordered receipt/entry/result suffixes. The
nested case stops at the original profile-introduction applicability leaf.
The ordinary known-callee case avoids that particular inferred-formal seed;
its remaining leaf is complete whole-carrier admission at the identity's
original descriptor. A returning control trace does not discharge either.
Neither result proves source impossibility or requires a user choice.

The governing clauses are:

- inferred call views §§2–5: original shared contract, beta, scope and xi;
  Q independence; provisional formal treatment and annotation absence;
- source contracts §§2–3,6–9: independently active descriptor/admission
  clauses, constructor typing, four history classes, Option A/2, and the
  conditional allocation theorem;
- typed core §§6,9: ordinary parameter tags, Result/Normalize, inert
  introduction, actual Value entry and complete carrier-dependent invocation;
- typed boundary §§4,6: executing-view observations before dispatch,
  source profile introduction, indexed transport, receipt and exact expiry;
- source-profile construction §§1,3–5: unsolved original inventory/policy,
  mandatory upper member, inherited-source separation and exact Init factors;
- initial-context construction §§1–9: two rigid holes, source-owned open
  descriptors, local complete Call predicates and PCInit-source;
- the nested source addendum §2 and directional addendum §§2–4: the exact
  lambda/bind/return/capture graph, upper-output protection and no backflow.

The typed-core and source-contract packages retain their conditional/Draft
scope. Their constructor equations are used as the inspected reference kernel;
this note does not promote them into an unrestricted production membership
law. The two Authoritative/current-user source decisions are preserved.

## 2. Nested candidate: construct one source-controlled seed

The exact source remains

```text
my apply f = { my step x = f x; step }
```

Let sigma_N contain the original outer formal d_f, local binding d_s,
inner formal d_x and inner use u. Retain exactly

```text
R_f          original shared inferred contract root
beta_N       (d_f,R_f)
F_u          original complete Function upper at u
p0           original designated complete-output effect occurrence of F_u
S_beta_N     original complete applicability/contribution inventory
Gamma_beta_N original profile on that inventory
xi_N         one (nu_N,K_N,D_N), at sigma_N
X_N          one tuple of all source interfaces, providers, scopes,
             S_beta_N,Gamma_beta_N,xi_N,current world and local witnesses
```

Choose the ordinary value endpoints of the intended actual argument/result
as Unit. Retain K_N and D_N by original predicate identity and incidence;
do not replace them with true or independently solve their ports. The
complete invocation endpoints remain carrier-dependent obligations. Empty
body/Name rows are not assigned to complete-call endpoints. This is a partial
candidate valuation of X_N, not a satisfying whole row.

Construct the identity independently, before placing it at the formal:

```text
v_id = Closure(Pure, Value(Unit), result(name z), captures=empty)
t_f  = Delay(result(v_id))
t_x  = Delay(result(Unit))
```

The ordinary literal/Name/closure/reify rules construct these descriptors and
actual source tags. No expected callback literal context is used for v_id.
Its actual role remains Pure and its actual entry Value. Its own empty
source profile is distinct from Gamma_beta_N; the original mandatory formal
upper incidence is retained separately.

Starting in the ordinary source root configuration with no imported roots,
handler, operation instance or raw handle, construct the current prefix:

```text
apply receipt of t_f
  -> Value entry forces exactly t_f
  -> Return(v_id); actual rebind of d_f
  -> inert step closure, capturing the SAME rebound f view
  -> bind d_s; return that same step provider; apply invocation return
step receipt of t_x
  -> Value entry forces exactly t_x
  -> Return(Unit); actual rebind of d_x
  -> arrive immediately before source Call u = f x
```

This is a constructor derivation of an actual control prefix, conditional on
the advertised descriptors' local typing checks. It does not claim an already
admitted typed prefix. No source entry is replayed, no prefix eagerly executes
f's body, and the returned step is not invoked by the block's final expression.

At that point puncture u. H_f refers everywhere to the one captured d_f root;
H_a is the original whole argument computation J_x = result(name d_x),
whose inert carrier is Delay(J_x). The ordinary source argument certificate
is independent of H_f and Q: d_x has the actual Unit result and Name returns
that same descriptor/root. The carrier is not an arbitrary member of the
printed Comp(empty,Unit). The generated two-hole context retains all these
references in the containing source closure and pending suffix.

The resulting partial seed has a concrete current configuration, actual
step owner, original source complete-call address, original carrier root,
result path and suffix. After plugging v_id, the suffix is

```text
id receipt; designated argument Force; rebind z;
identity body result; designated consumer; id invocation return;
step invocation return; original surrounding consumer
```

The whole code graph uses one substitution for every H_f/H_a occurrence.
None of its containing closures is checked for closed target membership of
the actual tested H_f while constructing the open context.

The no-import root and this source prefix remove arbitrary import witnesses
from this particular attempted initial tuple. They do not establish a theorem
about arbitrary semantic external worlds. The ordinary source constructors
provide its ownership/control records; their full independently typed world
validity is still part of prefix typing, rather than a license for every
empty-looking configuration.

The outer apply receiver has expired before the displayed later step Call.
Its persistent beta profile may survive transport, but any candidate
Inc rooted at that exact expired receiver is false by typed-boundary §6.
This is a current-state consequence for this prefix, not removal of the
original profile obligation. Keeping apply live, resuming another raw suffix,
or using another receiver is a different world and cannot reuse this expiry.

### Smallest remaining nested leaf

`a0=(k,beta_N,u,sigma_N,p0)`. Its original prospective position in the

Policy assembly fixes protection and no grant at every independently
applicable unannotated own-source incidence. Source-result lift, rebind,

The final profile-introduction step requires exactly this independent fact:

```text
SignaturePolicyLicense_original(beta_N,F_u,sigma_N,xi_N;
                                S_beta_N,Gamma_beta_N)
```

Here this notation names the existing introduction premise, not a newly
selected predicate definition. Its unresolved component is a proof that the
own-source incidence inventory of this original complete contract is
EXHAUSTIVE, with its original contribution and position correspondence.
The source derivation supplies a0 and its sort; it does not supply that
inversion law. The candidate


is therefore not a proved member of original Completions. Unit specialization,

This is the first unresolved nested admission factor, before PCInit-source

complete-descriptor/world factors are solved. It is a reduced exact leaf,
not a proof that the original completion family is empty.

## 3. Separate ordinary caller: remove the formal seed, retain the inlet

Use this distinct finite ordinary source derivation (Unit denotes the ordinary
Unit literal in this proof notation):

```text
my id z = z
my caller x = id x
caller Unit
```

This is not a new interpretation of the approved braced source. Let sigma_O,
xi_O=(nu_O,K_O,D_O), the id/caller roots, and X_O be this source's own original
scopes and whole tuple. No row, slot, receiver or witness is merged with X_N.
The same xi_O is retained through every constructor of this candidate.

Construct id as the standalone v_id above. Construct caller as an ordinary
Pure closure with Value(Unit) entry, whose body reads the already known id
root and passes the returning Name x carrier. Name lookup of the known id
adds no unannotated higher-order formal seed. The profiles inherited from
these independently constructed ordinary descriptors are retained; no
nested beta_N profile is imported or discarded.

A source-controlled prefix receives Delay(result(Unit)) at caller, forces
it once, rebinds x=Unit, and reaches the distinguished id x Call. Puncturing
that Call supplies H_f at the same known id reference and H_a at J_x. The
current caller owner, source call/result positions, whole returning argument
and ordered suffix are actual source-constructor outputs. There are no
imports, handlers, operations or resumptions in this prefix.

At arbitrary independently admitted whole carrier t, the identity's complete
source equation is

```text
ExecuteCallable(v_id,t,C) =
  enter actual id receiver and receipt;
  View(V_id,p_call,
       Force_argument(t) >>= rebind z >>= result(name z)
       >>= designated consumer >>= invocation return)
```

Thus its body has Result(Value(Unit)) = Comp(empty,Unit), while its complete
image includes t's actual execution, current world, complete view, receipt
and suffix. It is not identified with its body's empty row. The particular
source carrier `Delay(result(Unit))` is received by `caller`; after its Value
entry rebinds `x=Unit`, the separate `id x` call receives `Delay(J_x)`, where
`J_x=result(name x)` retains the source Name and original argument root. For
either carrier, an independently admitted request-bearing challenge would
retain its request and exact raw suffix, but this note admits neither carrier
merely because it can be drawn.

One can name a *candidate source-base root* by the complete constructor image,
with a retained independent carrier-domain predicate. Source contracts §2
would interpret this image jointly with DescMem; §3.2 supplies its constructor
shape. This makes a useful finite relation schema independent of Q. It does
not establish that this candidate root is the original complete Function
interpretation, select an Option 2 grammar, or prove its descriptor conjunct.

### Smallest remaining ordinary leaf

The original complete inlet of `id` must admit the actual source carrier
constructed for `id x`, at the proposed original Function root `F_id`:

```text
WholeArgCompatible(Comp(empty,Unit), CarrierContract(F_id);xi_O)
with carrier/root `Delay(J_x)`, `J_x=result(name x)`, and the current source world
```

This is exactly the independent inlet predicate of initial-context §4.4,
not actual membership of the tested H_f and not success of pending Q. The
source-side Return/Delay/Name derivation for `J_x` has been supplied. Value(Unit)
parameter formation supplies the expected result after entry, but typed
core §9 explicitly says that it does not specify the complete incoming
carrier contract. The required Return-carrier constructor typing/admission

Consequently the ordinary case has no missing inferred-formal beta seed,
yet still does not provide an original full-row witness. A conditional
PCInit-source application is available if the original complete inlet,
constructor descriptor and prefix-world typing laws supply this leaf and
the other original conjuncts. That conditional statement is not a source
admission theorem without those hypotheses.

## 4. Discriminators, independence and failure conditions

This is a symbolic derivation on two fixed finite source graphs; there is no
numerical oracle, random seed, range search or executable checker. The reference
is the inspected source constructor/entry equations, independently of a solver
or Oracle implementation. The construction and those equations share their
stated local descriptor, original-profile and current-world hypotheses.
Therefore even a checker faithfully implementing this derivation would only
check rule-relative consistency; it would not validate the missing original
profile/inlet rules from source.

The following premise mutations are discriminating logical checks, not run
mutation tests:

| Mutation | Exact failure |
| --- | --- |
| Replace Gamma_beta_N by singleton S_try because the trace is silent | Supplies a0 but loses exhaustive original signature-policy licensing |
| Copy upper delta onto the identity's lower output | Violates current directional no-backflow decision |
| Put a0 on argument.effect | Lacks the original carrier-result position correspondence |
| Erase beta after apply return | Confuses persistent profile with current activation filtering |
| Set complete identity output equal to empty body result | Omits argument execution, view and pending suffix |
| Restrict identity inlet to Delay(Return Unit) | Replaces the independently complete incoming-carrier domain |
| Derive carrier admission from hypothetical H_a typing or successful Q | Assumes the independent realization/admission premise |
| Use separate witnesses for captures, worlds or signature ports | Loses the single original X and xi correlations |

No repeat of the prior empty-support probe was run. The positive construction
instead fixes the actual source argument and source-controlled current prefix,
and localizes the remaining inlet/profile rule. A second or larger identity
trace would leave those same premises untouched and should not be dispatched.

Omitted: recursive unknown inference, other brace forms, general annotations,
handler source typing, State/general references, executable conversions,
production-only provider/history coverage, principal inference, both production
inclusions, arbitrary external-world initial admission, and current compiler
acceptance. No failure of these scopes is claimed.

Recommended next action: extract the original Function/profile constructor's
independently interpreted rule and its Return-carrier inlet typing lemma;
instantiate them on these exact same roots and scopes before another probe.
The nested inversion law must account for own and inherited sources without
assuming Slots(beta_N) singleton. This is a request for source-rule evidence,
not a proposed language meaning or a user decision.
