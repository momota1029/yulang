## Discriminating source derivation: what the existing map rule generates

[Typed-boundary §6](../design/2026-10-02-typed-boundary-realization-draft.md),
lines 665–818, contains the following source facts. A typed occurrence is a
view with value identity, signature position and evidence root. Correspondence
is generated by ordinary typed structure: binding without changing type uses
identity; forcing removes the result prefix for the returned value. Its
relational image transports profiles and dependency incidence, preserving the
shared `K` and inherited lineage. Receipt is introduced when the invocation
obtains that typed view; it supplies ownership of use and creates no contract.
The theorem at lines 970–1015 remains conditional on typed correspondences
and owner derivations, and explicitly leaves full source elaboration open.

Here is the exact conditional consequence, separate from a source formation
theorem. Assume:

1. An independently formed complete carrier `t` at its original typed
   computation port, including inert license and all execution, request,
   response, raw-resumption, future and lifetime evidence.
2. A genuine received-view/receipt application at actual `(u,L,d_f)`, with
   its whole original port correspondence `M_receive`, registered paths,
   profile, scopes and independent current guards. These are the premise
   still needing its owning source application.
3. The designated Force returns the same decorated `(v,C1)` at the formal's
   endpoint `A_f`, or an independently justified same-value inclusion into
   that endpoint; use that inclusion's actual typed path map when necessary.
   This assumption concerns a completed Return case only. It does not assert
   that every carrier returns, and does not remove other observations.

For every already declared payload path `p`, with distinct indexed source and
target views, the ordinary Force and equal-type binding rules generate

```text
M_force  = { (result.p, p) : p is an actual payload path }
M_rebind = { (p, p)       : p is an actual payload path }
M_value  = M_rebind o M_force o M_receive
```

If result checking is needed, insert its actual correspondence between
`M_force` and `M_rebind`. This is not identity of carrier, provider and formal
roots, nor identification of distinct alias views. No solved Function shape
or family equality generates any of these edges. The correspondence is a
schema over the actual declared path domain; it assumes neither a finite path
depth nor an enumeration of future observations.

Relational-image composition gives, on those corresponding result paths,
`chi_formal = M_value*chi_carrier` and
`D_formal = M_value*D_carrier`, with the same `K`, `nu`, actual returned value,
provider and inherited lineage. The packet can also retain other original
sources of result evidence under their separate indexed maps. The displayed
equations do not discard such sources or project unrelated request/residual
roots into the value. They establish no capture grant or admission certificate.

Before Return, this map does not install a formal value. The original receipt,
Force observation and unfinished rebind/body/return suffix remain at their
event scopes. On Request, the original response/raw handle and resumed current
state feed that same suffix; receipt and completed phases are not replayed.
Divergence retains every finite prefix and supplies no completed binding.
These are the selected expansion cases of
[source-computation-role §10](../design/2026-10-02-source-computation-role-elaboration.md):582–665
and [typed-core §9](../design/2026-10-02-typed-computation-core-elaboration.md):912–996.
The algebra above supplies no new theorem about the body Call or all its
pending developments.

Thus arbitrary path-map syntax is not the unresolved premise. The missing
premise is the actual typed domain and owner application of `M_receive` and
the designated result/rebind ports at `L,d_f`, before using their elimination.
No event witness is moved above the formal Desc. The names `ParameterOrigin`
and `Fam_delta` are one static presentation of that application; their spelling
is not independently proved necessary to every original source proof.
