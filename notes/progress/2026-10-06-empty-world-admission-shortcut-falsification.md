## 3. One minimized logical countermodel

Fix one formal original fiber `xi0`, one original Function label `F0`, and one
candidate tuple label `X0`. Collapse all constructed-prefix and ordinary
Return/Delay facts into `S(X0)`. Let `W(X0)` be precisely the independent
complete inlet judgment above. This collapse strengthens the shortcut's
available evidence: no deficiency of an ordinary construction fact is needed.

The inspected clause skeleton contains these implications:

```text
Init(X0) implies W(X0)                 [applicable original inlet conjunct]
CompleteOriginalRow(X0) implies Init(X0)

all PCInit-source premises imply Initial_source(Seed(X0);xi0).
```

The PCInit-source premises include satisfaction of every local relation,
including the independent inlet factor. None of the inspected clauses gives
`S(X0) implies W(X0)` without a complete constructor typing/admission lemma.
The smallest Boolean valuation exposing that missing implication is

```text
S(X0)                    = true
W(X0)                    = false
Init(X0)                 = false
CompleteOriginalRow(X0)   = false.
```

The required implications hold; PCInit-source has an unsatisfied premise;
the proposed shortcut fails. A single tuple and a single unproved admission
bit suffice. Additional events, aliases, worlds, ports or source code do not
make this discriminator smaller or stronger. The countermodel can leave
other original predicates unassigned: `W=false` already prevents completion,
whatever their independently justified values.

**Exact limitation:** this is a logical countermodel to inference from the
displayed weak hypotheses through the inspected conditional clause skeleton.
It is not a model of the fully interpreted intended Yulang descriptors. It
does not establish that the actual `F0` rejects `t0`, that this source is
untypable, that the original completion family is empty, or that an empty inlet
is a permitted complete Function. An independently proved original rule that
entails `W` for this same candidate would defeat this countermodel's application
to that richer premise set. Its result is the missing rule/premise, not a new
language meaning. The alternative assignment `W=true` is also not source
evidence. No second construction or equivalent toy probe was attempted.

## 4. Quantifiers and failure conditions

For each original `F,xi`, the approved domain has the form

```text
D_A(F;xi) = { h | IndependentTypedCompatible_F(h;xi) }.
```

Here `h` retains the punctured context with both direct holes, the whole
argument carrier, other environment roots, current world, original scope,
paths, continuations, authority and joint evidence. It includes independently
admitted history developments. The tested callable's actual checked membership
and Q success are not admission premises. Independently licensed Option 2
carriers/providers need no source-constructor witness merely to belong to this
domain. The equation names the approved independently interpreted domain;
it does not select its still-open exhaustive primitive clauses.

One complete row for a fixed partial source construction `eta0` requires

```text
ScopedExists_sigma0 X.
  X extends eta0 and CompleteOriginalRow(X;xi0).
```

`eta0` is the constructed prefix, carrier and graph, not a complete valuation.
For any argument needing validity over challenges, the same original row and
profile precede the universal challenge quantifier; separate completions
`X_h` chosen independently per challenge do not prove such a claim. Providing
one `h0 in D_A(F0;xi0)` would establish a single admission instance. It neither
defines the domain as `{h0}` nor establishes its exhaustive interpretation.

The unchanged containment obligations retain their full quantifiers:

```text
for every original xi:
  D_C(xi) subseteq D_A(xi)
  for every h in D_C(xi): P_A(h;xi) subseteq P_C(h;xi).
```

These remain separate from existence of one complete source row. The source
contracts' allocation result retains exactly `forall V in V_alloc(S).
exists m_V`; a returning Unit construction does not expand that view class,
prove general soundness or principality, or supply either production inclusion.

Premise mutations audited symbolically, not executed as tests:

- Replace `CarrierContract(F0)` with `{t0}`: changes the original inlet rather
  than proving its compatibility judgment.
- Infer the complete call row from the identity body row: drops carrier entry,
  current view, rebind and pending suffix required by typed core §9.
- Set profile applicability from observed empty support or receiver expiry:
  confuses persistent source contracts with event/current-activity filtering.
- Infer `W` from hypothetical hole typing or Q: omits actual carrier evidence
  or violates approved comparison independence.
- Use independent witnesses for ports or `X_h` per challenge: changes joint
  dependencies or the uniform original-row obligation.

Recommended next action: prove or locate the **original complete Function
Return/Delay inlet lemma**, then instantiate it at the same `F0,xi0,sigma0,t0`
and current source world. Keep all other row/profile conjuncts visible. Another
returning identity trace would leave precisely this premise untouched.
