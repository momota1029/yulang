## 2. Bounded producer and explicit hypotheses

is a constructor skeleton, not a claim that a particular raw Yulang program

The declaration is the §2 form


Take one already fixed family instance `rho`, one actual retained map


Open once at `o` with fresh rigid tuple `kappa`; fix Delta, the family
instance and captured/shared coordinates. Check under declaration interface
and bounds only. The actual caller relation remains in the ledger; it does

fixed declaration, not a newly licensed primitive.

## 3. Field and telescope derivation

Let `G` be this supplied finite source/local-rule graph, with original binder
tree `T`. Name/immutable projection restricts the existing **joint** payload
certificate to its selected root. It does not independently infer fields or
choose another provider. Result chooses that root `R_r` in the same current
world. Selected §3.3 says each field edge retains the target record and its
complete dependent telescope; records come from their owning constructors.

Consequently the following input map is constructed at the Result site. A
row records a reference or binder incidence, not an extra runtime field.

| Item | Source origin / retained reference | Scope and sharing |
| --- | --- | --- |
| Returned descriptor and value/provider | Payload binding's selected existing root and the same actual payload object | Original payload telescope under `o`; no independently selected provider |
| Final result root/path | Actual `r` and `R_r`, with the selected certificate restriction | Original source result path; no hidden replacement root |
| Rigid local dependencies | Complete free dependency occurrences of `R_r` in the opening tuple `kappa` | Owned by `o`, kept distinct from ordinary Desc declarations |
| Shared/captured imports | Original Delta/family/environment references incident to the selected certificate | Original outer binders; one assignment or one original Shared binder |
| Payload profile and logical evidence | The selected certificate's complete incident typed paths/proofs | Their original typed scopes; ViewLogic/EventProof retain their source classification |
| Current configuration and operational evidence | Actual event/current-world operands incident to Result | Original EventField/OneShot/Shared ownership, as supplied by the owning law |
| `K,D,xi` | Original incident witness/profile/joint-interpretation references of the selected root | One original correspondence; no new solved witness or checking permission |
| Request response and raw suffix | Original `B(rho,kappa)`, `raw_k`, `J_q`, request profiles and `K_q,D_q` in `G` | Same request/opening tuple; no replacement by the arm's result |
| Original comparisons/guards | Each actually retained local comparison origin, guard reference and complete operand/dependency telescope | Original checking scope; no union of caller-private and arm assumptions |

The raw continuation row stays in the complete source ledger. It belongs to
the outward result interface only if the original result has an incident
dependency on it. This construction neither discards that ledger nor adds
an unrelated continuation field to the result. Likewise `K_r,D_r` denote
the original root's incident references; they are not asserted to equal the
entire request's `K_q,D_q`.

More formally, begin at the actual root reference. Follow existing field and
dependency-telescope edges to a fixed point in the finite `G`, retaining
their field kinds, source origins, owning binder nodes, and original order.
Call this graph `Inc_r`. Keep its boundary partition: original outer
dependencies, references bound under `o`, and any nested source binders.
This is the forward traversal of constructor outputs. It does not recover
ownership from names, numeric levels, assigned endpoint shapes or query
success. The traversal terminates by finite graph visitation and changes no
constraints or semantic assignments.

Selected §5.2 can retain this original tree and route its existing shared
and event operands into an allocated finite use schema. It supplies no
justification for moving `kappa` outside `o`, making it a free skolem, turning
it into a Desc template, or opening a result packet. Its source-directed
retention removes the need to reconstruct `Inc_r` after the fact; it does
not remove the remaining lifecycle theorem.

## 4. Exact finite encoding of the constructed data

For this fixed `G`, form a finite disjoint port universe `I` of its source
sites, endpoint/field ports, binder/opening ports, witness/proof ports,
world/configuration references, guard references and fixed rule identifiers.
Keep original sibling openings as different ports. Endpoint terms and
evidence are references to this fixed finite graph, not fresh unfolded
expressions. No quotient of actual worlds or witness values is claimed.

Encode `Inc_r` and its original context by finite relations including:

```text
FieldKind(field,kind)             Root(result_site,field)
Ref(field,target)                 Dependency(field,binder)
Own(binder,opening_or_region)     Before(binder,binder)
Scope(field,scope_port)           CheckingAssumption(scope,assumption_port)
Origin(comparison,source_site)    Guard(comparison,guard_port)
GuardDependency(guard,operand)    JointReference(field,witness_or_KD_port)
```

The relation symbols and their fixed arities are metatheoretic encodings,
not a proposed compiler representation. All encoded operands are original
references supplied above. The context space for these relations satisfies

```text
J_inc = product_i Powerset(I ^ arity_i)
|J_inc| = 2 ^ (sum_i |I| ^ arity_i).
```

The relational record decodes to the same labelled incidence graph and
original assumptions by reading each relation, because no port or edge has
been identified or omitted. This is an exact encoding of **construction
data**, not RAW_SOURCE atom decoding or an equation for every semantic read.
Within this fixed domain, one capture-avoiding bijection `alpha` on all bound
ports, fixing outer ports, preserves field incidence, ownership, order,
sharing, assumptions and guard-dependency references: each stored tuple is
mapped componentwise, and applying `alpha^-1` recovers it. This proves only
the structural statement. Semantic substitution/equivariance of local laws
is a separate premise and a source lifecycle step must first justify its
actual map. Dynamic event keys in Generalize §5.2 do not imply that this
fixed `I` covers all histories or source instances.

Thus the useful bounded result is: the selected owning rules determine a
finite, information-preserving input record for the sealed-boundary proof.
The conditional closure theorem of context-finiteness §3 cannot yet be
applied to result transport: its context-closed and source-preserving rule
premises for that operation remain missing.

## 5. First trace-local missing law and obligation operands

The first missing lifecycle law in this chosen trace is **outward result
package formation from `R_r` under the rigid opening**. Request `Pack_s` and
uniform request `Unpack` are selected. Neither their cut theorem nor the
selected Result/Generalize clauses supplies a result-boundary construction
that closes exactly the incident local binders and defines the later
checking interface. Operation-instance §7 explicitly leaves dependent
returned/stored-root preservation open.

The missing proof needs this operand/output signature; this is an obligation
description, not an adopted `Seal` API or new source constructor:

```text
Inputs:
  actual Result occurrence r and original typed root R_r under T;
  full Inc_r and its original outer/bound/nested binder partition;
  complete source ledger G, original provider/current-world/xi and K,D;
  retained actual operation map theta and request/opening correspondence;
  actual source result boundary and destination checking scope;
  actual downstream read/open sites and their original local laws.

Needed output/equations:
  source-justified target interface and bound-capture map;
  the same actual returned object and complete incident dependencies;
  packing realization at the original witness tuple;
  one coherent transport of every dependent field and binder;
  each actual Observe_h(original data;xi)
    = Eval_accessor_h(target record;xi), at its original scope;
  opening correspondence under declared interface/bounds, with caller-private
    ledger equations retained but unavailable as new checking assumptions;
  original guards and invalidation dependencies for every generated check.
```

Without the first output, the target operand of transport/read/open is not
yet specified by the selected clauses. Choosing an existential telescope,
new stored fields or accessor semantics here would silently supply the
missing source law. This lane stops at that point. It makes no escape ban
and does not weaken the requirement that dependent returned values retain
their original correlations.

If a later source-directed law supplies this signature, a lifecycle proof
must additionally establish semantic substitution/cut for its authentic
local fields, exact actual-observer equations, and all guard dependencies.
The componentwise relation argument in §4 alone cannot prove any of them.
Neither successful Generalize allocation nor a checker using stipulated
Pack/Read rules is an independent oracle for those rules.
