## Falsifiers, independence and stop condition

P requires a concrete last rule with conclusion E_old(j_c), its exact source
scope/Instance origin and full installation/occurrence inventory. Returning
Code, Initial, FrameCall, Own, Rep, E+ or a semantic truth value instead fails
the conclusion test. A genuine e_old immediately falsifies any proposed full
absence conclusion by Keep inclusion.

A requires a complete original producer case partition and inversion at j_c,
followed by exclusion of every case. Excluding the displayed Name/Name case
while preserving unknown old literal cases fails the partition test. The
sources expressly prevent equating Old with that singleton.

Analytic mutations were considered, not executed: renaming the instance as a
formal fails owner provenance; relabeling Initial as Emission changes judgment;
dropping unspecified Old cases violates complete import; replacing a literal
by a Name changes the source fiber; running id through a formal f changes the
source occurrence even when the provider is unchanged. No mutants, seeds,
random ranges or finite-model enumerations were run.

There is no independent executable oracle. This audit shares the selected
constructor interfaces and provenance hypotheses with its inputs. Source
conclusion inspection checks whether a cited result can supply a premise;
it does not prove the trusted local semantic laws, source-rule correctness
or production correspondence. A checker supplied these same rule transitions
would not resolve the missing producer inventory.

Stop: the inspected constructors repeatedly return the same original-emission
premise, or a different conclusion sort; two speculative probes would leave
that premise untouched. No third representation/model variant is proposed.
**Recommended next action:** primary obtains the actual Old module declaration
and its producer/eliminator interface, or delegates one explicit Instance-callee
owner constructor at c. Preserve the current selected semantics and full frame;
review that concrete output before any emission coverage or absence promotion.
