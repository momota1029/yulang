## 1. Objective, method and exact claim

Construct the most specific static-schema manifest supported by the existing
exact `my id x=x` constructors, preserving every original dependent operand.
This follows the [schema census](2026-10-08-id-sourcebuild-schema-census.md),
rather than recounting its family inventory as graph cardinalities. The
governing sources are [Generalize definition](../design/2026-10-08-source-generalize-definition.md)
§§2–4; [source proof](../theory/2026-10-08-source-generalize-definition-and-proof.md)

`f08e015e34b8034bb603e23107486a82553261b698ff1eddffbfa29e27ad20f1`.

**Result:** the origin substitutions, typed traversal boundaries and one
eligible Desc can be fixed conditionally. A closed node/edge/scope/telescope
manifest cannot be extracted from these sections. Even `Delta_a` has no
enumerated arity; the selected IF0, initial-world and event/proof telescopes
also remain abstract. The seven schema variants below are a proposed static
organization of known outputs, with explicit holes. They are not seven
source-rule nodes or a complete `N_id` implementation.

H-source is authentic Parameter/Lambda/Name/Result/generic-inlet formation,
L1–L5 at original scopes, a valid immutable initial world, and no genuine
fixed free dependency on a. The exact input excludes import, capture,
annotation, conversion and recursion. The binding-publication owner selects
the authentic inert-registration or ReturnedInstallation arm; neither arm is
chosen here. H-identity/H-bridge and canonical publication allocation are
unsupplied production premises. The proposed decomposition requires no new
language meaning and supplies none of those premises.

Claim classes:

- **Established dependencies:** the selected source Generalize construction
  and its retained source-rule partition, used at their recorded scope.
- **Conditional derivation:** under H-source, the selected retain/fix walk
  yields exactly one template, at the original Parameter type scope.
- **Bounded characterization:** exact origin and named record/constructor
  incidences available from the cited sections; no production-wide absence
  theorem or complete resource bound.
- **Candidate representation:** the seven-variant organization and reference
  boundaries below. Their adequacy awaits complete supplier schemas and review.

The proposal declares seven **indexing variants** and uses one occurrence of
each role for this source. That does not determine seven storage allocations,
seven binder scopes or seven rule nodes: a variant can index many source
clauses and registered subrules. It cannot replace the graph with a list of
variant tags. In particular `Invocation` must expose its complete referenced
source schema before `ScopedClosureRef` can be considered complete.

The native public VP grammar is not used as a replacement for that source
schema. Its ten named constructor families, seven phase cases and Echo
refinement provide a discriminating cross-check for the source bridge;
VP-BodyReturn explicitly permits a different valid B-provider (phases §4.3,
lines 290–306). Source Name/Result retains the same provider. The public
grammar's abstract administrative positions also are not counted as
publication-time nodes (phases §4.2, lines 266–282).

## 4. Typed edge and reference manifest

An edge occurrence is an original typed field incidence; a compound field
must expose its transitive dependencies. This table fixes traversal behavior,
not the unknown number of edge occurrences inside its target.

| Incidence | Required traversal and ownership boundary |
| --- | --- |
| Parameter → `Description(C,q)` → I_a/full component | Retain complete relation and all constraints. The one Desc a is shared by formal, body and outward payload references. |
| U_g → `Internal(C,r)` → complete component | Retain even when the raw provider is fixed; preserve separate description edge. Never change it to Established. |
| Raw U_g/anchor → Intrinsic, IF0, world/allocation/lifetime/captures | Fix every actual free dependent field. Empty captures need authentic ownership evidence. A typed reference may share storage but must expose the complete dependency closure. |
| ReturnedInstallation → `Executed(b,arm,tuple)` / `OneShot(b,field)` | Fix actual selected arm and complete same-world return/world/allocation/installed-contract/evidence tuple. Do not infer this arm from the generic U_g registration. |
| Scope → parent / Delta dependencies | Preserve original parents and each full telescope. `sigma_a` precedes challenge; ViewLogic lies below its Desc dependencies and before challenge; Shared stays once in base. |
| Event → EventField / EventProof / proof scope | EventField keys share actual runtime operands; EventProof additionally has incoming-frame/original-proof-region incidence. Both preserve exact dependent telescopes. |
| Frame admission → `PackGeneric(kappa,gamma)` → same gamma | Fixed sum introduction/elimination; the independently formed description index is internally bound. Preserve all eight named gamma fields and their dependent subrecords. No free a is introduced in raw U_g. |
| Receipt/Force/Return → rebind → Name → body Result → invocation Return | Same decorated value/provider and current-world action; distinct original body/outward ports. Before Force completion there is no formal or result. |
| Request/raw continuation/future → registered source/contract target | Keep typed arguments, response/demand/handle/current-world/lifetime/suffix incidence; reuse the declared continuation reference without eager history unfolding or receipt replay. |
| Publication → component / final root / anchor | All three authentic targets remain reachable and immutable for the package lifetime. Their semantic identity is not proved by pointer or tag identity. |

The six general Build categories are primitive local relation, conjunction,
union, constructor image, scoped binding and registered reference (source
proof §4, lines 372–384). A lower-level manifest must declare each occurrence
and target using these operations and supplied local rule telescopes. Naming
these six categories is not an occurrence manifest. References to future
independently typed J/contracts/proof grammars retain their original laws;
arbitrary finite developments are interpreted through registered schemas and
are not copied into the static publication package.

**Conditional derivation.** Retain starts from whole `N_id,R_id,T_id,C_id`.
Fix starts from U_g/Intrinsic/IF0 and genuine base fields. Uniform §5.2 binds
the description presentation inside the generic sum, so raw U_g has no free
a. H-source excludes every other fixed free dependency on a. Description and
Internal retain the complete component; hence the only ordinary Desc is
reachable and unmarked. Source proof §5.1 then yields exactly d_a at its
original sigma_a. No argument assigns an arity to Delta in this derivation.

**Minimal arity blocker:** Parameter's `Delta_a` is specified only as its
original free dependency telescope (source proof §3.3, lines 207–217; uniform
§4.1, lines 103–118). Instance §2.1, lines 71–77 expressly keeps its actual
incident operands; import-free does not make them empty. None of those
sections gives a field list, integer length or authentic instance supplier.
Therefore even the number of telescope slots on the single certified Desc
cannot be computed. This one omission suffices to block a total that includes
all dependent telescope slots. It cannot be repaired by assigning Delta_a one
slot because it is printed as one metavariable.

This is a finite source-document non-extraction result: inspection of the
specified governing sections finds no explicit arity/supplier. It does not
prove that no omitted document or future constructor could supply the arity.

**Smallest representation witness.** Even with a fixed telescope, the named
three-premise conjunction `P1 & P2 & P3` can have one ternary conjunction node
with three child incidences, or two binary conjunction nodes with four child
incidences. Both retain all three premises and their scopes. Source proof §4,
lines 372–379 specifies whole-tuple conjunction but no storage normalization,
child-list convention or sharing rule. This one-node/two-node distinction
shows that semantic clause preservation alone cannot determine a storage
node/edge total. It is a representation counterexample, not two alternate
language meanings or a claim that either encoding is approved.

## 6. Minimal completion obligations

Three supplier groups are necessary for a complete manifest. They are grouped
by ownership, not independent requests for new semantics:

1. **Parameter/Lambda static source schema:** enumerate `Delta_a`, complete
   Delta/Intrinsic/IF0 ports and scopes, original checking/body/invocation
   clauses, their premise arities and registered references. Uniform §4.1
   lines 112–124 and §5.1 lines 320–329 enumerate semantic categories but not
   field cardinalities. Its §4.3 lines 256–265 says conjoin local projections
   under existing binders, without an operand-occurrence table. This supplier
   must preserve the existing selected meaning.
2. **Authentic binder/formation/publication payloads:** enumerate every actual
   base/Shared/ViewLogic/Event/EventField/EventProof/Check/Specialize
   introduction, full telescope and typed reference target. Instance §2.1
   lines 108–112 and §2.2 lines 141–150 explicitly delegate their number and
   scope to actual owners. InertRegistration and ReturnedInstallation need
   separately complete payloads, selected by publication evidence. Owner
   draft §4.1 lines 295–305 supplies only placeholder owner fields; lines
   324–327 leave transitive acyclicity/dependency completeness unproved.
3. **Chosen finite storage encoding:** state inline-versus-reference rules,
   conjunction/union arity, deduplication and scope-parent representation,
   then count declared node/edge/telescope occurrences. Referenced manifests
   must be included transitively or explicitly excluded with separate exact
   size/retention accounting. Source proof §4 lines 396–402 guarantees finite
   schema only conditional on finitely presented local catalogues and does
   not supply an effective representation/complexity bound.

No complete per-binding byte bound follows even after static-schema counts:
publication/anchor records, retained transitive data, Arc activity, capacities,
construction scratch, coexistence and teardown need the separate census/owner
resource accounting. These are unsupplied, not assumed zero. This assignment
stops at these source arity/supplier/encoding boundaries.
