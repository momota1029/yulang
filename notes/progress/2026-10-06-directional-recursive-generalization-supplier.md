## 1. Result and the separation that matters

A source-origin supplier has a structural part that can be **constructed**,
without assuming an opaque whole-use origin certificate. Given a finite
rule-occurrence derivation with its actual generalization/use boundaries,
ordered operands, original scopes and comparison-premise links, the construction
in §3 is total. It assigns a single component ledger, constructs each use's
one whole-copy action, and records the source and rule ancestry of every
comparison. It treats recursive roots as back references and never unfolds
them to recover provenance. Its inverse is erasure of its own decorations.
Existing §22 introduction facts, when present, travel through that supplier;
the supplier does not need to classify a fresh coordinate as an existential
in order to preserve its source ancestry.

This removes a separate *certificate-construction* obstacle for a complete
retained rule derivation. It does not turn the existing resolved HIR graph
into such a derivation. Resolved names supply binder/use identities and
already derive lexical source ownership/import correspondence (§3.4), but do
not supply successor recursive environment discharge, semantic eligible-binder
selection at a generalization boundary, or a complete derivation of every
solver comparison. On the weaker graph the same pass is total as a structural
inventory, with these semantic obligations explicitly unresolved. Calling that
inventory `Supply22` would hide its missing conclusion.

For the exact approved `apply f x = f x` instance, source registration and
Name/Call inversion derive the directional upper incidence, and the approved
example determines the `NonHandlerFormal` outcome on the same root. Section 5
constructs a **complete active-predicate** seed/refined normalization for that
instance. The complete original same-source relation already contains both
the registration seed and the selected ordinary-use role conclusion. Its
formal-role coordinate is therefore fixed to `NonHandlerFormal`; substitution
of that source-entailed value into every original active primitive preserves
the full relation, irrespective of those primitives' otherwise unknown
role/effect meanings. This is more than raw `Role_0` conservativity. Comparing
an incomplete registration prefix with the completed source relation is a
different obligation, and is not certified by this normalization.

The strongest claim is therefore two positive constructions and a precise
boundary: total derivation decoration/whole-use provenance, exact active
relation preservation for that decoration, and the exact singleton's
completed-source role normalization. Actual source formation, new semantic
kernel changes and generic mixed-use refinement remain distinct gates.

## 3. A constructive supplier on rule occurrences

### 3.1 Inputs, nominal keys and one ledger

Let `Delta` be a finite resolved **rule-occurrence** graph. It contains the
actual constructor premises and original binder tree, not only a successful
constraint solution. A recursive source/root reference may make the presentation
cyclic; individual proof witnesses have the declared finite-derivation meaning.
Generalization and member-use nodes record their actual selected source view
and eligible owned identities. Their lexical source-import correspondence is
derived by §3.4; any additional semantic fixed anchors remain identified by
the actual source/generalization premises. A comparison node records its
actual rule, ordered endpoints and premise references. Independent semantic
meaning for those rules remains separate from this structural input.

The supplier produces:

```text
Decorate(Delta) = (Delta, Ledger_Delta, UseMaps_Delta)

Ledger entry:
  original component, original rule occurrence, binder, scope,
  original root/coordinate, source position, directed constraint occurrence,
  effect-position occurrence, source-stage premise references

Use map entry:
  actual use event, actual generalized view, one identity action,
  original-to-copied binder/operand/incidence correspondence, fixed imports
```

These are metatheoretic keys and dependent definitions. No new semantic type,
runtime evidence carrier or solvable inference existential is introduced.
For every original identity `a` owned by view `P` and use event `q`, choose
the canonical fresh key `(q,P,a)`. For an imported identity use `a` itself.
This defines the entire copy map at once. An owned source occurrence has a
copied occurrence key and a pointer to its original source occurrence;
neither is identified with a type endpoint. Repetition of `a` in a value,
recursive bound, effect position, provider, packet or formula uses that same
key. Different independent events have disjoint keys.

There is one original component ledger and one coherent family of these maps.
There are no independently supplied witnesses per port. A component may have
several selected member-root views; their original sharing stays in the
component ledger. SCC membership alone does not declare them one generalized
binder block. If a source event exports a tuple jointly, its single actual
view and single map govern that entire tuple.

### 3.2 The source/rule-directed pass

The following clauses are an algorithm for decorating the input derivation,
not additional Yulang typing rules.

| Input rule | Decoration constructed from that rule's operands |
| --- | --- |
| Parameter/binder registration | Record the original binder, its actual annotation occurrence or absence, source-selected entry, introduced coordinate and scope. Record a protected-variable seed only when that rule has the source seed premise; for the approved singleton registration this premise is established in §5. |
| SCC root registration | Give each registered member root its component/member key once and preserve the actual simultaneous environment references. This records root allocation; it neither validates the provisional environment nor equates root and body types. |
| Name/Result | Attach the actual lexical/environment reference and copy its original dependent roots/packets. The pure Result wrapper adds no origin seed. A capture refers to the fixed imported binder and scope, not a freshly seeded local Name. |
| Lambda/Bind/Call/annotation | Decorate ordered original operands, actual role/entry and every provider/result packet together. A Call's source upper constraint and designated complete-invocation output address get distinct nominal occurrence keys. An annotation gets its own original boundary/grant provenance; no grant is inferred from shape. |
| Original lower/provider constraint | Retain its own orientation, occurrence, inherited profile and packet. No `Dir-Protect` head is added by this clause. |
| Generalize | Retain the entire actual view and residual, its original binder tree, exports and latent/admission dependencies. Record its selected owned/import partition and origin correspondence; do not reconstruct a view from marginal rows. |
| Internal member use | Point to the same live member root and component ledger. No fresh use map or new seed is generated. |
| Independent incoming/member use | Construct `(q,P,a)` for all actual eligible owned identities; substitute the resulting *one* action through the whole view/residual and incidence. Keep all fixed imports, client constraints and the new direct query. |
| Comparison derivation | Record the actual comparison rule and its premise links: direct source check, structural child position/polarity, alias transport, transitivity, lower/upper restoration, or replay. Preserve the endpoint expression paths and original scopes. Each derived comparison is a new rule occurrence; a canonical endpoint pair is not its provenance. |

The last clause distinguishes three relations:

```text
SourceSite(e,s)             e's originating source/rule site
CoordinateLineage(q,a,a')   q's actual coordinate correspondence
PremiseOf(e,e_parent)       the comparison rule's proof dependencies
```

Their union is not an existential classification, a protection propagation
rule or a permission theorem. A derived endpoint may depend on several
source sites; their presence in its proof ancestry does not make every
endpoint an introduced existential. The actual source introduction judgment,
when supplied, is kept at its own event, variable correspondence and level.
Every guard invocation can consult the preserved lineage without deriving
`Intro22` from `Fresh`, from mathematical `exists`, or from a Q/R ordinal.

If the original system coalesces equal comparisons, the proof decoration
retains their rule occurrences separately while letting them reference the
same canonical endpoint pair. If the input gives only the coalesced pair
and discards its rule premises, the pass cannot recover which justification
occurred; it is outside the stated rule-occurrence input.

### 3.3 Theorem RS: total supplier, coverage and reflection

For every finite `Delta` with the input data in §3.1, the above pass constructs
its complete structural source-origin correspondence. No whole-origin/use
certificate is an input. Every original rule occurrence and ordered operand
has a decorated counterpart, every copied identity has its original preimage,
and erasure reconstructs the entire original derivation graph. The construction
is canonical up to the harmless choice of nominal key spelling.

**Proof.** First index the finite rule nodes, original scopes and identity
declarations. Registration allocates only nominal keys and references; it
does not recurse through root bodies. Then assign each Generalize view's
actual owned/import partition its key action, so all its recursive back
references have already determined images. Walk the finite operand/incidence
graph with a visited-node table, copying all fields and scopes under that
action. Imports are fixed by its definition; repeated owned operands have
the same image by key equality. This constructs each whole-use map and its
inverse on the owned image, including every original recursive bound.

Decorate each remaining constructor and comparison occurrence from its
given ordered operands and premise references. All references are to the
already indexed graph, so cycles do not require unfolding. Direct source
sites remain the original ones; comparison ancestry is represented by those
actual references, rather than inferred from endpoint equality. Consequently
every node/field/premise in the input is covered once. Conversely a decoration
can only reference an input node or its keyed use copy; erase the keys and
definition entries to reconstruct it. These arguments also cover arbitrary
finite witnesses through recursive references by induction on their finite
rule applications. QED.

The theorem constructs rule provenance **for every comparison already in the
derivation**, even one whose guard fails. It does not prove that a generator
emits all semantically required comparisons, that their rules are valid,
or that the selected §22 guard has been applied. Those are comparison-coverage
and preservation gates. Totality here does not mean accepting every source.

On an actual resolved syntax graph lacking some §3.1 fields, the same pass
constructs the available sites, lexical/capture references, nominal root
inventory and use-family keys. It emits missing obligations at the corresponding
nodes instead of inventing those fields. This weaker result is total structural
inventory, **not** RS's total complete derivation supplier.

### 3.4 Bounded delta: lexical ownership/import correspondence is derived

Fix a finite correctly resolved source binder tree and an actual source
boundary `B`, such as the complete definition component. For a component,
`B` means its resolved member declarations and their parameter/body trees,
not a newly invented lexical binder around those declarations. Let `Desc_B(d)`
mean that the declaration/parameter binder `d` lies within that boundary's
source ancestry. For each resolved Name occurrence `u`, resolution already
gives its unique binder `Resolve(u)=d`. Define the structural source map by

```text
SourceOwner(d) = d's original declaration scope
LocalSrc_B(u,d)  iff Resolve(u)=d and Desc_B(d)
ImportSrc_B(u,d) iff Resolve(u)=d and not Desc_B(d).
```

This is a partition of **resolved source references**, not a generalization
rule or an existential-origin classification. If a Name's supplied interface
contains dependent provider roots, packets or other captured endpoints,
retain their original references and lexical correspondence through the
existing environment/constructor premises; do not reconstruct them from its
printed endpoint type. Traverse a finite retained dependency graph by its
references, preserving each original source binder/scope. Any semantic
coordinate lacking such a source correspondence remains an unresolved
source-to-coordinate obligation rather than an invented lexical owner.

**Theorem LX.** The correctly resolved tree determines this lexical map
totally and uniquely. Name/Result and constructor composition preserve it;
recursive references require no choice of an outer import and no unfolding.
It is therefore not an opaque additional premise of RS.

**Proof.** Index the finite binder tree and its parent relation. At a binder
declaration, its scope and ancestry are the original source data. At a Name,
read the unique resolved binder and classify its ancestry relative to `B`.
The two cases are exhaustive and disjoint. A capture records that same
binder across an intervening scope; it does not allocate a new declaration.
Name copies its supplied environment entry, and Result preserves that
entry's provider/dependency references, so neither changes the classification.
Induction over the remaining source constructors keeps the original operand
references. An SCC back reference still points to its already registered
binder; classifying that binder does not recurse into its body. Following
the actual finite dependent-root references likewise preserves their
original lexical correspondences. QED.

For the closed source

```yu
my f x = g
my g y = f
```

take `B` to be the whole resolved `{f,g}` component and its parameter/body
tree. Its two body Names resolve respectively to `d_g` and `d_f`, both
inside `B`; `d_x,d_y` also lie inside that source tree. Thus no body reference
introduces a **captured outer value root of the component**. The `f` closure
can still capture the original `g` root across its own lambda boundary,
and conversely: those are internal component references, not nonexistent
captures. Ambient primitive/declaration identities and any independently
specified rigid environment remain fixed. An isolated member-root view need
not have the same boundary as the complete component.

The relation to actual RS use actions is precise. LX provides each source
reference's original binder and capture/import path. An actual eligible
Generalize view `P` then provides its semantic binder set `Omega_P` and any
additional fixed semantic anchors. RS's action maps each eligible semantic
identity once and fixes the actual rigid imported roots; all its source
reference pointers continue to name the same original LX binder under the
copied occurrence correspondence. A copied coordinate can retain ancestry
from an external generalized template while being allocated at a local use;
that source ancestry is not confused with semantic ownership of the copied
coordinate. The action transports both facts jointly.

LX consequently removes arbitrary selection of **which source binder a
capture imports**. It does not entail that every coordinate with a local
allocation/source site belongs to `Omega_P`, or that every coordinate not
eligible for freshening is an outer source capture. A locally originated
coordinate may remain an additional semantic anchor if the actual source
generalization rule justifies it. Eligibility and binder placement must
still be derived; they cannot be obtained by rebranding such an anchor as
a source import. Nor does LX choose one SCC-wide generalized view, discard
latent dependencies, classify `Fresh` as §22 introduction, or create a
protection seed at a captured/external Name.

The direct source basis is the selected Name/Result environment rule,
call-view §2's source resolution/capture and scope-preservation requirements,
and approved a2 item 4. The semantic eligibility boundary is expressly
retained by the Authoritative experimental transport gate's scope paragraph
and the reviewed constrained-use construction, both of which start from an
actual eligible view. This delta introduces no generic typing rule.

## 4. Complete active relation preservation for this construction

Let `E_Delta` be the original independently interpreted complete relation of
the input derivation, at its original binder tree. It contains all its actual
roles/entry, upper/lower checks, argument obligations, providers/results,
profiles, receipt/path relations and active membership/admission/observation
predicates. Fix one whole assignment `xi=(nu,K,D)` and original internal tuple
`w`; any proof-local definition stays below every original rigid dependency.

There are two useful claims, which must not be merged.

**RS-active, decoration.** Materialize `Decorate(Delta)` as dependent proof
definitions and keep every active primitive's original interpretation and
whole operand tuple. Where an original primitive reads source incidence,
give it exactly the incidence computed from its original rule derivation.
Then erasure gives precisely `E_Delta`, in both directions, preserving the
same original `xi,w`. This also holds when a primitive rejects a tuple because
it reads protection, and when it negatively tests an incidence.

The derivation is stronger than an assertion that role records are conservative:
all primitives are held fixed, including `Typed`, `DescMem`, `OpenInit`,
provider/profile compatibility, `Path`, `Observe` and `Visible`. The derived
ledger supplies their old source-indexed arguments; it does not redefine
their meaning. For the selected singleton, §5 derives the original directional
incidence supplied to those predicates. Outside that source case any missing
stage applicability remains an explicit missing premise.

**Proof.** The proof definitions have the unique values constructed in §3;
each original active primitive sees the same original arguments and incidence.
Every old whole witness extends by these definitions and every decorated
witness erases to it. Conjunction, alternatives, images and scoped binding
retain their original shared witnesses. At a recursive block this argument
holds for *arbitrary* recursive predicate arguments `X`, before any fixed
point is taken: all original clauses and operands are still present. Thus
the defining operators on the same original carrier are pointwise equal,
and their designated finite-derivation interpretations agree. Decoration
introduces no larger semantic recursive carrier. QED.

**RS-use, constructed alpha certificate.** Each §3 incoming-use action
provides the concrete alpha certificate for the **whole** original relation,
under the independently given primitive equivariance laws. It is constructed
by visiting all ordered fields; it is not a supplied unexplained origin map.
Satisfaction at the copied tuple is satisfaction at its single original
pullback. Every scope, imported capture, residual and active predicate is
transported together. Recursive operators are conjugate under the constructed
bijection on their actual carriers, so finite witnesses translate in both
directions. A new client query is retained as a conjunct on that copied
relation; it does not become an origin premise.

This proves provenance transport separately from §22 classification. It does
not prove exact projection through an arbitrary hiding step. Old witnesses
affecting admission remain in the fixed comparison interface unless the
separate joint-hiding/admission theorem applies. No `exists w. forall challenge`
is exchanged with `forall challenge. exists w_challenge`.

If an alleged “decoration” changes an active primitive's role/profile meaning,
adds a new descriptor obligation, or exposes a different admission domain,
RS-active does not apply. It belongs to DREL-2 below. Operator equality cannot
be recovered merely by equating the projections of final satisfying tuples.

### 5.1 Which original relation is being normalized

Distinguish these two objects:

```text
Prefix_c: registration/seed before all of c's source obligations are present;
Complete_c: the complete original relation of this same approved source.
```

`Complete_c` includes both the source seed fact and the required ordinary-use
role decision. The authoritative source/public/internal distinction proves
that the provisional `ProtectedHandlerSeed` tag is not an equation on an
actual callable role, and that the completed `NonHandlerFormal` result

coordinate by `rho_f` on the existing inferred root; keep the source seed tag

installation of a new source type or a generic Value-entry-implies-Pure rule.

For this exact source, call-view §3 and the returning ordinary `x` evidence
above entail the **completed-source** clause

```text
Complete_c(xi,w,rho_f) -> rho_f = NonHandlerFormal.       (Selected-c)
```

This entailment is obtained from the selected singleton outcome, not by
defining `Complete_c` to satisfy it. A claimed complete relation without
that outcome is not a presentation of this selected example. The authority
does not similarly imply that the incomplete `Prefix_c` already excludes
every other unresolved candidate; no prefix-to-complete coverage is inferred.

Here the source-selection clause is independent of recursive predicate
arguments: the ordinary parameter tag and returning Name of `x`, resolution

### 5.2 Theorem SC-normalization: full active singleton bridge

Take any independently interpreted complete presentation of this original
source obeying its selected outcome. Let `G_c(xi,w,rho_f;X)` be **all** of its
original clauses with that formal-role coordinate explicit. Include ordinary
registrations, Name/Result, source seed and incidence, actual provider role/entry
and own profiles, all upper/lower constraints, `WF_Dec(F_c)`, whole-argument
compatibility, complete invocation/result checks, original packets and client
constraints. Include every active role/effect-dependent primitive:

```text
Typed, DescMem, provider/profile compatibility, source-view realization,
OpenInit and future admission, typed receipt/path/capture attachment,
Observe and Visible, every residual and latent/provider dependency.
```

Their meanings are given independently and are left unchanged. They can be
arbitrary functions/relations of `rho_f` and the entire original tuple; no
monotonicity, empty row, unique realization or role-insensitivity is assumed.
The original selection clause is retained. Present the two stages by

```text
E_seed,c(xi,w,rho_f;X)
  = (rho_f = N) and G_c(xi,w,rho_f;X)

E_ref,c(xi,w,rho_f;X)
  = (rho_f = N) and G_c(xi,w,N;X),
N = NonHandlerFormal.
```

If `G_c` already contains an independently expressed source-role decision
predicate, retain that predicate too and substitute into it. Conjoining
`rho_f=N` is a checked entailed-equality step by `(Selected-c)`, not a new
restriction on the original complete relation. `E_ref,c` is obtained by
capture-avoiding substitution of a proved equal term throughout the *actual
original presentation*, not by specifying an otherwise unknown refined
predicate to have the desired meaning.

**SC-normalization.** The two complete relations above are pointwise equal
on the whole original tuple, including every active semantic primitive.
When the formal coordinate is eligible for elimination at its original
binder position,

```text
exists_original_scope rho_f.
  (rho_f=N and G_c(xi,w,rho_f;X))
    iff G_c(xi,w,N;X).
```

The inverse restores the unique original `rho_f=N` at that position. All
other original witnesses, including semantic realization witnesses and
providers/results, are retained; there is no independent reselection per
use, port, challenge or observation.

**Proof.** `(Selected-c)` justifies insertion of the equality on the complete
source presentation. At any fixed original scoped assignment satisfying
that equality, each active primitive sees identical arguments before and
after substitution: the same `xi,w`, the same actual callable role/entry,
the same `rho_f=N`, original `M_c` and inherited profiles. Thus every original
primitive has the same truth value, including a role-dependent effect-port
interpretation or a negative protection test. Ordinary equality substitution
then proves the formula equality without a supplied `FormalSeed/FormalRef`
equivalence. Existential elimination uses its unique equal witness at the
original scope; any outer rigid binders remain outer. QED.

For recursion, retain the formal coordinate in the old carrier and the
selection equality in the paired clause, or work at the fixed original
selected fiber `rho_f=N`. For arbitrary recursive relation arguments `X`,
the same primitive argument equality proves pointwise defining-operator
equality on that fiber. The common least/finite-derivation interpretation
therefore agrees. Do not eliminate a coordinate from one recursive carrier
and assert equality to the old operator on a different carrier. If elimination
is desired, use the explicit inverse insertion `rho_f=N` as the carrier
