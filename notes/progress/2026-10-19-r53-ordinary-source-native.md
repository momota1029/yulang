This gives a static ordinary producer-to-dispatch path conditional on successful completion of all preceding source and admission owners.

The scalar Function comparison inserts one signed physical bound and replays it (`candidate_extrusion.rs:912–941`). Extrusion retains each copy/parent with the current source-event set and qualifies pending parents only when that set contains a source event accepted by the retained reference graph (`candidate_intrusion.rs:305–385`).
