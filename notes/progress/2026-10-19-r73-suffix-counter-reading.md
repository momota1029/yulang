## 3. Adversarial schedule and lineage checks

The following checks discriminate claims that would otherwise look like A/C:

* **Fiber multiplicity:** `Capture::bound` iterates the entire exact bound
  cursor; it creates one captured Bound per `(kind,side,lower,upper,relation)`
  (`candidate_scheme.rs:1007–1050`). One physical key is not one restoration.
  With no attached relation, it still captures one None relation/snapshot case.
* **Mutation during restoration:** the saved opposite count is sampled after
  insertion (`candidate_extrusion.rs:763–783`); each product rereads the live
  canonical owner and saved index (`:801–877`). Restored earlier children can
  append bounds or redirect representatives. An entry-time list used for every
  later product would need a separate invariant.
* **Replay parents:** incoming Local uses ignore prior replay-head cutoffs;
  `incoming_use=true` constructs all current lower/upper fiber products, even
  if an ordinary dependency already existed (`candidate_context.rs:3781–3837`).
  Replay identity does not erase those parent IDs or input BoundKeys.
* **Memo reuse:** `pair_is_current` requires the actual processing relation's
  completion at the current generation, plus the raw typed-pair entry
  (`lib.rs:11599–11610`). Pair equality alone cannot suppress work. Retained
  extrusion rewrites enter recapture before enqueueing the rewritten task
  (`:12493–12526`). Recapture searches only groups indexed by the original memo
  key and actual reused output endpoint; source-set reuse can activate a
  previously unqualified group (`candidate_intrusion.rs:388–427`).
* **Physical aliases:** merge copies from canonicalized items before its forest
  write; canonicalization forwards fibers and retains raw keys. Production
  `Work::Bound` instead retains the selected raw item as its source key
  (`candidate_extrusion.rs:145–167,325–341`; `candidate_effect.rs:677–727`).
  Every same-class physical selected slot must be included before claiming a
  missing canonical fiber. This note did not complete that inventory.
* **FreshUse is not Work::Bound:** Local restoration at `:763ff` does not run
  production `Work::Bound`; that work variant belongs to the structural
  extrusion loop. Its production callers remain `lib.rs:12572,12585`.
