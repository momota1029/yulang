## Disposition

The current selected authority fixes the original source Call and Function
meaning and requires ordinary source constraint generation followed by
Simple-sub propagation. It does **not** select an abstract source judgment and
interpretation that maps the original fixed-`xi,z` Apply/Check obligations to
the four native contextual Function children with their actual post-check
contexts and scoped-flow actions.

This is an authority/source-owner gap for the requested source/native bridge.
It does not show the bridge is false, establish a source-qualified
counterexample, or close `FIRST-RESULT-ADEQUACY`. A proof could still derive
the correspondence from the selected semantics if it supplies the missing
argument. Defining the four child predicates as assumed consequences or adding
them to the source antecedent would change the proof obligation and is rejected.
