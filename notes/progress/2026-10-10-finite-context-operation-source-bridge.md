## Static derivations and discriminators

For a successfully formed closed covariant row, source construction retains a
view `v` and weight `w` with its exact owner/position. A check `s <: Allowance(v)`
seeds `PrefixLeft(w, Identity)`. Whole-DAG validation authenticates `w` against
that view before calling the check. If `s` canonicalizes to a row, the live
consumer either installs its negative Allowance bound or records this source
origin on the existing bound and replays it. Only after every validated filter
has a retained check does it record discharge. The bound's Identity context is
licensed only when the active checking relation and canonical lower owner
match. New opposite fibers are then replayed in their original lower/upper
order. These source rules support the conditional finite closed-filter seam;
they do not contain PUSH/POP subtraction or gamma creation.

The smallest explicit missing-producer source schema here is:

```yulang
act E
my answer (cb:int -> [E] int) = cb
```

This is a static schema, not a freshly parsed/run witness. Given its HIR
annotation, formal variance starts Negative, and Function result variance stays
Negative. Its one concrete result member therefore fails `preflight_formal`.
Bypassing preflight still fails `candidate_formal_pair` before constructing a
view. A direct existing test at `candidate_context_tests.rs:2308–2335` mutates
the formed symbolic formal's result row by adding E and asserts constructor
failure with unchanged contextual state; that test was read, not run here.
The missing premise is the actual contravariant source-owned attachment
constructor and consumer, not inference of a target result scheme.

The minimal structural consumer discriminator is an authenticated filter
`f = PrefixLeft(w, Identity)` versus `Swap(f)`, on the same Effect relation.
The former enters the supported branch. The latter reaches the validator's
default error before any registration is published. This is a direct branch
derivation, not a source-reachable Swap counterexample or executed probe.
One local prefix alone does not witness failed nonempty operation execution;
the extra Swap is necessary for this discriminator. Likewise
`PrefixLeft(w, f)` fails the leaf-only prefix requirement. The detached algebra
accepting these trees cannot establish live source execution.
