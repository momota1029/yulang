## 1. Result and theorem envelope

For the exact approved source

```text
my apply f = { my step x = f x; step }
```

one can emit a **finite unsolved profile/slot obligation alongside the unknown
complete Function demand**. A completed original profile is not needed as an
input to that emission. The binding, original upper occurrence, prospective
carrier-result position, and no-annotation policy have constructive sources.
Policy completion at independently applicable positions is deterministic:
protection is present and there is no concrete grant from this formal. The
original provider/result packets are independent additional inputs.

The complete applicable-position/contribution predicate is different. The
source rules read here construct its mandatory upper-output member and its
incidence, but do not establish an exhaustive interpretation for all positions
of the independently interpreted original inferred contract. The construction
below keeps that obligation explicit, instead of declaring a singleton complete
profile or retaining a completed profile as an emission premise.

A parallel expansion of the initial-admission obligations constructs the exact
two-hole source graph, environment, ordered suffix, and source-owned result
paths. It separates the actual code/carrier, import/world, operation-response,
raw-handle and future-port checks. No check is success of pending Q. This is
more precise than a supplied `TypedContext` or `JointWF` certificate. Some
primitive interpretation leaves still lack their unrestricted construction.

Two actual source/control attempts are worked below. A standalone identity
value gives an event-free returning execution of this source; a registered
pure loop gives nonreturning finite prefixes; a declared request gives a
suspended source/control case with its exact raw suffix. These are concrete
constructor witnesses for their stated structural/operational envelopes.
**They are not witnesses that the independent COMPLETE original profile and
all-world Function/admission predicates hold.** Their remaining predicates are
displayed. In particular, there is no proved nonempty family of complete
original profile solutions in this note.

The useful new envelope is:

1. finite unsolved source profile/policy obligation generation;
2. unique policy assembly from original applicability, without a new semantic
   policy choice;
3. expanded comparison-independent initial/history obligations and finite
   parametric templates, including nonreturning developments;
4. an explicit failure of the identity/empty-support shortcut to certify
   original full-row validity.

The selected SV realization is reused only after original validity has been
established. This note does not claim its conditional transport as a new
completion theorem. Full original profile/admission coverage, effective
inference, general recursive eligibility and both production inclusions stay
open. No new user decision is requested.

### 3.3 Policy-assembly lemma

Fix an independently valid original applicability/contribution relation
`S_beta` at the original row. Include original source tags and the typed
correspondence, rather than just an effect endpoint. The no-annotation part
of its source-owned profile is forced:

```text
for every original applicable incidence a in S_beta:
    Gamma_beta(a).protected = true
    Gamma_beta(a).grant     = none
for every nonapplicable incidence a:
    this source boundary contributes no incidence at a
```

Inherited provider/result packets are not members of this source-owned
boundary component merely because they meet the same target path. They stay
separate sources of the full receiving packet. An inherited concrete grant
remains indexed by its own boundary/receiver and is not changed to `none`.

**Proof.** Typed-boundary §6 says the original profile specifies exactly the
protected computation positions and concrete capture contracts of the
source signature. At applicable omitted/wildcard positions it supplies
protection without a concrete grant; a nonexposed/nonprotected position gets
no incidence from that source. There is no other annotation at this original
formal. Consequently two profiles for the same fixed original applicable
incidences and source tags agree on these policy fields pointwise. Assembly
creates no permission and performs no solving. The Dir-Protect instance fixes
one mandatory incidence, not exhaustiveness of its inventory. QED.

This is **unique source-owned policy assembly conditional on original
applicability**, not unique whole receiving packets, a singleton Slots proof,
completion nonemptiness, or principality of the source relation. It identifies
which part of P is already specified instead of asking for another policy.

## 4. The atomic coverage problem behind a complete original profile

The original applicability/contribution obligation has four questions at an
original dependent position `a`:

```text
1. Which original source declaration/binder/exposure licenses a?
2. Which original contribution and tagged upper occurrence does it govern?
3. What is its original signature-position correspondence, including scopes?
4. Is that licensing inventory exhaustive for this original contract/row?
```

For `(k,beta,u,sigma,p0)` all four pieces needed to construct that **member**
are produced by the selected source rule. For inherited provider/result
positions, their own independent origin/profile inputs answer their member
questions; retaining them does not license a new beta-origin. For other
positions of the unknown complete inferred signature, solving its shape
answers none of questions 1, 2 or 4. A hypothetical latent effect under its
result has a type address if the endpoint permits it, but does not thereby
have an original beta introduction.

This is not an argument from the absence of a printed completed judgment.
The source constructors have been actively composed: registration produces
the seed; the resolved Call produces the unsolved upper/output address;
Value entry produces the result prefix; binding/Name/capture produce the
retained identity correspondences; policy assembly supplies every licensed
mark and its absent grant. What remains is the independent formation rule
whose inversion would establish **all** original applicable source/profile
incidences. Transport cannot be its last rule because it introduces no new
boundary or applicability; `VIncl/CIncl` cannot be its last rule because it
checks same-value/interface membership without boundary introduction.

A rule may be written using another notation or incorporated into an existing
Function-constructor interpretation. It need not be a new language feature.
If so, the next proof must expand that constructor's original independent
clause and prove the four items above. This note establishes no impossibility,
no pair of incompatible complete Yulang semantics, and no necessity for a new
user decision.

An exact finite source **rule-template** inventory can be emitted now:
registration; original upper/output introduction; original carrier-result
lift; actual-result rebind; Lambda environment capture; Name read; future
opening of an already typed returned view. It does not follow that the set
of complete original profile incidences equals this template inventory.
That equality is precisely what needs original applicability inversion.
Replacing it with syntax-counting would omit the independent interface,
provider, annotation and future-world judgments.

### 4.1 Bounded original-beta inversion, including the inherited-source arm

Here is the bounded inversion attempt on the exact original source graph.
It uses the independently specified no-new-boundary/no-new-origin discipline
of typed-boundary §6, rather than counting syntax nodes. Let a source-typed
profile incidence at the captured read of f carry original beta. Retain its
indexed input witness: `own-beta-introduction` or an inherited provider/result
source. Filtering solely by a numerical beta label is insufficient. A value
can inherit a profile from another invocation of this same static source
slot, with the same beta and a different receiver/boundary occurrence.

Invert the actual source rules on the own-introduction arm:

```text
read profile incidence
  -- Name/read indexed identity --> same captured environment incidence
  -- Lambda/capture indexed identity --> same rebound f incidence
  -- actual-result Rebind --> corresponding prospective result incidence
  -- original receipt source arm --> original Gamma_beta at beta introduction
```

Each arrow is inversion of the original ordinary source constructor's
specified relational image. An output witness includes its input path and
indexed source, so this backward proof retains the exact original boundary
reference, original scope and complete packet. Rebind inversion requires
its actual Return/result transition. Without that transition there is only
the prospective Pending packet; the backward tree cannot fabricate a read.
If a result image selects the inherited-provider arm instead, inversion
returns that independently existing provider packet, including all its lower
marks. It does not relabel it as an own-beta source or delete it.

For an actually exposed event at the later f invocation, add its original
source Call-output observation and matching owner receipt before this
inversion. The static `ElimOrigin` identifies the original upper complete
output; the actual executing source Call supplies Observe there. Candidate
incidence still requires the original handler, owner and boundary receiver
live in the queried configuration. Inversion of the profile alone supplies
none of these actual event/control facts.

The own-introduction branch now reaches an exact final premise:

```text
original source beta introduction consumes Gamma_beta's applicable
signature/profile incidence at its original prospective result position.
```

The selected seed/upper constructor proves the p0 member of that premise.
No other ordinary rule in the backward tree manufactures a member: Lambda,
Name, Bind and result transport preserve indexed originals; Call exposes its
designated source output without enumerating new latent positions. The source
profile-introduction primitive, however, consumes the original full Gamma.
The no-new-origin law for transport cannot invert through that supplied
signature-profile input to prove its entire original licensing inventory.

This is a genuine reduction of the original-beta inversion obligation:
source transport and provider inheritance are fully separated, and the first
remaining own-source clause is specifically **original signature-policy
licensing at beta introduction**, not a missing captured-read association or
a generic event profile/path predicate. To finish the proposed inversion one
needs an original law showing that every such newly introduced signature
incidence has a declaration/seed/exposure proof at that same beta, and that
those proofs are exhaustive. Treating that law as already true because the
currently displayed graph has one Call would restore the forbidden singleton
converse. The proof does not select it or conclude Slots(beta) is a singleton.

## 5. Independent initial-admission predicate, without a supplied context

Puncture a distinguished Call at the original source graph. `H_f` denotes
the checked callable hole; `H_a` denotes the whole argument code/carrier
hole. Neither is an actual member in the ordinary semantic environment.
Generate the source-owned context graph with hypothetical interfaces,
retaining both hole references everywhere, including open captures and saved
suffixes. For this exact component the generated open skeleton is

```text
lambda(d_f,
  bind(d_s,
    result(lambda(d_x,call(result(H_f),n_H_a))),
    result(name d_s)))
```

A puncture at the inner Call replaces the callee reference by the rigid
`H_f`, retaining its original association with d_f in the surrounding graph.
`n_H_a` denotes the whole argument code/consumer hole, without executing it;
its unpunctured source operand is the original `J_x`. The original outer formal
receipt/result prefix and the local closure's capture reference are retained.
The skeleton above displays the surrounding ordinary source, not a replacement
which eagerly evaluates the hole or gives it a new binder.

Expand an initial-seed witness as the following joint conjunction:

```text
Init(X) = OpenSourceGraph(X)
        & OriginalProfilePositions(beta,S_beta,Gamma_beta;X)
        & ArgumentCodeContract(H_a, original source interface/root;X)
        & JointImportsAndCurrentWorld(X)
        & OriginalDistinguishedPortAndOrderedSuffix(X).
```

The conjuncts are not opaque aliases for completed context typing:

- `OpenSourceGraph` is the finite Lambda/Bind/Result/Name/Call constraint
  conjunction. Lambda stores its actual role/entry, body and open captured
  references; Name reads one registered root; Bind uses one result/state and
  suffix witness. Local Calls retain their whole semantic checks under the
  hypothetical hole contract. The independently interpreted descriptor
  leaves and profile applicability remain explicit inputs.
- `OriginalProfilePositions` contains the original inventory and policy
  obligations of §§3–4, not successful Q or endpoint-shape matching.
- `ArgumentCodeContract` checks the source code/carrier independently of Q.
  Actual code may suspend or diverge; a hypothetical hole interface is not
  evidence that arbitrary actual code belongs to it.
- `JointImportsAndCurrentWorld` checks the independently supplied import
  descriptor contracts on their original roots; shared aliases/operation
  witnesses/current continuations/active owner records are one relation.
  A source-constructed current prefix can supply these by the original
  constructors. Arbitrary external semantic worlds need their independent
  interpretation; graph-shapedness and closed-program reachability are
  neither definitions of that domain.
- `OriginalDistinguishedPortAndOrderedSuffix` keeps the two holes, actual
  source complete-call port, result/rebind position, original receipt owner,
  current configuration and the exact unfinished source suffix together.
  Static schemas become actual receipt/rebind facts at those transitions.

All existentials are at their original positions. Neither actual target
membership of `H_f` nor preservation of the plugged program is a conjunct.
For an independent actual filling, plugging replaces both holes throughout
this single graph, including every capture and pending suffix. It preserves
provider aliasing. This does not prove checked-to-actual domain inclusion.

The predicate assembly is source-owned and comparison-independent. Its
structural rules and their inverse witnesses are constructive by the
initial-context note. Its applicability, descriptor/import and complete world
leaves must still be independently interpreted and discharged. In particular,
this is not a definition of unrestricted Option A/2 admission by source code.

## 6. Full finite histories and parametric finiteness

Extend an initial witness only by the original four admission classes:

| Extension | Required independent joint facts |
| --- | --- |
| Initial | The complete Init witness above, including actual source argument/world evidence when instantiated |
| Response | An actually exposed request q, its declaration-instance response contract, same invariant arguments/payload/response dependencies and the actual current configuration |
| Raw resumption | That request's original raw handle and saved suffix; current state and original borrow-or-fresh owner protocol; no replay of receipt |
| Future call/force | An actually returned provider with its original typed port, actual role/entry, current world and independently typed whole argument/consumer |

No request-free carrier must return. No indefinitely suspended history must
choose a response. At Request, the pending suffix is the original
`rebind; body; designated consumer; invocation return`, appended to the same
raw handle by ordinary Bind. At pure divergence, its actual finite prefixes
remain Pending; no limiting returned provider or future-port witness is added.

If every history extension appends one entry, induction on history length
proves exact finite closure over its independently interpreted local rules.
This does not construct the initial import/world/profile leaves. It also does
not assert an infinite-history compactness principle: all horizons share the
original row and causal witnesses, rather than independent `exists witness_n`.

Static emission is finite even when executions/resumptions are unbounded.
Preallocate source labels, register recursive references, and emit templates
with dependent parameters for original receiver, returned provider, request
and path occurrences. Recursive references target registered nodes. Every
original source node creates a bounded number of templates; explicit imported
profile/contract descriptions are counted as inputs. No unknown result shape
is traversed to mint origins. Unknown dependent paths remain variables of
the original source obligation.

This establishes a finite **schema**, not a finite set of concrete receipts,
profile incidences or worlds, and not decidable satisfiability. Repeated
resumptions may create arbitrarily many distinct result/view occurrences.
Erasing those occurrence parameters would conflate original receivers with
fresh execution owners. Existing original predicates in K,D may require
unbounded semantic quantification even though their retained reference graph
is finite. No finite effective all-view solver is inferred.

An independently valid future client can have its own finite source graph.
That graph introduces origins only under its own original source rules;
the original beta template is transported, not regenerated by the client's
solved shape. Production-only providers/future developments remain permitted
at independent leaves with their original certificates, without source bodies.
The exact coverage of those permitted leaves is a separate Option A/2 gate.

### Why an empty-support/reflexivity repair does not work

An arbitrary whole carrier with printed `Comp(empty,Unit)` need not be the
actual returning Name/Unit computation above. It can diverge. It can also
contain internal requests consumed before its outward boundary, if its
independent original complete contract admits that decorated behavior.
Typed-boundary §4 supplies an explicit decorated control witness where a
raw resumption installs a receiver-owned handler inside a protected executing
view V. In that original witness, receiver r has actually received V; the
resumed suffix borrows r's live owner; the new handler HE belongs to r; and
the E event is observed at V's executing effect port before candidate search.
The protected V incidence, this Observe, the same-view Receive, and live r/HE
are the actual Path/Inc join. It is that join which makes protection relevant
although ordinary inner handling could hide the event from the outward row.

This is not a derived placement of that witness in this exact apply source.
To challenge the proposed upper F_u with it, one must independently admit
its complete carrier/current-world tuple at F_u and derive the source Call
observation and receipt mapping to that original upper occurrence. Without
those premises it is a conditional discriminator against the proposed
empty-support proof, not a source-derived protected event for this candidate.
In particular, delta initially sits at `argument.result.(u,p0)` of apply's
received factory carrier. A request while constructing/forcing that outer
factory is at `argument.effect` and receives no delta incidence from this
fragment. The separate later actual f invocation can execute its own
Value-entry argument under its complete call-output view, but the exact
body f x passes the returning Name x carrier. It does not contain the raw
resumption/handler witness above. The independent universal Function/carrier
domain and that exact source Call argument must not be identified.

Specializing the data answer to Unit does not remove that owner/continuation
structure. Thus the following proposed proof is invalid:

```text
this actual identity run emits nothing;
all printed rows are empty;
therefore any source-sorted Gamma extending delta is a valid complete row.
```

The first two premises do not cover the independently admitted universal
carrier/current-world domain. They do not prove that such an internally
handled/resumed carrier is admitted at the proposed original Function root,
either. The decorated counterexample establishes the need to retain the
original negative/routing/world obligations, not an accepted-source rejection
or a new Yulang semantic countermodel. One must decide admission from its
independent original rules before comparing behavior on that challenge.
Endpoint reflexivity cannot identify the upper/lower profile occurrences or
silently establish their complete domains.

## 8. Nonreturning, open and negative discriminators

Use the finite registered core graph

```text
loop = lambda(z,call(result(name loop),result(Unit)))
registered interface: Fun(Value(Unit),Comp(empty,A_f))
```

Its monomorphic source-kernel derivation copies the registered interface at
Name, passes Unit, and repeats the same complete call result interface.
Every finite unfolding is silent and leaves apply's entry suffix Pending
when that Call is supplied as apply's argument. This is a source-kernel
witness under the independently supplied registered-interface/recursive-rule
premises, not a new proof of unknown recursive source inference or a full
original profile solution. The original return/capture/read transitions do
not occur. No membership argument for the argument carrier requires an
inhabitant returned at A_f merely to admit its finite prefixes.

For a declared request at result endpoint A_f, keep its actual declaration
instance, response type and original raw continuation. Its initial request
leaves that same suffix Pending. An independently valid response/resumption
which returns a callable reaches rebind; a resumption which requests again
or diverges remains Pending. Repeated resumptions keep the original receipt
and receiver reference, even if execution uses a fresh owner. The original
current-state and owner-protocol checks are required at each extension.

The independently typed open context may contain a source-owned closure
`k=lambda y.call(H_f,result(name y))` and aliases of k. Source typing uses
H_f's hypothetical checked interface. Captures retain the one H_f reference;
plugging replaces every occurrence simultaneously. There is no requirement
that the resulting closed closure already belongs to the target checked
Function after substituting the actual tested provider. Externally imported
open dependencies need their independent import/world certificates; they
cannot be converted into source-owned open references by assertion.

The following negative observations distinguish genuine original coverage
from a merely successful selected trace:

| Mutation / shortcut | Failure that the original construction must retain |
| --- | --- |
| Remove delta because this run emits nothing | Original profile policy survives absence of observation; support is not source applicability |
| Add delta to the lower identity output with the same endpoint | No original lower introduction; violates selected no-backflow |
| Copy p0 onto argument.effect | The original result lift has no such edge; argument manufacture is a different observation position |
| Add a new nested-result mark after solving F_u | No source exposure/seed-origin proof for that new beta incidence |
| Rebind f or create the step capture for a diverging/suspended carrier | No original Return/rebind/Lambda transition to justify it |
| Require the argument or source hole to return before admission | Loses admitted divergent/suspended carriers and independently valid open contexts |
| Treat fresh resumption owner as beta's receiver | Can revive an expired receiver's incidence; owner activity is not receiver identity |
| Join separate response/provider/world witnesses per port | Destroys original operation-instance/capture/continuation correlations in the one xi |
| Check actual H_f target membership while constructing the context | Uses the comparison/preservation being tested to create its domain |
| Require a source body for every independent provider | Excludes permitted Option A/2 production-only members |

These are rule-grounded proof discriminators. No numerical enumeration or
compiler/runtime experiment was run. In particular, none claims current
production acceptance or an independently completed original profile.
