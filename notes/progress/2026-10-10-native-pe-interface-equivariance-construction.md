## 2. Exact action boundary and identity observers

Let P be one finite selected public presentation together with a finite
submitted proof grammar. H is a proposed bijection on its *presentation
names*, preserving sorts, ordered fields, graph incidences, binder order and
dependency edges. A name may change only when it denotes the same supplied
bound coordinate or internal graph node. H is not endpoint specialization
`a := A`, a different source binder, or a different runtime provider.

Possible movable spellings are a local descriptor-root label, an internal
graph-node reference, or the variable spelling of a template/proof coordinate
at the **same original** binder. Whether an actual native root/coordinate
supports that action is part of the missing premise, not an authorization
to relabel an identity-sensitive numeric ID. This construction supplies no
action on bare numbers read by an authentic primitive.

Fix the following identities and all their identity-sensitive dependencies:

| Observer / operational identity | Fixed coordinates |
| --- | --- |
| Source introduction, final-root selection, binder-level/scope/provenance tests | Actual binding and Parameter origins, actual binder nodes/levels/order, publication origin, selected final-root incidence, proof-region origin and source rule choice |
| Installed binding, provider and capture projection | Raw closure/value/carrier/provider identities, formal and captured slot registration, actual `q`/`b`, outer environment, each fixed import and its full free dependency closure |
| Primitive/proof registration and dispatch | Registry IDs, kernel IDs, rule and alternative tags, independent primitive interpretation, declared telescope/signature, recursive equation identity |
| Occurrence, receipt, receiver, ownership and continuation lookup | Actual invocation/event identities, current own occurrence, receipt and receiver lineage, response/resumption parent, actual continuation, original typed path and port roles |
| Authority and history compatibility | Original `nu,K,D`, IF0 declarations, live grants/permissions and lifetime anchors; the same actual history/world inputs |
| Frame/alias sharing and client joins | Actual new-event identity, alias antecedent, Shared/OneShot base binder, original ViewLogic region, actual EventField key and EventProof origin |
| Root lookup, rejection of a wrong root, equality/sharing and graph references | Preserve equality and inequality of local references by the whole bijection; fix any identity-sensitive external root/import and source-root anchor |
| Fixed import read and hereditary use | The same installed monomorphic `J_z`, its value/provider, contract/evidence and free fixed fields, even if its printed type equals another import's |

For source Generalize §5.2 keys, H changes only representations of references
to these incidences. The actual event key
`(origin, actual parent event path, event occurrence)` is fixed. In
`(i,q,description-region)` and `(i,event-key,q,proof-region)`, i denotes the
same actual incoming frame, q the same declaration/proof origin. An alias
still routes to that frame. H may consistently re-encode a local reference
to the key; it cannot create a different key or a new witness region.

This enumerates the observers explicitly exposed by the assigned constructor
text. It does **not** certify exhaustive observer coverage for an arbitrary
authentic `Local_f`, independent ground/hereditary operation, recursive
equation rule or production consumer. Any additional observer invalidates
the proposed H-domain until its read identity is fixed or its covariance is
independently proved. In particular registry identity staying fixed does not
prove that its interpretation ignores a local root spelling.

## 3. Derivation for the explicit finite assembly

The following subcase uses the actual §3 public fields and §4.1 assembly,
after the source owning-record inversion and original fixed/eligible result
are available. It does not prove the equivariance of recomputing that
source result from an unclassified compiler graph.

Interpret H on syntax by renaming references and bound spellings throughout
the **whole** tuple; keep tags, fixed anchors and original binder identities.
For an assignment rho, define `(H rho)(H x) = H(rho(x))`. For syntax whose
leaves are raw fixed identities, this last H is identity. For a scoped
strategy s, the candidate transport is conjugation
`s^H(H args) = H(s(args))`, under the same original telescope. Typedness and
domain closure of that transport are semantic premises in §4.

### 3.1 Record and reference operations

An ordered constructor `K(t1,...,tn)` satisfies the syntactic equation
`H K(t1,...,tn) = K(H t1,...,H tn)` by the defined action. Ordered positions
and tags cannot change. A selected projection commutes because it chooses
the same field position. Equality/sharing of references is preserved and
reflected because H is injective; different source/public roots cannot
become equal. A finite record lookup commutes when both its table references
and submitted key are transported. These are statements about the displayed
record operations; they do not prove semantic membership of their fields.

### 3.2 Extraction and CE raw aliases

Step 1 of Extract retains the same selected final-root incidence. Step 2
uses the original classification supplied to this subcase. Step 3 selects
the same authentic owning positions and four certificate-family tags;
step 5 installs the same original typed slot map. Step 6 discards the same
body graph and source-root accessors. Consequently all these field assemblies
commute with H, rather than matching new origins by printed type or shape.

For step 4 write alpha for the **total** forced raw-alias substitution. For
id it identifies the designated read/body/outward raw value/provider with
the formal entry projection. For pick it identifies those fields with the
fixed `J_z` projection; it never equates z to the ignored argument. H preserves
the defining graph, so define `alpha^H(H z) = H(alpha(z))`. Capture-free
structural induction on a term/predicate gives

```text
H(t[alpha]) = (H t)[alpha^H].
```

The binder step retains its original identity/order and renames all bound
references together, so no formerly free coordinate becomes bound. Applied
to the finite retained constraints, proof fields and syntactic W, this proves
commutation with substitution. It asserts no law for an opaque predicate's
semantic interpretation.

CE's F removes precisely these aliases; G restores precisely their displayed
values. Their syntactic commutation equations are `H F = F^H H` and
`H G = G^H H`. Their totality gives reflection for raw-alias **equations**:
given a retained tuple, reconstructed aliases satisfy the equations; any
tuple satisfying those equations reconstructs those same raw values.
No proof certificate is normalized. `Identity(A)` and
`Compose(Identity(A),Identity(A))` keep different tags and all intermediate
witnesses. W is transported as syntax and incidence, not assumed invariant
as an untransported predicate on an old local name.

### 3.3 Decode and frame routing

Pair the decoded roots by a chosen fresh presentation-name extension of H:
the two roots remain newly allocated ordinary roots, with corresponding
references in the complete inlet/IF/Delta/certificate tuple. This proves
equality up to names of the displayed §4.2 root equations, provided their
template image and whole frame inputs correspond. It does not compare an
independently rerun numerical allocator's counter or cache state.

The same alias antecedent yields the same paired decoded root. Different
actual new frames retain distinct roots and ViewLogic slots. Base Shared,
actual EventField and per-frame EventProof references retain exactly the
§5.2 sharing partition, since routing depends on preserved incidences.
Joins and Bind reference the same ordered world/response/suffix fields;
this is structural sharing, not permission to combine marginal strategies.

### 3.4 Finite consumer structure

Transport both submitted roots, the retrieved records and the entire proof
term. Wrong-root rejection, tag dispatch, premise edges, scope matching,
ordered telescope operands and equality/substitution certificates have the
same outcome in each direction. Value, Computation and Function remain
distinct cases; an Any/union target does not acquire Function equations.
Identity and Compose are not interchanged. A registered Ref points to the
same equation identity with transported local operands.

Thus the syntactic bottom-up consumer skeleton commutes. Acceptance that
also invokes a semantic/primitive validator is outside this unconditional
subcase. A typed registry entry may contain such a validator; its ID and
declared signature alone do not discharge that part.

## 4. Per-constructor semantic obligations

For each active relation R require, at its full original telescope,
`R(x) iff R^H(H x)`. For each constructor-image operation k require equality
of its entire output relation, `k^H(H x) = H[k(x)]`, including evidence and
auxiliaries. The inverse direction must hold for H inverse. Sort preservation
alone is insufficient; dependent domains and admitted histories must also
be bijectively transported. These are the exact hypotheses under which the
structural proof extends:

The explicit raw record equalities commute because they retain the same raw
values/providers/actual events, or use ordered field projection. They do not
by themselves type the transported evidence or prove the guards. In
particular `Install`/`ExitOwn_IF` equations are not treated as proofs of
arbitrary State/world compatibility. A preserved scope diagram also does not
prove that an independently supplied future-domain interpretation commutes.

The consumer's L cases are exhausted syntactically by Identity, Compose,
record width/depth, union injection/case, intersection intro/elim, Top/Any,
same-value/computation, complete Function, registered equation/congruence/
guarantee, method/adapter/annotation and additional authentic local primitive.
The first six constructors' reference/tag manipulations are structural.
Their membership/guard/evidence leaves still need the first row's laws.
Compose additionally needs the same transported intermediate interface;
Function additionally needs complete domain/production transport. Real
conversions retain their executed boundary/result handle and require their
own local law if included; no proof-only Direct rule replaces execution.

The native phase pairing includes Start/Receipt, Force/pending/divergence,
EntryValue/body prefix, BodyReturn, InvocationReturn, Restrict/Develop and
Future at its original response/current-event telescope. These are all
retained; no argument-use stage is skipped for pick. The assigned sources
reference independent ordinary phase meanings, rather than supplying their
nominal-action equations in the selected sections. That reference is a
specific missing dependency, not evidence that the phase law is false.

## 5. Conditional preservation/reflection theorem and exact blocker

**Conditional bounded theorem.** Assume H and H inverse are actions on all
active typed domains as in §2; the source owning/classification inputs
correspond; fresh decoded root names are paired; and every active leaf in
§4 has its two-way law and exhaustive identity-read coverage. Then Extract's
finite assembly, Decode, CE expansion/reconstruction and recognition by the
defined finite native Direct consumer preserve and reflect their complete
retained tuples, including the original scoped strategies and transported W,
for PE-ID and the selected finite PE-PICK import family.

**Derivation.** First apply §3 to retained records and aliases. Induct on the
finite certificate/proof term: an Elementary leaf uses its explicit record
equalities and its §4 laws; Check uses its already transported premise and
the local Apply_L law on the same full intermediate tuple; Local uses its
own supplied law. Reference graphs are transported node-for-node; the
registered equation interpretation is a separate hypothesis. Conjunction
uses one common transported tuple; union keeps the selected tag. At a
binder, transport its domain bijectively and conjugate its strategy, with
the original binder order and dependencies. This establishes both directions
by applying the same argument with H inverse. Finite developments use those
same cases, without replaying a completed prefix or inventing later fields.

At Direct Value/Computation, the corresponding membership implication and
its finite proof transport by those cases. At Direct Function both the domain
and complete-observation proof transport, at the actual submitted roots.
Unchanged initial inlet does not assert equality of differently annotated
future demands; the §6.3 declared-hole proof composition keeps its same
intermediate and local law. Consumer rejection also reflects: transported
acceptance could otherwise be transported back to acceptance of the original.
This includes tag/signature rejection and primitive-leaf rejection only when
that leaf's two-way acceptance law is supplied.

For pick, H fixes the entire installed J_z and its complete dependency
closure. `PublicValue(J_z)` and Fixed therefore retain the same operand, and
the alias proof substitutes z throughout. Literal, previously public
projection, and finite immutable record/tuple imports add no new renamable
capture identity. Their subsequent restriction/checking evidence remains
subject to the same explicit laws; no hidden source-summary theorem or
generic foreign covariance is inferred. QED under the named hypotheses.

The first exact blocker has two levels:

1. The governing §5.1 demands an independently supplied action on **typed
   evidence/observations/admissions/constructor carriers**. The assigned
   native definitions describe their content but do not define H on each
   actual interface or list every identity read of authentic local leaves.
   A proposed graph renaming is consequently not yet an admissible semantic
   action for the whole native object.
2. Even granting such an action, Decode attaches
   `inlet(u_i)=I_q[A_i;Delta_i]`. The first row of §4 requires two-way transport
   of its independent complete Car/input/image relation at the same q and
   original telescope. CE says its whole proof is retained; it does not say
   that changing a presentation coordinate transports that proof's typing,
   or all admission/production alternatives. No covariance law for this
   relation appears in the assigned governing sections. The corresponding
   V/W/T/Car and hereditary action laws remain prerequisites for the later
   elementary certificate rows as well.

Taking H to be identity gives a tautological special case and does not
discharge nontrivial interface equivalence. Defining admissible H by assuming
all §4 conclusions would also leave the requested premise untouched. This
note therefore does not claim a direct semantic IFACE_EQUIV subgate closed.
