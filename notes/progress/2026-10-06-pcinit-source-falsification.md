## 3. Smallest unresolved certificate cut

The ordinary binder/use attempt reduces to one Name leaf:

```text
Gamma(H) = Value(F)
------------------- Name
Gamma |- H : Value(F)
```

This is a concrete instance of the inspected rule schema, not a claimed
accepted surface program or a complete challenge. Its inversion yields the
declared lexical interface. It yields no environment rule for treating `H` as
a hole whose tested filling is absent.

Under the *candidate ordinary-environment assumption* that a realization of
`Gamma` certifies each bound provider, a realized `H` additionally has a
filling `v` and its certification at `F`. An extraction has two branches:
retain that certification, violating the intended filling-independent hole
premise; or delete it, leaving the ordinary environment's premise unproved.
Changing the remaining Name leaf into a declared-hole leaf needs exactly the
missing rule. That assumption is not an adopted Yulang environment judgment.
Thus this is a premise discriminator, **not a counterexample to production
admission**.

The reduction removes the surrounding Call, argument, result, annotation and
recursion because none is needed to expose this environment-premise cut.
One resolved Name occurrence and one declared interface are minimal for this
particular Name-inversion obstruction. This is local certificate minimization;
no global source-grammar minimization or finite source search was performed.
Adding a Unit argument and a Call would return to the already documented quiet
reference instance without resolving the cut, so that probe was not repeated.

## 5. Independence, coverage and failure conditions

No external oracle, executable checker, seeded search, numeric enumeration or
mutation campaign was used. The Name leaf shares the typed-core rule with the
audit; it only exposes that rule's premise inventory. The reference admission
framework shares its source decorations, joint witnesses and provider rules
with reference generation; it cannot independently supply production
semantics. A checker populated with a hole rule or Initial transition would
assume the very rule at issue.

Coverage is limited to the named sections and the four attempted transfer
families. The annotation and recursive attempts were blocked premise audits,
not accepted-source experiments. No equal-complete-evidence source pair with
different admitted challenge domains was established. No information-loss,
carrier-insufficiency, principality, production rejection or source-acceptance
claim follows.

A future falsifier must retain all candidate hypotheses: independently typed
other providers, original hole/slot/profile and whole carrier, exact Call
translation, joint original scopes, separability, and an independently
interpreted Initial rule. A filling hidden through another environment
provider, use of its private body proof, a Q-derived authority/path, changed
recursive incidence, or replayed receipt invalidates the proposed witness's
premises rather than refuting this conditional candidate. Source-witness-free
Option 2 observations and their provider histories require separate coverage.

Recommended next action: supply one independently interpreted declared-hole
environment/Initial rule at the original Function incidence. Then give the
falsification lane its concrete judgment and rejection conditions so it can
test deletion, annotation and recursive environment cases without guessing a
language meaning.
