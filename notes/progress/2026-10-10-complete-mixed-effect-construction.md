## 1. Result and boundaries

**Theorem.** For finite unguarded recursive mixed-weight grammars with two
fixed, distinct attachment IDs and explicit shared recursive child bindings,
it is undecidable whether some finite derivation has empty directed support.
The theorem uses only finite constants, binary replay, swap and
both-from-right. All filters are All and all active PUSHes have one fixed
family. No production has an enabling guard; no count, depth or integer-width
cap is imposed. The final observation is identity/absence of left and right
entries at one actual replay node. It is not an arbitrary cross-ID arithmetic
comparison added to the language.

The reduction is from the binary Post correspondence problem (PCP). First it
constructs synchronized word codes as pure left debt at one ID and pure right
debt at the other. Actual global swap/both/replay operations implement
coordinate-selective affine scaling of these codes. A separate common-PUSH
generator then converts code equality to empty directed support, using actual
same-ID cancellations at both IDs. This last step removes the possible
objection that the theorem only concerns a stronger Presburger query interface.

Consequently a proposed decision algorithm for **every** grammar in that
two-ID, shared-child class and the stated support observation cannot terminate
exactly on all inputs. A finite graph or production descriptor, finite ID set,
and finitely specified final consumer do not establish such decidability.

This theorem does not establish undecidability for one-ID grammars, for
grammars having only independent recursive children, or for active/filter
observations that cannot inspect pending support. It does not establish that
the particular PCP grammars are generated by an authentic source program or
the selected Simple-sub compiler. It therefore does not close the actual
source/production mixed Effect gate or authorize changing source behavior.
An actual source impossibility argument would require a constructor/owner
bridge realizing the grammar's synchronized two-ID choices and shared copies,
and a relevant consumer whose required query includes this support question.

## 2. Exact grammar semantics and multi-ID algebra

Let the two distinct fixed IDs be a and b. A weight carries a triple
`(p_i,n_i,r_i)` of natural counts for each i: left `POP_i^p_i PUSH_i^n_i`
and right `POP_i^r_i`. Zero entries are absent. Families and filters are fixed
as above. Counts use the natural-number lift of the pinned operations, not
Oracle u32 saturation.

Left composition at each ID is

```
p_i' = p_i^1 + max(p_i^2-n_i^1,0)
n_i' = n_i^2 + max(n_i^1-p_i^2,0).
```

Replay composes left words, adds same-ID right debts, and performs directed
mix. The pinned multi-ID mix has a global empty-side shortcut and then loops
over right entries. If either the entire left or entire right is empty, mix
returns the raw value. Otherwise, for each ID with positive right debt r,
it appends its POPs to that ID's left pair; a surviving active pair stays
left, a pure residual debt goes right, and exact cancellation erases that
ID. IDs without right entries retain their left entries unchanged. This is
the actual loop in `crates/infer/src/constraints/directed_weight.rs:12–39`.

In the all-debt subalgebra (`n_i=0`), put
`P_i=p_i^1+p_i^2` and `R_i=r_i^1+r_i^2`. Replay has the particularly useful
exact per-ID description

```
if R_i=0:  (P_i,0,0)
if R_i>0:  (0,0,P_i+R_i).
```

This formula also covers the global shortcut: when left is globally empty,
every P_i is zero and the second case retains exactly R_i; when right is
globally empty, only the first case occurs. Thus no global cross-ID behavior
is being replaced by a false local mix assumption in this construction.

For every ID, simultaneously,

```
swap(p_i,n_i,r_i) = (r_i,0,p_i)
both(p_i,n_i,r_i) = (r_i,0,r_i).
```

The pinned owning methods are `constraints/mod.rs:3566–3612`, including
`swapped`, `both_from_right`, and `compose_for_replay`. In particular, both
is a raw result with both copies present. It is not eagerly mixed before
the replay node written below. Swap/both apply globally to all IDs; the
projection proof does not assume a selective-ID primitive.

A grammar has finitely many nonterminals and finite productions made from
these operations and constants. The denotation contains the exact values
of **all finite permitted derivations**. An explicit production

```
T -> let t=child(T) in C(t)
```

chooses one finite child derivation and reuses that chosen value at every
occurrence of t in the finite expression C. Repeated `ref(T)` occurrences
without such a binding choose independently. The grammar may use both kinds
of reference; the distinction is part of its input semantics. Observations
do not prune its productions or condition its recursive derivations.

## 3. Actual coordinate-selective affine maps

Write `I` for the all-zero weight. Encode two natural numbers by

```
E(x,y):  at a, L_x=(x,0,0); at b, R_y=(0,0,y).
```

These are different IDs and are never identified or renamed. Define actual
finite expressions, with their displayed brackets,

```
A(t) = swap(replay(I,both(swap(t))))
B(t) = replay(I,both(t)).
```

**Projection lemma.** For all x,y>=0,

```
A(E(x,y)) = E(2x,0)
B(E(x,y)) = E(0,2y).
```

Proof for B: the right side of E contains only b's y POPs. Both deletes the
left a entry and creates `(y,0,y)` at b. Replay with I mixes those two
same-ID POP debts to R_(2y) at b, with no a entry. For y=0, both produces I
and the same equation holds. For A: swap E has L_y at b and R_x at a. Both
therefore deletes the b entry and makes `(x,0,x)` at a. Replay with I gives
R_(2x) at a; the last swap gives L_(2x) at a. Again zero works exactly.
These calculations use the actual global operations, not abstract coordinate
projections. In particular each projection's mixed intermediate has only one
nonempty ID, so the global shortcut causes no discrepancy. QED.

For positive **odd** constants m,n and nonnegative c,d, construct F from one
shared input t by replaying, in a fixed left-associated expression,

1. one occurrence of t;
2. `(m-1)/2` occurrences of A(t);
3. `(n-1)/2` occurrences of B(t);
4. the finite constant E(c,d).

Then

```
F_(m,n,c,d)(E(x,y)) = E(mx+c,ny+d).
```

Each component in this particular expression has only L debt at a and only
R debt at b. Replay therefore simply adds a's left debts and b's right
debts at every written node. A's projection contributes 2x at a and nothing
at b; B's contributes 2y at b and nothing at a. Starting with the original
t supplies the coefficient one at both IDs. The constants supply c,d.
This proves the equation without reassociating arbitrary mixed replay.

Odd scalars suffice below. No division operation is added to the weight
algebra: the divisions by two above calculate finite *syntactic occurrence
counts* from fixed odd input constants while constructing the grammar. A
tile with a long word can produce a large finite expression; effective
computability of the reduction is enough, and no polynomial size claim is
needed. All occurrences of t and its projected expressions receive the same
selected child derivation. Independently sampling those occurrences would
invalidate the affine equation and the reduction.

## 4. Synchronized ternary coding of PCP

The external undecidable problem is binary PCP. An instance is a finite list
of pairs `(u_j,v_j)` of binary words. A solution is a **nonempty** index
sequence whose corresponding concatenated first and second words are equal.

Map letters a,b to ternary digits 1,2. For a word w of length l define

```
d(w) = the ternary value of its l digits, with d(empty)=0
code(w) = 3^l + d(w).
```

This is the natural number whose ternary representation is leading digit 1
followed by the digits of w. Because the leading digit is nonzero, unique
ordinary positional representation proves that code is injective, including
the empty word. For all words z,w,

```
code(zw) = 3^|w| code(z) + d(w).
```

The identity follows by writing the ternary concatenation; it also follows
from `d(zw)=3^|w| d(z)+d(w)`. Each multiplier 3^l is positive and odd.
For tile j, use section 3's exact operation expression with

```
m_j=3^|u_j|, n_j=3^|v_j|, c_j=d(u_j), d_j=d(v_j),
F_j=F_(m_j,n_j,c_j,d_j).
```

Construct nonterminals T,S with productions

```
T -> E(1,1)
T -> let t=child(T) in F_j(t)       for each tile j
S -> let t=child(T) in F_j(t)       for each tile j.
```

The T base represents `(code(empty),code(empty))`. Section 3 and the coding
identity prove by induction on a chain of recursive choices that T has
exactly the values

```
E(code(u_(j1)...u_(jk)), code(v_(j1)...v_(jk)))   for k>=0.
```

Conversely each such finite index sequence supplies the corresponding finite
derivation. Shared occurrences in a production duplicate that one child's
already selected sequence; they do not introduce additional tile choices.
S applies at least one tile after a T choice, so its exact values are the
same expression with k>=1. This separates the empty index sequence without
any enabling or observation guard. Empty tile words, if admitted in the PCP
definition, also work: multiplier one means zero additional projected copies,
and digit constant zero is allowed. The usual nonempty-word PCP restriction
is therefore also covered.

Already, deciding the cross-ID count equation `p_a=r_b` at S would decide
PCP. That is a genuine limit for arbitrary Presburger observations, but the
next section realizes it with actual replay and support alone.

## 5. Same-ID cancellation realizes equality as actual empty support

Give a second independent nonterminal J the productions

```
J -> I
J -> replay(child(J),U),
U: at a, P_1=(0,1,0); at b, P_1=(0,1,0).
```

All PUSHes use one fixed family S and All filters. There are no right debts
inside this generator, so replay is ordinary left composition and induction
gives exactly

```
Values(J)={V(k): at a, P_k; at b, P_k | k>=0}.
```

One selected derivation of J determines the **same k at both IDs**. It is
not represented as the Cartesian product of separate per-ID possibilities.
J's selected derivation is independent of the selected S derivation.

At the finite, correctly bracketed final node compute

```
O(k,x,y)=replay(V(k),E(x,y)).
```

At a there is no right entry. Left composition of P_k with L_x gives

```
at a: (max(x-k,0),max(k-x,0),0).
```

No later mix loop handles a, since that loop visits right IDs only. Thus
a has empty support precisely when k=x.

At b, left composition supplies P_k and right addition supplies R_y. If
k,y are both positive, mix either retains P_(k-y) when k>y, erases the ID
when k=y, or retains R_(y-k) when k<y. If k=0 or y=0, the raw single-sided
shortcut gives exactly the same empty-support criterion, k=y. A left entry
at a cannot change it: the actual b loop is per-ID; a remains untouched.
Therefore

```
O(k,x,y) has empty directed support  iff  k=x and k=y.
```

This is exact for all natural x,y,k. It tests no arithmetic equation as a
grammar operation. It performs actual same-ID cancellations separately at
a and b, then observes zero support of the resulting actual weight. The
IDs remain distinct and authentic labels throughout.

Add a root nonterminal

```
Q -> replay(ref(J),ref(S)).
```

These two references are independent selections. A Q derivation with empty
support exists iff S produces some E(x,y) with x=y, since J supplies exactly
all common k and can choose k=x. Injectivity of code and the nonempty S
construction show that this is equivalent to a solution of the given PCP
instance. Conversely every PCP solution supplies its S derivation and the
J derivation of k=its code, giving a zero-support Q witness.

The grammar construction is finite and effective. An exact terminating
decision procedure for existential empty support on all such grammars would
therefore decide PCP, a contradiction. Its complement, universal absence
of empty-support derivations, is also undecidable: deciding that predicate
and negating its answer would solve the existential problem. Both claims
are about unguarded finite derivations; no check conditions recursion.

Existential positive queries remain semidecidable by enumerating finite
derivation trees with their shared bindings and evaluating the exact finite
operations. That witness procedure need not halt on a negative instance
and is not a decision algorithm.

## 7. Compatibility with established results and exact remaining work

The earlier recursive left-only decision theorem permits independent recursive
children, with sharing only in a fixed finite continuation. The PCP grammar
has repeated selected recursive children **inside a production** and also
uses recursive swap/both side projections. It therefore lies outside that
theorem's supplying grammar. This note does not challenge its PVASS reduction.

The earlier debt theorem decides fixed finite mixed continuations of debt-only
recursive inputs by a query-specific finite PUSH budget. The PCP's S is indeed
debt-only, but its observer is supplied by independent J with **unbounded
recursively generated PUSH mass**. There is no fixed finite PUSH budget for
that input. Before adding J, the equality observation `p_a=r_b` also is not
one of that theorem's bounded-budget pending-sign observations. Thus neither
version contradicts the existing debt result.

This construction does not add the zero-test guards of the earlier counter-
machine barrier. T's every tile production remains enabled for every child;
all F_j values are legitimate finite unguarded evaluations. J supplies every
common k without inspecting the selected code, and Q likewise replays every
J/S pair. Failure to reach identity is simply a non-witness observation.

The exact unresolved boundaries are:

- **One ID:** independent two-coordinate projection used distinct IDs with
  opposite debt orientation. This proof does not merge those IDs, and the
  one-ID full grammar remains unsettled here.
- **Independent children only:** the affine maps crucially reuse a selected
  child and its projections. Removing recursive sharing destroys the proof.
- **Only active/filter observations:** a nonidentity result may have only
  pending debt. For example k=1,x=2,y=3 has zero active count but nonempty
  support. This theorem does not replace empty-support observation by activity.
- **Authentic source generation:** the exact method equations are pinned,
  but there is no source program/certificate showing its owner graph generates
  the entire PCP scheme, repeated shared recursive choices, or the synchronized
  J ray. Finite source graph representability is a separate premise.
- **Required production query:** source contributions, subtraction, filter
  legality, compact support and all Effect consumers require their actual
  placement and correlations. An impossibility claim for the selected compiler
  would need a bridge from one of those required decisions to this existential
  root support query. This bridge is not supplied here.

These are theorem scope facts and source obligations, not proposed restrictions
on supported source inputs. Production Simple-sub constraints, legacy withdrawal,
Call meaning, effect hygiene, soundness and principality remain unchanged.
