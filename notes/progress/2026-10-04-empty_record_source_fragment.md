# Empty-Record source fragment: conditional structural witness theorem

Date: 2026-10-04
Status: proof result and source-fragment corollary; progress evidence only
Scope: existence/regular-witness theorem for a closed monomorphic pure
lambda/integer fragment. This is not a complete Yulang source-generation
theorem, a principal residual theorem, or implementation authority.

## Source-checkable premise

Use the syntax

```text
e ::= x | integer | λx.e | e e
```

with closed terms and an empty outer endpoint environment, monomorphic generation, no annotation, record or projection
forms, effect/callback forms, imports, or external endpoint environment. The
generator is the pure candidate judgment in
[`2026-09-30-intrusion-pure-source-typing-rules.md`](2026-09-30-intrusion-pure-source-typing-rules.md): integers emit `Int`, lambdas emit `Fun(α,r)`, and applications emit one inequality `t₁ <: Fun(t₂,β)` in addition to recursively generated constraints.

The source-checkable property is: **the generated fixed descriptor input has
empty nonempty-Record alphabet (`Λ = ∅`)**. This is not “a regular solution
exists”; it is checked from source syntax and the generator's constructors.

## Conditional main theorem

For every finite unguarded pure structural package generated by this fragment,
if it has a solution in the contractive regular type-graph domain of §7.4, it
has a contractive regular witness of size at most `N + 1`, where `N` is the
number of nodes in the fixed rational descriptor quotient. This is the
§7.4.1 input class: no nonempty Record descriptor, mandatory Records,
Functions, identity atoms, and finite fixed-arity constructors of declared
variance. Effects, rigid permissions, guards, casts/adapters, and `Phi/K,D`
predicates are not included. `Λ = ∅` is the smallest premise of this existing
proof route, not a claim that it is the weakest sufficient condition.

### Proof

Erase every Record label in a satisfying assignment by regular type graphs,
as required by §7.4. Since the
input alphabet is empty, every Record becomes `{}`; the map preserves all
successful structural comparisons and their retained child obligations. In
the resulting grammar, each successful directed comparison is exactly
constructor bisimulation: matching heads are required, and all declared
variance children are related in both directions. Temporarily make each
original inequality's roots equal and form the finite rational constructor
quotient. A clash would contradict the erased satisfying assignment. Assign
every remaining descriptor-free class the same available primitive atom
(`Int`). This finite graph satisfies each original inequality directly, so
the original directed bounds have a regular witness. Its size is at most
`N + 1`. The temporary equalities are an existence decision aid only; they
neither replace the original bounds nor describe the solution fiber.

This is the §7.4.1 argument in
[`2026-10-03-open-residual-factorization.md`](../design/2026-10-03-open-residual-factorization.md), specialized to source-generated Function/Int constraints.

## Separate source-generation theorem

For a closed term in the syntax above, the candidate generation judgment
produces only `Int`, fresh endpoint variables, Function descriptors, and
inequalities. By induction on the generation derivation: a bound-name rule
returns the endpoint variable installed by its enclosing lambda; the integer
rule introduces only `Int`; the lambda rule adds one Function descriptor to
the induction result; and the application rule adds a fresh variable and an
inequality whose only constructor is Function. Therefore its fixed descriptor
input has `Λ = ∅`. The property remains true after fresh-variable renaming,
flattening, and rational equality quotienting.

An empty outer endpoint environment is necessary: the candidate name rule
preserves its endpoint `Ξ(x)`, which may itself contain a nonempty Record.
Bound names are supplied by lambda parameters and carry only fresh endpoint
variables. Identity `λx.x` is included: it generates an open descriptor
`Fun(α,α)`, so this fragment is not limited to root-only/free-variable-free
descriptor graphs.

The candidate source rules quantify over a general preorder `D`, whereas the
conditional theorem uses §7.4's structural type-graph carrier and head/variance
rules. Thus the generation theorem proves the syntactic `Λ = ∅` fact; it does
not by itself prove that the candidate declarative typing semantics is
interpreted by that structural carrier. That carrier specialization is part
of the conditional theorem's explicit premise.

This proves source generation only for the named candidate pure judgment. It
does **not** prove that complete Yulang source generation satisfies `Λ = ∅`:
the authoritative core/callback contracts do not yet give complete
Function-endpoint generation, and annotations, callbacks, imports, effects,
records, and guards are outside this syntax. The smallest remaining source
obligation for extending the corollary is a label-conservation theorem for a
larger, explicitly specified generator; no claim about full Yulang follows.

There is also a direct boundary counterexample to extending the premise by
source spelling alone. A callback literal may be written without a Record
expression while its expected callback boundary is
`Fun({f:Int},{f:Int})`. Under authoritative callback B, that expected boundary
arrives before body generation and contributes its nonempty Record descriptors
to the package, so `Λ={f}`. Thus the source restriction must include the
expected-interface environment, not merely forbid Record syntax in the body.

## Gate outcome

The conditional regular-witness theorem closes for this syntactic fragment.
It does not close general structural regularity, decidability with arbitrary
Record descriptors, the full source-to-endpoint bridge, principal solutions,
or the overall inference-replacement objective. The proof reuses §7.4.1 and
adds no solver carrier or semantic rule.
