## Principal map construction and its remaining quantifiers

For a supplied source presentation `P` and independently valid public view
`V`, construct

```text
Use(P,V) = fresh whole P + finite V + optional uniform graft
           + one direct query at P's designated exported root.
```

Keep all original residuals and scope positions. Its representation size is
`|P| + |V| + linking entries + O(1)`, without unfolding recursive back edges.
This is a representation bound, not a solving or termination theorem.

The public projection is `C_V(v) and Ext_P(v)`, so exact preservation is
equivalent to

```text
for every v: C_V(v) implies Ext_P(v).
```

This condition must hold for **every independently valid finite V**. The
finite use graph exists before the condition is proved; it becomes a
solution-preserving map only when the condition holds. Logical local
witnesses remain in the original scope tree and need not be selected by a
ground substitution or source existential type.

Common-allowance totality remains

```text
for every xi and s in S_xi: exists a. Q_xi(s,a).
```

One legal descriptor target must have the source-defined complete views at
its existing occurrence paths, retain required challenges and satisfy all
direct invocation queries. If that descriptor replaces the exported root,
the same extension must additionally satisfy the direct root-to-`V` query.
The theorem does not bypass a public common descriptor through a hidden
source root. Its retained-exported-root corollary applies only if that root
condition is actually established for the presentation being exported.
