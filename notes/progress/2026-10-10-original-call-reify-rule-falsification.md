## 3. Minimal conditional obstruction: old license observes absence

Fix all target source indices, a scope `Delta`, the complete literal code
`q_a`, its exact complete Return image `J_a`, original references and one
joint `xi`. Let the actual nominal Call argument key be

```text
k_a = (S,c,argument-Reify,Delta).
```

Keep two distinct nominal keys `k_old != k_a`. Initially the registry is the
finite partial map `P={k_old -> e_old}`. Give `e_old` a complete otherwise
unchanged contract whose independently supplied licensing guard is

```text
L_old(P,k_a) iff lookup(P,k_a)=Absent(k_a,P).
```

The named source key `k_a` is an existing scope-valid source coordinate; its
registration is absent. The license's ordered free telescope explicitly
contains `P,k_a`. This model does not infer that dependency from spelling or
endpoint shape. All unrelated contract fields can be fixed, including one
provider/world/history and one proof choice; the old licensing fiber is
singleton when the guard holds and empty otherwise.

Grant the candidate every local success premise under examination:

1. The exhaustive search certifies `Absent(k_a,P)`.
2. The new entry `e_a` retains all exact code/Call/argument/scope/xi/reference
   indices and attaches the same `J_a` through an independently interpreted
   Delay law. No body, receiver, inlet or provider acceptance is used.
3. Allocate once, obtaining `P'=P + {k_a -> e_a}`. No old entry is overwritten;
   old positive lookup at `k_old` returns the identical complete `e_old`.
4. Both modules have lawful identity/composition actions. Under coherent
   bijective nominal renaming, transport `P,k_a` together. The guard is
   equivariant because lookup absence is equivariant. Identity actions on
   all other coordinates suffice for this finite example.

Then

```text
L_old(P,k_a) = true
L_old(P',k_a) = false.
```

The former old license witness has no target fiber at `P'`. Certified
freshness and an exact Delay law therefore do not imply conservation of
old active licenses over an unrestricted imported-contract envelope.
Lawful renaming/substitution actions do not prove a law for registry
extension: extension changes the finite domain and is not bijective renaming.

This is a **conditional counterexample**, not an assertion that an authentic
original Yulang license has this guard. WholeContract admits independent guard
and license interfaces but does not itself provide their extension law. The
inspected native results explicitly avoid universal active-registry claims.
The precise extra premise that excludes the example is an actual supplier law
making old active guards/licenses stable under the selected extension, or an
already established consumer interpretation using the preserved old domain.
Selecting such an interpretation would require its own original applicability
argument; this note does not reinterpret an existing consumer.

Minimality is relative to losing an **old entry's** license through one new
registration: one old entry and one new entry are necessary, one guard bit
suffices, and one scope/world/proof fiber suffices. With no old entry there is
no old license to lose. With no new entry this example does not change `P`.
The established root-count example is not rerun; this variant identifies the
specific license transport that could fail even with exact entry retention.

## 4. Conditional positive result and failure boundaries

For the local registry operation, the proposed discipline is sufficient under
these **explicit hypotheses**:

- P is a well-formed finite partial map with unique nominal keys and typed
  complete entries; source-address renaming is coherent and injective.
- Exact reuse checks the complete dependent interface, code, owner/role,
  parent/scope, references, licensing and component maps. This is a genuine
  supplier compatibility judgment, not merely equal endpoints.
- The old registry supplier gives extension/reuse preservation for the actual
  old guards, domains, licenses and actions exposed by relevant consumers.
- The independently interpreted Delay formation law accepts this very
  `q_a,J_a,refs,xi` package at the source-owned root and scope, with its original
  admission/history, witness, authority and output-dependent fields. Existence
  of a complete Delay module alone is not this applicability proof.
- The proposed source rule has an original introduction/interpretation law
  on this bounded target domain and retains the ordered dependency telescope.

**Conditional derivation.** Exhaustive lookup has two successful branches.
If found and exactly compatible, return that entry unchanged. If absent,
allocate one typed entry and apply the supplier's extension law. Old positive
lookups and their exposed complete contract fields are preserved. The
independent Delay attachment supplies the same-index original ReifyOrigin.
Applying existing Carrier-Delay to that origin and `q_a` produces the local
DelayCode judgment. Transport stored premises together; lookup compatibility,
extension and component action laws give naturality and identity/composition.
This reasoning assumes neither Call membership nor a satisfying inlet.

Reject or leave the construction unresolved on duplicate/ambiguous input
registrations, incompatible old-key reuse, missing exact attachment or scope
inclusion, failed old active-license preservation, or missing domain-changing
action certificates. Certified absence must cover the actual registry, not a
filtered table omitting old cases. The extension law cannot be supplied by
relabeling source syntax action as semantic license transport.

This is not a proof that all hypotheses are inhabited for `my invoke f=f 1`.
It does not establish complete Call formation or CarrierMem: SRC Delay and
Call-input §5.3 retain the independent inert and universal designated execution
obligations over every admitted pending/resume/future domain. The local
constructor's actual application domain must include the formal/literal case;
that inclusion is not obtained by weakening the native theorem's codomain.
