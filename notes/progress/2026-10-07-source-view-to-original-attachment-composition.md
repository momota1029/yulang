## 3. The composition that does follow

Write `e0=(k,beta,u,sigma_x,p0)`, with `beta=(d_f,R_f)` and the original
`ElimOrigin(c_fx,u_f,d_f,R_f,p0,p_out(c_fx))`. Let the receipt receiver be
`r_A`; later `step` entry is `r_S`, and actual provider entry is `r_G`.
These are distinct roles/occurrences. Use `upper[e0]` to select just the
newly introduced upper source of a packet's indexed image. It is a proof
projection of retained provenance, not a new evidence carrier.

At actual receipt, SV introduces `b` with `b.receiver=r_A` and the upper
fragment at `Lift_result(p0)=argument.result.(u,p0)`. Its Pending certificate
retains the original entry suffix and prospective result path. No executing
profile at `argument.effect`, rebound binding, capture or read follows yet.

If the original entry actually returns at `h` and rebinds, let `M_res`
denote that result correspondence; SV gives its rebound formal view and
`SourceViewInst`. At actual local Lambda and later resolved Name transitions,
SV constructs `M_cap` and `M_read` as same-binding typed identities. The
composition law yields, for this upper source alone,

```text
chi_read^upper[e0]
  = (M_read o M_cap o M_res)_* chi_receipt^upper[e0]

chi_read^upper[e0](p_read,b) iff
  exists p_lift,p_f,p_cap.
    chi_receipt^upper[e0](p_lift,b)
    and M_res(p_lift,p_f)
    and M_cap(p_f,p_cap)
    and M_read(p_cap,p_read).
```

For the designated source paths the witnesses are the actual result lift,
the rebound `(u,p0)` occurrence, the corresponding captured field occurrence
and the actual `u_f` read occurrence. Expanding relational image proves both
directions of this equivalence. Each incidence has that same input source
and those intermediate typed witnesses. The separately tagged returned
provider source is transported by its own maps and retained; its own lower
output is not relabeled `e0`. The same maps transport `D` while `K` and
inherited `L` stay shared.

Pair this derived read with CALL's `J_f=ReturnImage(Name(d_f),...)` using
the same resolved Name, original typed environment and actual transition.
CALL's operand is

```text
j_call : rooted complete invocation expression record
J_f >>= (lambda actual_f.
          ExecuteCallable_X(actual_f,Delay(J_x);U,e))
```

Here `J_x` is the inner rebound `x` Name, not the external carrier entering
`step`. The receipt/capture packet is therefore tied to the **actual callee
read of this operand**, rather than another alias of an equal provider.
The static `ElimOrigin` identifies the operand's designated output address.

If the original typed Call actually opens that demand, its independently
typed elimination correspondence instantiates this static address in its
executing view. If a request `q` has that current view's pre-dispatch
`Observe` witness and the matching receipt, TB/typed-boundary then derive
`Path`; `Inc_C` additionally needs the exact current live handler, owner and
`r_A`. This final step uses the actual Call/observation derivation. Neither
`ElimOrigin` alone nor the static expression creates it. No future latent
observation or provider-wide event membership is inferred.

**Conditional composition theorem.** Under `H_SV(X,hist)`, all reached
selected receipt/result/capture/read transitions extend CALL's source
operand record with the exact corresponding upper packet as above. Pending
prefixes extend it only with SV's prospective packet and original suffix.
With an actual typed Call opening/observation/receipt, the stated event-path
consequence also follows. Every construction retains that same `X,xi` and
original provider interpretation. This theorem proves a typed source/view
correspondence; it does not assign an original contribution-contract sort.

## 5. Licensing, discriminators and failure conditions

The conditional candidate Attach-Call rule still consumes the missing
association. Forward licensing would additionally need the independently
interpreted original licensing law for its entry:

```text
a_call(X) and OriginalAssocType_X(beta,p0,j_call;s0,c0)
  => Attach_C(X,e0,(beta,s0,p0,c0))                 [candidate introduction]

A_sound:  Attach_C(X,e0,t) => Lic_C(X,t)            [not established here]
A_invert: Lic_C(X,t) => Attach_C(X,e0,t)            [not established here]
```

Neither SV's typed-packet reflection nor having one direct source Call
enumerates original licensing last rules. Conversely, downstream candidate
protection is not an inversion theorem for pre-transport original licensing.
The source direct-exposure singleton `{e0}` remains distinct from a complete
signature/profile inventory. No minimized language witness refuting either
licensing direction was constructed.

Logical mutations, not executed experiments, discriminate the shortcuts:

- Set `c0=j_call` or `s0=p0`: assume the missing sort/interpretation conversion.
- Treat `chi_read^upper[e0]` as `c0`: retain a protection profile but omit
  complete invocation/contribution typing and original slot association.
- Retag a provider source as own-upper because its endpoint or target equals
  the upper's: discard indexed provenance and violate no-backflow.
- Conclude Rebound/read for a Pending history: fabricate unexecuted result,
  Lambda or Name witnesses. Conclude an observation from a prospective path:
  fabricate an executing view/event.
- Use expired `r_A`, replace it by `r_S`, or borrow another alias's receipt:
  break the exact receiver/path join even if static labels and values agree.
- Treat a passed Call certificate or SV inverse as introduction of its
  retained original kernel premises: circularly consume the sought rule.
- Rebuild `c0` with another world/`xi` or gate it on `Q`: break one-X
  correlation or comparison-independent formation/admission.

No Oracle or executable checker is used. The derivation shares the four
dependencies' independently stipulated source-slot/profile/typed-transport
and original admission premises. It checks their composition, not their
independent truth. A checker taking an `(s,c)` introduction or licensing
transition rule as input would not prove that rule's source interpretation.
There are no random seeds, numeric ranges, executed mutations or case counts.

The composition edge is localized, so this lane stops. Enlarging a packet
model or repeating Call-prefix probes would leave this same premise untouched.
Recommended next action: obtain the independently interpreted original
signature clause converting this exact source/view record and `j_call` into
`(s0,c0)`; then assign its one-Call source introduction and forward licensing
proof. Reverse licensing additionally requires its original last-rule inventory.
