original Result license and its lossless Return transport suffices to attach
the complete N consumer tuple and its action to the original Call consumer.

conditional equal-cardinality discriminator isolates an additional necessary
obligation at the downstream checking witness: the two incidence-indexed
actions must admit one lossless natural transformation. This obstruction
persists with singleton Return fibers and a granted identity Return bridge.

This is a theorem about explicitly assumed boundary fibers/actions. It is
neither a counterexample licensed by the selected source rules nor a formal
nonentailment result for their full interpretations. In particular, the
existence of the required source-legal stabilizer and its asymmetric action
on the two checking fibers is unproved. An authentic shared-kernel
reindexing can exclude the discriminator.

## Required map and conditional construction envelope

Write `j_N` and `j_O` for the complete N and original indices. A candidate
attachment consists of an authentic scoped index map `alpha`, and maps on
the entire dependent witness tuple:

```text
Phi_j : W_N(j) -> W_O(alpha(j))
Phi_(theta j)(theta_N z) = theta_O(Phi_j z).
```

Every contract-exposed N alternative must survive separately: `Phi_j` is
injective on those alternatives, with the declared inverse-on-image property
where required. Surjectivity onto all original alternatives is unnecessary.
The map acts jointly on `w_wf,e_f,e_a,e_out`, the actual operation evidence,
argument/result/consumer origins and output-dependent provider/future fields.
Independent existential choices of these projections are insufficient.

## Smallest equal-cardinality witness and derivation

Let the action monoid be the two-element group `G={id,s}`. At the checking
fiber, identify the full tuples with their distinct exposed proof alternatives:

```text
W_N(j_N) = {n0,n1};       W_O(alpha(j_N)) = {o0,o1}
s_N(n0)=n1; s_N(n1)=n0;  s_O(o0)=o0; s_O(o1)=o1.
```

Both actions obey identity/composition: the transposition squares to identity,
and the target identity action squares to identity. The fixed runtime tuple,
scope, operation, provider/world and granted singleton Return bridge coincide
under `alpha`; no value, provider or event is switched to make the witness.

Suppose `Phi` is an action-commuting attachment. Since `s j_N=j_N`, its square
at `n0` gives

```text
Phi(n1) = Phi(s_N n0) = s_O(Phi(n0)) = Phi(n0).
```

Hence `Phi` collapses the exposed alternatives and is not injective. No total
lossless action-commuting attachment exists under hypotheses 1–4, although
ordinary set bijections exist. There are exactly two injective assignments,
`n0->o0,n1->o1` and `n0->o1,n1->o0`; each fails the displayed equation.
The two constant maps commute but fail losslessness. This enumeration is a
hand derivation, not an executed search or independently grounded oracle.

Minimality for this equal-cardinality action method: one N alternative admits
no nontrivial permutation; with only the identity action any bijection works.
Two alternatives on each side and one involution are therefore the smallest
same-size nonempty-fiber obstruction. This does not claim smallest possible
counterexample among arbitrary source programs or different methods.

Analytic mutations discriminate the premise:

- If `s_O` also swaps `o0,o1`, either displayed bijection commutes.
- If `s_N` fixes both members, either bijection commutes with the fixed target.
- Removing action commutation permits the two ordinary bijections.
- Allowing alternative collapse permits either constant equivariant map;
  that weakens the selected whole-contract boundary.
- Replacing the supplied target by the same contract incidence together with
  its authentic transport/action law may force the first mutation, excluding
  the asymmetric witness. This must be derived from that contract's owner.

No mutations were executed. No random seed/range or runtime oracle exists;
the finite calculation covers all four functions on the assumed 2-to-2 fiber.

The exact conditional theorem excludes a full attachment even after a lossless
Return map and every static origin are granted. It therefore identifies a
downstream action obligation that cannot be replaced by static registration,
equal fiber size or a Return-only square. It does not prove that this obligation
fails for the actual existing kernels. Nor does it show it is an independent
new semantic gate: a single existing whole-kernel realization may discharge
Return, checking and every remaining consumer square simultaneously.

For the separate `IF_pick`/`IF_id` pairing, the same stabilizer test is a
necessary diagnostic **only if** an authentic scoped pairing of their base
indices and compatible action domains exists. This artifact constructs none.
Distinct telescopes must remain distinct; their imported/rigid dependencies
cannot be freshened to manufacture a common action. Even a successful
N-to-original map at one inlet does not give shared challenge admission,
same-event correspondence or provider/world-domain transport at the other.
No `mu_adm`, `Valid_V`, ALL_VIEW refutation or id/pick result-separation theorem
follows. The selected static source incidence and independent operation arms
must be preserved in any future pairing.

Under the proof-obligation-economy rules, static origin/incidence attachment
has a reconstruction-debt aspect: use the owning constructor's retained typed
maps when genuinely available. Whole witness-action/domain compatibility is a
semantic realization obligation; an owner ID or printed endpoint cannot prove
it. This local falsification is stronger-characterization research within its
assigned gate and changes no production prerequisite or recorded gate class.
Do not add a proof-only relation or source restriction from it.
