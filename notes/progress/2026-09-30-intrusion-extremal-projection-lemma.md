# Intrusion pointwise extremal-projection lemma

Date: 2026-09-30
Branch: `research/simple-sub-intrusion`
Classification: conditional semantic lemma; Oracle correspondence remains open

## Statement and proof

Let `(D, ≤)` be a subtype preorder and let Function subtyping obey

```text
Arr(A, R) ≤ Arr(A', R') iff A' ≤ A and R ≤ R'
```

For fixed `R`, let `S ⊆ D` be the nonempty admissible assignment set of a
negative-only Function argument after fixing all other local and environment
assignments. If `S` has greatest element `m`, then

```text
↑{Arr(a, R) | a ∈ S} = ↑{Arr(m, R)}
```

For each `a ∈ S`, `a ≤ m`; contravariance gives `Arr(m,R) ≤ Arr(a,R)`, so the
upward closure generated by `Arr(a,R)` is contained in the one generated by
`Arr(m,R)`. Since `m ∈ S`, the reverse inclusion follows. Reflexivity and
transitivity of the subtype preorder suffice.

If `D` has finite meets and, after fixing all other assignments, `S` is exactly
the nonempty set defined by finite lower and upper interval constraints, then
its greatest element is the meet of its upper bounds. Every member lies below
that meet. Nonemptiness ensures each lower bound also lies below the meet, so
the meet itself is admissible. The empty set of upper bounds has meet `Top`.
Consequently, the bounded negative example with only `x ≤ Int` projects to
`Arr(Int,R)`, while the unconstrained case projects to `Arr(Top,R)`.

Independent compiler-semantic review confirmed the two inclusions and noted
that a preorder suffices; the exact two-way Function variance law is stronger
than this proof requires. Independent spec review approved the conditional
scope: this is a candidate-model result, not an Oracle behavior claim. Both
reviewers required the Oracle correspondence claim to remain separate: the
mathematical lemma requires the retained `m` to satisfy all lower and
environment obligations and no other correlation with the result/anchors.

## Limits and handoff

This is fiberwise. Other occurrences, cross-variable obligations, and
environment anchors are fixed during the argument and may make an independent
admissible set unavailable. A greatest element may also fail to have a finite
graph expression when bounds depend on other variables. The result does not
show that Oracle's selected upper structure denotes the same extremum. Source
audit confirms that negative compaction merges projection upper records and
that one-polar elimination is conditional on eligibility (including polarity,
level, non-generic status, and roles); weighted alias and row cases can alter
what an upper record contributes. The bounded `expect` source probe confirms
one exact execution only, not this general correspondence.

Next prove or refute the Oracle correspondence between evidence-selected upper
bounds, their compact negative merge, and this greatest admissible value.
General projection, ordered root simulation, use simulation, and
implementation remain open.
