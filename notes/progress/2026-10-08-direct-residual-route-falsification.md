## Objective and result

Audit whether restricting a direct effective solver to residuals actually
generated by the selected source constructors removes the missing joint
decision obligation. The method inverts the native id input clauses and
separates their constructed parametric proof action from the obligations
supplied to that action. No finite quotient is assumed or required.

**Result class: conditional derivation and bounded source characterization.**
The native id action can be implemented as a uniform transformation of supplied
complete certificates, without enumerating challenges or classifying them into
EPR states. That fact leaves a precise obligation: decide or construct the
remaining input and checking witnesses jointly at their original prefixes,
with complete independent challenge coverage and terminating negative answers.
Restricting the outer input to emitted source residuals does not itself prove
this obligation. No source counterexample to a complete direct route, Yulang
undecidability, or necessity of EPR/ER is established.

## 1. What the source restriction actually restricts

Write Em(S) for the selected source-rule generation, with original source
positions, imports, scopes and xi=(nu,K,D) fixed. This is notation for source
Generalize §4's existing generation, not a new emission algorithm. The proposed
input restriction is

```text
input residual is Em(S), for an admitted S.
```

It does not replace an inner independent challenge domain by executions of S.
Already at bare `my id x=x`, the finite emitted schema has the whole carrier,
result check, registered port map, static Delta and observation-dependent Delta
proof slots. At each checked challenge, J is the typed argument's complete
contract. Delta checking quantifies over every J alternative and its original
response/raw/future telescope. J may license observations absent from the
argument's executions. Uniform inlet §4.2 states this explicitly; §4.3 forbids
filtering those observations after admission.

Thus a source-derived residual can have finite syntax while its operands carry
an independently specified observation family. No arbitrary new primitive is
needed to locate that operand. Conversely, this observation does not prove
that the native id's *own* Delta is hard: §4.3 constructs its exact finite
projection/image derivation schema, with no extra operation bound.

## 2. Direct action without a finite abstraction

Fix these hypotheses at their original scopes:

1. The selected native source meanings and genuine local L/carrier/world laws.
2. One lawful original prefix and joint input strategy s; its A/Delta and any
   ViewLogic choices precede their challenges exactly as already declared.
3. Each legal checked challenge supplies that same argument's full gamma and
   current guards, with all independently licensed J alternatives and genuine
   local checking proofs. This is an input hypothesis, not an inferred fact.

For that challenge, project its kappa/gamma and construct
PackGeneric(kappa,gamma). Project carrier_J at its actual current demand; apply
the same delta_check to the complete J observation at that event. At Return,
apply mu_result to the same decorated result. At Request or unfinished prefix,
retain the actual raw handle and construct no completed result. Native
Bind/Read/Return/frame-return actions then produce the local output evidence.
At a later response/raw/future challenge, apply the corresponding hereditary
subtree at the current world and retain only the unfinished suffix.

Induction over the original finite development constructors yields this
parametric action for every legal finite extension. Joining the actions uses
the already supplied s and shared actual event operands. No earlier witness is
reselected. This is the reused Uniform-ID/Joint-ID construction expressed at
the direct residual seam; it is not a new independent proof of those results.

This gives a concrete way to avoid ER's *particular classifier requirement*:
the action can be polymorphic in opaque lawful challenge/certificate inputs.
Its independent interpretation must justify the action for every allowed
interpretation of those inputs. It need not compute q(h), enumerate worlds,
or inspect every history. Effective term manipulation additionally requires
finite codes for the submitted records and their local eliminators; the
source mathematics does not supply a production encoding by itself.

The conclusion is an action **on** supplied witnesses. It does not establish
that those input witnesses exist jointly, or decide an unsatisfied residual.
The algebraic location of the gap is visible without introducing a quotient:

```text
same-prefix lawful input records + same-prefix strategy s
  -> native output proof records extending exactly that prefix and s
```

The arrow does not construct its left side. An arbitrary false input/client
conjunct is not repaired by a total output action.

## 3. Exact obligations for the direct route

A direct algorithm may discharge the remaining obligations by a terminating
symbolic calculus, a syntax-directed proof constructor, or another effective
kernel. It need not use EPR/ER. For its claimed emitted-source scope, however,
the missing evidence has these concrete forms:

| Required evidence | Owning seam and exact scope |
| --- | --- |
| Emission closure | An exhaustive inventory of the residual atoms and operand telescopes actually generated by each included constructor and source checking choice; no arbitrary Phi substituted for actual source emission. |
| Faithful input interpretation | Finite submitted or symbolic complete J/Car/context/L records, with an independent interpretation covering their licensed alternatives and legal challenges. A law name or opaque semantic oracle is insufficient. |
| Same-prefix constructive reflection | When the original remaining residual has a strategy at a fixed lawful prefix, construct one satisfying that whole residual at that same prefix, extending earlier witnesses and preserving Shared/ViewLogic/EventProof dependencies. It cannot pick an easier J, different provider, or another compatible world. |
| Total residual decision | Prove termination of the kernel on every admitted emitted input and exact negative answers. Recognizing a submitted finite proof, or fairly searching finite proofs until one appears, gives no negative termination theorem. |
| Complete retained evidence | Keep each proof alternative/intermediate read by the original relation or client; establish any canonicalization law against those actual observers. An endpoint-only equality cannot justify erasure. |

These are proof obligations for the proposed route, not additional language
clauses or required data layouts. If a direct parametric derivation settles an
atom uniformly, no effective challenge classification is needed for that atom.
If an atom's truth depends on a challenge field, its kernel must either prove
that dependence symbolically at the original telescope or faithfully interpret
that field; a semantic predicate call is not an effective implementation.

The precise prefix-lift requirement is constructive reflection at each *fixed*
earlier prefix. Existence of some successful original source derivation with
different earlier choices proves neither that requirement nor the residual at
the caller's current prefix. This requirement survives removal of q/Next.

## 4. Source-grounded family and its honest limit

The source checking grammar itself supplies an infinite family of retained
finite derivations, without adding an arbitrary predicate:

```text
d_0 = Identity(A)
d_(n+1) = Compose(d_n, Identity(A)),  n >= 0.
```

At one same-decorated-value check A -> A, identity supplies the base case.
Composition with the same intermediate A and evidence supplies the induction
step. Source checking §3.2 and native registry §3 explicitly permit these
terms and retain their tags/intermediates. Each d_n has n composition nodes
and n+1 identity nodes, hence tree size 2n+1. This family belongs to the
selected local source proof grammar under the genuine identity/composition
laws. It concerns source-lawful derivation alternatives, not measured compiler
output. No claim is made that ordinary F5 emits any d_n.

Consequently a source constructor/schema count alone does not bound all exact
retained proof alternatives. A client can submit an arbitrarily large finite
local derivation at its genuine checking occurrence; its submitted proof size
then belongs in the input/resource measure. A recursive proof grammar or
parametric retained reference can represent this family without listing it.
This is compatible with a direct route.

This family does **not** refute a source-size bound on the smallest satisfiable
witness: d_0 exists, and no actual source-emitted conjunct forcing d_n instead
has been shown. It does not refute canonicalization when an independently
proved observer-preservation law permits it. The reviewed identity/composition
distinction is reused as a source premise; its old erasure counterexample is
not repeated or rerun. The new use here is solely the unbounded derivation-size
calculation and its separation from decision completeness.

An analogous scope error would test Delta only against actual argument runs.
Uniform inlet §4.3 already provides the discriminant: a constrained Delta
forbids q while J licenses a q Request only as a production extra. The whole
input proof must fail that arm even when the actual run never requests q.
This accepted discriminator is not a new search result. Bare id introduces no
such q bound, and no owning source rule emitting this constrained Delta has
been established in this lane. It therefore cannot be reported as an actual
emitted-source counterexample. It identifies exactly the domain-preservation
obligation that a proposed trace-only kernel would violate conditionally.
