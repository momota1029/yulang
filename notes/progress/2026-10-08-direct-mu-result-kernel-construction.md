the selected native unannotated immutable `my id x=x` inlet. The rule consumes
the supplied finite original inclusion certificate and constructs its
same-value hereditary result action. Its input is a proof-bearing checked
argument, not an untyped carrier or an already successful id query.

## Original dependent input and direct rule

Let S be the original argument-check occurrence with telescope T. It includes
the already chosen frame endpoint A, registered result incidence r, complete
J and formation kappa_J, retained original witnesses and any actual scoped
dependencies of this check. Write B = J.payload. Keep actual provider p as the
complete original provider/decomposition data, not a shape-selected provider.

Use the proof-validation judgment

```text
T ; L |- d : SameIncl(B,A) @ S,r
```

whose finite rule schemas are listed below. It records both original endpoints
and every introduction position. Free references must occur earlier in their
own original telescope; an introduced intermediate may depend only on the
inputs available at its owning rule. A proof originally inside an observation
or EventProof region stays there. It is not hoisted to the frame region.

For a compatible Return event e, the independent J/Car projection supplies

```text
eta_B : VCert(B,v,p,W_e,e,r)
rho   : original legal restriction/substitution from T to this Return region
```

where rho carries current scope, authority, world and any required incidence
evidence. It never transports stale activity as a current live permission.
The direct application rule is

```text
T ; L |- d : SameIncl(B,A) @ S,r
eta_B : VCert(B,v,p,W_e,e,r)       LegalOriginal(rho,T,e,r)
------------------------------------------------------ MU-RESULT
eta_A, a = Run(d,rho,eta_B)
eta_A : VCert(A,v,p,W_e,e,r)
```

`a` contains original children, intermediate certificates, branch choices and
primitive output witnesses. The result action retains `(d,rho,eta_B,eta_A,a)`
as its typed record. It does not replace d with an equivalent proof, erase a,
or overwrite the independent runtime Return evidence. If the original rule
relates distinct proof certificates at the same raw tuple, they remain distinct.

The judgment is schematic over the original dependent inputs. Where an
original local proof term is produced under an event binder, Run consumes that
term there. Where a finite derivation has a scoped binder body, Run instantiates
that body there. This construction does not assume that every arbitrary
semantic family of local proof terms has one finite effective representation.

For a later independently compatible development e', eliminate the hereditary
part of eta_B and apply the same original derivation under its lawful dependent
restriction rho'. Retain the target proof and all local auxiliaries at e'.
This can be represented as a finite closure over d and its earlier inputs,
with an argument for the later event and its legality proof. It is not a new
generalized Desc or an executed dictionary.

An immediate output certificate need not be definitionally equal to the
restriction of a separately supplied target proof. When the registered rule
requires such equality its explicit law must prove it. The construction claims
the required hereditary typing and retained provenance, not proof irrelevance
or equality of independently chosen proof objects.

## Algorithm and derivation

`Validate` traverses the finite source-check term or registered graph. It checks
constructor identity, original operand references, telescope order, child
interfaces, explicit equality/incidence premises, full auxiliary declarations,
and each primitive/equation rule through its H2/H4 recognizer. Binder bodies
are checked symbolically with their original earlier-variable context. It
does not enumerate worlds, challenges, observations or futures. Scope checking
uses the original dependence graph; name equality is not a substitute for
owner or binder identity.

There are three distinct outcomes:

- Valid: all represented finite proof obligations are checked.
- InvalidProof: a represented decidable obligation fails, such as a wrong
  endpoint, forbidden future dependency, missing arm or rejected primitive
  certificate. This rejects this supplied proof presentation only.
- Unknown: a needed primitive law/recognizer, faithful encoding, equation
  certificate or original input correspondence is unavailable. This cannot
  be interpreted as source rejection or as absence of semantic inclusion.

These are research-kernel outcomes, not a selected compiler diagnostic policy.
When H1–H5 hold for every rule of a supplied term, Validate is a terminating
binary decision of that finite term's derivability in the represented fragment.
If there are n finite term/graph nodes, its cost is traversal plus the costs
of local reference/scope and primitive/equation checks. There is no claimed
global polynomial bound: H2/H4 costs and output-sharing behavior are unknown.
Run follows the same constructors, retaining its outputs; it need not eagerly
unfold a hereditary infinite family. Productivity requires H4 and may not be
deduced from finite syntax.

**Soundness, conditional.** Induct on the supplied finite derivation. Identity
preserves its certificate. Compose applies the induction hypothesis at the
same intermediate tuple. Record/union/intersection use the independently
interpreted constructor projections and the induction hypothesis on every
child, so outputs retain all ambient identities. Function uses tau, original
source membership, and psi as above. Primitive and equation steps use their
independent complete local laws, H2 and H4. Scope validation ensures that
every output depends only on inputs available at its original introduction.
Thus MU-RESULT produces VCert(A) on the exact input `(v,p,W_e,e,r)`.

For hereditary typing, repeat this induction under each original legal event
restriction. Structural projections and logical introduction instantiate at
the current event; composed intermediates are the corresponding current
outputs of their children. Function binder bodies use their actual later
domain/observation/context premises. Primitive and recursive cases require
H3–H4. No current permission is copied from an earlier event without its law.
This constructs a target hereditary family at the original binders, including
nested future demands. It proves no outer Echo equality for nested responses
or nested future returns. Divergence supplies no eta_B Return to this rule.

**Relative grammar completeness, conditional.** Invert a finite source
§3.2 checking derivation whose rules all have the H1–H5 interfaces. Its outer
constructor appears in the table; inversion supplies its original endpoints,
child proofs, local witnesses and scopes. Inductively validate those same
children, keeping their terms and witnesses. H2/H4 recognition completeness
for their finite certificate presentations validates each primitive/reference
case. Reassemble the identical outer proof. Therefore every such represented
source derivation is accepted and replayed with its original proof fields.
Conversely the validation cases reconstruct a source-check derivation from
their checked premises, provided the registry entry is actually source-adopted.
A locally sound but unadopted rule cannot be counted as a source rule.

This inversion is not a proof that the local registry laws follow from source
meaning: source-adoption, actual primitive interpretations and their recognizer
contracts are independent hypotheses. It proves structural agreement of
finite derivations under those laws. H2's primitive recognition completeness
is essential to the stated converse and remains unproved for the open catalogue.

## Exact admission seam and negative-completeness limit

At a J Return, project eta_B from the authentic original carrier certificate;
MU-RESULT then derives eta_A. The original port map and independently supplied
delta_static/delta_check build the whole I_q[A;Delta] image. At a prefix or
Request there is no fabricated result: retain J's complete fields and apply
the appropriate delta_check subtree at its current telescope. Generic inlet
admission injects that exact formed schema and gamma with PackGeneric.

This gives a concrete parametric operation on a supplied gamma's mu_result.
It supplies no gamma from an arbitrary carrier, no carrier_J truth recognizer,
and no Delta proof from scalar result inclusion. Delta can add original
guarantee/profile/whole-observation obligations with separate local laws.
Checking mu_result also does not decide the whole admission record.

The exact predicate decided under H1–H5 is

```text
Given original finite d and scoped input presentation:
  d is a derivation of SameIncl(J.payload,A) in this represented registry.
```

It is not

```text
There exists any original lawful finite d proving SameIncl(J.payload,A),
or J.payload is extensionally included in A,
or the complete original admission/residual has a lawful joint strategy.
```

InvalidProof cannot establish any of these existential negatives. Enumerating
finite derivations would additionally need effective rule/operand enumeration
and can at best semidecide existence without a terminating complete bound or
a proved symbolic decision procedure. The selected grammar itself disclaims
complete derivability of every true inclusion. No finite bound on minimal
proofs, complete primitive catalogue, or same-prefix joint-search reflection
is proved here. This construction therefore does not close JOINT_DEC.

The precise next blocker is not hereditary alias reconstruction. It is an
effective complete decision of proof existence for the actual emitted
inclusion/admission predicates, with the original endpoint/telescope and
independently supplied primitive input meanings. Repeating another validator
or identity transport would leave that premise untouched.
