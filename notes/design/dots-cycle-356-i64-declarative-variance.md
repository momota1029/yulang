The premise `Coverage` recurs below normalized declarations (including defaults). `GeneralDeclarativeWitnessCoverageBoundary355.checked_nominal_excludes_legacy_coverage` proves the incompatibility for an actual selected unary covariant constructor, not just an artificially missing metadata entry.

Generalize or reuse this shape with a mode-indexed local meaning, keeping exactly the current declarative state and model fixed. Only once the declarative theorem is independently defined and proved should S2 connect the actual checker.

## First implementation slice

1. Independently derive an interpretation/coverage of used declarations from exact source constructor names, argument kinds, arity, and the declared variance at each argument. Keep primitive interpretation and invariant interval projection as ordinary special cases. Check table length/kind exactly; do not use unspecified/missing slots as a variance default. Keep authored provenance/current state separate from branch output and witness claims. Hidden row fields, I-61 endpoint-based record capture and I-58 actual-center ties stay explicit; replacing their former proofs with name equality would not be a preservation result.
2. Build one mode-indexed supported local read and fixed-output meaning. Existing `CommonDeclaredNominalVariance.nominal_head_variance_exact` expresses the direction at a known head. `CommonRecursiveNominalIntervals.ContextDerives`, `inspect_context_exact`, and interval admission `compile_exact` give candidates for independent declarative comparisons with already-declared variance (including reversed contravariant order and inherited invariant intervals). These are not themselves supported source observations, compiler receipts, a mixed classification, or coverage. Use them only where the actual checked state/source and interpretation connect the premises.
3. First positive source fixture: a genuinely declared unary covariant `Box`, selected from same-tag arms with actual independent sources; use the single merged `Box(a | b)` and bind the entire merged payload to both variables. Keep real physical centers and the unchanged ordinary typed/record receipts. First controls: never silently reclassify that same constructor as invariant; reverse the one-way comparison in a true contravariant fixture without generalizing the covariant join rule by analogy. Only add further joins if spec 6.3 or established declarative rules determine them.
4. Prove local soundness from the mode-indexed declarative positive rule alone. Then carry it through the ordered-dictionary induction and prove scoped preservation for existing primitive/invariant fixtures. For S2 equality use the separately specified output relation: exact diagnostic tree, ordered dictionary and exact writes/targets in one state/model. The C353–356 independently authored type/physical-address/ledger checks are a possible witness implementation of the covariant case, not the definition of which source programs accept.

Not in scope: transporting C356 to the old C334 Coverage, legacy Local, reconstructing C316 evidence, general completeness or termination. No new language priority or representation workaround is authorized.
