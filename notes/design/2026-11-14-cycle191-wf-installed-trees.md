Target: the I32 WF boundary and V6 Evidence. Existing cycle190 gives current-context
Instance/Evidence after one actual Installable. This cycle connects ordinary
actual WF traces and a parent followed by a terminal child installation.

Data and independent judgments are unchanged: HeadStepKernel.State/Installable/
Step/Models and boundary.Evidence. No new source semantics or classifier is defined.
An ordinary trace restricts actual Step by exact OrdinaryTrace.Extension of current
contexts. Descriptor-changing refresh is not covered. The existing generic
instance_extension/evidence_extension proofs are reused, not claimed as new.

The nonempty-child theorem quantifies over arbitrary roles, registry, parent state,
parent/child plans and supports, with real Installable at each stage. The parent
packet's children must equal the singleton of the second packet's focus; the second
packet must be terminal. Every model of the final state has the parent dictionary
node with its one child dictionary, in that same final context/model. No child
Evidence, source Instance, or universal materialization is an assumption. Actual
execution additionally needs generated parent focus and semantic novelty at both
steps. Final inhabitation follows from the second Installable, not an assumed model.

These are conditional installation theorems, not source-derived general enablement,
V6 EvidenceNode or full B4. Universal Available remains obstructed by the existing
supervisor counterexample. No supervisor-owned definition is changed.

exact canonical child order. Both require genuine Installable, generated focus,

certificate. It is NOT construction of such certificates from Classify, a solver,
termination, completeness, or the general EvidenceNode field. The concrete
regression instantiates a real one-leaf repeated-variable source only. A concrete
nonempty-child source certificate was not constructed in this cycle. The generic
nonempty-child theorems retain explicit real enablement/scheduling premises.
