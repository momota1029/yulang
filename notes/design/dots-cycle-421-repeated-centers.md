# C421: C13, 重複 binder を選んでから元中心を等しくする

仕様 6.3 の `impl R 't 't`（二つの入力に同じ binder）を対象とする。元の可視候補一つ・where なし・出力なし、元の普通 variant の下端根拠と共通上端への実区間、raw 根 K2 をまず検査し、候補を確定する。この段階は実中心の式・中心間の等式・結果の型・モデルを使わない（区間の実アドレスを照合する）。次に出現順の二つの中心から、後の中心 = 最初の中心の正確な等式を生成する。実 State に保持された等式を照合する正の場合と、同じ tag で実中心の payload が int / bool となりその等式を足すとモデルを持たなくなる拒否を別々に扱う。等式の単なる欠落は拒否でなく未対応。先行 raw K2 と既存の分岐・固定 I-65 を維持する。外側の P/Foo → where の全経路はこの周の対象外。
