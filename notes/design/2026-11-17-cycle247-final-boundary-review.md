# Cycle247 final independent boundary review

This review read the cycle247 modules and the actual source interfaces. It
assesses proof scope, not publication or audit completion. The reviewed new modules
provide real semantic/representation results, but do not yet implement the I47
successor SourceBoundary or prove its unconditional EvidenceNode.

## What the new results actually establish

The guarded group constructs and recovers regular Common models for the
explicit payload-guarded Layer246 fragment. It preserves arbitrary consumers
using finite closure environments, including private cyclic reads, and proves
public solution equivalence for that new representation. The concrete
recordDefault/arrow example tests mutual recursion and private row reads.
Commutation/local compression requires explicit independent-owner conditions.
There is no general bound on environments, current bodies or operational work.
The global normalization draft was stopped and is not a cycle247 result.

The ordered group operates directly on actual Presence TyTerm/Atom lists,
including unguarded var, union and inter terms. SafeOrder permits later RHSs to
read earlier defined type targets and prohibits a write from invalidating an
earlier definition. Rows are unchanged at every name. The solver constructs
models under reflexive subtyping; recovery of existing models uses explicit
constructor-congruence preorder laws, instantiated by the concrete Common laws.
Finite compiled substitution has an exact evaluation bridge for any list.
Ordered old/fresh blocks with the stated target containment and private-public
boundary preserve public solution sets after rewriting arbitrary consumers.

OrderedQueries247 additionally proves exact readback of listed CompTerm queries,
forward equivalence of their type values with exact row values, concrete Common
probe equivalence, and an observed-public model iff for a tagged bundle of
explicitly equivalence-stable observation predicates. The combined theorem uses
one witness for the constraints and the listed observations. This is genuine
coverage of the supplied bundle, not enumeration or stability proofs for all
actual packet/cache/inspection fields.

The preparation pipeline now handles coherent repeated targets without changing
the original block semantics, then topologically sorts a finite list. Successful
prepare supplies permutation/semantic equivalence and SafeOrder. A strictly
lower rank for each in-block typed dependency guarantees the sorter succeeds;
the rank producer is not supplied for all actual source operations. Initial
allocation also constructs a disjoint support certificate for arbitrary supplied
RHSs and consumer atoms, plus listed extra names. It is an initial reservation,
not a rule to allocate more names on every refresh.

The syntax stabilization result is about a fixed consumer list rewritten by
successive blocks whose target sets stay within the original block. After its
first expansion, that list is literally unchanged. It does not cover newly
appended packet/history obligations, growth of live definitions, arbitrary
cross-owner dependencies, or termination of refresh scheduling.

## Minimum three remaining proof packages

These are logical work packages, not a claim that each is one small lemma.
They can overlap, but none can be replaced by assuming the desired conclusion.

### 1. Actual source/metadata representation and model correspondence

Implement the selected stable-owner successor representation and connect real
allocation/capture/refresh operations to it. Actual lo/hi RHSs come from
`GeneralNominalAllocation.lower/upper`, which contain unguarded endpoint vars
and lattice chains. Guarded Layer246 does not encode those in general. The
ordered preparation route covers the successfully prepared cases; unsupported
cycles require a semantics-preserving treatment, not a new language rejection.

Prove actual callers provide coherent entries, complete support, ownership and
successful preparation or the appropriate alternative representation. The
existing actual `Definitions241.coherent` can support the duplicate-removal
adapter, but the full source application was not rebuilt here. The full-source
support function used by Definitions241 and the lighter typeSources244 function
have matching constructors but still need an imported bridge in that adapter.

Fresh naming is not semantic privacy. The cycle241 reviews already identify
an actual 240 trace where an aggregate becomes `base.source` slot5 and is read
by a descriptor; later root endpoints are retargeted to that promoted value.
A stable-name interpretation can expose a self-dependent aggregate such as
`L = union L L`. Merely defining sharedNames to exclude L would hide an actual
source observation, not prove its preservation. Public source coordinates,
current promoted source fields and allocator-private names must be distinguished
by a proved interface. Every promoted source/descriptor/query must be retained
through a complete query or state adapter, rather than dropped from the public
boundary by declaration.

The adapter must include source and current raw states, historical and live
plan effects, Fits/schema/output constraints, inspector origins and observation
witnesses, and trusted cache support. Do not delete cross/selfChecks or source
constraints as though all equations mentioning an owned name were private.
The generic CompTerm/query transport and expression views are ingredients,
not a certificate that every actual metadata field has been covered. In
particular, equivalent type values do not automatically preserve the same
literal `Observes.source` witness; witness transport up to equivalence remains
part of the metadata proof.

There is a concrete model-interface mismatch to resolve. The current vocabulary
in `GeneralNominalVersionedDiagnostic232.vocabulary` uses `Model := Assignment`.
`B4SkeletonV8.B4Bridges.stepModels` requires the *same* model in
`b.Models after model -> b.Models before model`. Cycle247 backward laws instead
construct a readback assignment, and public iff existentially projects private
assignments. Those are valuable but not the same statement. A successor needs
an explicit stable-source interpretation/internal existential representation or
another justified correspondence that actually establishes the required
same-model law. For a newly defined projected predicate
`Models boundary := exists witness, All constraints witness and Agrees public witness boundary`,
the already proved iff holds at each fixed boundary and directly supplies its
same-boundary backwards law. That narrow construction is available, not an
additional unresolved algebraic theorem. What remains is compatibility with the
existing full-assignment Models and the common witness needed by actual current
packets, EvidenceAt and the other operational laws. Do not silently replace the
old model interpretation without those proofs.

### 2. Actual operational progress, coverage and old regression transfer

Define the real successor Step/Stable/Initial and prove the operational bridges
on all checked reachable states. The finite work calculus needs an actual
projection with strict progress for every operation: installation, refresh,
reobservation, newly invalidated consumers, cache/inspection work and any
representation normalization. Fixed target names, a bounded owner list, finite
sort fuel, or stable consumer text do not alone establish that measure.
Unpaid repeated service and live-body or fact-domain growth must be excluded by
proved operation rules without changing program acceptance.

This package must connect to the concrete B4Bridges fields, including progress
(Acc), execution, halted, closure, stepModels, frontier/local agreement,
where-accessibility, tree execution, canonical local order, dictionary
reflexivity and initial reorder transport. Preserve existing V8 diagnostic
priority/sharing behavior and the I45 protection of established point-source
descriptors; the new helper modules have not changed those source rules.

The new sorter terminates as a finite preprocessing algorithm. Its returning
none is not a source diagnostic. Likewise SafeOrder failure, a failed Fresh
or protected-pool check, or a private row occurrence must not be converted into
a new rejected source program. Rows may read private names because their
values are preserved globally. Unguarded cyclic equations can have multiple
solutions: the new concrete Common self-alias counterexample shows that naive
replacement can shrink public solutions. It is a warning about an invalid
representation generalization, not a source-language failure.

The old regressions199,202,204,206,218,230,239,240 have not been revalidated on a
new I47 source boundary in this cycle. Existing239/240 nontermination theorems
remain facts about their old boundaries; the new helper results do not refute
them. New successor paths and outcomes must be established and checked, rather
than inferred from these algebraic examples or from old-boundary results.

### 3. Unconditional selected-node evidence and final composition

`B4SkeletonV8.EvidenceNode b` quantifies every checked registry and every
reachable state/root. Its `EvidenceAt` obligation concerns the root or a truly
generated demand when parent and immediate children are stable in the same
snapshot, selection is actual Local selection, and child dictionaries already
have the required evidence. Construct the parent node's actual evidence from
source plan/frame/instantiation and child evidence, with no extra premise that
merely restates EvidenceNode. Follow the selected-tree generation route of
`GeneralDictionaryDefaultComposition211` and its actual V8 transfer
`GeneralDictionaryHeadSharingComposition220.composition`, whose only remaining
evidence premise is EvidenceNode. The latter uses
`GeneralDictionaryHeadSharingSoundness220.classified_generated` for demands
actually present in a selected dictionary tree. Transfer that established
selected-tree route to the successor; do not revive the stronger general
GeneratedChildren or withdrawn FreshCompletion obligations from older generic
skeleton interfaces. I40 remains in force.

A conditional theorem taking an EvidenceNode argument, a no-selection vacuity
lemma, or one hand-built compiled-block model does not discharge this package.
Once the actual operational bridges and selected-node producers are proved,
the established 211/220-style B4 composition can yield SaturationTotal, Exact, OrderIndependent,
DictionarySound and NoFalseRejection. Cycle247 has not reached that point.

## Most likely misreadings to avoid in the report

- “Actual Presence/Common” identifies the syntax/model used by the theorems;
  it does not mean the actual source transition system was implemented.
- “Public iff” preserves the stated projection. It cannot silently exclude an
  escaped/promoted source name that the real program still observes.
- “Prepared” requires coherence and successful sorting; a supplied rank is a
  sufficient completeness certificate, not a rank produced for every source.
- Generic dedup is now verified, so repeated input names need not be forbidden.
  Discarding conflicting duplicates is not covered.
- Guarded raw-value inequality examples distinguish syntax representatives,
  not necessarily inequivalent semantic observations for every boundary.
- Finite preprocessing, local closure compression and fixed consumer syntax
  are separate from global solver Acc and EvidenceNode.

No Lean source was changed during this final review. No broad legacy/journal
build or old source regression rerun was performed by the review worker.

## Next adapter: ordered readback through actual origin paths (read-only proposal)

The following are proposed lemma statements, not additional compiled results.
They were checked against the actual definitions in
`GeneralNominalRebaseOriginView243` and
`GeneralNominalRecursiveInspection.Test.Holds`. Write `M` for the concrete
CommonNominalFullCarrier.model, `O` for OriginView243, `S` for Ordered.solve,
and `mapping` for OrderedSubstitution247.mapping.

1. **Exact ordered origin evaluation, with no ordering premise.**
   For arbitrary entries, assignment rho, O.Origin origin and actual value:
   `O.Observes rho (O.subst (mapping entries) origin) actual <->
    O.Observes (S M entries rho) origin actual`.
   This is `O.subst_exact` plus function extensionality and `mapping_eval`.
   The analogous `O.compile` theorem connects an actual
   RecursiveInspection.Origin to RecursiveInspection.Observes under solve,
   directly using `compile_exact`. Both preserve the SAME actual witness.
   These exact equations alone do not compare solve rho with rho.

2. **Compatible assignment transport up to equivalence.**
   `Compatible M first last -> O.Observes first origin actual ->
    exists other, O.Observes last origin other /\ Equivalent actual other`.
   At a source leaf use `type_eval_equiv common_laws`. At a nominal or
   structural node, transport the parent witness, retain the same original
   arguments/values list and selected actual, and compose parent Equivalent
   in the correct direction. No constructor injectivity, uniqueness of
   projections, or new observation-selection policy is required.

3. **Projected paths preserve literal observed witnesses.**
   Under the same Compatible premise, separately:
   `O.Observes first (.nominal parent name index) actual <->
    O.Observes last (.nominal parent name index) actual`, and analogously
   for `.structural parent shape index`. Use item 2 for the parent, keep the
   selected value and constructor witness list unchanged, and reverse using
   Compatible symmetry. This includes arbitrarily nested parents.
   It is FALSE in general for `.source term`: that constructor exposes the
   exact evaluated syntax representative, not its entire Equivalent class.

4. **Fresh-extension projected-origin transport.**
   With `SafeOrder old`, `TargetsWithin fresh old`, and
   `All M rho (block old)`, for a nominal/structural outer origin:
   `O.Observes (S M fresh rho) (O.subst (mapping old) origin) actual <->
    O.Observes rho origin actual`.
   Combine item 1, solve_absorbs, solve_compatible, and item 3.
   Fresh SafeOrder is not needed for this observation-only statement;
   it is needed separately when certifying the fresh block's satisfaction.
   For arbitrary origins replace exact actual preservation by item 2's
   equivalent-witness relation.

5. **Actual observation predicates are equivalence-stable.**
   The inspected actual `Test.Holds` has three constructors: scalar is
   Equivalent to a fixed base, structural existentially chooses a values
   list with the required length and Equivalent to shapeValue, and nominal
   existentially chooses arguments of the required arity and Equivalent to
   nominal. Therefore `Equivalent a b -> (test.Holds a <-> test.Holds b)`
   follows by transitivity, retaining each list witness. Item 2 in both
   directions consequently preserves `O.Head` even for source origins;
   it also preserves `O.Same` by transporting both observed witnesses and
   composing Equivalent. In conjunction with item 1 and recovery this gives
   Head/Same transport for ordered rebase, not merely a generic Stable
   assumption for these particular predicates.

These are direct opportunities for a small concrete adapter, but are NOT a
claim of all-boundary coverage. Actual report captures, bounds, anchors,
current/history/cache records and EvidenceAt require their corresponding
fields to be compiled together and evaluated against one common model
witness. Bounds endpoints also need transport; they cannot be silently left
as raw private addresses. The new OrderedQueryLimit247 regression makes this
failure semantic, not merely syntactic: a safe old alias at private name 2
has width-emptyRecord value, a safe fresh exactEmpty definition changes it
to a non-equivalent value, whereas the substituted query preserves it.
Thus source-origin identity must not be generalized from the projected-path
same-witness result, and excluding promoted names from the public list is
still not an actual metadata adapter.
