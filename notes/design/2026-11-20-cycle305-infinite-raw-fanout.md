# C305: infinite raw fan-out and a checked finite V8 observer

The C285 depth-three selected fixture has an actual output request, not an
empty obligation. In the endpoint family every successor gains the scalar
observations, satisfying the actual strict refresh rule. Simultaneously it
adds one unused normalized shape, tagged by an arbitrary natural number.
This is a change to the representation, not an extra term, model equation,
dictionary child or output in the program. The selected dictionary child list
is empty; the nontrivial depth belongs to the requested output type, not to
a dictionary child. The prior observer design note's hypothetical unlocated
child was not used in this fixture.

The same starting installed state has infinitely many pairwise different
raw halt successors. Every full raw rule is disabled at each endpoint. Yet
one complete V8 compiler input is valid at every endpoint and computes the
same selected frontier, and the indexed evidence preserves the exact deep
payload. The tags therefore refute literal finite enumeration even when
one restricts to legal strict-refresh terminal successors with that
particular complete input. They do not refute finite exhaustive search in
a separately justified quotient or establish its termination in general.
A snapshot-only change between two equivalent post-refresh representatives
is not an additional strict raw refresh; the strict extension is always
from the same installed predecessor. No new Rust execution is implied.
