# I-56: 局所選定の入力根拠と実中心の導出

状態は通常の制約・区間・等式のみ。展開に使用可能な根拠は、同じ等式の上に
置く別の宣言的判断とする（source または完成した需要の出力）。
未完了の出力は通常の全モデルと K2 の構造グラフから落とさない。
展開用の観測と、選んだ候補の出力右辺が全モデルで成り立つことは別。

まず任意の状態について、出所による射影が通常のモデルに関して保守的
になる条件、一般の受理済み head の実中心読取りと式の導出を証明する。
その後、根および非変数 pattern が実際に調べる位置だけで K2 を調べる。
全ての候補・必要な下界・順序つき where/関連型を揃えた選定がなければ、
`Compiles` 全体の完成とはしない。中心を復元できないことを理由とする
言語の保留・拒否は追加しない。

## 周の後半で判明した正確な切り口

- 同じ普通状態・需要でも、頭の等式の独立な source 根拠の有無で展開可否が
  変わる。状態に帳簿を混ぜず、source 導出にて根拠を供給する方が自然。
  `no_bare_state_readiness` はこの区別を普通状態とモデルから復元できないことを
  証明する。普通の型行・区間に変換された根拠も別に追跡する観測を定義した。
- 受理済み where の全ての名前なし引数の code は、nominal 内部も含め、
  可視 head 変数だけを読む。順序つきの三端・名前つき要求を加える普通等式は、
  既存の論理名すべてと衝突しない新変数を使えば、どのモデルにも実際に拡張できる。
  これは現状態にどの同値な名前が既に記録されているかを選ぶ定理ではない。
  親の既存の出力 target に別の値を入れることは許さない。
- 不変 nominal の actual は下界の実 operand から取れる。上界が別名でも、
  下界から上界への通常の型不等式による不変性が上界との同値を供給する。
  共変 pair では同じ推論をしてはいけない。両端の繰返し変数が一致しても
  中心は非対角になりうる。`projection_exact` は actual の pair を読めば
  その二成分の普通の同値が正確な条件であることを示す。
- 残る一般の源泉側は、通常の正規化・伝播がどの候補の観測／阻害／実捕捉を
  本当に供給するか。とくに名のない再帰型の正則同値・開行・共有する共変な
  actual の同じ論理名、ならびに安定した既存名の出力等式を正規化導出から得る。
  `Local` の選択を「証拠があるとき」と再定義するのでなく、この読み出しを証明する。

## 次に必要な source exactness の型

通常状態に user-visible な由来を表す別の証明 context を添えるが、その
由来は `Models` の引数にしない。三つの target を分ける。

1. source 式・普通の制約の正規化導出から `Available` な根拠の存在と、
   root と非変数の調査位置だけにおける K2 の正規化像を導く。
   型・行の普通の原子や区間に変換しても、出所の依存を消さない。
   alias の「証明済み等値」と、正則な展開の観測同値を区別して橋渡しする。
   開行の段階で閉じた record の投影を割り当てない。
2. 同じ普通状態で、実際の許された局所選定から
   `HeadCases321.Head` を作る。共変 root では actual の構成子／実
   operand の出所を直接読む。`CovariantIntervals321.component_bounds`
   が区間への整合を、`PairProjection321.projection_exact` が繰返し実
   identity を正確に扱う。nominal root ではより弱い下端中心の規則を使う。
   探索した一つの assignment や、候補の自己申告する `Node` は根拠にしない。
3. source の順序付き where 伝播と関連型の出力 RHS が、既存の普通の論理名で
   同じ定義を既に実現するかを示す。新しい論理名が必要なら
   `FreshExact321.exact_forest` と `Fresh321.old_model_projection` を使う。
   既存の出力 target は新しい定義の左辺として上書きしない。

いずれも実行履歴・実行結果との照合は I-56 (2) の別の問題。
