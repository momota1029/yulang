# Cycle242: next executable boundary contract

Draft, 2026-11-17. This is a representation plan under I47, not a language decision.

## New evidence

`RebaseBirthWitness242.source_owners` derives one finite live owner domain from
actual PointSourceBoundary240 reachability, without a final model witness.
Installation provides its own common model; later empty model sets do not erase
the structural owner bound. Thus the remaining infinite growth in239/240 is
not unbounded live owner generation. It is version/source/observation history.

`RebaseAggregateFinite242` gives a single, model-independent finite list
representative for lower/upper aggregates over a supplied finite endpoint pool.
Its representative is chosen before quantifying assignments. It does not prove
that arbitrary nested substituted formulas have a finite canonical family.

## Why ordinary Store replacement alone is not the successor

240 promotes private aggregate names into base.source. The nominal descriptor
and graph constraints read those names as well as ordinary atoms. In addition,
`Plan.binder` returns an existing endpoint for a point singleton capture; the
center namespace separation for fresh purposes8/9 is not a universal proof
that every existing center is outside every mutable aggregate cell.

RawProjection242 preserves every raw descriptor via semantic pullback by the
old finite patch. That is a real existential projection theorem, but its
conclusion is not a freshly constructed GeneralNominalState.State. The current
State.base.source and Site.center fields hold Nat names, not arbitrary type
expressions. Merely retaining a raw snapshot while changing its assignment,
or silently pretending its old center reads the new cell, loses obligations.

## Candidate explicit representation

A successor should separate mutable owner definitions from persistent consumers.
Persistent consumers include base ordinary atoms, nominal/structural descriptor
constraints, actual-center expressions for all live sites, and old effect/
output/child-certificate expressions. Each consumer has an expression-valued
view. A rebase first substitutes the OLD definitions into every consumer and
into new definition right sides, then replaces that owner's definition block.
The semantic theorem compares source projections, not identical assignments.

Required independently testable producers:
1. A finite traversal from real raw/plan/effect structures to the expression
   view, with an iff to the old Models/Inputs/output/child judgement.
2. Substitution commutes with each judgement, including nominal descriptors,
   rows and all inherited actual centers. RawProjection242 supplies the raw
   semantic part, not the traversal or executable State reconstruction.
3. A new RHS which mentions the owner's old cells is rewritten before treating
   it as external. Stable-name reuse can create self-reference in240; fresh
   spelling does not establish this external-RHS invariant.
4. A newly active private cell was not previously an unconstrained source read.
   Expanding the private projection domain to a union without this invariant
   is unsound. The singleton-to-multiple case is not covered by the current
   TargetsWithin theorem and must not be accepted by removing that premise.
5. Finite source/descriptor and expression-observation facts, with genuinely
   unchanged normalized observations rejected as no-op. Names and owner bounds
   alone do not bound term nesting, descriptor copies, or work repetitions.
6. Real operations mapped to checked Scheduler242 learn/service, and no work
   left implies actual Stable/Local/Evidence, not merely a compiler table match.

No all-input successor boundary or completed B4 theorem is claimed. The current
partial projection path remains useful; these are its missing concrete inputs.

## B4 quantifier compatibility

Direct reread of `B4SkeletonV8.B4Bridges.stepModels` shows that the same Model
argument must satisfy before and after Models. Internal owner assignments cannot
be that fixed public model: 230 proves old/new aggregate equations incompatible
on one assignment. A successor must hide replaceable private cells behind an
existential internal valuation, while retaining a fixed source/public observation
model. The intended shape is `Models state publicModel := ∃ internal,
PublicReadback state internal publicModel ∧ InternalModels state internal`.
PublicReadback must cover original source and the exact all-live observations
used by Evidence, not simply a conveniently chosen source subset.

The current projection theorems justify some internal witness changes. They do
not yet construct this successor Models/Readback or its evidence interpretation.
The existing V8 target is not weakened, and stepModels is not silently replaced
by an existential law with different quantifiers. The new representation must
make its required same-public-model law genuinely true.

## Evidence cannot choose a different private witness per child

Public Models hides internal private coordinates existentially. It does not
license defining each child Evidence by an unrelated existential internal
witness: separate witnesses for child1 and child2 need not satisfy the same
parent/effect snapshot. The original EvidenceAt composes children in one model.

A successor therefore needs source/public readback that determines the live
argument/output expressions relevant to evidence, together with invariance of
the independent declarative Evidence judgement under internal witness changes.
An alternative intermediate definition can quantify over all internal witnesses
of the same projected state, but it must then be shown equal to the intended
public judgement, not substituted as a weaker goal. This is part of the whole
live consumer bridge, not a new semantic choice or permission to weaken V8.

## Newly completed local compatibility

PublicModel242 defines a fixed PublicAgree (all rows literal, private-outside
values exact) and existential Models. Its replacement_models_iff keeps the SAME
public assignment on both sides and changes only internal witnesses. Its
raw_step_models is a local same-public-model implication from actual raw/atom
congruence plus coherent/external/private-domain hypotheses. The230 concrete
application uses old/new real merge entries and rawsnapshot+publicAtoms.
This closes the quantifier mismatch for that local replacement; the complete
successor state/evidence readback and all operations are still to be built.

The expression rewrite need not depend on unbounded choice: Lookup242 implements
substitution/patch/new-RHS rewrite using finite List.find?, proves equality to the
existing semantic operations under coherence, preserves every row, and computes
`x := x ∪ x` through old `x := a` to `x := a ∪ a`. This is a syntactic step toward
an executable view, not a proof that all observation growth is finite.
