The cycle 288 supplement is a semantic test, not an original raw transition.
Do not add the leaf to `State.plans` and do not refresh the old journal. Add
a separate, read-only finite input classifier and a deterministic auxiliary
phase. The two fixture registries share producer/input layout and child
identity; the row-pattern branch is still pending and still passes the old

raw state and must not pass the receipt check merely from plan count.

The checked packet binds declared registry data (the exact finite
declaration list of this fixture, not a generic fingerprint), parent effect
declaration/target and actual edge, child occurrence and declaration,
recorded observation shape, and no live output requests. The interpreter
consumes a compact structured wire extracted from the actual state, not a
caller-supplied boolean choosing the answer. Forge explicit controls for missing
producer, changed registry, wrong edge/target and deferred inspection. It is
not sound to infer eligibility from a matching identity, model set, or empty

the correspondence theorem requires this fixture's checked source context.

a recorded owning effect, an exact registry and current source-certified

initial fixture. Negative counterexamples stop that proxy, not unrelated
work. Existing Yulang2 C3-ROLE-01/02 checks successful and unsatisfied actual

## Falsifying a wider provenance interpretation before extending scope

Try a checked registry with the same declarations, keys and actual raw
state but a different constructor catalogue. The declared-world list is
not full `Metadata`. A closed collision will not invalidate the earlier
trace theorem, which is restricted to the fixed actual pair. Test an
independent finite gate at the constructor keys actually present as
nominal descriptors in the raw snapshot; bind both the supplied registry
and the owning historical effect. Test an observed key mutation versus
an unobserved one. The gate is not a proof of equality of arbitrary
catalogue functions: preserve a negative control outside the selected
footprint and retain the checked-source premise. Do not widen the raw
transition or infer general language support from a finite table.

The raw carrier does not make occurrence IDs injective over all caller-
constructed demands. Test a second counterfeit using the real child's
identity and role but changing its argument from point 0 to point 1.

An ID-only edge check will not distinguish them. Compare complete finite
occurrence data (role, ordered endpoint pairs and named output pairs)

injectivity at a fixed Roles environment. On the real initial/installed
pair this changes no outcome. It does not prove global catalogue/context
authenticity; the separate unobserved-key control still matters.

## 接続先と、次に狙う三つの補題

I-52 の rebase 版 Step に向けては、今回の二枝の対応を「旧 raw と
新しい公開観測が一致し、証拠が揃った場合だけ一つの source 出力を
補助公開できる」という十分条件の特殊例と位置づける。大域的な Acc、
B4 の四分類、主型性をこれから導くとは言わない。次の一般化の候補は
`∀ old new p q, SourceReach old → SourceCheckedEdge old p q →
Release old p q new → ∀ m, Models old m → Mark.Holds m`。
`SourceCheckedEdge` は観察した catalogue の一致だけでなく、現行の
要求・候補・所有効果に戻ることを要する。`Release` は文字列や ID の
一致ではなく、検査済みの `Wire` と `Stamp` を受け取る補助操作の
関係として定義する。今はこの量化された命題を証明していない。

候補となる三本（一般停止性の残り本数ではない）:

1. **実読取りの出所**: 任意の正の evidence に対し、実 generated edge、
   同じ producer、matched argument の型端点と行端点、観測キーの
   checked projection を証明できる形で切り出す。未観測 Metadata の
   一致は結論にしない。
2. **正の行読取り自体**: `GeneralRebaseRowHeadBoundary287.recursive_row_not_finished`
   は既存 inspector が row-bearing nominal を分解しきれないことを
   示す。この入口に fixture の registry を変えるだけでは正例にならない。
   `RowDeferredDecisionGuard288.direct_read` は型 head の `ReadyAt` で
   あって独立行の解決ではない。先に既存の行 atom を持つ別入口を探し、
   そこで実ソース据付と二つの行割当の区別（型座標を固定）を示す。
   `CommonPresenceInspectionRows.inspect_preserves_rows` と
   `GeneralRebaseFiniteRowReads285.equation_iff` は行側の候補だが、
   generated where 辺との接続は未証明。繋ぐには frozen な inspector
   の規則を替えるしかないと分かったら、この箇所は設計質問で止める。
3. **raw への影響を抑える**: 新しい読みが source fact を公開する場合に
   公開射影の等価と、実 Step 射影／補助の stutter を二方向で示す。
   point mark、raw の Known、独立行 evidence を混同しない。先に 1 と 2
   が済まなければ全体の完全性や一般停止性を主張しない。
