# Root stability and selected descendant evidence

The full-tree adapter previously asks for settled Stable separately at each
selected descendant. Replace this with root Stable plus JointClosure, which
keeps the genuine applicability obligation at each selected descendant.

Induct on the finite selected-child path. The reflexive case is Generated.root.
At each edge, prior generation restricts root Stable to its parent. Reachability,
the selected parent and its explicit Joint yield a committed current-context
instance and actual Generated children. Compose generation and continue.
This is not a claim that a purely syntactic child graph is always generated.

Derive NodeClosure from actual generation and root stability, then reuse the
full-tree theorem for selected classification and completed diagnostic trees.
Only final-context Models are quantified. Joint remains explicit; no all-original-
models theorem, unconditional EvidenceNode, or old/new Stable equivalence is
claimed. The only new modules are additive and existing semantics are unchanged.
