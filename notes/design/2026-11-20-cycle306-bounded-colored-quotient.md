# C306 generic finite observer minimization

For a supplied finite, transition-closed list, start with equality of a
decidable observation color. One round retains exactly pairs whose edge
choices match in both directions using the previous relation. Every actual
color-preserving strong bisimulation remains in each round. A missing
stability bit yields a strict decrease in the count of retained enumerated
pairs. At pair-count rounds (or before) the relation is stable and hence the
greatest such bisimulation on the closed list. No theorem supplies a finite
raw list or assumes that diagnostic agreement is an operational quotient.
