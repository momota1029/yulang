# C377: independent one-rail projection versus an actual native visit

I-65 step 1 only. The EarlyPorts module is audited and public.
The split NativePrefix drafts described below are not Lean-verified.

An endpoint port identifies a potential comparison job by (original
rail, bound corner, literal argument index and left/right job face).
It depends on one declared parameter effective in its actual inherited
context. A completed comparison supplies the other rail and can verify
the same ordinal by the EarlyPorts theorem. Do not use that later
comparison as input authority, or interpret a missing one-sided
projection as a veto. Unused parameters enumerate no jobs.

## Difference between two independent proof obligations

1. **Read a current authorized physical original.** Start with the exact
   C376 typed authoring and a successful actual C360 install; disjoint
   appends preserve its lookup and active owner. Require an independent
   grant for that full address. The exact read can now supply an encoding
   of the stored row using the existing literal `NativeOrder362.node`.
   To attach the origin to a logical lower/upper rail, still require that
   the exact encoded origin, with its real slot and issuer, is retained
   in `s.origins` and that `OriginRoute s` proves the requested logical
   coordinate. Neither premise follows from a model's equal values.
2. **Project the actual source head position.** Pair that rail with the
   actual request argument index and visible candidate's normalized
   written application, and with the same source mode/kind table. For
   each selected potential subargument, the original argument-indexed
   bound, its mode, and EarlyPorts give exactly the projected corner at
   that job. This is a model-free source-indexed statement even before
   the opposite end is known. A candidate visiting this port is a further
   independent statement; comparison decomposition is not a trace.

The first proof uses physical release and the exact source write
constructor; the second can use only State365 and EarlyPorts369 without
the deep native example imports. Splitting the Lean dependencies along
this line will not replace the exact upstream endpoint encoding by an
opaque arbitrary conversion. The remaining source obligation is the
actual independent visit and candidate-local K2/priority judgment;
neither the one-sided projection nor a real successful installation
establishes it. No verdict, permitted program change, fixture, or
automatic grant follows from this note.
