# Semantic duplicate-arm collapse (Evidence bridge)

Prove an actual depth-two nominal inspection bridge. A certified same-carrier
revision changes the outer parameter `(a,b)` with `a != b` to `(a,a)` and keeps
the lower inner descriptor. Both old inner arms are unary nominal heads of the
same name; each captures the same binder. Current inspection drops the upper
arm, so its report and bindings need not equal the historical ones.

For every current model, if the old inspection has ProjectionModels, derive all
four current ProjectionModels fields. The new inner anchor is justified by the
current outer descriptor's semantic model. Remaining anchors/tests/capture
sharing are inherited from the retained lower arm. No current ProjectionModels,
Refines, endpoint equivalence or current report equality is assumed.

This is a precise depth-two fragment, not arbitrary finite nested transport or
current materialization. It shrinks the reobserve gap of V5 evidenceNode but
does not close that general field.
