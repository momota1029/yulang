# Draft: cycle26 shared finite branch certificates

One finite list of `(full ancestor route, declaration)` pairs is shared by all
siblings. Enumerate sublists of the observation-independent route carrier crossed
with registered declarations. Boolean validation checks independently specified:
(1) at most one declaration per route, (2) every stored pair is reachable under
this very table and is an independently viable Candidate, (3) every reachable
route has a chosen declaration. The selected mask is table membership.

For every checked registry, source root and fixed ordinary observation, search
membership iff canonical sublist plus this declarative certificate. Every child
of any chosen declaration is reachable under the same table; no sibling may
silently use a different choice for the same full route. An empty table cannot
certify a root. This is a diagnostic total branch certificate, NOT the language
policy: pending routes may have no certificate; existence, uniqueness of the
whole table, ordinary consistency, stable observation, source lowering and B4
are not claimed. Annotations remain input. Exponential enumeration is deliberate
finite reference semantics, not a production resolver.

Completeness includes arbitrary valid table representations: membership implies
retention in the computed choice space, and filtering that space by original
membership produces a returned certificate with exactly the original members.
The active mask and validity depend only on membership, not table order/duplicates.
Uniqueness is by full route, not by bare source node across distinct histories.
The latter node-coherence and ordinary equation satisfiability are not established.

The whole equation family now satisfies an existential model iff: for every assignment, some enumerated state is modeled iff the seed is modeled and an independently Valid table exists whose chosen associated outputs all hold on that same assignment. AssocWellFormed explicitly connects Computed to independent declaration resolution. This asserts neither satisfiability nor stable feedback, and the shared assignment does not assert bare-source candidate coherence.

A request with no Computed/DeclarativeComputed result contributes no equation (universal implication). Associated resolution success/totality is not proved.
