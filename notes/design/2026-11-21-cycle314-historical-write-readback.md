# C314 technical checkpoint: honest residual obligations on actual source states

## Checked facts used in the cut

1. Each historical input center has a genuine source origin. The exact finite
   full-model support includes past packet conditions and the live class
   observation, not just the current raw binding list. A coordinate with an
   uninstalled numerical owner cannot occur anywhere in this support. All
   current constructor tests are recovered from actual rooted or emitted
   typed labels (in any live model), not from the mere existence of a local
   candidate model.
2. A positive-version aggregate includes the declaration key, input name,
   polarity, and ordered list of observed lower/upper address pairs. The raw
   reservation from an earlier real install is retained, but looking it up
   as a prior equation is valid only when the key matches the actual chosen
   rule and the multiplicity does not equal one. This gives precise
   same-owner prior Prepared, then equality of its key with the current
   selection by uniqueness, rather than assuming prospective key stability.
3. Every aggregate cell appearing in a selected plan's protected journal,
   inspection, or class-body footprint is traced back to the current raw
   domain and then to a matching historical equation. An essential/actual
   protected purpose-8 binder is different: it never enters raw allocation,
   but its occurrence in the full footprint forces a historical binder
   producing that exact name at that exact owner and rule. These two exact
   producers give the general same-model current head.
4. Newly owned internal rows are either tautological or outside the
   protected set, and free-row collisions respect checked source keys.
   At a visited owner, actual-mode child-center and computed where-output
   rows transport using normalized actual variables on the same live
   assignment. This does not require lower/upper projections to agree.
5. A protected lower/upper compound where equation uses an old stable
   address. The precise old Eq (including expression and mode) is emitted
   by every same-owner frame under the same checked rule. Thus the residual
   question concerns declaration-specific operand readback, not recovering
   the historical target or generating the equation. Exact mode-sensitive
   readback suffices; nominal arguments reset to actual mode.

## What still needs to be produced

- Foreign keys: a genuinely different historical owner in the current
  alias class can only mismatch if the current-owner history reserved an
  exact alternate-declaration address (the reinspection's entire ordered
  per-name read version agrees) that is semantically read now but never
  received an installed equation. Determine whether this can occur on a
  genuine inhabited mixed trace, not a hand-built snapshot. If there is an
  obstruction, consider proving that an equation is already true in a
  suitable model or tracking exact source dependencies of the reservation.
  A raw occurrence or its registry-wide reservation alone is not evidence.
- Endpoint reads: the Readback reducer is a sufficient form on protected
  compound where rows only; it does not claim equality of all old/current
  intervals or that unconditional evidence fails if this particular witness
  family is absent. Check point and nominal cases separately; for a genuine
  strict refresh whose old/live endpoint RHSs differ in some model, try
  preserving the required equation in a chosen joint model instead of
  trying to prove universal equality between all operand slots.

The resulting recursive EvidenceNode theorem assumes the two residual
producer families. It recurses over the provided dictionary evidence and
uses actual selected effects and ordered child edges; it is not a program
or saturation termination theorem.
