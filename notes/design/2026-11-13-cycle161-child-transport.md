# Child identities and interval acceptance under capture collapse

Evidence-lane auxiliary, not a new saturation rule. Source spec 06 §6.5 and
Y2-ROLE-003/004 preserve interval endpoints rather than invented centers.

Prove emitted child occurrence IDs, roles and named output sources are unchanged
for a fixed seed/invocation/clause under changed capture inputs. The actual child
input intervals need not be equal. For variable-only arguments, old interval Fits
implies current interval Fits under the actual depth-two nonpoint collapse,
using old private propagation. No child candidate selection/Evidence is inferred
from Fits alone. This is one missing premise for nonterminal parent replay.
