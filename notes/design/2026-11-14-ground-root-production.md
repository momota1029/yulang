# Ground-root Class P: finite input production and the remaining factorization

Status: partial proof companion, 2026-11-14. Continues
[compound input producers](2026-11-14-classp-compound-inputs.md).
Authority remains `spec/06-roles.md` §6 and the approved B4 draft, including
addendum 7. No semantics, Step, guard, emitter or previous definition changes.

**Result:** actual structural compound containment, repeated-capture sharing,
emitted-child meanings, and recovered-input meanings are proved. A local
finite-capture factorization implies an explicit ancestry bound and then
accessibility of the unchanged actual-inspection Step, for arbitrary Checked
registries and the ground sources defined below. The local factorization is
still open. This does **not** establish unconditional ground-root Class P Acc
or discharge the full `ClassPProducer`.

## 1. Exact source restriction and theorem

`GeneralNominalGroundAccessibility.GroundRoots context root labels` says:

* `labels` has exactly the root role's unnamed arity;
* each normalized label translates to the quotation of a finite `Expr Nat`;
* this expression has no leaves and has canonical structural shapes;
* in **every** initial source model, the corresponding lower endpoint is
  equivalent to its denotation.

The closed terms use scalars, pairs, finite canonical records, variants,
exact-empty, and invariant nominals with finitely many type arguments.
No nominal body is opened. Leaf-emptiness makes the dummy leaf valuation
irrelevant (`FiniteMeaning.closed_independent`); it does not select a value
inside an interval. The same finite root label works for all source models.

This is an explicit subset of the requested ground source class. It does
not represent arbitrary finite unions/intersections, arbitrary row arguments,
or all source normal forms. The theorem also takes the existing `PointSource`
and `InitialSource` predicates. Only root pointness is consumed by the new
depth proof; the other initial pointness fields document the Class P boundary.
Later observations need not have literal point endpoints.

The strongest theorem is
`GeneralNominalGroundProduction.ground_accessible_of_capture_factorization`:

    Checked registry
    InitialSource registry context root
    PointSource context root
    GroundRoots context root rootLabels
    GroundCaptureFactorization roles registry context
      → Acc (fun next current => ActualInspectionSteps.Step registry root current next)
          (initial context root).

The registry is otherwise unrestricted: heads and children can have multiple
positions and compounds; associated equations and output-only binders are
allowed. There is no reachable-role hierarchy or distinguished input spine
premise. The extra local premise is stated precisely in §5; it is not supplied
by `Checked` in this change.

## 2. Finite readbacks and actual materialization

`FiniteMeaning.denote` interprets an expression by its existing carrier
constructors. `At m mode origin value` requires an actual observation and
compares **all** observations at that origin to the value: below it in lower
mode, above it in upper mode, equivalent in actual mode.

`assemble` proves constructor composition. Structural constructors preserve
the direction of containment. Nominal arguments reset to actual mode, as
required by invariant argument identity. Conversely, `project_value` derives
each actual child readback from an exact parent readback and a canonical
constructor position. The proof constructs a witness observation and then
uses projection uniqueness. `followed_readback` and `followed_closed` iterate
this for finite explicit constructor paths. Their `Follows` premise is a
syntax-aligned path; extraction of such paths from arbitrary live inspection
reports is not claimed.

For one declaration variable, `GroundProduction.capture_value` starts with
one `Usable` origin, its exact readback, and exclusion from output-only names.
`InputBound` places that value inside the actual merged capture interval.
`usable_same` transfers the readback to **every** usable representative of
the same name. Thus choosing another representative cannot change the value.
Neither endpoint coincidence nor interval overlap proves this sharing.

`StructuralContainment.schema_contains` then inducts over a quoted expression
inside the packet's real input schema. It obtains tests and variable uses
from `packet_exact`, rather than assuming materialization is sound:

* lower/upper variable uses are equivalent to the corresponding capture
  endpoints; the shared capture value lies between those endpoints;
* actual variable uses are linked to usable origins by `InputCoherence`;
* child schemas are included in the parent schema generated by `schemas`;
* structural and nominal nodes use the composition theorem above.

`compound_child_contains` combines this with the actual canonical emitter's
lower and upper requests. For every nonvariable unnamed child argument,
its finite instantiation lies between the **emitted** endpoints. This fills
the structural-root containment gap in the preceding note. Endpoint equality
is not required for containment and is not inferred from it.

## 3. Child provenance and observations

`GroundProduction.emitted_clause_unique` extracts equality of clause IDs
from equality of literal emitted occurrences, using injective allocator
encoding. Checked clause-ID uniqueness then identifies the clause itself.
This argument does not identify aliased demands with literally equal ones.

`argument_retained` follows both layers of the actual emitter:

1. A bare-variable child with a usable capture takes the shared-origin branch.
   Any witness selected by that branch names the same variable in the same
   clause, so its finite readback is the common capture value.
2. For a compound argument, clause uniqueness excludes both shared and legacy
   variable-origin branches. A retained fallback must therefore be the
   point-site source endpoint. Containment plus literal endpoint equality
   gives its exact value. If the endpoints differ, the fallback is absent.

`child_inputs` packages containment and retained-origin readback for **all**
child positions simultaneously, given finite capture/template evidence for
their expressions. It does not assume the semantic conclusion of the emitter.

`recovered_inputs` handles later observations. Previously retained origins
are unchanged. A missing origin can be recovered only through the existing
`EndpointEqual` certificate; its source endpoint then equals the contained
finite value in the current model. The theorem does not introduce a center
for a strict interval or assert that every contained value permits recovery.

## 4. Conditional termination argument and measure

Fix the initial finite root labels and let N be their normalized Paterson
mass, `GeneralNominalPatersonLineage.mass rootLabels`. For any finite actual
trace ending at state S and **any model m of S**, the invariant is:

    each stored site has finite labels L and literal birth depth d,
    each label contains its unnamed input and represents every retained origin,
    d + mass(L) ≤ N.

Labels may depend on m, S and the site. A single global choice of labels for
all future models is unnecessary. In particular, the argument does not
assume a model of an entire infinite trace or invoke compactness.

The initial site follows from root pointness and `GroundRoots`. Every actual
Step restricts models backwards. Hence a model after an observation, alias,
ordinary constraint or installation is also a model for all earlier packet
constraints. Administrative steps and merges keep the literal site list.
Source formation rules out new external enqueue events.

For an installation with at least one child, the remaining local factorization
provides one finite substitution sigma satisfying

    mass(sigma(head)) ≤ mass(L_parent),

and the actual child-production theorem provides labels `sigma(child)` at
every emitted site. `checked_child_descent` gives, for each child separately,

    mass(sigma(child)) < mass(sigma(head)).

Its literal allocated ancestry is one edge deeper. Therefore

    (d + 1) + mass(sigma(child)) ≤ d + mass(L_parent) ≤ N.

The same substitution is used across all head and child positions. Leaf
packets need no factorization because they extend no ancestry. This is
`sites_bounded`, proved by induction over the **actual** Step constructors.

For any future installing packet, `Installable` supplies a prospective model.
Applying the invariant to its registered parent site gives depth at most N:
`installed_depth_bound`. Repeated expansion of aliased occurrences cannot
increase this bound: each literal child birth must still pass the same
strict-descent argument. No quotient of ancestry by aliases is assumed.

The existing `ActualBudget.signatureCover` then enumerates allocator ancestry
through depth N, actual occurrence data, reserved source identities and finite
reports. This produces the finite signature basis, including semantic packet
deltas and emitted edges. The saturation measure is the number of basis
signatures not yet held. Every novel installation strictly decreases it;
other steps do not increase it. Within a fixed remaining count, the existing
passive accessibility theorem handles refresh, reobservation, equating and
merging. Nested induction gives `Acc`.

No fixed-hole elimination history or separate settled-output growth bound
occurs in this reduction. Once the local factorization is available, associated
equations can restrict the retrospective model but cannot invalidate its
earlier finite input labels. Output-only binders are excluded from unnamed
child arguments by the declaration checker. This does **not** independently
prove a uniform bound on all output terms. It shows that such a bound is not
an additional premise of this ground-input route to the existing signature
enumerator.

## 5. The one remaining hypothesis

`GroundCaptureFactorization roles registry context` quantifies over a tracked
state, an actually installable packet, its full actual-inspection guard,
unchanged constructor/interpretation metadata, a model satisfying the state
and packet, and finite input labels. If the declaration has children it must
produce one `Nat → Pattern` substitution with:

1. instantiated head mass at most the input-label mass;
2. closed quoted child labels of the required arities;
3. for each child position, `ArgumentValue`: either a usable bare-variable
   capture with that exact value, or a canonical quoted compound template,
   shared values for its leaves, and the correct denotation of the substituted
   label.

`packet_production` derives `GroundPacketProduction` from this evidence using
the real child emitter. The latter then supplies the depth and Acc theorems.
Neither predicate contains trace length, ancestry depth, accessibility,
finite signature covers, an output-tree budget or a hole-elimination history.
The state quantifier is currently stronger than the trace proof needs: it
ranges over all states with the given metadata. If this proves excessive,
restricting it to source-formed states is possible without adding a depth
assumption; that restriction has not been needed or formalized here.

The missing derivation is substantial: invert finite input meanings along
actual inspection paths; construct simultaneous finite labels for repeated
variables and multi-position heads; reconcile normalization, translation,
and substitution with the checker's counted mass. The per-template quotation
and denotation equalities in `ArgumentValue` are still hypotheses. They are
not a completed general syntax-substitution theorem.

Do not replace this work by assuming that `ActualInspection.Safe` implies
semantic satisfaction of all inherited tests. `Safe` certifies represented,
acyclic actual positions; packet projection constraints are produced from
the separate raw report. In particular, scalar inspection consults a lower
endpoint. The required mass comparison may be weaker than exact reconstruction
of the head. No source-formed infinite counterexecution or semantic gap was
established in this work, so no guard repair or owner question is proposed.

## 6. Concrete branching source

The checked declaration data describe these role constraints (method bodies
omitted, as in the existing declaration fixtures):

```yulang
impl Show (pair 'a 'b):
    where 'a: Show
    where 'b: Show

impl Show (list 'a):
    where 'a: Show

impl Show int:
```

`GroundExamples` uses the root `Show (pair (list int) int)`. Sources 0 and 1
come from the preceding closed list/int fixture. A source equation fixes
reserved identity 2 to `pair source0 source1`, with root interval `(2,2)`.
The source has a concrete model, satisfies `InitialSource` and `PointSource`,
and has a uniformly closed root label. `both_positions` proves exact semantic
readback at both structural pair positions.

This is a fixture of the new source representation and simultaneous semantic
projection theorem. Its `accessible` theorem explicitly retains
`GroundCaptureFactorization`. It is **not** a new unconditional Acc result,
an installation witness, or a successful dictionary execution. In particular,
the initial reserved root need not yet have a structural observation slot.
