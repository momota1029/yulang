# Named certificate persistence

Every finite observed scalar/nominal tree is preserved by an ordinary extension
that changes only constraint/reservation ledgers, not source slots, descriptors,
heads or interpretation. Thus Observed actual requests remain structural witnesses.
Computed-report transport and binding equality identify the actual request list;
this is not an assumed semantic Evidence transport.

A NamedLeaf shape and recursive NamedTree then survive ordinary extensions with
packet membership preservation. Real Shared ordinary traces supply both. Only the
final model and SourceFormed state are needed for interpretation. Descriptor
refresh and general Shared transitions are deliberately outside this theorem.
