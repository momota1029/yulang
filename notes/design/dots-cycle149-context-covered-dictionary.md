# Same-context journal coverage and recursive dictionaries

The node-level historical theorem is to be lifted through the existing finite
Classify derivation, not through an invented evaluator. Structural coverage is:
every selected occurrence generated from the saturation root has a packet in the current
journal whose stored context equals the current context and whose occurrence is
that demand. Key and emitted children are NOT extra coverage assumptions: current
selection uniqueness and the historical installation recover them.

For arbitrary source-formed state, such coverage, one caller model, and a finite
selected Classify derivation at the root, derive Evidence in that unchanged model
for the entire dictionary. Historical edges supply coverage for child nodes.
This is a restricted recursive evidence theorem, not a proof of unrestricted
coverage at every reachable stable state or of the general V5 EvidenceNode field.

Operational refinement: on actual ordinary-only enqueue/equate/install/merge
traces from InitialSource, context Extension is derived for every journal packet.
No Extension premise is attached to an edge.

Important limitation discovered during this cycle: the existing recursive
stable-success fixture has an unrecorded selected leaf, even on such an ordinary
trace. Packet coverage is therefore a deliberately strict subclass; it is not
claimed necessary for Evidence or implied by stability. A separate structural
leaf alternative is under investigation.
