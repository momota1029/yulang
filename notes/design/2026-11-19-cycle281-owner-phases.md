# Cycle 281 — 意味が静かな証明書修理には有限 owner phase を使う

実 optional leaf の point→second service は型公開モデル・raw 辺を変えないが、古い内部割当に対する現 frame の葉証明は得られない。二つの新しい集約座標を修理すると同じ公開型で旧 point でも葉が得られる。単純な意味 strict filter はその現実の Step を落とす。

候補: phase key を (invocation ID、declaration ID、有限 codec tag) とする。tag は checked plan の観測された descriptor から読み、不明 / 未対応は none。計画に新しい key が初めて現れるときだけ service creditを使う。保存済み plan が消えない raw trace で key 登録は単調。owner の候補は Paterson から最初に有限、tag リストは定義から有限。事実・辺・phase の残量で制限された Step 全体が Acc。古い raw journal の対応や永続的な占有の意味は unchanged、historical plans の無制限な再生成は guard が止める。

抽象的な任意相互再観測の活性は証明しない。実 optional source の初回は出力事実、point reobserve は quiet、次の個別 service は finite phase tag で残し、旧239/240の版の番号をそのまま有限 tag に利用しない。
