閉じた元候補の実 query から、record field / variant / pair / 宣言どおりの単項 covariant point nominal を有限回たどる。旧 graph の raw row と元 source を別々に読み、raw の論理 child を native の物理 source slot に結ぶには **元 issuer・route に加えて既存 raw Alias** を要求する。モデル内の偶然の同値では代用しない。各 parent と選んだ child の nativeSyntax は同じ FitsFull に対して読む。途中の K2 なし・実 field 終点の raw K2 ありを照合する。新しい raw edge、名前、bind/capture、body の展開、診断位置は作らない。

- 名付き raw variant/pair/nominal と異なり、元の native payload は inline のまま。closed record の元 field は first-visible shadow の順を保つ。pair は当該 ordinal だけを読む。nominal の比較証拠は実宣言と同じ自己 point、両 context での反映であって、非 point の端点比較ではない。
- 実 fixture は record → declared nominal → pair #1 → variant → record field の経路。初段の record は旧 named、最後の record hop が新 inline。四種類の inline receipt が一つの FullProblem・FitsFull に共存。変異のうち pair 全体の source spelling を崩すものは**直前 nominal の選んだ payload 照合**で落ちる。pair 自体が未選択側の native receipt をすべて監査する、という主張ではない。
- 最終の累積入口 `RoutedInlineStructural458.check_full_structural458` は `RoutedInlineVariant458.check_full458` をそのまま委譲する。新分岐は実際に使った新 pair/record/nominal ticket が最低一つ必要。独立な実 query/field 判定から同じ報告の有限 witness を作り、任意の同じ FitsFull で保存する。選択・辞書・where 子・出力は作らない。
