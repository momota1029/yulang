# C333: 支持済み RHS の first hit に依存しない正の read

I-56/I-58/I-59。本線は宣言的 (4)。元の支持行 E と正当な alias (n,o) の有限な表から、n について複数の RHS を同時に公開する index を作る。中間名の割当、モデル、候補提案や固定出力は index に入れない。閉じた record tail は実支持行を辿り、終端を確認したものだけを出す。通常の Read/Spine を別の判断として保つ。

計算は有限深さで全ての正の読取りを列挙する。対象断片について、任意の独立した Read/Spine と、それに実際に使った行と alias が表に入っていれば、十分な深さで同じ位置・mode・raw 出現が列挙されることを狙う。枝選びは出現ごとであり、先頭の行を勝者にしない。証拠がないことを拒否や保留としない。成功した読取りを実 Frame・順序付き子列・固定 target に繋ぐとき、現選定ガードと通常式の receipt を別に要求する。任意の安定選定がこの有限な支持を生む一般橋を証明したときだけ (4) 残数を減らす。
