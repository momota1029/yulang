# Cycle 280 — 位置ポートと小さな読み戻し表の台帳

固定子だけでは古い Known 判定に渡せないことを実 Display で検出したので、子ごとに固定 occurrence と裸変数の位置→元の端点の有限表を組にする。同じ子 ID が別の descriptor で現れた場合、辞書の選択を変えずに読めるよう、表を勝手に一つにまとめない。

plan の列から、実 canonical 構文順で ticket を発行する。各 ticket の lookup は exact raw Site を返す。初期 raw site と初期 centered site に、実 plan の古い順の ticket を併合すると、到達状態の raw sites、centered sites、raw edges の各リストを順序・重複込みで復元できるかを確かめる。古い順は、実 install が plans を先頭、サイトとグラフを末尾に追加するため。非到達状態の raw enqueue についてはこの式を主張しない。これができれば、将来の successor が raw lookup を使う場面と固定グラフを数える場面を分離できる。ticket 数が一般に有限という結論や、版を再利用してよい条件はまだ別。
