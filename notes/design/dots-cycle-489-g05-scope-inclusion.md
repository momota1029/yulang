# G05: 比較可能な独立 prior の診断列

C489 の補助検証。元問題・元引数・可視列を固定し、二つの independent prior に明示的な包含関係を仮定する。包含は仕様変更の権限を意味しない。各実経路の必要 prefix がすべて新しい prior に含まれるため、元の実 K2 は失われない。全 signed roster の同じ位置では ordinal は変わらず、正の bit のみ増えうる。実行側が両方成功すれば、元の K2 列は新しい K2 列の部分列で、相対的な元順は保持される。失敗を all-safe とはみなさない。独立根拠が実 compiler に由来するとは主張しない。
