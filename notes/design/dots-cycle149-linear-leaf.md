# Structural selected leaf without historical packet coverage

A successful recursive trace may select an already-committed leaf without
recording a packet. Do not require packet coverage for every selected focus.

`LinearLeafShape` stores only syntax/state witnesses: terminal declaration,
no demanded associated outputs, a recorded nominal descriptor with arbitrary
finite type-argument intervals, injective binder-name map matching declared
inputs, nominal query, actual head argument lookup, and role agreement.
For every source model, private allocation and projection follow from the
existing general linear-head theorem, while actual generated requests are empty.
This derives BranchModels without assuming it or child Evidence.

A current selected judgment supplies shared Metadata guards. Construct an
independent semantic Instance from the structural leaf, then current selection
uniqueness identifies its key and empty children. Produce the terminal payload
Evidence at the caller's unchanged assignment. This is a genuine alternative to
historical packet coverage, not unrestricted V5 or completeness of this shape.
