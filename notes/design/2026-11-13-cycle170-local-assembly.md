# Named local coverage and bounded dictionary assembly

Status: Draft proof-progress record, 2026-11-13. This records verified auxiliary
mathematics, not a change in language semantics or the V5 completion target.

## Gap and scope

Cycle169's old mixed local nodes cannot cover its concrete named-output initial
source. The new local Node has recorded, scalar, spine and named alternatives.
Every alternative is one node only: no prebuilt child trees or semantic Evidence.
The named alternative retains the actual calculated report/request observations.
Coverage supplies a node on a chosen child-closed domain, not on all demands.

The finite-journal argument extends to this local datatype. Only recorded nodes
have outgoing edges; their identities are bounded by the journal's maximum parent
identity M and every actual allocator child has strictly larger identity. Thus
rank = M + 1 - identity strictly decreases, for arbitrary covered domains.
Accessibility follows without a new Acc or finite-domain premise. Coverage itself
has not been derived from Shared Stable, Generated, or SourceFormed.

## A bounded algorithm, not merely an existential dictionary

GeneralDictionary170BoundedAssembly defines a fuel-recursive Option Payload
assembler. Zero fuel returns none. Positive fuel traverses the actual local node's
children in their exact order, recursively assembles them, and constructs the
node with that declaration key. Its List traversal fails if a child fails.

Successful output is always a NamedTree. Fuel strictly greater than the root rank
always succeeds; build uses exactly rank+1. With SourceFormed, its one computed
payload has Evidence in every current model. These quantifiers do not prove that
models exist. The concrete ternary named-output example has an explicit model,
and its build result reduces to the terminal payload by rfl, without native_decide.

The function is relative to supplied local Coverage (which may itself be chosen
noncomputably). This is not an algorithm that discovers coverage from an arbitrary
program, nor a time/memory complexity bound. The bound counts dictionary path
edges, not all nodes or saturation execution steps. A path with n edges has n+1
vertices, including its root; an empty path has length zero.

## Verified extensions in the same cycle

AssemblyPersistence proves exact Option-result equality for every common fuel
under transported Coverage. Any two successful fuels yield identical payloads;
therefore build is preserved even if the journal-derived rank ceilings differ.
AssemblySize derives B, the maximum actual packet-child-list length in the fixed
journal, and bounds the total expanded payload node count by cap(B,fuel), with
cap(B,0)=0 and cap(B,n+1)=1+B*cap(B,n). This counts duplicate subtrees separately;
it is not a runtime or memory bound for Lean or the language evaluator.

NamedSpine combines arbitrary finite nominal input spines with actual finite
named-output observations. It derives branch validity/Instance/Evidence, without
assuming these conclusions in the shape. A new inhabited example has a ternary
nominal input with three binders and a nonempty nominal named output, not the
previous scalar input. It is an InitialSource example, not a new Stable execution.

The same example has no Node of this cycle's four-alternative NamedCoverage:
its journal is empty, old scalar/spine leaves require empty outputs, and the new
scalar-named leaf requires inputNames=[], contradicted by its three binders.
Thus coverage discovery remains open and the current assembler cannot consume
this new spine leaf without a future extended node datatype. The negative fact
is not a counterexample to V5 or to semantic dictionary existence. A follow-up
should extend the local leaf interface and re-establish assembly once, rather
than accumulate ad-hoc existential exceptions.
