# Structural packet-free named-output leaf

For arbitrary registry/context/root/declaration, a terminal scalar-input shape
contains the exact source head, input/report lookup, no input binders, RootDefined,
and finite structural Observed trees for the ACTUAL generated named requests.
No Models, BranchModels, Instance, Evidence, selection, or packet assumption occurs
inside the shape. Every current source model then satisfies the full branch and
named materialization; metadata and declaration visibility yield terminal Evidence.

Unlike ScalarLeafShape/SpineLeafShape this does not require outputs=[]; the old
ternary named-output initial fixture provides a genuine nonempty-output example.
This is soundness of structural coverage, not coverage of all selected leaves or
completion of V5 evidenceNode. Existing source equations may already entail the
named output; no speculative output is invented or installed.
