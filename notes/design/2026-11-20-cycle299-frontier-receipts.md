# Compile an existing checked frontier into ordered index rows

For a supplied finite index namespace, encode each *actual* ordered child
from the independently checked frontier. A successful reverse lookup must
denote the same occurrence, not merely the same declaration key. Preserve
root receipt absence, pending, ambiguity, rejection, and a selected child
without an index as distinct results. Only the selected-complete case yields
a dictionary row. Connect this adapter to C277's existing executable
`GeneralRebaseDisplayExecutor276.localTable` and its mixed-boundary proof
`GeneralRebaseCompiledExecutor277.exact_local`. This is a validated client
of the existing scoped table, not a new exhaustive B4 observer.
