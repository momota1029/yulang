# Cycle 282 — 実履歴を展開して固定表と同居させる
固定書き先の追加は全 journal と再帰証拠から独立だと証明する。その上で実 plans の versioned entries を重複除去し、番号で厳密降下する依存を使い、型の右辺を先に評価する有限順序へコンパイルする。old Models は全履歴の定義式を満たすため、正規化 witness は同値。journal と node ごとの compiler に同じ mapping を渡すことで、各古い参照は無制約な型変数として残らない。分離した固定表は正規化後にその式を読む。各 state の有限な実 table と正確な射影を主張し、全到達族に一様な大きさの上限や、後継 compiler の全遷移を同時に主張しない。
