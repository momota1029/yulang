## 2. Proposed formation judgment and declaration identity

Use a finite declaration syntax graph with its actual binder/occurrence scope,
not a printed arrow or solved endpoint. The candidate judgment is

```text
Gamma; scope s |- FormOp(decl p, owner o, signature syntax T, clauses L)
  => Sigma_p = (identity p/o, binder telescope Q,
                payload A*, response B*, operation interface Lambda*, maps).
```

L is an ordered collection of **individual** declared contract clauses: entry
protocol, primitive observation/response constructors, typed paths, scope/receipt
and owner actions, hard equations/relations and licensed alternative clauses.
It is not a field containing B*, D_B*, P_B* or desired response preservation.
Each clause carries its source declaration occurrence and all bound/free
variables. A missing primitive clause is recorded as missing; a root ID cannot
stand for it. This is semantic source formation, not a new AST or inference test.

Proposed rules:

1. **Decl.** Read p from the actual operation declaration; o is its resolved
   declaration owner, distinct from a later use owner. Walk T/L once, register
   each actual syntax/contract occurrence, and collect declared family binders,
   local value binders and local row binders with their sorts and scopes. Rigid
   imports are references. Distinct binders sharing a spelling stay distinct;
   repeated occurrences of one binder share one coordinate. Construct each node
   by §3 and retain each L relation at its original tuple and scope. Unexplained
   contract alternatives are missing formation cases, never discarded.
2. **Outer operation.** For outer Function(payload,result), form its argument
   and result subtrees separately. B* is the result subtree's VALUE descriptor;
   response computation/effect positions remain separately indexed. The actual
   operation-emission clause belongs to the outer operation body, once. It is
   not an effect on each Function reachable in B*. Lambda* retains payload,
   emission, response/raw-suffix and all original cross-port dependencies.
3. **Use.** A separately typed use of a generalized declaration obtains one
   capture-avoiding substitution theta for Q, fixing rigid imports, and an
   occurrence map j_u from that declaration to its actual use. Apply theta
   jointly to A*, B*, Lambda*, L, K/D, path maps and every dependent predicate.
   A use of an already monomorphic instance retains its existing theta. Dynamic
   Request emission gets an event, not another static instantiation.
4. **Open.** A handler's operation-local binders open as fresh rigid kappa,
   uniformly checked under declared bounds, with actual witness theta retained
   existentially in the packet. Family equality never reconstructs local theta.
   The same theta is used by payload, response and raw continuation. No private
   equation about theta becomes a checking assumption about kappa.
5. **Restrict.** An already independently compatible event extension restricts
   evidence and substitutes current world coordinates together; immutable
   declaration, witness and provider identities remain. Current activity is
   evaluated at the new event. This action cannot establish compatibility,
   resurrect an exited owner or generalize an incident witness.

Rules 3–4 reuse only the ownership/transport scope of the October 2 instance
package §§2–4,7. They do not adopt that Draft wholesale or prove generalization.
Its finite shared-graph substitution argument gives the candidate syntactic
commutation law sigma(Sigma theta)=Sigma(sigma composed theta), preserving
imports and scopes. No solver algorithm is inferred from this equation.

## 3. Explicit descriptor constructors

The output of forming a type node is an interface expression with value,
computation, challenge, observation and incidence components. Semantic
interpretation is not computed by an endpoint solver. For a node (E,V), first
form the value descriptor V*, then the separately located computation contract
Comp(E*,V*). Returning a Function value does not execute its latent Function.

### Ground, variables and rows

- **Unit/Int/Bool/Str.** A value judgment uses its actual ground constructor and
  the unchanged registered root/current joint world. A literal certificate is
  hereditary because restrictions retain that constructor and reference; it
  contains no invented provider action. Computation Return supplies precisely
  this value at its actual output world. Pending computation observations are
  covered by the computation rules, not mistaken for ground returns.
- **Value binder alpha.** Reuse the descriptor expression at the unique scoped
  binder coordinate Q(alpha). Substitution replaces every occurrence jointly,
  including nested Function and row dependencies. This is a parameterized type
  interpretation, not a proof that an arbitrary value belongs to alpha. A
  supplied substitution must have its original sort/scope justification.
- **Concrete row member f.** Resolve the actual family declaration and retain
  its invariant family substitution, operation identities and occurrence. Its
  allowance checks an observation's outward contribution at that member; it
  grants neither receipt nor authority. A Request clause separately retains
  the complete operation-local substitution and typed payload/response/raw
  fields; row support cannot reconstruct them.
- **Row binder epsilon.** Reuse its single scoped coordinate, jointly with all
  value/profile dependencies. Multiple symbolic entries remain distinct unless
  an actual declaration equality relates them.
- **Row list.** Form the union of the declared concrete and symbolic outward
  allowances. Retain each contribution's original occurrence/provenance and the
  entire joint K/D relation; no existential choices are made independently per
  component. Equal outward sets do not merge witnesses, providers or residuals.
  Row inclusion constrains outward contributions only. Observation hard typing,
  scope, authority and dependent futures are checked separately below.

**Minimal undecided default clause C-OMIT.** For an omitted row in an operation
signature, propose the empty outward allowance at that exact computation port;
outer operation emission is the separate rule above. This is an explicit
candidate semantic choice, motivated by the current signature producer's
operation case, not authorized by that code. An omitted row on an ordinary
binding annotation has different current generation behavior and does not
inherit this choice. Its source-owned default remains a separate clause.
Explicit empty rows already form as empty lists.

C-OMIT does not assert that original omission means empty, nor narrow the
original accepted source or response domain. If any original admissible carrier
or observation at this port requires a nonempty outward allowance, C-OMIT fails
the required correspondence and must be rejected or revised by Luna. No such
original case is deleted to save this proposal. Without deciding C-OMIT (or
supplying the real original default), the ping instance below remains a
parameterized schema B*[E_in,E_out], not a completed original B.

## 4. Expanded response constructor and same-tuple projection

Fix q's actual request derivation, theta_q and candidate formed result B*.
A response record is one dependent tuple, not a product of independently chosen
fields:

```text
tau_hat = (q identity and original emission incidence,
           theta_q and joint assignment eta0/xi,
           r and actual root p_r, all retained Act(r,U,p_r) evidence,
           C_resume, actual resumed event e and joint w_e,
           actual observations/receipts at their respective events,
           eta with original residual/path/provider incidences,
           Future(r,p_r,e,eta), indexed further by each actual output tuple).
```

Historical q/emission observations stay historical. The current resume/world
fields do not restore C_y. Retaining the original payload and raw-handle
references here ties this response to that request without executing raw or
adding the saved suffix's answer A_S to B*. All previously original dependencies
of eta remain, even when not printable as an arrow.

Propose **Resp-Ground**, **Resp-Variable** and **Resp-Function** as introduction
clauses at this tuple. Ground uses §3's actual ground fact. Variable uses its
scoped substituted descriptor's corresponding introduction, with no fresh map.
Function has the following EXPANDED obligations:

1. For each actual Act(r,U,p_r) retained by this tuple, retain U's actual role,
   entry, executable operation and immutable captured references at their real
   incidences. Every alternative is checked; there is no existential provider
   chosen after seeing a challenge.
2. For every originally compatible future demand/event e' in this tuple's
   fixed domain and every d in the generated D_B* there, supply acceptance of
   d's SAME whole carrier at U's actual carrier contract and U's original live
   receipt/path/context preconditions. This does not execute receipt.
3. For each such U,e',d, EVERY actual complete, pending, administrative and
   zero-step observation of ExecuteCallable(U,d.wholeCarrier), and every
   independently admitted continuation/future development, has the P_B*(d)
   constructor evidence of §3. Neither observed failure nor divergence is
   filtered out of this quantifier. Each output's future is indexed by its own
   output provider, world and original dependent evidence.
4. Evidence restriction along an independently compatible extension is prefix
   restriction of the SAME universal family; composition/identity keep the
   original tuple and all shared witnesses. Immediate authority predicates are
   reevaluated at e', not transported as static truth from e.

These are new proposed source response-admission clauses, not an assumption
named hereditary membership and not evidence that an arbitrary runtime Function
passes them. They specify the independently needed semantic duties of typed
response introduction. Actual source checking/preservation must discharge these
duties from response constructors (or original independently licensed external
contracts); merely placing them in this Draft does not do so.

**Candidate projection derivation.** Invert Resp-Function at tau_hat. Clause 1
is contextual ValueMem's actual decomposition field; clause 2 is its ActualAdm
field at each identical checked challenge; clause 3 is its full observation
field. Clause 4 restricts that family to later compatible events. Thus the
selected contextual Function definition yields ValueMem_B*(r,p_r,e) with no
change to q,theta,r,U,p_r,e,eta,world or future. Ground projection uses the
constructor fact; variable projection follows the single substituted coordinate.
The proof is record elimination plus restriction of universal families. It does
not derive clauses 2–3 from the syntax of r or assume they always exist.

To obtain the requested projection for EVERY ORIGINAL admitted tau, the source
owner must establish a tuple-preserving translation from each original response
introduction to these clauses AND identify the generated challenge/observation
interfaces with original B's. Both directions of interface/domain correspondence
matter: reducing challenges makes candidate membership weaker; adding challenges
can reject formerly admitted responses. Keeping only translatable original tau
would be domain narrowing and is prohibited. This is the exact remaining
premise, not an optional stronger characterization or a new conditional parent.
