# Retained equations with exact compound readback (cycle 273)

A retained equation can fix a public type without proving an exact head. For
the real 238 output this distinction cannot be erased: the optional field
is the union of an exact-empty and a nonempty record, not a canonical tree.
A single full-model readback is not enough for all-model statements.

1. A partial expression interpreter substitutes only known semantic type
   representatives. It keeps joins and open record tails literally; finite
   canonical trees form an optional source of representatives, not the
   codomain. It returns none when a type read is unknown. Under pointwise
   semantic agreement of available representatives it returns equivalent
   values. Nominal arguments must read actual mode, not the surrounding mode.
2. A retained-plan interpreter uses the original equation's mode and target.
   Its result is equivalent to the original model's value for every valid
   full model of the original journal. It must never force an unknown
   equation into a head fact or regenerate models.
3. Test on the actual first Step of cycle 238: retain the exact optional
   union, and show it excludes every normalized inspection head and is
   incompatible with an existing initial width assignment. This gives a
   direct test for any finite successor purporting to preserve public models:
   treating output 4 as width, as exact-empty, or as observationally unchanged
   across the actual install is incorrect. The witness should keep the
   emitted choice and explicitly say which constraints are quantified.
4. Use Step installation monotonicity for transport only after checking the
   boundary. A projection-preserving replacement should preserve the
   after-state's joint public models, not equate them to the before-state's
   models or produce separate witnesses for mutually dependent outputs.

## Reobserve: ownership of generated child coordinates

The genuine 238 point state keeps the historical lower child output. Its
current packet requests the same generated name with a different compound
value. It is not enough to rename the two capture aggregate slots: the
old and new child-low equations conflict when conjoined. Test a restricted
replacement that overwrites only the generated child's lower type and
retains the five original source types and every row. Prove that this
coordinate is absent from the current head-read support, that the current
emitted and child schemas then hold jointly, and that the historical packet
does not generally survive that overwrite. The resulting restricted
replacement is not a proof of general original-journal equivalence or of
evidence for an unlocated child. Do not silently classify a generated child
that is itself observable as an original input/output coordinate.
