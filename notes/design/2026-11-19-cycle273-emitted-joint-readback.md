# Retained equations with exact compound readback (cycle 273)

A retained equation can fix a public type without proving an exact head. For
the real 238 output this distinction cannot be erased: the optional field
is the union of an exact-empty and a nonempty record, not a canonical tree.
A single full-model readback is not enough for all-model statements.

1. A partial expression interpreter substitutes only known semantic type
   representatives. It keeps joins and open record tails literally; finite
   canonical trees form an optional source of representatives, not the
   codomain. It returns none when a type read is unknown. Under pointwise
   semantic agreement of available representatives it returns equivalent
   values. Nominal arguments must read actual mode, not the surrounding mode.
2. A retained-plan interpreter uses the original equation's mode and target.
   Its result is equivalent to the original model's value for every valid
   full model of the original journal. It must never force an unknown
   equation into a head fact or regenerate models.
3. Test on the actual first Step of cycle 238: retain the exact optional
   union, and show it excludes every normalized inspection head and is
   incompatible with an existing initial width assignment. This gives a
   direct test for any finite successor purporting to preserve public models:
   treating output 4 as width, as exact-empty, or as observationally unchanged
   across the actual install is incorrect. The witness should keep the
   emitted choice and explicitly say which constraints are quantified.
4. Use Step installation monotonicity for transport only after checking the
   boundary. A projection-preserving replacement should preserve the
   after-state's joint public models, not equate them to the before-state's
   models or produce separate witnesses for mutually dependent outputs.

## Reobserve: ownership of generated child coordinates

The genuine 238 point state keeps the historical lower child output. Its
current packet requests the same generated name with a different compound
value. It is not enough to rename the two capture aggregate slots: the
old and new child-low equations conflict when conjoined. Test a restricted
replacement that overwrites only the generated child's lower type and
retains the five original source types and every row. Prove that this
coordinate is absent from the current head-read support, that the current
emitted and child schemas then hold jointly, and that the historical packet
does not generally survive that overwrite. The resulting restricted
replacement is not a proof of general original-journal equivalence or of
evidence for an unlocated child. Do not silently classify a generated child
that is itself observable as an original input/output coordinate.

## Finite owner block for this checked case

Use one owner identity and five typed field addresses: lower/upper capture,
lower/upper generated child, and actual generated child center. The two
actual binding lists consist of identical pairs of endpoints. Restrict a
small compiler to input name 0 with two equal binding triples over source
slots 0..4, a checked actual center premise, and the known single child
schema. Replace the repeated lower union and upper intersection by their
singleton supporting source under the respective lattice laws. For the
actual case the observed center has the width at source 2, so the child
center refers to that public type semantically; it is not an arbitrary
alias of the upper in generic code.

The finite state machine consumes these actual observations and replaces
the sole owner's block in place. It has three states (uninstalled, loose,
point), matching the selected source's strict installation and its first
Reobserve-plus-replacement, not arbitrary engine scheduling. It must
retain the real optional body fact for output 4 in both installed states
and use the fresh bounded projection proof above. A generated child's
lower type, if retained as a public observation, cannot be preserved.

## What the paired witnesses do and do not justify

The restricted compiler is exact before/after on source identities 0..4
and every row. It is not correct to replace the installed journal by an
arbitrary raw model and five individually proved equations: use a single
joint extension, supplied here by the fixed canonical completion. At the
point phase we can choose old and replacement extensions differing in only
the lower generated child's type. The current packet's fresh aggregate
coordinates are already populated in that chosen old extension; a general
existing full assignment need not already have those private values.

For a future generalization, the owner compiler should explicitly separate:
(a) types that public requests or possibly other owners read, (b) private
type coordinates whose values can change, and (c) row coordinates, none of
which may change here. A reuse certificate should prove that removing the
superseded equation affects neither the live dependency support of other
owners nor the public projection. The 238 lower child rules out a support
test based only on the owner key or on unchanged generated identity:
that lower cell has unchanged address but incompatible old/new types.
Conversely the versioned upper aggregate changes its physical address but
its logical value is preserved. The case is a regression test for both
directions of any proposed escape certificate.

A correctly registered child is a separate obligation. In 238 its two
bound names are present in journal sources but absent from the actual base
slot map. They still need distinct addresses even when the types become
equivalent at point. Adding addresses alone would not make this fixture a
positive recursive-evidence example: the required child has variant head,
whereas the only declaration has the nominal head. A positive continuation
for EvidenceNode will need another source fixture with a genuinely matching
child and a checked registration/refinement; an old kernel EvidenceNode
claim must not fill the gap from this parent's local certificate.
