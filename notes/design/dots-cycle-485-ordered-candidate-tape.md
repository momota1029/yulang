# C485 G05: 選択前の全候補 tape

I-98 では G04 は `G04Entry` を未証明の命題としてここに残し、G05 の仕事と分ける。G04 の単一可視候補の前提を満たすために、G05 の元の可視一覧を絞り直してはいけない。

選択前の exact tape は、不変の元 request から取得した **可視宣言の一覧そのもの** と同じ順序・長さを持つ。位置と宣言は物理位置で照合し、同じ ID または同じ型でも別位置を一つに潰さない。各位置は別途与えられた candidate-local 規則で判断し、訪問した候補の正負は、その実際の統一グラフの選択位置に関する既存入力規則で裏づける。訪問証拠の無い候補を false や不一致として扱わない。candidate-local 検査が none なら tape を検証できないだけで、言語規則の否定ではない。

まず一つの finite wire と exact-order replay を独立仕様と照合する。真の K2 を含む全 tape は election の前に signed rejection を返し、全項の K2-negative を検証したときだけ後段の election を許す。生存候補の一般的な match/mismatch/defer は G10、一般再帰要求は既存入口に残す。K2 があるかどうかの不変性と、複数の真がある場合の特定の報告位置を混同しない。今回の検査は一つの具体的な election policy を新設しない。
