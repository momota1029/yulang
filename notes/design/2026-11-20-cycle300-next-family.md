# What would generalize the real two-install example?

C300 ends the three-slot fixture without a hand-supplied installability
proof. It does not settle an arbitrary V8 source. A sensible next
regression is the ground, output-free Display ladder, with an arbitrary
but fixed number of observed nominal links and one known scalar leaf.
The relevant invariants are not a single termination counter:

1. **Raw source:** define the ordered slot spine and its model towers
   independently of the compiler. Start from a genuine ground initial
   state. Do not reuse the older `GeneralNominalPeelingSources.source`
   as a proof that the leaf head is already known: that family has a
   terminal scalar equation, which is not the same as an observed
   normalized scalar head. Either construct an observed-leaf family or
   prove an actual terminal refresh, with its strict unknown→known guard.
2. **Current journal:** after an install the registered raw and center
   rows are exactly the visited spine prefix. Give ownership of the
   reserved keys per actual occurrence. As ordinary equations are added,
   use `GeneralDepthTwoFrameCarry300.frame_carried` with both existing keys
   and new keys, and supply the new model witness; do not replace the
   source with its earlier snapshot. Keep all where occurrences, even
   if every recursive node uses implementation key 1.
3. **Reader versus raw stopping:** the selected graph rank follows the
   observed list/where descent when the observer and frame evidence cover
   all rows. It cannot count silent raw changes. To prove raw closure
   for this family, factor the present no-extra-event argument:
   point-normalization excludes reobserve, every untracked reservation
   admits headless padding in one common model, unrelated center names
   are separable, and recorded current effects are committed. If another
   source violates any hypothesis, only the independent observer/the
   checked reader result survives.

No new source syntax, scheduler assumption, or Rust result is proposed.
