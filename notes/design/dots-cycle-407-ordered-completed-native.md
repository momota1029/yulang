# C407: 元の可視順の単項 native 候補を全件検査

I-72/I-67。元の固定定理・C380 の形は変えない。C406 の actual completed lower と spec/06-roles.md §6.3（未完了出力は頭の根拠だけに使わない、raw K2 は先、実際に調べる位置の K2）を使う。

候補の根を可視リストの添字で順に辿り、各添字を元レジストリ添字に引き戻す。既にある有限 producer の元の型つき出力と固定式をそのまま参照し、declared 単項の別名について型構文から真正な不一致を出す。変数の child では constructor を見ない。未完了の出力しか根拠がない場合、型を読んだことにせず、raw root K2 はフィルタしない。入力名の欠落は新しい pending 規則にしない。一意選択で既知の同名候補を除くために不足した比較を不一致にしない。

狙う命題: 完全な可視走査と全候補の元の登録位置から、同じ State の completed 元下端を見た検査だけと、実構文に基づく不一致・一意の生存（条件を明記）を得る。そこから、元の実入力名・B6 出力・where forest がある場合のみ辞書に合成する。全言語の Classifies や網羅性をこの断片の主張にしない。
