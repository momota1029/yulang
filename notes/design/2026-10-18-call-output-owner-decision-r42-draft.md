## 3. Finite dependency-sensitive strategy model

**Design discriminator only; not a source-qualified counterexample.** Let
H=P=A={0,1}. Fix all earlier inputs. h is an inherited-challenge proxy and p
is a later-provider proxy; in this model both range independently over all
bits. The output-description proxy a is a mathematical choice. These bits
are not proposed Yulang types, admitted challenges or actual returned
providers. In particular, the actual source return may have dependent or
existential fields; this model supplies no identification with its binder.

An allowed strategy depends only on the named preceding inputs. Embed each
class into the common function set `A^(H x P)` by ignoring unavailable inputs:

| Order of model inputs and choice | Embedded strategies | Count |
| --- | --- | --- |
| choose a; input h; input p | `C={f(h,p)=c : c in A}` | 2 |
| input h; choose a(h); input p | `J={f(h,p)=g(h) : g:H->A}` | 4 |
| input p; choose a(p); input h | `L={f(h,p)=k(p) : k:P->A}` | 4 |
| input h; input p; choose a(h,p) | `F={f:H x P->A}` | 16 |

The counts follow by choosing one bit for each available input tuple: one,
two, two and four independent entries. Thus `C` is a strict subset of J and
L; J and L are strict subsets of F; and `J intersect L=C`. For the last
equality, a function independent of p and also independent of h has the same
value on all four inputs. The witnesses `f(h,p)=h` and `f(h,p)=p` show that
J and L are incomparable.

The two required order distinctions follow without swapping independent
inputs in a single comparison:

* **Before versus after inherited challenge:** compare C's
  `choose a; input h; input p` with J's
  `input h; choose a(h); input p`. The obligation `a=h` for every h,p has no
  C strategy and has J strategy `g(h)=h`. Equivalently
  `exists a. forall h,p. a=h` is false, while
  `forall h. exists a. forall p. a=h` is true.
* **Before versus after later provider:** compare J's
  `input h; choose a(h); input p` with F's
  `input h; input p; choose a(h,p)`. The obligation `a=p` for every h,p has
  no J strategy: fixing either h would require its one output to be both 0
  and 1. F has `f(h,p)=p`. Equivalently
  `forall h. exists a. forall p. a=p` is false, while
  `forall h,p. exists a. a=p` is true.

If two proposed placement policies instead allow just h or just p, J and L
have no general inclusion in either direction. A late placement is therefore
not uniformly “more general” when it also loses a different dependency.

There is a useful projection trap. For **each** of C,J,L,F, the union of the
graphs of its strategies is all eight triples `(h,p,a)`: the two constant
strategies alone realize both a values at every particular input pair. Thus
pointwise existential endpoint solving can report the same projected tuples
while uniform strategy sets differ. The separating obligations above ask for
one strategy to satisfy every admitted input, not separate choices for each
already observed tuple.

Application to q is conditional only on a future identification of its actual
scoped inputs: a JOF cursor containing inherited h and excluding later p
would have J's **dependency pattern**, not an asserted count of four actual
source typings. Authentic source constraints, original effect/header laws,
W/Z alternatives and provider correlations may restrict or relate the
available strategies. A genuine source difference would require an original
typed source derivation/client and one missing or added **complete** fiber
under the actual quantifier tree. No such witness is provided here. “Choose”
in the model describes semantic strategies, not speculative inference or a
proposal to solve constraints while generating them.
