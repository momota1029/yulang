The strongest structural dictionary rule is now `GeneralDictionaryTreeCoverage`.
It keeps the existing general Classify and Evidence unchanged. A generated
selected node has an actual historical packet with ordinary context growth,
a finite binary nominal Tree leaf, or a scalar leaf. The Tree contains only
source lookup/syntax, not an assumed semantic branch.

Seven theorems compose this with the general recursive dictionary:
selected_instance, dictionary_evidence, dictionaries_evidence, of_branch,
recursive_fixture, of_trace, initial_dictionary_evidence.
The same arbitrary current model is held fixed through all recursion.
`of_branch` embeds earlier spine/single-fork certificates without a new premise.
`of_trace` derives historical growth from any finite actual ordinary empty-journal
trace; it does not assume per-packet Extension.

Tree depth, number of binary forks and total distinct binders are arbitrary finite.
Internal edges are point; binder names globally injective; declaration terminal
and demand outputs empty. Leaf binder intervals can be nonpoint. N-ary internal
branching above2, repeated binders and arbitrary reachable selected-focus coverage
are not established by this module. Finite Classify evidence remains an input,
not a proof of executor termination. General V5 remains6/14 supplied,8/14 open.

prior single-Fork query class. It demonstrates strictly broader structural scope,
not an assertion that this raw fixture is reachable/stable.
