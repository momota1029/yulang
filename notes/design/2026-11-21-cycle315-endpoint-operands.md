# C315: effective operand readback of protected where equations

For a selected actual same-owner revisit, separate the allocation of an
endpoint row from its current value. C314 proves the row has already been
generated with that address, code, and mode. First discharge any effective
operand whose actual binder gives both endpoints, using the checked common
model and history rather than equality of raw IDs. Then test whether point
or semantic-equivalence readback is forced by real inspections across
history. If it is not, the target is existence of one full current model
satisfying old and current endpoint equations, not identification of all raw
intervals. No change to program acceptance or termination goal.
