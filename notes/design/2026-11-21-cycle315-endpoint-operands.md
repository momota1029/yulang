# C315: effective operand readback of protected where equations

For a selected actual same-owner revisit, separate the allocation of an
endpoint row from its current value. C314 proves the row has already been
generated with that address, code, and mode. First discharge any effective
operand whose actual binder gives both endpoints, using the checked common
model and history rather than equality of raw IDs. Then test whether point
or semantic-equivalence readback is forced by real inspections across
history. If it is not, the target is existence of one full current model
satisfying old and current endpoint equations, not identification of all raw
intervals. No change to program acceptance or termination goal.

## Why a larger linear proof on the old address cannot work

The existing compound trace installs a lower leaf value at a stable
clause/index cell, then soundly reobserves nominal arguments with a
strictly stronger lower endpoint. The source input's actual value and
associated output are unchanged. The old lower row cannot be overwritten
in its live models. The C314 contract asked for operand agreement even in
this dead-child state. Do not solve that false contract, and do not infer
a failure of the recursive theorem when its child premise is impossible.

At the real recursive node, replace the required input by protected
endpoint equations in one full head/class model, only when the same-model
ordered child evidence exists. This requires no equality of all operands
and gives the exact existential residual. For a representation study,
a distinct internal endpoint address would additionally distinguish the
actual ordered read IDs of the compiled expression. Reuse would then
force identical whole RHS under any common assignment; the current source
reachability relation, stable child identity contract, and old committed
child demand must still be connected before this could replace any source
semantics. No representation or language rule is changed here.
