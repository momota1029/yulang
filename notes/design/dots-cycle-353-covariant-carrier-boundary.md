# C353 proof boundary: declared covariant Box root and ordinary child scopes

The original inference carrier stores invariant nominal heads, and source metadata classifies a constructor as primitive, invariant, or unclassified. A declared covariant value parameter cannot be implemented by changing the interpretation flag to invariant. The raw root's legacy coverage fails even on this concrete input. C353 deliberately leaves that carrier and the old normalizer untouched.

## Actual data and proof chain

1. Constructor declaration and snapshot are reassembled from the fixed source, checked at the same exact key with one value argument. A separately authored (kind=value, variance=covariant) row must exist. No constructor fallback participates. Typed current rows are parsed from independent literal written source, preserving exact original ordinals.
2. The accepted written head remains two same-tag Box arms originally. The scoped normalizer checks their common constructor; the actual proof of strict raw descent covers either underlying binder through arbitrary substitutions, including the equal-substitution collapse. The specialized declaration certificate does not pretend the generic original residual-join CountsCovered guard succeeded.
3. A typed source row at the actual demand center names the ordinary payload. The original ordinary state contains the literal join of the two actual arm value names. Both named suffixes get that complete payload and the shared ordinary center. Explicit nonpoint endpoints carry independent declared covariant comparisons, checked by actual ordinary path coordinates transported to the Common projection. The normal body compiler uses the original demand.
4. The ordinary child scope is exactly the original source with the parent covariant role removed (same tables and roles, all other declarations retained). Existing C352 checker handles the genuine compiler-emitted child requests at their exact ordered scope/paths. The main written nonpoint fixture yields 92[93,94] plus original ordered fixed targets 5/6 in one explicitly exhibited satisfying model.
5. For any ordinary model, typed valuation is constructed from the exact distinct written source rows and that same assignment. Other compatible typed valuations can only differ up to Common equivalence at those rows. Children, fixed targets, outputs and both original captures are still justified in the unmodified ordinary assignment.

## Unsupported boundary

The typed root extension uses first-order declared Box heads interpreted over Common projections; it is not a general new recursive value carrier and does not classify the root under C334 or C337. Erasure distinguishes the embedded Common fragment exactly but may equate two distinct richer nominal payloads. Scope failures and incorrect certificates do not denote language rejection. There is no old Local, raw stopping/release correctness or generalized producer claim here.

A useful next proof is one author-backed nominal-valued associated output in the declared carrier, with the exact output ordinal linked to an independently checked later nominal child. That requires an actual typed output occurrence and a carrier-preserving valuation/receipt, not an equivalence inferred from the current ordinary erasure. Continue to keep declaration checks and finite positive evidence separate from completeness.
