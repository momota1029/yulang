# C433: 受理から元の関連型の意味への逆引き

元の public `check p r (.associatedWrap data) = true` に対し、その **実際に使われた一つのデータ読取結果** を戻す。元の clause 0 と独立な selected Event、元の順の全書き込み、元の子の固定ターゲットを同じ State の中で取り出す。

同じ適合モデルごとに、親の元 B6 RHS の実際の評価が `list(child-assignment)` になること、子と親それぞれの関連型辞書と固定出力が意味を持つこと、選んだ元の親/子根に raw K2 がないことを証明する。モデルから元位置を逆算せず、二つの成果値の数値が一致することを住所の証拠にしない。これは C16 の同じ既存 public route の補強であり、受理を広げない。
