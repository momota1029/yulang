# C484: 独立な入力事象と exact signed report

C483 の二つの経路を、元の `TypedInput` と independently checked `PriorPhase.ExactFor` の両方に固定する。一つの物理状態・同じ原位置・型 Fits があっても、出所は report から復元しない。元 raw 型読みと元 source 支持あるいは完了 association／release を別々に確かめる。有限の選択済み action と raw ordinals に沿って、old Trail と相の証拠を照合する。完了 branch の計算用 view は、各元 source 行と実 released owner を区別する。

まず既存の全 route から絶対に変わらない元事象 report とコンポーネント再生の条件を確かめる。その上で、一つの unchanged fitting fixture に対して、source と release を別々の独立な事象として構築する。両者は同一 report でも別の先行証拠。各 selected child の old card/old slot、完了の元 version と grant、root safety は別条件として残す。任意の raw から根拠を推測しない。グローバルな FlatReport、旧 State、spec、既存 Lean には手を加えず、削除も行わない。
