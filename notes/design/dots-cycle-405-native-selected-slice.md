# C405: 非空の具体化のための unary authored native 分岐

C405 の変数 head では exact 訪問列が空になる。入れ子に入った K2 は別に証明した。
既存 C365 の型で完結する正の構造例として、同じ State の authored mode window と
unary `K 'a`（子は変数）だけを対象にする。既存の native `DeepRead` を明示した head
と元の宣言位置を使い、設ける訪問列は第一 lower 根だけ。子の変数位置は検査でない。
既知の根で K2 なら旧 raw 規則優先。実際に表せる一候補・一引数の本物の樹を使う。
同じ events/where の意味を持つ辞書へ出す。中心名の供給は選択条件とせず、
この証明で実際に観測済みの場合だけの readback とする。取れないケースは拒否しない。

完了済み出力が lower の場合は旧 C365 `SourceHead` の制約が残るので、この試みでは
それを authored Origin に変換しない。本文・固定先の一般的な根拠は別義務。
