# C456 / G04: 元の由来を持つ混在 field 経路

C455 では各 proper prefix を閉 record に限った。G04 の次の対象は同じ FullProblem・同じ選択候補・同じ著者側 pattern の上で、record field と variant/pair 引数を実際に交互に辿る局所 K2。nominal body、open tail、完了 origin を推測しない。

- 独立した判断: 各 proper prefix で元の論理位置から実 raw owner への経路、選んだ author occurrence、および実際の field/引数の位置を求める。終点のみ raw K2 で、終点に開口の権限は要求しない。終点は実 record field のままとする。
- データ: 元の行／source occurrence の番号、alias witness、子の種別と元位置、各 proper prefix の finite escape と終点の raw cycle witness。報告は実際に入った全経路を保持する。
- 目標: ∀ p r, 独立した局所導出 ↔ 有限 wire が exact r を通す。∀ 同じ FitsFull、実 source trace の健全性。旧 C455 canonical witness の Bool は全入力で不変。
- 実例: record→variant→record→field K2、および pair の実位置。raw のみ、issuer 違い、tag 違い、未訪問の循環、置換経路を通さない。既存の ConservativeSmaller 不足と native nominal opening は別に点検。G04 全域の完了とはみなさない。
