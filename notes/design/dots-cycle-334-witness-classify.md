# C334 I-60 の証人つき宣言的分類

節点の証人を独立に分ける: 現在使える supported 下端と端点での候補選定、実中心の supported named / inline 読取りまたは supported 区間射影、通常 head の組立、選定後の I-58 等式を含む実コンパイラの順序付き子列と固定 target、現在の同名 ordinary receipt。予約名が別の普通の source slice から来る場合も、そこでの普通行と利用可能な支持行の両方が現在へ入ることを検査する。この slice に solver の履歴・slot は入れない。

証人に Meaning、Evidence、コンパイラ Frame を仮定しない。子の診断木を別に保持し、checked/covered な registry と一つの任意の現在モデルで同じ Evidence に帰納する。旧 Local との双方向対応は (4) の仮定にしない。未知は現行の保留範囲を保ち、選定後の共有を見失っただけでは保留にしない。I-59 の根 K2 は展開せず別の具体的拒否理由のままとする。
