# Next B4 observer proof: beyond the current-head quotient

C304 proves an exact quotient for every actual deferred-ladder schedule and a
general B4 diagnosis transport theorem under a current-head/slice contract.
It does not prove that the full normalized recursive report of an arbitrary
source is invariant under every mutually refining context, or that a finite
procedure decides its full-carrier model tests.

1. **Exact slot report transport.** Introduce an explicitly stronger input
   relation than mutual refinement: slot maps are inverse as in
   `GeneralNominalTotalLocation304.roundtrip`, source and row identifiers
   commute, recursive query interpretation is identical, and each normalized
   observation/deferred reason commutes with the slot maps (including the
   shape argument map for arrows, products, records, and variants).
   Do not require the entire shape catalogue to have the same size; unused
   shape entries need not occur in any reachable observation.
   Induct on the existing report trace/fuel, transporting inspected pairs,
   blockers, conflicts and captured intervals before erasing slot indices.
   Establish the displayed `arguments_total` equation separately, including
   failed lookup. The two-slot swap fixture and unused-record widening are
   first regression cases.
2. **Allocator and model-test footprint.** Once erased reports agree,
   prove the exact same source support of reserved/allocated keys and
   constraints. Derive Fresh in both directions from support/ownership and
   retain distinction between a finite tested support and decidability of
   a complete carrier model there. C279–281's rejected-assignment witnesses
   should be applied to the actual generated chart, not to a postulated
   finite set that merely contains the answers.
3. **New output requests.** C304 preserves the slice under installation
   with unchanged class-request membership, which includes a real explicit
   output install eliminating a model. Truly new emitted requests may
   activate stored effect bodies. Extend `class_after` with an explicit
   old/new request difference: prove alias-class membership and equivalence
   of each historical effect's body obligations on the newly exposed
   target, or give a reachable counterexample. Whole Models agreement
   cannot replace positive/negative feasibility of slices.

No Rust parser witness is required for these steps. The finite source
control graph is evidence for a useful fragment, not a proof of full B4
totality, general raw termination, or source-wide EvidenceNode.
