# Source-derived saturation to scalar registry classification

Status: Draft. Scope: I-16 P1/P2. Reduce `frontierLocal` and `evidenceNode` on
states computed by the existing named ordinary/associated closure. This extends
the new registry classifier beyond externally supplied snapshots; it does not
change the existing closure, associated semantics, or scalar materializer.

Use the existing structural associated program, named ordinary inequalities,
checked associated environment, and computed finite allocation. The root is an
original source name. A finite lookup computes its allocated receiver slot;
missing names remain adapter failure. Execute the existing mixed closure, then
the real ordinary solver/materializer and scalar registry dictionary elaborator.
The independent classifier uses `CommonRoleNamedOrdinaryInputs.Derives` on the
original name and declaration-origin candidates. It contains no executor result,
allocated slot, completed model, or caller-supplied evidence.

Prove exact classification iff named source models and the independent source
classification, on the computed source-name domain. Prove every returned leaf
dictionary sound for every original named valuation satisfying ordinary input
and all independently derived associated facts. Visible-set equality must retain
the exact returned dictionary. A second invariant should transport original
input reordering/duplication despite changes to allocation.

Limits: the associated environment's existing well-formedness proofs remain
inputs. Program lowering, general structural materialization, effects, where
children of the final scalar registry, and the full B4 target remain outside.
This is not a resolution-completeness claim for unsupported bool/unit evidence.

The final scalar registry and the associated-declaration environment are separate
inputs to this adapter. Their agreement as one language-visible source registry
has not been established. All-model soundness is for the named source model
predicate and the supplied final scalar entries, not method-body semantics or
an end-to-end parser/module-visibility theorem.
