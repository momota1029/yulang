# C451 / G03: 原 where の同入力 raw 証拠と位置

spec §6.3 L231, L383 と §6.5 K2 の原入力を分離する。原 where literal の位置と実 role/point は選択元の宣言と捕捉だけから得る。現在の ordinary graph の flat Alias と双方向 Bound は、「同じ実入力」の証拠として十分な独立経路。証拠不足や raw 非 Alias は言語の非併合／拒否にしない。
実位置の role/point から有限の同値類証拠を読んで、各実位置で raw K2 を個別反映する。証人が要求や代表や結果を選ばない。同じ raw Alias 類での K2 の不変性と、逆にモデル値同値だけでは不変でないことを分ける。全原位置・全取り出した対象を保存し、選択済み実 Event の原 clause から論理 request の位置を照合する。
出力付き併合、一般の等式 entailment、同値類の表示と実際の solver の canonical representative 方針は別。必要なら仕様に観測可能な判断を質問ノートへ分離する。C450 累積判定の動作は変えない。
