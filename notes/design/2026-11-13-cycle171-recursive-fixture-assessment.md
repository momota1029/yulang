# Recursive named-spine fixture assessment

Status: Draft proof assessment, 2026-11-13. No new operational trace is claimed.

The compiled `GeneralDictionary171RecursiveStrictness.recorded_parent_strict`
is a generic two-level graft. It retains real packet membership, current
`Relocates`, exactly one emitted child, the child's structural NamedSpine.Shape,
the old local-node obstruction, SourceFormed, one current model and current
parent selection. It constructs a new recursive tree and one payload's Evidence
in every current model; selected-child decomposition excludes every old tree.
These premises are not claimed inhabited by the new initial leaf fixture.

The actual initial source in `GeneralDictionary170NamedSpineExample` is
Shared-stable with an empty journal. Cycle171 covers it and proves that no old
NamedTree exists there, but it is still a zero-step terminal example.

Two existing nonterminal fixtures do not fill this remaining concrete bridge:

- `GeneralDictionarySharedRecursiveExample.nonvacuous_recursive_dictionary`
  has an actual one-step Shared installation, a recorded Display parent and a
  scalar Display child. Its child has no named output and does not exercise the
  new nominal-input/named-output constructor. Relabeling this as the new example
  would hide the structural difference.
- `GeneralDictionaryNonterminalNamedExample.positive_nonterminal` has two
  named actual-mode requests and private BranchModels through a nonpoint
  capture collapse. Its stated scope deliberately excludes child Evidence,
  operational output installation and certified revision. It cannot supply the
  recorded packet and child source observations required by the graft theorem.

A concrete nonzero-step example needs a nested nominal source snapshot where
an installed outer declaration emits an inner nominal child with an observed
named output. Independently prove declaration checkedness, actual emitted child
identities, the I26 generation/input guards, initial source formation, an
inhabited post-install current model, current packet relocation, and the child's
exact observed Shape. None follows merely from the existence of semantic
BranchModels or the initial terminal Shape. No semantic choice is needed, but
these are substantive proof obligations rather than a constructor invocation.
