# Cycle250: arbitrary materialized metadata congruence

Status: Draft proof plan. B4 StepModels/EvidenceNode support; I47(a).

249's Materialized provenance was sufficient for semantic recovery, but made
metadata insertion awkward. Prove the actual field definitions congruent under
pointwise mutual type subtyping and literal row equality, for EVERY finite
Journal243 value, not just a compile/subst provenance. Observational witnesses
must be transported up to equivalence, not assumed literally equal: the source
case of Origin.Observes records the evaluated type itself. Nominal/structural
projection witnesses can then retain their actual argument list.

Proof chain: raw View parameters/descriptors; expression Origin; projection;
requirements/use/schema; total Expr/Equation; packet including all eight fields;
observed/class/effect; Journal conjunction. New frame theorems derive recovery
from this proved congruence, not a new assumed law. This enables arbitrary actual
metadata addition before rebase, with its constraints on the SAME assignment.
Adding metadata may reduce models and must never be described as preserving the
unaugmented frame automatically. Source insertion eligibility is still separate.
