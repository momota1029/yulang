## Semantic representation cut

Keep the assignment and authored values unchanged, and set `nativeSyntax L := none` while leaving all other slots unchanged. Thus the hypothetical stronger semantic conclusion that *all* fitting models contain `nativeSyntax L = some …` is false whenever the state has a fit. Do not fill this field by model equality or by injecting a new Origin.
