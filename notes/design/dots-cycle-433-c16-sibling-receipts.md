# C433: 二つの実 where 子が同じ名前つき出力先を使う

既存 R15 の公開入口でそれぞれ成功する実 Container / sibling の二つの元の子を、同じ State の元の where clause 0 / 1 に付ける。元の匿名入力はどちらも `a`、名前つき出力はそれぞれ `item` と別の `seen` でともに元の固定 slot 4。元の `b` を匿名入力へ変更していない。親は固定 output 12 に `list` of slot 4 を評価する。書き込みの順は親の元 receipt、child 0、child 1。両方を満たす実モデルを構成した。

一般補題 `selected_named_sibling_replays_same_fixed_target433` は、任意の既存局所健全性法と**実際に選択された元の親 trace** の下で、別の出現の二つの元の名前つき出力が同じ住所を持ち、各適合モデルで値が同値であることを与える。親子 trace を仮作成しない。二子ローカル試験は独立で、現行公開 R16 の受理範囲を変更しない。兄弟がどの順で solver によって安定するか、保留時にどう進めるかは証明していない。
