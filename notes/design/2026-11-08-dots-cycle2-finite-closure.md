# Finite closure for the actual structural producer

Data: checked Registry and actual Request. Executable children are extracted
from the actual producer frontier's selected case, with no separately supplied
enumeration or fuel. Build a finite list by recursive unfolding of those children.
The existing declaration-check-derived two-endpoint measure justifies recursion.

Independent judgment Reach has a reflexive rule and a producer Child step.
Target theorem: for every checked registry/root/target, target belongs to the
computed list iff Reach root target. Consequence: every actual reachable child
has an occurrence in an endpoint table collected from this computed list.

Scope: exact for the existing structural dual-inspection producer only. It does
not cover future children introduced by ordinary-state narrowing or saturation.
