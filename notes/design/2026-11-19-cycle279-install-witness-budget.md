# Two consumable finite budgets for successor installs

A full-model loss is not enough by itself for a finite measure: the old 239 family loses a different private full model every round. A fresh child edge is also not enough without a fixed finite vocabulary. Use one fixed list with tagged facts: `recorded full edge` or `specified full assignment is no longer a model`. Both are monotone along the actual mixed Step; the second counts negative information and is semantic, not decidable. Each real install must consume a listed fact, justified by a finite compiler/source witness lemma. Administrative moves never increase the residual rank.

This gives a precise sufficient interface for the existing installation-descent and bounded-trace theorems. It is not the missing proof of such coverage for arbitrary source. Test the proof criterion on the real graph-only Display→Int step and show where the actual 239 repetition prevents a certificate for the old kernel.
