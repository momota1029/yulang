# Remove the globally equal row assumption

The exact symbolic journal/program has finite type and row dependencies.
Do not read every row or combine types and rows by untagged numeric index.
The old typed-support lemmas assumed global equality of all row values.
Add complementary row-local lemmas with globally equal type values, then
compare arbitrary models via the intermediate assignment using first
model's types and second model's rows. Use the existing local term/effect
evaluators, retaining nominal descriptor .row parameters, arrow input and
output effects, capture/observed/child/schema data, historical/live bodies,
and paired merge terms.

For every symbolic question and every pair of assignments agreeing on its
typed footprint, the truth values agree. Thus full source Models and
positive/negative existential questions can be evaluated on an independent
finite two-column copy of all read coordinates and arbitrary fallback
outside that footprint. This is an exact finite-dimensional reduction, not
finite cardinality of the value or row carriers or a decision procedure.
Keep prior raw history separate from candidate-only reads on already
certified prior models.
