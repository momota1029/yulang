# From finite local answers to a selected node: remaining obligation

The signed finite observer is local to a raw source. Its exact footprint and
ordered scan do not construct a source-current effect for every selection.
In particular, the finite-window choice is not a strategy for proving existence
of a current effect or ending a silent path.

1. Keep the next statement at the existing interface
   `GeneralNominalVersionedMixedEvidenceReduction235.InhabitedAvailable roles`:
   for each checked registry, reachable state, saturation root, stable selected
   focus in the generated closure, and proof that the state has some model,
   construct `GeneralNominalVersionedMixedCurrentCandidate235.Current` for the
   selected focus. The required witness carries the precise encoded registry,
   current snapshot, occurrence, materialized schema, choice compatibility,
   position safety, alternative safety, and a shared installation model.
   Reachability supplies the cache and selection supplies its own safety via
   `source_installable`; the Boolean observer alone supplies neither novelty
   nor all these witnesses.
2. For the first actual closure test, replay through
   `GeneralRebaseCompiledInstall277.reachable` and use
   `GeneralRebaseCompiledSelection277.picked_child` together with
   `GeneralRebasePackedNonleaf298.model_and_tree_packed`. Verify whether the
   child's current candidate can be certified in the post-parent snapshot
   independent of an extra install. If a separate raw child install is the
   requested test, first prove the scoped non-commitment needed by the raw
   guard. `GeneralRebaseDisplayStable276.committed_child` is evidence against
   assuming a separate step in the corresponding uncompiled fixture; it is
   not a checked obstruction for every compiled fixture.
3. Keep composition and closure distinct:
   `GeneralNominalVersionedMixedEvidenceReduction235.evidenceNode` needs
   `InhabitedAvailable`, while its unconditional `generatedChildren` uses
   `Available`, which omits the model premise. Do not silently upgrade the
   former; use its separate `inhabited_generated_children` if that is exactly
   the available scope. Keep the independent old C239/C240 obstructions when
   bridging I-54 item 2: projected finiteness does not prove raw termination.

The C287 positive local row read is not a source-reachability shortcut, and
X1's legacy runtime branch is comparison evidence, not a proof of M1-final's
kernel transition. No change to meaning, raw kernel or public API is proposed
by this note.
