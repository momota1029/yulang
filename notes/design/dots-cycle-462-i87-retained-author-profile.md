# C462 / I-87: 元の階層内に残る部分の捕捉後の度量

同じ元 head/where に対する、もう一つの有限な安定性の十分条件。元 AST の app の実引数位置・record の当該 payload・variant の当該 payload だけを読む。record tail、join、変数の下、および raw graph は読まない。これは where の型が元 head の部分木として構文的に実在するかの純粋な照合で、field K2 の経路とは別。

独立の Subtree と元 path の有限読取を iff。任意 capture 後に各 recognized context が記録した payload の全変数出現を保ち、深さの長さだけサイズ余裕が増える。兄弟の syntax に前提を置かない。実元の単一 head/where の場合、この非空な元 path は既存 StableSmaller を証明。Closed profile 算法とこの witness を一つの proof-only protocol にまとめ、同じ source の finite shell と同じ report/stamp の構造 reader 以外を使わない。負側の capture table は、同じ実元のどの正証人とも矛盾する。

実対照: 左側の constructor の下の本物の元 where は任意 capture で安定。右側の異なる tag の残余 join は一切訪問せず、全形を WrittenArgs へ投影する十分条件は任意の empty key で偽と確認。実元の DeclarationReady は別に証明済みだが、そこから新しい実 K2/Report や solver の応答を導いていない。
