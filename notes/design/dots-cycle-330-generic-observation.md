# C330 設計: 支持された一般有限 head と現在子バッチ

I-56 / I-58。候補照合に中心を使わず、選定が書く反復中心等式を C329 の通常バッチとして残す。いま不足しているのは、独立な支持付き観測から、その通常バッチが読む実引数位置・順序を得る部分と、任意の安定した選定が同じ書込みと子を使う証明である。

まず、二つの支持付き端点 trace の同じ正規形から、任意の引数個数の不変 nominal（0 引数を含む）を共変 pair / variant の下でも読める有限構造を作る。高い端点を実中心にせず、nominal sandwich と下端の既知の実パラメータを使う。一般実 trace の経路とは別であり、opaque row・join・負位置の投影を仮定しない。異なる実出現名を順に保つので、後から C329 の等式・区間集約・where / 関連出力の実書込みに渡せる。独立の現在ガードと、実際に保持された行があるなら、正確な子の役割・順序・出力先を照合する。同じモデルでもそれだけで支持や辞書選定を運ばない。

並行して opaque record の required field と tail を観測的に切り分ける。default、mask、残余ラベルの理由を確かめ、支持された名を与える範囲だけ定理にする。語義が決まっていない diagnostic 順位・K2 は変えない。
