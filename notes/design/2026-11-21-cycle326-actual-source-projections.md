# C326: 見えている source 観測から実際の共変中心を読む

I-56、宣言的な普通状態のみ。下端の観測を展開の由来として読むことと、実際の中心項を普通制約で読むことを区別する。共変 pair の端点が同じ形でも、中心座標の値をどちらかの端点から選ばない。

1. 既存の別名や親 pair の可視な射影で中心の ordinary 定義を得る。区間下端・実際の中心・上端の三つを独立に射影し、座標ごとの上下関係を導く。普通の同一性は、下限の展開に認可された由来があることを含意しない。
2. 座標の既存名がないときだけ、読み取った式を新しい普通名で定義する拡張を作る。古いモデルと指定済み出力先を保持しつつ、普通の区間と where に使える中心式を得る。古い名前を指定した追加等式はこの保存を主張しない。
3. 見えている record の tail は既知ラベルだけ引く。閉じた実例なら、元の source 規則・K2・保留のチェックを通る木まで確かめる。候補／棄却／保留と実際の where/substitution を分離し、既存の承認範囲を変更しない。
