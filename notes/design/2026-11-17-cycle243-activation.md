# Checked inactive-cell activation

I47 remains unchanged. Cycle242 rejected unrestricted union-domain projection:
a formerly unconstrained cell may already constrain a source through a consumer.
This cycle supplies a finite no-read producer instead of removing that condition.

First fragment: singleton aggregate block has no defining entries; introduce
actual repeated-capture entries only after checking each target absent from raw
semantic support, retained ordinary atoms, and every live site's endpoints and
actual centers. Reservation membership is excluded from semantic raw support.
This directly permits a reserved but unread cell, unlike allocator freshness
alone. Patch satisfies new equations and preserves all checked consumers and
all row values. A converse from outside-cell equality gives exact projection.

The check is a finite structural condition, not model backextension. It can be
verified on concrete snapshots, or produced at a never-allocated initial site
from allocator freshness. Preservation of the check across all old kernel
operations is not asserted. All extra output/evidence atom consumers must be
included; arbitrary history is not silently covered by a raw snapshot alone.

After this fragment, investigate mixed existing and newly active definitions
using old substitution plus a no-read check for the newly active names only.
No existing module, language meaning, or old counterexample will be changed.
