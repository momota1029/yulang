# Finite nominal heads with arbitrary binder sharing

Generalize cycle147's injective finite head and two-position repeated binder.
For arbitrary n and names: Fin n -> Nat, define observed coherence only between
positions bearing the same name, in the unchanged assignment. No distinct-name
hypothesis. Derive cross-interval compatibility, inspection projection and
self-checks from source Models + coherence; characterize branch models by
those source obligations, allocation merge equations and materialization.
Then remove materialization for terminal single associated output at the same
nominal head source. Merge equations stay explicit, never silently derived from
interval inhabitation. This is a fragment-level residual theorem, not a new
unconditional V5 bridge. Existing semantics remain unchanged.
