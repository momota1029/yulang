# C415: X4 後半の元の record 残部

対象は C07 だけ。実際に確定した有限 record `{x:int,y:str}` から、元の `x` だけを除き、`{y:str}` を元の論理名の実行と結び付ける。x と y は別ラベル。元の閉じた行と残部行の syntax を独立に読んでから、保持された「x を同じ残部名の上に載せた」行を照合する。マスクや一つの適合モデルの tail から残部を決めない。

前回の保留には手を入れない。候補の宣言・role・where 順は元入力を読む。選択まで数える条件: 残部を実中心として捕捉し、記述された where を実際に一つ生成し、その子にも独立に実選択がある。同じ State の辞書証拠を子から組み上げる。任意の tail 代入に課す旧 StableSmaller を open tail に課さず、実際に減る残部を確認する。K2 と既存分岐は変えない。この三条件を満たさない段階は部分進捗とし、C の数を減らさない。
