## 1. Operational locality, not an assumed final Joint

`GeneralDictionaryFiniteJournalJointExample` applies cycle149's theorem to the
actual reachable stable recursive fixture, deriving locality from actual sites.
`GeneralDictionaryNamedLocality` derives all-sites naming and empty aliases by
induction over arbitrary finite real enqueue/equate/install updates. Root and
newly inserted occurrences obey a fixed syntactic ID map; every original guard
remains. Final locality/focus naming/Instance/Joint are not assumptions.
`GeneralDictionaryNamedLocalityExample` instantiates that real trace.
No-merge alone is insufficient because Occurrence does not enforce unique IDs.

## 2. Distinct-occurrence alias classes in one supplied model

`GeneralDictionaryAliasRecordedLocality`, `AliasMixedLocality`, and
`AliasTreeLocality` progressively allow actual packet replay, unrecorded chosen-
declaration spine/scalar leaves, then finite binary tree leaves. Occurrence IDs,
child IDs and named-output demands may differ. Each site uses its own constraints
in the same supplied current model, not a collection of independent existential
models. Tree/scalar syntax must concern the actual chosen packet's declaration;
an arbitrary HasLeaf cannot establish cross-alias key coherence.
The operational wrapper explicitly assumes ordinary trace AND existing
EarlyMergeChoices.Scheduled. Arbitrary execution is not proved Scheduled, and
Related-site coverage/current selection remain required. See the residual audit
for the exact merge-key and first-install gap.

## 3. Strictly larger structural terminal leaves

`GeneralNominalBranchProjection`, `BranchFacts`, `GeneralDictionaryBranchLeaf`
prove one binary fork of independently arbitrary finite unary spines.
`GeneralNominalTreeFacts`, `GeneralDictionaryTreeLeaf` generalize this recursively:
arbitrary finite binary branching and unary wrapping, globally injective finite
binder names, point internal edges, arbitrary innermost binder intervals.
The Tree certificate contains only syntax/source lookup/parameter facts. Actual
inspection, projection Models, exact Fin-indexed binding allocation, finished
checks and privateState Models are derived for the unchanged arbitrary source
model. Then terminal/no-output BranchModels, Instance and selected Evidence follow.
`ofSpine`/`ofFork` preserve queries; shape adapters preserve prior certificates.

`GeneralNominalBranchExample` gives an explicit3slot inhabited fork outside every
old unary Spine query. `GeneralNominalTreeExample` gives an explicit5slot nested
two-fork model outside every old single Fork query. These are source-model branch
fixtures, NOT asserted reachable/stable support states. They use0binders; the
parameterized theorems, not these examples, cover arbitrary finite binder count.
N-ary internal branching above2, repeated binders, row parameters and nonpoint
internal edges remain outside the proof. N-ary forests need an actual variable-
arity flatten/binding-allocation proof, not a reinterpretation of binary trees.

## 4. Existing general Classify and dictionary Evidence

`GeneralDictionaryBranchOrdinaryCoverage` derives per-packet Extension from real
ordinary histories while permitting unrecorded spine/scalar leaves.
`GeneralDictionaryBranchCoverage` adds the single-fork shape.
`GeneralDictionaryTreeCoverage` is the strongest composition: actual historical
packet, structural finite binary tree leaf, or scalar leaf at each generated
selected focus. Existing general Classify and model-indexed Evidence are unchanged.

model. `of_trace` removes the per-packet growth premise along real ordinary traces.
Finite Classify evidence and explicit structural coverage remain inputs; neither
executor termination nor coverage for every reachable stable state is derived.

## 5. Remaining circularity and rigorous limits

`dots-cycle150-general-evidence-residual.md` identifies the actual first-install
Joint obligation. Selected supplies support guards; reachable/stable supply other
closure facts. EdgeOrigin's nonterminal packet theorem itself assumes Joint, so
using it first to prove coverage and then Joint is circular. Unrestricted actual
merge does not automatically provide the cross-key equation. A model-inconsistent
merge alone cannot refute universal Evidence. No fully reachable/stable/inhabited
counterexample was established in this cycle.
