# From C367 observations to the remaining I-65 source rule

The fixed I-65 statements are unchanged. This is a design note, not a theorem or a language rule.

## What now composes

An ordered tape is indexed by the declarations actually visible for the requested role. A `matched` entry retains the exact authored head; a `waiting` entry cites an unfinished output and shows the corresponding input head is unsupported by independent sources; a rigid miss cites the actual pattern position and an incompatible observed declared tag. These are positive kinds of evidence. No missing checker case becomes a miss or a waiting reason. Given one live row and no waiting, the tape locates its original witness. The exact compiler run exposes the real child order and the actual first center for input names, and attaching its body to that witness produces a `SourceNode` on the same state. The tape alone does not make the compiler run or define general selection.

## Three independent remaining cuts

1. **Pre-inspection K2.** The current ordinary root-cycle condition vetoes a tape even if expansion is waiting. Candidate K2 cannot be computed only from completed `SourceHead` evidence, because a rival can reach a forbidden constructor while its match is still incomplete. Record the actual normalized nonvariable positions reached *so far* for each applicable source candidate. Existing `GeneralDeclarativeInspect321.Visit` is evidence for its ordinary named fragment; each recorded step follows a constructor edge in the ordinary graph, even when the equation supplying that edge cannot support an input match. Binder capture is not a visit. Require a structural nonempty return to the reached ordinary alias class, not a cycle elsewhere in the graph. For declared-mode endpoints, still derive the site and used bound from original authored syntax, exact constructor kind and inherited variance, before using ordinary alias reachability. Do not look inside a named declaration body or use numerical identity as a provenance link. A successful boxed-head read, an unrepresented path, a pending descendant, or a sufficient graph rank is not by itself a complete K2 verdict.
2. **Model-free misses and complete priorities.** Current rigid exclusion uses `Fits` to relate two records of the same physical source slot, so it is not an unconditional source conflict across arbitrary states. The candidate-native subcase can instead scan *all actual routes* for the lower logical endpoint and prove that an independently present route exists and that all routed original heads have the same constructor tag. Different physical origins can agree on the tag without becoming equal. Once the source candidate uses a different declared tag, ordinary translation is inapplicable by its real declared mode and any genuine nominal read must see the agreed tag. No route, a conflicting origin table or an unsupported interpretation proves neither rejection nor that the language must wait. The source rules still need to account for every approved result and priority, including the unsafe rival before ambiguity/selection and ordinary root K2 before waiting.
3. **Literal typed body.** The current `SourceNode` body assembles an ordinary fixed batch. For a typed body keep the same source declaration (not just its ID), current problem and occurrence, actual input spans, exact ordered children, and same report trace. A literal typed fixed write at its exact authored name, ordinal and target needs a producer that installs that exact typed observation on the current state. Every fitting model then interprets that observation using `ModelsCurrent` and separately interprets ordinary equations; that is not authority for a downstream input read. The C354 release proof is useful for the latter but cannot fill an absent current authored output or be silently reclassified as an ordinary equation.

The conclusion is still the existing fixed all-state/all-model theorem, not a new restricted interface. Neither unified checker nor its top-level theorem was started. No new fixtures, language choice, old `Local` correspondence, completeness, or termination work.
