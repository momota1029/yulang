## 4. Whole substitution and the authentic Name use

The following is a candidate derived lemma about the selected constructors,

a primitive's arguments; syntactic substitution alone does not prove changed

at the same original Resolve edge. The third equality follows because the

## 5. Unselected local rule proposal: explicit partial telescope elaboration

Proposed name: `RB-Local-Telescope?`. This is a partial source elaboration rule
for exposing the result-binding certificate and its actual uses. It is not
`Gen-CallView`, an admission definition, or a complete IF(g) introduction.
Its structural content is justified by §§2–4; adoption and any implementation
remain with Luna. No new L2, SAT, role policy or descriptor universe is chosen.

Inputs are the actual Bind/initializer/Name occurrence graph and source scope
tree; the initializer's **own local derivation nodes**; and the original
primitive declarations encountered at those nodes with their typed parameter
and result declarations. It does not take a complete IF(g), F2, L2, role/entry
package, successful c1 Return, provider selection or Q as its open-stage input.
A primitive declaration is required only as the genuine independently typed
leaf of that derivation; a newly named primitive whose content is “g has the
desired Call interface” is forbidden. If such a leaf is missing, the rule
returns that obligation without a complete-interface certificate.

The proposed clauses are concrete:

1. At each original primitive result clause retain its actual field
   declarations `h_j:T_j` and its typed parameter substitution theta_j.
   At Result retain both tagged packet legs and their maps. At Ref retain
   the existing declaration reference and its whole substitution. At Scope
   preserve its binder; at Bind preserve the dependent middle result/current
   world and suspended suffix. Union/Conj retain all actual alternatives and
   one shared whole tuple where required. These are the selected IF clause
   grammar applied to result-binding output construction.
2. Register the hypothetical value binder at original A1 and retain its
   Value-checking position, source occurrence and Resolve edges. The output
   is an open declaration graph with every unresolved local semantic clause
   still explicit. A declared field schema creates no actual runtime field.
3. Emit c2's ordinary unsolved source obligations at its existing F2 scope.
   If the next node needs a role/entry relation or L2 without an owning
   introduction, report `Missing(c2,F2,sigma2,Delta2,role-entry/L2)` there.
   Do not default the clause, infer it from Unit, or certify a complete frame.
4. At an actual matching c1 Return, instantiate the result part of that graph
   with the same Delta_R and construct the selected CheckBind/Env extension.
   Apply §4's whole substitution at Name uses. No Return instance is produced
   while pending; no c2 interface is upgraded by this operation.

The useful output is an explicit source-to-field and field-to-use dependency
map plus the earliest unresolved typed operand. The rule preserves the
original relation and never substitutes this partial graph for a complete
source derivation. In this packet its successful concrete outputs are already
selected structural/retention facts; the missing semantic field is unchanged.
It is therefore not a claim to have designed the missing complete inference
introduction under another name.

**Discriminating failure conditions.** Reject a purported complete application
if a primitive leaf lacks its original telescope; any field obtains a new
provider/role/receipt from Q or actual execution during Stage A; theta_j is
replaced by endpoint identity; a Shared binder is duplicated; a private
contract is retagged logical; or an original alternative/future field has no
retained owner. These are rule falsifiers, not newly established source
counterexamples. A rule adding semantic inlet clauses beyond these retention
steps requires the next authority decision and proof at the actual owner.
