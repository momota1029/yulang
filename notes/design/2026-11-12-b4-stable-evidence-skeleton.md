# Stable evidence composition for B4 (I-23)

Status: Draft proof architecture, 2026-11-12. Scope: conditional B4SkeletonV4;
no change to source semantics, V3's target, or Astra definitions.

The target remains exactly `B4TargetV3.Statement b e`, with every registry,
initial state, demand, dictionary, and final-model quantifier unchanged.
The executor and independent `Classify` / `Local` judgments are unchanged.

V4 has **thirteen** local obligations. Eleven non-evidence fields from V3
are retained. `EvidenceNode` is restricted to a stable parent and stable
immediate children. A new `GeneratedChildren` obligation connects each
stable selected edge to the saturation root's genuine `b.Generated` set:
for all checked registries, states, roots, parents, keys, and child lists,
if the parent is the root or generated by it, and the parent is stable with
`SafeKnown` and `Unique`, each listed child is generated by the root.
This is a one-edge obligation, not recursive dictionary soundness. Concrete
boundaries can establish it from immediate-child generation and transitivity;
neither property is supplied by the abstract `SourceBoundary` definition.

The proof first obtains root stability and generated-demand stability from
`closure` at the halted final state. Structural dictionary induction carries
only root-or-generated membership. At each selected node it derives parent
stability from that closure, propagates membership through `GeneratedChildren`,
and derives child stability from the same closure before invoking the stable
node evidence rule. No caller-supplied descendant-stability premise is added
to `b4_of_bridges`, and no field contains `DictionarySound`.

Intended theorem: for all vocabularies, boundaries `b`, executors `e`, and
frontier functions `frontiers`, `B4Bridges b e frontiers →
B4TargetV3.Statement b e`. This is conditional composition, not completion
of the general-source B4 instance. Focused Lean compilation and axiom checks
are the validation scope; no full build or Audit is run by this worker.
