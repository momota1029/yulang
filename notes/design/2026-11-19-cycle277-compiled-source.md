children are independent of the unrelated registry entries. Candidate

## Quantitative progress and the unresolved installation bound

The owner and linked-port invariants remove all newly named sources from
administrative segments: a certified refresh's support is included and grows
monotonically, equate uses existing names, merge uses linked recorded output
targets, and reobserve only changes descriptor precision. Existing source
registration (cycle 235) rules out the enqueue case. Counting distinct source
names M and distinct centered occurrence IDs C gives an explicit
installation-free length at most 2M + M² + C². This does not assert a new
administrative termination argument from an arbitrary forged snapshot.

Each actual installation adds at most A new distinct names (the compiled
registry's binding-independent allocation-key count) and at most B new
centered identities (maximum requirements of a compiled declaration).
For k actual installations, use M + kA and C + kB in Q above; the full trace
is at most k + (k+1)Q. Thus a bound on the number of plans installed in any
finite prefix is sufficient for full accessibility. A finite inventory can
supply that bound if a repeated key absorbs the next plan semantically:
every full model of the current state must satisfy its Inputs/Outputs and
class effects, and its child edges must already be retained. Code equality
alone is not substituted for these obligations.
