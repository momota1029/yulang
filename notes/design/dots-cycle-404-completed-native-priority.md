# C404 — an entered unary native position from a completed output

Spec/06-roles §6.3 and its K2 decisions distinguish two steps: establishing an eligible input head, then checking the unfiltered ordinary graph at an actually entered structural position. The C403 native position used two authored original endpoints. This extension uses the actual finite completed producer on the lower side, the original authored upper side, and no solver release. It does not register the completed output as an authored Origin.

In the exact represented case, the actual raw lower name equals the selected producer's original fixed target; the original typed RHS is a unary declared covariant value application whose one point argument directly reads the original bound lexical name. The opposite authored endpoint has the same constructor and a point operand. The only written candidate child is an ordinary structural query, so its first port names that exact lower child. The raw K2 fact may use pending rows at that child, but the candidate branch itself cannot open without the real completed producer in its SupportForest. If the raw demand root is cyclic, it rejects even when the support entry is unavailable. Unsupported other forms do not generate a language verdict.
