## 1. Objective and proposed next gate

Make the ordinary default path infer `my invoke f = f 1`, preserving the full
Call contract through collection, solving, generalization, public export and
fresh use. A private four-endpoint result, a fixed empty Call effect, or a
source body hidden behind a public accessor does not satisfy this objective.

Propose one compiler-owned finite graph of complete dependent interfaces and
one correlated solution/publication package. The graph retains facts at their
actual construction points. It does not enumerate infinite carrier, world,
history or observation domains. Those domains remain in the independently
declared contracts referenced by graph nodes. The selected finite source graph
construction supports this representation direction; it does not supply an
effective solver or missing source meaning by itself.

The next approval object is this representation and its bounded implementation
sequence, together with the exact missing source rule in §7. Safe graph design
can proceed while the selected-source `P_old` bridge remains external. Default
acceptance cannot proceed by replacing that bridge, the formal-resolution rule,
or a full contract consumer with an assumed certificate.

This draft is deliberately implementer-ready about owners, data and failure
boundaries, while identifying which inputs still prevent an implementation
authorization. It introduces no rule that `Result(1)` alone resolves the
provisional formal state.

## 3. Entry envelope and success behavior

The proposed first default-path slice admits a resolved immutable ordinary
Value formal Name applied to an actual integer literal, inside a finite
acyclic already supported Lambda/immutable-binding context. It includes
renaming `invoke` or `f`, changing the literal integer, and repeated such
occurrences sharing the same formal. These use structural resolution and
primitive identity; no identifier or literal spelling is a semantic switch.
One Call is the smallest acceptance case, not a special inference rule.

Construction fixes the enclosing ordinary literal's actual role and its
Value-entry formal from the existing source rules. The formal's inferred
call view remains a separate object from the role/entry of any later supplied
provider. The entry envelope does not restrict later compatible providers to
Pure, Value-entry or empty-effect implementations. Full independently
admitted effectful, divergent, pending, retained-entry and W/Z contractual
alternatives remain in the relation even when this source argument is `1`.

Computed callees, nested general Apply operands, new annotations/conversions,
general recursion and mutable State construction are later source producers.
Keep existing accepted source paths intact; this is a proposed bounded rollout,
not permission to impose a new annotation or change language support. Existing
authoritative aggregate gates are not silently retired. A supported rollout
boundary and its diagnostic behavior require approval before default routing.

Success means a real ordinary `SolvedModule` export whose printed scheme and
ordinary use preserve the correlated complete relation. This draft does not
select a new printed invoke scheme. In particular, carrying a symbolic
complete effect allowance is acceptable; replacing it with empty because the
operand Results are pure is incorrect. The public package must support two
independent uses and an alias through ordinary decoding/checking without
consulting the source body.

### 4.1 Finite dependent interface graph

Use one immutable arena per collected source component, with typed keys for
source registration, contracts, uses and evidence. A key includes artifact,
actual constructor occurrence, role and lexical scope. Equality of solved
endpoints never merges distinct roles or certificates. One formal root is
shared across its source uses; each exposure retains its own demand and proof.

The minimum node kinds are:

1. **Scope/declaration.** Ordered dependent binder telescope; source-owned Desc
   declarations; imported Family parameters; rigid/request variables with
   their selected levels; fixed provider/world/state/lifetime anchors; proof
   scopes and dependencies. `xi=(nu,K,D)` is one joint assignment family.
2. **Independent contract reference.** Original identity and owner; whole
   membership/admission/typing/license/guard/domain interfaces and action laws;
   complete provider/world/output/future/evidence telescope. Opaque original
   arms retain complete signatures and actual meanings. Their possibly empty
   or infinite witness fibers are never flattened into one canonical witness.
3. **Source constructor certificate.** Registration, route, child/code, Result,
   reify/capture and suspension; formal seed, exposure, paired owner facets,
   elimination and receiver schema. Each constructor stores its actual inputs
   and a typed eliminator. A certificate forms only after those inputs exist;
   an unfilled field is an implementation gap, not a trusted certificate.
4. **Typed incidence edge.** Actual clause insertion and reference use under
   a certified scoped substitution; parent/child and source/result inclusion;
   whole-map dependency edges. Edges preserve every dependent field. A static
   receiver-address edge is not a live receipt or `TypedCallCert_Dec`.
5. **Constraint occurrence.** Rule identity, ordered scoped operands, full
   evidence result telescope and dependencies. Required semantic heads include
   WF of the demand, same-value inclusion of the callee, whole-argument
   compatibility, and full complete-result inclusion. Four heads are not four
   scalar endpoints. The complete predicate contracts remain reachable.

Register all finite interface nodes before linking references, then close the
dependency graph once. This retains finite monomorphic reference cycles without
unfolding them. Semantic validity of new recursive source remains outside this
first acyclic source producer. Complexity is proportional to retained nodes,
edges and finite clause syntax until solve; symbolic domains are not enumerated.
Solver cost needs a separate bound, not an assumed linear-time claim.

An opaque arm's static interface remains complete even when no local source
execution witnesses it. `W`/`Z` insertions and actual root uses retain their
own scopes, guards, licenses and introduced-provider maps. On a
domain-changing action retain its actual domain certificate. There is no
fallback cast to the structural provider or license synthesized by membership.

### 4.2 Complete carrier/image and phase interface

The literal has its independent Int value law and original Return formation.
The Call-owned whole-argument object additionally retains `ChildCode(a,q)`,
the actual registration and reference/capture licenses, the exact old image
package and the separately selected source literal image `J_lit`, with their
own domains. `J_lit` is not identified with arbitrary old `J`. Inert formation
and universal designated one-layer execution are distinct fields, checked at
their authentic scopes and live events. No creation-world activity snapshot
is used as a later grant.

The carrier hole remains an independently admitted open whole-carrier hole.
The source Delay is one section, not its entire domain. Keep provider identity,
current world, hard constraints, context/continuation, arbitrary finite admitted
history, future-use fields, original guards and proof alternatives. Literal
Return realization does not prove WholeArg compatibility at an unknown formal
by endpoint equality; the full checking rule must establish that exact tuple.

Represent the complete phase distinction in the dependent operation schema:

```text
callee pending         -> remaining callee + receipt + actual entry/body/consumer
callee returned        -> receipt at that provider/current configuration
receiver consumed      -> remaining actual entry/body/consumer, no second receipt
complete return        -> actual returned value/provider/world + dependent future
```

These are typed symbolic cases, not inference-time execution. A later pending
resume uses its live configuration and preserves its original receipt identity.
Value entry forces/rebinds once after receipt; retained entry binds the same
carrier. Complete effects include callee, receipt/entry, body, designated
consumption, native boundary and return as required by the original operation.
Inert argument formation contributes no speculative prefix execution. Returning
a latent value does not add another force.

## 5. Correlated solver and ordinary publication package

The proposed algorithm uses the existing scalar solver as a leaf service where
its established laws apply, behind a new complete-component owner. It cannot
promote the shadow candidate's admission rule. Every new rule module declares
its source/contract rule, full inputs, residual output and evidence transformer;
no rule reduces full carrier or invocation checking to endpoint compatibility.

1. Collect the real site, reuse the shared formal registration, construct typed
   operand Results and complete argument suspension, and declare a source-use
   demand before any comparison succeeds. Build clause/use incidences and the
   complete Call/result interfaces in one unpublished arena.
2. Produce the source-scoped seed/exposure and ordinary-value refinement inputs
   according to the approved rule selected from §7. Keep source upper marks
   separate from independently retained lower/provider marks. Never seed an
   external Name merely because its use has no annotation.
3. Instantiate independent contract rules under one joint scope. A worklist
   processes dependent constraint occurrences and revalidates the selected
   level/extrusion guard on every derived comparison, including replay and
   transitivity. The rule result is contradiction, a proved rewrite plus
   evidence, or a lawful symbolic residual; not a guessed witness. Preserve
   constraints and evidence dependencies when scalar terms simplify.
4. Validate the jointly correlated solution/residual. Witnesses for inclusion,
   argument checking, complete output and protection may depend on one another
   under the original order. Separate successful queries cannot supply that
   tuple. Preserve independent admission and all original witness alternatives;
   source reachability is not the production domain. Solver optimizations need
   sound rewrite laws and required natural-inference completeness, including
   B-equivalence where callback scheduling is actually affected.
5. Generalize the **enclosing Lambda/binding's actual final result**, not the
   interior Call result. Walk typed dependencies to template only eligible
   own-component Desc variables outside fixed closure. Keep actual provider,
   world, allocation, external contracts, boundary and one-shot evidence fixed.
   Shared, ViewLogic and actual event scopes retain their source order.
6. Extract a transformed finite public package: displayed scheme plus ordinary
   complete interface, fixed anchors, residual/evidence slot telescope and
   whole-frame action. Validate the new ordinary public root. Erase Build
   graphs/source bodies/source-root accessors. Public evidence schema may retain
   needed static provenance, but cannot be the complete source relation under
   another name. Native id/pick extraction is a precedent, not this supplier.
7. At each independent use decode one fresh whole frame, preserving all
   correlations and fixed dependencies. An alias reuses its monomorphic frame.
   Check submitted ordinary roots with the actual complete consumer. Stage all
   root, descriptor, evidence and dependency tables and publish once.

Lawful symbolic residuals express selected parametric constraints whose public
meaning and ordinary checking are implemented. Unresolved implementation
suppliers, unknown rules or fields are different: they cannot be generalized
into a public obligation that asks users to supply the compiler's missing
meaning. Ordinary `invoke` must infer without a concrete provider for `f` and
without a user-written proof or artificial annotation.

The implementation plan therefore needs an effective local-rule set for this
source slice and an invoke extraction/ordinary-root consumer. A finite graph
alone is insufficient. If the finite public grammar cannot express the
remaining correlated clause, return the exact clause and public-grammar gap
to design; do not delete it, keep a private source-body escape hatch or assert
that current scalar schemes preserve it.

## 6. Smallest conditional construction derivation

Method: derive one actual source spine and assign each retained fact to its
first owner. No checker or repeated endpoint probe is involved. Exact premises:

- **Hsrc:** authentic resolved immutable formal/Lambda context, independent
  primitive Int/Return/entry laws, and their typed source scopes/incidences.
- **Hold:** actual selected-source `P_old` with complete registry
  registrations, lookup/inversion and old-consumer closure, plus complete
  independently interpreted primitive/admission/license/action contracts.
- **Hrefine:** the exact literal/formal ordinary-value and protection rule,
  applicability evidence and propagation policy missing in §7.
- **Hsolve:** effective complete local solving preserves the joint solution and
  observation/evidence fibers and infers the intended natural source slice;
  full production membership/admission obligations apply unchanged.
- **Hpub:** Generalize's local laws for this completed component and finite
  invoke public extraction/ordinary-root checking with soundness, source-lawful
  use preservation and required completed-contract principality.

Take one formal binding `d_f`, its one lexical use `u_f`, literal occurrence
`a=1` and Call `c`. Under Hsrc retain the formal's actual Value-entry binding
and one shared contract root; synthesize the Name and Int Results at their
separate typed ports. Under Hold and the selected Reify direction retain the
whole child-code registration/license/suspension and distinct old/literal
images. IF-Insert/IF-Use then places the actual complete references and all
original arms in the source graph, without proving their semantic obligations.

Declare `F_c,E_c,A_c` and the distinct checking occurrence at the real scope.
Construct the whole independent constraint occurrences at that joint tuple;
Hrefine supplies the authentic upper exposure/refinement evidence. Hsolve
produces a correlated residual/evidence package, retaining complete effects
and same-provider/world/suffix dependencies. Hpub generalizes the actual
enclosing source result and decodes ordinary public roots under whole actions.
Atomic publication exposes that package only after these validations.

This establishes a conditional route and removes reconstruction from scalar
IDs as the method. It does **not** establish Hrefine, Hsolve, Hpub, acceptance
of `f 1`, a principal printed type, or original-registry correspondence. Hsrc
also includes primitive semantic laws rather than deriving them from the token
`1`. Existing selected source constructors remain established only within their
own reviewed premises. The new graph/solver/public package is a candidate
architecture; the code-seam inspection is a bounded characterization.

The smallest decisive failure is the first new inference step: knowing
`a : Value(Int)` and `Result(a)=Comp(empty,Int)` still leaves no selected
literal-to-`NonHandlerFormal` introduction at this shared formal/exposure.
Another transition checker that assumes that introduction would leave the
same premise untouched. Supply that source rule, rather than another toy probe.

## 8. Failure behavior, limits and rollback

Construction and solve occur in a component-local unpublished transaction.
Only after all required semantic suppliers, lawful residuals and public decode
checks exist may ordinary exports become reachable. Earlier committed modules
and unrelated components remain usable.

| Failure | Required internal behavior |
| --- | --- |
| Missing typed contract field, source rule or supplier | Stop this implementation slice with its exact owner/field; no trusted placeholder, semantic rejection or scalar fallback |
| Registry duplicate with incompatible role/scope/dependent interface | Report the conflicting actual key and certificates; reuse only after full compatibility, not equal endpoints |
| Ill-scoped evidence or forbidden derived comparison | Reject before committing the edge/substitution; retain structured cause and source span for diagnostics |
| Genuine full-contract inconsistency | Return the original structured typing cause at the actual source boundary; do not alter expected results to match a shortcut |
| Budget exhaustion | Deterministic structured limit failure before uncontrolled allocation/recursion or partial publication; no approximation or truncated relation |
| Public extraction, decode or ordinary consumer mismatch | Discard staged export package; preserve no partial root/evidence tables |
| Review reveals semantics missing or changed | Stop the affected producer; return exact clause to the primary; retain unrelated approved work |

Source spans and structured errors belong to collection/solve outputs;
diagnostic wording belongs to the existing presentation layer. This draft does
not authorize changing error expectations. Disabling new default routing and
discarding its unpublished arena is the implementation rollback. Once public
interfaces are published, rollback requires rebuilding affected outputs as a
coherent change; no mixed old/new public package may remain reachable.
