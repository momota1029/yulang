# C370: candidate-local return rank and native position authority

This is the source-level proof cut for the unchanged I-65 step 1, not a selection algorithm or a new rank-based acceptance rule. The C369 one-sided modal projection and actual named crossing are prerequisites.

## Rank only the returns to an actually inspected site

Let `v` be an actual named ordinary inspection site. Use C321's full ordinary structural graph, including ordinary rows that are not yet available as input support. Rank an edge `a → b` only if there is a structural path from `v` to `a` and a structural path from `b` to a name genuinely aliased back to `v`. Require strictly lower rank across these edges and closing alias endpoints not ranked below `v`. This is neither a global graph rank nor a requirement for eligible source programs.

If a K2 cycle at `v` exists, its first structural edge strictly lowers rank. The rest of the exact walk cannot increase it, since every suffix still returns to `v` and every prefix comes from `v`. The closing alias forces the reverse weak inequality. Conversely any such returning structural edge provides a nonempty cycle: combine the prefix, the edge and the suffix, then close under the genuine alias. In the absence of a cycle the decreasing-edge clause is empty, so even a constant rank exists. This gives equality of two **logical** conditions, not a procedure that produces ranks or a default verdict on missing evidence.

Apply the result only to actual sites of a source prefix. In particular, no position computed by the modal comparison-port table has been inspected merely because it exists. The represented catalogue includes the independent ordinary root (without a supported input head), actual ordinary prefixes, and actual literal direct or nested native-to-named-ordinary crossings. A guard for one candidate cannot hide a cycle at an independently visited site of another visible candidate. Missing native-only site correspondence is not a language rejection, delay, or proof of safety.
