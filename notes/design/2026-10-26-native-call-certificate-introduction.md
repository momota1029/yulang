## 1. The definition being proposed

The independently reviewed
[Call-evidence construction](../theory/2026-10-26-original-call-evidence-construction.md)
gives ten explicit dependent fields, but deliberately does not declare an
introduction rule for the original certificate predicate. This proposal adds
that rule for the selected native constructor interpretation. It preserves
every old certificate case and every original conjunct of
[G_call §5](../progress/2026-10-06-source-call-generation-construction.md#5-genuine-semantic-call-constraint-generation).

This is a legitimate missing-definition proposal of the same kind as
[complete Call §§1–4](2026-10-07-complete-call-contribution-definition.md)
and [EvalInvoke](2026-10-24-computed-call-result-constructor.md). The existing
authorization to complete definitions makes an unadopted status a review
stage, not a prohibition. Conversely, adding a rule does not prove a typed
map into a separately fixed foreign interpretation. Section 7 states that
distinction at each actual consumer.

Fix the original source occurrence q and its full joint parameters

~~~text
p = (q, B, X, xi=(nu,K,D), Delta,
     callee registration and computation, whole argument/reify origin,
     authentic Q and original clause family,
     checked F and independent D_F/I_F,
     e_value, e_arg, e_result, original Comp(E_c,A_c), full IF_q).
~~~

The parameters retain all original event binders, current worlds, providers,
receipt/result/future incidences, shared witnesses, and the lexical/checking
occurrences separately. Neither a successful execution nor a particular
argument observation is a static parameter. The source-generated registration
and descriptor graph are fixed before the challenge.

Write OldCert_M(p) for the certificate family already present in a fixed
interpretation M. Proposed new cases are the tagged dependent sum

~~~text
NativeCallEvidence_M(p) := the ten fields specified in §3, with §4–7 maps

TypedCallCert_Dec^+(M,p) :=
    old    (k : OldCert_M(p))
  | native (n : NativeCallEvidence_M(p)).
~~~

The old constructor is injective and disjoint from the native constructor.
Its original eliminations are unchanged. A native elimination is the named
projection/action of the corresponding field below at exactly p. This is an
explicit additive declaration, not the assertion that the historical opaque
predicate was definitionally equal to a smaller record. The selection, if
accepted, adds this missing native case to the certificate used by G_call;
it does not replace G_call by the record or remove any other conjunct.

For an old proof, injection followed by its old-case elimination is the
identity. All old source derivations therefore remain available. There is
no assertion that erasing an arbitrary new native proof yields an old proof,
that all old and new proof fibers are equal, or that adding a constructor
preserves every separately fixed active existential. Those stronger claims
would require their actual maps and back laws. The source-forward use here
needs the displayed original consumer outputs, not such a reflection theorem.

### 2.1 Suspended laws precede actual source packets

There are two distinct objects wherever this proposal speaks of F4:

~~~text
sourceProtocolSchema_q :
  forall original joint indices/current events and genuine typed child inputs,
  forall independently admitted original challenges and actual raw developments,
  the original complete source phase/result evidence at those same indices

sourceProtocolAt_q(actualInputs,delta) :=
  sourceProtocolSchema_q(actualInputs,delta).
~~~

The schema is a function with the original child judgments as arguments.
It is constructed before any particular fixture operand is realized. The
second expression is its application, requiring actual proofs of those
arguments. F4 stores the schema and its original lawful action; a completed
F4 packet at a particular event is obtained only by this application.

This distinction is selected in
[GC3 §3](../theory/2026-10-24-generated-call-descriptor-typing.md#3-独立な局所-theorem-の正確な量化):
Operands_h contains genuine typed children, independent admission and the
existing phase/scope/authority/hard-guard inputs, and explicitly contains
neither this q_h's result typing, composite C0, nor a completed CallCert.
[PF2 §3](../theory/2026-10-24-native-local-profile-construction.md#pf2元-operator-law-の供給と-static-licensing)
places this uniform function in the suspended Op without realizing its
operand arguments. Moreover
[owned-Call construction §2](../theory/2026-10-07-owned-call-contribution-construction.md#2-original-indices-ports-and-independent-prerequisites)
defines C0 over the independently typed complete domain and expressly
excludes Contrib/Inc/Attach/Lic and desired source accounting as premises.
The phase-guard argument is not permission to add this Call's C0 or
new upper license to that independent domain.

The dependency order for the proposed native instance is therefore:

1. Form the original descriptor/reference graph, IF and policy/action
   schemas. NP can be a dependent function on licensed keys before a
   particular key is inhabited. This does not assert any license or
   actual boundary packet.
2. Construct each sourceProtocolSchema from the selected local source
   rules on genuine typed child inputs, independent original phase
   inputs and raw developments. Compose it with the genuine original
   declaration-local arm laws and branch-to-root/target maps of §6.
   This gives C0_schema at that actual Q's original open telescope.
   C0_schema is the original universal complete typing law, not a
   weaker law restricted to terminating sources or to a newly added
   licensing/desired-output predicate.
3. Apply the actual O1/Q/SpecCall/full IF and that C0_schema to construct
   the original L-UpperCall witness where the upper route exists. Then
   specialize PF1/NPR at the licensed key and construct the actual
   BoundaryIntro/Enter packet of §5. Ordinary declared Ref/Op routes
   use their own real license construction.
4. Construct the actual source closures and worlds by the direct
   NIgnore/NF/NG/NTop simultaneous source proof, now with those static
   formation packets and source boundary actions available. Actual
   current scope, authority, receipt and rebind fields come from the
   original independent challenge and actual source transition
   constructors. A provisional value is still handled by its direct
   one-step map, not by premature completed membership elimination.
5. After the source memberships are closed, instantiate the schemas
   on the actual typed operands/current phase inputs. Combine the
   resulting sourceProtocolAt packets with the original Q arms and
   the already constructed native maps in the additive certificate.

For q16 the schema accepts an arbitrary genuine h:H with its current
typed world and full existing profile, and transports that input. It
does not construct the enclosing top.h boundary. That latter packet
is built at step 3 using the schema's complete typing law. The actual
h invocation's argument is x:R: its receiver entry has the ordinary
current-carrier default, not a callable seed derived from R. Thus the
enclosing h.call field is not a premise manufactured by an earlier
application of this same sourceProtocolAt.

For q20/36/45 the schema similarly abstracts over genuine typed f:F.
For q35/44 it abstracts over the genuine complete callee computation
and its actual same-g G-to-G_A checking projection; the finite partial
Call schemas supply the callee computation law when eventually applied.
For q72 it abstracts over typed top:T and the whole ignore argument.
Receiver-local alternatives at this uniform stage come from the full
P_H/P_F/P_GA certificate of the quantified typed operand. Whole-Call
alternatives still use their separate genuine declaration-local laws.
None of these schemas needs the actual recursive fixture member in
order to exist. Actual fixture realization is step 4, not a hidden

The genuine independent phase fields are never deduced from profile
presence. They remain the original current context/transition premises;
receiver phase evidence comes from the typed receiver argument, or its

fixed foreign guard demanding this new upper packet at step 2 would

## 4. The bounded sourceProtocol generalization

### 4.1 Same-provider checking is an explicit input map

At a Name callee, hereditary lookup gives the original binding's complete
certificate at the current event. The checked view map preserves the actual
value, decomposition, provider, current world and original witness. It is
identity for H, F and T at the fixed source views. For a returned g:G checked
at G_A it is the actual intersection projection at that same g/world. It
does not retag the formal S or choose a different closure.

At a computed callee the proof waits for the actual CalRet of that callee
computation. Before it, the only available evidence is the callee's complete
packet and the suspended dependent suffix. At CalRet, apply the same-provider
checking map to that actual result. This is the parameter of EI-Intro, not
an extension of the Name-only ReadInvoke rule by assertion.

### 4.2 Whole-carrier producers for the actual arguments

All producers start with the actual code/capture/origin/reify record and
the original inert Delay constructor. Its universal designated-execution
function is built from the following source constructors, at every lawful
current event. It is independent of the receiver's eventual success.

| Actual argument code | Original whole-carrier proof |
| --- | --- |
| Name x at h x | Read the saved actual formal address. The carrier Return is that same x:R with the hereditary world and complete R certificate. W/D and the actual Name/Return/Delay laws give I_R; no runtime replacement of x is used. |
| Record(a:Name y) at recursive f use | Read that actual y:S, then the original ordered Record constructor creates the actual record with Value field a. Its field certificate is the retained S proof, its world keeps all old cells/captures, and its result has R. No latent field is forced, and no extra runtime field is discarded. |
| Record(a:0), Record(a:true) at partial f Calls | The respective original ground constructor gives Int or Bool; its actual union injection gives S. The same Record constructor yields R. These are source argument computations, not proofs that every I_R carrier is such a record literal. |

### 4.3 The phase function and the same-y result check

Define the F4 schema of §2.1 by induction on the original finite source
Call/Bind development, under its genuine typed child and phase arguments,
not on successful execution or descriptor membership. Initial and lookup

assemble the complete challenge; only the actual Invoke transition supplies
receipt. The actual provider clause then supplies its full entry/body/
designated-consumer/return fields. A Value entry performs its designated

At every Request the relevant original equation is

~~~text

~~~

The induction uses the same saved raw handle and original response domain
at C'. It preserves exactly the remaining suffix. It does not replay an
earlier callee, receipt, Force or completed Call. Final Return supplies the

## 5. Source-native boundary realization: the non-identity map

### 5.1 New, narrowly specified interpretation case

This subsection proposes the missing native-to-source realization clause
which [native-signature §4](2026-10-08-native-signature-formation-definition.md#4-whole-families-and-profile-use)
expressly leaves separate. PF/NPR construct licensed static packets and
their action; they do not by themselves create a receiving boundary. The
following constructor composes those packets with the actual source entry
and the existing receiving actions. It requires selection/review as part
of this Draft.

Use [BoundaryIntro/typed transport §6](2026-10-02-typed-boundary-realization-draft.md#6-common-typed-view-transport)
only through the source actions actually selected in
[receiving-profile introductions](2026-10-16-receiving-profile-introductions.md)
and their [grammar §§3–8](../theory/2026-10-16-receiving-profile-introduction-grammar.md).
This imports no other open Draft clause as a theorem. Extending that
bounded receiving-action instance to these four source formals is the
explicit source-specific constructor proposed here.

A native key is the actual licensed tuple

~~~text
k = (ell : L(I;Omega,beta_r,s,p,c), constituent, governedField, witness w_k).
~~~

It is not a support bit or an endpoint inferred to be reachable. Its source
IF derivation supplies the typed insertion i_q(k) into the actual formal or
Call path. A local unannotated key contains PF1's selected policy. An
inherited key contains its complete original boundary/view packet.

At an actual receiving entry e of source receiver r and formal slot a,
Enter gives the original boundary

~~~text
b_e = (r, e, a, actual annotation/profile and original endpoint references).
~~~

There is one original boundary instance for that actual receiving
entry/formal/view, independent of the checking facet A, proof unfolding,
or choice of license proof. Its profile is a dependent schema over the
genuine licensed keys. It is not one fresh boundary per key or endpoint.
For a local licensed key, map its field through i_q to the applicable
position of b_e, with the same nu,K,D, license witness and source lineage.
The local profile reads exactly NP(k)'s selected protection/permission
record. At an inherited key, transport its original boundary and entire
packet through i_q; allocate no replacement boundary. A source/result map
with no target for a position drops that position from this image only,
without deleting its original antecedent record.

The interpretation is one preformed instruction over actual event tuples.
It does not choose a boundary after examining an observation, and it does
not enumerate future events. Enter executes this instruction only at its
actual receiving event. Mere Name, capture, alias, ResultBind or Observe
does not run Enter again.

### 5.2 Exact application to the captured h route

At top's actual Value entry, the original action

~~~text
Enter(topActivation, e, formal_h, T_h, Value(H), None)
~~~

introduces the current whole-carrier root default at In(e,h).force, with no
concrete permission. The independently genuine h formal SeedExposure,
SourceUpperUse(q_h), and O0's actual invocation correspondence are retained
inside the ACTUAL L-UpperCall witness, together with its O1, authentic

not the three static premises alone, licenses the h complete-call governed
position. Its native packet maps to
In(e,h).result.H.call at the same original entry boundary. It is not an
equation between the carrier Force effect and H.call. No traversal of the
solved H descriptor mints additional protected ports.
The full C-Call Q/phase/arm fields remain attached alongside this governed
H.call policy position. Its placement does not cast whole-Call membership
into the smaller receiver-only Inv relation.

Only on the actual Force Return does the original result-prefix map send
In(e,h).result.H.call to H.call. The current Force root has no result image.
The original two-input Return/ValueBind transport combines the actual
returned-value packet and the matching carrier result packet at their
separate source-tagged paths. It does not union unrelated views merely
because they point at the same value.

The subsequent maps are the actual ValueBind identity, Capture(top to f),
Capture(f to g), and Name h lookup/transport. They retain the same b_top,

### 5.3 The other entries and returned g

The actual entries f.x:R, g.y:S and ignore.x:R use the same current
whole-carrier Enter action and no concrete grant. Their scalar/record
result shapes add no callable upper seed. All inherited packets stay at
their original positions. A future input is introduced at its own actual
later receiver entry, not at the earlier Function domain schema.

The actual f Return/ResultBind transports two original inputs: the newly
allocated g's actual value packet and the matching declared f-result
packet. Each uses its actual typed result-prefix insertion. The g packet
retains its complete captured h/f/x and all other saved world dependencies.
The returned descriptor's ordinary shape does not authorize collecting

actual formal S/entry and original Shared positions; their Ret_A evidence
remains EventProof and causes no additional boundary introduction.

### 5.4 Constructor laws

The source-native realization has the following direct laws.

1. **Indices.** Erasing its packet returns the same native governed field,
   actual receiver/slot, typed IF position, endpoints, scope, nu,K,D and
   lineage. This follows by the entry record and the field insertion; a
   local key and an inherited key are separate constructor cases.
2. **Permission.** A genuinely local unannotated entry has the selected
   protection and no concrete grant. An annotated or inherited key keeps
   its actual original permission witness. No enclosing annotation is
   copied onto every descendant; no support test creates a license.
3. **Return correspondence.** The two input images use their original
   source tags and the same actual Return tuple. Result-prefix transport
   drops only the current root from the result view. It leaves the original
   history and antecedent packet intact.
4. **Restriction.** At a compatible future event, use NPR on the same
   transported key and the original IF/receiving-action naturality on its
   typed insertion. Thus restriction of the realized packet equals
   realization of the restricted original operands at existing keys.
   New future entries are handled by their own Enter instances. A new
   future licensed key at an already existing boundary is evaluated by
   that boundary's same preformed dependent schema at its original
   telescope; it allocates no replacement boundary or default. This does
   not claim that every new key is an image of an old key.
5. **Current activity.** The persistent boundary reference is unchanged;
   the original current C determines Active/Inc/Grant/Visible. No law
   turns profile presence into liveness or calls a retired receiver live.
6. **Shared data.** The source witness's canonical projection strategy
   retains the actual predecessor EventFields at their original Shared
   positions. Old Shared references stay fixed; later current EventFields
   may change. Changing a checking view does not choose another retained
   formal or another boundary.

These are constructor calculations over actual retained records. They
prove the forward map for this source-native interpretation. They neither
derive an arbitrary independent profile predicate nor constitute a
source-to-Rust boundary correspondence theorem.

## 6. Authentic Q, complete arms, and the exact F5 supplier

### 6.1 Reference authenticity does not require enumerating opaque arms

be referenced as a whole. No finite enumeration of its observations, or
even of a parameterized family of its arm members, is needed.
