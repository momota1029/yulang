# Draft: finite self-supported equation search

Cycle22 showed that persistent speculative emissions need not retain final source support.
This cycle supplies exhaustive diagnostic search over the finite associated-token domain,
without monotonicity or selecting a candidate as the language result.

Data: checked registry, source root, finite fixed-receiver associated table/emit,
ordinary seed and checked associated environment. Enumerate all subsets of Fin k in
finRange order. At candidate S decode associated equations, recompute actual Reach,
retain S iff each token belongs to S exactly when a reachable source emits it.
Independent judgment uses this iff, not the search implementation.
Prove exact search membership, completeness for every canonical subset, finite bound,
and model exactness of every result. No existence, uniqueness, language rejection,
efficiency or B4 is claimed. A candidate may be inconsistent; no model existence claim.
Canonical order is an implementation restriction; arbitrary-list decoder equivalence
is not assumed. Raw candidates enumerate every finite token subset.
Yulang2 x-oracle X13–X16 does not inspect this internal search. No runtime validation
for this algorithm. Spec6.3 delayed sibling finalization is unchanged.

The implemented boundary uses actual checked associated computation and has no
supported candidate. Thus enumerating all support fixedpoints diagnoses but does
not repair speculative first-hit commitment. A guarded candidate carrier remains
necessary. No proof says all such annotation maps are generated by source lowering.
