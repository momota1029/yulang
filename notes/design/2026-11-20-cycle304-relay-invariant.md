# C304: operational relay after a single strict observation

The actual state can differ from the never-promoted ledger plus a hypothetical
refresh: installation records plans and effects with the observation context in
which they were taken. The relay compares current raw and centered sites,
edges, aliases, class requests and the whole model predicate. It compares
historical packets only by selected occurrence/declaration IDs. The
observation certificate relates the current context to the still-unpromoted
reference. A separate reachability witness supplies trusted cache soundness
for the actual history. Cache soundness is not deduced from extensional
agreement of the model predicates.

At each non-leaf index, rebuild the reference plan's effect with the actual
snapshot. The head view transports the frame and diagnostic guards. Empty
output requests, empty legacy effects and the transported plan's validity in
every current model discharge the exact installation-model conditions.
Compare next live views and the selected-ID projection under append, and
use C303's certificate lifting theorem for the next current context.
Eliminate non-installs using independent administrative closure conditions;
earlier plans are semantically committed and the actual frontier plan is unique.

At the leaf, compare the recomputed table (only current context, raw rows
and edges are read), and transport every local certificate in the recursive
Evidence tree rather than assuming equality of the old archive. This gives
exact counts and a dictionary for all raw paths, regardless of strict
promotion time or the choice of a legal context. It does not identify raw
terminal states. Infinite branching from redundant equations is compatible
with a uniform finite path length in this source family.

A natural generalization of the head-view interface must retain more than
full Models: the V7 merged-output diagnostic probes consistency of a
proper subset of live class equations, even when there is no full model.
Do not infer equality of that diagnostic solely from equality of full Models.
