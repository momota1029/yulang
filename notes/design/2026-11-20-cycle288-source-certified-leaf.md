# Cycle 288 design: one effect-free leaf can witness settlement without self-support

Start from the two actual cycle 287 raw mixed-kernel endpoints, not a new
language rule. The additional condition is an independently checkable leaf;
the existing full journal already entails parent outputs, so that entailment
cannot be the premise that declares the child settled.

1. Define `SourceSlice` as the original source constraints plus the original
   source-site checks (support slice with no facts). For any registry, state,
   demand, declaration key and plan, the proposed leaf witness consists of its
   exact current V8 frame, SafeKnown and no merged-output conflict, a unique
   match with zero emitted children, no effective class requests, a nonempty
   SourceSlice, and semantic packet validity under every SourceSlice
   assignment. Uniqueness by itself need not exclude other pending matches. Soundness target: for every such assignment, this
   witness implies the existing leaf dictionary at the declaration key. No
   installed parent output or full versioned Models is allowed as a premise.
2. Define a narrow parent condition: a recorded parent plan, and for each
   actual immediate child either the existing ledger discharge or the new
   witness. Admit only a **single** output fact over an already trusted
   (unchanged) prefix, with all old output premises retained except replacement
   of PacketSettled by this boundary. Prove full Models imply the new slice,
   and that old one-output proof steps embed. Do not change the versioned
   evaluator, refresh Step, global priority, or semantic acceptance.
3. Instantiate the witness at the row-bearing opaque child. The negative
   comparison remains the actual prepared-vs-pending root generated by the
   same source and parent; it must not gain the witness just because the same
   full models satisfy the parent output or the same finite view is exhausted.
   Check which actual source observations justify the parent input/class
   premises and derive exact source+output equations from the resulting
   single-output slice. If the proposed premises are false, preserve a closed
   counterexample and continue only independent obligations.
4. If enough of the above closes, test whether the new proof object gives a
   sufficient *auxiliary* observation certificate for the previously blocked
   point descriptor. Show this is not an old legal refresh or any new raw
   transition. Keep ledger, semantic evidence, and finite view distinct.

Existing Yulang2 audit X1 exhibits a nominal head and where (declaration
check). It does not test the proposed ledger proof, the cycle 287 row
fixtures, or any new semantics. No new Yulang2 run is claimed.

## Second proof path: a static ledger extension

In the exact one-child case, append the witness plan to the `plans` list
only. For every old full model prove the leaf packet from the original
SourceSlice; for every new model restrict the plan membership. Keep the
core and effects byte-for-byte equal. Transport the old trusted input slice
and obtain genuine old `Discharged` + `Trusted.output` in this static
state. Here "genuine" describes the old judgments, not reachability:
test that the existing raw Step has no path to the appended state from
the real endpoint, and do not call the append an existing install action.
The effect-free leaf is exactly the case where inventing an install could
violate the original novelty requirement. A formal integration must account
for history and queue scheduling, not just preservation of Models.

## Guard falsification before considering any integration

The two concrete registries use the same source/child identity, since the
reservation derives from the same parent invocation key. Prove or disprove
the tempting shortcut “record a plan from any registry if it holds in every
full Model.” Attempt to transplant the opaque (positive) child into the
row-destructuring state while retaining the latter's registry and graph.
If full Models survive but the old syntactic ledger now discharges a still
pending child, stop the unscoped shortcut. This tests a *static*, possibly
malformed ledger only, not the soundness of any source-reachable state.
A registry/current-frame check is not replaceable by model entailment or
by agreement of child identity. Continue only the scoped certificate and
its independent endpoint tests.

## Bounded follow-through from the guarded hypothetical state

A raw name listing includes actual reserved private addresses. A list bound
of 0,1,2 is therefore false, even though only those three type sources can
be certified Known: assign Top at an arbitrary larger identity without
violating full equations. For any legal first refresh on the guarded state,
invert invariant nominal subtyping in a single concrete model to show the
new output descriptor must be the point F(source 1), up to the refinement's
slot embedding. If all actual prepared packets transport through that
embedding, test absence of a further step from these refreshed states.
This is a finite fixture proof, never a theorem about arbitrary source or
about reachability of the supplemental ledger.

## Scoped operational observation

Try a three-state finite observation of the positive comparison family only:
`original`, `supplemented`, and `refreshed (certificate, Known 2)`. Its
executable fields are versioned plan count and the presence of the nominal
descriptor for type name 2. Prove a two-sided simulation on that family,
with one edge from supplemented to refreshed and no edge from the two
terminal phases. Then test that the unscoped wrong-registry state has the
same observations as supplemented. The observation is deliberately not a
validity checker, a new operational kernel, or a successor for arbitrary
source; membership in the guarded family does real work in its theorem.

## A stronger invariant to falsify: fresh evidence after harmless refresh

The definition of `Leaf` demands a full current-snapshot packet under
every source-only assignment. Once an independent leaf enables the output
mark, rechecking a **new** leaf certificate in the narrowed snapshot
might incorrectly require the old source to already know the parent
output. Try the assignment replacing only type(2) by Top. If the
certificate disappears even though models and ordinary dictionary
transport are preserved, do not claim Leaf is a persistent invariant.
Keep historical source provenance separate from the retargeted packet;
the historical witness is not a fresh witness at the new snapshot.

The independent follow-up is to separate exact child reads from the global
snapshot. The real opaque leaf reads root name 0 and makes no nested
inspections. Prove that the retained nominal head for name 0 is justified by
the original source even after any certified embedding, and that all leaf
local equations still hold under those same assignments. This neither
postulates fresh full packet evidence in that narrowed snapshot nor
authorizes a new settlement rule. A local support proof must retain the
Known/head guard, even when a variable-pattern packet's equations are
trivial. The wrong-registry frame remains invalid.

The local alternative is recorded as a separate proof interface only:
exact current frame and V8 guards; no children or class requests; every
actual root head and nested read justified from the empty source slice;
local packet input/output equations proved from that slice. Realizing
ordinary evidence uses the full model at the ambient-snapshot conjunct,
not as justification for the source reads. Test existence of this weaker
*support certificate* after the harmless refresh, while the strong fresh
`Leaf` remains impossible. Do not plug the new interface into
`Trusted.output` or extend the kernel.
