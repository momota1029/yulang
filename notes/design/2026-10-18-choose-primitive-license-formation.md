
This adds a retained proof view; it does not generate a contribution, license,
field attribution, admission, transition or new source requirement. No lookup
by matching family, shape, printed path, receiving signature or successful
query is permitted. For a composite constructor retain the whole tree and its
actual partition, including unselected schemas and original atomic evidence.
A source implementation can retain a reference/DAG rather than copy that tree.
For n retained original nodes, a traversal once per distinct node and stored
actual edges is O(n+edges); retaining an existing immutable root is constant
additional root work. This bound does not include constructing absent local
semantic proofs or enumerating parameter/future families.

**Compatibility proof for this record rule's limited scope.** For each already
existing d, pairing it with its deterministic readback constructs receipt;
erase returns that identical d by projection. Conversely every receipt stores
an existing d. On the same source derivation, q_decl/h/c/Omega/rho are identical
in both directions, and Inspect's constructor induction preserves its original
field map. No old semantic predicate or consumer is changed. Thus this
proof-only extension has an explicit total lift and erasure on its stated
existing-derivation domain. It adds no accepted/rejected source program there.
It supplies no total source-to-d construction where one is currently absent.

Do not misread the premise as a solution of the missing input. This proposal
only prevents losing a law already proved at its owning construction. If the
source currently produces only Support or AnnotationMember, this rule cannot
produce a semantic receipt from those records. There is no inference rule
