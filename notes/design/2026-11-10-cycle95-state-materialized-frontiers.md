# Cycle95: state-materialized interval frontiers

Status: Draft implementation boundary, 2026-11-10.

## Objective and independent meaning

Close the connection from actual ordinary paired scalar evidence to regenerated
structured interval frontiers and a finite work domain independent of the state.
Spec 6.3 requires constraint-driven narrowing and delayed child diagnosis, not
narrowing from unique impl visibility. The existing Form grammar contains int but
no str/bool/unit literal. This adapter therefore replaces a source variable only
when the existing ordinary detector returns int. All other variables remain their
original named Form; no new language meaning or rejection is assigned.

The declaration registry, original Form goal, ambient slots and invocation Sources
are existing caller boundaries. No new materialization oracle, finite work list,
fuel, model, successful child or termination proof is supplied to public run.
Ordinary atoms are kept verbatim when compiling every materialized frontier plan.

## Quantified target and finite computation

For every ordinary atom list, slots and original Form, and every assignment
satisfying that atom list, the materialized Form has equivalent independent
Form.eval meaning to the original under the same assignment. This includes all
pair, join and tick nesting, arbitrary repeated source variables and slot aliases.
It does not assert structural matching is invariant under semantic equivalence.

Compute all syntax variants by replacing each variable occurrence by either its
original name or int, keeping original constructors. Cartesian products enumerate
all endpoint pairs and argument lists. For every state, materializeGoal belongs
to this computed list. The list can overapproximate inconsistent combinations of
repeated variables; completeness, not minimality, is the requirement.

For every Checked registry and original goal, take the existing Paterson-derived
closure of each variant. Every node of every actual regenerated frontier at every
ordinary state belongs to this one finite domain. No monotonicity, consistency,
finite state sequence, or child success is assumed for that containment. Domain
membership is exactly Reach from one enumerated syntax variant. Public graph run
has exact independent Derives semantics at the actual materialized goal and
preserves old atoms and demands. Unsupported diagnostics remain in the tree.

## Explicit limits

Only explicit paired int evidence materializes, not general semantic entailment
or arbitrary interval refinement. Fixed source templates are required, although
the actual inspected goal and all descendants are recomputed from each state.
The domain is finite but potentially exponential. No solver decision, saturation
schedule, source/invocation derivation, final classification or dictionary
observation is provided. All five major B4 bridges remain; this closes a genuine
state-dependent fragment of generated_work_closed, not the general bridge.

## Persistence and review boundaries

For any before/after atom lists with actual membership inclusion, and every model
of the later list, detected int persists. Therefore materializing a previous
materialization at the later state equals materializing the original Form there,
literally, for every Form and the same slots map. Later consistency is necessary:
paired str before paired int can make the detector leave a variable unchanged,
whereas paired int alone had replaced it. This detector ordering is preserved,
not assigned a new inconsistent-state semantics.

`Sources` is indexed by the entire Goal. Regeneration changes that key and may
change aliases with old demands. Form.eval preservation does not prove original
Derives equivalence, source-identity persistence or cross-state model monotonicity.
The finite List Goal bounds diagnostic tree nodes, not internal graph vertices.
Public workDomain computes its checker and bound with no caller check proof.
