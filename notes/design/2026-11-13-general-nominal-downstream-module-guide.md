# Downstream support modules (Item 4i)

Status: Partial. Date: 2026-11-13.
See the [design and lemma ledger](2026-11-13-general-nominal-downstream-support.md).

| Module | Purpose |
|---|---|
| `GeneralNominalDownstreamSupport` | Journal-certified needed heads; unresolved waiting paths; alternative-sensitive output grounding; cycle exclusion |
| `GeneralNominalDownstreamSteps` | Additive installation guard; old-step embedding; source/model/closure laws |
| `GeneralNominalDownstreamDepth` | Finite support depth for one fixed journal, not global installation descent |
| `GeneralNominalDownstreamBoundary` | Concrete V5 boundary with support pending and unchanged K2 priority |
| `GeneralNominalDownstreamExamples` | Actual Display/Wrap/P/R first steps, direct-R pending, harmless redundant supports |
| `GeneralNominalDownstreamSiblingFixture` | Concrete Wrap emission/cut interface and downstream-blocking theorem; full prefix bridge remains explicit |
| `GeneralNominalDownstreamOrder` | Exact InstallationOrder premise and conditional accessibility reduction |
| `GeneralNominalDownstreamExecutor` | Execution, halted, treeExecution conditional only on Progress |
| `GeneralNominalDownstreamObligations` | Six proved V5 fields and exact eight-field Remaining package |
| `Audit/GeneralNominalDownstream` | Dependency audit for every new public theorem |

Existing general carriers and interfaces remain unchanged. No module here
constructs the source-derived generation budget, complete finite packet basis,
or unconditional Progress/Readback.
