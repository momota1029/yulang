## Exact difference from Astra's fresh source readback

GeneralNominalSourceProjection.followed_pattern starts with an actual semantic
origin path Follows, a ClosedTerm in the source Pattern context, and At(model,
actual,root,value). It returns a source Pattern part, a ClosedTerm for the finite
part, actual endpoint meaning, and a source mass inequality. The record/variant
specializations give strict descent. These statements preserve source syntax
keys, but they do not assert `current.nominals slot = some descriptor` or
`current.view.heads slot = scalar base` for any current Fin slot.

GeneralDictionaryObservedFiniteRequests.Tree instead takes a concrete current
snapshot and Fin slot. Its scalar constructor requires the actual scalar head;
its nominal constructor requires the actual stored descriptor and exact ordered
point parameter slots, with recursive certificates at those slots. `Observed`
also needs every actual generated request's target to be the source identity of
that particular slot, and its normalized translated query to be the certificate
query. These representation facts cannot be replaced by a model-relative label.

A further scope mismatch is explicit: this Tree currently has ONLY scalar and
nominal constructors. Source readback's record/variant parts have no constructor
here. Do not feed those results into the nominal Tree by assertion or normalize
away the structural case. Either restrict the next bounded bridge to actual
scalar/nominal report paths, or first add justified structural snapshot
constructors and their schema interpreter.

## Suggested bounded next proof

For scalar/nominal requests actually issued by a current packet, retain the
physical slot along the actual report traversal. Prove the source identity and
request.target equality at every step, as well as descriptor argument order.
Then construct a finite source Tree by induction on that traversal, not by
choosing an arbitrary semantic reification. Handle aliases by proving the chosen
representative's actual snapshot observations, not merely equal model values.
Only after exact request coverage is available use generated_shape/models and
NamedSpine/other local constructors.

For refresh, first state explicit report/binding/request correspondence. The
ordinary extension theorem preserves these structures by construction and is
not evidence that arbitrary refresh does. A small negative/positive fixture
should distinguish an old recorded packet, its current relocation, and unchanged
semantic meaning with changed physical descriptor. No new semantic decision is
required by this plan.
