# Cycle 281 — 同一区間への複数捕捉を呼出ポートのコピーに簡約

任意の nonempty capture list の全区間が代表区間の端点とモデル内で同値なら、lower の union と upper の intersection は、その二端点にそれぞれ同値である。同じ生の区間を繰り返したときは、この前提を有限リスト上の比較から得られる。捕捉が一回なら既存端点を使うためコピーを生成しない。二回以上なら既存の版付き集約の端点を target とし、代表区間から二本のコピーを生成する。空の捕捉・異なる端点は未判定とし、意味を決めない。

この表が通る範囲では、すべての宣言 inputNames の raw merges と compile したコピーの意味が任意のモデルで一致する。scope や cache-certified Known の移植は別。これが owner の永続 slot を安全に利用するためには、書き込み支持・読み元と干渉しないこと、および再観測での old reader の扱いを別途示す。
