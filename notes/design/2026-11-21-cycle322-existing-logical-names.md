# I-56: 既存の論理名から where と関連型を読む

C321 の新しい純論理名は保守的だが、元の普通状態に既にある名前を
同定したことにはならない。C322 は普通等式の alias / 構成子合同から
既存の順序つき三端と出力 target を検証する。元の名前を置換せず、
新しい事実が全モデルで既に成り立つ場合だけ使う。出力側の通常の等式と
候補検査の展開根拠を分けたままにする。

独立な source 規則側は actual の構成子・共有中心の根拠を供給し、
compiler はその根拠を読んで source の構文に従い普通の等式列を出す。
一般の選定や候補の完全性を新しい制限で置き換えず、既存の意味は変更しない。

## 既存の source emitter に合わせる

`GeneralDeclarationDemands.childDemand` は、正規化した where 入力が
単なる変数なら捕捉の区間そのものを、名前付き出力が出力専用変数なら
その binder の論理名そのものを使う。この規則を保持して actual 中心を
付ける。合成型だけに既存名の読み出しを求め、変数の要求にまで別の
候補名を選び直さない。前者の位置付き emitter と、同じ型を指す別名の
忠実性実験を区別する。
