# G05: 完全な元報告の存在に必要な局所判定

C488 の finite reification は独立に正確な報告を入力とする。今回は G05Goal の同じ範囲で、報告そのものの存在条件を分離する。元候補すべてに exact な実訪問キーを既存の有限計算から読み、再帰ならその印、非再帰なら独立な局所規則で成立する何らかの印を置く。全元候補を元順に集めるだけで、局所規則を作らず、候補を選ばず、一価性も仮定しない。

独立 exact scope と局所 protocol のもとで、完全な元順報告と replay 可能な有限証拠が存在するための追加条件は、全非再帰候補に独立に認められた印が少なくとも一つあること。陽性の早期 K2 だけならこの仮定は不要。引数ゼロでは独立な訪問列が空であることを用いる。これは存在の定理で、元 compiler の matcher や prior の生成を実装・正当化するものではない。
