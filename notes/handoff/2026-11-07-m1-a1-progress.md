## 証明済みの補題

- `CommonLegacyRecordErasure.recordView_probe`:
  任意の型 `Row`、行関係 `leRow : Row → Row → Prop`、旧有限要求環境 `env`、
  引数比較 `argumentOrder : StructuralBase.Ty Row → StructuralBase.Ty Row → Prop`、
  旧有限型 `type`、旧 observation `obs` に対し、
  `recordView type` の `ProbeStep` は、field 観測なら元の `type` と同値、
  trivial / records なら真、role 観測ならその role の head 集合に records が属すること、
  その他の観測なら偽と同値である。追加の前提はない。
- `CommonLegacyFiniteErasure.presence_exact`:
  任意の型 `Row`、行関係 `leRow`、Common 有限要求環境 `env`、
  引数比較 `argumentOrder`、Common 有限型 `type`、有限 mask `hidden`、label に対し、
  `presence hidden label type = true` と、同じ mask 下で `type` が
  `.field label .trivial` を受理することは同値である。追加の前提はない。
- `CommonLegacyFiniteErasure.erase_probe`:
  任意の `Row`、行関係、新旧有限要求環境、新旧の引数比較、Common 有限型 `type`、
  mask `hidden`、旧 observation `obs` に対し、両環境の role 表が等しく、
  `type` に現れる全 arrow domain と全要求名で新旧引数比較が erasure の前後で同値なら、
  `erase hidden type` の旧観測と元の masked 新観測は同値である。
  同じ前提の下、任意 label の optional payload 抽出の旧観測も元の新 optional 観測と同値。
  この有限個の負位置比較の前提は補助補題の前提であり、元の A1 へは追加しない。
- `CommonLegacyFiniteErasure.erase_compare`:
  任意の `Row`、行関係 `leRow : Row → Row → Prop`、有限 rank、
  任意の Common 有限型 `source,target` に対し、
  `NewCompare leRow rank source target` なら
  `OldCompare leRow rank (erase [] source) (erase [] target)`。
  行関係の反射性・推移性も、入力型の構文制限も、引数比較の同値前提も要求しない。
  有限 domain 列から新環境を交差で構成し、低 rank の帰納法で余計な比較を除く。
- `CommonLegacyTruncation.truncate_probe`:
  任意 `Row`、行関係、二つの旧有限要求環境と引数比較、旧有限型 `type`、
  深さ `depth`、旧 observation `obs` について、role 表が等しく、
  `obs` の経路に残る深さが正のとき、その残りの深さで切った全出現 domain の比較が
  二つの環境間で同値なら、`truncate depth type` の観測は、元の型を
  `clip` した観測で調べることと同値である。
  深さ 0 の arrowArgument は、bottom と引数の比較に従って arrow の形の観測か
  impossible 観測へ変換する。元の A1 にこの前提を追加していない。
- `CommonLegacyTruncation.truncate_compare`:
  任意 `Row`、行関係 `leRow`、rank、深さ `depth`、旧有限型 `source,target` について、
  `OldCompare leRow rank source target` なら
  `OldCompare leRow rank (truncate depth source) (truncate depth target)`。
  role 表の同値や負位置比較の前提は結論に残らない。
  元の比較以外の前提はなく、行関係も任意である。
- `CommonLegacyGraphSupport.finite_extension`:
  任意の index 型、有限後続列を返す関数 `next`、有限 root 列と leaf 列について、
  全 root の全後続が root 列または leaf 列に属し、全 leaf に有限閉 support が存在するなら、
  任意の root に有限閉 support が存在する。
