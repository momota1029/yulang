# T19 handoff

Date: 2026-11-09. Status: requested completion and cursor-context work implemented; EOF language decisions remain deferred.

`crates/yu-syntax/src/cursor_context.rs` exports `cursor_context`, `CursorContext`, `CursorSlot`, `PartialSigil`, `Sigil`, and `SigilContext` via `lib.rs`. The accessor returns the innermost matching CST node, trivia-inclusive left/right tokens, all mapped slots at the position, and an optional partial sigil. Offsets are UTF-8 byte boundaries; out-of-range or inside-code-point offsets return `None`. Nonempty ranges are half-open and empty ranges match exactly. EOF falls back to the root. Slots are ordered as structural diagnostic occurrences in CST preorder, followed by empty interpolation body slots in CST preorder; duplicates are retained. The compatibility fields `slot` and `expected` select the deepest mapped diagnostic occurrence. A structural projection failure leaves its diagnostic-derived slots absent. This is a whole-tree lookup, not an incremental index.

`structural_diagnostic.rs` maps existing Missing nodes for field/path/use names, operands, ForIterable, Pattern, TypeExpression, Condition, case/catch arm head, arrow and body, string interpolation opening and closing braces, and string terminator. `ExpectedSyntax` gains `OpeningBrace` and `Arrow`. An incomplete empty `StringInterpolationBody` is already an empty CST node, so the accessor exposes its statement expectation without creating a Missing node or changing the tree. `tests/completion_context.rs` covers intermediate arm and interpolation prefixes, exact reconstruction, coincident slots, byte positions, and sigils. For `case x:\n`, the parser places the missing arm at byte 7 before the newline; empty spans match that exact position, not EOF at byte 8.

Partial sigils are derived from the last preceding non-trivia Error token. `my '` is classified as a binding pattern, `type T = '` as a type right-hand side, and bare `$` and `&` as unknown. Both EOF and mid-line positions are tested. No parser construction or accepted syntax was changed. The updated `notes/questions/2026-11-09-t19-partial-sigils.md` records that a dedicated CST node is deferred, not required for this accessor.

`notes/questions/2026-11-09-t19-eof-ambiguity.md` records the deferred behavior decision for a trailing `---` and undeclared trailing operator. Tests pin the current empty-environment behavior and a declared-operator Missing separately. No language behavior was decided.

The deep cursor test runs in a 512 KiB stack subprocess with a 60-second timeout. It exercises 4,096 unclosed parentheses and every existing nesting stress family at depth 1,024, at multiple cursor positions. The accessor's tree and diagnostic traversals are iterative. This finite stress check is not an exhaustive proof over all malformed inputs or a benchmark.
