`EnvRel Common.model assignment environment bindings`、任意有限署名
`declaration : Declaration α`、任意有限 mask `permission : Permission`、

について、`generateHandler` が返す実 `Constraint` の充足と、独立 `HandlerTyping`
による同一結果 `out.eval Common.model assignment` の型付けが iff。

`∀ locals : Fin declaration.locals → Common.Ty, ∃ operated : Comp Common.model` の arm 型付け、
`union returned.value operated.value ≤ out.value`、
`residual [key] input.row ∪ returned.row ∪ operated.row ≤ out.row` を要求する。

## 閉じた補題候補: signed/residual 循環を持つ head-free 行 graph

`CommonSignedFlowFamily.solve_all_instances_exact`:
任意 `n : Nat`、任意有限 `graph : Graph n`、任意の独立な `rows : Fin n → Common.Row` について、
`Models graph rows ↔ ∃ scheme ∈ solve graph, ∃ parameters : Fin n → Common.Row,
  scheme.instantiate parameters = rows`。
`returned_all_parameters` は任意の同じ graph、任意返却 scheme、任意 parameters について Models。

Graph の edge は有限 identity/符号付き shift/residual。pure sinks も有限。
required constant heads はこの Graph には含まれない。各 edge は元の occurrence を運ぶ
独立な inclusion 規則であり、path や scheme で Models 自体を定義しない。
Scheme はこの有限 graph だけを保持する。解釈は pure sink へ届かない parameter seeds を
有限の全 path で閉じる。Safe は解釈内部の greatest-safe subset であり、parameter の前提ではない。
任意 parameters から Models を得る。任意 model そのものを parameters に取ると、全 rows を文字どおり回収する。
無限の path 長、任意長の weight lists、正負の非有界整数、無限の row support を許す。

`shift_edge_exact` / `residual_edge_exact` は任意 scope/mask/delta/handled keys、任意二 Common rows
について、この独立 edge 規則と既存 `CommonSignedRows.transport` / `commonResidual` の包含を iff で結ぶ。

この graph には required heads がなく、空 model が常にある。したがって B3 の実 source problem、
constant-head inconsistency の有限判定、全 compiled node values、全称 handler の solver 消去を
閉じたものではない。親の `solve_common_effect_all_instances_exact` は未完。
