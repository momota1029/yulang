### 継続 checkpoint 3: K2 の計算可能性を明示する対角化

`CommonRoleComputation` を新規追加。有限 binary tree / 有限 Code と独立した有限評価導出 Eval を定義する。
Code は const/id/projection/pair/composition/conditional/while を持つ。

これはまだ role 解決の決定不能性ではない。実 linear interpreter、regular clock 付き実 `Roles.Impl` への compiler、

## 検討済みの経路（新規 Lean 定理の完了報告ではない）

既存の `CommonRoleRegularObstructions.no_natural_descent_measure` は E2 としない。

## 現在の構成対象

関連型に対する、停止算法によらない障害を調べる。
一般 union annotation は source で禁止されているため、その候補は採用しない。
代わりに source 文法にある `{x:int,x:'a}` と、決定40の隠れた field の消去を用いる。
確定した有限 goal `R {x:int}` に対し、`'a=int` と `'a=bool` は
Common の要求同値で同じ head に一致するが、関連型は同値でない。

構成する正確な不足／障害 statement:

> 上の実 checker と関連型検査を通る singleton registry、上の有限確定 goal に対して、
> 任意の Common 型 `selected` が、head を goal と要求同値にするすべての代入 `σ` の
> 関連型右辺 `σ('a)` と要求同値になることはない。

さらに、実 `Roles.AssocDerives` / `assocOf` から二つの witness を取り、
有限記述の解釈を保存する head matching と、既存の関連型 evidence の保存を同時に満たす
resolver contract が存在しない形へ接続する。
union の具体的解釈を固定し、任意 decoder / arbitrary Theory は使わない。

## 最終 checkpoint: E2

`CommonRoleAssociatedExactness.no_common_associated_registry_extension`:
前提なしで、次の二条件をともに満たす任意の関数
`select : Pattern → Option Common.Ty` の存在を否定する。

1. 任意の `hidden,value : Pattern` について、hidden が ground であり、
   実 `Roles.assocOf environment roles declaration_wellFormed (rigidGoal hidden) 0`
   が `some value.encode` を返すなら、`select (groundHead hidden)` は成功し、
   その値が value の Common 解釈と要求同値である。

   goal の Common 解釈が要求同値なら関連型の返却値も要求同値である。

`checked_registry_counterexample` は、前提なしで、実 checker の受理、実 Paterson WF、
実 associated WF、二つの goal の groundness、上の非存在の連言を示す。
