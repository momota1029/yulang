## 証明済み checkpoint 2

`CommonPatternGeneration.generatePattern_exact`: 任意 `pattern : Pattern Empty Inference.Expr`、
任意 `α : Type`、`ρ : α → Comp Common.model`、`symbolic : SchemeEnv α`、
`semantic : List (Binding Common.model)`、唯一の前提 `EnvRel Common.model ρ symbolic semantic`、
任意 `priorBindings bindings : NamedTerms α` と `input : TyTerm α` に対し、

```lean
(generatePattern pattern symbolic priorBindings input bindings).Holds Common.model ρ ↔
  CommonPatternTyping.Typing (DefaultTyping semantic) (evalTypes ρ priorBindings) pattern
    (input.eval Common.model ρ) (evalTypes ρ bindings)
```

`DefaultTyping semantic prior code type` は、ある任意 row が存在して、
`PresenceGeneration.Typing Common.model (semanticPrefix prior ++ semantic) code (type,row)`。
これは fallback の**値型**の橋であり、pattern 全体の行や実行成功を結論しない。
generator は元の有限 `Formula` の atom / conjunction / existential だけを用い、Typing を atom にしない。
or の両枝は同じ参照を使い、pair / record の split は元順序、record rest の入力は元 record。
任意導出の root narrow を反映する original slot も回収する。
この独立判断に規則のない list/nominal は両側 false であり、それらの全 source 生成を証明したとはしない。
