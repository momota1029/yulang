## 4. 計算可能性の明示的な機械（還元の基礎）

新しい `CanonicalComputability` の Program は、有限な instruction 列と開始 address。
値は nil/cons の有限二分木、命令は定数・register 読取り・cons・左右射影の式による代入、
nil 分岐、goto、Bool を返す halt。構文に任意の意味関数・証明欄・oracle はない。
意味 `Executes` は有限な実行導出であり、停止を仮定した全域 evaluator ではない。

`CanonicalComputability.executes_deterministic`:
任意の有限 Program `P`、任意状態 `s`（pc と任意 register 割当て）、任意 Bool `a b` に対し、
`Executes P s a` と `Executes P s b` の二前提から `a = b`。
入力制限、well-formed address、全域停止の前提はない。
この定理追加後の `lake build --wfail` は終了コード 0（592 jobs）。

これは全 A2 文法の決定手続きでも不可能性でもない。還元元となる実効的な有限 machine syntax の基礎だけ。
次は、true を返す実行だけを無限 loop に変える実構文変換を証明し、対角停止判定の不存在を示す。
その後に、この機械の全有限実行と actual checked role evidence を双方向に接続する必要がある。

`CanonicalComputability.divergeOnTrue_step`:
任意 Program `P` と任意状態 `s` について、前提なしで、変換後の pc=`s.pc+1` の一歩は、
元の一歩が false 停止なら同じ false 停止、true 停止なら store を保つ trap pc=0 への一歩、
元の次状態 `t` への一歩なら pc=`t.pc+1` と同じ store への一歩に等しい。
範囲外 address の false 停止も保持する。追加後 build は終了コード 0（592 jobs）。

`CanonicalComputability.divergeOnTrue_trap`:
任意 Program `P`、任意状態 `s`、任意 Bool `b` に対し、
`Executes (divergeOnTrue P) s b` と `s.pc = 0` の二前提から False。
追加後 build は終了コード 0（592 jobs）。これは計算モデル内の trap の定理であり、role 解決の不可能性ではない。

`CanonicalComputability.executes_divergeOnTrue_iff`:
任意 Program `P`、任意状態 `s`、任意 Bool `b` に対し、追加前提なしで、
`Executes (divergeOnTrue P) (relocate s) b` と
`b = false ∧ Executes P s false` は同値。ここで relocate は pc を1増やし store を保持する。
追加後 build は終了コード 0（592 jobs）。

`CanonicalComputability.no_self_halting_decider`:

`Runs H (encoding P) true ↔ Halts P (encoding P)`。
encoding の計算可能性・単射性や universal interpreter は前提にしない。
