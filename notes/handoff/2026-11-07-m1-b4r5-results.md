## 1. 一つの未決点

spec6.3の「宣言時にwhereのsize/occurrenceを検査する」と
「variant payloadの合流を型が分かるまで遅らせ、合流後に数える」の接続が未指定。
別々だったpayloadが、実role引数の直接捕捉によって等しくなる場合がある。

```yulang
role R 'a 'row:
    type value

impl R 'a (:{tick (int, 'a), tick ('a, int)}):
    where 'a: R (:{tick ('a, 'a)})
    type value = int
```

具体goal `R int (:{tick (int,int)})` の最初の引数が'a=intを直接決める。
任意Common同値解や、record tailの恣意的捕捉は用いない。
symbolic Nで実size9/5、occ3/3なので実checkerはtrue。
捕捉後Nではheadもwhereも同じgoal、size5/5になる。
pairのunionを成分ごとに合流しても、symbolic9 / 捕捉後5は同じ。

一問を [capture-before-size](../questions/2026-11-07-b4r5-capture-before-size.md) に置いた。
推奨は、捕捉後の合流にも安全な宣言checkerでこのimplを拒否する選択肢1。
選択肢2は具体化後の新しい拒否、選択肢3はsymbolic checkのみ。
どれかをユーザーの決定として採用せず、各場合の局所検査を証明した。
この未決点を任意代入というモデルへ読み替えて、新E2として報告していない。

## 2. 新規定理の全量化・前提・結論

全定理のnamespaceは `Yulang.CommonRoleCaptureNormalization`。
Formはvar/int/pair/union/tickの有限countergrammar、normalizeは再帰的な同一union branch縮約。
このlocal stageを、全Common grammarのNまたは完全normalizerとは主張しない。
head/child/implementation/goal/captureは上の固定source例に対応する実有限データ。
任意代入の意味保存lemmaは解釈congruenceであり、solverの操作的捕捉の定義ではない。

| 定理名 | 全量化・前提・結論 |

## 3. grammar監査と正確な未証明lemma

表面のheadで許される基底/any/never/unit、tuple、arrowとeffect行、nominalとnamed再帰、
transparent alias、record first-wins/順序/幅、optional表示、closed variant row、
producer union/intersection、associated variable/equationを
[設計note §1](../design/2026-11-07-b4r5-head-grammar-and-capture.md#1-completeness-を主張する前の-grammar-監査) に列挙した。
aliasをnominalとして数える、行リストセルを数える、optional表示をsource注釈だと仮定する、
一般unionを要求位置へ追加する、他roleのassociated projectionを展開する、という反例は採用しない。

N後sizeが全文法のCommon同値headで不変であること、そしてそれだけで全捕捉の下降が出ることは未証明。
solverに必要な正確なlemmaは次。

```text
任意verified declaration i、任意型/行確定の有限regular goal g、
実matcherがgから計算したcanonical capture σ、任意実where child c∈i.constraintsについて、
  承認済みN後の宣言checkがiを受理し、両K2の禁止検査がなければ、
  size(N(c[σ])) < size(N(g))。
```

symbolic N checkだけを前提とした局所版は上の定理で否定した。
capture-safe宣言checkを前提にする版と、capture後の新しいuse-site拒否を入れる版は、この小例を拒否する。
これらを現契約へ黙って足していない。
別分解として、pair成分合流を先行させても同じ局所問題が残ることも証明した。

full resolver totality/exactness、全実dictionary、一般finite-tree/nominal agreementは未証明。
qualifiedについても、任意有限verified D/visible V/method M、有限kind付き自由名A、環境Γ、full式e、結果outで、
実有限package Cのordinary/associated等式とpending role辞書、共有captured/各使用generalizedが、
任意kind保存Common代入ρの独立QualifiedTypingとlocal割当てι存在を介してiffになるlemmaが未証明。
全返却schemeの任意無制約parameter soundnessと全元model回収も未証明。
