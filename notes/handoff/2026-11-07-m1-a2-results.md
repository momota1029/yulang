# M1 A2 results — 計算可能な完全 canonical code の障害

状態: **E2 に到達。E1 の `public_interface_canonical_exact` は証明していない。**
元の全有限 interface・既存公開 instance 意味・無制約 parameter の契約は変更していない。
計算可能な完全 code が存在しないことを、必要な構文だけを使う有限 interface 族への非停止帰着で Lean に証明した。
正確な変更提案は [未回答の問い](../questions/2026-11-07-a2-canonical-computability.md) に置いた。
案1（推奨）は全文法と意味を保ち、code 等号から意味同値への soundness を残して逆方向の完全性だけを外す。
ユーザーの承認前にこの案を採用していない。

## 主定理と量化・前提

以下で `model = Common.model.toModel`、`Interface = CommonCanonicalRowSyntax.Interface`。
`interfaceCode` は有限 token 列の自然数符号であり、意味的な `Common.Row` の述語を符号化しない。
`Runs` / `Halts` は有限 instruction table を持つ `CanonicalRegisterMachine.Program` の実行である。
計算可能性はこの通常の increment / zero-test-decrement / goto / halt counter model で明示した。

### 1. `CommonCanonicalUndecidability.no_computable_canonical_encoding_at_theory`

任意の固定 `theory : RoleConstraints.Theory model` に対し、次の関数と有限 Program は存在しない。

```text
encoding : Interface → Nat
machine : CanonicalRegisterMachine.Program

(∀ I : Interface, Runs machine (interfaceCode I) (encoding I)) ∧
(∀ I J : Interface,
  (∀ target : Inference.Comp model,
    QualifiedInference.BindingTyping model theory I.binding target ↔
    QualifiedInference.BindingTyping model theory J.binding target)
  ↔ encoding I = encoding J)
```

不正な数値入力での停止は前提にしていない。
比較する二 interface の parameter 数の一致、全単射、有限 row support、solver 成功、invariant の存在、
compiler の実現可能性は前提にしていない。

### 2. `CommonCanonicalUndecidability.no_computable_canonical_encoding`

上と同じ `encoding` / `machine` で、任意 `I/J` の意味同値を
**全 theory と全 target** に対する元 `BindingTyping` の iff とした二条件も同時には満たせない。
すなわち次は偽である。

```text
∃ encoding : Interface → Nat, ∃ machine : Program,
  (∀ I, Runs machine (interfaceCode I) (encoding I)) ∧
  (∀ I J,
    (∀ theory : RoleConstraints.Theory model, ∀ target : Inference.Comp model,
      BindingTyping model theory I.binding target ↔
      BindingTyping model theory J.binding target)
    ↔ encoding I = encoding J)
```

### 3. `CommonCanonicalCounterConstraints.constraints_iff_nonhalting`

任意有限 counter Program `P` と任意自然数 `x` に対し、
任意の Common rows を値域とする割当て
`ρ : Fin (P.states + P.states) → Common.Row` で有限 `constraints P x` の全 test が成立するものが存在することと、
`¬ Halts P x` は同値である。割当ての有限 support・regular 性や外部 invariant は仮定しない。

### 4. `CommonCanonicalCounterConstraints.public_instances_iff_nonhalting`

任意有限 counter Program `P` と任意自然数 `x` に対し、
`I = fixedInterface (constraints P x)`、`J = familyInterface (constraints P x)` と置くと、

```text
(∀ theory : RoleConstraints.Theory model, ∀ target : Inference.Comp model,
  BindingTyping model theory I.binding target ↔
  BindingTyping model theory J.binding target)
↔ ¬ Halts P x
```

が成立する。意味は元の公開 binding judgment であり、新しい α 同値ではない。

### 5. `CommonCanonicalReductionMachine.builder_program_runs`

任意有限 counter Program `P` と任意 `family : Bool` に対し、
固定された有限 Program `builder family` は入力 `programCode P` から
`interfaceCode (targetInterface family P)` を返す `Runs` を持つ。

`targetInterface false P = fixedInterface (constraints P (programCode P))`、
`targetInterface true P = familyInterface (constraints P (programCode P))`。
二つの builder は17 counter と有限 instruction table の実 Program であり、P ごとに別の外部 compiler を仮定しない。
元 source table の欠落は default halt、余分な entry は declared state 数以降で無視する既存意味と一致する。

### 6. `CanonicalRegisterRecognizer.recognizer_exact`

任意 `Index : Type`、任意三つの有限 Program `first/last/coder`、
任意五関数 `encoding/before/after/firstCode/lastCode : Index → Nat` に対し、
全 `i : Index` で次の四つの実行があることを前提とする。

```text
Runs first (encoding i) (before i)
Runs last  (encoding i) (after i)
Runs coder (before i) (firstCode i)
Runs coder (after i)  (lastCode i)
```

このとき単一の有限 Program `H` が存在し、全 `i` で
`Halts H (encoding i) ↔ firstCode i = lastCode i` が成立する。
実 copy、callee scratch 初期化、call、比較、zero の時だけ halt、それ以外の自己ループを構成した。
主定理では builder の二前提を定理5で、coder の二前提を反証仮定の実行契約で discharge している。

全補助定理の量化・前提、日本語の主張、各 build checkpoint は
[progress](2026-11-07-m1-a2-progress.md) に記録した。

## 帰着と全目標との関係

各 machine state に invariant row とその complement row の二 parameter を割り当てる。
有限閉再帰 row は自然数 counter grid と各 zero-plane を表し、head/protect/release により
初期値・increment・zero branch・positive decrement branch の有限制約を記述する。
cover/disjoint 制約が complement を固定し、halt state の invariant は空にする。
したがって全制約の解は非停止 invariant と同値になる。

入力行を共有する arrow の union が行の共通部分を観測し、`lock(T) = T → T` の正負共有が
部分型比較を元の要求同値に固定する。有限 test tuple を `F` と `G(ρ)` にして、
`I = F` と `J = F | G(ρ)` の上向き公開 instance family の等価性を制約解の存在へ接続する。
I の row parameter 数は0、J は `P.states + P.states` であり、等 arity の改名には縮めない。

builder と coder を実合成した recognizer H をその自身の `programCode H` に適用すると、
停止と非停止が同値となって矛盾する。主定理には未構成の計算的橋が残っていない。

必要な有限 symbolic grammar は次だけである。

- unit、pair、union、general domain/result の arrow。
- row head、union、protect、release、有限 `only []` mask。
- 有限 `AsRow` body で記述する閉 grid/zero-plane。
- 無制約 Common row parameters とその任意の正負共有。

record/default、weak/captured、nominal/role obligations、一般の regular **型** graph は帰着に不要。
role requirements は空なので固定 theory でも障害が成立する。
全 A2 grammar はこの essential fragment を含むため、全 grammar の計算可能な完全 code の存在も否定される。
部分文法の肯定的 canonical theorem を全 A2 の完成に置き換えたものではない。

ここで arrow domain は既存 producer `Common.Ty` の子である。
既存 `CommonCanonicalInterface.Form.arrow` 自体が union を含む `Expr` domain を許し、
recovery note §2 は任意の負の arrow 子を除外しない。
union-free な `CommonFinite.Demand` に constructor を追加していない。
実 source 生成器の像だけへの制限や別の極性付き有限文法への変換は今回の定理ではなく、
採用するなら問いの案2として量化域の変更と到達性の証明が必要になる。

## 残ること・確認していないこと

- E1 の全 grammar に対する computable canonical iff は証明していない。上の essential fragment で不可能である。
- 未承認の修正提案を言語仕様や元の theorem に採用していない。
- 全実 inference scheme の readback/export/EOF/display の保存・反映を今回完成させていない。
  初期 checkpoint の qualified-interface/実 EOF-use characterization は元の範囲で維持した。
  E2 は完全 code を伴う全契約の成立を阻むのであり、個別の表示・export の意味保存を不可能とする主張ではない。
- この帰着族が実 source inference の像に入ることは証明していない。元の全有限 interface 量化にはその前提はない。
- `wordCode_injective` は証明済みだが、dependent AST 全体の decoder/roundtrip 定理は別途追加していない。
  main theorem の明示的な計算契約と実合成による対角矛盾にはその前提を用いない。
- 実用的な表示アルゴリズムや Rust 実装の性能評価・parser からの新しい end-to-end test は実施していない。
