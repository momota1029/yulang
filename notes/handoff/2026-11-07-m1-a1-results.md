## 主定理と日本語の主張

以下では `old Comp := Inference.Comp CommonLegacyEmptyReflection.legacyModel`、
`contextualModel := CommonLegacyEmptyReflection.contextualModel` とする。
三定理の完全修飾名は、以下の名前の先頭に `Yulang.` を付けたものである。
実装は [CommonLegacySharedWitnesses.lean](../../lean/Yulang/CommonLegacySharedWitnesses.lean)、
監査登録は [Audit.lean](../../lean/Audit.lean) にある。

### `CommonLegacySharedWitnesses.legacy_generated_shared_witnesses`

任意の `e : Inference.Expr` について、`SourcePrincipalInference.supported e = true` ならば、
任意の `c : old Comp` に対し、
`PresenceGeneration.Typing Common.model [] e (Common.embedComp c)` が成り立つとき、
`normalise (principal [] e)` に属する実際の clause と、
一つの共有割当て `values : Fin (clause.locals + 1) → old Comp` が存在し、
出力 slot は値と行の組として `c` に等しく、clause の全制約を同時に満たす。

```text
∀ e : Inference.Expr,
  SourcePrincipalInference.supported e = true →
∀ c : old Comp,
  PresenceGeneration.Typing Common.model [] e (Common.embedComp c) →
∃ clause ∈ PresenceNormalForm.normalise (PresenceGeneration.principal [] e),
∃ values : Fin (clause.locals + 1) → old Comp,
  values (Fin.last clause.locals) = c ∧
  PresenceNormalForm.All Common.model
    (CommonLegacyTyping.assignment values) clause.pack
```

### `CommonLegacySharedWitnesses.legacy_instances_reflected`

任意の `e : Inference.Expr` について、`SourcePrincipalInference.supported e = true` ならば、
任意の `c : old Comp` に対し、
`(Core.infer (Core.Required.embed e)).Instance (Common.embedComp c)` が成り立つとき、
旧推論結果の instance である旧 computation `old` が存在する。
`c` と `old` の値の埋込みは `Common.Equivalent` であり、結果行は文字どおり等しい。

```text
∀ e : Inference.Expr,
  SourcePrincipalInference.supported e = true →
∀ c : old Comp,
  (Core.infer (Core.Required.embed e)).Instance (Common.embedComp c) →
∃ old : old Comp,
  (SourcePrincipalInference.infer e).Instance Common.rowAlgebra old ∧
  Common.Equivalent (Common.embedOld c.1) (Common.embedOld old.1) ∧
  c.2 = old.2
```

### `CommonLegacySharedWitnesses.typing_reflected`

任意の `e : Inference.Expr` について、`e.requiredFieldsOnly = true` ならば、
任意の `c : old Comp` に対し、
`PresenceGeneration.Typing Common.model [] e (Common.embedComp c)` が成り立つとき、
`Inference.Typing contextualModel [] e c` が成り立つ。
この補助定理には `SourcePrincipalInference.supported e = true` も不要である。

```text
∀ e : Inference.Expr,
  e.requiredFieldsOnly = true →
∀ c : old Comp,
  PresenceGeneration.Typing Common.model [] e (Common.embedComp c) →
  Inference.Typing contextualModel [] e c
```

## 構成

Common の任意の regular 型から実際の旧 regular 型への単調な erasure を構成した。
有限型での負位置 rank に関する帰納法と、観測の深さを切る操作の単調性を使う。
default の深さ 0 の挙動には、一段ずらした観測等式で対応した。
Common の具体的な graph 構文から有限閉 support を導き、旧 carrier 内の代表型を構成するため、
有限性を定理の利用者に要求しない。旧型の埋込みは erasure 後も全観測で元の旧型に等しい。

生成した Formula の clean 性から、全存在変数を一つの旧割当てへ反映する。
旧 contextual Typing と既存の `embedded_witnesses_iff_typing` により実 clause を回収する。
公開推論の系は `Core.infer_embed` と既存の旧 contextual completeness を使う。
行は erasure の全段階でそのまま保持する。

新 module は `CommonLegacyRecordErasure`、`CommonLegacyFiniteErasure`、
`CommonLegacyTruncation`、`CommonLegacyGraphSupport`、`CommonLegacyLayerErasure`、
`CommonLegacyRegularErasure`、`CommonLegacySharedWitnesses` の七つである。
全 module を `Yulang.lean` から import し、全公開補題と主定理を `Audit.lean` に登録した。
各補助定理の名前、量化子・前提を含む日本語の主張、checkpoint の結果は
[進捗記録](2026-11-07-m1-a1-progress.md) に記録した。
既存の定理は弱めていない。
