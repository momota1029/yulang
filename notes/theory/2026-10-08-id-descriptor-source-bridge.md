## 3. What source inversion actually constructs

Hypotheses: one ordinary unannotated, nonrecursive definition outside callback
position; lexical resolution of the body occurrence to its sole formal; no
capture, explicit computation annotation, adapter, existential opening or
operation declaration in this definition. Its argument at a later use is not
restricted to a pure, returning or first-order carrier.

The selected parameter rule allocates `A` and constructs `P = Value(A)`.
After the selected entry rebind, `Gamma_body(x) = Value(A)`. Name synthesis
copies that exact interface; result synthesis constructs
`Result(Value(A)) = Comp(empty,A)`. Ordinary introduction selects Pure before
effect-port elaboration. Thus the derived body/result skeleton is

```text
Value(Fun(Value(A), Comp(empty,A)))
Normalize(body) = result(name x).
```

The derivation also establishes a lexical fact stronger than repeated type
spelling: the returned data is the result of this formal's actual rebind. At
compile time, the owning constructor can record that fact at the typed
receipt/result paths. The result operation returns that provider package
without consuming any latent interface of it. The original receipt, rebind
and invocation consumer are still present; their validity is not proved by
the shared endpoint.

This supplies a finite *constructor certificate*, relative to the existing
typed-path/primitive premises. Its checking obligations are exact source
occurrence resolution, the one parameter/result endpoint, actual entry and
consumer, absence of a capture, and all original scope/dependency operands.
It is not a certificate that every raw source path is already decorated or
admitted. In particular, a source name rule does not define `DescMem`.

## 4. An explicit conditional decoder constructor

The following is a candidate specification interface, not a selected type
constructor or runtime representation. Fix once a decoder `Dec` and its
primitive contract environment `L`. Publication for this case is

```text
Sigma = forall q. q -> q
alpha = formal-result incidence schema (v,o), if Dec cannot recover it
        plus any role/entry/consumer schema not fixed by Dec's arrow meaning.
```

The binder and its sharing belong to `Sigma`. Decoder rules may contain the
uniform Pure/Value/Value-result conventions once. No lower bound requiring
separate per-export tags or the incidence in `alpha` is claimed. Conversely,
repeated `q` alone is not a derivation of provider identity. The schema is a
typed incidence fact, not a source Lambda root, reference to the definition,
execution trace, arbitrary predicate, or table of complete histories.

For a use `u`, the constructor does the following, in this order:

1. Freshen the eligible binder and local position schema by one simultaneous
   legal action `rho_u`; keep rigid/ambient operands and the original joint
   dependency assignment fixed. Generalization eligibility and scope legality
   are explicit premises, not inferred from displayability.
2. `Dec(rho_u(Sigma,alpha),L;xi)` forms the legal descriptor `r_u`, with
   carrier port `i_u`, designated demanded result `v_u`, returned result
   `o_u`, and `v_u.type = o_u.type = q_u`. The actual receiver activation and
   caller's whole carrier are use inputs. This construction does not invent
   a wrapper receiver or replace the runtime closure's selected boundary.
3. The decoder exposes **active** admission `A_u`, whole membership `M_u`,
   and ordinary descriptor membership `DescMem(r_u,...)`. The same original
   scoped tuple is used in every conjunct. `r_u` is the descriptor produced
   from the published export; no source root is substituted for it.
4. The use conjoins its independent caller constraints and a single
   `Direct(r_u,F_use)` at this very root. Its final projection is the original
   `Pi_xi`, after whole-observation reasoning.

An explicit source-base clause schema for step 3 is the relational image of

```text
actual receipt/boundary;
Force_argument(i_u) >>= (v_u,current_state).
typed RebindResultPath(i_u,v_u,current_state);
ValueResult(v_u) >>= actual ReturnFromInvocation.
```

All operations here are references to uniform independently interpreted
contracts in `L`, instantiated at the typed ports. This equation specifies
the decoder's proposed port interpretation. It is not a use-time reference
to `result(name x)` or its source relation. The source proof justifies the
replacement at construction time. `o_u` receives the same value/provider
through the existing typed transport. The image includes Return, Request
with original raw suffix, finite prefixes and divergence under the existing
contracts; it is not merely a row equation.

The separate admission schema has exactly these candidate constructors:

| Admission constructor | Required supplier, independent of `Direct` |
| --- | --- |
| Initial context | Typed punctured caller context, actual receiver/receipt, whole argument, result path and one original joint assignment. |
| Response | Typed response at the exposed operation's original witness and current state. |
| Resume | Original raw resumption handle with its pending suffix and dependency operands. |
| Future use | Independently typed use at a returned provider's original designated port, including the full reachable provider interface. |

The caller/provider supplies these premises at use time. No finite list of
its future histories is stored in `alpha`. Structural induction over an
arbitrary finite history is possible only after these primitive judgments
are supplied. An admitted divergent carrier stays admitted without a Return.
The scheme's binder need not expose an argument-effect coordinate merely
because `J_call` depends on the caller's carrier; this is a decoder obligation,
not a proved complete invocation scheme.

## 5. Residual supplier premises and conditional theorem

The constructor requires these distinct suppliers. Calling them a decoder
does not establish them.

| Supplier | Exact premise and failure condition |
| --- | --- |
| S1 legal formation | `Dec` constructs a legal existing inferred descriptor from the published inputs and exposes its actual complete clauses. Four typed ports, an inert provenance edge or a proof label without that formation rule fails. |
| S2 local typing/activation | For each source-base clause, establish its typed observation under active `DescMem(r_u,...)` with the original primitive/transport proof and the same scope map; the source-base observation may not be rejected. This clause-level condition does not forbid complete production observations introduced by `W,Z,G`; S4 must pair and account for those. Defining `DescMem` to be the wire's image is not a proof. S2 alone does not establish equality of complete observations. |
| S3 independent admission | The four admission constructors have the same complete domain as the selected source instance under one whole map, including current state, raw resumptions and future providers. No pending comparison, solved row spelling or successful source-root query supplies a premise. A missing admitted divergent carrier or mismatched future provider domain fails. |
| S4 complete production interpretation | The actual export's entire membership grammar, guards, primitive alternatives and admission-live extras are supplied. For the equality theorem, pair source and export derivations in both directions, including the `DescMem` conjunct and observations introduced by `W,Z,G`; pair all operands and alternatives with independent domain certificates, and establish equivalent complete hard envelopes under the same scope map (`Eq(G_source,G_export)`, or `Le` in both directions). Source-contracts §3.7 permits a single `Le` and then proves only containment; that weaker route does not establish this theorem's equality. A source-base-only grammar or `W=Z=empty` is not a proof about the approved production contract. |
| S5 transport | Eligibility, one capture-avoiding action on every binder/path/primitive/abstract operand, original rigid imports and joint `K,D`, and any joint hiding/admission certificate. Separately freshened provider evidence or segment-local hiding fails. |
| S6 actual-root query | Ordinary resolution accepts a checked finite proof for the descriptor actually produced by `Dec`. For the §5.3 sufficient rule, expose its whole admission and complete membership, match role/entry/consumer and fixed interface, prove `Eq` of admission and `Le` of membership under one original scope map. Successful comparisons at another hidden root do not satisfy this premise. |

**Conditional constructor theorem.** Assume the source hypotheses of §3,
its primitive/typed-path premises, S1–S5, and the bidirectional descriptor,
guard, and exhaustive-grammar pairing stated in S2/S4. Then the decoder
produces an active legal transformed instance with the same independently
admitted domain and equal complete observations, under the single port map.
Under S6, a §5.3-compatible use with an actual finite `Eq/Le` certificate
receives ordinary complete-query evidence at `r_u`. If only the one-way guard
`Le` permitted by source-contracts §3.7 is supplied, the supported conclusion
is the corresponding containment, not equality; that weaker route does not
discharge this theorem's premise.

**Derivation.** Source inversion resolves the returned name to the rebound
formal. In the source base, substitute that typed data result for the lookup;
both images retain the same receipt, demand, rebind and invocation consumer.
The replacement is at a single constructor occurrence, not an equation
between outward rows. The existing bind law carries it through request
continuations with current resumed state and the original suffix; provider
transport carries it through later uses. S2 activates the source-base clause
observations under `DescMem`; S4's bidirectional pairing accounts for every
complete observation on both sides, including production alternatives.
S3 supplies the domain proof separately. Under S4's bidirectional route,
induction over the paired positive abstraction
derivations transports source leaves, unanchored `Z` leaves, `W` steps and
both directions of the full guard. Any changed admission-live abstract
provider needs its separate S3/S4 certificate. The weaker one-way guard route
supplies only the inclusion indicated by that guard proof.
S5 transports these proofs to the fresh instance; one final projection gives
the corresponding complete observable result. Finally S6 applies the
ordinary Function rule to the exposed transformed roots and the actual
certificate, rather than converting semantic containment directly into
`Direct`. QED, conditionally.

S1/S2 are the remaining P2 suppliers; S3 and the admission-live part of S4
are the remaining P4 suppliers. S6 is distinct from both. Source generation
can furnish certificate operands; it cannot select or prove the governing
descriptor and resolver laws.

This theorem is deliberately restricted to uses that possess the stated
finite certificate. It does not establish that every independently valid
public view has one, that a new query algorithm finds it, or that all views
factor through the export. P6 remains open. There is no execution or
checker in this note that assumes a transition system and then claims to
have proved its source rules.

## 6. Exact blocker and possible next methods

The stopping premise is the decoder's **independently meaningful complete
descriptor/admission interpretation and ordinary query law**, including
production-only alternatives. Source-contracts §1 expressly says source
hypotheses cannot supply that meaning, §2.2 states active interpretation as
an additional hypothesis, and §5.3 states local resolution conformance as
another hypothesis. Those passages are the documentary reason P2/P4 are
still conditional; this is a bounded inspection, not a repository-wide
absence proof.

Two effects can be compared by the primary without deciding here:

- A uniform ordinary-arrow decoder can supply the fixed conventions, with
  only independently necessary incidence/dependency information in `alpha`.
  It must prove complete-domain/descriptor and actual-root query laws for its
  decoded arrow. An ordinary conservative result contract may forget
  source-base provider equality; equality of its complete solution family
  then needs the corresponding abstraction proof, not the exact-wire theorem.
- A finite typed interface certificate can retain source-established
  incidences that the ordinary decoder cannot supply. Its decoder still
  needs S1–S6, and each retained fact needs a use obligation justifying it.
  Source-base incidence need not be a universal restriction on every allowed
  Option 2 member: the actual abstraction guard must determine that. A
  certificate containing the whole source relation under a new name fails q1.

These are candidate proof/representation routes, not new language meanings
or a conclusion that nonempty per-export `alpha` is required. Changing the
complete semantic contract requires the primary's authority/approval process.
No such change is made here.

**Recommended next action:** supply and freeze one proposed ordinary decoder
for this envelope, with its exact active descriptor/admission clauses and
actual-root query rule. Independently review S1–S3/S6 before asking another
model to assume them; separately retain S4 production conformance and P6
all-view factorization as open.
