## 2. Proposed complete capture output, before its Function proof

at its actual capture boundary. Its saved part is built from:

```text
S ::= Hole | Bind(S,F) | Owner(i,u,S)
    | ForwardHandler(H,ownerSlot,S) | View(v,p,S).
```

F is the ORIGINAL suffix label with its typed lexical environment; it is not
an arbitrary host function. Define capture output by dependent record
introduction over precisely these operands:

```text
RawCapture = (
  original request q, operation declaration/instance and packet maps,
  original event/origin, response alpha telescope and current-state ports,
  original capture delimiter/source position and raw-continuation identity,
  Saved(S), original environments/aliases/cell references,
  every saved typed packet/view/port/profile/evidence root,
  original K/D ledger, typed incidence/path maps and runtime lineage,
  every actually installed private/Mono/Shared contract and its substitution,
  raw response/resume/future schema assembled from the original frame
    interfaces and compatibility domains, not an assumed membership proof

```

The telescope order is the original source/frame order, not the displayed
flat list. A later field may depend on its original earlier operands. Packet
maps are the original lawful maps; nu is shared throughout. Ledger retention
preserves predicate identity and all its incidences. Historical event and
return coordinates remain historical. The live configuration supplied at a
later resume is a different argument, never a saved-store snapshot.

The complete source checking derivation for the resumed code is separately
retained as `SuffixProof(S)` at its original Check/EventProof telescope.
Its source rule operands include these SAME actual saved fields. This
separation is a projection of constructor outputs, not an erasure of typed
views or proof irrelevance. Any subfield genuinely installed by evaluation
belongs in RawCapture with its full original dependencies even when also
used by SuffixProof. No existing installed field is retagged logical.

## 3. Constructive projection and control preservation

Construct Saved(S) recursively on the five constructors. Each clause pairs
its own original operands with the already constructed child; its projection
returns those operands literally at the original dependent indices. Conjoining
the original local typing premises constructs SuffixProof; no whole desired
Function membership is an ambient premise of this record introduction.
This does not prove those typing premises for an otherwise untyped source.

Erasure to saved control is the same recursion. Hole supplies the actual
response and current C. Bind executes the child, and only its actual Return
passes the same z/C2 to F; Request reattaches that same remaining suffix.
Owner uses the existing borrowed/owned activity cases, restoring its parent
completion before continuing. ForwardHandler creates only its source-prescribed
fresh handler and completes its value arm before its parent. View restores
the exact saved packet/port with a fresh executing view occurrence under the
resumer's current context. It neither restores expired receiving authority
nor replaces the ambient view. Only the raw capture root returns to the
resumer. These are exactly typed-source sections2–3 and typed-boundary section4.

Induction gives equality of each Return/Request/control step after forgetting
the projection/checking record split. In particular the split neither executes
nor re-executes any check, body, conversion, receipt or boundary entry. Repeat
the same induction at each compatible resume; each invocation has its own
pending/control frames and uses the actual current state. Alias retains the
same raw capture, original contracts and identity; it cannot create a new
source instantiation or an independent response history. No future domain is
enlarged, and no arbitrary client W is assumed satisfiable.

The source Function-introduction proof for raw k must consume the response
entry rule and these original SuffixProof premises at their original indices.
Its response-input and suffix-completion interfaces remain dependent, including
the argument Force, current state, arbitrary pending developments and future
restrictions. Four displayed public Function ports alone do not prove this
complete introduction. The projection is available before that proof and
does not manufacture acceptance by invoking its desired conclusion.

The interface is assembled as the original local source rule telescope before
proving its truth: Hole has the declaration response input; Bind composes its
child output with its original suffix interface; Owner and View retain their
original phase/view premises; ForwardHandler uses the existing shallow image.
This constructs operand slots and ordered equations, not truth of an opaque
primitive relation. The final `Btheta => J_raw` uses this SAME complete suffix
interface, not merely its public final value/effect projection.

## 4. Exact support theorem, without a no-free shortcut

Write FVactual(T) for the free Desc occurrences reached through an ACTUAL
field/type/substitution by source-Generalize's fix walk. It includes full
installed private/Shared/Mono fields and any actual packet/contract dependency;
it excludes a merely hypothetical binder introduction in an unexecuted rule.
Keep logical proof operands in their original retain/checking regions.

The frame induction proves:

```text
FVactual(RawCapture, installed Btheta => J_raw)
 = FVactual(original q/response/raw interface)
   union union_{captured frames f} FVactual(actual operands of f)
   union FVDesc(the ENTIRE installed Btheta => J_raw).
```

Each inclusion follows by dependent-record projection/introduction. In
particular capture does not add an evaluated dictionary for A1, but it does
not remove A1 already free in a saved environment/view/installed contract.
Fixing an original instantiated contract H[delta:=d0] still follows every
free field after that actual substitution. A static source position and its
logical description variable must not be identified with an evaluated Desc
dictionary; equally, that distinction cannot erase a genuine dependency in
the TYPE of a saved packet or installed contract.

For the Bind frame specifically, there is no edge through an ACTUAL g entry
before Return. The proposed construction derives the pending g:A1 judgment
under the future response/Return and checking telescope. Its original body
proof is Check/EventProof at that telescope, by the Bind introduction and
source-Generalize section3.3. This removes the previously unsupported claim
that capture itself has already installed g's entire checked certificate.
It does not prove every other summand of the support equation excludes A1.

In particular EventProof is NOT an erasure rule for an index in the TYPE
of an installed contract. If J_raw has free A1, h's Mono(k) edge reaches A1
even if the evidence proving membership at that index is logical. That is
a different path from a nonexistent already installed g entry.

## 5. Concrete raw-resumption discriminator

Use the following source-level construction; the display is semantic
pseudocode, not a parsed/inferred fixture:

```text
choose : Unit -> (Unit -> [ctrl] Int)
f(Unit) = perform choose(Unit)
receive(f : Unit -> alpha) = let g = f(Unit) in g(Unit)

outer shallow handler around receive(f):
  choose(_,k) ->
    let zero(Unit) = 0
    let h(Unit) = k(zero)
    k(h)
  Return(v) -> v
```

Here alpha is the original response Function view, not A1. The explicit ctrl
allowance permits the conservative whole-scrutinee suffix guarantee; it is
not a claim that raw suffix execution emits another ctrl request. No recursion
in h is needed. Typing still requires the actual source response/continuation
and full Function introduction premises, not just these printed arrows.

The selected operation's raw suffix contains the unfinished operation consumer,
f return/completion, first-call result/check/rebind, pending Bind of g, then
the g(Unit) suffix, with original owner/view delimiters in their source order.
The outer selected handler has no saved wrapper. Before the first resume,
g has no bound value. On k(h), the actual response h completes the original
f invocation; only then does ResultBind install that same h in g. The suffix
calls h; h calls k(zero), whose separate resume supplies zero at the SAME
original response slot, then reaches the corresponding actual Bind and calls
zero. Each nested resume uses the current configuration. This is not an arm
which merely escapes the first call without installing g.

The retained h-to-k capture is real. The proposed telescope proves that its
path through *already installed g* is absent at the first capture. It also
locates precisely where the remaining paths must be inspected: original
request/raw-response interface, captured typed lexical entries, and crossed
View packets. Neither the source code of g(Unit) nor its hypothetical g:A1
proof establishes an installed `Mono(k,H[A1])`. The example is therefore not
a source-qualified fixed-A1 counterexample established by this note.

## 6. Installed J_raw: exact scopes and the remaining source rule

The operation-package introduction is essential to the final dependency walk:

```text
handler arm Gamma, k : (Btheta => J_raw)
    -> ordinary closure capture by h
    -> Mono(k, the ENTIRE Btheta => J_raw).
```

The declaration response is original alpha in this case. There are no local
declaration binders which can stand for A1. More generally theta substitutes
ONLY declaration binders, fixing the outside source environment. Original
Apply c introduces A1 at its source description scope before the particular
request/return; AppTarget formation also precedes that event. Request opening,
raw capture, handler binder introduction and h's lexical capture do not bind
that original A1. Consequently any occurrence of A1 in the supplied J_raw is
FREE relative to k's installed interface. It is not rendered bound by the
response binder, a new execution owner or the later g binder.

The exact open source-rule presentation assembled by section3 has the segment

```text
response r : Value(alpha), current C
 -> designated operation consumer / original f completion
 -> SAME first-call Return z/C2
 -> AppTarget_c(A1,E1) check / ResultBind_g(A1,z,C2)
 -> original g(Unit) suffix / original completion.
```

In THAT complete open presentation A1 occurs free in the checking/ResultBind
operand types, at its original outer scope. It is not an actual installed g
value, but is a free index of the complete open suffix contract. If this
presentation is the installed J_raw, the fixed edge through Mono(k) EXISTS:
source-Generalize follows the entire installed interface, including that
index. Separating its proof fields does not make the edge disappear. This
is a scope calculation, not an assertion of an executed A1 dictionary.

The first precise unsupplied source rule is the passage from this complete
open suffix-rule telescope to the operation package's installed interface
parameter J_raw. Its section7 explicitly takes J_raw as an assumption, and
says theta does not establish the suffix guarantee. Typed-source section2
constructs the typed suffix label/environment and control, but supplies no
additional rule which seals an OUTER Apply-owned A1 inside the installed
raw-continuation interface. The selected ResultBind projection separates a
logical proof at A1 from actual returned fields; it does not abstract A1 out
of another already installed Btheta=>J_raw contract.

Thus this note proposes the complete frame/payload projection, but does not
select a new hiding/generalization operation at J_raw. The fully open
presentation gives the free-A1 edge just calculated. A claim that the actual
installed interface instead has A1 only in a separately bound proof family
requires an ORIGINAL suffix-interface introduction/elimination law, with its
exact binder and scope. Introducing a new binder here by definition would
change the generalization premise being tested. The existing source authors
have not supplied that law at this input, so no such operation is inferred.

The second inherited input is the entire saved View packet: full contract,
profile, K/D and actual substitution. Typed-source section1/typed-boundary
section4 take these decorated operands as inputs. Their supports must also
be retained, never assumed empty. The formal f has full alpha; selected
AppTarget creates no runtime view. Neither fact resolves the FIRST installed
J_raw interface issue above or removes any original enclosing-view dependency.

The concrete raw route is therefore not certified as an independently typed
counterexample: full raw-k membership and the uniform arm proof must use the
same J_raw, including its scopes, rather than choosing a convenient public
arrow afterward. Conversely, the proposed projection does not establish
no-free or local eligibility. The next decisive source-owner action is to
instantiate the existing operation-package J_raw input with the ORIGINAL
Bind/Call complete suffix interface, explicitly showing whether and by which
existing source rule the outer A1 is bound. The open presentation above gives
the falsifier if it is retained. This is one interface-formation question,
not a request for an exhaustive raw-k/private-provider catalogue.
