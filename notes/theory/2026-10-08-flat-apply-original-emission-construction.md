## 1. Objective and result

The target is an **actual original** source-owned emission package for the
inner elimination `c = Apply(Name(u_f),Literal(a,"1"))` in `my apply f = f 1`,
including authentic port registrations, rule installation, all original
emission occurrences, and their dependent attachments. The accepted Name
argument obstruction and the proposed `Rep = Keep + Add` representation are
inputs to this audit, not new attacks or original emission suppliers.

The forward construction stops before it obtains original operand Result
origins. The reference source rules construct the two normalized operands,
but the selected original rules do not supply a registration operation at
this flat source owner. Even supplying those registrations would leave
original installation and emitted-membership unsupplied. Thus there is no
actual original-emission theorem here. The result is a necessity derivation
for these two distinct cuts, an exact attachment dependency spine, and a
conditional assembly theorem whose hypotheses are stated separately from its
conclusion. It does not repeat the construction of `P_c^cand`.

This is a bounded statement about the assigned sources. It is neither a
repository-wide nonexistence result nor proof that ordinary literal arguments
need a different language meaning or a new source restriction.

**Derivation.** Name follows the actual local binding selection. Literal copies
the independent primitive and its relation. Both carry a Value source tag, so

```text

  let t = Delay(Return(1),references(T)) in ExecuteCallable(v,t).
```

This calculation determines the code and its reference interfaces. In
Call-input §3.1, **Code-Result additionally requires the original result
node/port**. Thus `n_f` and `n_a` as normalized reference terms do not yet yield
the actual `q_f` and `q_a` derivations needed by original Code-Call. The
literal leaf is also outside that note's displayed Name data grammar; its
reference primitive cannot be silently relabeled as Data-Name.

## 5. Why the construction stops; exact missing laws

Consider finite source-construction proofs using only the assigned original
rules and the independently supplied input leaves above. Within that rule
inventory the supplier relation is:

```text
Gen-Call-0(selected Name/Name) -> selected actual record
OSig-Demand(scoped demand)    -> signature root
OC-CallEff(actual record)    -> Call-effect occurrence / O0
OShared-Register(Reg)        -> shared source anchor
OSlot-SharedInvoke(Reg,Route,actual record,O0) -> slot
OOwn-Upper(...,actual record,O0,seed)          -> lexical owner
OOwn-Upper-Checking(...,actual record,O0,seed) -> checking owner
Code-Call(actual Application and emitted operand origins,...) -> Check/code
Keep/Add(supplied old record or candidate)     -> proposed Rep
```

The accepted Name/Name applicability obstruction prevents using its first
line for c; this audit does not reconstruct that counterexample. Every other
consumer of a flat actual record is downstream of it. No listed conclusion
is a flat original registration operation or original installation witness.

**Bounded acyclicity lemma.** These downstream rules cannot provide their
own missing original source premise.

**Proof.** Rank every finite derivation node above its premise nodes. A proposed
cycle `e_c -> O0_c -> slot_c/owner_c/Check_c -> e_c` would require e_c to have
both a smaller and larger rank. OShared-Register cannot break the cycle:
its conclusion is an anchor and its input is Reg, not vice versa. OSig-Demand
can construct a signature root independently, but its conclusion is not an
original source emission. Keep/Add changes the conclusion family to Rep.
Hence no cited downstream construction discharges the missing source
registration/installation premise. This is a finite rule-inventory result,
not a theorem that all possible original formalizations lack such a rule.

The earliest missing law is **R-flat**, an original owning registration
operation for this flat derivation. Starting from H-input/H-primitive and
actual child constructors, it must return typed original formal-contract,
operand Result, Call argument Reify, checking and result/ElimOrigin ports,
with constructor-parent/scope eliminators, freshness/reuse and one whole-map
law. This is a refinement of H-R's missing supplier; the present named keys
and the shared-anchor definition do not implement it.

After R-flat, a separate missing law is **E-flat**, admission of the genuine
literal-arm source derivation at its actual original owner/root. It must
install that arm with retained insertion/lookup, produce original emitted
membership in a fiber retaining LiteralOrigin(a), and retain all original
atom occurrences and dependent attachments from §4. This requires resolving
the already recorded argument-family representation seam. Rep equality or
candidate per-atom records cannot replace it. If the family is completed,
the old Name constructor equations and independent original cases must be
preserved. If a separately fixed family is used, its authentic typed bridge
is required instead. This audit selects neither representation route.

**Conditional assembly theorem.** Given independently justified R-flat and
E-flat at the original owner, a lawful argument fiber/bridge, and the same
primitive/reference input laws, the finite spine in §§3–4 constructs the
actual operand origins, argument Delay, authentic emitted record, complete
Check and selected O0/slot. Given additionally the independent flat
SeedExposure, both selected O1 facets follow.

**Proof.** Apply R-flat at each owning constructor, in child-before-parent
order. Literal uses its genuine primitive; Name its actual route. Introduce
the scoped complete demand once and emit the independently interpreted
reference occurrences without testing their truth. E-flat installs this
source arm and returns its actual emitted membership and original inventory;
retain all of it. Code-Result, Carrier-Delay and Code-Call now have their
formation premises. Project this actual e_c into selected OSig-Demand and
OC-CallEff, then OSlot-SharedInvoke with its reg/route. Apply the two owner
rules only with the separate seed. Whole action follows only with R-flat's
registration and E-flat's installed-emission/inventory laws. This proof
does not derive those laws, semantic acceptance, or a satisfying provider.

The minimal next supplier on this route is R-flat. E-flat remains necessary
even after R-flat. No assertion is made that these names are globally minimal
axioms or that a genuine user semantic decision is already necessary.
The full authentic inventory is not specified by the displayed reference
atoms; supplying its preserving original installation law is part of E-flat.

## 6. Independence, omitted cases and stop boundary

There is no executable oracle or model in this lane. The reference construction
shares the cited primitive, normalization, complete-call relation and source
indices with the proposal. Agreement of their code templates is conditional
equation evidence, not independent proof of original source rules. The
necessity and rank arguments inspect rule premise/conclusion dependencies;
they do not assume an actual flat package exists.

No search, seeds/ranges, executed mutations, runtime traces or timing samples
were used. Analytic shortcut failures are explicit: replacing a Result origin
by its key fails Code-Result's premise; creating O0 first fails its actual
record premise; bundling true inequalities fails emitted-origin premises;
casting Add into original membership changes the conclusion judgment;
reusing argument Reify as result Reify loses their different parent incidences;
dropping an extra original result atom violates authentic inventory retention.
These are derivation failures, not executed mutation results.

Coverage is the one flat inner literal elimination and the named selected
source/consumer rules. Other original introducers, computed arguments or
callees, other literals/annotations, recursive or State/method sources,
late/multiple seeds, exhaustive inventories, semantic assignments, CallInitial,
C0/C1/J0, independent admission, principality/export and implementation are
unverified. The flat seed is deliberately not proved by literal Int,
unannotated use syntax, a Pure lower provider or the established nested S1.

The stop condition from the assignment applies: selected source authority
does not supply enough for the original constructor. No further candidate
checker is run. The exact blocker is R-flat, followed by E-flat/argument
fiber installation; all downstream consumers leave these untouched.

Resources: one producer, one leased Markdown output, zero children, builds,

supplied; CPU, peak RAM and reasoning wall time are uninstrumented. Initial
