## 7. Falsifiers and limits

These are explicit discriminators of proposed mappings, not executed tests or source-qualified counterexamples to the parent.

1. **Lost dependency/scope:** take a well-typed opaque field `p : Provider(T(a),sigma)` in a copied dependent presentation. 2. **Lost contribution association:** retain distinct p,q at the same family/type point and x, but only p has a supplied applicable ingress. A map that substitutes q for p by family equality has no At(D,q,delta_p) derivation. This does not assert arbitrary At choices are emitted by native code; it tests the stated proof operands.
3. **Collapsed uses:** let two successful uses share the nongeneric x. A map indexed only by canonical x returns the same use record, although begin_use allocates distinct live context_use values (:2627–2630) and each source call owns its demand. Such a map cannot reconstruct both IncUse tuples. This is independent of whether row constraints later relate J1/J2.
4. **Dropped tail/future:** let an actual later derivation bring write through a still-live anchor/tail. A capture interpreted as a closed finite list of current lowers loses that derivation; Permission(ctrl) cannot exclude it. The local proof retains the anchor and states a pointwise later-event result, leaving generation/scheduling completeness open.
5. **J1/J2 confusion:** a supposed second-call proof ending at the k1 child Y+ <: J1 never uses the result-effect child of Inner+. Its endpoint is wrong even if canonical rows eventually coincide.
6. **Initializer replay:** a fresh-use construction that schedules k1/Work::Install again changes one-shot source computation into per-use computation. No inspected fresh-use owner does that; such an implementation would falsify U's source timing correspondence.
7. **False generic scope claim:** for an owned root with old parent p and different caller c, native fresh attaches it to c. An assertion preserving `parent(root)=p` is false unless the boundary relation is separately transported. The actual direct g route has c=p=r_B; the proof does not export that equality to foreign contexts.
