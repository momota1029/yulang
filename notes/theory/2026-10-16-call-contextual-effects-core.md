### 3.5 Local interpretation, finite generation and falsifiers

finite original interaction or licensed prefix. An incident opaque application

joint source parameters throughout. Entry expands to the original fresh
observer push; invert that graph for the reverse step. Child execution uses

removal and the same parent dispatch; inverse expansion recovers that source

completed image for an unknown child or invokes a desired Image predicate.

exactly the same executing extent on both sides. Thus an event's observation

encloses that event. Suspended views contribute no new observations. This
uses the original event projection; it is not a new guard or event-to-port
oracle. Result-provider and residual/witness identities never become oV.

- `CapView(...,k_foreign,...)` has a valid outer generated tag, but its later
