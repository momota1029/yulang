## 3. Complete declaration telescope at the source rule

Use the original operation-instance package, not independent marginal
instantiation. An original declaration has

```text
Delta |- op : forall rho_family, beta_local.
              Sigma(rho,beta) = (payload A, response B, full profile Lambda).
```

`Delta` contains shared/rigid roots; `rho` supplies original family arguments
when present. A lookup supplies one capture-avoiding `theta` fixing `Delta`:

```text
i = (op, F(theta rho), A theta, B theta, Lambda theta).
```

The HIR example has empty `rho,beta`; a signature containing `'a` has a
nonempty original local map, and all its occurrences share it. This is the
source declaration-use instantiation law; the current name-to-row maps do
not independently prove safe generalization or the complete existential
checking discipline.

The source-defined operation's interface is formed in the following order.
These are the original fields of the cited source rules, not newly supplied
primitive permissions:

1. Declaration identity and full `Sigma`; `theta`; the original use/root,
   lexical scope and origin; role and typed-path derivation from the declared
   outer payload annotation; the current source world and joint `xi`.
2. The actual provider `Operation(op,decl)[theta]`, its complete Call entry,
   actual receiver activation/typed receipt, and the admitted **whole** input
   carrier `t`. Strict/value entry consumes its selected outer computation
   once; retained-computation entry stores that same carrier. Neither case
   recursively forces a latent payload value.
3. In strict entry, each original Return/Request/divergent prefix of `Force(t)`
   and its actual live state. A returning branch supplies `a:A theta` and
   original typed rebind evidence. A requesting branch supplies its own full
   packet and continuation; the native body and all later suffixes are still
   pending. No request from this branch is replaced by the declared E family.
4. `MakeRequestThunk(i,a)` returns as inert computation data through the
   native invocation return delimiter. Its stored tuple retains `i,a,theta`,
   the source origin, `K,D` and the original typed references, without saving
   store contents or active handler snapshots. This is an actual introduced
   carrier provider with the latent relation in §4.
5. Only the designated result consumer/Force introduces the dynamic event
   and yielding configuration. It supplies the same `i,a,theta,K,D` and its
   original observation/visibility inputs. For each admitted response
   `r:B theta` at its live resumed configuration `Cnow`, the primitive
   response continuation returns **that same r**. Any surrounding suffix
   contributes its own original result and output-dependent future relation.
6. For operation-local binders, the request packet keeps
   `exists beta_local. (a:A, raw_k:B => J_q, Lambda,K,D,latent dependencies)`.
   Arm checking opens fresh rigid `kappa` uniformly under declaration bounds;
   actual application uses cut at the retained `theta`, with captured roots
   shared. The hidden response/continuation witness is never independently
   chosen, and caller-private equations are not generic arm assumptions.

For a functional or computation-valued response, the returned provider is
the actual `r` received from the responder, together with its own complete
original latent/future interface. It need not be a closure with a source
body. The operation neither fabricates that future behavior nor converts
it into the request carrier's interface. At bare response Return there are
no further immediate requests, but `r` can have nontrivial future behavior.
After an arm selects, the **arm's actual output provider** can instead govern
the outward result and future family. This is fixed by the arm, not by `B`.

The independently necessary original store/typing/profile/admission premises
remain necessary. A syntax tree, signature row or a positive Support member
does not prove their truth. The complete `Lambda` and receipt laws above are
supplied by the cited source derivation, not recovered from Function4.

## 4. Concrete local equations and finite action

Fix those original operands. Write `T(i,a)` for the original inert request
carrier, `Omega_u` for the invocation's genuine return delimiter, and `S`
for the original ordered continuation from the primitive response through
any designated-consumer completion/view/owner frames and the surrounding
source continuation. These are references to actual source nodes/frames;
`S` is not obtained by dropping administrative frames. For a strict
payload, the source rules give

```text
Lookup(op,theta,C) = Return(Operation(op,decl)[theta], C)

Native_i(t,C) = Invoke_u(receipt;
                Force(t) >>= lambda (a,C1).
                  Rebind_i(t,a,C1);
                  Return(T(i,a),C1);
                Omega_u)

Completed_i(t,C) = Native_i(t,C) >>= Consume_decl

Force(T(i,a),C2) = Request(q(i,a,event,origin,K,D),C2,k0)
k0(r,Cnow)       = Return(r,Cnow)       [r:B theta, original evidence]

Request(q,C2,k0) >>= S
  = Request(q,C2, lambda (r,Cnow). S(r,Cnow)).
```

The displayed Force/k0 equation is the inner request primitive. Its actual
raw continuation at the Catch boundary is `k0 >>= S`, with **all** crossed
source consumer/view/owner frames included in S. A completion that changes
the active configuration remains in S; the notation never asserts that the
final configuration equals the configuration before those frames complete.

In `Completed_i`, `Consume_decl` is the **separately derived computation
port consumer** of typed-core §3; its force is after native return, inside
the actual surrounding execution view. It is not an extra consumer justified
by result shape. For retained-computation entry replace Force/rebind by the
original inert binding of `t`; all later equations are unchanged. This
replacement is selected by source role, never by inspecting solved effects.

The native body has no other local Return or Request alternatives. This is
a statement about that specified source body, not exhaustion of the complete
production root. Arbitrary requests/divergence during entry, the responder's
admitted values/futures, every surrounding source suffix and every independent
production abstraction remain present. Infinite execution is accounted for
through its original finite-prefix relation, not an assumed eventual return.

Here is the finite **source-constructor action** at the actual declaration:
reference its one original instantiation map; retain receipt/entry; retain
the native Return of `T` and its delimiter; retain the designated consumer;
emit the operation Request schema at that consumer with its own event
binder and response continuation; append the existing ordered `S` by Bind.
There are finitely many template nodes, without enumerating carriers,
responses, states, futures or dynamic event occurrences. A signature graph
of size `s` is transported once with shared substitution references, in
`O(s+|theta|)` work as in operation instances §4; the added local phase
template has constant size. This is a static construction bound, not a
measurement or a bound for generic image solving.

Every reference retains source/phase/scope and the one joint map. A request
already encountered during `Force(t)` keeps its actual continuation followed
by rebind/native-return/consumer/`S`; it is not exchanged for the later
operation request. If that input continuation is opaque, expansion stops
at that original reference. This prevents finite local expansion from being
misreported as effective discharge of an arbitrary carrier.

## 5. Same shallow H, exact U and original solution preservation

Apply the original shallow image to the Request with raw suffix
`k_S(r,Cnow)=S(r,Cnow)`. The finite action is the source handler's actual
outside selector/matching/guard computation, with these exhaustive outcomes:

| Original outcome | Local image action |
| --- | --- |
| A source Return reaches H | Run its original value arm outside the selected activation, using the same value/current state. |
| Original ordered search selects arm h | Supply this exact q/payload and `k_S`; run matching/guards/selected arm outside h. A raw resume of `k_S` enters S in the live resumed state without H. |
| Search exhausts/forwards | Forward the same q and raw suffix, with only the original source forwarding/re-entry wrapper. |
| Selector/guard/arm requests or diverges | Retain its own Request/prefix and pending completion. It is outside h; it is not an E request manufactured from q's signature. |

Selection is conditioned on original visibility, match and current-world
evidence. `OpCompat` checks the selected operation instance; incompatibility
does not become forwarding. No successful match, permission or original
admission certificate is inferred from the table. For a finite source handler,
its selector/arms are finite existing derivation graphs, so grafting their
references is finite; arbitrary continuations remain their original references.

constraints and let `C_i` denote the full original operation source relation
