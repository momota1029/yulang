## Result and exact boundary

`OriginalIdentityCarrier.lean` constructs the execution of an initialized
lexical Value Name saved in an argument Delay. It derives the full original
`Meaning (.carrier row)` from that execution, independent surrounding
world/history evidence, and explicit native/descriptor readout facts. It applies
that result directly to `generated_identity_name_realization`, at the same
`Use.carrier` recovered from the original invocation and receipt. The resulting
`generated_identity_from_name_delay` has no `ForceCut.whole` argument.

The newly computed part is substantive: native allocation/capture equations,
actual bind-to-Name lookup, the complete finite run, uniqueness of its returned
raw record, unchanged registry projections, the actual prefix world, and the
returned Value membership are proved. The full Rust-to-original-Inputs
extraction is **not** proved. `NativeExtraction` below is an explicit remaining
operational/readout boundary, and the independent history/guard premises have
not been instantiated for every original source caller. Consequently this is a
concrete conditional constructor supplier, not completion of the original
identity/relay source derivation.

## Computed constructor and execution

`NameDelay` stores the allocated handle, saved environment, original resolved
Name, and occurrence site. `Allocation.before` is the optional executable
projection indexed by the native value vector. Its length is the old **value
count**, not the size of the sparse executable map. `Allocation.after` appends
the exact captured Name closure. `allocation_keeps_actual_code` and
`allocation_preserves_old` prove its new and old entries. These are exact
constructor equations; extraction of that projection from Rust remains open.

`run` computes the known Delay/Name branch:

| Fuel/prefix | Actual computed state |
| --- | --- |
| `0` | Force has not opened the saved code. |
| `1` | The saved Name code is ready in the live world. |
| `n + 2` | The same raw Value/view has been read, the actual Name receipt recorded, and `raw.atName dispatch` returned. |

Terminal states stutter when additional fuel is requested; fuel measures a
finite observation prefix and is not a termination assumption for the full
language. `run_unavailable` retains the real failed lookup/view branch.
`run_no_request_or_error` excludes Request/error for this initialized Name by
the computed execution, after its lookup and matching-view facts are supplied.
The machine does not execute a latent function or retained component of the
returned value.

`bound_name_delay_run` supplies the lookup from **actual**
`SourceIdentityWorld.bindValue` and `bind_read`. Its result is

```lean
let delay := NameDelay.mk handle world.environments.size name site
let bound := bindValue world parent name raw node found
run delay dispatch bound (n + 2) =
  ⟨namedWorld bound delay raw.asValue,
    Phase.returned (raw.asValue.atName dispatch)⟩
```

It requires the existing parent node and matching received view, with arbitrary
raw Value content. This is a computed source/native constructor instance, not an
interface countermodel or a supplied safe execution trace.

`History.capture` uses `NativeClosureEnvironment.lookup_history` to retain the
same lexical cell through native environment extensions. `history_same_capture`
proves that cell, complete raw record, and descriptor remain identical. Its
fresh-allocation premise derives `delay.handle ≠ returnedRaw.value`. There is
no equation identifying the delayed computation with the closure/value it
returns.

### Every `NativeExtraction` field

For each `event`, `reachable : Reach operator row.event event`, `demand`, and
`demanded : operator.demand (row.atEvent event) demand`:

| Field | Raw type/result |
| --- | --- |
| `execution` | `Execution operator delay demand` |
| `observations` | For **every** `raw : RawObservation S`, `operator.force (row.atEvent event).input demand raw → ObservationAt operator references row.interface delay demand capture execution raw`, where `capture` is `history.capture` at this same demand. |
| `incidence` | For every same `raw` and same Force premise, `operator.forceIncidence (row.atEvent event) demand raw`. |

No Force observation is filtered by membership, success, returnedness, a bound
on observation count, or a replaced admission predicate. The universal raw
quantifier includes unfinished/admin/pending/complete observations and any
admitted developments in the fixed original relation. Proving that all those
raw observations have the following readout is still the extraction owner's
obligation, not a theorem obtained by declaring a smaller Force relation.

`None` gives the original unfinished case. `Some returned` gives the original
pure Return case at the **same actual raw event**, interpreted from the computed
returned native record. The complete equation cannot select an unrelated
result: `run_returned_unique` identifies it with `capture.raw.atName dispatch`.
The independent residual machine state and current evidence are not equated
with the creation event. Native cells, lexical environment, provider/capture
readout and Shared strategy are preserved by computation; receiving receipts
are actually updated.

`WorldFields` is a positive projection derivation. Its leaves are ordinary
guard facts, the same world, or value/carrier entries with an **actual installed
equation**. Its logical constructors are conjunction, either alternative,
universal scope and existential scope. It contains no arbitrary trace leaf,
membership oracle, whole-carrier certificate or assumed `Positive.Holds` field.
`world_fields_hold` derives `Positive.Holds (Meaning N)` from the independently
valid world. `CaptureAt.installed` computes the actual Value binding from native
cell contents and its Value mode. `event_world` then derives the prefix world
from the preceding demand world and independent current guard/compatibility
facts. `immutable_name_value` supplies the returned member at that prefix;
hereditary Value semantics retains every compatible future and latent Function
obligation. No returned-value safety premise is introduced.

This projection syntax is not asserted to cover every possible original
observation-field formula automatically. In particular it has no direct
trace-valued continuation leaf. Any such field in a proposed original readout
must be justified at its owner; the theorem does not erase it or replace it
with `True`.

### Independent history premises remain visible

`History` contains the allocation and original initialized `CaptureAt`, the
existing raw value's allocation bound, saved-environment bound, exact
`row.carrier/root` interpretation, native environment extension/cell/matching
facts, stable view assignment, original inert guards, positive capture
projections, and the original demand-to-compatibility fact.

Its semantic premise is explicitly

```lean
worlds : ∀ event, Reach operator row.event event → Meaning N (.world event)
```

These are independently valid surrounding worlds in the sense of semantic-input
realization §4.1. They are **not** constructed from `carrierAccepted`, Build
satisfaction, or the new carrier theorem. This packet does not prove that
arbitrary native histories have those world certificates. Supplying them by
assuming the very carrier being introduced, for example through a future
installed copy of it, would be circular and would not instantiate this packet
as an original source supplier. That independent history obligation remains
open at the source/world owner.

`Reach` takes zero or arbitrarily many original compatibility edges. No
reflexivity/transitivity property is invented for opaque compatibility. The
coinduction candidate adds the **same** carrier/interface/root at each such
event to existing `Meaning`. It discharges every `PhiCar` conjunct, and recursive
carrier future membership comes from this candidate, not an assumed carrier
restriction theorem.
