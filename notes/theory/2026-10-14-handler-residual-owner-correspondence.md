original scoped assignment sigma, with resolved operation declarations,
original scrutinee computation S, original operation/value arm binders and
raw continuations, construct the handler's residual from S's effect alone.

exactly contributions eligible and actually consumed by H; preserve protected,
unmatched, independent and later raw-resumption contributions, including
survivors at the same resolved family/type support point. Preserve complete
output meaning, both residual feedback directions, existing and future lower
bounds, fresh-use independence and qualifying parent/copy equality without
coalescing separate residual constructor lineages. Soundness and required
principality remain required for the original ordinary source domain.

This is the parent objective, not a theorem established here. Original scopes,
binders, the assignment and whole provider/future interfaces are retained;
no independent marginal witnesses are selected. The decisive packet question
is whether the *current actual* operation/signature producer and consumers
already supply the premises for that construction. It is not whether one can
invent a finite model whose assumed transitions satisfy it.

## 4. Conditional construction and exact missing premise

The existing one-color theorem applies to an operation crossing an *actual*
active well-bracketed guard with identity c_u, current family H_u and the
entry-except snapshot Xi_u. If h is outside H_u and no entry exception
applies, the guard adds c_u and same-flow handling cannot see it. An entry
exception retains the pre-existing protection; h inside H_u does not change
colors. Under the theorem's supplied premises, a handler residual consumer
that removes only actually visible selected contributions preserves those
protected contributions. This conditional application needs no new hygiene
proof. Empty words or declaration equality do not supply its active-guard,
snapshot or operation-crossing premises.

The exact missing bridge is a source-owned constructor and live consumer law:
the existing Apply/invocation and typed-value transport provenance and the
yielding Catch boundary must construct, under the same original assignment,
the applicable annotation attachment/context and actual ordered-handler eligibility;
the residual owner must consume precisely that evidence and retain the complete
surviving output image. The certificate can be constructional; no particular
new storage layout or dynamic event catalogue is selected here. Operation
declaration/occurrence identity remains distinct from an annotation attachment,
handler lineage, dynamic request and raw continuation.

The smallest required implementation invariant for the selected existing
ResidualRecipe shape is:

1. **Original source ownership.** A Catch constructor retains original S,
   resolved arm operation identities and payload/result binders, coverage
   evidence and outside arm computations. The actual invocation path supplies
   authentic applicable context/protection. A member of a declared operation
   interface is never accepted as a proof that this request is capturable.
2. **Local residual image.** A recipe's source is only S's effect coordinate.
   Retained concrete heads are justified by the actual matching/eligibility
   evidence. Only the selected contributions are removed, so another surviving
   contribution at the same family/type point keeps that support point present.
3. **Live two-direction feedback.** Retain source-to-Row(heads,gamma) and every
   exact contextual gamma-to-tail relation, their origin dependencies and
   current/future lower activation. Gamma upper constraints replay through the
   source relation. Equal source representatives fan out to every recipe.
4. **Joint lifecycle.** Capture/freshen the reachable recipe/registration graph
   and related coordinates under the same per-use map, preserving shared
   identities within a use and independent local instances between uses.
   Extrusion transports actual row pairs and contexts. Qualifying parent/copy
   equality transfers obligations but does not merge separate recipe lineages.
5. **Shallow output.** Join all arm/guard/default effects outside the residual.
   The raw continuation maps the operation result to S's original result and
   effect, so a later same-family request is not implicitly handled again.
   Incomplete family coverage forwards S's effect; absent total value coverage
   preserves S's value. New outside computations receive their own ordinary
   eligibility checks.

These are proposed proof/implementation obligations at the existing owners,
not established transition axioms. In particular, a watcher table without
proof of insertion/replay activation is insufficient for item 3. Items 1–5
must be derived jointly before broad dependent implementation or closure.
Complete Call output and providers cannot be replaced by scalar support edges;
this packet imports no new Call theorem and independently chooses no witness.
