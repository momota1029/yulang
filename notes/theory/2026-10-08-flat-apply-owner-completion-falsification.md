## 1. Objective and result

Test what any typed R-flat/E-flat completion for the inner
`Apply(Name(u_f),Literal(a,"1"))` of `my apply f = f 1` must preserve.
No construction-independent impossibility of a faithful completion follows
from the assigned contracts. This note supplies minimized counterinterpretations
of weaker preservation claims and a checklist for reviewing a frozen completion.
It neither reads nor reviews the concurrently authored completion.

The previous [emission falsification](2026-10-08-flat-apply-original-emission-falsification.md)
§§3–4 grants registration/representation while leaving actual emitted membership
absent. This note does not repeat that attack. In the inventory mutants below,
**grant actual original installation and emitted membership as a separate
hypothesis**, so that the failure survives after that old premise is supplied.
Granting this hypothesis for an analytic discriminator does not establish it
from current source rules or discharge R-flat/E-flat.

The principal new witness is one omitted independent original atom and one
Boolean coordinate. Even an installed literal arm, exact displayed Call
projections and unchanged executable erasure cannot establish conservation of
an original inventory containing that atom. A second witness preserves all
atom truth while losing an occurrence and its insertion/lookup identity.

## 3. Minimal inventory and old-image falsifiers

### 3.1 One extra atom defeats display-only conservation

Fix the complete displayed Call tuple and grant H-install. Let the unchanged
displayed inventory have interpretation D(x)=true on x in {0,1}. Suppose an
independently fixed original inventory additionally contains one occurrence q
whose independent interpretation is q(x) iff x=0. Set

```text
Phi_original(x) = D(x) and q(x)
Phi_mutant(x)   = D(x)                 [q omitted]
Sol_original   = {0}
Sol_mutant     = {0,1}
```

All displayed demand/root/argument/result projections, primitive provenance,
original membership and executable erasure may be identical in this model.
Nevertheless x=1 satisfies only the mutant. An authentic installed member is
not sufficient to justify deletion of a premise from its independently fixed
inventory. Installation alone and the selected O0 equations do not constrain
q's interpretation or establish it redundant.

This is a conditional counterinterpretation of the implication from displayed
projection/erasure equality to full original relation equality. It does not
assert that the actual flat inventory contains this Boolean atom. A valid
completion can defeat the mutant by retaining every actual original occurrence
or proving an independently justified equivalence for a proposed removal.
The assigned contract requires retention; no removal permission is supplied.

Minimality: one false valuation already separates the relations. Two valuations
are the smallest nondegenerate example with an original satisfying assignment
as well as a new spurious one. One omitted atom suffices; with none omitted
this particular discriminator disappears. No second Call, runtime effect,
comparison, profile, solved Function or semantic-world construction is used.

### 3.2 Truth-preserving deduplication still loses an occurrence

Under H-extra, take two actual emission occurrences o1 != o2 with the same
formula q and separate constructor origins/insertions. Both interpret as true.
A mutant converts the original occurrence-indexed inventory to the set {q}.
Truth of the conjunction is unchanged, but a claimed occurrence-preserving
map sends both o1 and o2 to one occurrence z. Any old-image inverse r would
require r(z)=o1 and r(z)=o2, contradicting o1 != o2.

Thus semantic equality does not supply original insertion/lookup and attachment
conservation. This is an evidence-preservation failure, without a claimed
observable difference. Distinct proof identity cannot be discarded by assuming
proof irrelevance or set semantics that the source contract never supplied.
Two occurrences mapping to one are minimal for noninjectivity. If the actual
fiber has only one occurrence, this particular mutant cannot discriminate it.

### 3.3 Canonicalizing old records by demand loses old identity

Under H-old/H-extra, let e1 != e2 be two authentic old records with equal
projected demand F but distinct retained source incidences or derivations.
A mutant keeps only F and maps both to z_F. The same inverse contradiction
as §3.2 prevents r_old(i_old(e))=e for both records. Such a mutant can preserve
`Inv(Id(F),F)` and printed effect endpoints while failing the full source-origin
eliminator of OC-CallEff and the required Keep-image law.

This is conditional on the two old inputs, not a claim that the selected
canonical singleton has two identical derivations. Records at distinct original
frames are sufficient if the shortcut discards those frames. The authentic
completion must preserve every old input it actually receives and may share
a demand object while retaining separate derivation/source incidence payloads.

## 5. Frozen-candidate review checklist and stop boundary

A reviewer of an actual completion should inspect these exact equations and
suppliers rather than compare displayed schemas:

1. **Representability:** literal inversion returns the actual primitive at
   c.arg; Name inversion returns the old Name/Return child. No literal-to-Name
   coercion or total retraction of literal records into Name-only records.
2. **Typed registration:** every operand Result, ArgReify, checking occurrence,
   complete-result/result-Reify, p0/p_out and suffix origin has its real source
   parent, constructor role and scope; formal-contract R_f is reused while
   remaining distinct from the original binding root where required.
3. **Original installation:** actual original insertion/lookup and emitted
   membership at the same source root/fiber are produced by an independently
   justified original owner arm. Retaining a candidate token supplies neither.
4. **Old preservation:** r_old(i_old(e))=e, including all original indices,
   children, independent cases, evidence alternatives and inventory occurrences.
   The inverse is only on the old image; no exhaustive-family equation follows.
5. **Inventory:** every original atom occurrence has a preserved origin and
   insertion/lookup, including separate result/ambient lower obligations and
   extras absent from a displayed reference list. Equality of formula sets or
   Check projections is insufficient. Unknown inventories remain explicit
   dependencies, rather than disappearing under a claim of exhaustiveness.
6. **Action:** identity/composition and each origin's parent/scope eliminator
   commute under one supplied legal sorted map on graph, binder tree, xi,
   routes, imports, demand, atoms, installation and all dependent evidence.
   Endpoint substitution alone cannot justify source-occurrence collapse.
7. **Consumers:** O0 uses the same actual emitted record and exact complete
   invocation root/ElimOrigin. The source complete result keeps the callee
   prefix and the original ordered receipt/entry/body/designated-consumer/native
   return/invocation-return suffix; pending raw resumption preserves that tail
   at the current state without replaying receipt. Slot uses same Reg/Route/O0;
   paired O1 uses an
   independently derived flat seed and the same attachment. Static formation
   supplies no independent C0/C1/J0, CallInitial/I0, admission or execution truth.

If a new original rule excludes a documentary mutant, inspect that rule's
scope and independent premises; do not discard it because the fragment was
smaller. Conversely, if the completion imports full H-R/H-E as hypotheses,
the result remains conditional at those exact seams. After two earlier methods
left installation untouched, the appropriate different method is inspection
of the actual owner construction, not a third supplied-rule toy probe.
