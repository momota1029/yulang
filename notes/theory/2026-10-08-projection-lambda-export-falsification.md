## 1. Objective and result

Find a supported ordinary-use discriminator for candidate displayable schemes
for `my id x=x` and fixed-capture `my pick y=z`, and identify the least kind of
additional use-time information `alpha` required by that discriminator.

No source-admitted counterexample to **every scheme-only export** is established.
The scheme language and its use interpretation are not selected, and the local
authority does not complete independent admission. Displayability does not
specify which information the scheme omits. Conversely, different executions
with the same type do not by themselves require different typing exports.

The useful result is a precise discriminator criterion (§3), plus a minimized
entry observation (§4) that rejects a particular decoder shortcut. That
observation requires the selected whole-argument Value-entry completion law.
For this ordinary unannotated envelope the law is uniform, so it supplies no
lower bound on **per-export** `alpha`: a canonical scheme interpretation can
contain it once. This is a bounded failure to establish the requested lower
bound, not a sufficiency theorem for schemes alone.

## 3. Conditional necessary-information theorem

Let `s` be an independently admitted source export situation in the assigned
envelope, and let `U` be an ordinary use with fixed independently meaningful
caller inputs `I_U`. Those inputs include the caller environment and original
shared `xi`; they exclude consulting the exported definition again.

Let `Good(s,U)` be the set of observable use-checker answers and evidence
permitted by the selected contract. This is specification notation, not a
proposed public object or a full-source-relation field. Its obligations must
come from established safety, natural inference and required principality;
they cannot be defined as whatever the candidate checker returns.

**Hypotheses for a separating witness:**

1. `s0` and `s1` have independent source/admission derivations and the same
   candidate `Sigma`, after legal bound-variable renaming that fixes all
   external references.
2. The actual caller inputs `I_U` are identical for the comparison, or are
   legally identified by an independently justified whole action. Differences
   already visible in `Gamma` cannot silently be counted as missing export data.
3. `Good(s0,U)` and `Good(s1,U)` are nonempty and disjoint.
4. The use checker sees only `Sigma`, `alpha` and `I_U`. Its required answer
   is a function of these inputs; it cannot recover the definition.

**Conclusion.** A correct checker must distinguish `alpha(s0)` from
`alpha(s1)`, unless the scheme or caller interface is enriched to distinguish
the pair.

**Proof.** If the three checker inputs coincide, its answer is the same
`q`. Correctness requires `q` in both disjoint Good sets, a contradiction.
For a randomized checker required to be correct on every execution, the
same argument applies to every possible output. Random choice supplies no
missing source fact.

For this single binary witness, the least kind of new information is a
distinction between the two required use behaviors. One binary distinction
can select between two already justified rules. This does not establish a
bit-level representation, prove those rules, or bound metadata for other
uses. A tag with no independently interpreted rule repairs nothing. In
particular, naming the entire source relation as the distinction would not
meet the approved target.

The theorem prevents three false lower bounds:

- Same rendered text with different fixed environments fails hypothesis 2.
- Different source results with a common legal conservative typing answer
  fails hypothesis 3. Production membership Option 2 permits extras subject
  to complete containment; source trace inequality is insufficient.
- A hand-stipulated admission bit fails hypothesis 1 unless an actual source
  derivation supplies both alternatives. The earlier structural model remains
  a conditional model, without becoming a legal Yulang witness.

No such pair with disjoint Good sets has been constructed for this envelope.
This result reduces the missing evidence to an actual abstraction collision
with incompatible use obligations, rather than another arbitrary relation.

## 4. Smallest entry control and its exact repair

Fix one actual outer Value binding `Gamma(z)=Value(b)` and its complete
dependencies. Let `t_inf` be a supplied pure nonreturning argument computation
with legal endpoint `A`, independently typed/admitted in the selected
derivation core. Its availability is an explicit hypothesis; no raw spelling
or production acceptance is asserted.

The control is one completed invocation:

```text
call(result(lambda(Value(y), result(name z))), t_inf)
```

By the selected ordinary entry rule, its ordered suffix is

```text
receipt; Force(whole argument); rebind y; Return(original z).
```

`Force(t_inf)` has no return. Consequently this source execution cannot reach
the body's Return. A decoder or generated execution that treats the empty
body row and unused formal as permission to return `z` immediately introduces
a terminal return absent from that source execution. One closure, one call,
one nonreturning argument and one return observation suffice; no nested
binding, second use, operation family, new handler or recursive SCC is needed.
Removing the call removes the entry observation; a returning pure argument
does not distinguish skipping entry from this particular return observation.

This is a conditional decorated-core discriminator for **skip-entry**. The
argument may be implemented by a separately supplied diverging computation;
the export itself stays nonrecursive. It is not a new source-generality
result, a source-admitted bad use, or a proof that conservative production
membership must exclude every terminal return. The latter depends on the
independent checked upper contract and exhaustive Option 2 containment.

The least semantic fact repairing this control is:

> The ordinary arrow's parameter consumes its whole argument computation
> exactly once at Value entry, before executing the body; absence of a return
> leaves that body suffix pending.

That fact also identifies where argument effects, requests and resumptions
belong. It is stronger than marking the body row nonempty: the pure divergence
control has empty effect support. A complete request-prefix case would retain
the original pending entry/body suffix, receiver/receipt and current resumed
state, using the original provider and `xi`; no new resumption rule follows
from this control.

For the two assigned unannotated projection forms, the fact is uniform and
already selected. A scheme-only interpretation with canonical Value entry
can repair the control with **zero per-export extra information**. If the
candidate interpreter instead varies entry while erasing its distinction,
it must preserve a semantic entry distinction somewhere. The assigned
envelope supplies no second entry case establishing that lower bound.

The same Force prefix applies to `id`; its successful rebind returns the
argument value and its latent provider without another force. `pick` returns
the original capture after successful entry. These are retained source
invariants, not new repeated-port/capture attacks.

No inference is drawn that all latent providers, evidence or future-use
admission can be reconstructed from this uniform entry fact. In particular,
a typing arrow's conservative output guarantee is not an executable body.
A scheme-only use checker can type a closure whose implementation remains
ordinary compiled code without retaining that code as typing metadata.

## 5. Blocker, coverage and failure conditions

The precise blocker is the unselected candidate scheme interpretation and
the missing independently justified complete admission/use obligations for
an actual exported abstraction. Without them, “Sigma-only loses a fact” does
not identify either a required distinction or a source-admitted witness.

The entry, port, capture and arbitrary-admission mutations already exist in
the predecessor notes. Another finite Boolean checker would leave this same
premise untouched. This lane stops after deriving the discriminator criterion
and inspecting the entry control; it does not launch an equivalent model.

Oracle independence: there is no executable oracle, source transition
checker, solver query, legacy run or compiler acceptance observation here.
The hand derivation uses selected source entry/synthesis laws and the reviewed
conditional core. It does not independently prove those laws. The
indistinguishability theorem uses only its explicit input equality and
disjoint-contract hypotheses, without assuming a candidate's transitions.

Coverage is exactly two projection endpoint families and one conditional
nonreturning-argument control. No random seeds, enumeration range or executed
mutations. No recursive export, mutable State, callback literal B, annotation
permission, operation-family formation, provider-identity collision, arbitrary
view, method selection or exhaustive production-extra search was undertaken.
Actual role/entry, fixed environmental dependencies and original `nu,K,D`
remain unchanged. Neither all-model source equivalence nor a stronger
characterization is imposed as a new cutover premise.

Failure conditions for the control: `t_inf` lacks its independent typing or
admission; the observation is only a conservative upper member rather than
actual generated execution; or the accused decoder already includes the
canonical Value-entry completion. The source law cannot be weakened to evade
the control. Failure conditions for the metadata theorem: the inputs differ,
the Good sets overlap, a legitimate new observation lies outside the selected
contract, or no independently admitted source collision exists.

Recommended next action: supply the primary's exact candidate scheme grammar
and use decoder for this envelope, then seek one independently admitted
same-Sigma collision with disjoint required use answers. Treat fixed
environment references and canonical entry as explicit decoder premises;
require per-export extras only where that discriminator proves a need.
