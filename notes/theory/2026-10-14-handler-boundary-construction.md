## 4. Raw continuation: exact source meaning and conservative whole-S typing

For an original request `q : A -> B`, the raw continuation consumes its response
value B and resumes the **original suspended suffix** with current state and the
original dependent interfaces. It does not reinstall consumed H, apply H's
value arms, restore an expired receiver, or use the handler's output coordinate.
Invoking it with a source computation additionally has that computation's
ordinary entry/force effects in the outer context. A displayed empty argument
effect below describes an already supplied response value; it is not a proof
that arbitrary effectful response expressions can be dropped or rejected.

Selected source equation:

```text
H[Request(q,k)] = MatchRequest_H(q,k) >>= Finish_H(q,k)
Finish_H(Accepted(arm,bindings)) = Run(arm.body,bindings)  // outside H
```

The forwarding/NoArm branch alone installs the source-prescribed wrapper
`Forward(q, lambda a,Cnow. H[k(a,Cnow)])`, creating a new occurrence when it
later runs. This is distinct from k supplied to an accepted arm.

The frozen Oracle fixture at `compiled_runtime.rs:2243–2274` supplies a genuine

do not add arbitrary user replacement code or independent outside arm code to k.

Shared hypotheses:

1. Native EffectRow inclusion is interpreted monotonically under sigma and all
   retained generated constraints used here have completed ordinary processing.
2. The actual original callable interfaces bound every request of their complete
   invocation, including required argument force and latent body execution;
   source environment/response typing is preserved at the resumed use. A source

   retained rows or test passes.

any finite observed prefix of a divergent resumed execution. No global

Proof: induct on the finite source control derivation. A primitive or pure read
has no immediate request. A request produced by an authentic operation invocation
is in its invocation envelope. In each compound case the currently executing
subcomputation has its displayed envelope inclusion into the surrounding
computation. A conditional may have remaining conditions and either branch;
all their envelopes already constrain the parent. A block suffix may include
remaining initializers and its tail; their inclusions all exist independently
of which prefix was consumed. Normal-value Catch may be suspended in either its
scrutinee or an outside arm; both envelopes are retained. Group/ascription
preserve their original child coordinates. Entering a lambda or other callable
uses its sound original invocation envelope, which includes any entry force
and executed body; its actual Application inclusion then reaches the caller.
Repeated invocations use that same reasoning, under the same sigma and the
joint transported interpretation. Composition of the finite enclosing control
frames gives the root inclusion. Taking the union of finitely many observed
requests preserves it. Deleting the executed prefix cannot add a request absent
from these included subcomputations/interfaces, so the original raw suffix is
covered too.

This derivation proves a useful compositional envelope **conditional on the
stated original interface/preservation premises**. It does not assume suffix
coverage as a transition, but it also does not discharge the independent
source-to-native complete Call interpretation. In particular scalar argument,
result and result-effect children are not used to manufacture a complete
provider/future output law. For arbitrary later client computations not in the
original source/interface, the conclusion applies only after their own ordinary
typing and source inclusions are supplied.

Accordingly whole-S is a permissible conservative candidate for k's scalar
effect envelope, not proof of exact full k meaning. Independent arm effects
must join outside the Catch cut; one must never pass k's effects back through
the original consumed H's Allowance. No mandatory “signal remains” source law
or original parent closure follows.
