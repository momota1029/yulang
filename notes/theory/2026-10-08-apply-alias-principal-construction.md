## 3. Original solution space and the exact preservation requirement

Fix the original binder tree `Delta`, original complete row `X`,
`xi=(nu,K,D)`, rigid imports, independent declarations, actual provider
alternatives, original histories/challenges, and designated export `E`.
Let `Sol_o` be the whole original typed completions of this exact source
component. Each member includes its original jointly scoped witnesses; it is
not just an endpoint valuation. No existence of such a completion is asserted.

Fix the already designated observation map `Obs_E` and preorder `<=_E`.
The argument does not choose a different export, change quantifier order, or
select whether the principal convention is a least or greatest element.
Use that fixed convention throughout.

Literal preservation of every original whole solution requires an extension
`ext:Sol_o -> Sol_star` and erasure `erase:Sol_star -> Sol_o` with

```text
erase(ext(s)) = s
Obs_E(erase(t)) = Obs_E_star(t).
```

Erasure must recover every original coordinate, witness alternative, origin,
scope and actual provider arm. Recovering an observably equivalent completion
with different old fields does not satisfy this stronger requirement. Candidate
added schema syntax may have several equivalent presentations; no uniqueness of
that syntax is necessary for equality of the observable images.

**Conditional order consequence.** If both maps are total and have these laws,
the observable solution images are equal. Every original observation occurs
through `ext`; every candidate observation occurs through `erase`. With the
same preorder, their order-theoretic principal observations coincide. If schemes
contain residual or evidence observations, these must already be coordinates of
the fixed `Obs_E`. This proves neither a solver result nor that a principal
observation exists.

## 5. Fully conditional representation proof

Here is a sufficient supplier theorem at the owning source-generation phase,
with its nontrivial source equations exposed. It is not inferred from FVIEW.
Retain every original non-endpoint coordinate and witness in a row `Y`, with
the same old `xi` and binders. Require these **candidate hypotheses**:

1. **H_form:** independently typed source declaration equations define a
   total complete schema `S(Y)` and actual legal whole maps `m_f(Y),m_c(Y)`
   at the original formal and checking occurrences. Schema formation does not
   use Q, select a later provider, or combine separate existential witnesses.
2. **H_define:** the original source equations already entail, at those
   original indices, `A_f=EvalRef(S(Y),m_f(Y))` and
   `F_c=EvalRef(S(Y),m_c(Y))`. These are complete dependent descriptor
   equalities, not printed-type equality or final membership inclusion.
3. **H_local:** the original local Call, seed/refinement, protection,
   annotation and primitive rules have lawful substitution actions for these
   definitions in both directions. Their rule instances retain the same
   independent witness fibers, guards, actual arms and original scope. No
   original comparison premise is dropped unless its exact rule derivation is
   recoverable after substitution.
4. **H_export:** transformations actually performed on the source relation
   have their original whole certificates at original binders, and `Obs_E`
   reads the recovered old coordinates. This assumes no answer concerning
   Generalize root policy or export eligibility.

**Theorem (conditional, documentary).** Under H_form–H_export, replacing the
two descriptor coordinates by those complete references, while retaining `Y`,
preserves and reflects all whole solutions and principal observable solutions.

**Proof.** For `s` in `Sol_o`, retain its actual `Y` with every original witness.
Compute `S,m_f,m_c` by H_form. H_define identifies both evaluations with the
old descriptors. Transform each original rule instance by its H_local action,
under the same original binder; carry export transformations by H_export. This
defines `ext(s)` without a new constraint on `Y` or a chosen witness arm.

Conversely, evaluate both references in a candidate completion and retain its
original `Y`. Apply each reverse H_local action with its same actual evidence
and original rule premise; apply the reverse original export certificate where
used. This produces `erase(t)` in `Sol_o`, including the old descriptor values.
H_define and actual dependent record projection give `erase(ext(s))=s`.
H_export gives the observation law. Section 3 yields equality of observable
images and the fixed principal observations. QED.

The proof is constructive relative to these local suppliers. **H_define is the
unproved source factorization theorem**, and H_form/H_local's refinement and
complete-kernel instances are also unavailable. Naming these hypotheses does
not prove them. Thus this theorem is not progress toward their truth; it
identifies exactly what a legitimate constructor would have to establish.

Two complete references may use different maps. The theorem then proves
representation preservation only. To obtain the shared artifact's identity
action at an actual event, additionally derive that the evaluated complete
Function clauses coincide there for **every relevant background `Z`**, through
the actual scope/event maps. Contextual occurrence records remain distinct.
Equivalence only at the final fixed point does not give this stronger law.
Encoding the original pair inside a parameterized `S` is a lossless package;
it supplies no identity action when the maps recover different clauses.

## 6. Necessary obstruction: all solutions versus principal exports

Consider the stronger branch intended to remove RT.2's comparison action:
both complete references have the identical Function clause at the same joint
event after lawful index alignment, uniformly in the relevant backgrounds.
Let `Diag_o` be the original completions satisfying that exact aligned clause
equality. Whole readout fields include dependent challenge/observation/future
schemas and guards, not just final value membership.

**Lemma (necessary image condition).** A candidate using such identical
clauses, with erasure preserving both old complete descriptors and their
actual maps, can erase only to `Diag_o`. Therefore total extension of all
original whole solutions implies `Sol_o=Diag_o`.

**Proof.** A candidate has the aligned clause equality. Erasure preserves each
complete clause and map, so its original image has the same equality. Apply
this to `ext(s)` and use `erase(ext(s))=s` for every original completion. QED.

This is the exact obstruction; no admitted source counterexample is asserted.
Even if every original principal export had a diagonal representative, that
would not establish `Sol_o=Diag_o`. A same-export normalization replacing a
proper pair by an equal pair can potentially prove a weaker principal-export
claim; it changes old whole solutions. The assignment retains both obligations,
so this weaker route cannot silently replace it.

The earlier shared artifact already gives a schematic proper-inclusion local
witness. This lane does not repeat or promote that attack. The new result is
the necessary **whole-solution image condition**: a source theorem must rule out
every reachable non-diagonal completion, or derive a lawful nonidentity action
while retaining its separate views. No proof of reachable non-diagonality,
uniform diagonality, or principal representative normalization was found.

Provisional Handler refinement and directional protection add concrete reasons
to keep the full equation explicit: copying the formal seed onto an existing
provider lower packet violates the selected no-backflow rule; identifying
upper/lower witnesses by endpoint equality loses original provenance. Separate
occurrence records can avoid that error, but their lawful complete clause
factorization still requires proof. These are failure conditions, not a
contradiction inherent in shared reference syntax.
