## 3. Exact mathematical image of each selected summary

The deletion rule terminates by length. Its redexes do not overlap; disjoint
deletions commute. Therefore reduction is confluent, and the irreducible words
are exactly `D^p U^n`. Ordered left composition is consequently:

```text
(p,n) * (q,m) = (p + max(q-n,0), m + max(n-q,0)).
```

It is the image of literal concatenation, so arbitrary left-only replay
bracketing has this value. This conclusion does not reassociate a later mixed
replay. A path through the circuit is a real surviving primitive replay route
for the concrete Row lower, according to the cited source admission proof;
Var-only self suppression is not used as a route witness.

Fix one identity-seeded `c` at `e`, retaining `o(c)` and `i`. Let `A_c` be the
set of exact contextual values of all finite derivations for that contribution
ending at `e` within the complete selected component.

For PUSH-only, every primitive/nontrivial recursive operation contributes only
`U`; identity aliases contribute none. Induction on each finite derivation
gives `p=0`. Traversing `e -> r -> e` exactly `n` times supplies `U^n`, including
the empty route for `n=0`. Hence both inclusions hold:

```text
A_c = { (D^0 U^n, right=I, i, S, c, o(c)) | n in N }.
```

For nested, every finite derivation remains a natural left pair by the same
closure argument. Conversely, traverse `e -> h -> e` `p` times, then
`e -> r -> e` `n` times. The ordered word is `D^p U^n`; `DU` does not cancel.
All these routes satisfy the source registrations. Thus:

```text
A_c = { (D^p U^n, right=I, i, S, c, o(c)) | (p,n) in N^2 }.
```

The displayed tuple abbreviates the unchanged boundary data. It does not
assert that distinct internal derivation witnesses/origins are equal. The
original relations and their origin/dependency fiber must remain retained
where a consumer observes that fiber. These images are exact images of
contexts for the fixed source contribution, not an inverse reconstruction
of each derivation witness from `(p,n)`.

This distinction also fixes the contribution domain: an arbitrary new lower

the same freely traversable image. Existing current/future-lower checks remain
required. A source extension changing the complete component is subject to

```text

{ O(Trace_K(D^pj U^nj, i_j,S_j,c_j,o(c_j)))
```
