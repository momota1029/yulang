# Yulang inference theory map

Date: 2026-10-05 snapshot (assembled 2026-10-05)
Status: Research synthesis; navigation and classification only; not an Authoritative design
Scope: Current Yulang3 SCC-intrusion inference theory and its proof/implementation boundaries
Authority: Underlying documents retain their own status and scope. This map adds no theorem, semantics, carrier, rejection rule, or implementation authority.

This is a snapshot of a fast-moving research branch. “Current” below means supported by the cited reviewed/Authoritative source as of the date above, not that every upstream compiler path conforms to it. Bounded checkers and finite probes remain characterization evidence. Drafts, failed routes, and older progress descriptions are retained in place as research history.

## Reading the result labels

- **Theorem**: a general mathematical result as stated in its reviewed source.
- **Conditional theorem**: a result whose stated hypotheses or generated-source predicate remain part of the claim.
- **Characterization**: bounded executable or exhaustive evidence; never promoted here to a theorem.
- **Counterexample / obstruction**: refutes the specified shortcut or proof route, not a broader goal unless the source says so.
- **Open**: a remaining gate with its source quantifiers intact.
- **Historical / superseded**: still useful evidence, but no longer the active central condition for the stated gate.

## Current spine

### 1. Semantic core: endpoint inequality and complete callable interface

**Theorem/contract — one endpoint-dependent `A <: B`.** Concrete comparisons are resolved as a single directed query. Variable-bound propagation may use transitivity; two successful concrete comparisons are not composed as a substitute for a middle witness. Optional-record compatibility supplies a concrete nontransitivity witness. See [concrete compatibility boundary](../design/2026-10-03-concrete-compatibility-boundary.md) and the [endpoint-dispatch characterization](../progress/2026-10-05-inequality-endpoint-dispatch-playground.md).

**Counterexample / proof-interface obstruction — preorder source adequacy.** The legacy pure expression and recursive-group adequacy proofs remain valid for their explicitly assumed preorder structural fragment. They cannot be lifted to the complete concrete inequality solver by replacing `≤` with successful local `A <: B` resolutions: the source `Sub` chain `A={foo?: string} <: B={} <: C={foo?: int}` derives `x:C`, while Name generation retains only `A` and the direct `A <: C` check fails. The recursive-group completeness proof has the same transitive-value step. A production-coverage audit further finds `x as Int` currently reaches annotation CST; HIR association retains only its wrapper/range and preceding expression, while dropping the target type subtree. Semantic lowering rejects it as `UnsupportedExpression` before constraint generation; no cast realization exists in current `ResolvedExpr`/`yu-core`. Therefore the counterexample is to the proof interface, not an accepted current cast-sequence bug, and current rejection does not select a successor source restriction. The minimum missing bridge is comparison/evidence-preserving source generation or a proven transitive structural restriction for the source envelope. See the [source-adequacy concrete-transitivity obstruction](../progress/2026-10-05-source-adequacy-concrete-transitivity-obstruction.md) and [source-boundary coverage audit](../progress/2026-10-05-source-boundary-coverage-audit.md).

**Contract — complete Function and coupled effects.** A Function is not just a value arrow. Its complete view contains the polarized value ports, entry/role information, and correlated effect ports. Effects are not independently subtyped Types. Source introduction/context chooses Pure or Handler before port interpretation; a prebuilt Pure callback value retains its actual role and entry, while the callback slot supplies an invocation view. Covariant rows use canonical flat form; concrete-bearing contravariant descriptors retain only structure supported by witnessed partial reverse addition. The user-approved mixed-row fragment distinguishes polarity: covariant `['e, write int]` allows the shared `'e` plus the concrete contribution when `'e` also occurs contravariantly; in the matching contravariant case, the supplied compatibility example is `int <: 'a` for `write 'a` in `'e`; the illustrated deep-handler covariant result carries `'e` with the attached `write int` contribution removed. This is a scoped semantic contract, not a general row-combination or family-variance theorem. Removal still needs source-owned attachment and complete deep-handler-image evidence; same-family support alone is insufficient. `never`, `Any`, empty rows, and polarized solver bounds stay distinct. See the [approved polarity-sensitive fragment](../design/2026-10-03-concrete-compatibility-boundary.md#9-user-directed-mixed-effect-row-fragment-2026-10-05), [approved handoff receipt](../../questions/2026-10-05-function-effect-row-denotation/receipt.md), [descriptor derivation audit](../progress/2026-10-05-function-effect-descriptor-derivation.md), [coupled effect interface core](../design/2026-10-01-coupled-effect-interface-core-draft.md), [callback context delivery](../design/2026-10-03-callback-context-delivery.md), and the accepted decisions in [tasks/current.md](../../tasks/current.md).

**Contract — written annotations, inferred public schemes, and internal views are distinct.** Source annotation syntax is a constraint/contract language, not an identity presentation of the final inferred scheme or of the solver's internal evidence-rich view. `_` and `[_]` are annotation placeholders/contracts rather than canonical type constructors; inferred public schemes may contain structure not directly writable in source, while handler protection, role candidates, directed visibility evidence, typed paths and owner/receiver coordinates may remain internal. Therefore `f: _ -> [io] _` contributes a scoped source contract that must be mapped to the completed original profile; it does not state that the inferred type is literally that surface spelling. The provisional fully protected Handler view for unannotated `f` is likewise an internal inference seed. Non-Handler determination refines/discharges that seed on one shared inferred relation rather than rewriting a written type or a supplied callable's actual role. This clarification is Authoritative in [inferred Function call views](../design/2026-10-05-inferred-function-call-views.md#11-source-annotations-inferred-public-types-and-internal-views-are-distinct) and is consistent with the older [public type reference](../../web/docs/reference/types.md) and [type-inference reference](../../web/docs/reference/type-theory.md).

### 2. Source to finite constrained presentation

**Conditional theorem — source adequacy target.** The source-interface adequacy draft defines fiberwise forward coverage from source executions into a complete interface, under the same `nu` and retained joint `K,D`, including future uses, latent closures/thunks, requests and resumptions. Its exact complete-interface embedding is a semantic reference construction, not a finite solver or proof that current HIR generation emits such a presentation. See [source-to-complete-interface adequacy](../design/2026-10-02-source-interface-adequacy-theorem.md) and [typed source owner realization](../design/2026-10-02-typed-source-owner-realization.md).

**Contract — callback literal B.** Expected context chooses Handler/boundary before visiting the inline literal body. Parameter, body, and result endpoints are synthesized independently; the completed Function is checked once by ordinary `F_lit <: F_cb`. Endpoint copying/equality is not permitted. A is allowed only as B-equivalent constraint scheduling/partial evaluation preserving acceptance, principal solutions, method/adapter choice, and residual/evidence behavior. Prebuilt Pure values take their distinct actual-role path. This is a source contract, not a claim that current HIR implements Apply or inline lambdas. See [callback context delivery](../design/2026-10-03-callback-context-delivery.md) §2 and [production callback endpoint-generation draft](../design/2026-10-04-production-callback-endpoint-generation-draft.md).

**Conditional theorem — entailed early propagation preserves B solutions.** If `F` is independently proved entailed by the complete B solution relation `S_B`, then `S_B ∧ F = S_B`, including all method/adapter/residual/evidence alternatives and the final B query. This holds without a bounded-domain assumption. It gives a mathematical criterion for an A scheduling step, not a production algorithm for discovering entailed predicates; endpoint-only projection cannot delete B witnesses. See [source factor coverage and complete-use preservation](../design/2026-10-05-source-factor-cover-and-query-preservation.md) §4.1 and its [progress record](../progress/2026-10-05-factor-cover-main-gate-attack.md).

**Theorem — source-indexed reference realization.** A finite constructor interpretation in the existing relation carrier gives membership and independent query-free admission rules for the specified reference source objects. Whole-observation typed projection preserves the stated Theorem C crosswalk, including finite latent/future/resumption histories. This proves the reference's crosswalk only, not that the compiler's production endpoints denote it. ### 3. Structural solving

**Theorem — normalized pure structural FMP / finite-fence completion (classification A).** For every satisfiable fixed normalized pure structural package in the stated carrier, an arbitrary permitted tree model yields a permitted simultaneous regular graph model of at most `8^N` states. Exact shared recursive descriptors, mandatory Record width, Function variance, invariant coordinates, and arbitrary rigid permission sets are included. The proof also closes complete finite-quotient conflict reflection and the former bounded-rank residual. It assumes no source-generated regularity predicate. See [finite-fence completion](../design/2026-10-04-structural-fmp-fence-completion.md) §§1–2, 9–12 and [proof/review record](../progress/2026-10-04-structural-fmp-proof.md).

**Reviewed corollary — pure-package effective satisfiability.** With finite input fixed-head/Record-label alphabets, decidable identity for the finitely many input primitive/rigid atoms, and decidable permission membership for input rigid atoms, enumerate all guarded graphs up to the FMP bound `8^N` and check each package clause by finite graph simulation and root-reachability permission checks. The FMP construction's heads, atoms, and Record masks lie in this finite input alphabet, so the search is complete as well as terminating. This is a mathematical corollary, not a practical algorithm or production decision. It does not include `Guard`, `Phi`, `K,D`, effects, source admission, residual projection, or principality. See the [derivation](../progress/2026-10-05-pure-structural-effective-decision-corollary.md).

**Historical / superseded — structural regularity sufficient conditions.** The earlier two-sided constructor-bound [preclosed witness theorem](../design/2026-10-04-preclosed-structural-regular-witness.md) remains a valid constructive conditional result, including its explicit bound and multiple-anchor cases. It is no longer the condition needed to establish pure structural FMP; its one-sided/unbounded-root gap is covered by finite-fence completion. Likewise the source-generated/root-only/one-open-anchor/selector theorems remain useful conditional source results, but are not premises of the unrestricted normalized pure FMP theorem. See [source-generated theorems](../design/2026-10-04-source-generated-callback-structural-theorems.md) and their [progress record](../progress/2026-10-04-source-generated-theorems.md).

**Characterization.** The finite-fence Python checker and generated package searches check the construction on bounded families and retain shrunk defects as regressions. They do not establish the theorem, choose production algorithms, or set resource limits. See [finite-fence playground](../progress/2026-10-05-structural-fence-playground.md).

**Open — finite constrained residual and effective projection.** The reviewed scoped-solving work gives equality quotienting, closed structural comparison, and a candidate factorization of solutions through finite open-bound residual edges under stable finite guard/evidence contexts. It does not yet close source-wide context finiteness, the full effective joint solver for residuals plus `Phi/K,D` and structural projection, or an effective principal projection. The pure-package effective-search corollary above does not solve residual constraints, jointly project effects/guards, or provide a production decision procedure. See [scoped constraint solving](../design/2026-10-03-scoped-constraint-solving.md), [open residual factorization](../design/2026-10-03-open-residual-factorization.md) §§1, 4–7, and the active-gate summary in [tasks/current.md](../../tasks/current.md).

### 4. Callback transport and safe hiding

**Theorem — total-definition elimination.** Fresh total coordinates defined at their original scopes can be forgotten while preserving old witnesses, complete observations, and their independently generated admission certificates. This needs no admission-uniformity condition for those new derived coordinates. **Theorem — linked equality.** The specified actual and checked reference bounds are equal on each checked-admitted complete fiber. Both results are in [callback coverage and source-preserving composition](../design/2026-10-05-callback-coverage-and-source-joins.md) §§2–3 and strengthen the earlier inclusion-only formulation for that exact linked pair.

**Theorem — old-witness Coverage characterization.** After a legal existential marginal over old witnesses, the exact linked comparison holds iff every actual complete observation (at a checked challenge) has a checked-admitted old-witness representative with the *same* complete observation and retained challenge. Uniform admission is sufficient but stronger. This does not move quantifiers across rigid binders and does not permit changing retained owner, request/continuation, path, or shared fiber. The finite safe-hiding dependency closure is a sufficient source-derived class, including proof that exposed requests/providers were produced and retained. See [coverage/source joins](../design/2026-10-05-callback-coverage-and-source-joins.md) §§4–5.

**Theorem — finite certified transport.** The certificate class transports every finite membership and punctured-context admission derivation for the complete presentation, including latent/future/resumption histories, under its approved finite transformations and their original scopes. For additional hiding, admission-uniformity across the forgotten fiber is a sufficient condition in that theorem; dropping it has a countermodel. The later Coverage result refines the condition for the specified linked pair. Neither theorem derives certificates from production generation. See [certified callback transport](../design/2026-10-04-certified-callback-and-constrained-use.md) §§2–4 and [admission-hiding characterization](../progress/2026-10-05-callback-admission-hiding-playground.md).

**Counterexample / obstruction — wrong joins.** Independently joining stage/type marginals can lose the original source witness or provider incidence (`higher` diagonal); substituting a local representative can also fail under a scalar selector. The source-preserving composition route retains whole original witnesses and their joined request/provider correlation. These refute shortcuts, not every common allowance. See [coverage/source joins](../design/2026-10-05-callback-coverage-and-source-joins.md) §6 and [experiment-guided record](../progress/2026-10-05-experiment-guided-main-gate-attack.md).

**Theorem — factor coverage and complete-use preservation.** For a finite source relation `T` presented as factors `A_i` with complete operand scopes `E_i`, and proposed coordinate bags `B_j`, if every factor scope is contained in some retained bag, then joining the projections of the same `T` reconstructs exactly `T`. Over independent factors on nontrivial product domains this coverage condition is also necessary for a *uniform* guarantee; that converse is not claimed for a particular constrained fiber or after an observation projection. Exact reconstruction is stable under adjoining any unchanged joint client and direct-query/evidence relation, with its original scopes. A fixed XOR/returned-provider construction shows that every proper coordinate projection can lose an observation-visible source dependency. This supplies a finite certificate for an existing logical decomposition; it does not authorize a descriptor formation rule or produce a common allowance. See [source factor coverage and complete-use preservation](../design/2026-10-05-source-factor-cover-and-query-preservation.md) §§2–5.

### 5. Principality

**Theorem — constrained-use construction, conditional exactness.** Fresh-copying a finite presentation, applying a supplied uniform descriptor graft, retaining the client's constraints, and adding one direct complete query at the designated exported root constructs an ordinary finite use. Its solution relation is exact iff the scoped extension entailment `C_V(v) => Ext_P(v)` holds for each public assignment. Thus no separate explicit `m_V` map-construction calculus is required for this route. The theorem does not prove the entailment for every valid view. See [certified callback and constrained-use results](../design/2026-10-04-certified-callback-and-constrained-use.md) §§5–8.

Ordinary fresh-copy/graft/direct-query use removes the need for a separate map calculus when the query is retained; it does not remove the all-view completeness obligation. The current exact remaining criterion is `C_V(v) => Ext_P(v)` for every independently valid public view, plus legal common-descriptor realization. Do not report the universal all-view gate as solved.
