registration candidate at each owning constructor and an owner-indexed
installation schema. It proves conditional preservation calculations for the
schema. It does **not** complete E-flat: the assigned sources expressly leave
the exhaustive original Application atom inventory undefined. Section 4
isolates the missing inventory kernel rather than declaring the displayed
reference relation exhaustive. Construction stops before filling that kernel
or constructing an authentic original literal installation.

This is a construction proposal under fixed source meanings. The earlier
representation's old Name injection/retraction and the earlier missing-rule
counterinterpretation are retained inputs, not repeated attacks. The new
part is the registration judgment's dependent parent/role/scope structure and
the occurrence-by-occurrence inventory interface required at installation.

result port `o_result` is distinct from owner evidence `o_owner`. Those
distinctions govern this proposal.

## 4. The missing complete inventory kernel

The required inventory is an occurrence family, with multiplicity and proof
alternatives retained, rather than a set of formulas. A sufficient interface
for H-inventory is:

```text
InvKernel(j,registration_spine) =
  (A_j, enumerate_j, Atom_j, Origin_j, Attach_j, dependencies_j,
   InterpretAtom_j, inventory_inversion_j, inventory_action_j)
```

For the stated finite slice, `A_j` must have an independently specified
exhaustive enumeration of the original owner's atom occurrences. `Atom_j(a)`
is the actual independently interpreted proposition. `Origin_j(a)` is its
source introduction derivation, not satisfaction. `Attach_j(a)` records its
typed child/result/reify/check/suffix attachments at this same `j`.
Enumeration preserves distinct occurrences of the same formula and distinct
licensed derivations. It includes child and ambient original occurrences
with their own original owners; it does not falsely change their parent to c.

At minimum the local-generation projection must include the complete primitive
relation and the actual occurrences of WF_Dec, VIncl, WholeArgCompatible,
ReceiveSchema and complete-image CIncl. Any additional original result atom,
side condition or emitted obligation is also in A_j with its original origin
and attachment. Those five displayed heads are a **lower-bound projection**,
not an exhaustive definition.

An installation output must return a bijection of occurrence inventories:

```text
k_j : A_j <-> A_installed(j)
Atom_installed(k_j(a)) = Atom_j(a)              [same dependent proposition]
origin/attachment_installed(k_j(a)) = transported original fields of a
lookup(insert(j,a)) = (j,k_j(a),Atom_j(a),Origin_j(a),Attach_j(a))
```

Surjectivity excludes an unaccounted installed obligation; injectivity
excludes merging two original occurrences. Explicit alternatives, ambient
constraints and proof choices survive. Installation preserves the whole
dependency telescope, including every result obligation that Check does not
project. A legal map acts on all of A_j and its fibers together. For a
noninvertible legal endpoint substitution, occurrence identity/multiplicity
is still retained; no converse action or global bijection of endpoint values
is claimed. Coherent invertible renamings additionally have the inverse law.

The source of A_j and its inversion must be the independently specified
original owning atom grammar. Defining A_j to be whatever a candidate emits
would make the bijection tautological and establish no original retention.
Likewise an unexplained `Extras(j)` term merely restates the missing inventory.

**Bounded stop.** The literal proposal §3 explicitly says the reference
inventory is not exhaustive and assigns extra original atoms to H-E.
Construction audit §5 says the full authentic inventory is unspecified.
The Application-owner derivation §4 H_app lists the checking package but
does not add an exhaustive inventory inversion. Thus the assigned dependency
set supplies no definition of A_j with the required completeness law.
This note does not instantiate InvKernel, enumerate unknown extras, or
construct a completed E-flat from it. No broader absence search was performed.
