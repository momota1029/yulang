## 1. Objective, method and boundary

Construct a finite source-free public descriptor template for the bounded
immutable nonrecursive Value-parameter projections `id x = x` and
`pick ignored = z`. Method: typed clause assembly from the selected entry,
binding and result rules, with explicitly separate descriptor, admission,
import and production interfaces. This is construction of a proposed supplier,
not another information-collision experiment.

The result is one explicit **conditional constructor** below. Its source-base
wiring and substitution action are fixed. Its hard result guard, complete
production licenses and ordinary-descriptor embedding cannot be closed from
the inspected authority. Their exact alternatives are returned in §6 without
selection. A descriptor with arbitrary predicates renamed as these suppliers
would not complete D0. No original `M_E` witness, source-presentation owner or
source-root proof at use time is assumed.

The target is a displayable scheme and finite additional use information,
as selected in [q1/a1](../../questions/2026-10-08-successor-generalize-root-policy/approved-answer.md)
decision items 1–5 and its [receipt](../../questions/2026-10-08-successor-generalize-root-policy/receipt.md).
Construction may inspect source at publication. No source definition or full
source relation is exported under an import handle. Sufficiency, the necessary
size of additional information and concrete semantic adoption remain open.

## 3. Typed public input and deterministic assembly

The bounded input is the whole scoped scheme, not its printed instantiated
arrow. Write `A=rho(a)` and `B=A` for `id`; write `B=B_z` for `pick`.
The pure body endpoint is `Comp(empty,B)`; it does not give an empty bound on
the complete invocation. Pure role and Value entry are certified for this
specific publication envelope, never inferred from Value entry alone.

The candidate decoder input is

```text
I = (Sigma, binder/incidence map, selector, imports, Kernel, Policy)
selector = Formal | Fixed(0)
Sigma_id   = forall a. a -> a       imports_id   = []
Sigma_pick = forall a. a -> B_z     imports_pick = [J_z]
```

The selector is convenient proposed schema data, not proved necessary. The
prior attack's unique-import/scoped-binder hypotheses permit reconstructing
it. Neither that restricted elimination nor a concrete `alpha` lower bound
is established for the full successor envelope.

`Kernel` contains independently interpreted typed primitive contracts, not
source closures: receipt, designated Force, current-world Bind, rebind, pure
Value Result, invocation return, observation restriction, operation response,
raw resumption and future demand. `Policy` contains the independent descriptor
embedding and explicit production grammar/guard contracts of §§4–6. These are
finite global supplier interfaces; their interpretation is not made true by
this declaration.

The following typed indices make operand assembly explicit. They are proof
notation for existing interfaces, not new runtime types or compiler carriers:

```text
t : WholeCarrier(A)          v : Value(A)          z : Value(B_z)
C : CurrentConfiguration     h : CompleteChallenge
p : ActualCallable           r : ActualReceiver
e : Receipt                  O : WholeObservation
w : OriginalScopedEvidence
```

At an actual activation, dynamic `p,r,t,e,C` come from the genuine invocation;
none is a stored replacement receiver or a newly chosen provider. The shared
`xi`, original scope tree and incidence map parameterize every clause.

### 3.1 Fixed import contract summary

`J_z` has these explicit public fields, interpreted jointly:

```text
J_z = (B_z, same captured value/provider incidence,
       original rigid binders and shared dependency operands,
       value/interface membership clauses,
       independently admitted future-demand clauses,
       complete observation/guarantee clauses,
       visibility, authority, lifetime and scope clauses,
       explicit public references to every transitive contract dependency)
```

Each field is a public interface clause/reference with its independent
interpretation and original typed operands. The import may reference a
finite shared public contract graph. It cannot reference a source definition,
source relation or an oracle that reconstructs either. A provider identity
alone and an erased `B_z` alone are insufficient specifications of this
summary. No finite complete summary for every possible source capture is
proved here. The bounded constructor is conditional on such a supplied
`J_z` and on its truthful fixed-incidence certificate.

Whole instantiation freshens eligible local binder occurrences and every
incident clause once. It preserves the same `z`, `J_z`, all rigid import
coordinates and all shared dependencies. A local-to-import residual equation
remains active. No per-port hiding, per-challenge witness choice or independent
freshening of the import is part of the constructor.

### 3.2 Source-base template and its formation typing

Assemble this fixed ordered primitive-image template, with `s=v` for Formal
and `s=z` for Fixed(0):

```text
Receipt(p,r,t,e,C0);
DesignatedForce(t,C0) >>= (v,C1).
  Rebind(e,v,C1);
  ValueResult(s,C1);
  InvocationReturn(s,C1)
```

This notation records invocation phases; it does not run the body twice.
Value Result performs pure introduction at the body result interface;
InvocationReturn is the complete invocation's corresponding outward return.
The result's actual latent provider remains unforced in both forms. Entry
forces the argument once even for Fixed(0). Pending Force requests keep
their original raw continuation; resumption continues the suffix at its
current world and does not replay Receipt.

Formation obligations are now explicit:

| Node | Independent typed input/output obligation |
| --- | --- |
| Receipt | Same actual callable/receiver, whole carrier, valid live receipt/context preconditions; preserves `t : WholeCarrier(A)`. |
| DesignatedForce | Its supplied contract emits typed prefixes and returns `v : Value(A)` if it returns, at `C1`; it need not return. |
| Bind | Return passes its same value/current world to the suffix; Request keeps the original request and resumes its continuation before that suffix, as source-contracts §3.2 specifies. |
| Rebind | Installs that same returned `v` at the receipt's formal incidence in the actual `C1`; preserves original binding/world clauses. |
| Selection | Formal uses this `v` and `B=A`; Fixed(0) uses the same imported `z` and `B=B_z` with `J_z` valid at `C1`. |
| ValueResult/InvocationReturn | Pure body introduction of `s : Value(B)`; same result provider and current world at outward return; preserve its latent interface. |

An actual source base is the observations generated by these independently
typed local images and their prefix/restriction laws, not by a retained
source-root lookup. This is the complete bounded source-base inventory;
additional source bodies are outside the two-template envelope.

The finite graph is constant size beyond its explicit scope, incidence,
primitive and import interfaces. Sharing references avoids copying imported
graphs per call. This is a syntactic size statement; semantic predicates can
quantify over arbitrarily long finite interactions. It gives no solver,
runtime or public-summary size bound.

## 4. Independent admission and active ordinary descriptor inputs

### 4.1 Admission clauses

Before interpreting membership or resolving a query, the candidate declares
these admission clauses using the independent Kernel judgments:

```text
Initial(h) iff ContextOK(h,xi) and OtherValuesOK(h,xi)
  and ActualHoleIncidence(h,p,t,r,e,xi)
  and WholeCarrierOK(A,t,h,xi)
  and FixedImportsOK(J,h,xi).

Response(h') iff PreviousExposedRequest(h,q,k,C,xi)
  and ResponseOK(q,response,C_current,xi)
  and SameHistoryExtension(h,h',q,response,C_current,xi).

RawResume(h') iff PreviousExposedRawHandle(h,k,xi)
  and RawHandleDemandOK(k,demand,C_current,xi)
  and SameHistoryExtension(h,h',k,demand,C_current,xi).

Future(h') iff ActuallyReturnedAtPort(h,s,port,xi)
  and FutureDemandOK(contract(s,port),demand,C_current,xi)
  and SameHistoryExtension(h,h',s,demand,C_current,xi).
```

`ContextOK` ranges over every independently typed compatible punctured
context, with the actual whole carrier and callable filled directly. These
clauses have no `Q`, `Direct`, actual-U acceptance, successful execution,
output-safety or Return requirement. `WholeCarrierOK` checks the carrier's
complete independent contract, including pending/request/resumption ports,
not only completed payload types. The source-selected immutable/hereditary
interpretation governs its value/import fields; unknown primitive contracts
are not certified by their names here.

The dynamic live-event guards use their actual current configuration.
Static retained provenance never supplies an active handler/capture grant.
Response and Future clauses extend a supplied history; they do not choose a
new provider or independently hide the previous witness. The precise typed
predicate implementations and formation into the ordinary descriptor remain
suppliers, while these clause operands and independence constraints are fixed
by the proposal.

### 4.2 Observation clauses separate from the source base

The independent ordinary descriptor conjunction at public root `u` is:

```text
Guard_u(h,O,w;xi) =
  Interface(p,r,ValueEntry,ValueResult,InvocationReturn,e;h,O,w,xi)
  and Endpoints(A,B,J;h,O,w,xi)
  and EventTypingAndLicenses(h,O,w,xi)
  and PhaseBounds(h,O,w,xi)
  and SharedScopeAuthorityDependencies(h,O,w,xi)
  and ResultPolicy(h,O,w,xi).
```

These leaves mean the following independently of source-base generation:

- Interface checks the actual role/entry/consumer and actual receipt/rebind
  incidence; an outward return has a lawful entry-completion witness at that
  activation. A matching tag supplies no such witness.
- Endpoints checks returned input payloads at `A`, completed body/invocation
  results at `B`, and each latent result provider at its original complete
  contract, including all independently admitted compatible future demands.
  Pending and zero-step observations satisfy their own partial interfaces.
- EventTypingAndLicenses checks original operation instances, arguments,
  responses, raw resumptions and live authority. An effect family name does
  not supply an operation or handler witness.
- PhaseBounds imposes body purity on body events. Entry follows the complete
  argument contract; future latent demands follow their own provider contracts.
  It retains every fixed original guarantee equation. The independent typed
  phase/entry-completion judgement must be supplied; enumerating phase names
  does not prove it.
- SharedScopeAuthorityDependencies checks original `nu,K,D`, rigid imports,
  scopes, sharing, lifetime and authority predicates on the same whole tuple.
- ResultPolicy is exactly the unresolved S/T choice in §6. It cannot be
  silently inferred from the printed result endpoint.

These predicates do not mention the source-base relation or require a source
execution. Local typing laws must prove that each template image satisfies
them. Active ordinary-descriptor embedding must expose their actual clauses
at `u`; storing them as inactive metadata fails that supplier obligation.
This remains the exact independent `DescMem` input, not its redefinition as
the source image. No original `M_E` semantics is assigned by this notation.

## 5. Full production and actual-root query surface

Let `R_u` be §3.2's independently typed template relation before projection.
For a supplied exhaustive positive grammar, a candidate production relation is

```text
Complete_u = least X.
  Guard_u(y) and (R_u(y) or Z_u(y)
                 or exists x,z. X(x) and W_u(x,y,z)).
```

`y` contains the original whole `(h,O,w;xi)` tuple. `W_u,Z_u` are independent
licensed alternatives with explicit typed operands, fixed/changed coordinates,
introduced-provider contracts and complete future-domain certificates. No
rule tests query success, nonmembership in `R_u` or raw endpoint-ID equality.
`Z_u` permits an unanchored extra. Empty `W_u,Z_u` characterize only an
explicitly selected source-only subcase; they do not certify unspecified
production behavior. Fixed hereditary import/provider contracts remain
parameters; no universal quantification over growing `X` is introduced.

The grammar above is proposed under source-contracts §3.7, not selected.
An alternative exhaustive finite independent rule inventory is possible.
In either form every production alternative must be declared, typed and
guarded, including pending prefixes and zero-step observations. Existing
source-base correspondence certifies neither inventory nor licenses.

The public surface exposes, at the **same ordinary root** `u`:

```text
head/ports + actual interface + original scopes/incidences
D_u = the independent admission clauses of §4.1
Obs_u(h) = Pi_xi { (O,w) | Complete_u(h,O,w;xi) }
all active independent descriptor leaves and full production clauses
```

These are inputs to selected same-provider membership. At any genuine
`Act(v,U,r)`, check U's actual acceptance and actual complete invocation
against this independent contract, universally at the admitted challenges.
The decoder's `Complete_u` is not substituted for U's actual behavior.

The query must name `Direct(u,F)`. A finite proof may expose these ordinary
operands and use source-contracts §5.3's conditional `Eq(D_u,D_F)` and
`Le(Complete_u,Complete_F)` calculus where its matched-interface premises
apply. That calculus requires independent resolver-conformance approval;
neither a hidden-source comparison nor semantic equality supplies it. No
claim is made that it resolves arbitrary view/domain changes or establishes
principality. This proposal leaves ordinary cases beyond the matched
certificate fragment untouched by any claimed rule.

ordinary `Interface`, `Endpoints`, `PhaseBounds` and `ResultPolicy` clauses

**Explicit falsifier for this assembly:** find an independently typed complete

production, a licensed actual root rule outside the declared inventory
falsifies exhaustive accounting; a guarded licensed extra whose changed

certificate. These are specific falsifiers, not executed or source-admitted
counterexamples established here.

Prior notes already supply the one-request entry discriminator, S/T

evidence as it is formed. It requires no reopening of selected source entry
or membership meaning and no reconstruction from endpoint IDs.

## 7. Conditional derivation, independence and omissions

**Conditional syntactic theorem.** Assume the public fields and primitive
signatures of §3 are well-scoped, the Fixed(0) import is valid, and each local
Kernel image has exactly the displayed type/operand interface. Then assembling
the two template graphs is well-typed and source-free, and eligible whole
capture-avoiding renaming commutes with assembly while rigid imports stay fixed.

Proof: Formal supplies `v : A = B`; Fixed(0) supplies `z : B_z = B`. The Force
output is therefore a well-typed Rebind input in both forms, and selection is
a well-typed ValueResult input. Its outward return retains that value and
current world. Bind connects the same returned value/current world and
original raw continuation to the ordered suffix. Each remaining primitive
references exactly its displayed typed incidence. Apply the one renaming
to every incident local operand; each finite graph edge is then the edge
obtained by assembly after renaming. Imported operands are unchanged on
both sides. This proves a graph/signature statement conditional on those
interfaces; it does not prove the primitive source rules or independent
descriptor image laws.

**Conditional guard theorem.** If every local primitive image and prefix law
satisfies §4.2 independently, Bind preserves those leaves, and the declared
import contract transports to each lawful current world, induction on finite
template derivations gives `R_u subset Guard_u`. If the selected production
grammar is exactly §5's grammar, every finite production derivation satisfies
the guard by its conclusion rule. This latter fact says nothing about the
truth of licensing, exhaustiveness or admission-domain preservation. No
source witness is required of its W/Z observations. These premises remain
candidate assumptions; neither theorem is a D0 sufficiency result.

No executable oracle, transition checker, seed, random range, enumeration or
mutation execution was used. The syntactic derivation is independent of a
source transition model but shares the assumed typed primitive signatures.
The guard derivation assumes local image laws; it cannot independently prove
those laws or their source correspondence. Logical falsifiers in §6 target
image typing, inventory completeness and provider-domain preservation; no
claim of finding an actual satisfying witness is made.

Unverified scope: raw-source acceptance, general public-import realizability,
every independently valid view, necessary `alpha`, principality, solving,
recursive SCCs, annotations/callback literals, multiple captures, mutable
state, adapters, all concrete primitive licenses, compiler/runtime conformance
and production implementation. No abandoned or incomplete search is reported
as completed coverage.
