## 1. Frozen statement, grammar and context ownership

Fix authentic immutable LocalSource, original resolved operation declarations,
source IDs/binders, one original well-typed monomorphic assignment xi=(nu,K,D)
and the ordinary primitive payload/response/selected-arm OpCompat contracts.
Let A range over Unit, Int, Bool, Str. Consider complete constructed programs
whose admitted roots and all admitted executable dependencies are closed terms
generated by:

```text
e ::= primitive literal | x | (e)
    | block(nonparameterized ordinary local bindings x=e; ...; e)
    | if e then e ... else e                 // ordinary optional-else rule
    | resolved_operation(e)
    | catch e { ordered operation/value arms }
```

Names x resolve to actual lexical local or Catch payload/value binders of
these ground values. Every operation callee is its directly resolved original
operation, with declaration `A -> A'`, no outer signature effects and no
Computation annotation on its argument or result ports. Its generated operation
family effect is still present. Operation arms use the retained total payload
Binder/Wildcard/EmptyCall syntax and discard the continuation; value arms use
the retained total Binder/Wildcard. Branch and answer types obey the original
source contracts. Ordinary output annotation checks add no receiving boundary.

There is no user Lambda/formal, arbitrary callable expression/operation alias,
unknown callee, nonprimitive value/port, free/external/captured value, bound raw
continuation, recursive call or Resume entry in this universe. A bare operation
value is allowed only as the direct callee constructor, not as a ground result
or stored alias. Grouping is transparent. Other constructors make this bounded
certificate unavailable; this is a subtheorem, not a source rejection rule or
restriction of the original whole-language negative-completeness parent.

Execution starts from the fresh program ModuleRun with no imported views,
enclosing executing CallViews or external execution API. The certificate covers
the **complete constructed execution universe**, including all admitted roots,
dependencies and arm bodies, even if some are unused on a particular run.
It is not a syntax-local certificate reusable for an arbitrary embedded term.
In particular, executing syntactically closed `io::tick 7` inside an external
received Comp view can acquire that view's event observation/protection; that
case fails this theorem's initial-context hypothesis.

For every finite ordinary/request/Catch execution prefix from this initial
configuration, prove: every source view/evidence packet created in this universe
has empty persistent protection incidence chi; consequently every actual event
q has no source Path from a protected boundary to any candidate h, and
`Protected(q,h,C)=false`. Requests/continuations, concrete operation effects,
original source/event identities and K,D are preserved by ordinary execution;
empty chi does not mean an empty effect row or an absent request.

## 2. Source owners and exhaustive profile-generation argument

Governing clauses are typed-boundary §6 (boundary introduction, transport,
Receive/Observe/Path/Inc), charter §21 (source Value versus Computation entry),
selected scheduling §§1–2, ordinary-computation package §3 (operation expansion),
reviewed root-profile construction §§2–4 and directional-inferred-protection
addendum §§2–3,6. The reviewed receiving-view theorem at the frozen checkpoint
is reused for the meaning of the source witnesses, not for negative completeness.

At the source constructors of this grammar:

| Source owner | Why no new protected incidence is generated |
| --- | --- |
| Primitive literal/binding read | A ground value has no latent Function/thunk/structural effect-observation position. Identity read does not introduce a boundary. |
| Ordinary local binding, condition result or Catch value/payload binding | The actual value is primitive; storing/reading it uses its typed ground correspondence. No received callable/Computation formal is introduced. |
| Known operation callee | It is the original declaration's known Function, not an inferred protected variable exposed by an upper Function use. Directional protection cannot be manufactured from the provider's lower output. |
| Native operation payload entry | Original argument annotation is Value(A). The whole argument is delayed, then forced and rebound inside the native receiver, as required by charter/scheduling. A received primitive A has no profiled latent path. This is not the explicit outer Comp formal which derives RootCompSchema. |
| Operation's declared result/native request | Its primitive response type introduces no received latent value. The original family contributes the real request/effect at the designated result consumer; a provider contribution is not a protection profile. |
| Group, block, branch, Catch and its arms | These ordinary computation/control constructors generate no new callback/formal annotation boundary. Their typed flows and continuation composition preserve their actual inputs rather than invent profiles. |

In particular, there are zero user-formal annotation constructors capable of
RootCompSchema or nested callback-profile introduction. Every native operation
has the explicitly known primitive Value formal just described. One may still
have a fresh invocation/receipt or even an empty profile descriptor; none adds a
protected position. Root-profile §2 requires the actual explicit outer `[S] A`
formal and is therefore inapplicable here, not merely absent from runtime fields.

For inferred directional profiles, the selected rule requires a common original
`ProtectedVarAt` seed and a source Function upper-use exposure at that variable.
There is no omitted user formal in this grammar, and each actual Apply callee
is the directly resolved known operation. Ground local Names are never called.
Thus no seed/exposure pair can generate an output-effect protection here. This
does not claim that every internal fresh type variable lacks all seed metadata;
it rules out the actual source-producing premises for a profiled Function use.
Known operation provider output cannot acquire protection by reversing that rule.

Whole-argument Delay needs a separate argument: its latent computation does
have an effect port and may emit requests. It is **not** profileless because its
allocation is fresh. Its actual computation is a grammar child whose source
evidence is profileless by induction. Reification retains that whole child,
its original typed dependencies and code; the native Value entry adds no
profile-producing applicable path. Its latent root therefore has empty chi
by source construction. This discharges the specific missing premise which a
generic `fresh Delay -> complete empty` shortcut would merely assume.

## 3. Source transition induction for arbitrary finite prefixes

Strengthen the induction invariant: every current or retained source packet
and executing view in this closed universe has empty chi; ground lexical/cell
bindings have their original primitive values; pending request/arm/bind suffixes
retain the same source and event/evidence dependencies. The source schema
inventory in §2 is exhaustive for the grammar, not an assumed empty incoming
runtime vector.

**Initial state/literals.** The fresh initial context has no imported protected
views. Literal source construction creates the original ground value and no
profile. These establish the invariant at the initial roots.

**Local Name/binding/group.** Read the actual original ground binding. The
typed relational image of empty chi is empty; storing the whole result or
publishing an ordinary local does not introduce a receiver profile. Identity
grouping has the same property. The initializer computation's requests remain
its own source requests; reading its completed scalar does not replay them.

**If/block.** Execute the actual test/RHS and preserve its dependent suffix.
Every selected continuation is another term of the certified grammar. Its
inputs satisfy the invariant; branches not chosen invent no events. Ordinary
implicit Unit production has the same literal case. No evaluation-order change
or pre-execution of an inert suffix is used.

**Direct native operation call.** Reify the whole certified argument inertly.
By §2 its latent child evidence is profileless, rather than erased. Allocate
the ordinary native receiver, execute Value entry under Cnow, and preserve the
entry/native-body/return/result-consumer suffix if the argument emits. When it
returns, bind its declared primitive payload. Native body constructs the inert
request carrier; its separate designated result consumer emits the new q with
the original declaration, source origin and payload. No step is a nonempty
profile introduction. Actual nested argument computations can emit before the
outer operation: induction covers those q independently, with their own pending
native suffix. No early argument execution or operation-instance merging occurs.

**Receive/transport/Observe.** Any actual receipt records ownership of the
same typed view; it creates no boundary/contract. Any legitimate typed transport
maps empty chi to empty, even if its K,D or concrete computation effect port is
nonempty. Observation records an event at an actually executing computation
port; it does not generate a missing boundary profile. Since no persistent
protected incidence exists anywhere in this closed source universe, the first
profile witness required by Path does not exist. Hence Path, Inc and Protected
are false for every actual candidate, independently of the event's family,
native invocation depth or receipt owner. This uses exhaustive source production,
not the failure of a local-Grant lookup or a historical-profile scan.

**Catch, forwarding and compatible discard selection.** Installing an ordinary
Catch changes control/activity, not chi. The selected source visibility test
therefore reduces to live handler/owner plus exact operation coverage. Normal
return exits this shallow Catch before its value arm. An exact-operation total
payload pattern selects in original order under original OpCompat; its raw
continuation is discarded and its actual arm body executes outside that Catch.
The body is another certified term and may emit new independent requests. No
matching operation arm forwards the same q with its ordinary source wrapper/
pending suffix. These transitions neither erase unrelated events nor remove
the family globally. Abandoning an unfinished suffix is source control, not a
proof that its hypothetical effects executed or were handled.

**Owner exit and retained work.** Native return/unwind ends its exact owner
without adding profiles. A live outer owner and its unfinished work remain
unchanged. Current discarded/retained suffixes use their original sharing and
cache ownership obligations; this theorem does not replace the separately
reviewed cache proof. No raw Resume transition is included. These cases exhaust
the grammar's source operations and establish the invariant for every finite
prefix. No fixed nesting bound, execution trace enumeration or termination
assumption is used.

Consequently a fresh ModuleRun direct
`catch io::tick 7 { io::tick(p), _ -> p }`, with declared `tick:int->int`, has
source `!Protected` at its matching candidate even without a receiver-local
Grant. It can follow ordinary compatible shallow selection. This is a corollary
of the grammar proof, not a name-specific rule or a reported runtime test.

### 6.2 Two explicit source corollaries needed by the actual classifier

The implementation accepts more transparent source edges than §1's literal
grammar lists. They require proofs rather than silent domain identification.

**Internal ground module dependencies.** The actual classifier permits a
ModuleDef Name only when its DefId belongs to P's complete definition map,
its original initializer is checked in Ground role, and the dependency traversal
is acyclic. Extend the source invariant with these internal ground cells.
Materialization executes the original certified definition under its ordinary
cache-write suffix. By the same source-constructor induction its computation
introduces no protected profile. A successful write stores the actual primitive
result view; a cache read transports that ground view; an unfinished/abandoned
write creates no profile or fabricated completed value. Source receiver/Force
order and request dependencies remain the original ones. Topological induction
on the certified dependency graph establishes this for every such definition.
The roots already include all definitions, so no outside source term enters.
This proves the same empty-chi/!Protected conclusion for internal ground aliases
without textual inlining or repeating a cached initializer's effects. It adds
no free/external value and does not revise §1's original lexical-name theorem.

**Transparent Forward provenance.** Actual lowering maps both Group and
Ascription to Instruction::Forward. Its admitted source envelope is the
independently reviewed no-effect-adapter envelope of the ordinary runtime proof:
successful formation admits bindings and original Act placeholders, not import/

The current HIR `SemanticImports(())` is opaque and exposes only `empty()`,
confirming that an imported adapter registry cannot enter this constructor.
Thus this Forward introduces no hidden effect adapter/invocation. A compatible
ascription of these ground results neither introduces a received callback/
Computation formal nor an inferred callable upper use. Any ordinary output
effect allowance remains an output constraint, not a fresh receiving profile.
Identity forwarding of the child's empty chi is empty. Consequently the source
invariant extends through these admitted ground ascriptions. This does not prove
arbitrary ascription/conversion coherence; any future applicable adapter path

These are explicit source-preservation corollaries using the existing semantic

### 6.3 Every accepted constructor and dependency is closed

`primitive::closed_primitive` first scans the full code arena, then checks every
original definition/body/dependency. It is not a selected-root-only scan.

| Actual check | Established original source premise |
| --- | --- |
| Any Instruction::Lambda immediately returns false, including unused code | No user formal, closure or user callback/RootComp schema constructor can occur anywhere in a certified universe. Parameterized named headers lower to those same original Lambda constructors. |
| Block local IDs match code.site.definition, are distinct, and are not recursive | Original locals have one owner/initializer; the dependency graph has no accepted recursive local knot. Parameterized initializer code would already fail the Lambda check. |
| Catch patterns register original owned Binder IDs; operation resolution must be Resolved | Original value/payload binding identities are retained and their ground sources are certified; no unknown operation declaration is admitted. |
| Every operation continuation pattern must be Wildcard, and there is one total payload pattern | No raw continuation value is bound/constructed. Binder/Wildcard/EmptyCall payload semantics remain the existing total source patterns. |
| Every definition ID maps back to its original vector position, with equal map/vector sizes | Every definition/dependency target belongs to this complete constructed program; the table does not import an external executable value. |
| Every definition body is entered in Ground role | All roots and dependencies are checked, including unused definitions and roots not selected for one particular start. |

The two-role work traversal then proves the syntax restriction at each use.
Ground literals are accepted. Forward follows its child under the same role,
using §6.2's source corollary. A Ground Name must be source Observe, and must
resolve to an existing internal ModuleDef body, original registered Local
initializer, or original registered Catch binder. Parameter/unresolved/
ambiguous/free resolution fails. Existing source formation has already resolved
the lexical scope: Local/Catch IDs come from the original bracketed formation
constructors, including CatchArm/Restore. The classifier's global binder sets
are not an independent proof that arbitrary forged cross-arm references are
well scoped; authentic owner-checked source construction is essential here.

Apply checks its argument in Ground role and its callee in DirectCallee role.
DirectCallee admits only Forward chains ending at an actual resolved Operation.
It cannot admit a Name alias, Lambda, arbitrary Apply, free function or effectful
callee expression. Conversely a bare Operation in Ground role is rejected,
so it cannot be stored or returned as a supposedly ground value. These checks
close the known-provider/no-directional-callback-producer premise, not just
the absence of user Lambda syntax.

`primitive_operation` inspects the original declaration's Function signature:
outer signature effects are absent and both argument/result are exactly one
primitive value variant with `effects=None`. Its cache is keyed by the original
SourceOperationId. Authentic declaration identity fixes the signature, so
memoizing its checked property by that ID preserves the result. No solved
runtime tag is substituted for this source declaration/role check. The actual
native family contribution remains nonempty when an operation emits.

Block visits every initializer and final expression. If visits all tests/bodies
and the optional else. Catch visits its scrutinee and every retained arm body;
its prepass has already checked every pattern/declaration. Thus untaken arms
and branches cannot conceal an external/profile-producing term.

Each (label,role) uses white/gray/black states. Entry rejects gray and reuses
black; Leave blackens only a previously valid entered label. The DFS work stack
therefore rejects every reachable cycle conservatively, including a ModuleDef
or Local dependency cycle, instead of assuming a ground result for an ungrounded
cycle. Reusing a completed dependency preserves its proven property. The final
test requires every retained code node to be black in at least one valid role;
orphaned unvisited code cannot escape the whole-universe check. Exact code-label
owners/ranges are produced by `from_hir` from the original LocalSource index,
not reconstructed by this classifier from a numeric ordinal alone.

Consequently acceptance supplies every constructor/closed-dependency hypothesis
of the original source invariant plus §6.2's proved corollaries. It does not
infer complete emptiness from an empty runtime profile inventory or fresh Delay.

### 6.4 Certificate construction, lifetime and actual fresh entry

`RuntimeProgram::from_hir` constructs all code, definitions and exact definition
indices first. It creates a private `closed_primitive=false` field, runs the
classifier on that completed program once, stores its result and only then
publishes `Arc<RuntimeProgram>`. No prefix of the program is certified. Public
callers cannot set this field or replace code through the module's API; program
and source ownership remain immutable for the lifetime of the machine.

Actual `start` selects only existing definition IDs and validates every supplied
execution-root ID/duplicate. Irrespective of which subset/order a caller selects,
every admitted body and internal dependency has been certified; normal source
root-order correctness remains the existing execution-root contract. No new
external code/environment/value is an input. Start initializes empty lexical
bindings, uninitialized internal cells, empty receipts/views/executing views,
no invocation/template/continuation history, and current_owner=ModuleRun. These
are the theorem's actual initial-context hypotheses at their constructor.

The current public Machine methods are read-only value/continuation-depth/step
queries plus run/step. They expose no mutable environment, arbitrary code entry,
imported value execution or raw Resume method. Private state/handles cannot
inject a foreign protected view through that API. Resource-budget continuation
by run/step merely retains the same machine; it is not a new external execution
context.

Although this baseline includes private raw-Resume implementation, certified
programs cannot reach it: the only source construction of an executable raw
continuation occurs when a selected arm binds its continuation Binder, which
the classifier forbids in every arm. It also forbids user Lambda and all callee
aliases; direct callees can only be original operations. Initially there are
no executable continuations/templates. Induction on actual constructors therefore
keeps continuation application/EnterTemplate unreachable in this subcase.
An unhandled opaque ContinuationHandle is externally inspectable but has no
public execute/reentry method. This establishes the no-Resume hypothesis for
the certified universe despite the existence of unrelated private Resume code.
The private continuation module defines only internal template data, with no
additional public Machine/RuntimeProgram execution method.
It does not establish the whole raw-Resume proof or authorize future API reuse.

### 6.6 Structural cost and conservative failure

The initial pass visits every code/binding/arm once. The DFS processes each of
the two role states once and visits each associated syntax/dependency edge a
constant number of times. Each direct declaration signature is structurally
checked once through the ID cache. Thus structural work/storage are linear in
code, binding/arm/dependency edges and declaration operands; source-ID hashing/
equality costs must be added explicitly, or treated as bounded-ID costs. The
hash-table bound is expected amortized work, not a worst-case collision
guarantee. The work stack is iterative. There is no runtime historical-profile traversal for
this certificate. Per-query negative eligibility reads the immutable boolean;
ordinary operation/typing/liveness checks remain their existing costs.

Cycle, unsupported-node, unused-Lambda, incomplete-dependency or scope/property
failure returns false. This can conservatively withhold the certificate even
for some semantically unprotected programs; it cannot reject source admission
or replace the positive route. No source-size cap or dynamic certificate
invalidation/reuse mechanism is introduced by this proof.
