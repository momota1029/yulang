## 4. Constructor site for public result widening

The committed discriminator already proves the fixed-I semantic instance
`VP-Echo(I_n,Int,IF) <= VP(I_n,Int,Any,IF)` (§2.3). This note does not repeat

| --- | --- |
| Start / Receipt | Same independent initial fields, receipt action, current world and incidence guards; exact equality leaves. |
| Force / Entry | Same **whole I**, same gamma/J image, mu_result to Int, every Delta guard and original formal rebind; equality. |
| Body / Restrict | Preserve actual formal Int evidence and administrative/prefix fields; equality. |
| BodyReturn | Apply `c_top` to this production member's own hereditary `V(Int,b,p_b,e)`. Retain `(b,p_b)`, world and source/target check incidence. |

For R1, forgetting Echo is the independently established refinement projection
in phase §4.4. Keep the original entry/formal value and remove only the checked
membership conjunct required by that projection. No nested future result is
required to equal the outer entry. R0 needs no Echo projection.

This gives a finite constructor proof **when the actual paired interface
clauses expose these operations with their unchanged guard operands**. Induct
on finite VP derivations; pair the finite recursive suffix equations once.
Every source alternative has the corresponding row above. VP's arbitrary
Int BodyReturn alternative is covered by its own V(Int) proof, not merely by
the authentic id execution. Pending/divergent carrier prefixes require no
invented result. Licensed non-source J observations remain in Force unchanged.

The equality of initial admission clauses follows only for the explicitly
paired unchanged-I/IF initial presentation: B membership is introduced at
BodyReturn, not used to admit the initial carrier. That observation does not
prove equality of independently retargeted **future** contracts. The phase
definition checks each future demand at the original declared returned-port
contract. A public pairing must therefore present its actual future-domain
rule and the check's finite compatibility action; if a nonpositive child or
invariant changes, §5.3 requires its actual Eq/domain proof. No future-domain
equality is assumed from the words “Top” or “same provider”.

Consequently this table is a constructor recipe, not an unconditional proof
for every independently formed `VP(I,Int,Any,IF')`. Unmatched IF guards,
changed future ports, different J images or changed typed operands remain
