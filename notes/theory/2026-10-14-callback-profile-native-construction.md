Proposed invariant, **not adopted representation**: at formal formation retain
the already known `(L, cb, source position, scope, omission, A_cb)` as the sole
source owner of the receiving contract. Before processing an exposed Function
path, the accepted source elaboration derives its applicable profile and live
operation from that same owner and expected context. A_cb remains a variable;
ordinary demand generation, accumulation and levels continue. Newly exposed
paths are checked by that same source rule, not guessed from equal support or
copied wholesale from the root. Roles are fixed before effect-port elaboration.
This allows protection construction before the entire type is resolved without
eager solving. It does not specify new data layout, colors, snapshot storage or
the unresolved explicit negative-formal field law.

Required assertions for a primary-authorized construction/consumer slice are:

- The original unannotated cb source takes the protection path with no concrete
  grant; relay's literal remains pure-role and its Value parameter still forces.
- An authentic later Function demand and late concrete lower retain the exact
  owner/path context and reach its guard consumer. A second same-family local
  contribution has its own disposition; no support-wide cancellation occurs.
- Complete argument/body/result execution, actual returned value and matching
  latent result paths use one original Call/provider assignment. Root call
  protection does not become a grant on every returned latent position.
- Replay retains both parents; capture and fresh uses retain lifetime/sharing
  within a use and independent local instances across uses. Actual Value-SCC
  parent/copy equality transfers obligations without coalescing recipe lineage.
- Failed private construction cannot publish inconsistent results; successful
  suspension preserves its continuation and invalidated dependencies. Only
  state that has a proved meaningful invariant is reused.
