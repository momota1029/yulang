## 3. What levels and capture establish directly

Authentic initialization and fresh allocation set `non_generic=false`. Journal
restoration restores the earlier value; same-SCC equality ORs the two flags.
There is no production true-setting operation in the inspected native owners.
Consequently this flag cannot currently encode a newly discovered fixed source
dependency. This observation is not a new language genericity rule.

At capture boundary B, `Capture::row` canonicalizes its RowKey and computes

```text
local(v) = L(v) > B && !non_generic(v).
```

`expand_row` stops immediately at a nonlocal row. Otherwise it visits that
physical owner's lower and upper bounds and retains their actual sides,
relation incidences and evidence references. Function expansion keeps all four
ports, with the specified polarities. Context payload discovery may add Effect
tails; it is not a traversal of arbitrary semantic Value contract fields.

Fresh preparation maintains one canonical-source-row map. A local row still
above B and generic becomes fresh at use level U; a shared row remains the
canonical source identity. Every reference to that row in this graph uses that
same mapping. Functions use the jointly remapped four children. The local
consumer recaptures the live root at its stored boundary, prepares one mapping,
restores bounds in their captured order and only then links the occurrence.
These are direct operational facts, including actual consumers, not assumed
freshening transitions.

For `my apply f={my step x=f x;step}`, the source traversal assigns the outer
formal f level 1, step's initializer/parameter level 2, and step boundary 1.
Thus any encountered canonical representation of the original f row remains
shared at step use. x is a younger candidate row. This proves the lexical row
fact; it does not establish that every semantic free field of f's complete
Mono contract is represented by that older row or its retained dependencies.
Nor does it prove the outer publication's event/proof binder allocation.

## 4. The selected pair separates row progress from semantic closure
