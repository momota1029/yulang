Let S be the candidate family with components V/W/T/Car from

For each finite local checking tree d from A to F, the requested conclusion is:

```text
D_d: forall original events e and complete d0 in D_F(e).
       d0 belongs to D_A(e), with its same whole carrier and all indices;
P_d: forall such d0 and complete/pending/future observation o.

       with the same decorated o and one original scoped strategy.
```

Here d0 is a challenge, distinct from the proof tree d. D must be independent
of S. P ranges over the descriptor observation relation, including its
complete hereditary fields; it is not restricted to a convenient source
diagonal. The recursive consumer then uses the original source Phi(S)
readout on D_d(d0), followed by P_d on each same actual observation. No
ordinary `V*(A,v)` premise, extensional VIncl oracle, successful query,
provider reselection, body/invocation equality, admission-from-output rule,
or inference of P from Phi monotonicity is allowed.

**Finding.** The unconditional lift of every ordinary finite check into the
same candidate S is not established by the selected checking grammar.
The first missing premise appears when a structural child changes a

proves this implication at the selected semantic membership V*, not at an
unproved candidate S. This is an obstruction to the proposed proof step,
not a source-qualified counterexample to cO/cE or to natural inference.
The following conditional cases identify exactly where E is consumed.

## 3. Constructor induction up to its first missing premise

### 3.2 Structural checks: the earliest obstruction

At the logical observation level, conjunction/intersection introduction uses
the same o and the same strategy in both premises; union injection uses the
recorded actual alternative; finite union elimination follows that alternative
under its original guard. Record width projects the selected actual fields
and retains their latent providers and scope obligations. These operations
are independent of S once their positive child actions are available.

For depth checking at a positive value field, the source clause gives
`S.V(A_child,a,r,e)`. The target clause requires
`S.V(B_child,a,r,e)`. The child's ordinary semantic inclusion supplies only

```text
V*(A_child,a,r,e) -> V*(B_child,a,r,e).
```

No constructor displayed in §3.2 changes this to E_child[S]. Function result
structural checking encounters precisely the same problem through PhiT
Return. This is the first open constructor premise. Even if a record or
union constructor itself is unfolded positively, its leaf membership action
remains necessary. If those constructors are represented by opaque V tuples
in S, their own unfold/fold or endpoint closure is additionally required;
their ordinary membership interpretations cannot be silently substituted
for an arbitrary S tuple.

Top/Any retains its existing independent membership meaning. When the needed
tuple is an independently fixed leaf in B_H, B_H containment supplies it at
the same root/event without choosing a provider. This closes that particular
leaf. It does not establish closure under an enclosing checked Function
endpoint. A claim about every structural case cannot replace this distinction
by assuming all target V tuples already belong to S.

## 4. A bounded witness: background containment is not check closure

This is a mathematical witness about the displayed relative clauses. It
does not exhibit an admitted full source derivation, valid recursive L4,

Use one fixed complete Value entry I and the same independent nonempty
challenge domain throughout. Take an immutable actual callable u with a

```text

```

This is the same positive complete entry/Return constructor as the selected
pair, with one registered descriptor reference for A. Keep all complete

```text

A <= F3                   complete Function check; result child A <= F2.
```

Their D maps are identity on the entire fixed domain. At ordinary membership
the Function observation/result conclusions follow constructor by constructor;
the trees do not use an inclusion oracle or a cyclic proof leaf. They are
checks of an assumed source endpoint, rather than proof that this u realizes
that endpoint.

Set H to the exact decorated provisional value tuples `(A,u,r,e)` at lawful
events and set S=B_H for the same relative operator. H gives the A tuple.
Independent Any membership and Unit Return supply u's F1 readout. Unit has
no registered Function decomposition at F1; no H hole is at that tuple.
Therefore Unit is absent at F1, and u is absent at F2 in B_H: its actual
completed body Return of Unit fails F2's F1 result obligation. This conclusion
uses the genuine Act guard and an independently admitted returning carrier,
not termination of every carrier. B_H contains no world/carrier holes.

Now form an independently legal Return observation of u itself at its
original root and a B_H-valid immutable world containing the declared A
binding. The descriptor Return clause admits any same-world value at its
result endpoint (simultaneous introduction §2); the observation domain is
not the image of u's actual body. Its original result incidence is that of
this Return computation. It belongs to `P_A[S]` because `S.V(A,u,r,e)` holds.
It does not belong to `P_F3[S]`, since that Return needs `S.V(F2,u,r,e)`.
Thus the displayed P implication for the finite check A to F3 fails on
this relative family, despite S containing all B_H components.

The observation is deliberately not u's actual Unit body Return. Restricting
P to actual u observations would avoid this particular witness but would
weaken the assigned complete descriptor-inclusion map. Ordinary A membership
of u is also deliberately absent: proving it would discharge the very source
hole this relative argument leaves provisional. This witness explains why
an ordinary checked theorem is not automatically a theorem on relative holes;
it does not refute a theorem whose independently established source law or
explicit candidate closure prevents the witness.

Adding the checked tuple to S removes a membership gap only by introducing
its own Phi(S) readout obligation. A source-directed candidate closed under
the actual finite proof's positive endpoints might permit a simultaneous
construction, but that invariant and its source action are not established
here. No claim is made that such a construction is impossible. No new
semantics, certificate requirement or source restriction is adopted.
