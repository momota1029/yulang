## 1. Frozen objective, quantifiers and claim classes

The algebraic question is whether identifying selected Value type coordinates,
and transporting every constraint occurrence, has exactly the meaning of the
old constraints conjoined with those identifications. It is **not** whether all
old solutions survive an identification. The latter assertion generally fails
and is not imposed as a new source-inference prerequisite.

Freeze three disjoint identity domains: source Values `Vsrc`, Value type
coordinates `IV`, and Effect type coordinates `IE`. Resolved source binders,
lexical scopes, publication boundaries and all historical occurrence identities
remain original. Only free type-coordinate occurrences in live semantic
payloads are acted upon. Historical coordinate names in provenance are kept.

Let S be an arbitrary finite, well-sorted native monomorphic constraint
presentation, defined explicitly in section 3. Structural descriptions are
finite between free coordinates; bounds may have cycles through coordinates.
Let P be any finite list of actual occurrence-qualified Value parent/copy
pairs. Each pair's extrusion occurrence, polarity, target level and original
Value origin/receiver are retained. Those Value endpoints qualify in the
approved source-reference SCC graph; constraints, bounds and Function ports
are not edges of that graph. Qualification is an input certificate to this
lemma, not derived by this algebra.

Let `~` be exactly the equivalence relation generated by P, and let
`q: IV -> IV/~` be its surjective class map, extended by identity on IE and
Vsrc. An existing representative implementation may replace each abstract
class by one existing row; the abstract class is not an additional allocation.
Fix any interpretation A of the unchanged sorted structural signature and
constraint predicates, as specified in section 3. No solution, provider or
per-pair marginal witness is selected.

**Theorem ALG, independently reviewed:** for every such S, P and A,
quotient solutions are in bijection with old solutions satisfying every pair
equality, via pullback along q. Every unchanged whole observer has identical
value under that bijection. Tagged bound occurrences are preserved. The proof
holds for empty stores, inconsistent stores and cyclic bound stores.

**Conditional bridge Y:** ALG applies to a full Yulang source rule program
only when its actual typed interpretation makes coordinate substitution lawful
inside the unchanged original dependent telescope. Section 6 identifies that
precise missing bridge; it is not assumed established. Full Function membership
is not defined here by its four printed ports.

**Bounded operational characterization:** sections 7–8 identify what actual
insertion, replay, level and generalization consumers must additionally prove.
Neither their correctness nor the required source/principality preservation
follows from ALG. A schedule before publication is discussed conditionally,
without adopting one.

The original parent retains all supported-source and lawful-use quantifiers,
source reachability, complete Call, effect hygiene, soundness, required
principality, normal progress and termination. No annotations, source-domain
restrictions, eager solving, alternative witness selection or semantic
weakening is introduced. Tests, builds, code, shared records, question-board
work, Git operations and delegation were excluded by this packet.

## 3. Source-store and quotient-store meanings

Here “source-store” means the input native constraint presentation, not a new
Yulang source-typing judgment. Its independent interpretation is explicit.

Choose sorts V and E, semantic sets `DV, DE`, and fixed binary relations
`<=V, <=E`. For replay's transitive consequence below these are preorders;
ALG itself does not use transitivity or any Function variance law. A contains
the fixed interpretation of each original constructor, atom and constraint
predicate. In the reference instance DV may be the closed paper types, with
the original subtyping relation, Function and record constructors. Ground
type syntax may contain its original recursive binders; q changes neither
those binders nor their bound occurrences.

For the native four-port signature write

```text
F : V × E × E × V -> V
F(argument, argument_effect, result_effect, result).
```

Preserve positive/negative constructor tags where present. Other constructors
are treated by their own declared argument sorts. An Effect constructor with
Value-valued arguments transports those Value arguments; identity on Effect
coordinates does not mean ignoring nested Value payloads. A primitive with no
coordinate children is unchanged. No effect annotation, guard, handler
authority or source-selected subtraction is added or erased.

An assignment mu is one simultaneous pair of functions
`muV:IV->DV`, `muE:IE->DE`. Interpret coordinate leaves by mu, and each finite
structural description by its original constructor interpretation applied to
the recursively interpreted children. Cyclic *bound incidence* does not
require unfolding the bounds into a structural tree: a coordinate is a leaf
with one assigned value, and each bound is a separate finite formula.

S consists of:

1. Lower and upper lists L_s(a), U_s(a) for each coordinate a of sort s.
   Each bound occurrence retains its own immutable tag j and metadata m_j;
   duplicates with distinct tags remain distinct occurrences.
2. Every other retained live constraint occurrence `j:P_j(t_1,...,t_n;m_j)`.
   Its original predicate interpretation and full metadata are fixed in A.
   This includes pending admitted comparisons when they are part of the
   generated constraint presentation. An in-process key alone is not such a
   semantic assertion or evidence of discharge.
3. A finite collection of designated live observer expressions, including
   constructor returns and interfaces. Observers are not additional constraints.
   If an equality of live payloads is required, it is an explicit formula.

Define mu in Sol_A(S) precisely when

```text
for every (j,l,m) in L_s(a): [[l]]mu <=s mu_s(a),
for every (j,u,m) in U_s(a): mu_s(a) <=s [[u]]mu,
for every other retained j: A(P_j)([[t_1]]mu,...,[[t_n]]mu;m_j).
```

These constraints may be merely accumulated; their denotation does not assert
that the machine has processed them. A tagged witness version retains the
entire original joint witness record for all occurrences; it is available
only where that record's typed interpretation is specified, as in section 6.

Define q on syntax by mapping free Value coordinate leaves, fixing free
Effect leaves and all source/historical labels, and recursively rebuilding
each constructor with the same tag and ordered children. Lexical binders and
their bound variables are alpha-renamed only when needed for ordinary
capture-avoiding substitution; their scope and quantifier order are unchanged.

The quotient store qS has the same constraint-occurrence tags and metadata.
For each Value class k, define its lists by disjoint concatenation:

```text
L'(k) = concat_{a in k} [(j,q(l),m) | (j,l,m) in L_V(a)],
U'(k) = concat_{a in k} [(j,q(u),m) | (j,u,m) in U_V(a)].
```

Effect owners remain the same; every payload in their lists is still mapped
by q. Map all other live formulas and observers by q. Preserve historical
provenance/cache domains separately, with a semantic access map if those
records later return a live type operand. Concatenation order is immaterial
to this denotation, but no operational order-independence is inferred.

Define Sol_A(qS) by the same clauses, assigning one DV element to each class
and one DE element to each original Effect coordinate. Pair equalities mean
literal equality in DV, not identity of provider, source Value, receipt,
attachment, residual recipe or original historical coordinate. No merely
mutual-subtyping relation is silently substituted for this equality.

## 4. Constructive proof of ALG in both directions

### 4.1 Structural evaluation lemma

For any quotient assignment nu define its lift by

```text
muV(a) = nuV(q(a));       muE(e) = nuE(e).
```

For every finite well-sorted structural expression t,

```text
[[q(t)]]nu = [[t]]mu.                                      (1)
```

Proof is induction on actual description syntax. For a Value leaf a the
claim is the definition of muV; for an Effect leaf it is muE=nuE. At an atom
both expressions use the same fixed interpretation. At a constructor
`K(t_1,...,t_n)`, the induction hypotheses identify every ordered child value;
the unchanged interpretation of K applied to those same child values gives
the same result. In particular F keeps all four children, both Effect
children and their order; it is not replaced by a two-port arrow. Finite
shared structural DAGs admit the same induction in dependency order. Bound
cycles are not a case of this induction, since bounds are separate formulas.

For constructors with original internal lexical binders, the same induction
is under each unchanged bound environment; q acts on free coordinates only.
This proves (1) for a binder constructor **when** its original interpretation
already supplies ordinary capture-avoiding substitution. It is not a new law
for an unspecified dependent complete descriptor.

### 4.2 Quotient to old constraints plus equalities

Take nu in Sol_A(qS) and define mu by the lift. For every old lower occurrence
`j:l<=a`, its quotient occurrence lies in `L'(q(a))`. Satisfaction gives
`[[q(l)]]nu <=V nuV(q(a))`; (1) gives `[[l]]mu <=V muV(a)`.
The upper case is identical with the relation reversed. For Effect lists the
owner is unchanged and (1) applies to their whole payloads. Every other
predicate has exactly the same interpreted argument tuple and immutable
metadata, hence the same truth value. Thus mu satisfies every old occurrence.
For each selected pair (a,b), q(a)=q(b), so muV(a)=muV(b) jointly. This direction
does not select a new proof for a transferred lower/upper or residual recipe.

### 4.3 Old equal solutions to quotient

Take one mu in Sol_A(S) satisfying **all** selected pair equalities at once.
Equality propagates along the finite reflexive/symmetric/transitive closure,
so muV is constant on every class. Define

```text
nuV(k) = muV(a), for any a in k;       nuE = muE.
```

This is well defined and needs no search or independent choice of witnesses.
For each quotient lower occurrence retain its old tag j and old owner a.
The old inequality plus (1) proves its quotient inequality at k=q(a).
Every concatenated occurrence has such an old owner; no other occurrences
were inserted into these lists. Apply the dual argument to uppers, the same
argument to Effect lists, and (1) to every other predicate. Therefore nu
satisfies qS. Observer equality follows from (1).

### 4.4 Inverses and exact conclusion

Lifting and descending mu returns mu on every coordinate. Descending and
lifting nu returns nu since q is onto. Hence

```text
Sol_A(qS) ≅ { mu in Sol_A(S) | for all (a,b) in P, muV(a)=muV(b) }.
```

Equivalently qS denotes exactly `S AND Eq(P)`, with historical identities
separate. If that right-hand set is empty, the quotient solution set is empty;
the theorem proves no inhabitedness. All observers are preserved through
these inverse maps. If solution ordering is pointwise in the fixed semantic
preorders, the maps preserve and reflect it: surjectivity of q gives
reflection. Any least solution of the equal-augmented presentation therefore
corresponds to a least quotient solution when such a solution exists.
This is an order statement for those presentations, **not** the compiler's
generalized scheme-principality theorem.

No SCC property is used after P is selected. That is the useful separation:
ALG proves faithful representation of selected equality, whereas source
qualification/preservation determines whether that equality is the right
inference operation. Merging only list owners, ignoring structural children
or choosing marginal per-pair solutions would invalidate the proof.

## 5. Native propagation consequence and its limits

For any quotient class k and actual lower l and upper u, its stored formulas
give `l <= k <= u`; transitivity proves `l <= u`. Thus replay of that same
joint pair adds a semantic consequence, preserving the solution set of qS.
This proves the validity of the **comparison to be replayed**. It proves
neither execution nor completeness of replay.

In a reference Function comparison, the actual owner dispatches reversed
arguments and forward results. In the native four-port dispatch the inspected
code generates, for F0<=F1,

```text
arg1 <= arg0; argEff1 <= argEff0;
resEff0 <= resEff1; res0 <= res1.
```

Transport commutes with this literal dispatch: applying q before or after
forming those four child formulas gives the same four sorted formulas.
Both effect-coordinate leaves remain unchanged. This finite syntactic fact
does not assert that complete contextual Function inclusion is equivalent to
the four scalar child comparisons. Complete checking instead uses original
whole challenge and observation maps; their interpretation bridge is separate.

Reference ordinary insertion actively loops over the owner's opposite side.
Reference extrusion and freshening directly assign some lists. Yulang merge
transfers sides and explicitly replays lowers against the merged upper side.
These bodies are real owners to inspect for coverage, but storage or the mere
presence of that loop is not a proof of all current/future activation paths.

## 7. Additional operational, lexical-level and generalization conditions

The following are obligations, not new adopted invariants or proved hypotheses.

1. **Source activation and all semantic consumers.** Actual source constructors
   must retain the approved source-reference graph and actual occurrence/pairs,
   apply precisely those equalities, and make every live type read denote q.
   Include suspended Lambda parameters and App results, contexts, pending
   returned demands, structural descriptions, cached semantic levels and
   future memo returns. The fixed census already shows that context rewriting
   alone misses immutable `Lam.param`. A raw historical key stays separate.

2. **Complete replay coverage.** For every resulting class, each
   `L'(k) × U'(k)` comparison must be processed or retained as a live owned
   obligation before any dependent publication. This includes cross-member
   products created by equality, same-member pending products, direct/bulk
   copy initialization, both ordinary insertion sides and later canonical
   insertions. All four Function children and full contextual residual
   consumers keep their original lineage. Pending work cannot be marked
   complete merely because its class-normalized key matches another admitted
   task. Fairness/termination and invalidation of prior dependent completion
   remain required; they are not proved by finite initial storage.

3. **Actual lexical-level invariant.** Semantic descriptions supplied to native
   level tests must use current class levels and actual current children;
   historical raw levels can remain historical. Every active bound must have
   permissible level/scope at its owner. A minimum-level representative alone
   does not prove this: a class with a level-2 lower containing an unrelated
   level-2 coordinate can acquire a level-1 member, leaving a level-2 payload
   under a level-1 owner. Source qualification/closure, legitimate extrusion
   or another proved native level operation must handle that possibility.
   Lowering unrelated coordinates without a scope proof is not supplied here.

4. **Original generalized eligibility.** At every original boundary h, the
   quotient's shared/generic decision must agree with the source's fixed
   dependency closure and ordinary Desc eligibility. A class crossing h
   cannot be justified merely by taking its minimum level. One semantic class
   is copied once per independent use when legitimately generic and remains
   one shared capture when nongeneric; aliases share a use, different uses
   retain the original partition. Existing independent use maps and published
   snapshots must receive lawful transport/invalidation if equality occurs
   after they have been constructed. Equality supplies no new publication
   boundary and does not move a source binder.

5. **Principal and source closure.** Even with solution-faithful replay and
   level-safe generalization, prove the source generation/checking and scheme
   abstraction/instantiation correspondence, and qualified joint preservation
   from section 6. These must preserve all required original source typings
   and the governing scheme order. The equal-augmented store's solution
   bijection alone is insufficient for the source's principal interface.

Conditions 1–4 are necessary responsibilities for the proposed native handoff;
they are not asserted to be a proved jointly sufficient implementation
contract. In particular an implementation's extrusion operation may change
the raw presentation before publication, and needs its own lawful source and
generalization theorem. This note chooses no storage or SCC schedule.

## 8. Level discriminator, source motif and the publication schedule

The primary supplied a complementary discriminator: B at level 2, C at
level 1, native positive-extrusion link `U(B)=[C]`, qualified B=C, and a
boundary-1 scheme with body B. In the raw store, `freshenAbove(1,B)` creates
one B_i per use and keeps C. In a quotient-normalized store whose class has

quotient-first freshening do not commute.

```text

```

satisfies both copied upper constraints. If hypothetical client constraints
pin these two uses to those distinct types, quotient-first demands the one

distinction of generalized presentations, not a counterexample to ALG: ALG
never identified fresh B_1 and B_2 by the original pre-use q. That new use
relation would have to be established by the generalization bridge. These
client equalities are not claimed to be emitted by an actual source program.

The occurrence motif itself has a resolved original-Simple-sub source route:

```text

  let rec g = f g
  in g
in f
```

Keep original roots F,G and formal x. By approved definition-root ownership,
F's body Name g gives F->G; G's initializer gives G->F and G->G. Therefore
F,G share the approved Value SCC. Native inference allocates outer root o
and formal A at level 1; inner recursive root e and inner App result R at

`o <: Function(e,R)`; negative extrusion to 1 makes the actual pairs
`(C,e,+,1)` and `(D,R,-,1)`, giving `U(e)=[C]`, `L(R)=[D]`. Under the approved
call-demand origin law this actual occurrence has origin G and receiver F,
so those pairs qualify. This is a native source constructor derivation,
not a Y3 admission or complete Call proof.

The bare B/C model is nevertheless not the complete subsequent source store.
With stock inference before adding intrusion, recursive completion compares
R<:e and stores e in U(R). Replaying R's lower D compares D<:e. Because
e.level=2>D.level=1, native negative extrusion produces another row H at 1,
adds H to L(e), and gives H the upper C; D<:H is then stored in U(D).
Thus g is published with body e at boundary 1, but also with the newly
retained lower H and upper C. The outer Name use, outer completion and
further replays add more constraints. This derivation establishes a source
route for the cross-boundary **motif and raw generic body**, not for the
minimal whole-store/client-pinning counterexample. Qualification/ownership of
that secondary propagation extrusion is not selected or assumed here.

The missing counterexample premise is an actual supported source/client
derivation supplying the two distinguishing independent pins while satisfying
all those additional constraints and complete Call/scoping laws. No such
derivation is supplied by the simple term above. In particular use of a
generalized value as Int or Bool typically contributes an upper checking
constraint; it does not itself force equality to that primitive. Equating
the illustrative pins with ordinary source checking would be unsound.

A source-graph computation and qualified intrusion completed before the first
scheme publication would ensure this particular scheme never publishes raw

live consumers and pending work are correct, subsequent fresheners see that
shared class. This eliminates the stale-generalized-view schedule error.
It **does not** show that changing raw generic eligibility preserves all
required source typings, nor that the compiler actually has the early graph
and schedule. A later equality needs lawful treatment of already allocated
use frames. Neither schedule is adopted by this artifact.
