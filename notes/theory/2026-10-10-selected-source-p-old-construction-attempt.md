## 5. Minimal owner interface needed for the next construction

The next useful evidence is an authentic **registry representation
certificate**, at original source formation, with three separable obligations:

1. **Entries and lookup:** map each actual original registration/catalogue
   occurrence into its actual original typed key/payload; prove original
   lookup and complete decoder equalities, retaining original absence,
   alias/sharing, scopes and dependent payload alternatives.
2. **Exhaustive domain:** eliminate every original registry entry into an
   actual formation/catalogue occurrence or a declared old import with its
   whole contract. Conversely retain every required original formation entry.
   This is about entries, not enumeration of semantic witnesses.
3. **Consumer closure:** at each exposed old use retain a complete declared
   interface manifest and its actual dependency/reference projections,
   including any active registry parameter/guard/domain/operation, authority,
   provider/output and future fields. An opaque family can be one complete
   atomic interface; hidden required fields cannot be guessed from endpoints.

Given these laws, finite indexing of `F_form` is straightforward: retain actual
keys with original typed equality/sharing, store the complete payload fibers,
and use the representation certificate to translate index elimination to
original lookup/inversion. Traverse the finite declared reference graph for
consumer closure, retaining dependent family schemas without unrolling event
histories. The certificate's exhaustive domain supplies completeness; the
finite traversal alone does not. This is a conditional construction recipe,
not a proof of the three missing laws.

Whether these are implementation evidence omitted from the notes or require a
new original registry definition is unresolved in this bounded source cone.
Choosing a new exhaustive old-key scheme, rebinding an old active registry
parameter, or declaring an old consumer's dependency manifest exhaustive
without its owner would make a new durable choice. Work stops before that
choice. The proposed interface is a request for owner evidence, not an adopted
