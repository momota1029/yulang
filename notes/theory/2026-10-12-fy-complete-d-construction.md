There are two precise ways to check the failed inference within this bounded
dependency set.

1. **Required-child inversion.** The intended final node is complete Function

   or an actual local challenge constructor. Entry-Value and IF are formation
   constructors, not these domain constructors. Identity has no authentic
   complete A_f/F_c equality input. Composition has no semantic middle proof.
   No supplied record gives an independently typed domain conjunction, an
   original carrier structural action to I_x, or a registered local challenge
   constructor with that action. A further constructor is allowed only after
   independent establishment/adoption with its full premises. Treating the
   displayed D inclusion as a leaf is explicitly forbidden by §3.2. Thus no
   such node is instantiated by these children. This is nonderivability from
   this supplied child inventory, not nonderivability from every possible
   future authentic proof.

2. **Logical projection of the proposed origin-only rule.** For a fixed formal
   complete challenge variable d, project its existing fields to propositions
   q = checked carrier admission, p = actual I_x carrier admission, and retain
   the original static constructor records as formation propositions. The
   selected projected formation rules constrain their scopes/ports/incidences;
   they contain no implication q -> p. Checked challenge assembly uses q, not
   p. Actual challenge assembly, if A_f is identified with the corresponding
   Strict construction, uses p as an input, not as a formation output. The
   valuation with all the formation propositions and q true, and p false,
   therefore satisfies those projected constructor implications while
   falsifying the proposed conclusion. Generic complete Function checking
   does not repair it: its genuine domain-proof input is unavailable, so its
   corresponding implication has a false antecedent.

The second argument is expressly a counterinterpretation of the
**formation-only logical projection**. It uses the formal universally
quantified challenge variable; it asserts no actual source event, carrier,
accepted program or runtime witness satisfying that valuation. It neither
redefines I_x/F_c nor proves that such a valuation extends to their full
independently fixed semantics. It proves the exact limited claim that the
port/origin implications proposed as the proof contain no entailment of p.
Authentic semantic domain actions would add the absent premise, and this
argument makes no claim against such actions. No source-qualified
