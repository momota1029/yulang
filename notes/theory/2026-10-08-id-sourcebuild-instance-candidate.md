## 2. Concrete source record package before Generalize

### 2.1 Formation, description and anchors

The Parameter owner produces, before any challenge:

```text
d_a = Desc(C_id,q,ValueEndpoint,sigma_a,Delta_a): a
intr_q = Intrinsic(q, source-slot, Value-entry mode, designated one-layer port,
                  original receipt/receiver/formal paths, annotation absence)
I_a = ValueInletSchema(q,a;Delta)
Description(C_id,q) -> I_a and every incident original constraint
```

There is exactly one fresh ordinary value description a, occurring in the
formal, body payload and outward payload positions. `Delta_a` and the complete
schema Delta are the actual already introduced incident operands; import-free
does not mean that intrinsic port/scope/guarantee incidences are empty. No
additional flexible I, effect or profile binder is added. Any other incident
operand remains at its owning introduction; H-source excludes a free fixed
contract dependency on a, rather than deleting Delta.

At ell the selected generic constructor produces one fixed raw closure U_g:

```text
raw(U_g) = (r, actual Pure role, ordinary Value-entry program, q,
            body operation Result(Name(n,q)), empty captures, IF0)
CarrierContract(U_g) = GenericValueInlet(q,IF0)
Internal(C_id,r) -> (I_a, full body/result description, all original clauses)
```

IF0 is the finite original role/entry/consumer, port, receipt/receiver,
formal-rebind, invocation-return, scope/lifetime and joint `nu,K,D` registration
package. Pure is the actual role for this selected projection, rather than a
property inferred from Value entry or a solved Function term. The generic
inlet stores the fixed sum constructor and IF0; its presentation index binds
the independently formed description internally. It stores no free I[a]
contract. This is the exact reason fixing U_g does not fix a.

For an inert unevaluated definition, the base anchor is this actual source
closure/delay registration and its empty fixed capture environment, as source
construction §3 specifies. If the actual binding event returns/installs that
inert closure, its `Executed(b,arm,tuple)`/`OneShot(b,field)` records retain
that one actual returned U_g and complete world/evidence tuple; its separate
description edge remains Internal, by §3.3. This is a distinction between two
allowed anchor formations, **not** an assumption that the compiler executes
the initializer. Publication must identify which actual formation occurred.
No initializer invokes x, and no type frame repeats either formation.

There are no `Mono`, `Established`, prior `Published`/`Family` instantiations,
recursive `Live`, or simultaneous recursive `MemberEntry` records introduced
by this source. There is no forced need to fabricate a Shared witness: if the
authentic initializer/world formation introduces one, its actual `Shared`
binder/telescope remains once in the base. Logical closure evidence uses its
actual ViewLogic/EventProof owner; the notation below does not allocate an
arbitrary additional witness or claim their count from source spelling.

### 2.2 Binder tree and actual invocation fields

`T_id` is a finite source-rule schema tree/graph with registered development
references, rather than a finite enumeration of all histories:

```text
base: original initial-world/registration/initializer anchors and binders
  sigma_a: ordinary Parameter description a, with Delta_a dependencies
    description region: authentic Lambda/inlet/checking proof binders, if any
      independent initial challenge h at the complete I_a/IF0 ports
        actual receipt/frame event
          designated Force at this event and carrier port
            T_I prefix or Request/response/raw-resumption developments
            completed Return: current W, (v,p_v), V(a,v,p_v), formal rebind
              Name(n,q); body Result of that same decorated value/provider
                invocation return at IF0's original outward port
                  hereditary future demands at that returned provider/port
```

The type scope sigma_a precedes h; its description cannot depend on an entry
value chosen under h. The registered receipt and actual receipt token are
different fields. Until a completed carrier Return, no formal value, body
value or outward result exists. Request branches keep the same receipt and
unfinished rebind/body/return suffix; raw resume uses its actual current world.
A divergent Force has only its finite prefixes. Future development retains
the outward result incidence and checks the returned provider's own contract.

At each authentic later event owner retain `Event(e,parent,Delta_e)` and its
`EventField` telescope (actual receipt, response/raw handle, current world,
returned value/provider, rebind and pending suffix as introduced). Description
proofs under that event use `EventProof(C_id,e,k,sigma_k,Delta_k)` and share
the same runtime fields. No actual invocation need happen at publication;
these are the latent source-owned event schema and original rules. A concrete
future event supplies its actual operands, not a guessed publication-time
receipt. ViewLogic precedes its challenges in the description region; any
Shared introduction stays in the base. The actual source owners decide every
such region and telescope; this nesting does not replace missing owner laws.

### 2.3 Retained relation N and final root R

`N_id` is `Build(S_id,T_id)` under source construction §4, with the local
Parameter, Lambda, Name, Result and complete invocation rule nodes. In this
case its explicit incidences include:

- Parameter declares a and the complete I_a/Delta/Intrinsic schema.
- Lambda retains U_g, GenericValueInlet and IF0 separately from its Internal
  I_a/body/result description.
- At any prechosen complete frame presentation kappa at a, actual admission
  injects that very independently checked inlet witness gamma as
  `PackGeneric(kappa,gamma)`; it does not assert invocation safety.
- The designated Force eliminates the same frame's complete carrier
  certificate. Return supplies its actual W and hereditary V(a) witness;
  Request supplies its independently typed operation, response/raw handle and
  continuation obligations. All carrier alternatives stay present.
- Formal rebind installs exactly that returned decorated `(v,p_v)` in the
  current W. Name n resolves q and restricts that existing certificate.
  Body Result returns the same `(v,p_v)` and certificate at its original
  incidence, without latent execution. Invocation return preserves that same
  body result and projects the world by the actual IF0 action.
- Every original guard, binder, future obligation, pending suffix and local
  evidence clause stays incident to this one joint tuple. An actual initializer
  choice, if present, is fixed once; no executed branch is reopened per frame.

These are instances of named selected local rule clauses, not new opaque
`SafeID` or successful-query atoms. The full clauses include the independent
carrier/context/world laws; the equality incidence alone is not N_id. There
is no primitive literal in this definition. Ground and external carrier
primitive premises can enter later independently typed challenges and must
then have genuine L1 evidence.

`R_id` is the final **complete source synthesis root** of this Lambda, with
its entire descriptor membership, admission, I_a/IF0 ports, body/invocation
distinction and residual. No boundary annotation or common formation exists
in this source. Source construction §5's FinalRoot rule therefore selects
the synthesis root. The symbolic body payload and outward payload both refer
to a; their complete computation/interface ports need not be equal.
Neither a printed `a -> a` nor the independently formed public VP descriptor
is substituted for R_id. The selected transformed public export is a later,
separately justified operation; this internal note supplies no public consumer.

## 3. Exact Generalize derivation and local-law inputs

Seed fix with U_g/raw registration, Intrinsic/IF0 operational fields, actual

the original logical/event binders without promoting them to templates.
Thus d_a is reachable, owned by C_id, and unmarked by fix. The selected §5.1
walk yields precisely:

```text

anchors_id = complete fixed/base package above, with original shared binders
G_id = ScopedClosure(p_id,C_id,T_id,anchors_id,templates_id,N_id,R_id)
```

There is no second body/output template, because those occurrences reference
d_a. This is a conditional application of the already established source
construction, rather than a new eligibility theorem from compiler rows.
If a genuine fixed contract instead has a free dependency on a, rule 2 fixes
d_a and the one-template conclusion fails. Omitting that edge would invalidate
H-source; generalization must retain it.

For a future source `new(p_id,i,r)`, §5.2 opens this **whole** N_id frame and
gives d_a its `(i,q)` declaration at translated sigma_a. Alias/reuse keeps the

are keyed by their original owner/parent/occurrence, while EventProof also has
the description-frame key. This does not run the initializer or create a raw
provider per i. It is a source allocation derivation, not evidence that any
current incoming solver route performs that operation.

## 6. Independence, discriminators and stopping condition

The semantic instance shares the selected source constructor laws and L1–L5
with the existing theorem. The production crosswalk reads the two actual
owner files and checks their retained fields independently of a fabricated
transition table. Thus it is bounded construction evidence, not independent
validation of those laws, mathematical review, or an oracle run. A checker
fed N_id's transition assumptions would not prove that ordinary HIR builds
N_id. No executable experiment or mutation ran; no seeds/ranges apply.

Discriminators for a later separately authorized retained-record experiment:

- Give a a dependency on the argument witness under h: sigma_a must reject
  that dependency rather than freshen a after receipt.
- Replace the raw generic inlet with a fixed free I[a] contract: the fix walk
  must then fix a. Keeping a eligible falsifies the bridge.
- Omit receipt/Force and certify Body from its pure effect bound: the original
  Name proof must have no formal binding until completed carrier Return.
- Add a completed outward result before the corresponding body return, or
  replay receipt on a raw resume: original event incidence rejects the record.
- Keep the type endpoint shared while change the returned decorated provider:
  the actual Name/Result clause fails even if a -> a row constraints still hold.
- Copy OneShot/Shared per new frame or merge EventProof with runtime EventField:
  the original base/event/frame keys fail the selected allocation rule.

These are specified failure conditions, not executed counterexamples. A useful
experiment must compare genuine source-owner output/certificates with the
retained artifact, rather than compare two walkers sharing the same supplied
edge table. No third identity-row/Q/R probe is recommended: it leaves the
identified inlet/event/scope premise untouched. The missing retention is
reconstruction debt at source formation; identification with complete entry
behavior and sound publication remains a real correctness obligation.
