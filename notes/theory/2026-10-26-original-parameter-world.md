## 2. Selecting a contract before invocation

`Coordinate` stores the original declaration, source introduction route and
formal descriptor endpoint. Equal Site tokens do not identify distinct
introductions. `repeated_sites_separate_coordinates` and
`distinct_declarations_separate_coordinates` prove the two independent
discriminators.

`FormalAssignment` takes a Parameter, its containing route and all
`ScopeValues` at that Parameter's explicit prior scope. It returns a descriptor
for Value entry or an interface for Computation entry. It contains no
membership certificate. `select` applies this assignment before the actual
invocation. The later native constructor consumes that selected contract; it
does not infer a convenient descriptor from the returned value or from a
successful check.

The first stage does not yet derive the semantic payload-to-formal comparison
`B <= A`. It records the fixed formal `A` and exact returned value/root. An
ordinary completed-Meaning checking proof and a hole-relative checking proof
are different consumers. The former cannot silently be used for `B_H`.

## 5. The computed native/decoder consumer

`nativeEvidence` computes the allocated address as `world.cells.size`, installs
the previously selected formal descriptor, and preserves the actual raw
value/root projections. `deliverFrame` calls the original decoder on that
same `Retained.frame`. The installed map is proved equal to the one-cell
extension of the old installed map, and the original entire fixed-frame prefix
is retained with this one frame appended.

The key equality is `delivered_native_bind_readout`. Its input representation
invariant is:

```text
state.installed = bindingReadout assignment world.cells
```

Its output is the complete installed map of the original decoder equated with
the readout of the actual `bindValue` result. The output equality is proved,
not supplied as a commutation hypothesis.

The proof uses the actual finite vector representation to establish that the
fresh allocator address was empty. The derived address/view contract assignment
is updated at that address to the already selected formal descriptor. This
changes a total assignment function, but `fresh_contract_before_readout`
proves that it does not change the readout of the old cells. Every previous
`Some` remains present. The semantic installed quantifier is not replaced by
an `index < count` filter, and no missing owner lookup causes an occupied cell
to disappear.

`source_assigned_native_delivery` combines the actual source assignment,
computed raw Return key, one owned witness selection, generated delivery,
original decoder and native allocation. It specializes the native key to
`parameter.formal.name`. Its conclusions include the complete post-bind
readout equality, the new formal binding at the actual address, and preservation
of every prior installed entry. `source_formal_native_lookup` proves lookup
and shadowing at that same key. `source_formal_saved_capture` preserves lookup
through any old saved environment, including a nonlatest one.

That capture specialization proves preservation of the resolved **address**.
It does not yet prove equality of the complete captured-value readout after
`installValueContract` changes the derived assignment. The old address is the
necessary native incidence; a complete capture consumer must also combine
freshness, the old occupied cell and the unchanged contract at that old
address. An inherited theorem with an unchanged assignment does not alone
establish this additional result.

The pre-state representation invariant is a genuine induction invariant. This
stage does not construct its initial case or a complete fixed native world
presentation. It never resets or re-roots an existing Environment to make the
invariant true. `deliver_existing_environment` extends the actual old
Environment in place through the accepted `decode_extend` theorem.

The main theorem consumes the Shared frame at `RawKey.erasedPath`. It does
not first execute the Return frame through `Decoded.runtime`, derive the
complete key from an actual invocation/Force development, or identify the
pre-state representation invariant with that raw history. It is the local
source-data/native-bind/Shared-decoder constructor, not yet an actual Return
and world induction step.

These native equations concern the plain bind substep after any actual entry
preprocessing. The complete Rust `Frame::ValueEntry` can alter the incoming
view or receiving state through a callback, and record/unit pattern branches
have different operations. Their receipt/callback/pattern/body correspondence
is not inferred from the bind theorem. The accepted native model retains the
current receiving/control/rest and selected-parent dispatch for this plain
bind. It also preserves all older environments and their raw capture-address
lookups, with the changed-assignment capture-readout boundary stated above.
