## 3. Dependent interfaces, declaration insertion and use

### 3.1 The interface that an independently typed contract already exposes

A typed original declaration `alpha` has its actual ordinary parameter telescope
`P_alpha` and whole-tuple/evidence telescope `T_alpha`. A telescope is an ordered
list of dependent fields under the original binders, not a set of observations.
Fields include every coordinate its complete contract exposes: provider/root,
actual role/entry where present, whole carrier, current world, request and
response, raw handle and continuation, result, introduced provider, latent/future
interface, hard constraints and original license evidence. Fields may be indexed
families; infinite worlds or future-use indices require no finite enumeration.
An opaque predicate with a complete interface can retain that interface while
its predicate remains opaque.

Write the independently interpreted judgment as

```text
P_alpha |- w : Prim_alpha(h,y;xi)
```

with its independently specified projections into `T_alpha`. An original
license is one of those evidence projections or a judgment proved by that
primitive's independent typing contract; it is not a row-name convention.
This representation assumes no map to any source use. An interface field for
an introduced provider is dependent on the **actual output of this arm**, for
example

```text
p_new : Provider(A_new; original scope/world dependencies)
J_new : OriginalLatentInterface(p_new)
future_contract : OriginalFutureRelation(p_new,J_new; original use/current indices)
license_new : OriginalProviderLicense(alpha,origin_new,p_new,J_new)
```

where the displayed types are schematic names for the existing judgments, not
new permission rules. The future field denotes the original interaction relation
and its admitted-use/response schema, not a total function producing a returning
execution for every future argument. If the primitive does not introduce a provider there is
no such field. If it exposes a family, retain the entire dependent family.
A request/continuation has the corresponding original response/current-state
indices, not a continuation at the pre-request state.

Missing original primitive licensing cannot be generated by a telescope. A
predicate declaring an unlicensed operation allowed is not converted into an
independently typed primitive by this notation. Complete C0 or the original
primitive typing lemma must discharge that genuine semantic obligation.

In particular, if a W/Z clause changes a provider/continuation/capture coordinate
that is live in admission, its complete original contract must supply the actual
domain/admission certificate at that changed interface. Positive membership
closure alone does not prove this. The primitive may preserve admission by its
original law, or supply independently justified changed admission; the frame
retains whichever original law is actually declared. No new certificate follows
from slot insertion or equal descriptor sorts.

### 3.2 Interfaces of relation clauses: explicit finite grammar

Define a dependent interface `IF(q)` at the **formation of a clause**, by the
following recursion. The notation `in_l`, `in_r`, `in_operand`, etc. denotes a
new contextual occurrence with its source formation derivation. It does not
identify repeated uses of the same root. All context slots retain their origin.

| Actual clause constructor | Constructed dependent interface |
| --- | --- |
| `Prim(alpha,m)` | `T_alpha[m]`, retaining the actual declaration reference and ordinary typed parameter instantiation `m` |
| `Union(q1,q2)` | Both contextual operand slots, their full interfaces, the original result interface and tagged alternative-to-result clauses |
| `Conj(q1,q2)` | Both contextual operand slots and the one original shared whole tuple; their result maps refer to that same tuple |
| `Bind(x,q1,q2)` | First interface, dependent result/rebind slot for its actual value and current configuration, second interface under that binding, ordered result and pending-suffix interface |
| `Delay(q)` | Inert carrier slot, the whole q interface as its latent interface, and the original capture/dependency tuple |
| `Call(qf,t,dispatch,ret,arms)` | The full frame in §4, including all arms of the actual original declaration |
| `Return(d)` / designated consumer / producer | Original data/provider interface and selected result/consumer/phase slots, as detailed in §5 |
| `Scope(b,q)` | The original binder at its original position and q's whole interface under b |
| `Rename(m,q)` | q's whole interface under the same original legal substitution m |
| `Ref(t,m)` | A contextual slot for the registered root's entire declared interface instantiated by m; no body unfolding |

Every row uses its original result and hard constraints. For example, Union
retains each original branch-to-result relation, not equality of the branch
worlds; Bind retains its original relational image, not a support-row union.
Slots for unreached regions are part of a suspended interface, not executed
observations. Negative or universal primitive predicates can remain inside a
primitive; this grammar does not replace them by positive source execution.

A root registration initially exposes the **declared interface telescope** of
that root. This is already needed for independently typed recursive references;
it is not a proved membership or coverage fact. Construct its clauses using
the grammar above, with references to that registration. At clause insertion

```text

---------------------------------------------------------------- IF-Insert
RootClauseSlot(t,q) carrying IF(q), original clause/result relation,

```

The arrow is a typed contextual incidence: evaluation of its fields at an
original clause witness commutes with the original clause-to-root result
relation. It is not a function sending every possible q tuple into a satisfying
root tuple. The root's original alternative/conjunction rule determines when a
witness enters its result relation. `ins` is inclusion in the root's full
contract **frame**, which retains clause slots as well as result slots.
This distinction prevents a static slot from proving admission or membership.

Here IF(t) is the finite registered **frame graph**: a root node, its original
result telescope and contextual clause/reference slots. Allocating a node does
not require eagerly expanding the interfaces of referenced nodes. References
carry the original dependent instantiation at a registered node; recursive
frame edges remain edges. There is no recursive infinite telescope expansion.

For a primitive at that clause, `ins_(t,q)` composed with its operand-slot

```text

---------------------------------------------------------------- IF-Use

```

`m` is the original scoped operand instantiation, already needed to type that

**Callee pending.** For the original equation


the request/raw handle/response slot stays at the callee coordinate. The

body. When the actual raw continuation develops, use current C', its original

mistaken for receiver membership or placed at the own-upper receiver effect.

evidence, not inserted again. Retained entry has no entry Force; a later
explicit body consumer is placed at that consumer's phase. Native operation
return does not skip its declaration-derived consumer. Actual role/entry,
original boundary protection and annotation permissions remain unchanged.

**Return/future.** The result edge uses the actual returned provider and current
configuration. Future Force/Call uses its original dependent latent interface
and independently admitted use, including every finite future development.
Returning a closure executes neither its body nor its future uses. A returned
provider from an abstract clause uses that clause's actual introduced-provider
and result/future maps, not the structural provider with an equal descriptor.

**Z and opaque alternatives.** Read the original independently typed whole

contract origin; no observation-level source anchor is needed. Fields for new
