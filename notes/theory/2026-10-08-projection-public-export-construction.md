## 2. Source formation is fixed before export

They operate on independently interpreted V/W/T/Car records and the finite

explicit. Body/result ports and proof objects are not identified merely
because the raw returned value/provider is unchanged.

For this source synthesis case, select the independently interpreted ordinary

```text

```

at its original source root r. Echo applies to the completed body/outward

The source root's membership/production meaning is the exhaustive VP grammar

### 2.2 The complete native extra is nonempty

An actual Bool carrier t may return true, while its independently formed
complete pure-Bool contract J also licenses `Return(false)`. Ordinary pure

its membership does not require that t executed that alternative. The complete

This is a concrete Option 2 alternative in the **actual native public root**.
The construction does not set all extras empty or restrict the semantics to
source executions. Independently fixed foreign W/Z/provider-replacement arms
have not been identified with this native exhaustive law and are not changed.

## 3. The public representation and its size

Let Omega be the finite boundary consisting of the actual binding/provider
anchor; fixed outer declarations/contracts and their free dependency closure;
original intrinsic slots/permissions; IF0's role/entry/consumer declarations;
and the original nu,K,D scope/incidence operands. For bare id the capture
part is empty. An anchor is the same operational identity, not an instruction
to inspect its executable definition during type checking.

The public grammar is the following fixed interface grammar:

```text
ProjectionExport(
  display: ForallAt(sigma,a, Arrow(a,result)),
  boundary: Omega,
  inlet: ValueInletSchema(q,a;Delta),
  ordinary: Function(Pure,Value,ValueResult/InvocationReturn),
  result: a | J.value_type,
  dependency: EntryValue | PublicValue(J),
  certificates: ProjectionCertificateSchema(kind, original_slot_map)
)
```

`kind=EntryValue` uses the four ordinary certificate families of CE. `kind`
for PublicValue selects the same fixed import projection instead of the formal
projection. The original_slot_map records **typed certificate slot identities
and their dependency telescopes**, with Shared, ViewLogic, EventField and
EventProof classifications. It contains no source operator or Build node.
The source proof skeleton is replaced by these globally defined local
certificate families. A slot for a finite L derivation retains its entire
chosen proof term and intermediates at use; it is not a source-program handle.

Delta and the boundary's local predicates have their actual finite typed
syntax: equalities, conjunction/union, original-scoped binders, independent
V/W/T/Car and registry/authority/port clauses, and genuine registered local
proof constructors with all operands. An arbitrary predicate that needs the
private Lambda body is not an allowed opaque boundary field. Bare id creates
no such predicate and no Call/Operation/body adapter node to summarize.

### 3.2 Finite bound and why the fields remain

For bare id the added structure is one scoped type template, one ordinary
Function head, one inlet-schema application, one result-dependency tag, a
constant number of phase/certificate-schema references and their finite slot
incidences. Thus its size is

```text
O(1 + |Omega| + |Delta| + |original proof-slot telescope map|).
```

The proof-slot map is finite for the actual source rule schema. Arbitrarily
many intermediate proofs in a future legal client are values of its finite
proof-grammar slots, not pre-enumerated export nodes. Likewise an unbounded
number of finite invocations/resumptions does not create an execution table
inside the export. Type instantiation copies only the eligible declaration
images and frame-owned proof slots; fixed boundary nodes are shared.

The retained fields have concrete uses. Whole I/IF is necessary to check
pre-receipt admission, Force effects and all later guards. The result tag
states the actual projection dependency. Proof slots preserve W distinguishing
identity from a composed proof. Fixed imports preserve the actual captured
provider and all its free fields. The
[reviewed countermodels](2026-10-08-projection-export-proof-countermodels.md)
show why scalar input types and canonical proof objects cannot replace these
whole records. This is a sufficient finite representation, not a claim of a
unique or globally minimal encoding.

## 4. Construct it from Generalize and allocate its actual root

### 4.1 Concrete extraction algorithm

Input is `Generalize_source(S,b)` for the source formed in §2. SRC inversion
exposes its original Parameter/Lambda/Name/Result rules. The following finite
constructor operates at publication, where consulting that source is allowed:

1. Read the source-selected final root. For the unannotated definition in
   question, it is the complete synthesis root r of §2. If an actual final
   annotation/conversion/common formation selected another root, this case
   does not silently substitute the interior Lambda root for it.
2. Run the existing fixed-dependency result, not a new eligibility heuristic.
   Uniform-inlet §7 proves a is the sole ordinary eligible declaration of bare
   id; the fixed raw inlet contains no free a. Retain all actual fixed fields.
3. Read the owning slot/evidence records. Match the authentic formal read and
   the original pure result consumer, and expand their native witness records
   by CE. This is rule inversion, not a successful Q or shape-based guess.
4. Substitute only the forced raw value/provider aliases. Keep all worlds,
   ports, independent evidence choices, local proof terms and their original
   typed telescopes. Any exposed alias is represented by its explicit graph;
   all predicates and W occurrences on a private eliminated alias receive the
   same total substitution.
5. Replace the four local source-rule positions by the global ordinary
   certificate-schema references and the finite original_slot_map. Retain
   every genuine local check as its L proof-term slot. The only body data left
   are EntryValue and those original semantic operands.
6. Install the finite public grammar of §3 with its one template. Discard the
   source body graph, its eliminated aliases and all source-root accessors
   from the exported object. No retained field can dereference that graph.

Termination is by the four owning projection positions plus finite original
record/constraint maps. There is no source execution search. The parameter
walk and CE are concrete previously proved algorithms/equalities, not an
assumed whole-export relation used as an input.

### 4.2 Actual ordinary decode and root equations

### 4.3 Exact source/public fiber construction

## 6. A defined ordinary Direct consumer at u

### 6.1 Proof-directed native rule and actual acceptance

This section supplies a native **ordinary proof-certificate consumer**. It
is separate from proof search and the legacy production F5 implementation.
Its grammar is the independently established local checking grammar L of SRC
§3.2 and the native witness constructors; its rules inspect complete ordinary
interfaces, not source expressions. Each registered local rule has its full
scoped signature and independently proved semantic law. There is no arbitrary
true-inclusion, successful-source-query or whole-source leaf.

For submitted actual ordinary roots u,V, the consumer performs these finite
steps. Its dispatch is by the original **checking proof constructor**, not by
assuming that every view of a callable has a Function target:

1. Retrieve both actual ordinary root records and their complete registered
   interpretations, typed operands and scope maps. Validate each record at
   its own head. A target Any is an ordinary value descriptor; it is not
   required to have Function role/entry/consumer or invocation equations. A
   certificate naming a different record, including r in place of u, fails.
2. Check the appropriate finite local proof form against those readouts:

   - **Value(d_V):** a complete same-decorated-value membership implication
     `MemValue_u(v,p,e,xi) => MemValue_V(v,p,e,xi)`, with its original guards,
     hereditary fields and full input/output/intermediate evidence tuple.
     Identity/composition, Top, union/intersection and record rules use this
     ordinary case. They preserve the same runtime value/provider.
   - **Computation(d_T):** the genuine same-computation/carrier inclusion at
     the original designated computation interfaces, including every required
     demand, observation, provider and dependent evidence field. It uses the
     actual local computation rules and does not exchange Value/Computation
     tags from a solved latent shape.
   - **Function(d_D,d_P):** for the complete Function checking constructor,
     validate both actual role/entry/consumer/interface records and check
     `d_D : D_V(h) => D_u(h)` together with
     `d_P : D_V(h) and Complete_u(h,O,w) => Complete_V(h,O,w)`.
     These are the specialized complete invocation premises, not equations
     imposed on non-Function targets.

   A structural proof can contain a complete Function inclusion as a logical
   premise; it retains that finite proof tree. It does not compose previously
   successful concrete Function queries. An executed conversion is not one
   of these proof-only cases: it retains its original executed constructor
   and resulting handle at the source boundary.
3. Check term constructors bottom-up against L's declared scopes/operands and
   all premise subtrees. Identity and composition concern logical implications
   on the same whole tuple. Conjunction/union rules retain whole alternatives.
   Total substitutions require the actual equality proof. Structural children
   retain their value/provider/effect obligations. Nonpositive children need
   their actual equality/domain proof. Original binder congruence keeps its
   telescope. Registered recursive equation pairing covers every alternative
   using the actual independently justified equation rule; an arbitrary cycle
   is not accepted as an inclusion proof.
4. If these checks finish, construct the ordinary query certificate
   `Direct(u,V;Value(d_V))`, `Direct(u,V;Computation(d_T))`, or
   `Direct(u,V;Function(d_D,d_P))`. These are defined native consumer cases
   actually available at u. The Function notation below abbreviates its
   wrapper. No case calls a source-root resolver.

Checking a finite registered proof grammar means checking its local node
signatures and the genuine registered equation rule once, with all references
bound to their original scopes. It is not an oracle for arbitrary recursive
semantic truth. Any independent local primitive/capture law used in d remains
that rule's full typed premise, exactly as it was in source checking. Unknown
local laws do not acquire certificates by registration of a bare name.

The rule above closes **native certificate recognition** by construction:
structural checking of an already valid finite term returns that certificate.
No H7 assumption that a missing resolver somehow accepts it is used. It makes
no claim that the current F5 search route emits or consumes this new syntax.
The small reference script is explicitly a stricter, conditional same-I
fragment of this consumer, not an implementation of every L rule.

Construct the public client grammar and finite allocation as follows:

| Original client rule | Constructed public rule and evidence |

**Theorem PE-ID.** For the native id formed in §2, the constructed finite
ProjectionExport is sound and complete for every finite independent source-
