## Objective and result

Test whether original overlap compatibility, root-local lawful actions and
target import validity suffice for a root extension that recovers the old
external certificate by restriction. They do not in general. A two-valued
**shared witness**, with unchanged provider identities, gives a countermodel
to that implication. Both target local predicates remain valid, while their
restrictions to the shared incidence disagree. Existentially selecting a new
external certificate repairs validity but loses the required old certificate.

This does not falsify an interface that already requires a lawful action on
the complete joint dependent tuple. Such an action must transport overlap
compatibility too. The exact distinction is between separate clause actions
and an action respecting their common incidence. The candidate one-root
signature survives with that distinction made explicit; its independently
justified root-introduction last rule remains unproved.

No actual approved Yulang import/filling pair is exhibited. The finite
countermodel does not satisfy the stronger premise of joint open overlap
compatible with every independently licensed filling. It discriminates an
attempt to infer that premise from anchored overlap and local validity.
The two-valued witness is mathematical data, not a proposed Yulang carrier,
State meaning, authority token or semantic rule.

## Exact conditional interface and overlap derivation

Fix original B/X/xi, scopes and current C0. Let E be a supplied external
certificate, I^H an independent open semantic import certificate, and O their
actual common dependency/incidence telescope. Metanotation

```text
p_E : E -> O       p_I : I^H -> O
c : p_E(e) = p_I(i)
```

means restrictions to the **same** recorded provider/reference/configuration
and its dependent witnesses. These are projections of existing operands,
not new runtime fields. At dependent fibers the equality includes the
specified transports into the same target telescope; equality of printed
labels or an unsorted witness value is insufficient.

For an independently licensed substitution theta, assume root-local actions
A_E and A_I produce valid certificates at their transported incidences and
are identified with the fixed selected local meanings. This is already
stronger than the generic renamed relation image. The remaining local
overlap obligation is exactly

```text
c_theta : p_E_theta(A_E(e)) = p_I_theta(A_I(i)).          (O_theta)
```

A sufficient way to derive it is a common overlap action A_O with laws

```text
p_E_theta A_E = A_O p_E
p_I_theta A_I = A_O p_I.                                 (N)
```

**Conditional derivation.** Apply A_O to c, then use the two equations (N)
at these original certificates. This gives O_theta. This elementary
derivation is valid under the displayed action/equality hypotheses. For one
extension, O_theta itself suffices for this overlap obligation; global
naturality for every certificate is stronger. No globally minimal semantic
axiom basis is claimed.

Even O_theta does not introduce EnvStore/JointWF. A separate independently
justified last rule must consume the actual external base, actual open import
and local introduction data, and compatible overlap, and construct W_plus
with every added obligation and

```text
restrict_old(W_plus) = A_E(e).
```

For rigid old coordinates A_E is identity there. Hole-dependent old
incidences/witnesses move only under their licensed joint dependence; provider
rigidity does not imply that every incident witness is rigid. The restriction
must recover those transported **original** certificates, not freshly chosen
certificates satisfying the same predicates. Nothing in this derivation
assumes W_plus, actual checked-hole membership or Q.

## Smallest structural witness for the missing implication

Use one original external root and one added imported root, with distinct
fixed provider identities. They share one witness coordinate o in {0,1}.
Let h in {0,1} be an abstract filling index, not a callable membership fact.
Both holes remain part of the formal schema; H_a and every other coordinate
are inert in this witness. Define the supplied finite mathematical families:

```text
E = {0,1};              external validity: either certificate is valid
I_h = {h};             import validity: i = h
p_E(e) = e;            p_I(i) = i
Joint_h(e,i) iff e = i, with i in I_h.
```

An open import section i(h)=h exists without a source body. This section
alone supplies no jointly compatible open external certificate. At anchor
h=0, choose the actual original external certificate e=0 and import i=0;
their original overlap holds. For target filling h=1 let the root-local
actions be

```text
A_E(e) = e             retains the supplied external certificate
A_I(i) = 1             changes the dependent import witness with h.
```

Both target predicates hold: 0 is in E and 1 is in I_1. Yet O_theta requires
0=1, so no joint extension can restrict to that retained external certificate.
All root IDs, provider roles, hypothetical interfaces and C0 labels can
remain unchanged. The failure occurs solely in the dependent overlap;
there is no accidental provider coincidence or identity-replacement map.

A target joint world does exist: (e',i')=(1,1). Its old projection is e'=1,
which differs from original e=0. Thus pointwise target validity or an
existential target-world witness does not prove the required restriction
equation. Choosing it would replace an original witness, rather than
transporting that witness by the specified A_E.

This is a complete countermodel to the **finite structural implication**

```text
anchored overlap + valid separate target actions
  => compatible overlap with retained old certificate.
```

It is not a complete interpretation of the source clauses. Minimality is
relative to equality-based overlap: two certificates restricting to one
shared coordinate and two distinguishable values suffice. A singleton
coordinate cannot disagree; removing either restriction or permitting
retupling removes this obstruction. No minimum Yulang source size is claimed.

The stronger premise of an already joint open overlap certificate, equipped
with its lawful whole action, excludes this model. In that reading theta
above is locally licensed but not licensed on the full joint tuple. This
is the precise blocker to using the model as a Yulang-admissible witness:
the approved domain demands joint compatibility, and no approved independent
import contract licenses these separate actions as one joint filling.
The result cannot justify rejecting a natural source program or narrowing
the domain. A coherent mutation transports the shared external witness to
1 too, under an independently justified dependency action; the target overlap
then holds and old restriction recovers the transported certificate.

## Zero-step introduction and what survives

The obstruction uses no execution or changed configuration. The overlap must
hold before invoking the added root. A proof that preserves it only after a
source transition cannot provide initial root introduction. Nor can zero-step
coverage of a formed Call produce that root/world certificate: I0 requires
the independently valid initial package before P.CallInitial introduces its
observation. Zero local steps can occur at a nonempty history and later C0.

Selected Lemma W survives unchanged. It restricts a supplied joint certificate
and installs independently supplied rebind evidence; it does not claim that
two separately valid imports become joint. The selected positive immutable
two-closure theorem also survives in its actual full-operator/background
scope. It is not a license for this arbitrary semantic import. An appropriate
joint extension theorem may solve the gate; this note does not construct it.

The candidate signature therefore survives **conditionally** with O_theta
or a justified common overlap action, fixed-meaning identification and the
independent root-extension last rule. What fails is deriving those joint
properties from anchored overlap, independently valid leaves or existence
of some completed target world. The unsolved semantic premise is still
the actual independent importer constructor and its whole dependent action.
