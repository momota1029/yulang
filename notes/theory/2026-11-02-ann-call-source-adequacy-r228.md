## 4. Why original Function membership and the checker do not fill the gap

The fixed definitions in `OriginalSourceInterpretation.lean:420–438` retain

```text
FunctionAt(inputs,Z,row) =
  (exists actual provider) and
  for every actual provider U of the same row.value,row.root:
    FunctionGuards(row,U).Valid and capturedFields(row,U).Holds Z and
    for every original Challenge d of row:
      CheckedDomain(inputs,d) ->
        ActualAdm(inputs,U,d) and
        for every raw o: execute(U,d.input,o) ->
          checkedObservation(d,o).Holds Z.

PhiV(inputs,Z,row) =
  original value-form branch (FunctionAt in the function case) and
  for every independently compatible later event e:
    Z(value(row.atEvent(e))).
```

`FunctionGuards.Valid` includes **formation, roleAndEntry, profile, scope and
incidence**. `ActualAdm` includes the same whole carrier at the provider's
actual inlet, plus the original receipt-precondition, actual typed path and
actual context. `CheckedDomain` independently requires event coherence,
punctured context, other values, registered holes, incidences and checked
whole-carrier acceptance. None is supplied by `int -> int` syntax.
`PhiCar` separately retains all demanded Force observations and hereditary
carrier membership; `PhiT` retains its actual world, guards, returned-value
membership when present, and positive observation fields when unfinished too.

These are the preserved equations, not assumptions of membership in this
packet. No actual provider, captured-field certificate or Function membership
has been derived from the annotation. The checked source theorem
`function_challenge` has the type, with all indices retained:

```text

(form : inputs.valueForm row.descriptor = .function)
(valid : Meaning inputs (.value row)) (U : s.Provider)
(actual : inputs.actual row.value row.root U)
(d : Challenge row) (admitted : CheckedDomain inputs d)
```

Its membership and admitted-domain premises prevent using it to create the
missing annotated profile or actual source interpretation. Likewise
