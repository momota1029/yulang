# Original literal Call emission extension — bounded decision candidate

Date: 2026-10-10
Status: Draft; non-authoritative, no implementation authority
Scope: `Application_N` direct formal-Name / integer-literal case `f 1`
Claim class: proposed source-emission constructor and conditional O0 extension
Decision: not selected

## 1. Problem and exact boundary

The user selected the complete Call contract for `f 1` and rejected making the
four-port projection its success criterion. The approved
[Original-ResultLiteral](../theory/2026-10-09-original-literal-result-owner-extension-candidate.md)
decision supplies original literal `Data` and `Result`-port formation at the
actual argument occurrence. The selected `Application_N` constructor supplies
a fresh complete source record, but does not identify that record with original
emitted-Call membership.

The inspected original `Gen-Call-0` source constructor is specifically
Name/Name: it requires `u_x -> d_x`, the source Name occurrence and its
`ReturnImage(Name(d_x), environment)`. The actual `f 1` child is an integer
literal. The approved literal Result case creates no Name binding. Substituting
the literal for `u_x`, or relabeling `NewEmission_N` as an original record,
does not supply the missing introduction derivation.

This candidate addresses only the static source-emission seam. It does not
choose a satisfying Function description, successful argument check,
admission, execution receipt, solve result, generalized scheme, public export,
or production implementation. Emission must remain possible when generated
obligations are inconsistent.

## 2. Governing decisions and interfaces

- The selected complete-Call contract requires preserving the actual role,
  entry, protection, admission, operation/result contract, provenance and
  evidence through any implementation path.
- `Application_N` q1/d1 selects its fresh bounded Name/Int constructor and
  permits dependent proof work, without proving historical original-family
  correspondence.
- `original-literal-result-owner` q1/d1 selects only the bounded original
  literal Data/Result formation and registration. It explicitly leaves
  emitted-Application membership and later inference gates open.
- The original Call definition and selected O0/O1 apply to actual emitted
  records; they do not assert that every source Application already has such a
  record. O0 cannot manufacture the missing emission record downstream.
- `Application_N` §9 leaves two routes: adopt a literal case in the original
  emission family, or construct a typed dependent map into an independently
  fixed original family.

See [the constructor comparison](../progress/2026-10-09-literal-call-original-record-map-attempt.md)
for the bounded failed map attempt. It is not an impossibility proof for every
possible fixed original family.

## 3. Proposed bounded literal emission case

Candidate direction: add a tagged literal-origin constructor alongside the
unchanged old Name/Name emission case. Its source-owned derivation starts from
the actual resolved source Call `c = Apply(u_f, a)` and selected original
literal Result certificate. The proposed complete dependent package at one
original telescope and tuple must contain:

```text
u_f -> d_f; Gamma(d_f) = Value(A_f)
a : IntegerLiteral(k); ArgumentChild(c,a)
q_a : Data_orig(T_c, literal(a,k), Value(Int))
o_a : PortReg_orig(a, ResultOfLiteral, Comp(empty,Int), Delta_c, xi, ...)
q_res : Code_orig(T_c, result(literal(a,k)), Comp(empty,Int))
R_f, beta=(d_f,R_f), F_c : complete Function demand at R_f
actual original registration and same-root route
u_c : distinct upper checking occurrence, with its actual source incidence
typed callee-check, argument-Reify/Delay, WholeArgCompatible and
  complete result/operation predicate origins at their actual dependent indices
rho_c, p0=(beta,call.effect), p_out(c), ElimOrigin(c,...)
sourceOrigin = the complete tagged literal Call derivation
```

This is a proposed emission constructor, not a check constructor: its static
predicate occurrences are formed before their truth is solved. Every listed
field needs a typed producer in the eventual construction; none may be supplied
as an opaque premise that already assumes the desired emitted membership. The
construction must distinguish formed predicate origins from satisfying
evidence witnesses. It must retain every declared alternative and independent
WholeContract field, whole-tuple actions, original source scopes and origins,
and the literal coordinate. It may not identify a printed `Comp(empty,Int)`
endpoint with the complete literal Return image or derive evidence from
endpoint equality.

The selected O0 theorem cannot be claimed automatically for this new case.
The closure obligation is first to define an emitted-family/O0 interface that
produces every listed origin from the actual source constructor, then show the
new record's complete Function demand yields the selected immediate invocation
position and typed output correspondence. Preserve the literal source origin
in `sourceOrigin`, the distinct `u_c`, and the elimination leg at `p_out(c)`.
The extension must leave every old Name/Name O0 result exactly unchanged. O1
does not follow from supplying more fields: its existing source-input domain is
the original Gen-Call-0 case. A future O1 extension or typed realization for
the new tagged case, using genuine original `Reg`, `Route`, and independently
certified `SeedExposure`, is separate. This constructor does not invent that
seed.

## 4. Alternatives for the scoped decision

### Option A — select the bounded original literal emission extension

Select this bounded **definition direction** for the stated `Application_N`
Name/Int seam, keeping the old Name/Name family unchanged. This authorizes the
next construction gate to define the exact tagged emission judgment and
construct its sources, old-family conservation and O0 extension. It does not
declare that constructor/O0 object already complete or admit any new emitted
membership now. Adoption requires the exact artifact, independent review, and
a recorded explicit user approval. This choice does not authorize kernel
equivalence, O1, C0, complete admission, solving, public export, compiler
implementation or F5 cutover.

### Option B — require correspondence to a separately fixed original family

Do not pursue adding a literal constructor to the original emitted family.
Continue this route only if an actual independently fixed original literal
emission rule is located and a full typed map is constructed, retaining its
identity, dependent domains, witness fibers, actions and consumers. This
preserves that fixed family exactly; the original O0 route remains unavailable
until the map exists. `Application_N` source construction may continue
independently.

Neither option changes the already selected complete Call contract. Option A
adds a source-emission case; it does not replace any whole predicate or
consumer with native Gamma or a scalar endpoint approximation.

## 5. Required construction and review gates

Before either adoption or implementation, the exact artifact must state and
prove:

1. Introduction and inversion for the literal emission record at the same
   source occurrence, parent/child incidence, scope, telescope and `xi`.
2. An exact old-family inclusion/retraction, with no overwrite or quotient of
   Name/Name records.
3. Identity/composition and compatibility of each allowed whole dependent
   action across the literal source record and all original contracts.
4. An owning producer for the distinct upper occurrence `u_c`, its actual
   source incidence, complete call demand, role/protection origins, argument
   check, operation alternatives, output-dependent result suffix and actual
   provider entry, without assuming successful comparison.
5. A local O0 result for the new emitted case and exact unchanged O0 behavior
   for every member of the entire imported old family.
6. O1 remains outside this gate unless its source-input domain is separately
   extended or a typed realization into that domain is proved. It requires
   actual independent `SeedExposure`; no seed is inferred from unannotated
   spelling or literal typing.

Require an M2 `compiler_referee` review for dependent constructor ownership,
old-family conservation and O0 soundness, plus a `spec_auditor` review for the
approved q1/d1 scope and exact O0/O1 boundaries. Before adoption, both reviews
must close without blocking/major findings, each retained field must have an
actual producer, and explicit user approval of the exact reviewed scope must be
recorded. No performance review or test run is needed for this research-only
decision candidate.

## 6. Explicit non-claims

This proposal does not establish that every source Call is emitted, that
`WholeArgCompatible` or another independent kernel is decidable, that any
contract witness exists, or that a complete solution for `f 1` exists. It does
not complete `realizeResult_N`, primitive/Return kernel correspondence, O1,
C0, contribution/joint coverage, admission, solving, generalization,
principality, public-root installation or an executable compiler path. No
existing source is declared ill-typed because its constructor is missing.

It does not license a new implementation gate. If selected, the emission case
is still a design/proof gate; production representation, failure/resource
behavior, publication atomicity and focused checks require their own reviewed
implementation decision.
