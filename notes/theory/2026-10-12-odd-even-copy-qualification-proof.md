## 2. Actual source rules and the original root SCC

Definition publication assigns each resolved Name in the definition's owned
initializer/body to its root, excluding a nested declaration's initializer.
The final `even(n - 1)` therefore supplies `O → E` and `O → A`. E's own
initializer supplies `E → O` and `E → B`; repeated b occurrences give the
same adjacency target B. Consequently O and E have the two length-one paths
`O → E` and `E → O`, independently of the type of subtraction, comparison
or the branch result. They lie in a nontrivial SCC of the original row graph
across the inference-level boundary. Additional environmental references may
enlarge that SCC; this does not assert it is exactly `{O,E}` for the original
source with unspecified declarations.

For the inner `odd(b-1)` Apply result R and the final `even(a-1)` result S,
the approved Apply rule supplies `R → O` and `S → E`. If the genuine elaboration
of the arguments leaves their b/a Name occurrences inside the applicable
callee/argument subtrees, recursive membership also supplies `R → B` and
`S → A`. Its rule traverses nested Apply callee/argument subtrees; it does
not settle membership across an independently introduced wrapper, Lambda,
Block or local-initializer boundary. Any arithmetic Apply row owns exactly
the Names in its actual applicable subtree and targets their original
resolved binders. No invented desugaring or primitive binding is chosen here.

`true` is not silently a Bool literal: the admission audit identifies it as
a Name absent an independently selected syntax/declaration environment.
Minus/comparison operator elaboration and environmental targets are also
unsupplied. Thus the original program's complete adjacency cannot honestly
be enumerated. The displayed O/E paths require none of those missing laws.
The exact current Y3 indentation/If/infix source lacks an end-to-end HIR
route, as recorded by the [admission audit](../progress/2026-10-12-odd-even-source-admission-audit.md).
This limits the implementation correspondence claim; it does not restrict
the source theorem's domain or authorize rewriting its body.

SCC membership is not equality of O and E. Neither is named as the other's
extrusion copy. Definition roots, formal rows, Call results, Lambda/Block
rows, Name occurrence facades and fresh descriptions are separate owners.
The parent operation requires a real retained pair, not any two members of
a source SCC. On canonical vertices a prior independently justified equality
could collapse O/E; the nontrivial assertion here concerns their original
distinct rows and does not assume quotient separation after arbitrary history.

## 3. Native construction producing the exact finite pairs

Use only the established finite structural analogue:

```text
let rec odd = lambda a.
  let even = lambda b. odd b
  in even a
in odd
```

Its Yulang carrier is `my odd n = { my even n = odd(n); even(n) }`.
It isolates two Calls and changes the original computation; it is not a
translation theorem for its Branch/arithmetic or complete Call. Scala
reference `shared/src/main/scala/simplesub/Typer.scala:48–83` provides this
ordinary rule sequence (reference baseline
`9bae772624c23b52a93c1b226157e16898b4d9db`):

1. Allocate recursive o and outer A at level 1. Infer the nested RHS at
   level 2; allocate B there. The internal Name odd returns o monomorphically
   (`:62–67,205–207`). Its App allocates fresh R at level 2 and generates
   `o <: Function(B,R)` (`:68–72`).
2. The level guard rejects direct insertion of this level-2 demand on o.
   Negative extrusion to level 1 reverses the argument polarity and preserves
   the result polarity (`:115–126,134–156`). One polar memo creates C for
   `(B,+)` and D for `(R,-)`. It appends C to `U(B)` and D to `L(R)`, copying
   B's initially empty lower list and R's initially empty upper list. C/D
   are distinct fresh rows, not roots O/E. Insert `Function(C,D)` into `U(o)`.
   Empty `L(o)` means no opposite-bound replay at that first cut.
3. E's initializer type is `Function(B,R)`; its publication boundary is 1.
   The outer even use coherently freshens B/R to B'/R' at level 1, keeping
   C/D shared (`:166–188,201–202`): `U(B')=[C]`, `L(R')=[D]`.
4. The outer Call generates `Function(B',R') <: Function(A,S)`, giving
   `A <: B'` and `R' <: S`. Inserting S into `U(R')` actually replays its
   lower D and generates `D <: S` (`:106–108,115–117`).
5. Recursive completion inserts `Function(A,S)` into `L(o)` and replays
   its existing `Function(C,D)` upper demand, producing `C <: A` and
   `S <: D` (`:52,118–120`). These same-level comparisons do not extrude.

This yields the finite store of the earlier derivation, before final outer
scheme use. Scala has no operation equating distinct variables here;
its `lhs is rhs` check (`:93`) only recognizes existing identity. The bound
cycles `C → A → B' → C` and `D → S → D` are not source incidences.
The bound facts establish neither `B → C` nor `R → D` in the selected graph.

On the inspected Rust carrier, source Name occurrence U receives the active
O root on its lower side. Inner Apply retains U/B/R and all effects, builds
the negative four-port demand, inserts it on U's upper side and replays O
against it. Structural extrusion then retains exactly `(C,B,+,1)` and
`(D,R,-,1)`. The source/native owner crosswalk is in §6. This is a conditional
constructor trace, not a run of the carrier. Source root E is an independent
publication owner; Scala's nonrecursive let has a Function scheme body, not
an extra Variable named E. The source E row must not be recovered by
identifying it with R or an arbitrary Scala variable.

For the unchanged original source, genuine argument inference yields T for
`b-1`, with `level(T) ≤ 2`. Fresh R still forces the negative result copy
D at level 1, even when T is ground and existing bounds are nonempty.
Argument copies, if any, are copies of the actual wrong-level variables in
T and its selected bounds, in the same memo. The earlier arbitrary-store
derivation supplies this result; it does not imply a `(C,B)` pair for the
literal source or discharge the branch/Call consumers.

## 5. Canonical classes, independent copy owners and the exact OPEN premise

Let q be the **already established**, pre-proposed-equality canonical map at
a cut. Let K be the set `{q(v): v is an original resolved binder row}` in the
source under consideration. Let `G_Name` contain definition/Apply Name edges
and any independently assigned copied-row incidences that obey the approved
unchanged-binder target rule. Its edges all have targets in K.

**Conditional codomain lemma.** For every row c with `q(c) ∉ K`, its canonical
vertex has indegree zero in `q(G_Name)`. Hence, for any p with `q(p) ≠ q(c)`,
there is no path `q(p) →* q(c)`, so that pair does not qualify.

Proof: an incoming edge would have target q(c), but every edge target is in
K. A path between distinct vertices must have a last edge, so cannot end
there. This proof does not require c's outgoing incidence to be empty.
In particular, allowing a genuine independent owner to assign `C → B`,
`D → O`, or `D → E` while retaining those original binder targets cannot
by itself make either pair strongly connected. It adds no incoming path.

In the Scala finite history, q is identity: there are no distinct-row
equalities. C/D are fresh nonbinder rows, so the lemma applies. In the
inspected source allocation for the carrier, O/E/A/B are registered by
definition/Lambda/formal owners before these copies are allocated; none of
the displayed source actions binds one of those four Names to C or D.
No already-authorized owner in this traced carrier assigns C/D as one of
these original resolved binder rows. Source Generalize's per-frame description
allocation does not perform that assignment: raw providers and Shared fields
stay fixed, and fresh descriptions do not retarget the graph's Name incidences.

Within the closed rule subset there is also a noncircular induction: start
with the finite identity map, introduce each copy as a singleton outside K,
and retain only unchanged-binder-target incidences. Until an independently
justified extra equality or copy-to-binder installation occurs, no distinct
copy has an incoming path, so the selected intrusion rule cannot be the
first operation to destroy that separation. This does not justify prior
mergers made by the implementation's bound-derived graph.

The unrestricted inference-history conclusion needs two additional facts,
which are **not** silently hypotheses of the source theorem:

1. **Incidence coverage:** every applicable source constructor's actual
   Value-reference edges have been accounted for, or at least none supplies
   an edge into the canonical C/D class from another vertex. If some non-Name
   owner can target a copy, its original source rule and actual input/output
   row identities must be supplied. The selected graph clarification does
   not assert that every actual Value reference is a Name incidence.
2. **Canonical separation:** the actual prior justified equality history and
   source binder-to-row installation show `q(C),q(D) ∉ K` at the cut. Raw
   allocation freshness proves this only at creation, not after arbitrary
   later mergers. If a copy's class already contains a binder, a Name edge
   targeting that original binder can end at the copy's canonical class
   without retargeting the recorded raw edge. If `q(copy)=q(parent)`, it is
   already equal; that is not a new distinct-pair qualification proof.

Thus complete-graph nonqualification follows if the owning constructions
establish these facts. Conversely, a qualifying **distinct canonical** pair
must exhibit an actual path into the copy class: either an independently
licensed non-Name incidence supplies its last edge, or a prior justified
equality/installation places an original binder target in that class. It
must also exhibit a reverse path to the actual parent class. For `(D,R)`,
raw R itself is an Apply result rather than a resolved binder in this
carrier; when its class is also outside K, a Name-only graph cannot even
end a nontrivial reverse path at R. Both endpoint paths then require the
appropriate missing incidence/equality bridge.

These are necessary operational witnesses, not proposed new source rules.
An independent copy owner producing only outgoing unchanged-target Name
incidences is insufficient. Do not ask for inheritance again, invent an
edge to C/D from `B <: C`/`D <: R`, or use the equality under examination
to establish its own antecedent. The original parent gate remains OPEN.
