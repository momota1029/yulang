## 1. Objective and result

For exactly

```text
my apply f = { my step x = f x; step }
```

ask whether the outer formal endpoint `A_f`, captured Name endpoint, and
inner checked Function view `F_c` can borrow one complete Function descriptor.
The smallest justified construction retains one source-owned **relation
package** with separate endpoint projections and actual reference routes.
It preserves every existing whole solution by construction. It does not
entail literal `A_f = F_c`.

A stronger shared-descriptor construction would remove the non-hole
comparison action from outer-apply RT.2: at one actual event, identical full
Function clauses have the same one-step readout at every background. Section 5
proves this precise conditional result. The missing premise is a source
generation/principality proof permitting that descriptor identity, including
the original dependent decorations. No selected source rule currently
supplies it. This note therefore proposes no adopted alias rule and no new
mandatory annotation or admission restriction.

## 3. Lossless relation package: the construction available now

Take any original typed completion of the exact symbolic source graph. This
is a hypothesis, not a proof that a completion exists. Its formal interface
is the entire incoming `I_f` with result endpoint `A_f`; its inner Call has
the entire `F_c,D_c,P_c,IF_c`, original same-value inclusion obligation and
whole-argument checking. Retain their actual generating relation `R_src`.

Construct the dependent package

```text
C_f = (registration at b_f, Delta, X, xi,
       I_f with formal result A_f,
       captured/reference occurrences and actual maps,
       F_c with D_c, P_c and complete dependent interface,
       original R_src and comparison/checking evidence obligations,
       full origin partition, source policy and independent inherited packets).
```

This is one source-owned complete contract **package**. Its Function field
is complete; the package is not a new Function descriptor equating its two
endpoints. Allocate it once at the relevant source component, before Q, and
retain these actual constructor placements:

| Port | Retained object and route |
| --- | --- |
| Outer formal | `I_f`'s original result projection at `b_f`, under its original binder. |
| Step capture | The resolved outer binding's whole reference/capture package at the actual closure capture occurrence. |
| Inner Name f | That same capture/binding reference, under its lawful current-event restriction and actual Name-result injection. |
| Inner checking view | The original `F_c` projection of `R_src`, placed at `u_c` by the actual Call operand/receiver frame. |

Use SIG's actual operand/reference/root injections on every field. Retain
`j_use = J_use o use o j_decl` and its original whole substitution, rather
than choosing a destination by endpoint equality. Keep the original owner
partition on captures and reads; the receiving Call position is separate.
The Name result has the original `A_f` relationship, not a fresh captured
endpoint inferred independently. Returning step retains this package as
latent data; it invokes neither step nor f.

**Lemma Retain (conditional on an original typed completion).** This package
and its references preserve every original whole solution and every principal
solution under any already fixed original observable projection/preorder.

**Proof.** Extend an original solution with the displayed dependent record
whose fields are its original fields, and with the actual constructor maps.
Every newly retained field is a projection or a total definition, not an
additional constraint. Erase the package by reading those original fields.
The composites return exactly the original whole solution and its constructed
record, up to dependent record equality. In particular no old coordinate,
port fiber, primitive witness or original comparison obligation is removed.
Thus the extensions and erasures are inverse and leave the already fixed
observable projection unchanged. Any original solution ordering therefore
has the same principal elements under this correspondence. QED.

This proves preservation by retention only. It constructs no `VIncl`,
membership, solution, designated export, Generalize eligibility or new
endpoint equality. It cannot turn a relative `A_f` field into an `F_c`
readout. Borrowing a shared package is not borrowing the same predicate.

The unannotated provisional Handler seed is retained at its original inferred
formal/use component. Ordinary-value evidence from x remains the scoped
refinement obligation. Neither is replaced by an actual Pure-role declaration
for supplied f. Source-owned no-annotation protection and its no-removal policy
follow their licensed governed-field projections; independent provider lower
occurrences keep their original packets. Packaging cannot identify these
policies by a coincident endpoint or source slot.

## 4. Stronger shared-descriptor candidate and exact preservation obligation

A candidate source constructor could instead register one complete Function
schema `F_star` and reference it from both views:

```text
A_f = Ref(F_star,m_formal)
F_c = Ref(F_star,m_check)
R_c = ReadInvoke(F_c,D_c,IF_c).
```

Both substitutions must be actual source-derived maps of the entire original
dependent telescope. Capture and use occurrences remain distinct; one schema
does not mean one owner/receiver incidence or one profile witness. Retain all
actual roles, entry/consumer and provider alternatives, complete independent
domains, output-dependent future schemas, primitive/Option 2 arms and guards.
Do not infer `F_star` from successful Q or from an actual provider chosen later.

There are two different meanings of equality:

1. If both references instantiate precisely the same complete semantic schema
   at the same joint event/index, and contextual placements are retained as
   separate port records, their Function readout clauses can literally be
   identical. Identity of that common descriptor proves identity action.
2. If the descriptors themselves include differing contextual incidences,
   scopes, profiles or dependent maps, the indexed records are not literally
   equal. Their common referent is insufficient. One needs the actual lawful
   whole transport, including semantic guard and field actions. A SIG frame
   injection constructs placement, not this semantic action. A scope move must
   preserve original dependency placement and keep exited activations exited.

For the second case the precise extra law is, at each actual inner event and
same joint tuple, a derived action

```text
t_e[Z] : Phi(Z).V(A_f,v,r,e) -> Phi(Z).V(F_c,v,r,e)
```

on every whole readout, for the backgrounds in the outer proof. Its origin
must be an actual reference/restriction constructor with semantic laws, not
final-model inclusion. A whole renaming that yields `g_*Z` is not automatically
an action at the unchanged `Z`; prove the relevant background/restriction
correspondence before using it. No such general transport is proved here.

**Unproved obligation Alias-Principal.** Establish a source-derived complete
constructor for the exact unannotated source such that replacing the separate
formal/check endpoint relation with these common references preserves and
reflects its principal observable solutions at the original designated export,
with all original jointly scoped witnesses and independent contracts. Show
that every original principal solution has a matching common-reference
completion, and that each candidate principal solution maps back with the
same observable principal relation. Endpoint representation changes alone
do not justify dropping original witness alternatives.

Retain is not Alias-Principal: adding a record leaves `A_f <: F_c` intact;
substituting one endpoint for both adds equality. FVIEW §2 demands sharing of
the source relation and §5.4 demands the principality proof. Neither selects
equality, a variance-based widening rule, or elimination of this inequality.
The complete source-generating and scoped role-refinement judgments remain
open. The current baseline therefore does not prove this stronger constructor
or its preservation of all principal solutions. No Generalize choice is
assumed to resolve that gap.

**Smallest separating local witness.** A shared relation can retain two
complete Function contracts with identical independent challenge domain and
provider/phase/guard fields but result predicates `C` and `D` with `C` properly
contained in `D`. At one distinguishing result tuple, D holds and C does not;
all other full-domain fields may coincide. `A` requiring C and `F` requiring D
then support proper final inclusion, rather than equality, in an independently
interpreted model with the corresponding callable realizations. A callable
returning that tuple satisfies F's result field and fails A's. This requires
one differing result field and one differing tuple; no finite subset replaces
the independent challenge domain.

This is a logical witness that sharing plus inclusion does not entail complete
descriptor equality. It is not an admitted Yulang source counterexample, a
principal-scheme counterexample, or a claim that this exact source forces the
proper pair. Establishing either pair as a full source completion requires the
missing generation rules. It differs from the comparison candidate's
arbitrary-background countermodel: here the final result predicates differ;
the question is validity of merging source endpoints, not deriving arbitrary-Z
action from equal final-model predicates.

## 5. Conditional non-hole RT.2 derivation

Use exactly the selected positive operator and outer theorem's auxiliaries:

```text
M    = nu Phi
B_as = nu (Z -> Phi(Z) with V augmented by H_a union H_s).
```

`H_a` contains only the exact declared apply value tuples at its native
descriptor with original incidences/lawful restrictions. `H_s` similarly
contains the exact local step tuples. No world, carrier, continuation, guard
or authority is a hole. Independent challenge/history/guard domains remain
unchanged parameters of Phi.

**Lemma Shared-NonHole.** At any actual inner-use event assume:

1. The outer carrier's actual Return and lawful capture/restriction yield
   `q=(A_f,v_f,r_f,e)` in `B_as.V`, at that same original use tuple. This
   retains all fields required by RT.1/RT.3; no ordinary M membership is assumed.
2. `q` is outside `H_a union H_s` as a complete indexed tuple. Alternatively,
   independent constructor evidence already supplies its non-hole A_f readout.
3. The candidate common reference gives literal identity of the complete
   A_f/F_c Function clause at this event, or the genuine whole action `t_e`
   in §4 is supplied independently at `Z=B_as`.

Then `Phi(B_as).V(F_c,v_f,r_f,e)` supplies the complete non-hole RT.2 readout
for this event.

**Proof.** Unfold the greatest fixed point:

```text
B_as.V = Phi(B_as).V union H_a union H_s.
```

For q outside the holes, elimination of this union supplies
`Phi(B_as).V(A_f,v_f,r_f,e)`. An independent non-hole constructor proof
supplies the same field in the alternative case. Literal clause identity
rewrites this whole readout to F_c; otherwise apply the original action
`t_e[B_as]`. The selected Function clause already contains every actual
decomposition, captures, complete independent challenge, ActualAdm,
observation/development/future field and hard guard. Consequently the result
is the full Function readout, not merely a provider or output endpoint. QED.

This proof uses fixed-point unfolding and identity/action at the actual
event. It applies no ordinary `VIncl` to a relative assumption. It preserves
the original `nu,K,D`, whole carrier and dependent maps. Applying it uniformly
requires hypotheses 1–3 at **every** admitted Return and every later use.
The conditional lemma does not independently supply that uniform coverage.

Tuple identity, not the spelling or runtime identity of f, determines a
hole. In particular a returned value equal to apply but checked at a different
complete descriptor is not automatically an H_a member. Conversely original
lawful hole restrictions must be included when determining tuple equality;
moving the reference cannot evade an actual hole. No hole case is removed
from the independent challenge domain.

If `v_f=apply` and the actual descriptor/root/incidences coincide with an H_a
tuple, unfolding may return only the H_a assumption. Identity yields that
same assumption, not a `Phi` front. The exact apply/apply demand still needs
a genuine simultaneous postfixed source construction. An H_s coincidence
likewise needs its own constructed front. Source syntax contains no recursive
call to apply, but the approved counterfactual open context domain cannot be
reduced to syntactic clients on that basis.

The lemma supplies only RT.2's non-hole part **if** the shared-descriptor
constructor or transport is justified. RT.1 whole-background interpretation,
RT.3 guards/checking/primitive laws, all admitted carrier effects/divergence,
raw resumptions, future restrictions and Option 2 arm contracts remain.
Other result descriptors, foreign interpretation bridges, complete C0/KV,
general recursion/State, production source acceptance/conformance and full
inference principality remain unverified. OuterNat is not closed.
