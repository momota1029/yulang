## 3. Derivation to the first unsupplied judgment

Hypotheses: one ordinary unannotated, nonrecursive definition `my id x = x`,
outside callback position; no capture, adapter or explicit computation
parameter; admitted lexical/typed entry/result paths; the supplied primitive
transport laws and one original `xi=(nu,K,D)`.

Typed core §6 derives, in order:

```text
P = Value(A)
Gamma_body(x) = Value(A) after entry rebind
Synth(name x) = Value(A)
Result(Value(A)) = Comp(empty,A)
closure body/result skeleton = Fun(Value(A),Comp(empty,A)).
```

The lexical lookup proves that this body occurrence refers to the rebound
formal. This is stronger than observing two occurrences of the spelling `A`.
It does not establish a semantic provider identity rule for arbitrary arrow
members or for a decoded result. Such a rule needs an independently supplied
meaning; no parametricity/free theorem is imported for `forall q`.

Typed core §9 expands the source call within its actual activation:

```text
receipt;
Force_argument(t) >>= (a,current_state);
typed RebindResultPath(t,a,current_state);
result(a) >>= ReturnFromInvocation.
```

Under the hypotheses this returns the rebound value and transports its latent
interface without another force. The fixed decoder conventions agree with
these source choices. They therefore remove the predecessor's opportunity to
attack an unspecified entry choice. The argument carrier's effects and
divergence still belong to the complete invocation image; `Comp(empty,A)` is
the body result, not a pure-call guarantee.

Now let `r_u` be the actual descriptor constructed from one fresh use of
`Sigma_id`. Source-contracts §2.2 requires the complete predicate

```text
M_u(h,O,w;xi) and DescMem(r_u,O,w;xi).
```

The source call derivation supplies the source-base relation operands. The
dispatch's Pure/Value/Value-result conventions supply tags. Neither states
the constructor introduction rule for the second conjunct. In particular,
no rule here has this conclusion:

```text
source-base return at original typed ports
    ==> DescMem(Dec(rho_u(Sigma_id)),O,w;xi).
```

This is the **smallest missing supplier located by this method**: the decoded
ordinary descriptor's actual clauses and local constructor lemma, with its
typed operands and scopes. It is not a claim that a concrete zero-history
execution fails. No independent admitted runtime witness has been supplied
against a failing decoded clause, so there is no minimized bad program.
Deleting future calls, operations, recursion and captures from the obligation
still leaves this conjunct. Deleting it changes the selected complete-bound
contract rather than minimizing a counterexample.

The conditional result is only the existing source-core derivation above. A
uniform decoder can discharge this leaf once it supplies a legal formation
rule and proves its constructor lemma. Defining `DescMem` to equal the source
image, retaining a hidden source root, or asserting that matching `q` means
the same provider does not discharge it.
