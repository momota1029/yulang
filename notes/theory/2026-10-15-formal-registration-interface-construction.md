## 1. Frozen statement and method

For every formal registration on the source path relevant to the original
all-admitted shallow Catch theorem, preserve its original declaration `d_f`,
parameter endpoint `A_f`, binder context `Delta_f`, lexical/capture references
and all original shared indices `B,X,xi=(nu,K,D)`. Construct, before IF-Use
and Apply elaboration, an authentic declared dependent interface `T_f` and
one original inferred-contract reference `R_f` at that registration. Each
actual reference must instantiate that same interface by its one original
scoped substitution. Interpretation of all fields, alternatives and evidence
of a use must be the restriction of the same component `sigma`.

This is the bounded registration premise of the parent claim. The parent's
quantifiers still include every originally admitted shallow Catch, original
scrutinee/formal/arm binders, actual providers, complete Call/future interfaces,
raw resumptions and distinct residual lineages. No subdomain is selected here.

Local hypotheses used for the native prefix: successful authentic LocalSource
formation/resolution, successful candidate source collection and session
initialization, and the unchanged source constructors at the assigned code
baseline. They imply neither full source admission nor semantic satisfaction.
The unknown formal remains a symbolic Value endpoint; it need not already be
callable or have a solved type. A later Function use may generate constraints.

Method: forward construction from HIR formal through recipe, native row and
Name route; then attempt the declared-interface and registered-reference
introductions demanded by the selected original construction. Inspect the
suppliers of those introductions rather than assuming `T_f` or `R_f`.
