### What this projection does and does not contain

For Value entry, the original complete invocation includes the designated
argument Force, rebind and body. A suspended entry Request retains that same
ordered suffix. For retained entry, no entry Force is invented; body consumers
stay where the source puts them. For an operation provider, native
Return(MakeRequestThunk) precedes the declaration-derived result consumer
inside the complete executing view. Its Request and response suffix are
covered at p_call. Stopping at native body return would omit them.

At each compatible resumed event, membership uses the actual live state and
the same original provider, response binder and dependencies. The projection
therefore covers every finite pending prefix/development at this invocation
position, including divergent ones. A later returned-alpha invocation has
its **own** effect position; its full latent certificate is retained, rather
than bounding all of its requests by this first invocation's E_R.

Likewise pre-dispatch Observe at an inner executing view is not automatically
outward support. An internal handler can consume an observed event before
this outward projection. Its Inc/Grant/Protected evidence is still in the
complete observation and is not weakened below. The theorem makes no claim
that an outward-support bound classifies all such earlier observations.

## 3. Make the weakened field local; retain imported assumptions identically

At the caller, eliminate the original observation certificate to obtain its
outward support proof at p_call. This yields a **local consequence** of that
same certificate. It does not replace the source environment entry f:F_beta,
change its E_R operand, or create a new provider descriptor.

Use typed-core §8's fixed-Challenges interpretation on this local observation
certificate. Its old and new versions share one original O/d/xi and every
non-support field. The only compared support annotation is the local outward
guarantee at p_call: originally bounded by E_R, subsequently by i, then E1.
An explicit field classification is:

| Field/typed occurrence | Classification and actual preservation |
| --- | --- |
| Imported f, its whole Function descriptor, including its E_R occurrence | A/imported invariant: retain the identical descriptor and certificate. |
| Actual Unit/carrier admission, future argument and raw response interfaces | A: identical original contracts/challenge domain. |
| Alpha, latent returned providers and their future input/output contracts | Retain the identical full original object; no nested support widening. |
| Captures, shared writable views and joint K/D predicates/indices | Invariant: identical tuples, original scopes and assignment. |

| New local annotation bounding S_p_call(O) | G only: an outward guarantee consequence, never a premise for admitting a challenge or selecting a handler. |
| Any other support field, including a field also reachable as an assumption | Identical; no widening is performed there. |

The last but one row is G-only by its **local observation-certificate owner**:
it asserts a consequence for observations already supplied by the original
certificate. No input or routing rule reads that new consequence as admission

This avoids treating a Function imported at an argument as globally covariant.

If E_R aliases E_A, a latent-alpha row or a shared captured row, the original
aliased object remains identical. A support expression used at two typed
positions does not identify those positions. The new local bound uses that
unchanged operand as a premise and a separately indexed guarantee conclusion;
it changes neither the operand's value under nu nor its other incidences.
If the particular proposed changed field itself were an admission, routing
or shared/invariant field, §8 would require equality; that field is outside
the local modification just constructed and is kept identical here.

This argument needs no global enumeration or finite unfolding of arbitrary
alpha. The proof carries its original object by identity. It uses §8's
mathematical preservation argument for one identified guarantee position;
it does not claim an effective general finite classifier for every possible
