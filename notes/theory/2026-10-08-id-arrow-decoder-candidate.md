## 1. Result and boundary

A finite candidate schema can be stated for the actual transformed root

```text
Sigma = forall q. q -> q
alpha = empty
r_u = DecArrow(rho_u(Sigma); L, xi_u, actual_receiver_u).
```

`L` is one independently specified canonical decoder/kernel environment,
fixed before comparing exports. It contains uniform descriptor, admission,
transport and abstraction rules, not the source definition or its complete
relation. Use-time interpretation traverses this fixed schema and the
instantiated value/provider interfaces. It never follows a stored `id` body,
Lambda root or source relation. The construction certificate resolving `x`
to the rebound formal is a compile-time proof input, not part of `alpha`.

The source contracts do **not** select a unique `DecArrow`. The first
explicit clause distinction is whether the canonical decoder's result clause
retains the received provider or merely its complete value interface (§4).
This note states both alternatives without adopting either. Their effect on
complete observations still depends on the active `W,Z,G` grammar and guards;
the clause distinction is not yet an established user-visible difference.
Both alternatives require additional descriptor/admission and query suppliers.
A decoder that forgets provider identity can support a containment theorem; it
does not inherit the exact wire's source-base equality theorem. Option 2 remains
a separate exhaustive abstraction obligation, including ordinary descriptor
membership.

The result is a conditional derivation and a bounded identification of a
semantic decision. It is neither source sufficiency, a metadata lower bound,
an impossibility theorem, production certification nor principal solving.

## 3. Finite common schema and active clauses

Instantiate `q` and the schema's local ports `(i,v,o)` by one legal action
`rho_u`. `i` is the whole inert carrier; `v` is its designated demanded result;
`o` is the invocation result. Rigid imports, actual receiver/boundary,
ambient operation witnesses and the caller's original joint `xi=(nu,K,D)`
remain fixed. The decoder allocates a local position schema; it creates no
source call slot for a latent Function substituted at `q`. The actual runtime
closure must independently possess the chosen ordinary Pure/Value/Value-result
interface; decoding must not rewrite a supplied callable's role.

The fixed environment `L` provides the following independently meaningful
judgments, with all typed operands and original scopes explicit:

```text
Val_q(a,p,C;xi)           complete value/provider interface at q
Receipt(c,i,C;xi)         actual receiver and original receipt
Force(i;xi)              designated one-layer argument demand
Rebind(i,v,C;xi)          typed result-path/state transport
ReturnValue(o,C;xi)       ordinary Value result and invocation consumer
KernelArrow(q,O,w;xi)     independent whole descriptor judgment
Init_q, Response, Resume, Reach_q, Future_q
                         independent interaction/admission judgments
W_q, Z_q, G_q            independent exhaustive abstraction contracts.
```

These are supplier interfaces, not assertions that those complete judgments
have been supplied by current code. In particular `Val_q` is not just the
spelling of `q`: it includes the complete latent provider challenge/guarantee
interface where present. `KernelArrow` must state that actual role, entry,
consumer, the shared value interface, permitted body/result behavior, original
paths and whole interaction typing are valid. It may constrain a complete
invocation using its argument and executing context; the empty **body** row
does not forbid requests from entry. It is specified independently of the
source relation and of the next base image.

The proposed active descriptor introduction is

```text
legal q/interface substitution; actual Pure/Value/Value-result interface
one original typed port/incidence map; KernelArrow(q,O,w;xi)
---------------------------------------------------------------- ArrowMem
DescMem(r_u,O,w;xi).
```

`ArrowMem` is a proposed semantic clause. A separate constructor lemma must
show that every generated base observation satisfies its `KernelArrow`
premise; the rule cannot define that premise to mean “generated by the base”.
An opaque descriptor tag without this active rule is insufficient.

The finite base clause has no source-body reference:

```text
B_delta(h,O,w;xi) = image of
  actual Receipt;
  Force(i) >>= (v,C').
  Rebind(i,v,C');
  Ret_delta(q,v,o,C');
  ReturnValue(o,C').
```

Each operation refers to its uniform independently interpreted primitive
contract. `image` includes original Return/Request bind, finite-prefix,
divergence and future-provider interaction clauses. There is no enumeration
of histories. A request retains its original raw continuation followed by
this suffix and uses current resumed state. No receipt replay or recursive
force of latent `v` is added. The result clause below operates on a returned
value; it does not fabricate a return from a divergent argument.

Proposed admission is the independently generated history judgment:

```text
Init_q(c,i,context,result_path;xi)                 => A_delta(epsilon;xi)
A_delta(h); exposed original request; Response   => A_delta(h.response;xi)
A_delta(h); original raw handle; Resume          => A_delta(h.resume;xi)
A_delta(h); Reach_q(delta,h,p,port;xi);
  Future_q(p,port,whole_carrier,context;xi)        => A_delta(h.future;xi).
```

All conjuncts use the same assignment. `Reach_q` must be specified by an
independent licensed-prefix/returned-provider contract in `L`; it is not
inferred from `Direct`, type shape, a successful query or a projected row.
It must account for every provider introduced by permitted abstract rules.
These admission rules contain neither `Direct` nor a premise asking whether
whole-membership inclusion succeeds. Divergence does not remove the initial
challenge from admission. The compiler must supply an independent domain
correspondence before claiming `A_source = A_delta`; positivity of membership
does not prove the `Reach_q/Future_q` correspondence.

At the actual decoded root the complete membership clauses are

```text
X_delta(y) = least X. G_q(y) and
  (B_delta(y) or Z_q(y) or exists x,z. X(x) and W_q(x,y,z))

M_delta(h,O,w;xi) = X_delta(h,O,w;xi) and DescMem(r_u,O,w;xi)
D_delta(xi) = { h | A_delta(h;xi) }
P_delta(h;xi) = { Pi_xi(O) | exists original-scoped w. M_delta(h,O,w;xi) }.
```

`G_q` includes the ordinary descriptor conjunct, genuine guarantees, all
admission-live provider conditions, authority, scopes and original `K,D` at
the **final** tuple. Writing `DescMem` again exposes its active role; it is
not permission to omit it from guard comparisons. This is §3.7's finite
positive grammar, proposed for the decoder, with an exhaustive supplier for
all alternatives. `W/Z` neither branch on the root's spelling nor test query
success. Their admission-live changes require separate domain certificates.

No choice of empty `W/Z` is made. An empty grammar would describe only a
source-tight subcase and would not certify the approved Option 2 target.

## 4. Smallest alternatives left unresolved

Both candidates use the same finite schema. Only `Ret_delta` differs:

```text
Ret_diag(q,v,o,C) = same data/provider package through the typed transport

Ret_val(q,v,o,C) = Val_q(v,p_v,C) and Val_q(o,p_o,C)
                  and independently licensed result/provider transport.
```

`Ret_val` has no `p_v=p_o` premise. Its license must include all provider,
authority, dependency and future-domain obligations; two matching value-type
labels do not supply it. Identity transport must be one licensed alternative.
This is a conservative relation for type observation, not a claim that `id`
actually returns a different value.

| Candidate | Consequence and exact open premise |
| --- | --- |
| Diagonal canonical rule | Permits `alpha=empty` and source-base equality if the global decoder itself supplies typed identity transport. This is a proposed semantic restriction on exports decoded by this scheme shape; repeated `q` alone does not establish it. All other eligible exports must satisfy the same canonical interpretation. No per-export source-shape exception may be hidden in `DecArrow`. |
| Complete-value canonical rule | Forgets source-base identity and can include additional licensed results. Identity inclusion suffices for a one-way source-to-export base containment. Equality and identity-dependent future-provider observations require further proofs and are not inherited. The minimal logical discriminator is a returned provider pair
`p_v != p_o` admitted by the complete-value license under the same `q`.
`Ret_val` can contain that tuple while `Ret_diag` excludes it. This is a
conditional rule discriminator, not a source-admitted counterexample:
no such provider/license package has been constructed in this lane. It uses
one return and no request, capture or recursive call. Removing the unequal
pair removes this discrimination. Value/provider identity is stated under

Source-contracts §§2.2/3.7 permit additional interpretation/abstraction

```text

```

Both `M` terms include ordinary descriptor predicates, all original residuals
and every abstraction alternative. The left submitted root is the actual
`DecArrow(rho_u(Sigma);...)`, not a retained source Lambda. The caller conjoins
this one whole query with its independent use constraints and applies the
original final projection. No successful child query introduces the parent.

Primitive descriptor `Eq` leaves require original relation identifier,
operands and scopes to match; finite provider leaves retain the entire
non-coverage envelope. Constructor congruence and paired positive recursion
use the permitted §5.3 rules. Different result laws or guards are not compared
by merely asserting their semantic inclusion. Even self-comparison requires
the legal active decoder root and local resolution-conformance supplier;
reflexive clause proofs do not construct that descriptor.

This proposed query rule is distinct from its soundness premise and from
algorithmic completeness. The finite checker assumes the supplied primitive
contracts; it does not prove their source validity or decide every valid view.

## 6. Conditional theorem and derivation

Hypotheses, all necessary for the stated conclusion:

1. The isolated ordinary, unannotated nonrecursive source has no captures,
   adapters or computation parameter; its name resolves to the rebound formal.
   The selected entry/result facts and admitted typed-core primitives apply.
2. Legal generalization/freshening uses one eligible `q` and one simultaneous
   port map, retains every rigid operand and the original joint `nu,K,D`, and
   has any required joint hiding certificate.
3. The candidate canonical decoder and independent `KernelArrow` are supplied;
   constructor typing proves the base clauses satisfy active `DescMem`. The
   appropriate result license contains identity transport. The result law is
   fixed globally for this scheme's decoding, without consulting its source.
4. The separate initial/response/resumption/future-provider domain proof gives
   `Eq(A_source,A_delta)` for all complete histories on each original fiber,
   including every admission-live abstract-provider rule.
5. Actual source and decoded production membership have exactly paired
   `W/Z` grammars with every parameter/operand transported. Their full guards,
   including ordinary descriptor membership, have a proved inclusion
   `G_source <= G_delta`; both bases satisfy their guards. No primitive or
   alternative remains unaccounted for.
6. For a query conclusion, the required actual finite `Eq/Le` certificates
   and the ordinary local resolution-conformance rule of §5.3 are supplied.

**Containment theorem.** Under 1–5, the actual transformed root preserves
every complete source-base observation and every production observation
generated by the paired exhaustive Option 2 grammar, on equal independently
admitted domains, before and after the same final `Pi`. Under 6 a compatible
required view with those certificates receives `Direct(r_u,r_T)`.

**Proof.** Name inversion replaces the source body's resolved lookup by the
very value produced by rebind. Receipt, one-layer demand, rebind, current
state, result consumer and invocation return remain the same. Identity is
an allowed result clause by 3, so each source-base derivation translates to
`B_delta`. This is equality for `Ret_diag`; for `Ret_val` it proves only base
inclusion. The bind law translates request continuations with the original
suffix; supplied prefix/divergence laws and typed provider transport handle
non-returning arguments and future use without traversing a source root.
Constructor typing proves the descriptor conjunct for these observations.

For full production inclusion, induct on a finite `H` derivation. A source
leaf uses base inclusion; a `Z` leaf uses the paired independent extra;
a `W` step uses its same operands and the translated predecessor. Every
final guard uses the **complete** guard inclusion in 5, including the active
ordinary descriptor predicate. Thus no observation is discarded by a later
`DescMem` conjunct. Admission equality is hypothesis 4, proved separately,
not an induction consequence. Whole freshening in 2 and the same projection
preserve inclusion. Finally 6 introduces the one ordinary query at `r_u`.

**Conditional equality specialization.** For the diagonal rule, replace 5
by bidirectional complete guard/descriptor/grammar pairing and use base
equality. The reverse finite-derivation induction proves equality. A one-way
guard inclusion cannot establish that conclusion; this preserves the source
bridge's repaired equality boundary. No equality theorem is claimed for the
complete-value rule absent its separate reverse base/abstraction proof.

This theorem does not establish suppliers 2–6 from selected source formation.
It gives no all-view factorization, principal solution family, certificate
search algorithm, raw-source acceptance or current compiler correspondence.
