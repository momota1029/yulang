## 1. Objective and result


the existing rules give a finite **conditional** source Code/Check derivation.
The child Name/Result derivations, literal normalization, inert whole-argument
construction and dependent receipt/entry schema have constructive suppliers.
They need not each be assumed as unexplained completed certificates. Authentic
original source origins are still needed to turn this instantiated constructor
schema into a derivation at the actual emitted source records. No such original
emission or its satisfiability is established here.

In particular, the generated reference initial-context schema and the literal
`id 1` reference Initial rule do not supply original source `CallInitial`, its
`I0/K0/P0`, observation/evidence action, or fixed-root insertion. Their
conclusion sorts differ. The current production lowerer rejects the application
body on its ordinary path; this does not refute the conditional source rules.
Candidate Int is no premise or oracle for this derivation.

## 3. Explicit finite derivation


This is a graph of module declarations and uses. It is not a new assertion
