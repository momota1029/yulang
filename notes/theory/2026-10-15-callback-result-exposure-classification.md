## 1. Frozen case and conclusion

The case is the ordinary source constructor sequence

```yu

    my g = f();

}
```

The syntax denotes a received **Value** formal with a Function annotation,
followed by a completed source Call, ordinary local result binding, a Name

and these source rules; no current private-native admission or execution of
this text is asserted. In particular the native scoped collector has the
coverage boundary described in §5. These ordinary source constructors remain
in the original supported domain; that boundary is not adopted as semantics.

Fix original receiver definition `d`, formal `f`, annotation `a`, its binding
scope `S`, original shared value result endpoint `alpha`, static callback
identity `beta_f`, and first/second source upper-use occurrences `u1,u2`.
`alpha` is a value endpoint, not an effect row. It stays at its original binder
scope under one joint `xi=(nu,K,D)`. Fix one complete first-Call constructor
witness, including its actual provider, whole Unit argument, entry, pending
suffix and actual returned typed value packet `W`. Every projection below is
of that same witness; independent marginal choices are prohibited.
Quantification is pointwise over every original `xi` and every returning
witness of that original complete Call relation, with nonreturn/request cases
handled by the same Bind suffix. `W` remains the source relation's original
result binder, at its original scope under that Call's challenges and shared
provider witnesses; it is not a new independently chosen existential.
The source constructor emits this symbolic binder and the maps without
executing the Call, choosing a returned callable or first proving query success.

**Conclusion.** This sequence is a result-transport case. Its receipt,
Call-result, local binding and Name rules create no new protected-variable
seed at `g` from the outer formal's annotation or first output-effect mark.
Therefore these rules do not license a new `Dir-Protect` introduction at
`u2` merely because `alpha` becomes callable. They do construct the exact
typed transport of the actual returned packet and any independently existing
callee-result profile. Independently justified variable-stage seeds retain
their original source identity and can license their own upper exposures;
they are not disproved by this non-generation result. Thus this is neither
absence of all protection nor an authority contradiction.

The theorem is about the constructor's output for arbitrary original typed
packets, not a test that assumes all such packets are empty. The exact result
is the finite source rule in §4. It does not demand that every symbolic future
shape be enumerated or that every returned leaf receive a positive seed.

## 3. Derive the actual source maps and introduction classification

The annotation is ordinary Function data, so outer entry receives and forces
its whole argument once, rebinding `f:Value(F_cb)` before its body. The
explicit binder does not match the selected *unannotated-formal* seed
constructor. This does not decide the independent annotation profile's marks.
Its actual receiving boundary retains its original `beta_f` and profile;
it is not reconstructed from the eventual value of `alpha`.

Name `f` reads the original received view. The first Apply emits its original
complete Function upper demand `U1`, including a result-value port constrained
to `alpha`. It emits this demand independently of successful Function solving.
If an independently justified directional seed applies at this exposure,
`Dir-Protect` adds its one output-effect incidence. The rule's head is
`NewProtection(...,outEff(U1))`; it is not
`ProtectedVarAt(...,alpha,...,u2)`. Omitted AE/RE coordinates remain distinct
open rows, without making the result value an effect position.

Now generate result correspondences from the **actual source constructors**:

| Constructor | Exact generated map or output |
| --- | --- |
| Completed `f()` return | The actual returned value packet `W` has its whole value correspondence into the Call result. The callee-result view contributes only by removing the original `result` prefix at its matching value/result paths. |

To prove these maps are generated, use core §6's Application, Binding and
Name rows in order. Application synthesizes `Computation(E1,A1)` with a

Application uses this Name result as its callee and creates its own demand.
Typed-boundary §6's ordinary structure then gives precisely result-prefix
removal, binding identity and read identity. These are source-chosen maps,
not an existential assumption that some map preserves a desired protection.

Let `R` denote the first Call's returned-value position and let `q` be an
already justified typed path in a returned view. Result projection is

```text

```

This is a finite prefix-removal rule. It neither generates `q` by unfolding
the possible shape of `alpha` nor inserts a mark at every possible suffix.
The first complete-call effect position `p_call` is not of the form `R.q`,
so it has no image by this result correspondence. In particular an annotation
permission at `p_call` is not a nested grant. The actual-value input packet
may independently contain the same original boundary witness; that separate

underlying value pointers alone do not unite different view packets.

**Non-generation proof.** Inspect the output sorts of these source steps.
Source boundary introduction creates profile incidence at supplied positions;
receipt creates ownership of a typed use; result/bind/Name transport the
existing packet. None has a `ProtectedVarAt` seed as a new conclusion.

## 4. Finite rule and exact evidence preservation

Write `W` for the actual returned packet and `F_R` for the original callee
result-view packet, as indexed inputs of the same complete Call witness.

construction is exactly

```text

Packet_Name(g) = Packet_g

```

`union_tagged` is the existing multi-input typed transport operation, not
union of effect supports. It acts jointly on `chi,D`, retains the common

The last row reuses the reviewed directional constructor's exact join; the
previous rows do not populate its seed input by shape inspection. Any
independently justified seed must keep its original variable-stage, scope,
shared root and occurrence correspondence to `u2`.

**Exact classification.** Every carried profile at a returned path comes
from one of these two actual source inputs and its matching map. Conversely
every such source witness is retained by result, binding and Name composition.
This follows by expanding the generated image and the two identity maps;
no marginal source choices are recombined. Every new directional incidence
has the original seed/exposure witnesses by the reused local rule, and every
instance with those witnesses is included. Hence transport, independent
introduction and justified non-generation coexist in one source case; a
positive seed at every returned leaf is unnecessary.

This finite rule is valid with symbolic `alpha`: paths are retained as
original typed evidence references, with result-prefix stripping when their
source correspondence applies. It adds constant constructor metadata and
visits only carried evidence, not all future type shapes or future programs.
Its finiteness is rule/presentation finiteness, not a new whole-source finite
model, complete Function inclusion algorithm or principal projection theorem.
