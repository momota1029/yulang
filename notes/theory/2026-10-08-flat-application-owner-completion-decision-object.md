## 1. Decision object and its scope

This proposal defines a **fresh** source-owner family `Application_N`. Its first
new constructor handles a direct resolved formal Name applied to an integer
literal, including the inner `f 1` of `my apply f = f 1`. It retains the entire
previous family through a tagged inclusion. It does not assert discovery of an
exhaustive, historically implicit original Application rule.

The exact proposed decision is: adopt §§3–8 as the first bounded source-owner
completion `Application_N`, with the independently interpreted whole contracts
specified in §3; or require correspondence to a separately fixed original
Application family before selecting a completion. The second route requires
that family's actual declaration, complete interface, source rule and typed
forward/back maps. No complete competing observable meanings have been proved.
This is a reviewable decision object, not evidence that a user choice has
already been made or must be solicited before independent review.

The proposed definition answers which owner constructors, occurrences,
attachments and installation rules exist **in N**. It stops trying to recover
those definitions from the five reference heads. The correspondence of this
definition with an independently fixed family remains an explicit obligation,
not an input named `H-original-install` disguised as a construction conclusion.

This is the first bounded constructor gate toward completing ordinary
Application and inference. Its research envelope is not a new source support
boundary. Other calls keep their existing derivations. Section 9 specifies the
recursive typed-operand composition seam; this note does not establish
all-source typing, computed-callee formation or production inference.

## 3. Exact input contracts; opaque does not mean unspecified

Fix a finite resolved source artifact S with a finite binder/scope graph B and
a jointly ordered symbolic context X. `xi=(nu,K,D)` is one dependent assignment
family over X, not three independently selectable port witnesses. The first
new source domain is the finite set

```text
D_lit(S) = { c | S has an actual Application c with
  callee(c)=Name(u_f), argument(c)=Integer(a,k),
  u_f resolves through actual local/capture edges to an immutable
    ordinary Value formal d_f at its original root r_bind,
  the operand and enclosing formation graph is finite and acyclic,
  this selected declaration has no unresolved annotation/adapter boundary }.
```

`k` is the actual integer value/spelling at a; no semantic case depends on its
text. This domain includes arbitrary many such occurrences in one finite S,
not just the identifier `apply` or the value 1. Unannotated formals retain the
selected protection direction; no seed is inferred merely from this domain.
The syntax fragment for a new occurrence is exactly
`Application(Name(resolved-formal),Integer(actual-literal))`. Its context may
contain already typed Lambda/capture/immutable Bind nodes. Those context nodes
are inputs with their own constructor derivations, not newly proved here.

Inputs have the following complete interface, written `WholeContract(t)`:

```text
identity: actual independently declared primitive/root t, original owner;
parameters: ordered dependent P_t and fixed/imported parameter map;
tuple: complete H_t/O_t/provider/world/state/future/evidence telescope T_t;
membership: independently interpreted R_t(h,o,w;xi) with its whole
  witness family, including every declared alternative and proof choice;
admission: independent A_t(h;xi) and complete future-use/history domain;
typing: original source/interface tags, descriptors, hard constraints,
  and independent local typing laws over the full declared domain;
license: original licensing judgments, authority, scope, incidence and
  guard interfaces, including changed/introduced-provider domain laws;
output: actual-output-dependent provider, world and future-use interfaces;
action: sorted whole-tuple maps on every foregoing field, with
  identity/composition and predicate/witness/domain/license compatibility;
boundary: a declared complete interface projection and inverse-on-image
  law for exactly the fields exposed to these consumers.
```

`R_t` may be empty and its witness family may be infinite. An opaque contract
is one atomic boundary containing **all** these fields. It is not an unknown
predicate accompanied only by a promised endpoint. Its internal alternatives
remain inside its actual witness family; N never chooses a canonical witness
or enumerates them. Completeness means no required field is hidden from the
declared consumer interface, not that every tuple satisfies R_t. Distinct
declared clauses stay distinct contracts when their own interface distinguishes
them; opaque treatment is not a quotient of their evidence.

The concrete input classes are:

1. `Old`: the entire old indexed Application emission/presentation family,
   old port registry, rule entries, original occurrence/alternative fibers,
   lookup/inversion and whole action. N imports it as a module verbatim. This
   includes every old Name/Name case and any other old case; N asserts no
   old-family exhaustiveness theorem from Name/Name examples.
2. `Env`: the dependency-closed binding/capture telescope, actual Resolve and
   Capture derivations, and the original joint ambient/Name/import contracts
   under their real scope inclusions. Joint imports remain joint contracts.
3. `Integer(k)`: the declared complete literal primitive at a with
   `Value(Int)`, inert descriptor k and its full `WholeContract`. Its ordinary
   Return formation uses the existing independent Return kernel. No fresh
   literal value variable or literal value-bound pair is added.
4. `Kernel`: the existing independently interpreted `WF_Dec`, `VIncl`,
   `WholeArgCompatible`, `CIncl`, Return, Delay, one-layer consumer, Bind and
   complete ExecuteCallable kernels. Each is a `WholeContract` at its own
   dependent indices. A complete Call kernel is a reusable operation
   interface, not an already formed source Application at c. Its source image
   includes callee Bind and inert Delay, dispatch to the actual provider/current
   world, that provider's entry/body/designated consumer and native/complete
   return, all independently declared whole-Call arms and future fields.

The Kernel boundary deliberately exposes full callable/carrier descriptor
domains, original licenses and complete witness actions. It does not fix W/Z
meaning or construct a provider's admission from membership. On a
domain-changing primitive action its actual domain certificate is required.
Missing any field above is the exact failure `IncompleteContract(t,field)`;
an endpoint-only replacement is inadmissible even for a first review object.

These are explicit candidate hypotheses about independently supplied modules,
not claims that the repository or current compiler realizes all of them.
None assumes a source-specific `Application_N(c)`, a seed, completed original
membership at c, successful checking or satisfying solution. Thus the new owner
construction below is noncircular, but its semantic realization remains
conditional on these full contracts.

## 4. Dependent telescope and source-owned constructors

Construction retains the following order, with declarations well scoped to
all earlier dependencies. X contains the outer free endpoints; Delta_c is
the actual local source scope. The displayed result is one dependent record,
not a cartesian product assembled from independently existential ports.

```text
S,B,X,xi,T_c,Delta_c, Old,Env,Kernel;
d_f,A_f,r_bind,b_f,route_f,u_f, a,k,Prim_a;
Reg_N(beta), R_f with beta=(d_f,R_f);
q_f : Data_N(Name u_f,Value(A_f)),
q_a : Data_N(Integer a k,Value(Int));
o_f,o_a, n_f,n_a with R_f_operand=Comp(empty,A_f), R_a=Comp(empty,Int);
c, parent_f,parent_a, o_arg,r_arg, Delay_a;
F_c : complete-demand sort in Delta_c, E_c,A_c, view_c;
u_c : checking occurrence, p0=(beta,call.effect),
check_f,check_a,o_result,p_out, o_reify_result,r_result,p_consume_result;
rho_c,ElimOrigin_N,ReceiveSchema_N,Suffix_N(U);
RuleEntry_N,occurrence entries,installed owner record e_N,Check_N.
```

`R_f` (formal shared contract root), `r_bind` (value binding), operand Result
port `o_f`, argument carrier `r_arg` and Application result carrier `r_result`
are different roles. The symbol `R_f_operand` above abbreviates a computation
interface, not the formal root R_f. `F_c` is a symbolic demand and never the
actual returned provider U. `u_f` and `u_c` are distinct tagged occurrences.
Ports have nominal keys `(artifact,constructor occurrence,role,scope)`; role
tags persist even when endpoints later coincide. A shared formal key is
`(artifact,d_f,formal-contract)` independently of how many calls expose it.

The proposed constructor table is exhaustive for the new static spine:

| Constructor | Premises retained and interpretation |

Every new certificate is a constructor term storing exactly its row's premises.
Its interpretation is the indicated static typed source incidence or the
independent constructor image; its eliminator returns those premises and
its dependent fields. It has no rule taking its own desired output as input.
Port formation is genuine **in N** by these definitions. “Original PortReg”
requires separate adoption or a typed realization into a fixed interpretation.

Registry lookup returns `Found(old certificate)`, `Found(N certificate)`, or
`Absent(key,complete searched finite registry)`. Reuse requires equality of
the complete dependent interface, parent and scope certificate, not just
endpoint equality. A mismatched existing key produces `RegistryConflict`.
An absent root gets one nominal allocation and its constructor certificate.
This fixes reuse, absence and inversion at the old/new seam without assuming
that a generic expression ID table already contains a typed port.

## 5. Occurrence grammar and complete interpretation of the new owner

The finite source-level grammar is:

```text
ContractRef(t,use,inclusion)       -- complete opaque contract boundary
Static(tag,constructor-proof)     -- static formation certificate boundary
Obligation(tag,predicate-code)    -- independent interpreted proposition
All(P1,...,Pn) | Scope(ordered declarations,P)

P_N(c) = Scope(F_c,E_c,A_c at Delta_c;
  All(ContractRef(Env,joint-use,scope inclusion),
      ContractRef(Name_f,callee-use,its inclusion),
      ContractRef(Integer(k),argument-use,its inclusion),
      Static(formal,Formal-N), Static(name,Name-N), Static(literal,Literal-N),
      Static(result-f,Result-N), Static(result-a,Result-N),
      Static(argument-reify,ArgDelay-N), Static(demand,Demand-N),
      Static(check-f,Checks-N), Static(check-a,Checks-N),
      Static(complete-result,Output-N), Static(result-reify,Output-N),
      Static(result-consumer,Output-N), Static(elimination,Elim-N),
      Obligation(wf,WF_Dec(F_c;xi)),
      Obligation(value,VIncl(A_f,F_c;xi)),
      Obligation(argument,WholeArgCompatible(R_a,CarrierContract(F_c);xi)),
      Static(receive,Receive-N),
      Obligation(result,CIncl(ExecuteCallableImage(n_f,Delay_a,F_c;xi),
                              Comp(E_c,A_c);xi))))
```

This is an explicit **proposed** exhaustive grammar, not the claim that five
reference heads were independently discovered to exhaust the actual original.
Four heads are semantic obligations; Receive is a typed schema certificate.
The local reference's receive proposition is interpreted here by the fiber
of Receive-N's full structural evidence. Its fields remain more precise than
a boolean. Semantic receipt/dispatch validity is not that fiber.

`Static(result-reify)` and `Static(result-consumer)` are separate typed
projections of Output-N at their own roles, not extra CIncl conjuncts. No
missing side condition is filled with an unspecified `Extras`. There are no
top-level new alternative branches beyond this clause. Every alternative of
the imported full primitive/kernel/old contracts stays inside its own opaque
fiber, unchanged; the complete operation reference described below retains
all its independent arm declarations. This precisely defines the atomic
boundary at which finite source exhaustiveness is claimed.

Occurrences are full constructor addresses, including Scope/All child index
and exact contract-reference use. Distinct uses of the same contract have
distinct contextual occurrence addresses while referring to the same original
root. Env and Name references are incidences to the retained joint telescope;
they do not independently replicate membership witnesses or conjoin two copies
of the same declaration's body. Shared-root equalities are in the same tuple.

For a sorted assignment sigma to the symbolic declarations, interpretation is
dependent: Scope keeps exactly that assignment and its original scope; All
contains the fields together at that same tuple; ContractRef keeps the entire
original reference interface and witnesses; Static keeps the indicated
constructor proof. Obligation introduces its **original kernel witness**,
not a fresh canonical proof. For the four obligations, the witness telescope is

```text
w_wf : WF_Dec(sigma F_c; sigma xi)
e_f  : VIncl(sigma A_f,sigma F_c; sigma xi)
e_a  : WholeArgCompatible(sigma R_a,CarrierContract(sigma F_c); sigma xi)
e_out: CIncl(Image_c(sigma n_f,sigma Delay_a,sigma F_c,e_f,e_a),
             Comp(sigma E_c,sigma A_c); sigma xi)
```

All original dependencies of these witnesses remain; `e_out` can depend on
`e_f,e_a`. All shared world/provider/operation references agree at sigma xi.
Formation emits predicate codes with their typed interface, without supplying
these satisfying witnesses. It can succeed when this interpreted fiber is empty.
Interpretation/formation separation therefore introduces no inhabitance claim.

The complete operation root is allocated at the same owning c as

```text
Q_N(c) = Ref(complete-call Kernel,
             operands=(n_f,Delay_a), source j, open whole-carrier inlet,
             actual-output-dependent provider/world/future interface).
```

The generic kernel's independently specified full relation is the authority
for this operation's meaning, including every declared arm and evidence
alternative. `Q_N` is an actual **new** declared use/root of that complete
operation, installed with all complete interface inclusions. It does not
assume an existing authentic original Q_e at c. It also does not define its
whole membership as only the source diagonal Delay_a: the open carrier inlet
remains available in the kernel interface. The actual source supplies that
one diagonal section. Under whole operator realization, unfolding Q_N gives
the already selected complete Call image; no inference solution is used.

Each opaque arm has the generic contract's actual arm-to-root insertion and
root-to-use incidence, license, provider and future dependencies. N preserves
those through the chosen operation use and selected IF contextual constructors.
If the generic contract has no such complete interface, Q_N is not constructible.
Nothing forces an independent Z arm through a source execution or reuses the
structural provider's future certificate for another output provider.

## 6. Receive, suffix, Check and the decorated-certificate boundary

```text

source-complete-output(c) -> F_c.complete-call, retaining p_out/view_c;
dependent instantiation slot (actual provider U,current world C,
```

`Suffix_N(U,C)` is a family, not a producer chosen during emission. Given an
independent complete producer interface at U and C it retains the ordered
receipt, U's own entry, body, designated consumer, native delimiter and
complete return. Value entry contains designated Force then typed rebind;
retained entry binds the same carrier. An operation retains native Return of

suffix. Entry-pending and later tails are the remaining ordered suffix at the

retains port/schema interpretations only. Semantic phase/dispatch/guard laws

## 7. Actual N installation, lookup and exhaustive inversion

N has an immutable candidate presentation `Presentation_N` with two tagged
modules. Rule entries and memberships are dependent inductive judgments:

```text
KeepEntry(h_old)                         -- every entire old rule entry
NewEntry(owner=c,rule=LiteralApply,build) -- build from §§3–6, no emission input

KeepEmission(e_old) : E_N(j)              -- every entire old emitted witness
NewEmission(build,h,complete_table,Q_N) : E_N(owner=c,j,LiteralOrigin(a,k))
```

The new construction order is leaf/route, registry certificates, ordered
telescope/spine, P_N and Q_N declaration, NewEntry, occurrence table, then
NewEmission. Check_N is formed by projecting that emitted record. Its reference
to e_N is therefore noncircular. `CompleteTable` is a finite vector indexed by
**every** leaf address in the declared P_N grammar, including ContractRef and
Static leaves; each cell stores its exact code, original/constructor owner,
scope, typed attachment, parameter projection and witness interface. The root
and each Scope/All node also retain their complete declared children/binders.

`install` stages this table plus the Q_N interface insertions and the entry at
the actual source owner c. It checks exact address coverage, unique addresses,
same-index attachment types and all registry certificates, then returns the
dependent record with `Member_N(NewEntry,NewEmission)`. This is N membership,
not lookup in a hidden P_orig. Table lookup is finite indexed elimination:

```text
lookupRule(install(build), (New,c,LiteralApply)) = NewEntry(build)
lookupOcc(install(build), address) = the declared CompleteTable[address]
invertMember(NewEmission(...)) = (build,entry,whole table,Q_N insertions)
```

Keys include module tags, so an old entry is never overwritten by a new one.
Installation does not fabricate literal Name evidence. A complete staged
package may contain inconsistent semantic obligations; installation is not a
solver or admission check. No actual Rust mutation/registry API is prescribed.

**Conditional constructor derivation.** Under §3's typed input contracts,
resolve the real Name and copy the real integer primitive. By the Value tag
construct their two Results. ArgDelay-N retains the whole argument. Demand-N
declares F_c/E_c/A_c under the original scope. Checks-N and Output-N construct
their distinct ports and predicate codes; Elim-N and Receive-N construct the
dependent links. Build P_N by its stated grammar, Q_N from the full reusable
operation contract, then NewEntry and the complete table. Finite indexed
elimination gives the installation/member equations above. No premise mentions
desired E_N membership or semantic comparison success.

**Exhaustive N inversion.** E_N case analysis gives Keep or New. Keep returns
the entire old derivation; its internal inverse remains the old module's.
New returns exactly the source literal occurrence, route, registry/spine,
P_N/Q_N declarations, entry and complete table. Scope/All address induction
returns each declared leaf once, its constructor and all premises. A
ContractRef inverse returns its entire independent contract interface and
reference inclusion; it does not inspect/enumerate an infinite primitive
fiber. A semantic witness inverse returns the full w_wf/e_f/e_a/e_out fiber.
This proves exhaustive **source-boundary** inversion under the proposed grammar.
It proves no hidden-original inventory bijection or finite primitive internals.

**Old inclusion and rollback.** For the entire old dependent sum,
`i(e)=KeepEmission(e)` and `r(KeepEmission(e))=e`; r is undefined on New.
Then `r(i(e))=e` and `i(r(z))=z` on the Keep image, including all Name/Name
proofs, alternative witnesses, owners, scopes and attachments. Old entries,
lookup and action are exact imported operations. Source generation of an old
Name/Name frame continues to select its unchanged old entry; this proposal adds
no NewName branch or second emission there. Any old literal case also survives
as Keep; the new tagged record does not identify or quotient it.

Deleting N's New module and its newly allocated roots/ports retracts the old
module exactly; reused old roots/ports remain. This old-image theorem is not
universal conservativity for formulas quantifying over the enlarged E_N domain.
An active legacy consumer requiring such a law needs its own proof. N may not
be substituted globally into old quantifiers merely because r exists.

## 8. Whole action and its exact hypothesis

A legal theta is a sorted coherent action on the complete context and contracts:
B,X,xi, dependent binders, scopes, source roots/ports, registrations, demands,
origins, references, evidence families, provider/world/future extensions,
predicate interfaces, rule entries and lookup derivations. It preserves source
tags and actual primitive identities, respects fixed imports and licenses and
comes with each §3 contract's lawful action. Endpoint substitution can be
noninjective; source occurrence addresses and proof choices are not thereby
identified. A source renaming is bijective on nominal occurrence identities.

Define theta on N constructors by transporting **all** their stored premises
once and reapplying the same constructor; on Keep use the exact old action.
The registry action transports the finite registry, keys, found/absent evidence
and complete compatibility judgment together. Whole freshening is one coherent
nominal renaming, including new-entry tags and every incidence.

By constructor/address induction and the independent component laws:

```text
theta(P_N(j)) = P_N(theta j)
theta(build_N(j)) = build_N(theta j)
theta(install_N(build)) = install_N(theta build)
theta(lookup(table,address)) = lookup(theta table,theta address)
theta(i(e)) = i(theta e); r(theta(i(e))) = theta e
theta(Suffix_N(U,C)) = Suffix_N(theta U,theta C).
```

The semantic consequence is witness transport in each whole interpreted fiber,
using the independent kernel/primitive actions. Identity and composition follow
from those component laws and constructor recursion. Reflection is claimed only
for invertible coherent renaming or a separately supplied inverse-on-image law.
No arbitrary noninjective semantic substitution is declared a bijection.

This is a conditional theorem about N. Free syntax action alone proves neither
the component semantic laws nor CallInitial/I0/K0/P0 phase actions. The same
restriction applies if an admission-live provider/world coordinate changes:
its actual complete domain certificate is required, regardless of positive
membership preservation.
