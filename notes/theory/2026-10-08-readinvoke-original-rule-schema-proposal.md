## 3. Exact envelope and indices


node. Enclosing Lambda/entry roots and receiver implementations are supplied

`C_e` is live, not frozen by `eta0`. Original formation inputs retain each
source occurrence, resolution/capture edge, Return delimiter, reify origin,
ResultBind telescope, actual Application origin and complete `IF_c`. Call
interface `u_f`, checking interface `u`, actual exposure and ElimOrigin stay
distinct. A root registration and a checking origin are not proofs of their
semantic obligations.

Notation in the tables is metanotation for requested original judgments:

- `D_n(z)` is a finite original data-observation derivation at occurrence n;
- `C_q(O)` is a finite original computation-observation derivation at q;
- `L_t(O)` is an original designated one-layer latent development of carrier t;
- `I_p(a)` is original admission at initial/request/raw-handle/future port p;
- `V_U(t,O)` is original actual-provider invocation evidence, with U's actual
  role, entry, phases and dependent return/future fields.

These names do not create new semantic predicates. An implementation of these
names would need the original judgments and their actual signatures. A
`Return` in a premise is an actual completed Return, never a prefix with a
guessed result. `Form(q)` means genuine original formation evidence, not merely
a tuple with matching sorts.

For every schema, a legal original whole-witness action g acts once on j,
history/evidence, scopes, environment, child operands and conclusion. Rigid

no per-child hiding, provider reselection, operation-witness freshening or

## 5. Derived equations and conditional finite evidence factorization

Take the selected ordered suffix, at the actual callee Return:

```text
S(v_f,C_1) = inertly form t_x from the whole q_x and original references;
             ExecuteCallable(actual U_f,t_x,C_1).
```

The suffix is dependent on that same returned v_f/root/U_f/current witness.
Formation does not derive a request or Force of q_x. With the original Bind
operator, the following two equations are supplied independently by
source-contracts §3.2 and source generation §2.3:

```text
Return(v,C) >>= S = S(v,C)
Request(q,C,k) >>= S
  = Request(q,C,(a,C').k(a,C') >>= S).
```

Therefore a callee Return followed by an original suffix observation has the
Call's ordered image. A pending first-child Request preserves that operation
and composes its original raw continuation with S. On resume the computation
is `k(a,C') >>= S`, at C', not the earlier C; S runs only when k returns.
Neither equation replays past receipt. These are deductions at the supplied
operator relation, with its original indices. They do not prove a concrete
decorated prefix map that was omitted from the operator's signature.

**Conditional factorization.** Suppose all unresolved maps in §4 are the
original decorated operator maps, with original scope/whole-witness laws, and
the following independent completeness input is supplied:

> Every finite derivation in this local source envelope has a last rule from
> the original finite local signature, the original registered-reference
> signature, or the complete original receiver/history signature. Each rule
> exposes its actual source-child premises and does not hide a second source
> execution in a purported inert formation leaf.

Then translate a finite derivation by last-rule induction: retain each
non-source guard, original witness, provider and history evidence; translate
only its actual source-child derivations; instantiate the corresponding
unchanged original schema. Name has no latent-execution child. Result has its
data child. Delay formation has only code formation; a demand has q_x's reached
development. Bind prefix has only the reached child and suspended suffix;
Bind Return has the shared dependent middle child/suffix; Request and resume
retain the original handle and live state. Call uses these Bind cases and the
actual-provider signature. FutureUse uses its actual returned-provider port.
Registered references preserve their original substitution, and induction is
on finite evidence, never infinite graph unfolding.

Every original subderivation has strictly smaller finite evidence, so this
translation terminates. Its inverse likewise needs exact last-rule lookup;
no independent production W/Z derivation is converted to a structural source
execution. This establishes a finite translation **conditional on** the stated
last-rule signature. It does not establish that signature by partitioning
arbitrary observations into the descriptive rows above.

For emission attachment, the translated source-child heads can subsequently
be replaced by allocated root references under its `EM-Insert`. That step
remains a separate construction. This note produces no lookup equality at a
fixed E_c. The identity result descriptor proves the corresponding DescMem
only with its independent phase/guard evidence; it cannot be used as a premise
for constructing these source observation heads.
