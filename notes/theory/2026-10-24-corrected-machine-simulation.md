## 2. What must be represented

A concrete finite-prefix state has immutable allocated evidence `E`, current control `C` (active owners/handlers, executing View occurrences and frame modes), current relation `L ⊆ Scope × Target`, and typed packets with route witnesses. Scope origin, receipt, target capture table `B_t`, saved evidence and old Observe rows remain immutable. A route witness includes its own transported target set `H(w)`; two routes with the same event remain distinct witnesses. Treating witness identity as event identity is invalid.

For each currently queried packet/candidate pair `j`, use these concrete predicates on a protection witness `w`:

- `D_j(w)`: all original receipt/Path/Observe/incidence and current activity conjuncts required for protection, excluding Prot and release;
- `P0(w)`: original protection kind;
- `A(w)`: activity of its original receiver;
- `F_j(w)`: original receiver differs from the current candidate owner;
- `Z(w)`: there exists `t ∈ H(w)` with `L(s(w),t)` and `Match(t,s(w))`.

Thus `Live(w)=P0(w) ∧ ¬(A(w) ∧ Z(w))`, and

`P_j = ∃w. D_j(w) ∧ Live(w)`,

`PF_j = ∃w. D_j(w) ∧ Live(w) ∧ F_j(w)`.

This factors the concrete R-Project formula without changing it. Z is a derived **current binary-incidence query**, not a unary replacement for L, nor a permanent fact stored at capture. `D_j` must include exactly the source query's other activity/path conjuncts; expired protection is not resurrected by merely making Live true when A becomes false.

Also retain finite scalar observations `Base_j, GC_j, GW_j`, operation/declaration/port tags, completion modes, and finite static template labels. Actual family/type-instance equality required by a query is an equality observation; coincident finite colors never establish that equality.

## 3. Explicit finite joint cell

Fix a finite interface I from a finite typed code/template derivation. It has finitely many register *slots*, sorted by evidence owner, control owner, handler, scope, target, receipt, event, view occurrence and route witness; owner identity comparisons across evidence/control roles are allowed through their common owner-name sort. The action role is separate from the identity sort. Finitely many packet ports and candidate slots are jointly represented. Runtime identities and stack depth are unbounded; the number of slots is not. A route witness is an occurrence with one fixed scope and transported target set H, not just an event or an underlying value identity. Two routes that transport different H have separate rows even if their event and scope agree.

A cell contains:

1. Defined bits and the equality partition of all identity registers, with sort restrictions; role tags and finite scalar observations.
2. Named binary observations `L(s_i,t_k)` and `Match(t_k,s_i)`, origin/receiver equalities, and named activity. These are only for represented endpoints.
3. For every named witness, its complete Boolean vector over the predicates in §2, membership in the interface packet ports, scope/receiver equalities with named registers, and `t_k ∈ H(w)`. Include any finite additional discriminator columns required by the current primitive. For hidden witnesses, one occupancy bit `e_beta` per complete vector beta. Hidden means distinct from *all* named witness registers.
4. Analogous joint unary diagrams for owner activity/incidence when needed by existing transfers. These owner diagrams do not replace the witness diagram.

The witness population for I is the union of the route sets of its designated packet/ambient ports, not every historical route in the world. Every row records membership in each such port. Restriction to fewer ports first discards rows with no remaining membership, then forgets columns/registers and disjoins the remaining occupied vectors. This makes restriction of the actual union diagram equal to the actual smaller-interface diagram. Forgetting a still-relevant named row moves it into the hidden population; forgetting its last relevant port removes it from this interface only, not from the evidence history.

Alpha_I evaluates these finite predicates in the concrete state. The concrete evaluation may traverse a finite history DAG; the abstract table generator never evaluates an arbitrary history. There are finitely many partitions, Boolean vectors and occupancy bits, so the set S_I of **syntactic** cells is finite. It may include unrealizable cells. Require only explicit finite constraints (equality coherence, named-row agreement, sort correctness, and PF implies P as derived below); do not test concrete reachability or realizability.

Query is a total Boolean function on a cell: compute P and PF by disjoining qualifying named vectors and hidden occupancy bits, then use

`Eligible_j = Base_j ∧ (¬P_j ∨ GC_j ∨ (GW_j ∧ ¬PF_j))`.

**Lemma 1 (observation exactness).** For every finite concrete state x, this function on Alpha_I(x) equals current W-Eligible, provided I contains the current query slots.

**Proof.** Partition the concrete witness set into named singletons and hidden complete-vector regions. The body of each existential is constant on each region. Its existential is therefore exactly the disjunction of the corresponding occupancy bits and named truth values. All four scalar observations are evaluated in that same state and packet/candidate tuple. Substitution into W-Eligible proves equality. Binary L/H/Match correlations are evaluated together inside Z; the proof never infers their intersection from separate nonemptiness bits. ∎

Exactness belongs to **Alpha_I(x)**. An abstract set U containing Alpha_I(x) can contain cells with either query answer. Filtering U by a desired answer is not an exact decision about x. Both reachable answers must remain in graph branches.

## 4. Finite splitting, selective mutation and reexposure

The following executable-by-enumeration operations define abstract tables without a soundness oracle.

**Refine.** Add k Boolean columns. A named vector receives every compatible refinement. For a hidden occupied beta, choose any nonempty subset of its at most `2^k` compatible refined vectors as occupied. An empty beta has no occupied refinements. Constraints already represented remain fixed. Enumerate all such choices jointly with the register partition. The result is finite. Multiple refinements may be occupied even if some concrete realization has only one witness; this is intentional overapproximation.

**Map.** When a primitive has a justified pointwise Boolean formula f on the same witness occurrences, map named vectors by f and set `e'_gamma = OR_{beta:f(beta)=gamma} e_beta`. The same unchanged route may belong to several packet ports. This operation does **not** copy a route into a new route with different H or provenance; that requires Fork below. Do not subtract a shared witness merely because one View ends. A specified deleted output port is forgotten, not removed from all other ports.

**Expose.** To name a previously hidden witness from occupied beta, create its named vector and choose independently whether the residual beta is empty or occupied. Other regions are unchanged. If the new register aliases an existing named witness, use its existing row instead. Forget is the converse safe operation: add the forgotten singleton to its hidden region if no register still names it. No count of one is inferred from occupancy.

**Refresh.** Drop selected mutable/derived columns and refine them anew using all finite assignments satisfying explicit constraints. Preserve immutable identity and origin facts that the action really preserves. If a predicate depends on any forgotten binary endpoint, hidden route, changed world or new candidate, it is refreshed unless a concrete defining equation proves its update. In particular Z, D, F and grant-query results cannot be copied merely because a packet was saved. New target introduction and newly exposed candidate endpoints require fresh joint columns.

**Lemma 2 (representation preservation of these four operations).** For every concrete operation of the stated kind and input x, its actual output cell is among the enumerated outputs from Alpha_I(x).

**Proof.** For refinement, choose precisely the refined regions containing an actual witness. They form a nonempty subset for each occupied old region. For map, a region is occupied exactly when some occupied input region maps into it. For expose, the actual residual has one of the two enumerated emptiness values, including the case of two indistinguishable witnesses. Forget contributes the actual singleton. For refresh, the actual new predicate values are one enumerated refinement and satisfy each retained defining equation. Named identities are chosen according to their actual partition. None of these arguments requires an upper bound on concrete multiplicity. ∎

### 4.1 Newly introduced and copied route witnesses

The four operations above suffice only for a fixed witness population. The following additional finite operation is necessary even for an initially empty state.

**Extend.** A concrete step may append a finite set J of new route occurrences to its evidence history. After mapping/refining the old rows into the union input/output interface, enumerate:

1. The defined bits and equality partition of any finitely many newly named witness slots. A genuinely new witness differs from all old witness slots; explicit same-result slots share their one new identity. Old rows remain present in the union interface.
2. Every Boolean vector for each new named row satisfying the constructor's explicit immutable equations, e.g. its scope/receiver equalities, P0, source tag and named target memberships. Unknown observations receive both values.
3. For unnamed new rows, every subset N of the finitely many allowed complete vectors, including the empty subset, and set `e'_beta = e_old,beta ∨ [beta∈N]`. Exclude from the hidden population the new rows named in step 1. When finite constraints cannot relate old and new rows, retain all possibilities rather than assert a relation.
4. Project to the output interface using Forget, preserving only coordinates actually belonging to that output. Current derived predicates are refreshed where their concrete definition changed.

The number of concrete new rows need not be statically bounded. Their set of occupied vectors is a subset of a finite set. Allowing impossible counts is conservative. Named immutable equations used here must be syntactic constructor equations; none may be chosen by asking whether the output is safe or source reachable.

**Lemma 2a (witness extension).** Extend contains the abstraction of every concrete finite extension J satisfying its specified constructor equations, including extension of the empty population.

**Proof.** Choose the actual equalities and vectors of the named members of J. For unnamed members choose exactly their occupied vector set N. The actual output region is occupied precisely if an old row or an unnamed new row occupies it; this is the displayed disjunction. Every required constructor equation holds by the concrete introduction rule. Subsequent Forget and Refresh preserve representation by Lemma 2. The construction does not infer a row count from occupancy. ∎

**Fork.** A transport that constructs a new view/result route first retains the input route rows, then uses Extend for the distinct output route rows. For `view_t`, each actual input witness w produces a new output occurrence w' with the same scope/origin/protection kind and `H(w')=H(w)∪{t}`; the old w and its H remain unchanged. The finite relation enumerates a parent vector for each new named row from the existing named/occupied vectors, adds any hidden parent discriminators by Refine, and enforces only the copied coordinates actually represented. For unnamed result rows it allows every subset of vectors compatible with some represented parent. It may allow additional result rows or lose parent multiplicity; it never assumes the parent population has size one. If no represented equation applies to a route observation, Refresh it.

At unchanged current world, represented named-target memberships obey `H_k(w')=H_k(w)∨[t_k=t]`. Z may use `Z(w')=Z(w)∨(L(s(w),t)∧Match(t,s(w)))` when all operands of that equation are represented; otherwise it is refreshed. D and other route/candidate observations need their own defining equation or Refresh. Exact alias transport that really returns the same route uses Map instead. Projection selects the actual component's parent candidates; unknown selection keeps all candidates. No two unequal route occurrences are identified by a shared event ID.

**Lemma 2b (route construction).** Fork includes every finite concrete route-copy/view/projection result satisfying those actual parent/child equations, while preserving independently retained input routes.

**Proof.** For each concrete new route choose its actual parent's vector and concrete discriminators. That choice occurs in the finite enumeration. Its immutable copied coordinates and known H equation match, and its current derived coordinates are allowed by the stated equation or Refresh. Choose the occupied new-vector set and apply Lemma 2a. Old rows have not been replaced. In particular old H=∅, new H={t}, and L(s,t)=1 yield two rows with Z=0 and Z=1, respectively, rather than one contradictory row. ∎

The row-producing constructors in the candidate are now classified explicitly: actual protection introduction at receipt/upper-use uses Extend; reservation of an unused receipt key has no witness insertion; fresh View, source structural transport and `view_t` use Fork when they produce route occurrences; emission creates a fresh event register and uses Fork/Extend for the finite union of its actual observed routes; new grant evidence uses ordinary fresh named evidence and its defining scalar observations. Release history updates and raw resume do not recreate old protection. Source F-Owner/lookup may select an existing route (Expose/Map) or produce a transported result (Fork); they cannot use Map to manufacture an absent row. Unknown source constructors remain a source-correspondence obligation, not an unstated new case of Lemma 3.

### 4.2 Saved immutable evidence and the present world

An exact current cell and a saved observation of the same packet are different objects. For saved packet p, define `Imm(p)` to retain p's immutable identity, payload/response instance, source origin, saved Observe records, route identities/scopes/H, target capture tables and other immutable evidence. Its witness population is restricted to the saved packet's own fixed routes before projecting; newly created unrelated routes are not tested against an old zero occupancy bit. Its finite projection forgets **all** activity, L, Z, D, candidate-owner comparisons and grant-query truth values. Match can be retained only for the same immutable s,t endpoints. A saved control descriptor is immutable; its eventual resolved control owner is not.

**Rejoin.** Given (a) a saved finite immutable projection and (b) the current ambient/operand cell after the intervening computation, enumerate all union-interface cells whose restriction to the saved immutable coordinates is (a) and whose restriction to the current represented coordinates is (b). Preserve explicit shared-identity equations; enumerate unknown aliases consistently by sort. Extend the current columns to the saved packet's witness rows using Refine/Expose/Extend as needed to combine represented populations, or enumerate the whole finite union diagram directly. Direct enumeration is the definition: it avoids assuming that two hidden regions have disjoint populations. Only explicit finite equality/Boolean constraints are checked. Every unrepresented current query bit is unconstrained. In particular there is no equality from an old saved L bit to a current L bit, since (a) contains no L bits.

**Lemma 2c (current-world rejoin).** If p was saved in state x, the intervening finite computation reaches y while preserving p's immutable evidence, and input (b) is the current abstraction at y, then Rejoin contains `Alpha(y,p,current operands)`.

**Proof.** Its saved immutable restriction equals (a), because the intervening steps do not mutate p's evidence. Its current restriction equals (b) by definition. Actual name equalities satisfy the retained shared-identity/sort equations. The actual joint hidden-region occupancies and all unrepresented predicate values form one of the finitely enumerated union diagrams. Thus the actual cell is included. This argument assumes no stale mutable observation is retained. With saved L(s,t)=0 and current L(s,t)=1, the input's saved bit is removed; the actual output bit 1 therefore remains permitted. ∎

**World-threading rule and induction.** The graph interpretation in this revision uses a current-world port on every administrative computation. A pending frame stores only the immutable projection of its packet. Child execution connects its current-world output to the parent's next current-world input. On No, read or resume, insert Rejoin before refreshing/testing the pending candidate. Enter/leave and crossing transform this current port atomically. A saved continuation stores code/evidence, not a current-world port value to restore.

For every finite number n of intervening steps, the current-world input is represented: n=0 uses the save-time current seed; the successor case uses the immediately previous step's local relation and the ordinary closure edge. At the return to a pending frame, apply Lemma 2c. This is a simultaneous prefix induction with local simulation, not an assumption that a future actual joint cell appears without a producing edge. No-copying of immutable evidence is checked directly for each action below. This **defines the revised graph interpretation**. A preexisting certificate lacking these current-world/Rejoin edges is not thereby repaired or certified.

**Selective-release example.** Suppose two hidden witnesses w1,w2 have identical old displayed vector, P0=A=D=1 and Z=0. Their scopes are distinct and a crossing selects only s(w1). Introduce a discriminator `U(w)` for the actual selected scope/target/route condition before updating. Refinement permits both U=1 and U=0 regions to be occupied. The actual state chooses both. At fixed activity and with the relevant target carried by each tested witness, `Z'=Z∨U`; the output contains one released and one protected region, hence P'=1. Mapping the old region uniformly to Z'=1 would incorrectly make P'=0. Even a single scope can have differently targeted route witnesses, so the discriminator must include each witness's H, not scope alone.

For general R-Cross, use `U(w) = ∃s,t. s=s(w) ∧ (s,t) is newly added ∧ t∈H'(w) ∧ Match(t,s)` and the unchanged L facts, or simply Refresh Z when this finite interface cannot express the equation. H' must include the delimiter's new transported target where appropriate. The concrete U is a finite query; the abstract relation introduces U by Refine, not by solving hidden reachability. For known named `(s,t)`, use the exact equation `L'(s,t)=L(s,t)∨[t=t_frame ∧ s∈Scopes(q) ∧ From_s(q) ∧ Match(t,s) ∧ Act(r(s))]`. Unrepresented conjuncts are fresh finite observation bits. Joint scope consistency may be lost, producing extra states; actual successor inclusion remains proved.

**Binary-incidence obstruction to an exact quotient.** Let hidden scopes a,b and targets x,y have no represented endpoint distinguishing them. Two finite structures may agree on every existing unary occupancy/marginal: L1={(a,x),(b,y)} and L2={(a,y),(b,x)}. A later witness with scope a and H={x}, with active receiver and Match true, has Z=1 in the first and Z=0 in the second. Therefore old unary diagrams do not determine future query answers. Naming/exposing x must refine the joint observations, not recover a unique answer from the old quotient. This is an information-loss countermodel, not a source-qualified counterexample: reachability of both structures by the approved source constructors is not proved here.
