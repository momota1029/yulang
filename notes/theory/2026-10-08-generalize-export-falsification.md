## 1. Objective and result

Attack the bridge from a generalized component to a transformed public export
used twice, without repeating the committed capture, marginalization,
binder-exchange, same-copy or premature-publication countermodels. The distinct
mutation is **opening a new component frame when an invocation returns an
internal recursive peer**. It can preserve both raw closure identities and
freshness between incoming uses while breaking the original description
incidence within each use.

The selected native source rules already determine the relevant incidence:
for `my f x=g; my g y=f`, one incoming frame `i` has the result path
`F_f[i] -> F_g[i] -> F_f[i]`. A second independent incoming frame `k` has
its own path, `F_f[k] -> F_g[k] -> F_f[k]`, with the same actual closures.
A bare Name/Result on the returned peer does not introduce another source
instantiation event. The shortcut `F_f[i] -> F_g[j] -> F_f[j]`, without a
source instantiation/checking rule or lawful equivalent transformation,
therefore cannot receive the selected exact source-allocation certificate.

This is a source-rule certificate discriminator, not a source-admitted
acceptance counterexample or a proof that every public representation must
expose frame keys. No concrete independently admitted returning challenge,
complete descriptor assignment and transformed-root query have been supplied
for a separating client. Section 5 names that precise remaining premise and
stops there. Native source Generalize and its eligibility theorem are already
selected at this baseline; they are not missing suppliers to reopen.

## 3. Explicit hypotheses and claim classes

Fix the exact bare pair, one original binder tree, joint `xi=(nu,K,D)`, the
selected Pure/Value roles, actual closures `v_f,v_g`, and their installed
world. Let `A_x,A_y` be the two ordinary description declarations. Write
`F_f[i],F_g[i]` for the complete source descriptions in incoming frame `i`.
This notation includes all independent guards, scopes, incidence and
background/member conjuncts; it is not merely a printed arrow.

The following premises have different statuses:

1. **Established selected source rule:** a genuine source event
   `new(p_f,i,f)` opens one whole component frame. Its internal references,
   aliases and source Name/Result occurrences use that frame. No external
   Established dependency in the bare pair fixes `A_x,A_y`. Selection of a
   result interface does not introduce a new event by itself.
2. **Conditional semantic instance:** actual original registration/guard,
   primitive, world, lifetime and CompleteMem/KV inputs satisfy the source
   theorem's genuine L1–L5 premises at the chosen assignments. Source syntax,
   truth of a transport law and names of these predicates do not prove this.
3. **Conditional returning development:** for the two calls used below,
   independently formed whole challenges are admitted and designated argument
   Force returns. Receipt, rebind and invocation return have their actual
   current-world witnesses. A nonreturning challenge is still admitted when
   its independent contract permits it, but supplies no returned-peer path.
4. **Mutation under attack:** the decoder opens `j != i` for a returned
   Internal peer, changes its eligible description operands, omits residual
   glue to `i`, and supplies no independent checking, specialization,
   conversion or genuine source `new` rule at that point. It claims this is
   an exact equivalent use of the original generalized relation.
5. **Unprovided public supplier:** a complete ordinary transformed-root
   formation, exhaustive production interpretation and active finite
   actual-root query rule. The source path below establishes none of them.

The finite derivation in §4 is conditional on (2)–(3), uses the established
rule in (1), and rejects the certificate claimed in (4). An observable
acceptance separation additionally needs (5) and a lawful distinguishing
client. No stronger theorem about every public view follows. In particular,
an explicitly justified weaker result view is allowed by the selected source
checking rules and is not the shortcut in (4).

## 4. Minimized returned-peer derivation

The source's complete simultaneous relation has the selected result legs

```text
F_f[i] = Strict(I_x[i], x:A_x[i], Comp(empty,F_g[i]), IF_f[i])
F_g[i] = Strict(I_y[i], y:A_y[i], Comp(empty,F_f[i]), IF_g[i]).
```

These equations describe body result ports. Complete invocation still
includes Value entry and all argument effects, pending prefixes, current
configuration and future developments. Neither equation deletes that entry.

Begin at the actual final root selected by `new(p_f,i,f)`. After an
independently admitted returning invocation of `v_f`, the source occurrence
`Name(g)` restricts the existing original peer certificate in frame `i`.
`Result(Name(g))` and invocation return preserve that same returned provider
and source description incidence. The result is `v_g` at `F_g[i]`, in the
actual returned configuration. Bind in a client can name this returned
monomorphic result; it creates no additional source instantiation event.

After an independently admitted returning invocation of that result, its
body occurrence `Name(f)` similarly restricts `F_f[i]`. Return/Bind preserve
that same incidence. Thus two result legs return to the starting description
frame. The same derivation applies to the other independent incoming event:

| Start event | Before a completed call | After first return | After second return |
| --- | --- | --- | --- |
| `new(p_f,i,f)` | `F_f[i]` | `F_g[i]` | `F_f[i]` |
| `new(p_f,k,f)`, `k != i` | `F_f[k]` | `F_g[k]` | `F_f[k]` |

There are six hand-inspected path positions, two independently allocated
frames and two future result legs per path. Independent frames can carry
different lawful description assignments while retaining the same actual
providers. Both `A_x[i]` and `A_y[i]` are in frame `i`; no rule sets
`A_x[i]=A_y[i]`. A direct genuine use of separately published `g` can open
another frame: that is a different source use from the returned `g` above.

Now mutate only the first returned-peer step. Let it use `F_g[j]` from a
fresh component copy, keeping actual provider `v_g` but omitting the original
description incidence/residual. The next unmodified internal result step
returns `F_f[j]`. The return path is now

```text
F_f[i] --same actual v_g, wrongly new description frame--> F_g[j]
       --internal result--> F_f[j],              j != i.
```

The source allocation rule routes that peer edge to `i`, not `j`. Its
Name/Result/Bind derivation contains no `new`, and no actual check/adapter
proof justifies replacing the result by another description. Therefore the
mutated edge has no justification from those exact source rules. A complete
finite map cannot assign the original Internal edge both target incidences
without a supplied equivalence/checking bridge. Distinct numeral names are
not themselves an observable error; the error is omission of the common
dependent operands and justification when opening the new frame.

This strengthens the older uninhabited diagonal-root model in a different
direction: the original source occurrence and owning rules now identify
*where* correlation must be retained in a selected recursive source. It
does not assign that pair the arbitrary diagonal bit relation used in the
older model, nor substitute shape equality for complete formation.

Minimality is relative to this selected two-member route. One returned leg
exposes a frame drift; two revisit the same member and expose the round-trip
incidence directly. Two incoming events are enough to distinguish permissible
inter-frame freshness from impermissible intra-frame regeneration. A
one-member self-returning source could be syntactically smaller, but its
independent local recursive-introduction instance is outside the exact
selected two-member witness here. No global smallest-source claim is made.

## 5. What prevents an acceptance counterexample

The proof above rejects an unjustified source-allocation shortcut. It does
not establish that the mutated public export accepts a concrete unsound
program. To do that, supply all of the following at the same original tuple:

- Two lawful complete description choices whose relevant admission/result
  distinction survives the actual public projection, with genuine local
  guards and primitive/world laws. Merely assigning different endpoint
  labels or two Boolean values establishes no such descriptions.
- Independently typed returning carriers and a well-scoped client after the
  returned peer, with a constraint/check whose derivation distinguishes the
  original joint frame from the unglued one. The client must keep the actual
  provider and current configurations, and require the relevant correlation
  rather than accept a lawful weaker result view.
- Complete active clauses and actual-root finite query evidence at the
  transformed export, including all independently licensed Option 2 arms.
  A successful query at a hidden source root supplies none of this evidence.

The D0 and actual-root fragment are explicitly nonrecursive and conditional
on complete operands. They do not provide these three items. The selected
native recursive interface retains independent background/guard inputs; it
does not instantiate arbitrary complete parameter choices merely because its
source graph is finite. Thus no actual separating source/client instance is
proved here. This is the precise legality/formation blocker for upgrading
the path discriminator to an acceptance counterexample.

The assigned broader shortcuts have these bounded dispositions:

| Shortcut | Existing evidence and remaining obligation |
| --- | --- |
| Independent per-root exports erase the joint SCC relation | Prior reviewed structural covariance witness; selected native §5.3 now identifies the whole pair's source relation. Separate accessors retaining that relation survive. No new marginal probe. |
| Fixed imports or transitive dependencies disappear | D0 §3.1 and native §5.1 require the complete public/fixed dependency closure. Existing import attacks remain conditional on actual complete import/admission suppliers. No invented provider pair. |
| Per-field freshening or same fresh copy for independent uses | Prior reviewed splitting/isolation controls; native §5.2 determines whole-frame and alias incidence. Returned-peer regeneration above can fail even when these simpler controls pass. |
| Original entry, pending/latent/history/evidence/future fields disappear | Existing entry and complete-root attacks; here both returning steps require complete entry and current-world Return/Bind. Pending/nonreturning paths retain their independent obligations and are not replaced by a successful-return domain. |
| A member becomes visible before complete closure | Prior two-member failure trace; charter preserves logical all-member visibility, allowing internal staging. No compiler interleaving is invented. |
| Hidden source query is used for transformed-root acceptance | Prior actual-root discriminator and H1–H7 suppliers; query must be formed and accepted at the actual transformed root. No new resolver toy model. |

transition checker would leave the complete lawful descriptions, challenge
formation and actual public query suppliers untouched. The next evidence must

## 6. Independence, coverage and resource limits

There is no executable oracle, semantic enumeration, randomized seed or
mutation execution. The finite hand trace covers the six positions in §4
and one explicit returned-peer mutation. It derives the correct routing from
the independently selected source rules; it does not derive their L1–L5
semantic laws. Its conditional calling argument shares those original entry,
Name, Result, Bind and recursive constructor premises. An evaluator supplied
with the same rules would check their consistency, not prove their source
meaning or the existence of the missing challenge/descriptor witnesses.

Failure or inapplicability conditions: a genuine new publication/instantiation
event at the peer; independently justified same-value checking or an actual
adapter/specialization; an equivalent encoding retaining the same dependent
relation despite different keys; nonreturning entry; missing original guards;
or a public contract explicitly allowed to widen the result. The mutation
claims exact equivalent transport and excludes the first three justifications.
Correct transforms may encode correlation without exposing source/frame IDs
or retaining the full source relation under another name.

Omitted scope: actual parser/HIR/solver execution, a concrete admitted client,
general recursive SCCs, State, nonidentity public resolution, complete
production licenses, import-summary sufficiency, resource representation and
full principality. Reads were bounded documentary inspections, not an
exhaustive repository supplier search. Two aggregate outputs were truncated;
the operative source Generalize, native recursive, architecture, D0 and
actual-root windows were read again in narrower slices. No conclusion uses
an omitted portion of a truncated read.

No numeric CPU/RAM/wall-time allocation was supplied. Work used lightweight
read/hash/document-write commands and no heavyweight processes, tests,
