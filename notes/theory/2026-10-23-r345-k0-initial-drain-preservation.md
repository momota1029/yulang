## A. Four-port equivalence in the existing algebra

For finite Value terms and finite Effect values,

```text
Fun(A,EA,ER,B) ≤V Fun(A',EA',ER',B')
 iff A' ≤V A ∧ EA' ⊆ EA ∧ ER ⊆ ER' ∧ B ≤V B'.                 (F)
```

The reverse implication is exactly R336's Function rule. Here is a derivation
of the forward implication; it is not an extra inversion axiom.

Define a result-value map on finite Value syntax by sending a Function term
to its raw result argument B, extending over joins/meets homomorphically,
and sending bottom/top to bottom/top. Send every base atom or free variable
to bottom (any fixed choice works). Induct on a derivation of the least
preorder. Reflexivity/transitivity and every bounded-lattice rule are
preserved. On a Function-variance inference, the images are exactly B and
B', and its result premise already gives B ≤V B'. Thus the map is monotone.
It sends the displayed Function comparison to its result inequality.

For argument Value, send a Function to its raw A, exchange joins with meets,
send bottom to top and top to bottom, and assign arbitrary fixed images to
atoms/variables. The same derivation induction proves **antitonicity**: each
lattice rule is reversed, and the Function inference supplies A' ≤V A.

For the two Effect coordinates use the auxiliary lattice P(Ω), with union,
intersection, empty and Ω. The covariant map sends Function to ER and
preserves lattice operations; the contravariant map sends Function to EA
and reverses them. The same proof gives ER ⊆ ER' and EA' ⊆ EA. P(Ω) is only
a codomain for these proof maps; Ω need not be finite, and no infinite Effect
assignment or new native endpoint is admitted. All actual Effect ports and
row assignments remain finite. These maps establish (F) for the original
least preorder, including Function comparisons proved through intermediate
joins/meets/transitivity. No assumption of a special syntax-directed proof
of the Function comparison is needed.

**Application to D2.** Adding all four actual dispatch children while the
parent is retained adds only consequences by (F). Conversely, all four
children imply their actual parent. This covers both directions needed at
Function construction and at removal of the parent current item.
