## Hypotheses and exact conditional result

Write `G_L(rho,a)` for PG-1's complete projection kernel, with actual source
role, entry, receiver, consumer, provider, admission, residual and binder tree.
Use `D_R` and `M_R` for the designated root's active complete admission and
membership predicates, including descriptor membership and every alternative.

The useful sufficient hypotheses are distinct:

1. **Source reconstruction.** A separately derived PG-1 view `V` retains the
   same original semantic imports/captures `rho`, complete non-value kernel
   and original scopes; parameter registration uses legal endpoint term `T`.
   Parameter/Name/Result/ordered Bind then reconstruct `G_L(rho,T)` with the
   view's own scoped witnesses. This is PG-1's existing bounded result.
2. **Actual export correspondence and admission.** The actual source
   Generalize event is independently admissible and exports a designated
   root `R_L` exposing exactly that complete kernel after one legal whole
   freshening/graft, with eligible `a`, fixed `rho`, original binder positions
   and applicable transport laws. It must not silently export a replacement
   common bound, a result-value root or an explanatory source label instead.
3. **Actual comparison law.** The ordinary resolver for these actual complete
   roots accepts the scope-admitted finite identity/congruence certificate
   and whole Function introduction of source-contracts §5.3, or an independently
   established equivalent local reflexivity law. Every introduced/derived
   comparison passes its existing generation-time guard. This is a local
   premise; no general concrete-success transitivity or resolver completeness
   is needed.

Under (1)–(3), take any assignment satisfying the independently formed
complete client relation `C_V`. PG-1 reconstructs the source kernel at `T`
with one coherent original-scope strategy. The legal whole action in (2)
aligns every operand of its designated root with `R_V`, including non-child
operands and original primitive contracts. Thus, under that single action,

```text
Eq(D_(R_L^fresh), D_(R_V))
Eq(M_(R_L^fresh), M_(R_V)).
```

These equations are proved by identity at original leaves and constructor
congruence, retaining the same binder in the same position; they are not an
extensional oracle invocation. Use Eq as Le for complete membership, then
the same-head/role/entry/consumer whole Function rule in (3). This yields
`Direct(R_L^fresh,R_V)` at the designated export and supplies PG-1 §4.1's
remaining query conjunct for this aligned class. Keep `C_V` conjoined to the
same tuple throughout; no separately chosen per-conjunct witness is used.

The inference stops at its explicit premises. (1) does not prove (2).
Source-contracts §5.3 proves soundness of the supplied local certificate
calculus; its conditional status does not establish (3) for the existing
compiler or for an independently fixed resolver interpretation.

The weakest semantic comparison premises are inclusion of the checked
admission domain in the actual domain and inclusion of all actual observations
on each checked-admitted fiber. Complete root equality is stronger but offers
a finite constructor proof. For *reflexivity*, the extra operational premise
is only a guarded local identity rule at an already formed actual root. For
*congruence*, it is additionally a certified common whole-operand action;
matching printed constructors is insufficient. Generalize admissibility and
actual export correspondence remain separate source premises even if this
local comparison law is granted.

## Minimized syntax-only countermodel

Consider the same printed constructor skeleton

```text
Lambda(Value(a), Result(Name(x)))
Formal(x)=a; Name(x)=a; Result(Name(x))=a.
```

Hold actual role/entry, body, endpoint, scope position and one observation
fixed. Let the original admission operand be a token `r` with two possible
interpretations; this operand is deliberately absent from the printed
skeleton. There is one complete carrier challenge `h` and one complete
observation `o`:

```text
D_r = {h} if r=1, otherwise empty
M_r(h,o) = true                     (same constructor/member clause)
DescMem(o) = true.
```

For source root `A=Root(r=0)` and target root `B=Root(r=1)`, all displayed
endpoint equations and constructor tags match, but `D_B={h}` is not included
in `D_A=empty`. The necessary complete Function admission condition fails.
Identity or constructor congruence cannot equate the changed original `r`
operand. This model needs only two distinguishable admission tokens, one
challenge and one observation; with no challenge, the failed domain inclusion
cannot be witnessed. It involves no projection, hiding, copied-use aliasing
or exchange of quantifiers.

This is a **structural countermodel** to “same constructor syntax and endpoint
equations imply complete Direct”. It is not a Yulang-admitted counterexample:
the changed active admission operand violates PG-1 §3.1's complete kernel
alignment. No independent source rule or full primitive/world package has
been constructed that admits both roots as views of the same fixed source
tuple. The token is not a proposed Yulang permission or new descriptor field.

Changing a proof witness for the *same* original predicate is different.
If both witnesses satisfy the same scoped predicate at the same complete
tuple and no active primitive treats their proof identity as an operand,
the roots denote the same relation; different derivation trees do not defeat
reflexivity. If a certificate's identity, world or scope is an active operand,
that operand must also be transported and matched. Alpha-related binder
names require one legal scope-preserving action, not a demand that every
independent proof allocate the same textual name. Same scopes/operators and
same complete tuple guarantee equality in the generic active interpretation;
there is no countermodel to equality under those exact premises.

## Coverage, independence, failure and stopping condition

No solver/Oracle is used as an oracle, and no executable transition checker
is presented. The hand denotation uses independently stipulated finite sets
to refute a syntax-only implication; it shares the generic active relation
and complete Function necessary condition with the conditional derivation.
It validates neither Yulang's primitive transition rules nor the emitted
source admission rules. The equality derivation uses supplied constructor
interpretations/transport; its logical identity case is independent of any
inference success but not independent of those interpretation hypotheses.

Coverage: one nonrecursive projection/alias family and one 2-token/1-challenge/
1-observation structural model. No randomized seed or search range. No finite
enumeration, operational run, parser/production acceptance check, builds,
tests, recursive-type/State/method search or enumeration of production extras.
Memory, CPU and research wall time were not instrumented. This assignment
specified a bounded hand model without numeric resource limits; local work
used sequential read/bookkeeping processes and no heavyweight process.

Failure of the conditional conclusion occurs if the actual source event lacks
the independent Generalize/admission certificate, exports another root,
changes an active operand/scope or loses a legal transport law, or if the
actual resolver lacks the guarded local identity rule. A view that is merely
semantically sound after widening a result or changing an admission contract
may be legal yet lies beyond this equality proof; its nonidentity query stays
open. This note establishes no lack of natural source generalization.

Further Boolean variants would leave the same source and resolver premises
untouched. Recommended next action: obtain from the owning Generalize
constructor one independently justified complete admissible export certificate
for ordinary `id`, with its actual designated root, then establish that root's
guarded whole identity query. Keep source admission and resolver adoption as
two separately evidenced obligations.
