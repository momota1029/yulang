## D0: source domain and independent judgment

Let `ValidK0(s)` mean one authentic nonrecursive definition body with empty
outer environment, ordinary candidate mode and selected-definition runtime
entry. Here ordinary means `CandidateInference::solve` calls
`solve_mode(hir, false, false)` and the ordinary collector uses
`candidate_values=true` and `candidate_graph_effects=true`; scoped and operation-v1
entry points are excluded (`shadow_apply.rs:1584-1585, 1823-1824`). Its expression
tree contains only Unit, Bool, decoder-valid canonical
ASCII decimal Integer, decoder-valid source String, parameter Name resolving
to an enclosing simple Value Lambda binder, annotation-free single-binder
Value Lambda, Apply, else-complete If, Group, and binding-free Block or
StatementBlock. StatementBlock may contain expression statements and a final
expression. `LocalSourceForm::DecodedString` is present in the carrier, but its
authentic owner is an interpolation text piece and interpolation is excluded;
it therefore supplies no standalone K0 constructor case. There are no root
parameters, annotations, `where` clauses, imports, external module
dependencies, additional definitions, local bindings, recursion, unit/record
formals, defaults, operators, interpolation, Case, Catch, records, tuples,
variants, members/roles, operations/handlers or Comp formals. The membership
facts come from authentic HIR/source identities; recovery and unknown forms
fail closed.

### Fixed K0 algebra

Value expressions are finite terms generated by type variables `α`, `⊥V`,
`⊤V`, the atoms `Unit`, `Bool`, `Int`, `String`, finite joins `τ₁ ∨ τ₂`, finite
meets `τ₁ ∧ τ₂`, and `Fun(A, EA, ER, B)` in the four-port order
`(argument value, argument effect, return effect, result value)`. There are no
recursive type terms or record compatibility operations. Define `≤V` as the
least preorder on these terms containing reflexivity/transitivity, the bounded
lattice rules (`⊥V ≤V τ ≤V ⊤V`; each join injection is below its join, and a
join is below every common upper bound; each meet is below both components,
and every common lower bound is below their meet; distinct base atoms have no
additional comparison rule), and the Function variance rule

```text
A' ≤V A   EA' ≤E EA   ER ≤E ER'   B ≤V B'
────────────────────────────────────────────
Fun(A,EA,ER,B) ≤V Fun(A',EA',ER',B')
```

The algebra does not assume that two optional-record comparisons compose.
Effect values are finite subsets of a fixed universe `Ω` of effect labels,
ordered by subset inclusion. Both distinguished pure endpoints denote the
empty set: `EffectBottom = ∅ = EmptyEffect`. Thus
`EffectBottom ≤E ε ≤E EmptyEffect` fixes `ε = ∅`. K0 has no source form that
introduces an effect label; `Ω` merely makes the latent effect ports explicit.
A row assignment `ρ` maps each live Value row to a finite value term and each
Effect row to a finite subset of `Ω`. `Reifiable₀(ρ)` means exactly that every
row in the finite K0 construction receives such a finite witness. It does not
assert that every cyclic graph solution has a witness.

These are declarative proof objects, not an interpretation of Rust action
names or runtime success. In particular, `≤V` and `≤E` are fixed before
checking whether native construction succeeds. The source judgment
`Γ ⊢₀ e : τ ! ε` is independent of the collector and is closed under the
independently defined Value-subsumption rule below. It has no general Effect
subsumption rule.

| Form | Source rule premise and conclusion |
| --- | --- |
| Value subsumption | If `Γ ⊢₀ e : A ! ε` and `A ≤V B`, conclude `Γ ⊢₀ e : B ! ε` |
| literal `c` | `Atom(c) ≤V τ` and `τ ≤V Atom(c)`; `EffectBottom ≤E ε ≤E EmptyEffect`; conclude `Γ ⊢₀ c : τ ! ε` |
| parameter `x` | `Γ(x)=τ`; `EffectBottom ≤E ε ≤E EmptyEffect`; conclude `Γ ⊢₀ x : τ ! ε` |
| Value Lambda | If `Γ,x:A ⊢₀ b:B ! EB`, `EA ≤E ER`, `EB ≤E ER`, and `Fun(A,EA,ER,B) ≤V τ`, then `Γ ⊢₀ (λx.b) : τ ! ελ` where `EffectBottom ≤E ελ ≤E EmptyEffect` |
| Apply | If `Γ ⊢₀ f:F ! EF`, `Γ ⊢₀ a:A ! EA`, `F ≤V Fun(A,EA,K,R)`, `EF ≤E E`, and `K ≤E E`, then `Γ ⊢₀ f a : R ! E` |
| else-complete If | Every condition has type below Bool; each branch type is below `R`; every condition/branch effect is below `E`; conclude `Γ ⊢₀ if … : R ! E` |
| Group | If child is `A ! EA`, `A ≤V R` and `EA ≤E E`; conclude Group at `R ! E` |
| binding-free Block | Type the final expression at `A ! EA`; type each prefix expression at any value/effect; require `A ≤V R` and each evaluated effect `≤E E`; conclude block at `R ! E` |

These rules are fixed independently of the Rust action names and of whether
native construction succeeds. `Fun(A,EA,K,R)` in Apply is the same algebraic
constructor as in a Lambda type; its Function preorder gives the explicit
four-port compatibility condition, including contravariant argument and
argument-effect ports and covariant return-effect and result ports. `H(C_s)`
below is a predicate on an independently supplied assignment, not a
restatement of `Γ ⊢₀` and not a runtime judgment. Runtime meaning and actual
call safety remain D3 obligations.

## D1 statement

Let `e_s` be the unique authentic `LocalSource` body expression. Let `v_body`
be its semantic Value endpoint (`endpoints[body]`), `ε_body` its
evaluation-Effect component, and `v_root` the allocated `DefinitionValue` row.
The candidate collector separately allocates a Value component for every Name,
but a parameter Name endpoint aliases its registered formal; its unused
component is not the Name type.

Let `C_s` contain the authentic Value/Effect inequalities and four-port
relations for every K0 occurrence, together with the authentic Definition-root
Link `v_body ≤V v_root`. `H(C_s)` means every one of these constraints holds
under a single assignment `ρ` to the source components, formal rows, K0
invocation-effect rows and root Value row. `CompleteK0Construction` requires
successful authentic source collection and admission of every K0 source relation
and the root Link; it says nothing about worklist saturation or static
`CandidateInference::unresolved()`. There is no Definition-root Effect row, so
`ε_s` denotes `ε_body`.

**D1 / G-sound.**

```text
ValidK0(s) ∧ CompleteK0Construction(s,C_s)
∧ ρ ⊨ H(C_s) ∧ Reifiable₀(ρ)
  ⇒ ∅ ⊢₀ e_s : ρ(v_root) ! ρ(ε_body).
```

## D1 proof by structural induction — current derivation

Induct on the authentic `LocalSource` expression tree, with a binder
environment assigning each admitted simple Lambda parameter the type given by
`ρ` on its registered formal row. `ValidK0` excludes every source form not
listed below. `CompleteK0Construction` gives the authentic row/occurrence
crosswalk, and `ρ ⊨ H(C_s)` discharges each generated inequality.

1. **Literal.** The literal occurrence contributes both
   `Atom(c) ≤V ρ(v_c)` and `ρ(v_c) ≤V Atom(c)`, plus
   `EffectBottom ≤E ρ(ε_c) ≤E EmptyEffect`. These are exactly the literal
   source-rule premises.
2. **Parameter Name.** HIR resolution identifies a particular Lambda
   `HirParameterId`. The collector's semantic endpoint map uses the
   corresponding `CandidateEndpoint::Parameter`, so its value is the same `ρ`
   entry used by the extended binder environment. The separately allocated
   Value component for this Name is unused and is not identified with that
   formal. The Name's pure effect bounds discharge the other source premise.
3. **Value Lambda.** By induction, its body has the type/effect assigned by
   `ρ` under the environment extended with the exact formal type. The
   `LambdaRecipe` admission supplies the positive Function interface at the
   expression row and the two effect inclusions `EA ≤E ER`, `EB ≤E ER`.
   `candidate_local_lambda_effect` supplies the pure creation interval. These are exactly
   the independent Lambda-rule premises, so that rule types the Lambda at its
   result row/effect.
4. **Apply.** By induction, callee and argument have their assigned types and
   effects. The admitted negative Function demand is precisely
   `Fun(ρ(v_a),ρ(ε_a),K,ρ(v_apply))` for its fresh invocation row `K`;
   `ρ ⊨ H(C_s)` gives the callee compatibility inequality under the fixed
   four-port preorder. The two admitted
   Effect edges give `ρ(ε_f) ≤E ρ(ε_apply)` and `K ≤E ρ(ε_apply)`. The Apply
   rule concludes the required result.
5. **Else-complete If.** The source collector emits the Boolean demand for
   every condition, Value inclusion for every branch and Effect inclusion for
   every evaluated condition and branch. Satisfaction gives all premises of
   the If rule; apply it once with the parent result/effect rows.
6. **Group.** Its `CandidateRelation::Group` supplies child Value and Effect
   inclusion. The induction hypothesis types the child; the Group rule
   forwards it to the parent.
7. **Block/StatementBlock.** With no local binding, the final expression is
   typed by induction and the Group relation forwards its Value and Effect.
   Each expression statement/prefix is typed by induction and its effect is
   included in the block effect. Its value is discarded, as required by the
   block rule. There is no initializer/capture/generalization case.

The induction first gives the body expression at its semantic endpoint:
`∅ ⊢₀ e_s : ρ(v_body) ! ρ(ε_body)`. For an annotation-free K0 Definition,
the authentic source action emits `Action::Link { endpoint: endpoints[body],
target: root }` (`candidate_source.rs:2164-2165`) and its executor admits exactly
`ρ(v_body) ≤V ρ(v_root)` (`candidate_source.rs:2428-2432`). Apply the independent
Value-subsumption rule once to conclude
`∅ ⊢₀ e_s : ρ(v_root) ! ρ(ε_body)`. The root allocates no Effect component;
no effect widening or root-effect identity is claimed. This proves D1 if the
D0 algebra, source/native table and root Link are accepted as stated. It uses
no propagation-preservation claim and no runtime-success premise.

## L0 and implementation census

The source walker starts at level 1 and passes the same level through the K0
If, Apply, Group, Lambda and binding-free block children
(`candidate_source.rs:1204-1278`, `1346-1369`). There is no K0 local
initializer, so the `level+1` branch is absent. Candidate-source fresh
allocation sites in the inspected owner are: Lambda's entry/return Effect
rows, Apply's invocation Effect row, and excluded contextual-formal support.
The Apply and Lambda rows use an existing K0 expression/formal level. The
other candidate-relation allocations at `shadow_apply.rs:4052,4077` belong to
excluded wildcard Variant/Tuple patterns; operation/member scheme allocations
and FreshUse rows are outside K0. `candidate_extrusion.rs:84-178` copies only
when `original_level > target`; both are 1 here. Hence no higher-level
extrusion copy occurs, and no intrusion equality sourced from such a copy is
available. This is the L0 source/allocator argument, not a proof that all
solver operations terminate.

Ordinary default flow, absence of Allowance and context identity remain
separate audit points. `retain_inferred_entry` records Lambda evidence; it is
not itself a scope transformation. Do not turn this observation into a proof
that every generated context is identity without checking all K0 admission
paths.

## Runtime D3 locator; deliberately not S0

`RuntimeProgram::from_candidate_world` checks same-HIR candidate ownership and
candidate conflicts, then builds runtime evidence; it does not return a
typing derivation (`runtime/program.rs:315-328`). Selected definition entry is
provided by `RuntimeProgram::start`; module completion instead manufactures a
Unit value (`program.rs:376-393`, `machine.rs:2330-2370`), so K0 runtime
claims must use the selected entry.

At an actual Apply, `Frame::Callee` constructs an inert Delay from the whole
argument code and its lexical environment, obtains the executable by the
actual received value handle, and for a Value closure enters `Frame::ValueEntry`
before executing the Delay (`machine.rs:1162-1179`, `1204-1274`). This retains
the closure/environment/Delay identity required by D3. `literal.rs` accepts
ASCII digits and canonicalizes leading zeroes for integers; string decoding
can return `None` on malformed delimiters/escapes (`literal.rs:1-55`). These
are implementation locators only. No simulation or preservation theorem is
claimed here.
