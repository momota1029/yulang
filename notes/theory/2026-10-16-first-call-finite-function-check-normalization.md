## 2. What a finite Function-check inversion really gives


It retains provider/entry, whole carrier, phase, hard envelope and current
configuration. It does not return a separate marginal value or effect proof.

The finite proof may contain composition, structural checks, guarantee
weakening, constructor congruence and registered equation pairing. Its local
laws are independent; the inclusion conclusions are not oracle leaves. A
proper D_H is permitted, but the actual Unit call must remain independently
admitted. Neither nonidentity checking nor a proper domain is itself a
counterexample: a complete legal instance and all its observation premises
would still have to be constructed.

An internal check can change the checked callee interface without changing
the executable source Name or its provider. Its two endpoints and checking
position remain recorded. It cannot be erased by identifying H with F_beta,
nor can a different checking target be renamed original alpha/A1. Conversely,
an outer check above an existing Apply does not delete that Apply's retained
premises. The current native first-Apply recipe still reads the original
annotation endpoint. Thus neither "all checks are identity" nor "a checked
callee has changed source syntax" disposes of the invariant.

## 3. Changed method: use all-context reflection, not native decomposition

The previous packet stopped at the whole finite Function-check node. This
attempt tries to force the original port relations by testing that finite
proof against independently formed contexts/providers. It does **not** assume
that the proof already follows four native Function children.

To prove VIncl, fix an arbitrary complete decorated w satisfying alpha at
its original indexed position. We must derive membership of that **same** w
at A1. A natural reflection argument is:

1. Use source Name/Return to construct a computation returning that w.
2. Place it in a callable that ignores its Unit value after entry, retaining
   w as its original immutable capture.
3. Introduce that callable at the original complete annotation F_beta;
   assemble an independently admitted checked Unit challenge; instantiate
   the original finite checking derivation there.
4. Its complete Return certificate at A1 would give the required same-w
   membership, without choosing a marginal witness or altering A1.

This is a mathematical test of the universal checking proof. It is not
replacement of the actual f in the required source/native conclusion, and
is not an executable probe or a new source premise. For this argument to be
legal, every substituted object and challenge must have an independent finite
source derivation under the original target and dependencies.

### First missing rule axiom: introduce that test Return at F_beta

The next step is **not** another invocation of ReturnMem. The needed local
judgment is a finite source introduction/check of the constructed callable at
the original written target F_beta, with its original E_A/E_R and joint

- the callable's genuine role/receipt/entry and capture/reference evidence;
- admission of every carrier required by the complete target, including
  effectful, divergent and future carriers;
- every complete/pending/administrative invocation observation in
  P_beta(d), with the actual world, typed paths, K/D and hard guards;
- lawful target checking/realization at that same annotation boundary.

The available Return introduction proves only the inner Return judgment.
The source Lambda rule introduces the interface of its **actual** entry and
body; it does not introduce an arbitrary annotated complete F_beta from the
fact that its body returns an alpha member. Annotation checking still owes
its actual full target comparison/realization. Contextual membership §2 /
semantic-input §3.1 requires the final P_beta evidence for **all** admitted
challenges; it is not a rule deriving those fields from alpha membership.

This is a precise first missing local introduction law at the original
Function/annotation owner, before the attempted port reflection can be
applied. It cannot be supplied by treating a Function as four fields. The
[written inlet construction §2](2026-10-16-written-unit-arrow-inlet-construction.md)

constructs incidences and retains original contracts; it explicitly leaves

missing arbitrary-w callable introduction at this target.

There is an additional concrete reason not to postulate it: a Value-entry
constant-body lambda still forces its incoming whole carrier. Returning w
creates no request, but that entry may expose argument requests, whose
admission is governed by E_A and the complete target while its full invocation

lambda to retained entry to obtain the test. A retained-entry alternative
needs its own independently proved whole target/role check. Existence of the

### Narrowed checking domains cannot be silently replaced

Even if a test callable were introduced at F_beta, the actual check might
have D_H properly smaller than D_beta. p_D transports H challenges **into**
beta challenges, not the reverse. The full original Unit domain therefore
does not alone admit this substituted test in D_H. The finite p_D constructor
and actual checked-descriptor law must establish that admission; no inverse
domain inclusion or provider-substitution stability is assumed. This is a
later obligation of this reflection route, not a new restriction of legal
source checks.

target, and a checked challenge admitting it. That test requires an actual
operation declaration/instance, valid payload/response and continuation,

typing evidence. Row membership is not such a source introduction.

The existing RE theorem derives


It does not prove the reverse. A finite checking proof that establishes
S_p(O) subset Allow(E1) for each relevant O does not, just by that conclusion,

tight, and permission/inflow/residual/actual requests remain separate. No
uninhabited-operation or impossible-guard example is asserted here without
its real source declaration and finite proof. Since the Value reflection
already lacks its target introduction, an effect test is not presented as
an independently completed counterexample or a second solved case.
