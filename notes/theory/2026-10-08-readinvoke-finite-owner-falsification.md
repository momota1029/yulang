## 4. Call/Bind action: the precise composition premise

telescope and suspended suffix. At zero steps there is no middle value m.

```text

```


not a lawful tau_F construction without the complete domain-transfer proof.

## 5. Smallest discriminator for the weakened action implication

Consider the claim: finite original-index bookkeeping plus a well-sorted action
on that bookkeeping suffices for semantic guard preservation. The following
abstract logical discriminator refutes it. It is not a Yulang interpretation,
admitted source program, or actual original guard instance.

Fix one F, source root, binder tree, scope and all interface fields. Allow two
values of one independent original witness coordinate, `nu0` and `nu1`. Let
one independently interpreted primitive guard have the table

```text
P(nu0) = true; P(nu1) = false.
```

Take a finite initial schema whose original independent premises include
P(nu). A candidate structural map swaps these two coordinate values while
preserving the recorded constructor tags, sorts, rigid binder positions and
other projected fields. At nu0 there is a guard proof. At nu1 there is none.
Thus no total g_I0 preserving that fixed primitive can accompany the swap,
and no original initial evidence at its transported head follows. Installing
the same finite schema at both indices does not change the guard's truth.

The witness uses one guard and two coordinate values; one value cannot
distinguish source and target truth, and zero guards cannot exhibit this
failure. It needs no receiver, request, carrier execution, altered source
timing, independent overlap pair, or varied emission inventory. It targets
only the implication from structural action to semantic action.

This swap is **not** an original lawful action: the missing premise is exactly
primitive preservation. Hence it is no counterexample to §3's full conditional
theorem or to the pinned proposal's explicit lawful-action hypothesis. It
shows why a checker that admits every structurally typed swap would validate
an unjustified stronger claim. Changing the primitive to its image under the
swap would change the fixed meaning; it is not preservation in that meaning.

At the actual owner seam, the relevant potential predicates include original
import installation, world registration, hole-dependent compatibility and
admission/authority guards. The fixed-import audit identifies their independent
specifications as remaining inputs. This note does not assert that an actual
Yulang predicate has the above table or that any real lawful action violates it.
