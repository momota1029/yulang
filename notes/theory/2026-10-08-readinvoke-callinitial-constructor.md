## 1. Objective and result

Determine whether the selected original Name/Result/Delay/Bind/Call constructors
already derive the early source observation head for the fixed captured
Name/Name Call. The method is a finite formation derivation followed by an
analysis of the conclusions actually supplied by each candidate proof step.
It does not repeat the original-initial-world extraction, the forward record
proposal, or the alternative-emission-inventory comparison.

**Result:** the inner source certificate has a finite six-application formation
derivation once its actual formation origins are supplied. Those constructors
conclude `Data`, `Code` or `DelayCode`. The selected Bind equations constrain
the ordered erasure but supply no original decorated initial-observation
introduction. The selected `ReadInvoke` clause supplies a descriptor head,
and explicitly leaves `M_E` unchanged. Thus this displayed formation proof
cannot be extended to original `C-initial` using the inspected introductions.
This is bounded nonderivability in that displayed rule inventory, not a proof
that the original kernel lacks such a rule.

The smallest additional source rule needed for this case has zero executed
source-child premises: genuine Call formation and the original independent
initial input must map into the original initial observation and its evidence.
Its telescope, map and lawful joint action are owner inputs. A candidate
record does not supply their interpretation into the fixed original carrier.
Even an original source introduction must subsequently be attached to the
already fixed emitted root before it yields `M_E` there.

Claim classes:

- **Established inputs reused:** selected pure-read identity descriptor and
  retained source formation constructors, each only within its declared scope;
  no independent certification is claimed here.
- **Conditional derivation:** the exact six-application source certificate,
  under the actual formation origins in §3; the optional source/emission
  completion in §5, under additional original suppliers.
- **Bounded characterization:** conclusion sorts, phase constraints and the
  missing introduction in the listed documentary inventory.
- **Candidate assumption:** any newly specified initial constructor or native
  record interpretation. No such candidate is adopted by this note.

## 4. Why normalization does not introduce C-initial

Let **L_display** be only the explicitly displayed formation introductions in
Call-input §§3–4,7, the two original Bind equations, and the selected
ReadInvoke descriptor introduction. We do not include opaque kernel contracts
as invented inference rules. We also do not assume the conditional emission
conformance theorem's entire prerequisite as an output of these rules.

The following obstruction is syntactic, relative to L_display:

| Proposed next step | Actual supplied conclusion / premise | Missing connection |
| --- | --- | --- |
| Reuse Code-Call or Theorem S | Finite `Code(T_step,c,R_c;q_c)` with checking origins. | No original `C_c(O_0,w_0;j)` conclusion. |
| Substitute `Return(v,C) >>= S = S(v,C)` | Ordered equality at its supplied Bind operator; it uses an actual returned value/current state when interpreted as a reached phase. | No original initial-observation coordinate or evidence constructor. |
| Substitute the Request equation | Same original request/raw continuation with ordered suffix; a Request is required. | Exact Name callee has no executing Request; neither side introduces a pre-lookup initial witness. |
| Use Name/Return typing | Original returned/prefix descriptor evidence where supplied. | No original Call prefix-image map or source-base introduction follows from descriptor typing. |
| Use ReadInvoke-Desc | `DescMem(R_c,O,w;xi)`, under staged evidence and original guards. | No `C_c` or `M_E` head; §5 explicitly retains the assumed finite `M_E` derivation. |
| Use emission attachment §4 | Copy an existing original schema, with independently interpreted maps and guards, to its allocated root. | The original P.CallInitial schema and the fixed-root insertion evidence must first exist. |
| Use C-realization | Correspondence under the finite source-base conformance certificate and local typing hypotheses. | The missing constructor is part of that certificate; the theorem does not construct it from H_form. |

**Bounded head obstruction.** Induction on a proof using the displayed
formation introductions gives a formation-sort conclusion. Equality
substitution can replace an expression at that sort or in a supplied existing
judgment; it cannot introduce a new original membership assertion without an
inhabited judgment to transport. ReadInvoke-Desc introduces only the
independent descriptor sort. Consequently this particular proof inventory
contains no terminal step yielding the requested original C-initial head.

This does not assume all original primitive rules have been enumerated.
An original kernel might supply P.CallInitial outside L_display, or give a
fully decorated Bind-initial rule plus a Call image. The characterization
locates exactly where such evidence would enter. It is not a global
impossibility theorem or a countermodel to the conditional C-realization
contract. No alternative presentations E+ / E− are constructed here.

In particular, erasing a pure lookup into Return may collapse distinctions
that the full original prefix carrier retains. The equations alone say
nothing about a faithful observation/evidence lift of that collapse. The
argument uses the absence of that lift, not a guessed number of lookup
transitions or a new operational step convention.

## 5. Smallest completion and exact premise

Give the missing original independent initial input the placeholder `i0`.
This is not a definition of a `Valid0` predicate or a claim that its complete
telescope is known. Even granting a genuine original i0, one still needs:

```text
q_c : Code(T_step,c,R_c) at original j
i0  : the original independent initial input for this formation at j
---------------------------------------------------------------- [original P.CallInitial]
p0(q_c,i0) : C_c(k0(q_c,i0), original dependent witness; j)
```

Here `k0`, `p0` and their domain denote **missing original owner data**.
They are not newly selected constructors. The target observation keeps the
same initial history, live configuration, environment/world, assignment,
scopes and joint witness; the callee and whole suffix are suspended. No
actual callee Return, runtime Delay, assembled challenge, receipt, entry,
Force or returned-provider witness is a premise. The rule has zero executed
source-child premises. This is minimal in phase and source-child dependency;
minimality of the unknown dependent telescope is not claimed.

There are two possible owner suppliers:

1. An actual original direct P.CallInitial rule with its complete initial
   input and lawful observation/evidence actions.
2. An actual original Bind-initial rule on `q_f` and suspended `S`, followed
   by an original evidence-preserving Call image at c. The erased Call/Bind
   equation is insufficient to identify those decorated heads. If both
   original rules and maps are supplied, this is a finite two-step original
   source derivation; their action/compatibility laws remain required.

These are suppliers for the same selected stage, not choices of new timing.
A forward record would need an original interpretation with the same action
laws before either route can claim original `C_c` membership. Defining a new
native initial relation would instead be a candidate presentation requiring
the applicable authority and correspondence; it would not prove adoption
by a separately fixed original kernel.

**Conditional source-to-emission completion.** If route 1 or 2 is supplied,
and the actual source owner provides the matching EM-Insert certificate at
`rho(c)=E_c` with unchanged original guards/maps, copying that zero-child rule
and instantiating it with the same `(q_c,i0)` gives a one-rule membership
derivation at E_c. The source introduction and this insertion are separate
premises. This is a conditional finite construction, not the assumed desired
`M_E` conclusion as a premise. No receiver certificate or executed q_x can
replace either supplier. Option 2 membership extras cannot establish that
this original source introduction exists; their providers and laws remain
separate.
