## 3. Construct the elimination export at its actual source rule

Let `a_c` name the exact original operand occurrence of elimination `c`.
Its declared source interface is `Computation(E,A)`. Introduce no fresh type,
receiver, annotation or inference instance. Retain the original computation
effect edge and original result edge as distinct source paths:

```text
e_eff(c) = (a_c, computation.effect)
e_res(c) = (a_c, computation.result)
```

The actual designated-consumer constructor in source-interface formation
§5 retains its one-layer port and generates a return/future slot even for
latent results. Form that slot with its source result endpoint `A`. Its
projection is the following syntactic edge action:

```text
rho_c(e_res(c).q) = q
rho_c(e_eff(c))   = undefined
```

At an actual explicit-Comp receiving entry, the original formal/annotation
and outer row identify this same current computation port independently of
`A`. Receiver-relative default protection introduces the fresh original-entry
boundary at that port; the contravariant written concrete row supplies its
local permission. This is the existing RootComp source introduction with
unchanged operands: no proof step about it inspects the result's primitive
tag. Additional nested profiles come from their independent source owners in
`T`, not from this outer introduction. Thus this extraction does not silently
assume that receiving a Function result makes all nested positions protected.

Here `q` is a path of the actual result in `T` at the same assignment, not an
enumerated possible shape. The rule is generated by constructing this result
slot; no lawful-projection certificate is an input. At a symbolic endpoint,
retain the original result-edge reference with that endpoint's original
binder. At a recursive reference, retain the registered edge. Thus the rule
is finite even if its future path family is unbounded.

Retain the exact consumed packet `V_c` from the operand derivation in its
original source/input slot. An unresolved coverage dependency remains the
same dependency reference, indexed by `e_res(c)` when used by this result
slot. This restricts its target incidence; it does not invent its profile or
declare it empty. Unknown effect variables likewise retain their original
`K,D` connections rather than becoming concrete annotation atoms.

The resulting **static source output** is

```text
ElimExport(c) = (
  original source/annotation/instance/binding/port references,
  original scope and substitution references,
  V_c at its actual operand slot,
  e_eff(c), e_res(c), rho_c,
  ReturnSlot(c, z, C_z, W_z)
).
```

`z,C_z,W_z` are the already existing dependent return binders of the source
operation, below its actual execution event. They are not values chosen at
compile time or fresh unrelated existential witnesses. The slot is formed
before execution; evaluation fills it only at an actual Return. A Request
retains that slot in the same pending suffix and creates no premature `W_z`.

At an actual Return, the Result rule supplies `W_z` by *its own constructor*:
Result of a descriptor uses that descriptor's whole packet; Name uses the
actual binding certificate; Lambda/Operation uses its actual producer packet;
Bind uses the actual RHS/suffix result; Call uses that Call's actual return
slot; a selected branch or shallow arm uses its actual child result and
original checking map. An admitted conversion uses its own original map.
None chooses a profile by inspecting a returned closure tag.

Construct the result view by the already selected multi-input operation:

```text
J_z = (mu_z)*W_z union_tagged (rho_c)*V_c
```

`mu_z` is the actual Result rule's value correspondence, generated as identity
for direct Return/bind/read and retained from the original conversion rule
when nonidentity. Both inputs are now concrete source-rule operands of the
same `z`, not independent desired packets. Apply the generated actions to
`chi,D`, retain the same `K,nu`, original provider/receiver and lineage, and
keep every genuine installed/private contract at its original telescope.
Unrelated request/residual/continuation roots remain in their original graph.

This construction eliminates only the `e_eff(c)` input from this result
image. If `W_z` independently contains an incidence of the same boundary,
it survives through `mu_z`. An independently placed result contract survives
through `rho_c`. No incidence is created from equal families or merged
because witnesses have the same type endpoints.

## 4. Construct the actual callable export and later complete consumer

The full returned callable export is formed at its original producer/use,
not by traversing possible Function assignments to `A`:

```text
CallableExport(v) = (
  actual source/instance/provider decomposition Act(v,U,r),
  original typed public view and complete J_call position p_U,
  actual whole-carrier/entry/consumer interfaces of U,
  original complete-call result edge and its Result/ReturnSlot recipe
).
```

For a source Lambda, source-interface formation §5 “Producer and entry”
constructs these fields from its original parameter role, lexical references,
body/result derivation and complete invocation. Typed-core §3 constructs its
actual `ExecuteCallable` and §9 derives its complete `J_call`; the result edge
comes from that same invocation's return slot. For an operation, read the
actual declaration's native return delimiter and designated result consumer;
retain both in order. For an alias/instance, project/restrict the same actual
certificate under its original substitution; do not instantiate a second
producer or discover its entry role from the checked shape. A raw continuation
uses its original actual response-entry and saved-context operation and the
declared answer-result slot. No foreign opaque producer is given a guessed
source Lambda or operation recipe.

At the later source Call, first evaluate its original callee derivation. Its
actual return supplies `v` and the transported view `J_z`. Observe its
actual provider decomposition through that same binding certificate. The
original actual source Call then constructs

```text

     ExecuteCallable_U(Delay(X[actual argument], lexical references)))
```

and retains the complete-call Result/ReturnSlot recipe from `CallableExport`.
This is the existing typed-view constructor, now with the original source
operands made explicit; its validity is not asserted by successful native
Function comparison. For an independently typed checked Function view, use
its original lawful whole-map/port substitution and same-provider contract,
never a new producer chosen after Return.

The delimiter encloses the actual `Invoke` entry, hence starts before Value
entry's designated argument Force and before retained entry binds its carrier.
For a closure it continues through actual rebind/body/invocation return. For
an operation it continues across native return through the separate declared

inside that complete source view. Latent descendants of the resulting value
are not recursively executed.

Each fresh request therefore has `Observe(q,J_z,p_U,o)` by the existing
emission-context projection: the constructed View is a member of its actual
executing context. It does not observe every latent position at once. Actual
receipt and current receiver/handler activity are still independent source

## 5. Source proof, forwarding and repeated saved-context use

**Extraction induction.** Traverse `T` at its original rules, retaining
operand references as in §2. Name/alias/import/instance projects exactly its
existing certificate with the original substitution. Lambda/Operation
constructs §4 at the producer-owned entry/body/consumer slots. Elimination
constructs §3's two edges and return binder. Result fills that existing
return binder with its actual descriptor packet. Bind connects the exact
shared return/world to its ordered suffix. Call constructs the provider's
complete executing view and result slot. Branch/handler extraction follows
the actual selected source child and full original guards. Registered source
cycles refer to preallocated original interface nodes; they are not unfolded.
These cases construct the advertised outputs from source premises without
an extra `LawfulExport` or desired-result-packet premise.

All shared symbolic variables remain references to their original scope;
aliases retain one instance and independent source instances retain their
original instance substitution. Source-generalize §3.3 ownership is inherited
field by field: actual events/contracts remain EventField/OneShot or original
Shared/Established, logical checks remain Check/ViewLogic/EventProof. Export
does not change eligibility by adding a dependency through a logical check
or deleting a genuine fixed dependency.

**Saved contexts.** Typed-boundary's existing source context grammar already
contains `View(view,port,K)`. Retain its elimination/complete-call return-slot
recipe as an explicit projection of that same typed context. Capture retains
the exact crossed View, port, pending binds and original packet references;
an outer uncrossed View stays ambient. The selected shallow handler is absent.
Re-entry allocates only a fresh executing occurrence, beneath the current
ambient context, and uses the *same* original view/port/result recipe. It
does not allocate a receiving boundary or replay a receipt.

The saved recipe contains the dependent return binder, not an old `W_z`.
Each use fills it with that use's actual Return and current cells/world.
Thus repeated use may return different actual packets without changing the
original projection or borrowing a prior return witness. Old receiver IDs
are never passed through executable-owner remapping. New events receive
fresh Observe occurrences; candidate incidence uses the current configuration.
On a new Request, save only the still-unfinished local contexts and the same
recipes. Induction over finite source steps and finite reuse histories gives
the same result for forwarding, recapture and arbitrary finite reuse. It
asserts neither termination nor that unknown future obligations are discharged.

**Erasure.** Define erasure to delete only the new export fields, keeping
the existing decorated source packets, View/port contexts, primitive guards
and source program. Each extended rule has exactly the same original
premises and executable conclusion; the new fields are projections and
constructor edges of those premises. Return uses the preexisting typed
two-input rule. A captured recipe is the return projection of the same typed
saved context. Consequently rule-by-rule erasure is literal equality on old
operations, including source effects, typed observations, current worlds,
full contracts and pending suffixes. Induction gives equality of every finite
erased execution/development. No new Force, handler, boundary, receipt,
predicate success, challenge restriction or primitive meaning was inserted.
