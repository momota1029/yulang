# G03: 併合された一つの K2 診断を、複数の元 where のどこに表示するか

**第一案・遅延:** 診断表示は今は決めず、併合された一需要に対し、対応する全ての元 where 節の位置を宣言順のまま証拠に保存する。位置を勝手に選ばない。既存の候補選択・K2・併合・拒否は変えない。

型レベルの例（実行できるプログラムを主張するものではない）:

```yulang
impl Show (list 'a):
    where 'a: Inspect
    where 'a: Inspect
// Show (list A) を要求し、A = :tick A が ordinary の型グラフにある。
```

両方の where が同じ Inspect の同じ元の実引数 A を指すため、仕様 §6.3 の決定どおり候補選択前に一需要へ併合される。A の根の循環も両方の元位置に対応するが、親 Show の根の拒否とは違う。未決の質問は **同じ一つの K2 診断の、利用者が見る場所**だけ。
- 第一案の後、もし一箇所だけ主位置にするなら、元のどちらを主位置にするか（先頭を固定するか）。ほかの位置を関連位置として添えるか。
- または、一つの診断に両方（一般には全て）の位置を同じ立場で添えるか。
