## Parent and bounded outcome

The unchanged parent is the original Simple-sub source/native A/B objective,
with its original quantifiers, source domain, behavior, and expected outputs.
This sprint targets only the audit's **W: construct a finite model and its
reification witness from a conflict-free completed graph**. It must bring the
result back to R341's explicit `Reifiable₀` premise; it does not discharge the
whole W gate or the parent theorem.

Use exactly R336 rev4's authentic ordinary K0 source domain, finite Value
preorder, Function four-port order, and finite Effect-set algebra; R341's
occurrence-indexed `C_s`, actual-state interpretation `H₀(S)`, and
`NativeComplete₀`; and R348's reviewed correspondence only under the same
source, state, coordinate, and completion premises. `H₀(S)` is the solver
relation in those proofs. It is not the newest TeX's evidence-hole field
`H`, semantic world, `Y_H`, or complete Call relation.

The exact bounded claim is:

```text
∀ authentic s,S.
  ValidK0(s) ∧ CompleteK0Construction(s,C_s) ∧ NativeComplete₀(s,S)
    ⇒ ∃ρ ∈ Assign(R_S).
         ρ ⊨ H₀(S) ∧ Reifiable₀(ρ).
```

Here `s`, `C_s`, and `S` must be from the same actual ordinary candidate
construction. Preserve R341's definition of `NativeComplete₀`: authentic
source collection/admission has finished, target work is closed, and there
are no typing conflicts or concrete pending K0 obligations, with the same live
identities and row interpretation. It is not `solve = Ok`, an empty
`unresolved()` list, an empty public projection, or an assumed model. The
primary census must verify the precise source owners and completion predicate
against pinned code; it may not strengthen or redefine this premise to hide an
obstruction.

`Assign(R_S)` uses the fixed K0 sorts. Every Value row receives a finite term
over type variables, `⊥V`, `⊤V`, the four base atoms, finite joins/meets, and
`Fun(A,EA,ER,B)`; every Effect row receives a finite subset of the fixed
universe `Ω`. The construction must satisfy the actual directed bounds and
all live work/frame formulas in `H₀(S)`. `Reifiable₀` is the explicit
finite-witness conclusion, not an extra hypothesis.

The proof must not assume a source solution `σ ⊨ C_s`: supplying a finite
solution is the outcome. R348 only transports already-existing source
solutions to the actual native state and back; it does not establish that any
source solution exists. Do not infer finite satisfiability from finite graph
size, local conflict checks, a regular/infinite unfolding, a drained queue,
`CandidateInference::candidate_conflicts()` being empty by itself, or a
successful API return. Treat the report of no conflicts as a premise whose
ability to support this model construction is the theorem under study.

Success is either (a) a uniform constructive derivation of this implication
for every state in the exact domain, including mixed-variance Function rows,
cyclic bounds, arbitrary symbolic source Effect ports, every final auxiliary
row, and all K0 constructors; or (b) the first exact finite-carrier
obstruction, with an authentic `s`, a genuine completed conflict-free `S`,
the pinned `H₀(S)`, and a proof that no finite `ρ` can satisfy it. A cycle or
occurs-check is not a nonexistence proof. If authenticity or completion cannot
be established, report a conditional obstacle/source gap, not a compiler
counterexample.
