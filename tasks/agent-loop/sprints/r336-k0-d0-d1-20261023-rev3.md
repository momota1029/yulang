## Fixed D0 contract

Use ordinary candidate inference (`scoped=false`), one authentic, nonrecursive
definition root with an empty outer environment, and selected-definition
runtime entry. Define `ValidK0(s)` from authentic HIR/source metadata. It admits
only:

- Unit, Bool, decoder-valid canonical ASCII decimal Integer and decoder-valid
  source String literals. `DecodedString` is in the HIR carrier, but its only
  authentic owner is an interpolation text piece and interpolation is
  excluded, so it contributes no standalone K0 case;
- Name expressions resolved to a Value parameter of an enclosing simple
  Lambda;
- annotation-free Value Lambdas with a single binder, no unit or record
  pattern, and no default fields;
- Apply, else-complete If, Group, and Block/StatementBlock with no local
  bindings (a statement block may contain only expression statements and a
  final expression).

The definition has no root parameters, annotations, `where` clause, import,
module dependency, recursion or additional definition. Exclude hidden operator
lowering, interpolation, Sequence's special result rule, Case/Catch, records,
tuples, variants, members/roles, operations/handlers, and Comp formals. A
successful K0 source collection must retain authentic owner/occurrence and
parameter identity; syntax recovery or an unrecognized form is not evidence
for membership.

Fix this independent finite K0 algebra before interpreting source actions.
Value terms are finite expressions over type variables, `⊥V`, `⊤V`, `Unit`,
`Bool`, `Int`, `String`, finite joins/meets, and
`Fun(A,EA,ER,B)` in argument-value, argument-effect, return-effect,
result-value order. `≤V` is the least preorder generated by reflexivity,
transitivity, `⊥V≤V τ≤V ⊤V`, the least-upper-bound rules for joins, the
greatest-lower-bound rules for meets, no extra comparisons between distinct
base atoms, and Function variance:
`A'≤V A`, `EA'≤E EA`, `ER≤E ER'`, `B≤V B'` imply
`Fun(A,EA,ER,B)≤V Fun(A',EA',ER',B')`. Effects are finite subsets of a fixed
label universe `Ω`, ordered by inclusion, with
`EffectBottom = ∅ = EmptyEffect`; hence a pure interval forces the empty set.
No K0 source form introduces an effect label. Types are nonrecursive and have
no record operations. `Reifiable₀(ρ)` means every construction row is assigned
one of these finite value/effect witnesses; it does not claim every cyclic
graph solution is reifiable.

Fix an independent source judgment `Γ ⊢₀ e : τ ! ε` over this algebra. Add
Value subsumption: from `Γ ⊢₀ e : A ! ε` and `A ≤V B`, derive
`Γ ⊢₀ e : B ! ε`. This rule uses only the independently fixed preorder; it
is not defined by native success. There is no general Effect subsumption rule.
The remaining declarative rules are:

- a literal has a type mutually below and above its atom type, and a pure
  effect;
- a parameter Name has its binder's type and pure effect;
- a Value Lambda has a positive Function interface whose argument is the
  binder type, whose argument-effect port is included in its return-effect
  port, and whose body effect is included in that return-effect port; creating
  the Lambda is pure;
- Apply requires the callee type to be below the four-port demand formed from
  the argument's type/effect, a fresh invocation effect and the result type;
  the preorder makes argument and argument-effect ports contravariant and
  return-effect and result ports covariant; callee and invocation effects are
  included in the Apply effect;
- else-complete If requires each condition to have Bool type, every branch
  type to fit the result, and every condition/branch effect to fit the If
  effect;
- Group forwards its child type/effect; binding-free Block and StatementBlock
  forward the final expression type and include every evaluated expression's
  effect.

Interpret generated inequalities in this independently fixed algebra as
`H(C_s)`. `ρ ⊨ H(C_s)` means all generated Value/Effect and four-port
constraints hold under one row assignment; it does not mean that source
typing, runtime safety or successful execution holds. `Reifiable₀(ρ)` supplies
finite type/effect witnesses. Do not assume optional-record compatibility
laws or import runtime success into these definitions.

## Fixed D1 outcome

Produce a constructive, source-constructor-by-source-constructor proof of the
same root-output claim. Let `e_s` be the authentic body expression, `v_body`
its semantic Value endpoint, `ε_body` its evaluation-Effect component, and
`v_root` the `DefinitionValue` root row. The collector allocates an unused
Value component for a parameter Name, but its semantic endpoint is the exact
registered formal row.

```text
ValidK0(s) ∧ CompleteK0Construction(s, C_s)
∧ ρ ⊨ H(C_s) ∧ Reifiable₀(ρ)
  ⇒ ∅ ⊢₀ e_s : ρ(v_root) ! ρ(ε_body).
```

`C_s` includes the authentic Definition-root Link `v_body ≤V v_root`;
`CompleteK0Construction` requires its admission along with every initial K0
source relation and endpoint. There is no root Effect row, so preserve the body
evaluation effect in the conclusion. The constructor induction first types
`e_s` at `ρ(v_body)`, then independent Value subsumption uses the generated
root Link to type it at `ρ(v_root)`. This predicate is not defined by the static
`UNRESOLVED` list, by `solve = Ok`, or by runtime completion. If one K0
constructor, formal registration, endpoint or allocator fails to match the
independent rules, freeze that exact source/native obstruction instead of
weakening `ValidK0`.

K0, no higher-level extrusion copy is created, and therefore no extrusion-
