## Decoder construction and exact limits

All following names have prefix `YulangClosure.FormalPermissionExportWitness`.

`ValueCode`/`TupleCode` are DATA constructor instructions. `decodeMemo` inspects
the supplied State table, then constructs the existing `.hit` or `.miss` event.

proofs; Origin and Construction are neither raw inputs nor validation checks.

The `decoded_origins`, `decoded_catalog` and `observed_origins` theorem types

output certificate is not an independently authenticated native history: the
link from actual source execution to supplied instructions and initial State
is still required. No claim is made that a proposition definition or arbitrary
law parameter constructs a concrete native instance.

`delegated_allocations` constructs a SignaturePairEvent from the computed
positive call and then the computed negative call, and records each resulting
port in its own call's births. This keeps both delegated ports distinct in the
representation from the optional memoized symbolic tail. It does not prove
native fresh allocation, global counter freshness or actual bound insertion.
`parameter_row_equation` is the exact arithmetic `base + parameter`; it does
not prove Rust checked addition, conversion or the actual parameter-base mapping.
