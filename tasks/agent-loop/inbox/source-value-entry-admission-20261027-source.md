## One source-origin path and field correspondence

Chosen path: a source `Lambda` with the narrow annotated Value callback formal accepted by `CallbackResultSchema::from_parameter` (ordinary Value function whose argument is unit and whose result is `int` with a nonempty concrete effect row), then a source `Apply` selecting that closure. It is a concrete compiler path, not a claim that every source Call is covered.

1. **HIR identity and source labels — `program.rs:567–574,653–664,819–856`.** `from_hir_with_roots` selects `local_source_for(source_root)`. Its expression walk follows the Lambda body and Apply callee/argument by their `LocalSourceIndex` references. `label(index)` checks the index belongs to this source and maps it to `Label(offset + index.ordinal())`. The Lambda lowering copies `parameter.id` into `Instruction::Lambda.parameter`, computes `ParameterRole` from the source annotation's outer effect slot, and builds `callback_schema` from the original `LocalSourceParameter` plus a `SourceSite` made from the root, Lambda occurrence and source range. The Apply lowering stores the labels of its actual callee and argument. Thus the formal binder identity is `HirParameterId`; code labels point to source expressions, while the source root/occurrence/range remain on their `Code.site`.
2. **Selected provider and Closure — `machine.rs:864–898`.** Evaluating `Instruction::Lambda` allocates a `RuntimeValueKind::Closure` and an `ExecutableValue::Closure` carrying `parameter`, role, callback schema, body label, and saved lexical environment. Evaluating `Instruction::Apply` pushes `Frame::Callee { callee: Some(label), argument, environment, site: Apply Code.site }` and evaluates the callee. On return, the selected `received.value` indexes this Closure and its `RuntimeValue.source` is the provider `SourceSite`.
3. **Callee Delay, view, and invocation — `machine.rs:1181–1199,1224–1297,1780–1798`; `receiving.rs:208–222`.** Before argument code executes, `Frame::Callee` allocates a Computation Delay at the Apply site, retaining the argument label and caller environment, then creates its ordinary `delay_view`, inheriting the direct formal root when one exists (otherwise `(image=None, unknown=true)`). For the selected Closure it calls `new_invocation(Apply site, Closure RuntimeValue.source)`. The resulting invocation ordinal is both the active `ExecutionOwner::Invocation(activation)` and the `ValueEntry.entry_receiver`; the invocation descriptor stores the call and provider sites. The environment saved in the closure is substituted for dispatch, then `ValueEntry` and `ReceiverReturn` are pushed and `execute(delay)` runs the argument. This is the ordinary Closure/Value path only; other receiver kinds are outside this trace.
4. **Formal receipt timing and owner — `machine.rs:1285–1297,1438–1465`; `receiving.rs:146–163,261–279,297–335`.** For `ParameterRole::Value`, no `Receiving::Receipt` is created at invocation creation. `Frame::ValueEntry` is reached only after `execute(delay)` returns. If its callback schema exists, it checks the active invocation matches `entry_receiver`, the schema formal matches the HIR parameter and source root, and the received interface is Value. `callback_entry` validates the incoming view refers to that returned value; it appends a `CallbackEntry` view preserving incoming image/unknown fields; then creates its `formal_receipt` via `receipt(owner, view, schema.lambda, Some(schema.formal.id))`. Exact native receipt fields: owner `ExecutionOwner::Invocation(entry_receiver)`; view = the new callback-entry view; slot = source Lambda `SourceSite` (source root, occurrence, range); formal = `Some(HirParameterId)`; value = the Force-returned argument `ValueHandle`. The environment subsequently binds the same parameter ID to this returned Value and view.
