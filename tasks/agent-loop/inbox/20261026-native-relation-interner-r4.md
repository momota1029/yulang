## Construction and eliminated premise

The original immediate seam is §7 of the accepted native Value-port note:
actual ScopedFlowId/RelationKey decoding must supply the Arena's complete
relation keys and exact native IDs. The packet now constructs materialized
native flow, relation and pair-head maps, not an arbitrary full-key lookup.
Its `Native.call` reads those maps and performs the source operations in order.

`NativeHistory` starts from empty maps. Actual calls include failed outcomes;
external successful ScopeInventory work charges can interleave. Cancellation
removes the actual relation suffix in reverse, erases every complete relation
key and restores every `previous_on_pair` head. It retains current flows,
flow cache, work charge and the immutable ghost allocation clock. Map
coherence and full physical-key decoding are derived from that construction.

`native_ok_refines_arena` requires only this constructed history and the actual
call result's `.ok id`. It constructs the same output Arena and exact raw ID
as `NativeValuePorts.Arena.relation`, with intact Pair, Context, optional
sources, transformer and all five demand fields. It assumes no matching
output, map coherence, complete-key reflection or finished semantic body.

`Entry.origin` and `birth` are ghost values created by the actual allocation
input/clock. Physical decisions do not read them. The physical decoder reads
the stored RawKey and flow vector; a separate theorem proves that it recovers
the origin. Thus the provenance copy is not substituted for physical readback.
