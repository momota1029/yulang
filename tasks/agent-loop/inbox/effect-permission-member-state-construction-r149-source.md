## Inventory, collision, rollback and independent protection obligations

Source scopes and inputs are append indices (`candidate_source.rs:155–169,1870–1893`); the inventory initializes identity origins (`223–245`). Successful `fresh` appends copied images at current lengths and retains external IDs (`296–357`). For a pre-copy cut `(S,I)`, require **all** incoming protections, transformer scope support and demand scopes below S, and **all** incoming inputs, transformer stamps/predicates and demand inputs below I. The state's association must reference the same inventory/use. This is the missing combined bound, not a theorem inferred from transformer-local checks.

Conditional injection derivation: copied old IDs are distinct within each namespace; their images are at or above the corresponding cut; fixed external IDs are below the cut. Therefore copy/copy and copy/fixed collisions are impossible on the combined support, assuming valid unique region ownership and the combined bound. `ScopeTransformer::remap:214–265` checks injectivity only on its own support; it does not check the new state. IDs outside inventory must fail validation rather than silently take identity fallback. Do not compare scope and input IDs across their distinct namespaces. Member/provider identity cannot be reconstructed from equal family, origins or remapped numeric IDs.

Limits 4096 records and 65536 work (`candidate_source.rs:194–196`) are private experiment availability limits, not an adopted language envelope. New state capacity, support scans/copies, association count and retained heap require accounting and rejection before inconsistent publication; this packet chooses no new production resource limit.

`fresh` can append scopes/inputs/regions before a later fallible step fails; no completed map then returns. Do not claim allocation rollback or reuse its partial map. Existing effect checkpoints truncate views/contributions (`candidate_effect.rs:502–527,529–579`), context checkpoints revoke observations and relation-related state (`candidate_context.rs:2149–2185,2266–2282`). New association references must be invalidated consistently if those endpoints disappear, even if inventories retain consumed IDs. Exact capacity restoration is not required by inference §§4–5. Persisted caches/handles must not survive an aborted identity without a valid owner/generation.

Kernel `evaluate:178–210` preserves inherited protections absent from the transform's scope entries. `release(s)` changes only entry s (`120–127`). Under the combined injectivity premise, renaming cannot merge independent p with s. Therefore an initialized state containing p ≠ s retains p through release(s), and member identity/family is unchanged because the scope kernel does not contain effects or permission grants. This is a conditional local derivation, not proof that the actual source path initializes/preserves p or releases all compose output occurrences.

For the independent-protection mutation, use a second valid scope p ≠ s and input state `(inputs=[], protections=[s,p])`; release(s) leaves `[p]`. A single scope cannot witness independent-protection loss; two scopes are minimal for that property. These are conditional kernel witnesses, not proven jointly reachable source states for one source program.

A source trace with no state, an assumed transition model or an empty observer alone does not establish a reachable counterexample. Mutations recommended for a later authorized instrument: omit state from identity, map only transformer, initialize every observation empty, key by family, discard inherited protection, or reapply an already consumed transform.
