   both bound inputs and both parent relations. Incoming FreshUse replay sets

   conflated.

   `record_typed_pair_admission` (`lib.rs:15295–15340`) calls

   `pair_is_current` (`lib.rs:13507–13518`) reads this relation/generation guard
   together with raw pair memo presence. Therefore this map is a recursion/
   duplicate-processing guard; it is not a returned-child or semantic-success
   certificate. An invariant equating it with abstract `Owner.completed` is
   false already during an ordinary structured dispatch.
4. A queued child has an actual owner. Replay `queued` and `consumed` are
   separate cursors; `transfer_replay_child` and
   `prepare_replay_child_completion` enforce their bounds
   (`candidate_context.rs:2369–2427`). `complete_replay_child` requires
   `consumed == ack.index`. `prepare_replay_return` requires the exact waiting

   derivation can retain its event without requiring production history.
6. Canonicalization scans the frozen original incidence prefix at *all* owners,
   including third owners (`candidate_context.rs:4230–4254`). It retains

7. Context rollback (`candidate_context.rs:2081–2173`) restores drain frames,

not completed. Any proposed refinement that labels it completed fails.
