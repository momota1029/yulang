## Finding

The local proposed cycle survives the actual one-sided row rule. `B <: N`
stores N on B.upper, while B stays high. Replaying B.lower `F(B,B)` therefore
creates the next structural-to-low-row demand. There is a required intermediate
step: a rewritten `F(N,P)` propagated through the receiver's upper A must be
extruded unchanged into A before meeting A's retained high upper `F(B,B)`.
Both ports are already level 0, so the unchanged step has the needed shape.

The new Lean certificate derives newer-copy production from individual cut,
Function, selected-bound-copy, one-sided row admission, unchanged-extrusion and
freshness laws. It does not assume a universal successor-production law.

The strongest remaining native objection is the scalar/fiber gap:
`candidate_context_begin_replay` enumerates actual bound-origin fibers and
memoized dependency products. Scalar lower/upper membership alone is not
native completed-cut closure. Function port admission also carries scoped
guards which can reject. No theorem in this packet authenticates those
histories or rules out availability failure.

Pending qualified copies do not immediately merge. Both actual production
settlement call sites require the drain's no-current-item / empty-worklist
boundary. A valid application should examine the FIRST later settlement
frontier, prove the finite prefix there is closed, and derive contradiction.
It should not assume B stays high after arbitrary later settlements or
silently require every later copy occurrence to be unqualified.
