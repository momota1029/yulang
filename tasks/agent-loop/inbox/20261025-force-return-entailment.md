## Conditional derivation from an explicit local constructor

Let `P_A` be all finite tagged typed paths of the retained actual result
instance. This set may be infinite for recursive types. Its effect subset is
`Eff(P_A)`; dependency incidences may use other typed paths too. Define the
typed embedding `k(p)=force.result · p` into `t`'s signature. Its existence
and agreement with the retained descriptor are source obligations; equal
type nodes/family names alone do not establish matching tagged paths.

The precise additional premise **LOCAL-LEAVE** is:

- One fresh output occurrence `o : A` is created, different from every
  occurrence in `G`, with the same underlying actual result as `r`.
- The leave's local Flow batch consists exactly of the following two indexed
  source correspondences into `o`, and no other incoming correspondence:
  `I_A={(p,p) | p in P_A}` from actual result `r`, and
  `D_A={(k(p),p) | p in P_A}` from actual operand `t`.
- All pre-leave Flow rows are preserved. This local batch creates no
  outgoing row from `o`, no new boundary/receipt/event/Observe and no new
  inherited evidence identity. Ambient restoration is performed separately.

This is a candidate constructor premise, **not** a rule inferred by naming
the desired FR-ROUTE. It records allocation, actual inputs, exhaustive
domains and permitted local changes before the route conclusion is used.
It permits coincident old occurrences if the retained typing licenses them;
it does not require an unjustified `t != r`. The source indices and ports
remain explicit even in that case.

Its primitive domains/images are determined without path enumeration:

| Correspondence | Domain | Image | Primitive template |
|---|---|---|---|
| `I_A`, actual result | `P_A` | `P_A` | identity prefix replacement, typed to `A` |
| `D_A`, operand result | `{force.result · p | p in P_A}` | `P_A` | remove the fixed `force.result` prefix, preserving `p` |

For profile incidence, restrict these domains/images to the corresponding
effect-path subsets; do not extend `chi` to non-effect roots. For dependency
incidence, use its own typed path domain. A finite template denotes each
relation even when its recognized finite paths form an infinite set.
The batch allocates one local output interface, not two intermediate
occurrences; this count follows from LOCAL-LEAVE only and is not claimed as
the paper's independently established allocation count.

Write `F_G(x,a;y,b)` for the recorded Flow closure, including the zero-length
identity route. Let `G'` be the local extension above. For every old endpoint
`(x,a)` and every `p in P_A`, LOCAL-LEAVE implies

```text
F_G'(x,a; o,p)
  iff F_G(x,a; r,p) or F_G(x,a; t,force.result · p).
```

**Forward derivation.** Since `x` is old and `o` fresh, a route from `x` to
`o` is nonempty. Its last local edge is incoming to `o`. By exhaustiveness
it is either the `r` edge with `I_A`, or the `t` edge with `D_A`. Membership
of the first relation forces the predecessor port to be `p`; membership of
the second forces it to be `k(p)`. The preceding route uses only `G`: the
only fresh occurrence is `o`, and it has no outgoing edge in this extension.
This gives exactly one of the two right-hand witnesses.

**Reverse derivation.** Append the `r` identity edge to the first old route,
or the `t` result-prefix-removal edge to the second. The occurrence and
intermediate port agree exactly, so either is a route in `G'`. Empty old
routes are allowed when the old endpoint already is the appropriate source.

This is a graph-cut proof from LOCAL-LEAVE, not a checker which assumes
source transitions and then calls their execution a proof. It covers every
finite suffix symbolically and uses no depth bound or unfolding of nominal
types. The fixed-prefix form is compatible with the paper's primitive
template restriction. It adds no route from an unrelated raw-equal alias.

The candidate §6 image equation gives, for each applicable `p,b`,

```text
chi_o(p,b) iff chi_r(p,b) or chi_t(force.result · p,b).
```

The analogous dependency formula keeps its original predicate identity.
This follows by expanding the two relational images. It concerns persistent
incidence, not current protection/grant: activity and the actual later
Observe/Receive witnesses are still required. A formula about `chi` alone
does not imply the stronger Flow* biconditional for **every old endpoint**;
the latter used the exact local row batch and its exhaustiveness.

## Returned-thunk discriminator and limits of the attack

Take a retained result type `A=U(E2,B)` and operand type `U(E1,A)`. Its
smallest relevant latent suffix is `p=force.effect`; the corresponding
operand path is exactly `force.result.force.effect`. Under LOCAL-LEAVE an
existing route to either `(r,force.effect)` or
`(t,force.result.force.effect)` reaches `(o,force.effect)`. A route only to
`(t,force.effect)` does not reach that output through `D_A`. The result
thunk is not executed during this transport. A later force introduces its
own executing View and observations in the then-current activity/handler
context. A ground-result example would not exercise this distinction.

This is a symbolic discriminator for the conditional equation, not a
source-admitted counterexample. Removing the operand-result row, losing the
actual-result row, shortening the suffix, adding an unrelated alias row or
reusing an old output violates LOCAL-LEAVE. These are logical failure
conditions; none was executed, and no mutated system is asserted to satisfy
all accepted source clauses.

I did not construct two full interpretations with complete shared typing,
occurrence, profile, latent graph and allocation coverage. Therefore there
is **no semantic underdetermination result**. The high-level selected
typed-path principle must remain binding; a hand-written Ret-only machine
would not establish an alternative accepted meaning. Failure to derive an
exact row batch is not permission to select that machine.
