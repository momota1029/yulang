The native kernel in `candidate_scope` :106–130,:134 onward,:190 onward gives
these local equations for arbitrary supplied states:

```text
Stamp_i(I,P)       = (I union {i}, P)
Protect_s,i(I,P)   = (I, P union ({s} if i notin I else {}))
Release_s(I,P)     = (I, P minus {s})
(T_lower then T_upper)(S) = T_upper(T_lower(S)).
```

Thus the Function result port preserves *all* initial protections while adding
the designated scope only under its actual missing-input condition. If an
independent `t != s` is already in `P`, it remains. If `i` is already in `I`, no
new `s` is added. Evaluating on `([],[])` can respectively omit `t` or add an
unjustified `s`; these are algebraic discriminants, not established reachable
counterexamples for this source.
